## Highlights (Official `0.5.20` Release Notes & Static Evidence)

- **Cloud Tasks (`cloud-session:*` & `automations.*`)**: Official notes introduce creating or continuing cloud tasks in desktop, tracking progress, and viewing generated files. Static macOS `arm64` diffs corroborate `14` new `cloud-session:*` IPC channels, an expanded `automations.*` IPC surface, `+6` new `AUTOMATION_TASK_*` error codes (expanding from `2` pre-existing `0.5.18` entries to `8`), renderer copy (`"The cloud task name is too long. Shorten it and save again."`), and worker `/tasks` completion notice. Cloud execution depends on server-side services and was not runtime-verified.
- **Cross-Device Collaboration (`automationPeer.*` & Peer File Download)**: Official notes add downloading files from a connected device's workspace and permission-scoped automation management. Static diffs add `19` `automationPeer.*` renderer keys, `downloadArtifact`, `chatSession.fileDownload.*` / `Resources/runtime/file-transfer.cjs`, and main-process permission markers `automations.read.v1` / `automations.manage.v1` (`automationsRead` / `automationsWrite`). Actual authorization granularity is governed server-side and was not runtime-verified.
- **Local Task Recovery After Quit or Update**: Official notes add resuming eligible unfinished local tasks after quitting or updating Qoder. Static diffs add `chat-session-recovery:{changed,decide,get}`, `.recoveryPhase`, SQLite migration `20261119-00-chat-session-restart-resumption.sql`, and renderer prompts (`"This run was interrupted while the device was offline or asleep."`, `"Restore all tasks"`).
- **Managed Device Sign-In**: Official notes let enterprise administrators restrict managed-device sign-in to enterprise accounts from approved organizations. Static diffs add `auth.deviceAccountBlocked.{confirm,description}`, `"Device account policy rejected the current login"`, `"Enterprise VPC sign-in"`, and worker browser sign-in / organization plugin-lock strings. Enterprise policy schemas and enforcement are server-dependent and cannot be verified statically.
- **Archive Group Actions, Extra-Large Text & 125% Scaling**: Official improvements add group restore/delete for archived local tasks (search bulk delete affects matching items only), extra-large text for conversations and the message box, and independent `125%` interface scaling. Static diffs confirm `restoreGroupTasks` / `archivedGroupMore` / `deleteArchiveSearchResults*` renderer keys and `fontSizeExtraLarge` / `uiScaleExtraLarge` entry strings only (no plaintext layout parameters were verified).
- **Fixes (With Static Attribution Boundaries)**:
  - *Plugin installation failures after data directory migration & plugin background services failing to start in restricted Windows environments*: Worker adds archive-directory/symlink install guards (`Refusing to install: archive directory is not a real directory (`) and `actionId` retry guidance; `pluginHost.js` grows `+1,487` B; macOS `arm64` diff also removes `Resources/plugin-lifecycle/{WindowsPluginJob.cs,windows-job.ps1}` (a PowerShell `Add-Type` C# job helper). Neither scenario can be attributed line-by-line from static evidence alone.
  - *Background disconnect blocking the next automation run after previous results were saved*: Corroborated structurally by new SQLite migrations `20261121-00-automation-run-retry-count.sql` and `20261121-01-automation-manual-pending-index.sql` (not runtime-verified).
  - *Conversations unable to start with a valid model selected*: Worker adds sign-out / model-reselection guidance (`Run /auth to sign in again, or /model to choose another model.`); exact valid-model startup root cause cannot be attributed line-by-line statically.
  - *Remote Control messages appearing out of order when earlier messages synced later*: Corroborated by migration ID `20261123-01-async-question-order-clock` and `.messageOrder` / `.supportsMessageOrder`.
