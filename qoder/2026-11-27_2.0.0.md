## Highlights (Two-APK Static Evidence — No Official `2.0.0` Release Notes)

- **QBot Assistant Experience (`features/qbot`, `335` New `qbot.*` Localization Keys & `/api/v1/qbot/*`)**:
  - Introduces a major new assistant mode (`qbot` / `qbot_list` in `AndroidManifest.xml`, `features/qbot` package, `QBOT_ARTIFACT_*` and related event codes, and `31` new `/api/v1/qbot*` DEX API paths vs. `0` in `0.11.0`) covering initialization, bot listing, avatars, environments, events, file uploads/content, pause/resume, schedules (`pause`/`unpause`), VM message items (`read`, `quote-chain`, `unread`), worker tasks, connector cards/actions, and artifact browsing/download (`/signed-artifact-download`).
  - Adds `335` `qbot.*` keys across `assets/dynamic-content/qoder-mobile.{en,zh}.json` (`2,220 → 2,572` keys, `+352`), including onboarding/naming placeholders (`Call me Qbot, or pick a name you like` / `Call me %1$s, or give me a name of your own`), attachment limits (`You can attach up to 10 images and 5 files.`), and pause confirmation (`Pausing %1$s will stop your ongoing follow-ups and delegated tasks. Pause it?`).
  - Ships dedicated QBot visual, audio, and icon assets (`qbot_*` images/GIFs/SVGs, `qbot_gear_tick.wav`, `ic_qbot_image_share.xml`, `qbot_home_unread_badge.xml`, `qbot_task_activity.xml`), dual-mode navigation drawer icons (`drawer_home_mode.png`, `qbot_drawer_mode.png`, `qbot_list_add.png`), an artifact file-icon font (`artifact_file_icons.ttf`), and Figma connector SVG assets (`qbot_connector_figma.svg`, `qbot_connector_figma_mark.svg`). Note: `streamable_http` does **not** appear in `2.0.0` DEX, so desktop `0.5.21` Streamable HTTP sync is **not** independently corroborated in this APK.
- **Biometric & Local Device Remote-Control Authorization (`USE_BIOMETRIC`)**:
  - `AndroidManifest.xml` newly requests `android.permission.USE_BIOMETRIC`.
  - Adds `device_management.remote_control.*` authorization copy covering biometric prompt reason (`"Allow Qoder Mobile to remotely control this device"`), device passcode fallback (`"Use device passcode"`), and keeping the device awake while Qoder is running (`"Keep this device awake"` / `"Prevent this device from sleeping automatically while Qoder is running."`).
- **Automation Schedules, Run Endpoints & Onboarding Visuals**:
  - Extends automation capabilities with QBot schedule endpoints (`/api/v1/qbot/{bot_id}/schedules`, `pause`, `unpause`), newly added `/api/v1/qcloud/cloud-automation-runs`, `/api/v1/remote/automations`, and `/api/v1/remote/automation-runs` paths (note that many other `/api/v1/qcloud/*` and `/api/v1/remote/*` endpoints—such as `/api/v1/qcloud/cloud-automations`—already existed in `0.11.0`), `automation_history_empty_pendulum.webp`, and editor-connection onboarding GIFs (`home_connect_editor_{en,zh}_{dark,light}.gif`).
