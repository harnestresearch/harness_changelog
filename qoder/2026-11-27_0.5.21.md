## Highlights (Official `0.5.21` Release Notes & Static Evidence)

- **Feature — AppHub Connector Sync (`streamable_http` & `cloud-configuration:*`)**: Official release notes introduce AppHub connector sync, uploading locally authorized Streamable HTTP connectors to the cloud for use by cloud agents and automations. Static inspection of extracted macOS `arm64` metadata verifies new renderer literals `appHubError`, `loadingSyncSources`, and `streamable_http` (new in the renderer layer), new main-process IPC/permission strings `cloud-configuration:list-apphub-items` and `cloud-configuration:sync-apphub-vault`, and two credential-chain telemetry strings (`SDK JobToken callback failed` and `SDK JobToken callback returned no credential`). Actual cloud sync execution resides in obfuscated/server-side paths and was not verified at runtime.
- **Improvement — Re-Run Network Diagnostics Prompt After Proxy Changes (Statically Unverifiable)**: Official notes state that after changing proxy settings, the sign-in screen and Settings prompt the user to re-run network diagnostics. No corresponding new plaintext strings were confirmed in static inspection (consistent with the unchanged decoded worker string table and the static diff report's finding of no new prompt copy); this item **cannot be verified statically** in the binary diff.
- **Fixes (Four Official Items — Statically Unverifiable Line-by-Line)**:
  - *Cloud automation editing*: Prevents removed Skills/connectors from remaining behind and avoids clearing selections before resource lists finish loading.
  - *Device clock skew*: Stops clock skew from mistakenly rejecting valid registration, pairing, or reconnection.
  - *System proxy model list*: Fixes local tasks failing to load the model list under a system proxy.
  - *Windows OpenSSH host verification*: Fixes Windows OpenSSH host verification failures (on connection or reconnect after host/address changes).
  - *Static evidence boundary*: All four fixes exist in the official `2026-11-27` release notes, and the decoded worker string table is completely identical between `0.5.20` and `0.5.21` (`13,966 === 13,966`, zero additions or deletions), matching the static diff report's finding of no new fix-specific UI/worker strings. None of the four fixes can be independently confirmed line-by-line from static package diffs alone.
