# Cursor Desktop 3.30.14

English | [简体中文](../zh-CN/cursor/2026-11-14_3.30.14.md) · **Highlight** | [Full Detail](../full/cursor/2026-11-14_3.30.14.md)

- **Release Date**: 2026-11-14 (CDN release time: `2026-11-14 04:27` UTC+8 / `2026-11-13 20:27:26` GMT; not yet listed on the official Cursor changelog)
- **Platforms**: `mac`, `win`, `ubuntu`

## Highlights

- **Live Web App Publishing ("Deploy App", Feature-Gated)**: Ships default-off client support for turning prototypes built in chat into live, shareable web apps (*"Build Live, Shareable Apps with Cursor"* / *"Deploy Folder"*), including deploy-intent suggestions in local chat, cloud project migration (excluding dependencies, build output, and `.env` files), publish proposal confirmation, app update/redeploy/unpublish controls, and local dev-server preview cards.
- **Granular Team Repository & Path Glob Governance**: Expands enterprise team repository allowlists and blocklists from whole-repository URL matching to wildcard repositories (`*`), organization URL globs (`org-*`), and in-repository file path glob rules—defaulting to blocking unapproved paths when a team allowlist is active (while exempting Cursor's own data directory).
- **Zen Mode Tab Bar Option, Side-Chat Metadata & Grok Config Support**: Adds *"Hide Tab Bar in Zen Mode"* copy in the Agents (`glass`) surface, records subagent types on side chats, distinguishes calling window layouts in the local agent daemon, and adds desktop support for reading local `~/.grok` configuration files and submitting Grok feedback.
- **Electron Runtime Patch Update (`43.8.4` → `43.8.9`)**: Upgrades the bundled Electron runtime across macOS, Windows, and Linux alongside recompiled file-watcher and syntax-tree native bindings, while keeping all `3.30.8` agent tools, MCP connectors, and Remote Control capabilities unchanged.
