- **Release Date**: 2026-11-12 (Package release times: Windows & macOS `2026-11-12 06:23` UTC+8, Linux `2026-11-12 10:26` UTC+8; not yet listed on the official Cursor changelog)
- **Platforms**: `mac`, `win`, `ubuntu`

## Highlights

- **Enterprise MCP Policies, Step-Up Auth & Session Governance**: Enforces team-level MCP server allowlists, denylists, Cloud Agent allowlists, and read-only or per-tool access rules directly in the desktop client with clear policy-block notices; expands organization admin capabilities with Step-Up secondary authentication, third-party OAuth app management, API key inventory controls, and member session revocation.
- **Expanded Remote Control Actions & Cryptographic Pairing Proof**: Remote controllers (including Cursor iOS) can now archive, pin, or mark sessions unread, restore local file checkpoints, list or update local MCP servers, and watch daemon reports—while strengthening device pairing with a cryptographic `pairing_proof` verification step.
- **MCP Event-Triggered Automations, App Documents & Kalshi Connector**: Background automations can now trigger directly from MCP server events, MCP tools can return interactive app documents alongside execution results, the built-in MCP extension adds a Kalshi connector (and removes legacy Outlook, OneDrive, and Teams blocks), MCP state can share across Git worktrees, and OAuth discovery automatically backs off on `429`/`503` rate limits.
- **Team Access Tool, Orbit Airlock Container Controls & Idle Update Relaunch**: Added a team/collaborator access-management agent tool (`manage_access`) and a server-dispatched `execute` fallback tool (with client-side rejection support), Orbit Airlock local-turn admission controls with Docker/Podman container engine abstraction, idle auto-update relaunches, PowerShell process pool pre-warming on Windows, and voice chat toggles.
- **Staged "Grok Build" Branding & Molten Agents Window Rollouts (Feature-Gated)**: Ships default-off client support for an upcoming *"Cursor is now Grok Build"* onboarding flow in the Agents surface (alongside Grok calendar, shopping cart, try-on, messaging, credit billing, and `api.x.ai` real-time voice probes) and an Agents Window (`molten`) open beta with local Git AI-attribution tracking gated by Privacy Mode.
