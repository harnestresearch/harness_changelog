# WorkBuddy Desktop 5.9.4

English | [简体中文](../zh-CN/workbuddy/2026-10-29_5.9.4.md) · **Highlight** | [Full Detail](../full/workbuddy/2026-10-29_5.9.4.md)

- **Release Date**: 2026-10-29
- **Platforms**: `mac`, `win`

## Highlights

- **7 New Interface Languages, Message Center & PPT Presenter View**: Added Japanese, Korean, French, European Spanish, Vietnamese, Thai, and Arabic UI translations, a centralized Message Center, local PowerPoint slideshow playback with Presenter View, and automatic light/dark system theme following.
- **High-Credit Tool Confirmations & Richer Artifact Previews**: Prompts for confirmation before running credit-intensive image/video generation tools, and upgrades artifact tabs with `Ctrl+Tab` switching, double-click rename, right-click image Copy/Save As, chunked large-Markdown & frontmatter rendering, and Refresh/Save As prompts when local files change on disk.
- **Interactive Visual Widgets, Enterprise Knowledge & Deep Research**: Renders live diagrams, UI mockups, charts, and interactive widgets inline beside replies; searches authorized content across WorkBuddy Library, Tencent ima, Tencent Docs, Tencent Meeting, and Tencent Drive; supports per-conversation local memory toggles with cached summary fallbacks; and delegates multi-step domain research.
- **Full-Stack App Publishing, Serverless Cloud, Mini Programs & Automations**: Deploy static sites and Node/Python/Go apps to custom subdomains, provision managed Serverless backends, scaffold native WeChat Mini Programs, and run scheduled tasks with clearer failure diagnostics and reliable post-sleep catch-up runs.
- **Stronger Connector Security, Multi-IM Channels & Desktop Stability Fixes**: Enforces Security Center network rules on remote connectors, adds pre-chat connector suggestions, incremental Gmail sign-in, and automatic OAuth token renewal; integrates WeCom, Feishu/Lark, DingTalk, Slack, QQ Bot, Office editors, and optional local CPU/GPU LLMs; and fixes subagent task-cancellation status bugs, WPS file locks, and Windows/macOS updater & IME stability issues.
