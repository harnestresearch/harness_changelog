- **Release Date**: 2026-09-18
- **Platforms**: `mac`, `ubuntu`

## Highlights

- **Connector-Aware Link Previews**: Automatic link recognition and title previews for Notion, Slack, GitHub, GitLab, and Azure DevOps URLs.
- **Expanded Cloud Agent Workflows**: Added cloud task modes for monitoring pull requests, automated bug fixes, investigating CI build failures, and running tasks in parallel.
- **Team Bot Starter Tasks & Skill Ecosystem**: Added guided starter tasks for team Bots, required/default/optional team plugin install policies, and cross-ecosystem skill source support.
