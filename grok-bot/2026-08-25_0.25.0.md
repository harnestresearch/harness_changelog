# Grok Bot 0.25.0

English | [简体中文](../zh-CN/grok-bot/2026-08-25_0.25.0.md) · **Highlight** | [Full Detail](../full/grok-bot/2026-08-25_0.25.0.md)

- **Release Date**: 2026-08-25
- **Platforms**: `mac`, `win`

## Highlights

- **Bot Templates & Customization**: Create Bots from reusable templates in the new Templates pane, customize Bot avatars, and inspect scheduled tasks in the automation detail panel.
- **Remote Computer Control & Multi-Member Rooms**: Added remote control support for running tasks on your computer, multi-member chat rooms combining teammates and Bots, and guided onboarding.
- **Chrome Login Import & Notification Sounds**: Import existing Chrome browser profiles and login sessions for web tasks, choose from 5 built-in desktop notification sounds, and enable initial voice model settings.
