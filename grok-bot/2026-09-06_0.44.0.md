# Grok Bot 0.44.0

English | [简体中文](../zh-CN/grok-bot/2026-09-06_0.44.0.md) · **Highlight** | [Full Detail](../full/grok-bot/2026-09-06_0.44.0.md)

- **Release Date**: 2026-09-06
- **Platforms**: `mac`, `win`, `ubuntu`

## Highlights

- **Account Merging & Team Bots**: Added candidate detection and guided runs for merging duplicate accounts, alongside admin views for managing team-level Bots and sandbox migrations.
- **In-Chat Secret Prompts & Auto-Review**: Bots can request required credentials via an interactive submission card in chat; added auto-review enforcement toggles and automatic cloud repository setup during onboarding.
- **Security Keys & Linux Self-Updates**: Added PIN prompts for hardware security keys and built-in self-update support for Linux AppImage installations.
