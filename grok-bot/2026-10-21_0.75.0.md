# Grok Bot 0.75.0

English | [简体中文](../zh-CN/grok-bot/2026-10-21_0.75.0.md) · **Highlight** | [Full Detail](../full/grok-bot/2026-10-21_0.75.0.md)

- **Release Date**: 2026-10-21
- **Platforms**: `mac`, `win`, `ubuntu`

## Highlights

- **X, Shop & Cloudflare Connectors**: Added official connectors for X, Shop, and Cloudflare (covering D1 databases, DNS, and zones), plus a custom tool server setup form.
- **Memory Import, Quoted Replies & 1Password Moves**: Import existing memories into Grok Bot, quote specific messages when replying in chat, and move 1Password credentials between vaults.
- **Tray Animations, Diagrams & Login Recovery**: Expanded menu bar Bot animations (dictating, sending, writing, humming, powering down), added a new diagram rendering engine and chat wallpapers, and added "Reopen" / "Copy link" recovery actions if browser sign-in stalls.
