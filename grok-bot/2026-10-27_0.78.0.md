# Grok Bot 0.78.0

English | [简体中文](../zh-CN/grok-bot/2026-10-27_0.78.0.md) · **Highlight** | [Full Detail](../full/grok-bot/2026-10-27_0.78.0.md)

- **Release Date**: 2026-10-27
- **Platforms**: `mac`, `win`

## Highlights

- **macOS Mail Setup & Expanded Tool Permissions**: Added a guided macOS Mail setup dialog and granular Once/Always/Deny/Never approval prompts for sending mail, making phone calls, and controlling local apps.
- **Stripe Link & Shop Pay Wallets**: Expanded supported payment wallets for Bot commerce workflows to include Stripe Link and Shop Pay.
- **Security & Update Diagnostics**: Strengthened connector token verification with post-quantum signature protection, and added Apple Silicon Rosetta warnings plus clearer restart-to-update prompts.
