# Grok Bot 0.46.0

English | [简体中文](../zh-CN/grok-bot/2026-09-09_0.46.0.md) · **Highlight** | [Full Detail](../full/grok-bot/2026-09-09_0.46.0.md)

- **Release Date**: 2026-09-09
- **Platforms**: `mac`, `win`

## Highlights

- **1Password Credential Integration**: Connect 1Password service accounts so Bots can request vault credentials with per-request approval, denial, or "Always allow" rules.
- **GitLab, Bitbucket, Azure DevOps & Webhooks**: Expanded source-control connectors beyond GitHub to GitLab, Bitbucket, and Azure DevOps, and added webhook notifications for pull request, review, CI, and issue events.
- **Plugin Marketplace, Account Unification & Diagnostics**: Introduced the cloud Bot plugin marketplace, Cursor/Grok account unification, team data export downloads, automatic update channel controls, and a built-in network diagnostics debugger.
