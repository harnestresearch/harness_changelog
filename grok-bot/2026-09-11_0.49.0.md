# Grok Bot 0.49.0

English | [简体中文](../zh-CN/grok-bot/2026-09-11_0.49.0.md) · **Highlight** | [Full Detail](../full/grok-bot/2026-09-11_0.49.0.md)

- **Release Date**: 2026-09-11
- **Platforms**: `mac`, `win`

## Highlights

- **Bot Canvas Editing & Expanded Connectors**: Bots can now directly read and update Canvas workspaces; completed live sign-in callbacks for GitLab, Bitbucket, and Azure DevOps, and added Linear issue summaries plus Google BigQuery and Slides access.
- **Skills, Secrets & Messages Allowlist**: Added UI to create and edit custom Bot skills, manage per-server secrets, and view or revoke allowed macOS Messages recipients.
- **Team Bot Console & System Accent Colors**: Added team context, plugin, and secret management sections, marketplace search, team member spend breakdowns, clearer 1Password setup guidance, and automatic OS accent color matching.
