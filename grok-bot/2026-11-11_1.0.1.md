# Grok Bot 1.0.1

English | [简体中文](../zh-CN/grok-bot/2026-11-11_1.0.1.md) · **Highlight** | [Full Detail](../full/grok-bot/2026-11-11_1.0.1.md)

- **Release Date**: 2026-11-11
- **Platforms**: `mac`, `win`, `ubuntu`

## Highlights

- **Spotlight Quick Input & Desktop Runtime Upgrade**: Added a Spotlight-style quick input bar, saved window size and maximized state across restarts, faster chat code syntax highlighting, country flags in language selectors, and an upgraded desktop runtime for improved performance and stability.
- **Status Chimes & Voice Reachability Diagnostics**: Added optional Status Chimes audio cues (task sent, result returned, awaiting decision, error) and voice call reachability diagnostics that identify regional, network tunnel, or certificate blocks.
- **iMessage Group Chats & SMS Phone Linking**: View iMessage group chat logs, allow Bots to leave group chats, and link phone numbers via SMS verification codes.
- **Cart Checkout, Car Rentals & Travel Cards**: Added shopping cart checkout initiation and cancellation, car rental search and detail cards, airline logos and click-to-book flight links, gift delivery date validation, saved promo codes, and virtual try-on photo deletion.
- **Bot Preferences, Dual-Model Evaluation & Team Governance**: Added multi-layer Bot preferences, private files and skills controls, immediate automation runs and card reruns, admin side-by-side dual-model comparison, team sandbox self-tests, enterprise spend limits, and connector policy allowlists.
- **Graduated 0.79 Capabilities**: Brings privacy mode, training opt-in controls, Passkey sign-in, Google Calendar and meeting prompts, interactive iMessage approval cards, full-text transcript search, the Agent Store marketplace, QuickBooks & Tailscale connectors, and 1Password vault connections into the 1.0 stable channel.
