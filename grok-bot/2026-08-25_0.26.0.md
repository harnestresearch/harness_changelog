## Highlights

- **Team & Organization Governance**: Added organization service account management, team credit grants, and one-click reset of team or group Bot run modes to auto-review.

- **Link Previews & Code Highlighting**: Added rich web link previews in chat, expanded code syntax highlighting across 80+ programming languages, and significantly reduced the app package size.
