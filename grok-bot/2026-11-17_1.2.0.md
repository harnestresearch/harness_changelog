## Highlights (Statically Observed in Linux `x64` `.deb` & macOS `arm64` `.dmg`)

- **Slack Workspace Install Flow & Per-Bot Third-Party Connections**: Added client protocol state machines and UI strings (`"Connect Slack"`, `"Return to Slack"`) for team-level Slack workspace installation, status lookup, and uninstallation (covering already-installed, rate-limited, and rejected states), alongside per-Bot listing and disconnection of authorized third-party apps (paired with a `grok_bot_connected_apps_settings` gate and connector link/auth UI bundles).
- **Skill Revision History, Rollback & Team Publishing Prompts**: Added client support for listing and reverting Skill revisions (attributed to either a person or a Bot), a skill change-diff view, chat skill-link gating, and team skill-publishing validation copy (requiring a description and Cursor team publishing permissions).
- **Public Changelog Feed, Order Status Lookup, File Store Previews & Flight Copy**: Added a client-facing read-only public changelog endpoint, shopping order state lookup, messaging contact photo retrieval, Bot vs. User file-store read resolution with file preview and library gates, five flight-search status strings (`"Searching flights"`, `"Checking the fare"`, `"Sorting flights"`, `"Searching {route}"`, `"Looking over the results"`), and updated fallback status wording to `"Grok's servers did not report a status"`.
- **MCP Governance, Microsoft 365 Admin Consent & Squarespace Connector**: Added Grok SSO sign-in flags and organization block-reason messages on MCP server entries, team MCP allowlist admin settings, a restricted `"connectors-only"` access mode, a built-in Squarespace MCP host (`mcp.squarespace.com`), and Microsoft 365 (Excel, OneDrive, Outlook, Power BI, SharePoint) icons with tenant admin-consent approval link prompts, while removing the desktop MCP iframe `unsafe-eval` gate (`allowEval`).
- **Cloud Agent App Secrets Preload Wiring, Account Switch on Sign-Out & Security Controls**: Wired five desktop preload methods for the `1.1.0` Cloud Agent **App Secrets** subsystem (creating, reading, listing available, declining, and widening secret scopes), added optional direct account switching on sign-out (`switchToAccountId`), a dismissible update-restart prompt, vault-saving flags on SMS form submissions, designated team Bot sharers and enterprise seat grant states, tighter local-tool approval target wording, and a default-off system-proxy auto-follow gate (`sand_system_proxy_auto`) for sandbox outbound networking.
- **Android Device Control Tool Slot & Client Surface Adjustments**: Added an `AndroidControlDevice` slot in the static agent tool registry and local approval enum while removing four task CRUD tool entries (`CreateTask`, `ReadTask`, `UpdateTask`, `DeleteTrackedTasks`—a static coordinator tool-registry change that retains `UpdateTrackedTaskTags` and adds task status `description` fields rather than retiring product-wide task features); removed client-side Factory UI chunks, preload telemetry hooks, and the `grok_bot_factories` gate while keeping Factory RPC/protobuf definitions intact; and removed standalone `telegram.png` / `whatsapp.png` icon files while retaining their bundle identifiers.
