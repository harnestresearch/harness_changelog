# Grok Bot 0.62.0

English | [简体中文](../zh-CN/grok-bot/2026-09-28_0.62.0.md) · **Highlight** | [Full Detail](../full/grok-bot/2026-09-28_0.62.0.md)

- **Release Date**: 2026-09-28
- **Platforms**: `mac`, `win`

## Highlights

- **Animated Meeting Avatars**: Bots joining Google Meet and Zoom calls now appear with an animated visual avatar persona and color whiteboard stroke rendering.
- **Spell Check & Clearer Status Guidance**: Added "Add to Dictionary" in the editor context menu, clearer Slack reinstall troubleshooting prompts, and alerts when macOS Messages is turned off.
- **Chinese & Cantonese Locale Support**: Added Simplified Chinese, Traditional Chinese, and Cantonese language detection, plus safeguards preventing auto-review settings from crossing accounts.
