# Grok Bot 1.1.0

English | [简体中文](../zh-CN/grok-bot/2026-11-14_1.1.0.md) · **Highlight** | [Full Detail](../full/grok-bot/2026-11-14_1.1.0.md)

- **Release Date**: 2026-11-14
- **Platforms**: `mac`, `win`, `ubuntu`

## Highlights

- **Factories Multi-Step Pipelines**: Added declarative YAML **Factories** to author, schedule, run, and manage multi-step automated Agent pipelines directly in Grok Bot.
- **Cloud Agent Apps & Page Publishing**: Added end-to-end hosting and publishing for Cloud Agent apps and pages, complete with scoped **App Secrets** management, pre-publish security reviews and overrides, live previews, and team/organization audience sharing controls.
- **Spotlight Screen Element Picker & Local Meeting Recorder**: Extended Spotlight with an interactive screen element picker overlay, introduced a local meeting recording & **Local Pitman** meeting assistant flow, and added speaker diarization (`speaker` turn separation) to real-time speech-to-text transcripts.
- **Purchase Auto-Approval, Spend Limits & X App Approval**: Added configurable purchase auto-approval with per-currency spend limits, X Money spend challenges, and **"Approve in the X app"** confirmation prompts, alongside richer order, place, and shopping status cards.
- **Account Phone Verification, Mobile QR Pairing & GitHub Connect**: Added account-level SMS verification, SMS-authenticated form links, a QR code sheet to pair the mobile app with desktop, and an integrated GitHub / SCM repository connection flow.
- **Cursor ↔ xAI Team Unification & Enterprise Network Security**: Added guided Cursor and xAI account/team merging, organization-wide network blocklists, team-managed Tailscale exit nodes, policy-enforced sandboxing, task-to-transcript linking with tags and pull requests, threaded chat replies, and an upgraded desktop runtime.
