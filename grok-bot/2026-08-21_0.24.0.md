# Grok Bot 0.24.0

English | [简体中文](../zh-CN/grok-bot/2026-08-21_0.24.0.md) · **Highlight** | [Full Detail](../full/grok-bot/2026-08-21_0.24.0.md)

- **Release Date**: 2026-08-21
- **Platforms**: `mac`, `win`

## Highlights

- **Desktop Agent Workspace**: Initial desktop release featuring multi-model conversations, local command execution, cloud sandbox task execution, and credential storage.
- **Rich Formatting & Document Reading**: Built-in rich-text message composer with math formula and diagram rendering, plus support for reading PDF, Word, and Excel documents.
- **App Integrations**: Built-in support for connecting Google Workspace (Gmail, Calendar, Drive, Docs, Sheets, Slides), Slack, Notion, Salesforce, Stripe, Telegram, and Todoist.
