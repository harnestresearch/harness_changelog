## Overview

Switched OAuth architecture to platform.claude.com (including CLI API key issuance and credit purchases), introduced dedicated FedStart domains and mcp-proxy.anthropic.com; made the Buddy desktop accessory repository public; converted web install-hub icons to PNG and added Apple channel icons; reverted the index2 chunk experiment.

## Changes

- **Components & Native Modules**: No new binaries.
- **Main Process (`app.asar`)**: +117 -357 ~36 (renames 0) — fully retired the index2.chunk-* family (130 chunks) introduced in the previous release, restoring a single index.chunk namespace; reorganized heavy-work and standard chunks.
- **Web UI (`ion-dist`)**: 1072 added, 1004 deleted, 145 genuinely new: converted all install-hub icons to PNG and added apple-icon/apple-icon-white (Apple/iMessage channel); added vendor-motion (animation library) and preload-helper; removed vendor-datadog, vendor-intl, vendor-frame, etc.
