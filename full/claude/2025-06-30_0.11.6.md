## Overview

Routine rebuild release: rewrote stdin handling in the MCP runtime alongside a full chunk reshuffle, with no user-visible functional changes.

## Changes

- **Components & Native Modules**: Unchanged (claude-swift libSwiftCode.a recompiled with no API changes)
- **Main Process (`app.asar`)**: +10 -10 ~12 (renames 0); all 10 hashed chunks (index.chunk-* and per-window renderer assets) rehashed, with no named files added or removed. The sole substantive modification to a named file is `.vite/build/mcp-runtime/nodeHost.js` (+70/-18) — replacing the previous fakeStdin approach that spoofed `process.stdin` with per-method wrapping (read/push/pause/resume/pipe/on...) when `process.stdin` is present, rewriting the MCP host's stdin bridge; all other diffs are version number, Sentry debugId, and artifact id replacements.
