## Overview

A read-only static XAPK, manifest, resource, DEX string-pool (`171,650 → 173,615`, `+23,574 / −21,609`), and jadx `1.5.6` decompilation diff of `com.anthropic.claude` (`1.261123.19` → `1.261124.19`). Neither APK was installed or executed. On the packaging side, XAPK entries drop `37 → 30` (language splits `28 → 21`) while all `20` native `.so` libraries remain byte-identical and manifest permissions (`66`) and components (`83`) stay unchanged. At the code and resource layers, the update expands GitHub integration (`connect_github_card` telemetry, Claude GitHub App install prompts, PR/plan/tool-call approval error taxonomy, cloud-environment setup copy), introduces ~12 safeguards auto-model-switch strings on mobile, adds a `places_list` Places panel, adds usage-page sections, default-tab settings, PHI-exclusion project instructions copy, read-aloud limit and sign-in/error copy, and removes `continue_on_cloud.*` (`8 → 1`), `ready_made_card.rated`, and `money.message_box.*`—with **zero API endpoint additions or removals**.
