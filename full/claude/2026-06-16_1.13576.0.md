## Overview

Feature release: added the Bedrock Mantle gateway and Claude API credential types, a managed toggle for beta features, streamlined `office365-mcp` packaging layout, and introduced a `.deb` packager in preparation for Linux distribution.

## Changes

- **Dependencies**: `claude-agent-sdk` 0.3.170 → 0.3.177 (`future` → 0.3.174-dev.20260610); added dev dependency `@electron-forge/maker-deb ^7.8.3` (Linux `.deb` packaging in preparation for a Linux build); `typescript` ~6.0.3, `oxlint` 1.67.0
- **Components & Native Modules**: Repackaged `office365-mcp`: moved native MSAL libraries up from `node_modules/@azure/msal-node-runtime/dist/` to the `resources/office365-mcp/` root directory (73 `node_modules` files removed, 2 renamed), `office365-mcp.mjs` 6.53MB → 6.62MB
- **Main Process (`app.asar`)**: +11/-73/~19, renames 2. `index.js` +97KB: added gateway type `mantle` (display name "Bedrock Mantle", adding a new tier to the `gateway`/`anthropic`/`bedrock`/`mantle`/`vertex`/`foundry` gateway enum), credential type labels "Claude API" / "Claude API key", managed configuration `betaFeaturesEnabled` ("Allow beta features", defaulting to `true`), and error class `AllModelsRestrictedError`
- **Web UI (`ion-dist`)**: +411/-433 assets; removed entry point `frame-gallery.html` (which existed for only three weeks across 1.11847.5–1.12603.1); updated `frame-shell.html` and 11-language i18n
- **UI & Experience**: Added "Bedrock Mantle" gateway type and "Claude API (key)" credential option in settings; administrators can configure "Allow beta features"
