## Overview

Major version bump 3→4 is an engineering milestone: the web frontend and language packs are fully packaged into asar archives with integrity verification, significantly consolidating the Resources directory; smol-bin images also expand.

## Changes

- **Dependencies**: Shipped package.json strips all devDependencies (build artifact cleanup; runtime dependencies unchanged)
- **Components & Native Modules**: **Added `Resources/ion-dist.asar` (4,532 files, ~190MB)**: the formerly loose Resources/ion-dist directory (4,458 files) is packed into an asar archive and registered in the main Info.plist asar integrity hash table (`Resources/ion-dist.asar` SHA256 entry); ~50 Resources/*.json language packs moved into app.asar `resources/i18n/` (43 files) + dynamic i18n; Resources/quick-actions and claude-browser-shim.js moved into app.asar as well; dual-architecture smol-bin images grew from 24MB→27MB (+3MB per architecture, expanded content)
- **Main Process (`app.asar`)**: +558/-491/~44; chunks +489/-468; heavy-work-worker/dist-*.js hashed sub-chunks renamed (dist-CI9lzb1v→dist-CqFVLHvr); 25 named bundles modified (first simultaneous appearance of the full set of stall-sampler-worker, pty-host, transcript-search-worker, and frame-local-worker)
- **Web UI (`ion-dist`)**: Migrated into asar; contains `audio/voice/` (voice mode sound effects: enter/exit_voice_mode, tool_approval_needed, and airy/buttery/glassy/mellow/rounded selection tones) and 67 install page icons under `images/install-hub/` (Android/Apple and other platform icons)
- **UI & Experience**: Voice mode sound effect assets and installation hub assets landed
- **Network & Endpoints**: Added `https://json.schemastore.org/claude-code-settings.json` (settings schema), `https://git-lfs.github.com/spec/`, `https://claude.com/docs/third-party/claude-desktop/overview.`, and git bisect/cherry-pick identifiers (deeper CLI git capabilities)
