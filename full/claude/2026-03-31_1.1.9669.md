## Overview

Launched the direct MCP host: the main process now bundles the full MCP SDK (Zod v4 validation, elicitation, OAuth DCR, tasks, and SSE), providing a runtime for third-party/direct MCP servers (the "direct host" mode corresponding to the `directMcpHost` name).
