## Overview

Reshaped claude-native responsibilities (added a standalone About window preload, fixed MCP host path loading, and upgraded MCP SDK and zod), and introduced the claude.com domain into the client.

## Changes

- **Dependencies**: `@modelcontextprotocol/sdk` 1.11.3 → ^1.12.1; `zod` ^3.23.8 → ^3.25.64
- **Components & Native Modules**: Replaced the claude-native dependency tree: removed rxjs/debug/ms, added `@malept/cross-spawn-promise` ^2.0.0, `listr2` ^8.2.4, and terminal rendering libraries (ansi-escapes/ansi-regex/ansi-styles/cli-cursor/cli-truncate/colorette, etc.); significantly narrowed the API surface: removed KeyboardKey, requestAccessibility, getWindowInfo, getMonitorInfo, InputEmulator, ScrollDirection, and MouseButton, while keeping getActiveWindowHandle/focusWindow/readRegistryValues/readPlistValue and adding `readCfPrefValue` (reading CFPreferences) — pivoting the native module from "input emulation / window inspection" to "window focusing + reading system config"
- **Main Process (`app.asar`)**: +126 -797 ~13 (renames 0). Added named bundle: `.vite/build/aboutWindow.js` (106371B, standalone preload for the About window). Fixed `mcp-runtime/nodeHost.js`: dynamic import now uses `node_url.pathToFileURL` (fixing loading of paths containing spaces and special characters).
- **UI & Experience**: None (en-US.json unchanged; recalculated es-419/en-XB and other locale JSONs)
- **Network & Endpoints**: Added `https://claude.com` (first appearance of the new primary domain in the bundle)
