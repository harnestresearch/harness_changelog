## Overview

Internationalization release: bundled `react-intl` and 16 locale packs, migrating all menu and settings copy to localized message keys; simultaneously upgraded to Electron 34.

## Changes

- **Dependencies**: Added @formatjs/intl ^2.10.7, react-intl ^6.7.2
- **Components & Native Modules**: Electron 33.3.1 → 34.0.2 (79 binary members updated); added 16 locale JSON files under Resources: de-DE, en-US, en-XA/XB (pseudo-locales), es-419, es-ES, fr-FR, hi-IN, id-ID, it-IT, ja-JP, ko-KR, pt-BR, and xx-AC/HA/LS (placeholders)
- **Main Process (`app.asar`)**: +4 -4 ~7 (renames 0). index.js 1,038,060 → 1,124,246 B (+86KB, react-intl runtime); mainWindow.js +0.3KB
- **UI & Experience**: Full app-wide i18n migration — menu bar (File/Edit/View/Developer/Window/Help), MCP settings ("Are you sure you want to remove the MCP server \"{serverKey}\"?"), and update notifications ("A new version is available. It will be downloaded and installed automatically.") all routed through react-intl message keys; added menu items "Start New Chat", "Show Main Window", "Set shortcut", "Open Documentation", etc.
- **Network & Endpoints**: Added formatjs.io documentation link (from library internals)
