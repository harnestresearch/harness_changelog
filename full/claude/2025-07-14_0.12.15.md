## Overview

Voice dictation and Quick Entry (⌥Space quick input with image attachment support) landed in this release, complete with microphone/speech-recognition permission declarations and claude-swift submission events; meanwhile, the local settings window was removed in favor of web-based settings.

## Changes

- **Dependencies**: `@anthropic-ai/dxt` 0.1.0-dev → ^0.2.3; added `esbuild` ^0.25.5
- **Components & Native Modules**: Added events to the claude-swift JS layer: `quickEntrySubmitted` (carrying prompt + imageBase64 for Quick Entry submissions), `capsLockChanged`, and `optionDoubleTapped`; recompiled libSwiftCode.a
- **Main Process (`app.asar`)**: +10 -25 ~17. Named deletions: removed the entire `.vite/renderer/settings_window/` directory (settings.html, window-shared.css, main-*.js, and 14 Anthropic brand OTF fonts: Copernicus×5, StyreneBLC×4, TiemposText×5) — retiring the local settings page and migrating settings to the web side. mainWindow.js and mainView.js each grew by ~300 lines (Quick Entry and dictation logic).
- **UI & Experience**: en-US.json -139 entries (copy for local settings, extension management, MCP configuration, launch-at-login, etc. removed alongside the settings window), +5 DXT installation confirmation entries ("Do you want to install {extensionName}?", etc.). Info.plist added `NSMicrophoneUsageDescription` ("Claude needs access to your microphone for voice dictation.") and `NSSpeechRecognitionUsageDescription` — introducing system permission declarations for voice dictation for the first time.
- **Network & Endpoints**: Added `https://preview.claude.ai` (preview environment domain)
