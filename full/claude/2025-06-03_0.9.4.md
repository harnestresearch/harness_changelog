## Overview

Major release spanning a month: upgraded to Electron 36, introduced a Swift native addon experiment and the `claude-studio` package (bundling an MCP permission server + React renderer + full bundled TypeScript toolchain), increasing zip size by +18MB.

## Changes

- **Dependencies**: Added claude-swift (file:../packages/claude-swift-node), claude-studio (link:../packages/claude-studio); devDeps electron 34.0.2 → 36.2.1; added resolutions node-abi 3.75.0
- **Components & Native Modules**: Added claude-swift native module: swift_addon.node (93KB, universal artifact alongside x64/arm64) + libSwiftCode.a + nothing.a distributed in the zip (app.asar.unpacked). js/index.js reveals experimental scaffolding: helloWorldClaudeSwift/helloWorldClaudeSwiftUI + "magicMade" event (Swift/SwiftUI bridge PoC). Electron jumped directly past 35 to 36.2.1 (accounting for most of the +18MB zip increase)
- **Main Process (`app.asar`)**: +83 -8 ~10 (renames 0). Added node_modules/claude-studio/ (dist/main, dist/mcp/mcpPermissionServer.js, renderer index.html, etc. — 78 named files + 5 hashed chunks); index.js 1,129,784 → 1,134,201 B
- **UI & Experience**: No new desktop UI strings; claude-studio's MCP permission server runs as a background component (see below)
- **Network & Endpoints**: Added http://localhost:3456/requestPermission and /makePermissionDecision
