## Overview

Major wave of enterprise features landed: managed configuration added an LLM inference gateway framework (`inferenceProvider` / `inferenceGatewayBaseUrl`/`ApiKey` / Bedrock `bearerToken`+VPCE+`region` / Vertex `project`+`region`+`credentialsFile`+`baseUrl` / Foundry `resource`+`apiKey` / `credentialHelper`+TTL / token window limits / `models` allowlist) and support for reading managed MCP configuration from the native Windows registry ("Native registry reading failed", "must be a JSON array of valid MCP server configs"); locally added a transcript search worker and `host_call_log` migration; hardened file permissions in the shell path worker.
