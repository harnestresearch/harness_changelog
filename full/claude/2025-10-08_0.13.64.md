## Overview

Upgraded to Electron 37.6.0; switched brand fonts to the new AnthropicSans / AnthropicSerif typefaces; introduced JWT dependencies (for organization extension signature verification); unveiled Claude for Chrome integration.

## Changes

- **Dependencies**: Added `jsonwebtoken` ^9.0.2 (distributed inside asar along with jwks-rsa, ecdsa-sig-formatter, buffer-equal-constant-time, semver, lodash, etc. — JWT verification for the extension / organization trust chain)
- **Components & Native Modules**: Full brand font replacement: removed StyreneBLC/TiemposText/Copernicus across Resources/fonts and all renderer assets, replacing them with variable fonts AnthropicSans-Italics/Romans-Variable-25x258.ttf and AnthropicSerif-Italics/Romans-Variable-25x258.ttf
- **Main Process (`app.asar`)**: +154 -59 ~12 (renames 0). index.js +321 lines (JWT and organization extension logic); added `quickEntryError` event to claude-swift (allowing submission failures to report back to the UI).
- **UI & Experience**: en-US.json +8: "Install Claude for Chrome", "Open Chrome Web Store", "Copy Link", "Open App Features", and "To use browser tools, install the Claude for Chrome extension, enable Native app integration in the extension settings, and restart browser." — marking the first appearance of Claude for Chrome browser extension integration
