## Overview

Ostensibly a rebuild release (chunk reshuffle + Sentry ID rotation), its substantive change is repointing the update feed to the `downloads.claude.ai` channel — the final preparatory step for the 0.x → 1.0 channel migration.

## Changes

- **Dependencies**: @electron-forge/maker-msix ^7.10.0 → ^7.10.2 (sole dependency change)
- **Components & Native Modules**: Unchanged (app.asar + claude-native + claude-swift)
- **Main Process (`app.asar`)**: +7 -7 ~23 (renames 0). All hashed chunks across the 4 renderer entries (about/find_in_page/main_window/quick_window) reshuffled (+7/-7 one-to-one); named bundles only rotated Sentry release ID (fc796f5b→fe3f5688) and debug IDs; index.js 1,833,773 → 1,836,074 bytes (+2.3KB).
- **Web UI (`ion-dist`)**: None (no ion-dist.asar in this series yet)
- **UI & Experience**: No additions or removals in en-US.json; added log/error strings "Auto-updates disabled because no update url" and "Electron safeStorage encryption is not available, cannot decrypt allowlist cache"
- **Network & Endpoints**: Added URL `https://downloads.claude.ai` in app.asar — introduced constant `Y6="https://downloads.claude.ai"` in main-process update logic, setting the feed URL to `${Y6}/releases/darwin/universal/RELEASES.json` (and `${Y6}/releases/win32/${arch}` on win32) to lay the groundwork for switching to the new release channel
