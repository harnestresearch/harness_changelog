## Overview

Enterprise governance groundwork release: added the `managed-config` dependency (managed IdP/OIDC configuration, with `issuer`/`authorizationUrl`/`tokenUrl`/`oidc`/`bootstrapUrl` validation and a `healthy`/`invalid_config`/`auth_failed` state machine visible in `index.js`), while adding organization restriction and spend-limit UI on the web frontend.
