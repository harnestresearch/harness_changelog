## Overview

Milestone release: upgraded Electron to 40.8.5; bundled the claude.ai frontend offline into the app for the first time (ion-dist, 781 files); removed the claude-ssh helper binary; added audio capture permission declaration; transitioned versioning scheme from 1.1.x (four-part) to 1.2.x (three-part).

## Changes

- **Components & Native Modules**: Electron 40.4.1 → 40.8.5 (~60 binary member changes); **first appearance of ion-dist**: added `Resources/ion-dist/` with 781 files — full offline bundle of the claude.ai web frontend (index.html 3.7KB, favicon, assets/v1/* hash chunks, install-hub/installer illustrations, settings, session SVG/PNG illustrations, etc.), i.e., bundled Web UI distribution; removed all 5 files under `Resources/claude-ssh/` (claude-ssh-darwin-amd64/arm64, claude-ssh-linux-amd64/arm64, version.txt; embedded ssh helper binary retired); added drizzle/sqlite/0005_execution_log.sql
- **Main Process (`app.asar`)**: +8 -7 ~15 (renames 0); added `.vite/build/shell-path-worker/index-BLUmpn_m.js` hash chunk (35KB); rewrote shellPathWorker.js into a multi-chunk structure
- **Web UI (`ion-dist`)**: First bundled release (781 files; ~300 files undergo rolling hash updates per release thereafter)
- **UI & Experience**: Added `NSAudioCaptureUsageDescription: "This app needs access to audio capture"` in Info.plist (macOS audio capture permission declaration, paving the way for microphone capture in recording and demo features alongside `watchRecord` / `onMicState`); new strings include date formatting ("MMM D, YYYY", etc.) and Sentry/winston diagnostic copy
- **Network & Endpoints**: No new real endpoints (winston/sentry reference URLs belong to library internals)
