## Overview

Introduced Claude Code mobile simulator tools: bundled iOS Simulator control helper (Facebook idb frameworks) + Android Emulator (adb) integration, accompanied by settings toggles, admin blocking policies, and Statsig dashboards ("Claude Code iOS Simulator" / "Claude Code Android Emulator" dashboard UUIDs); meanwhile, heavy-work worker incorporated node-forge PKI and gitignore matching capabilities.
