## Overview

Major release: upgraded Electron to 42.4.0 and bundled the built-in `office365-mcp` server for the first time (with native Microsoft MSAL authentication and PDF extraction), increasing installer size by ~8MB.

## Changes

- **Dependencies**: `electron` 41.6.1 → 42.4.0 (dev dependency; runtime framework replaced accordingly and 83 binaries re-signed); `claude-agent-sdk-future` → 0.3.167-dev.20260608; `vitest` ^3.2.6
- **Components & Native Modules**: Added built-in **office365-mcp** server: +68 files under `resources/office365-mcp/` inside `app.asar` (`office365-mcp.mjs` 6.5MB, `pdf.worker.mjs` 2.1MB, `pdfExtractorProcess.mjs` 410KB, `@azure/msal-node-extensions`, `keytar`), plus 2 unpacked native binaries `libmsalruntime_arm64.dylib` (6.85MB) and `msal-node-runtime.node` (MSAL native broker)
- **Main Process (`app.asar`)**: +77/-9/~20, renames 0. Added named bundle `claudePagePreview.js` (`claude.ai` page preview preload; preview strings already existed in 1.11847.5 and were split into a standalone file in this build); `index.js` +1.47MB (`office365-mcp` host wiring: MSAL cache encrypted via `safeStorage`, `connect` deferral / `sweep-decision` state machine, missing-bundle fallback); `findInPage.js` +323B, `mcp-runtime/nodeHost.js` +831B, plus minor updates in `transcript-search-worker` and `shell-path-worker`
- **Web UI (`ion-dist`)**: +409/-392 assets; added image `images/crochet/browser.png`; updated `frame-gallery`/`frame-shell` entry points; updated 11-language i18n (including `dynamic/`)
- **UI & Experience**: Launched built-in Microsoft 365 (Office) MCP connector (including PDF document extraction)
- **Network & Endpoints**: Added `https://login.microsoftonline.com/common/oauth2/nativeclient` (MSAL native client redirect), `https://aka.ms/msal.js.errors`, `https://www.microsoft.com`, and AzureAD GitHub references (all originating from the MSAL runtime library)
