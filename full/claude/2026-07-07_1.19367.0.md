## Overview

Major dependency upgrade release: major version jump for the agent SDK and TS SDK, hash-chunked main process bundle for the first time (+48 chunks), and new file-index worker and agent-base; extracted strings reveal built-in local agent capabilities including GitHub PR operations, SSH remote sessions, MCPB packaging, Slack connector, and Claude Code CLI downloads (mostly carried via the embedded agent-sdk).
