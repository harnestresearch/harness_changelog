## Overview

Major expansion of claude-studio; added a hardware acceleration toggle and a cache clearing / reset dialog to the desktop app.

## Changes

- **Dependencies**: debug 4.3.6 → 4.4.1; added fflate ^0.8.2
- **Components & Native Modules**: Electron 36.2.1 → 36.4.0
- **Main Process (`app.asar`)**: +526 -31 ~13 (renames 1: hoisted update-browserslist-db/picocolors). The bulk of the additions are claude-studio node_modules dependencies (eslint, radix-ui/react-slot, class-variance-authority, framer-motion ("A simple and powerful JavaScript animation library"), react-markdown, etc. — ~500 files) plus Anthropic brand variable fonts in woff2 (AnthropicSans/AnthropicSerif VF); index.js 1,134,201 → 1,154,328 B; mainView.js -1.8KB (preload cleanup)
- **UI & Experience**: First major appearance of claude-studio UI copy: task system ("Cannot switch tasks while Claude is processing", "Delete this task and all its messages?", "Close tab"), skill learning ("Claude has learned the new skill from your project.", "An error occurred while learning the skill", "Failed to create skill zip"), file uploads ("Claude Studio is more fun with files!", "Failed to load uploads"), and a teaser ("Board creation feature will be available in a future update."); desktop app added "Disable Hardware Acceleration", "Clear Cache and Restart", and a reset completion dialog
- **Network & Endpoints**: No new external endpoints (numerous library homepage links only)
