## Overview

Major milestone feature release (zip +15MB): Buddy Bluetooth hardware companion (pairing / firmware installation / gamification stats, codenamed `Nibblet`) landed as a standalone `buddy_window`; the data layer added four new tables including `compute_usage` (laying groundwork for Cowork compute metering and bundled agent configuration).

## Changes

- **Components & Native Modules**: Added Drizzle migrations `0007_mcp_connector_provider`, `0008_compute_usage`, `0009_user_agents`, and `0010_bundled_agent_settings` (four tables for MCP connector providers, compute usage metrics, user agents, and bundled agent settings); removed the hashed `shell-path-worker/index-*.js` chunk added in the previous release
- **Main Process (`app.asar`)**: +17 -8 ~15 (renames 0); **Buddy hardware companion launched**: added `.vite/build/buddy.js` preload (59KB; exposes `buddy` via `contextBridge`: `scanDevices`/`cancelScan`/`pairDevice`/`pickDevice`/`pickFolder`/`install`/`preview`/`setName`/`forgetDevice`/`status`/`deviceStatus` + `progress` events — end-to-end flow for Bluetooth scanning, pairing, firmware installation/preview, renaming, and forgetting devices) and `.vite/renderer/buddy_window/` (`BuddyWindow.js`, `buddy.html` 190KB, `main.js`/CSS, plus 4 bundled Anthropic Sans/Serif variable font `.ttf` files)
- **Web UI (`ion-dist`)**: +330 -316 ~12
- **UI & Experience**: New UI copy: "Device did not respond", "Web Bluetooth not available", "Name saved", "Confirmation after the buddy device name was updated", "Error when renaming the buddy device times out", "Section header for buddy gamification stats", "Claude Desktop failed to launch, attempting to write debug info"; new identifiers: `Nibblet` (internal codename for the Buddy device), `Approved` / `Progress` / `Velocity` (gamification metrics), `CLAUDE_CODE_EFFORT_LEVEL`, "MCP server names must be unique", "oauth and headers are mutually exclusive"; updated `Info.plist` Bluetooth usage description to "Claude uses Bluetooth to connect to hardware accessories." (explicitly referencing hardware accessories)
- **Network & Endpoints**: No net-new real endpoints
