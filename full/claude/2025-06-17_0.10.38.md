## Overview

Milestone release introducing the Extension System (CDX) and built-in MCP Node Host: `.cdx` file association, extension installation UI, API Key management, a full auto-updater (scheduled + idle-aware + auto-restart), and main-process Sentry crash reporting all launched simultaneously; the standalone claude-studio package was removed.

## Changes

- **Dependencies**: Added @anthropic-ai/claude-cli ^1.0.22-dev (Claude Code CLI/SDK), @anthropic-ai/cdx, @anthropic-ai/cdx-registry (link), semver ^7.7.2, fs-extra ^11.3.0; @modelcontextprotocol/sdk 1.4.1 → 1.11.3
- **Components & Native Modules**: Added `.vite/build/mcp-runtime/nodeHost.js` ("Claude Desktop MCP Node Host" — hosts MCP servers in a built-in Node child process, corresponding to the `isUsingBuiltInNodeForMcp` config option); Info.plist registered the `.cdx` file type ("Claude Desktop Extension", cdx.icns). Note: @anthropic-ai/claude-cli is only declared in package.json; no cli.js file was found in the zip/asar snapshot (code throws "CLI not found at path" as this feature is feature-gated and not bundled in this release)
- **Main Process (`app.asar`)**: +10 -569 ~11 (renames 0). Removed all 562 claude-studio dist/node_modules files (studio logic merged into the main bundle or deferred from distribution); index.js 1,154,328 → 1,639,211 B (+485KB, merging the extension system + auto-updater + main-process Sentry reporting + Claude SDK launcher); settings.html +195 lines (reworked sticky positioning, scrollbar, and other settings page styles)
- **UI & Experience**: Launched Claude Desktop Extensions (CDX): installation, preview, and compatibility checks (reusing "Are you sure you want to install MCP servers?", "Checking compatibility...", "Button to install an extension from a file", "Add to Claude"); API Key management ("API Key Updated", "Change API Key..."); auto-update UX
- **Network & Endpoints**: Added Sentry ingest DSN https://o1158394.ingest.us.sentry.io/4507368973008896 (main-process crash reporting enabled); https://docs.anthropic.com/en/docs/agents-and-tools/mcp; update feed pointing to the osprey GCS bucket (nest/update_manifest.json); https://support.anthropic.com, claude.ai, feedback Google Form
