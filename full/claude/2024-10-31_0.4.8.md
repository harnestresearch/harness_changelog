## Overview

Initial macOS desktop release baseline (internal package name `@ant/desktop`), featuring a main window and Quick Window floating input bar, bundled with the `claude-native` Rust native module and `@modelcontextprotocol/sdk` 0.1.0.

## Changes

- **Dependencies**: Ships with Electron `32.1.2`, `@modelcontextprotocol/sdk ^0.1.0`, `electron-store ^8.2.0`, `@sentry/electron ^5.8.0`, `zod ^3.23.8`, `semver ^7.6.3`, `minimatch ^10.0.1`, and `uuid ^10.0.0`.
- **Components & Native Modules**: Bundles `app.asar` and `claude-native` (macOS native helper module `claude-native-binding.darwin-universal.node`).
- **Main Process (`app.asar`)**: Contains `.vite/build/{index.js, mainView.js, mainWindow.js, window-shared.css}` and two renderer entries (`main_window` and `quick_window`), accompanied by Anthropic brand fonts (Copernicus, StyreneBLC, TiemposText).
- **UI & Experience**: Provides the desktop main chat window and a global-hotkey-summoned Quick Window floating input bar, complete with tray icon and baseline localization dictionaries for 10 languages (including German, French, Japanese, Korean, and Spanish).
