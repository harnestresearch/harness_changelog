## Overview

Major feature release: terminal support (node-pty), "Claude in Chrome" rebranding + standalone helper, and Echo device windows (API key pairing / notifications) landed; legacy internal updater strings were removed at the same time.

## Changes

- **Dependencies**: Added `@ant/claude-for-chrome-mcp "*"` (MCP server for Claude in Chrome); removed form-data (19 packages / 286 files under node_modules deleted from asar, bundled directly instead)
- **Components & Native Modules**:
  - Added native module **node-pty** (app.asar.unpacked: pty.node 111,896B + spawn-helper 67,104B; 19 JS library files added to asar simultaneously) — terminal/PTY support
  - Added `Contents/Helpers/chrome-native-host` (Mach-O helper, Chrome native messaging host) and `Contents/Helpers/disclaimer` (Mach-O helper: all commands spawned by the main process on macOS are wrapped through `disclaimer [cmd, ...args]`, acting as a command-execution disclaimer/confirmation gatekeeper)
  - Added 6 EchoTray tray icons (EchoTrayActive/Template ×1x/2x/3x) — Echo device tray assets (not yet referenced in app.asar JS, rolling out incrementally alongside echoWindows)
- **Main Process (`app.asar`)**: +26 -293 ~14. Added named bundles: **echoWindows.js** (Echo preload: claude-echo-api-key, echo-onboarding-*, echo-settings-*, notification dismiss/chat IPC, etc.), **shell-path-worker/shellPathWorker.js** (+window-shared.css); index.js 2,131,357 → 2,973,264B (+39%, Chrome extension mechanism `Chrome` keyword occurrences 4→40, terminal/pty integration); 4 preload bundles uniformly grew to ~137-150KB due to shared code consolidation
- **Web UI (`ion-dist`)**: None
  - **User-Facing** (en-US.json +5 -16):
  - Renamed "Claude for Chrome" to **"Claude in Chrome"**, with new installation onboarding strings: "Install Claude in Chrome Extension", "To use browser tools, install the Claude in Chrome extension from the Chrome Web Store." (extension is now fetched from the Chrome Web Store)
  - Removed the entire set of Claude Nest internal updater strings ("Claude Nest is getting dusty!", "Update Script Not Found", Kandji, "open a Terminal window...") — legacy osprey internal update mechanism retired following channel migration
- **Network & Endpoints**: Added `https://preview.claude.ai`, `https://preview.claude.com` (preview environments); remaining new URLs are node-pty/ws library documentation links
