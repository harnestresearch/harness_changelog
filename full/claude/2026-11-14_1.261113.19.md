## Overview

A static XAPK, manifest, resource, DEX string-pool, and jadx decompilation diff of `com.anthropic.claude` (`1.261112.18` → `1.261113.19`). Neither APK was installed or executed at runtime. On the packaging side, `1.261113.19` raises `minSdkVersion` from `29` (Android 10) to `32` (Android 12L) and expands language splits from `27` to `30`. At the code and resource layers (`55,431` → `55,804` jadx `.java` outputs; deduplicated DEX string pool `161,929` → `163,593`, `+6,649 / -4,985`; non-obfuscated `com.anthropic.*` classes `1,707` → `2,130`, `+452 / -29`), the build refactors voice dictation (including offline dictation) and read-aloud into standalone `com.anthropic.voice.internal` modules while retaining `TTSPlaybackService`, expands Claude Code Remote (CCR) project sheets, GitHub SSO repository-source handling, background turn notifications, and 49-type bottom-sheet navigation while retiring legacy Threads screens, and ships static client code/strings for promotional-to-credits migration prompts, voice credit notices, and KYC status/purchase outcomes.
