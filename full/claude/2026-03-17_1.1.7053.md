## Overview

Landed the Cowork plugin system (in-VM shim confirmation protocol) and Git commit signing support in the PTY environment; also introduced an `imagine-server` dependency (related to the `imagine` image generation feature; dependency declaration only, with no standalone process file observed).

## Changes

- **Dependencies**: Added `@ant/imagine-server: "*"` (`package.json` `dep_changes`)
- **Components & Native Modules**: Added resource file `Claude.app/Contents/Resources/cowork-plugin-shim.sh` (7.4KB): Cowork plugin shim library, mounted read-only by the host into `/sessions/<vm>/mnt/.cowork-lib/shim.sh` inside the VM; plugins declare `argv` classification, the `confirm` confirmation protocol, token requirements (e.g., `cowork_require_token GOOGLE_WORKSPACE_CLI_TOKEN`), and architecture dispatch via `plugin.json`, requiring only ~8 lines of bash for the plugin body itself
