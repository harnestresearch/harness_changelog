## Overview

Cross-platform (`mac`, `win`, `ubuntu`) embedded Claude Code engine minor update, bundled Office skill security hardening, localization catch-up, and sandbox/native artifact rotation following `5.11492.2` (`5.11492.0` → `.2` was a targeted sandbox/stability hotfix, whereas `.2` → `.5` centers on engine storage integrity and managed settings with **zero desktop UI feature changes**). Introduces a comprehensive local session storage key validation schema (`index.chunk-BDY2-Sqh.js`, including `jobs-root` and `setSessionArchived`), adds the `blockFileToolReadsOutsideWorkingDirectories` enterprise managed setting and `env.CLAUDE_CODE_AUTO_MODE_MODEL` admin settings guidance, hardens `docx`/`pptx`/`xlsx` validators against Windows-style path traversal, OOXML relationship zip-slip, and large-file diff resource exhaustion, catches up 10 non-English `ion-dist` locales (`+~48` keys each), and rotates `smol-bin` sandbox images across platforms.

## Embedded Engine, Managed Settings & Web UI (`ion-dist`)

- **Engine Session Storage Key Schema (`index.chunk-BDY2-Sqh.js`)**
  - Expanded `index.chunk-BDY2-Sqh.js` to `21 KB` (from a `739 B` chunk in `5.11492.2`), defining a unified local-storage key validation schema across engine namespaces: `transcript`, `sessionJournal`, `agentMemory`, `tasks` (`listId` / `taskId` / `highWaterMark` / reserved `.meta`), `drafts` (`draftKey`), **`jobs-root`** (new; mutually exclusive between pins file and draft), recovery copies (`stamp`), tree file (`relPath`), `pluginRegistry` / `pluginAssetCache` (SHA-256 digest), and three-tier `settings` (`user` / `project` / `local`, where `user` omits `projectKey`).
  - Added strict validation diagnostics such as `"a transcript key names an agent transcript or the run journal, never both"` and `"must be 8 lowercase hex characters"`.
  - Refactored existing session APIs (`deleteSession`, `tagSession`, `tryAppend`, whose error paths already existed in `5.11492.2`) into the unified schema and added `setSessionArchived` alongside archiving error handling (`"Archiving is not supported with sessionStore…"`), laying storage-key integrity groundwork for cloud ↔ local task synchronization (paired with `5.11492.2`'s `"A cloud copy of this task was made"`).
- **Enterprise Managed Setting `blockFileToolReadsOutsideWorkingDirectories`**
  - Added `blockFileToolReadsOutsideWorkingDirectories` alongside existing `blockWritesOutsideWorkingDirectories` (explicitly naming file-tool reads where the legacy key name referenced `"Writes"` while governing read checks), controlling one-time authorization prompts in auto-mode.
- **`ion-dist` Managed Settings Documentation (`c6f6cf4c2`)**
  - Updated settings bundle `c6f6cf4c2` (`454 KB`, the sole `ion-dist` JS asset with substantive content changes in this release) to add `"env.CLAUDE_CODE_AUTO_MODE_MODEL in a computer's machine-wide Claude Code managed settings replaces it there"` in the auto-mode review model documentation (the environment variable identifier itself was already present in `5.11492.2`).
- **`ion-dist` Non-English Localization Catch-Up**
  - Added `~48` keys (`0` deletions) across `10` non-English locales covering built-in browser extension install/removal/permission confirmations and CRX content verification warnings (e.g., `"Claude が審査していない拡張機能…"`, `"ダウンロードした内容がこれと異なるものを要求する場合、拡張機能は追加されません"`) as well as purchase/subscription consent copy (auto-reload, annual subscriptions, VAT, and the `2026-09-10` credit expiration policy); the English source strings were already in `app.asar` in `5.11492.2`, and `ion-dist` `i18n/en-US.json` has zero key-level diffs.

## Bundled Office Skills Security Hardening

- **`docx` / `pptx` / `xlsx` Validator Hardening (`agentSkillsRef` `1794527255` → `1794592614`)**
  - **Windows-Style Root & Drive Traversal Check**: Added `names_another_root()` using `PureWindowsPath` to reject OOXML part names and archive entries carrying Windows drive letters or root anchors.
  - **OOXML Relationship Zip-Slip Containment**: Updated relationship target resolution to enforce `os.path.normpath` + `is_relative_to(unpacked_dir)` containment checks, recording out-of-bounds relationship targets under `broken_refs`.
  - **Bounded Document Redlining Diffs**: Replaced `subprocess` `git diff` execution in `redlining.py` with a work-bounded `SequenceMatcher` raising `_WorkSpent` when exceeding its work budget (mitigating resource-exhaustion DoS on very large documents), alongside a minor update in `xlsx` `recalc.py`.
