## Overview

Upgraded MCP SDK to 0.4.0 and introduced rxjs; added a full suite of window and accessibility APIs to claude-native, while Quick Window gained multi-line input and click-outside-to-dismiss support.

## Changes

- **Dependencies**: @modelcontextprotocol/sdk ^0.1.0 → ^0.4.0; added debug ^4.3.6, rxjs ^7.8.1
- **Components & Native Modules**: Added exports to the claude-native module: requestAccessibility, getWindowInfo, getActiveWindowHandle, getMonitorInfo, and focusWindow — bringing window management and accessibility APIs to the desktop app for the first time (laying the groundwork for computer-use and Quick Window focus management)
- **Main Process (`app.asar`)**: +5 -3 ~10 (renames 0). Added node_modules/claude-native/{package.json,tsconfig.json}; `.vite/build/index.js` 837,013 → 849,331 B; mainWindow.js +1.6KB; mainView.js (preload) +0.7KB; OpenTelemetry strings such as OTEL_TRACES_SAMPLER appeared in the bundle (telemetry infrastructure pulled in by new dependencies)
- **UI & Experience**: Switched the Quick Window input field from a single-line input to a textarea (enabling multi-line input), and added click-outside-to-close behavior (quick-window.html diff: `-webkit-app-region: no-drag` "click outside of the window to close it")
