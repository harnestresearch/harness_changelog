## Overview

Cross-platform (`mac`, `win`, `ubuntu`) feature, enterprise-governance, and security hardening update incorporating `5.11492.0` and the `5.11492.2` sandbox/stability hotfix. Adds an enterprise managed configuration template export window (`ConfigTemplateExport`), splits sandbox network permissions into a dedicated `SandboxNetworkAccess` tool rule type, introduces per-host SSH settings (`ssh_host_settings`) and chunked large-file session reads (`readOpenedFileChunk`), expands `ion-dist` with action-level Claude for Chrome permission prompts, MCP connector OAuth credential modes, metered-connection update deferral, and credit purchase flows, hardens Windows `claude://` protocol invocation against argument injection, tightens Linux binary permissions (`04755` → `0755`), and brings Linux Artifact CDN allowlists to parity with macOS.

## Main Process, Bridges & Tool Permissions

- **Enterprise Configuration Template Export (`ConfigTemplateExport`)**
  - Added `.vite/build/configTemplateWindow.js` and full renderer window `.vite/renderer/config_template_window/` (HTML/CSS/JS/fonts, ~20 files) across all desktop platforms, backed by eipc bridge method `ConfigTemplateExport_$_exportTemplates(selection)` (18 references in `app.asar`) and support article `support.claude.com/articles/12622667-enterprise-configuration-for-claude-desktop` for exporting managed macOS/Windows deployment templates.
- **`SandboxNetworkAccess` Tool Permission Rule Type**
  - Added `SandboxNetworkAccess` alongside `WebFetch` (`new Set(["WebFetch", "SandboxNetworkAccess"])`), decoupling general sandbox network access from `WebFetch` rules.
  - Updated the schema tool-permission allowlist to core set `{Bash, PowerShell, Read, Write, Edit, MultiEdit, NotebookEdit, Grep, Glob, WebFetch, SandboxNetworkAccess}` plus gated set `{Skill, Workflow, ClaudeInChromeDomain}` (`ClaudeInChromeDomain` gated by `"1927384307"`).
- **Per-Host SSH Settings & Transport Diagnostics**
  - Added `ssh_host_settings` in `app.asar` paired with new `ion-dist` connection management surfaces (`"SSH hosts"`, `"Not in your SSH connections"`, `"Sessions on this computer"`).
  - Expanded SSH host-key verification exemption states (`posture` for configured `accept-new`, `redial` for strict interactive login redial, `redial_unverified` when redial fails verification) and macOS local-network privacy diagnostics (`local_network_app_suspected`: `"macOS may keep Claude itself off the local network"`, `"built-in ssh (macOS local-network host, remembered)"`).
- **Chunked File Reads & macOS TCC Microphone Deep-Link**
  - Added `LocalAgentModeSessions.readOpenedFileChunk(readId)` to the local agent session bridge for chunked continuation reads of large files (complementing single-shot `readOpenedFiles`, `setMcpServers`, `replaceRemoteMcpServers`, `replaceEnabledMcpTools`, `addFolderToSession`, `autoSaveDeliveredFiles`, and `syncSkills`).
  - Added `ComputerUseTcc.openMicrophoneSettings` to the macOS TCC bridge alongside `getState`, `requestAccessibility`, `requestScreenRecording`, `requestMicrophone`, `revokeGrant`, and `listInstalledApps`.
- **Media Embed Providers & Renderer Dependency Upgrades**
  - Added embed/preview providers in `app.asar` for Loom (`embed`/`oembed`/`thumbnail`), Vimeo (`player`/`oembed`), YouTube and `youtube-nocookie`, Google Drive file thumbnails, and Artifact frame font origin `fonts.frame.claudeusercontent.com`.
  - Upgraded renderer dependencies including `react` (`19.2.4` / `19.2.7`), `happy-dom` `20.9.0`, `mediabunny` `1.27.3`, `jszip` `3.10.1`, `jquery` `4.0.0` (license reference), `floating-ui`, `base-ui`, and `tailwind-merge`.

## Security, Packaging & Cross-Platform Diffs

- **Windows `claude://` Protocol Hardening & MSIX Distribution**
  - Hardened `AppxManifest.xml.in` protocol launch parameters from `Parameters='"%1"'` to `Parameters='-- "%1"'`, inserting `--` before the URI argument to prevent command-line option injection (the sole Windows manifest change in this release).
  - Windows `x64` MSIX packages (`174` archive members, shared artifact ID `b1edc633…` with `darwin`) resolve via `claude.ai/api/desktop/win32/x64/msix/latest/redirect` (`307` → `downloads.claude.ai/releases/win32/x64/5.11492.2/Claude-b1edc633….msix`).
- **Linux Binary Permission Tightening & Artifact CDN Allowlist Parity**
  - Changed `/usr/lib/claude-desktop/claude-desktop` permissions in the APT `.deb` (`99` archive members) from `04755` to `0755` while keeping `chrome-sandbox` at `04755` (`setuid root`); GNOME search provider, `TrayIconLinux`, and MIME definitions are unchanged.
  - Brought `5.11492.2-linux` to parity with macOS on Artifact external CDN allowlists by adding `esm.sh`, `cdn.jsdelivr.net`, `cdnjs.cloudflare.com`, `unpkg.com`, and `fonts.googleapis.com` / `fonts.gstatic.com` (previously missing from `5.1231.2-linux`).
- **Native MCP, Cowork Sandbox Rebuilds & Cross-Platform Topology**
  - Rebuilt bundled native MCP servers and bindings across platforms: `github-mcp-server` (`24.9 MB` on Linux / `.exe` on Windows), `office365-mcp` (macOS bundles `libmsalruntime` dylib + `msal-node-runtime.node` and Windows bundles `msalruntime.dll`, whereas Linux ships JS-only without native MSAL SSO support), `@ant/claude-native`, `node-pty` (including Windows ConPTY binaries), and macOS-only `Claude iOS Sim.app` / `resources/quick-actions/`.
  - Rebuilt SSH helpers (`claude-ssh-askpass/broker/proxy.exe` on Windows vs standalone `claude-ssh-askpass` on Linux with broker/proxy merged into the main binary) and all Cowork micro-VM images (`smol-bin.{arm64,x64}.img` on macOS, `smol-bin.x64.img` `28.3 MB` + `virtiofsd` + `cowork-linux-helper` on Linux, and `smol-bin.x64.vhdx` + `cowork-svc.exe` on Windows).
  - Same-version `5.11492.2` `darwin` ↔ `linux` `app.asar` baseline shows `+542/-566` chunk hash drift and `28` platform-guarded preload/worker files (dual-arch `arm64+x64` `.jsc` compile cache on macOS vs `x64`-only on Linux).
- **`5.11492.0` → `5.11492.2` Hotfix Delta (Linux APT Observation)**
  - Between `5.11492.0` (`2026-11-12`, `183.4 MB`) and `5.11492.2` (`2026-11-13`, `183.3 MB`), changes are isolated to `app.asar` (~47 files), the `claude-desktop` binary, and `smol-bin.x64.img` with zero new UI string batches, indicating a targeted sandbox and runtime stability hotfix.
