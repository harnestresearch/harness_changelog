## Overview

2.0 milestone release. The second version segment switches to an internal build number (110, used as the release train number); core new capabilities include the model catalog (catalog.json + default model/effort settings) and self-hosted third-party inference (Azure AI Foundry / Microsoft Entra OIDC / full credential helper script setting family), alongside a new iOS Simulator bridge binary and hardened MCP/filesystem security; the web frontend simultaneously migrates to a new build pipeline with a major copy expansion. Capabilities such as Claude Code cloud sessions do not yet appear in settings in this release (see 2.2553.0).
