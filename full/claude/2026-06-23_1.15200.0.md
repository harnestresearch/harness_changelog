## Overview

Major enterprise and cloud integration release: upgraded `node-pty` and switched to dual-architecture prebuilds; landed built-in Microsoft 365 MCP server configuration, AWS Bedrock/Vertex/Foundry cloud provider integrations, and `managed-config` policy UI in the main process; upgraded the MCP SDK to 1.29.0.

- **Dependencies**: `@modelcontextprotocol/sdk` 1.28.0→1.29.0; `node-pty` 1.1.0-beta34→1.2.0-beta.13; added `js-yaml` ^4.1.1 (+`@types/js-yaml`)
- **Components & Native Modules**: Switched `node-pty` from a single `build/Release/{pty.node,spawn-helper}` directory to per-architecture prebuilds (separate sets for `darwin-arm64` and `darwin-x64`, migrated synchronously across zip members and `asar` members; 4 renames/additions in total); rebuilt `smol-bin` as usual
