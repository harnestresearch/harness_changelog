# Claude Desktop 1.0.734

English | [简体中文](../../zh-CN/full/claude/2025-11-21_1.0.734.md) · [Highlight](../../claude/2025-11-21_1.0.734.md) | **Full Detail**

- **Release Date**: 2025-11-21
- **Platforms**: `mac`, `win`
- **Installer Size**: 209 MB
- **Electron Version**: 37.10.0 (upgraded from 37.6.0)
- **Bundled Components**: `app.asar, claude-native, claude-swift`

## Overview

First 1.0 release = channel migration + major engineering cleanup: package names migrated to `@ant/*`, 252 build toolchain packages stripped from distribution, IPC channel signatures rotated, plus pre-bundled Clod pet assets, Claude for Chrome integration entry points, and a macOS 13 minimum requirement. Modest user-facing feature changes, but a complete overhaul of the release packaging structure.

## Changes

- **Components & Native Modules**:
  - Native module package names migrated across the board: `node_modules/claude-native` → `node_modules/@ant/claude-native` (claude-native-binding.node, unchanged at 2,383,824B); `@anthropic-ai/claude-swift` → `@ant/claude-swift` (swift_addon.node 3,660,408 → 3,976,248B, +316KB, with substantive updates)
  - Added `Claude.app/Contents/Resources/default.clod` (48,796B): ZIP archive containing `personality.txt` ("You are Clod, a minimalist AI assistant...") + `idling_0.png`/`working_0.png` animation frames — the "Clod" desktop pet asset bundle; unreferenced across all JS in app.asar (pre-staged for pet/mascot features in later versions)
  - Anthropic Sans/Serif Variable fonts re-subsetted (25x258 series replaced with updated cuts; Serif Roman 824KB → 504KB, smaller overall)
- **Main Process (`app.asar`)**: +248 -3735 ~12 (renames 11)
  - Biggest change is bundle slimming: removed 252 node_modules packages / 3,735 files — all build/packaging toolchains (@electron/get, @electron/rebuild, node-gyp, @electron/notarize, @electron/windows-sign, electron-windows-msix, @electron-forge/maker-msix, etc.); earlier builds shipped CI toolchains inside production packages, which are no longer distributed starting in this release; zip size dropped from 216MB to 209MB
  - Only 16 new node_modules packages added (214 files; 23 of the remaining +248 are .vite/renderer hashed chunks): form-data and its dependency stack (asynckit, combined-stream, delayed-stream, mime-db, dunder-proto, es-object-atoms, es-set-tostringtag, get-intrinsic, get-proto, has-symbols, has-tostringtag, math-intrimitives, etc.)
  - Named bundles unchanged; index.js 2,131,357B (1.84MB→2.13MB, +16%), index.pre.js 669,526 → 588,108B (-12%); minor synchronized updates across the 4 preloads (aboutWindow/findInPage/mainWindow/quickWindow)
  - Preload↔main-process IPC namespace UUID rotated: `$eipc_message$_3aebb0c8-...` → `$eipc_message$_fe8e247e-...` (channel signature rotation for security hardening)
  - index.js added main-process strings: "an update to Claude Desktop" (update prompt), "Menu item for copying the current Claude.ai URL to clipboard"; index.pre.js added launch-failure fallback dialog "Claude Desktop failed to Launch" (with debug info write-out logic)
- **Web UI (`ion-dist`)**: None (ion-dist.asar not yet bundled in this version)
  - **User-Facing** (en-US.json +7 -4):
  - Added Claude for Chrome integration strings: "Login to Claude for Chrome Extension", "Login & Enable native app integration", "Make sure you're authenticated in Claude for Chrome settings."
  - Raised minimum OS requirement: "This feature requires macOS 12.0 or higher" → "macOS 13.0 or higher"
  - Added "Copy URL" (menu item for copying the current claude.ai page URL)
- **Network & Endpoints**: Added `https://claude.com` (official domain alongside claude.ai); the remaining ~180 new URLs all come from newly bundled node_modules (README badge links in mime-db, es-shims, Sentry SDK, etc.) rather than runtime endpoints
