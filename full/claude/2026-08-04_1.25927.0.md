## Overview

Major milestone update: bundled GitHub MCP server binary and permission-fixer helper; added local execution consent window (localExecConsent) and stall-sampler worker in the main process; split main bundle chunks into dual namespaces and bundled node-forge/rxjs/winston; introduced official binary download endpoints for Claude Code / Claude SSH along with extensive enterprise integration endpoints (M365/Box/Slack/Bedrock/Google OAuth); renamed localization directories.
