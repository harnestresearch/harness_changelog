# Claude Desktop 0.12.112

English | [简体中文](../../zh-CN/full/claude/2025-08-20_0.12.112.md) · [Highlight](../../claude/2025-08-20_0.12.112.md) | **Full Detail**

- **Release Date**: 2025-08-20
- **Platforms**: `mac`, `win`
- **Installer Size**: 205 MB
- **Electron Version**: 36.8.1 (upgraded from 36.4.0)
- **Bundled Components**: `app.asar, claude-native, claude-swift`

## Overview

Major architectural milestone: upgraded Electron to 36.8.1, switched packaging from "node_modules + scattered renderer assets" to a fully inlined single bundle; native layer completely taken over by claude-swift (retiring claude-native node binaries); Quick Entry, dictation, and drag-to-screenshot UI completed along with localization into 11 languages.

## Changes

- **Dependencies**: Removed 28 package.json dependencies (`@anthropic-ai/claude-cli`, `@anthropic-ai/dxt`, `@anthropic-ai/dxt-registry`, `@sentry/electron`, `react`/`react-dom`, `react-intl`, `winston`, `rxjs`, `zod`, `semver`, `electron-store`, `spawn-rx`, `design-system`, `claude-studio`, etc.) — all inlined into the Vite bundle
- **Components & Native Modules**: Removed all claude-native native binaries (deleted `artifacts/*.node` inside asar and unpacked darwin-arm64/darwin-x64 `.node` files); claude-swift returned in full force: `swift_addon.node` (incorporating libSwiftCode.a into a single binary) placed into app.asar.unpacked
- **Main Process (`app.asar`)**: +9 -794 ~14 (renames 2: claude-native .node → claude-swift artifacts). Major structural overhaul: index.chunk-* hashed chunks reduced from 14 to 7 and consolidated into a single 2.4MB `.vite/build/index.js`; deleted `.vite/renderer/{about,find_in_page,main,quick}_window/assets/` renderer asset directories entirely (React/Sentry/claude-cli all inlined).
- **UI & Experience**: Added native macOS localization `*.lproj/Localizable.strings` for the first time across 11 locales (de-DE, en, es-419, es-ES, fr-FR, hi-IN, id-ID, it-IT, ja-JP, ko-KR, pt-BR); strings include "Ask Claude..." (Quick Entry placeholder), "Drag to screenshot", "Toggle Quick Entry", "⌘N → New Chat", "Show Dictation", "Speak to Claude, then press ⏎", "Talk to Claude about …", and "Screen Recording Permission Required". i18n dictionary +10/-2: "Install Update", "Skip This Update", organization extension update prompts, and "This feature requires macOS 12.0/14.0 or higher". Added `claude-screen.png`/`claude-screen-dark.png` (screenshot/virtual screen assets for drag-to-screenshot preview).
- **Network & Endpoints**: Added `https://preview.claude.com` (preview domain alongside preview.claude.ai); the claude.com/claude.ai domain family in the main bundle is now fully formed
