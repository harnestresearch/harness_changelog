## Overview

Major version bump 2→3: Electron 44.9 + downgrade prevention flag + new artifactShell bundle (Cowork artifact network bridge) + two new internal packages (OOXML→HTML and frame-local-backend), marking the start of the Cowork artifact rendering stack refactor; no breaking UI reorganization.

## Changes

- **Dependencies**: Added `@ant/frame-local-backend` (workspace), `@ant/ooxml-to-html` (workspace), `jsdom`; `@anthropic-ai/claude-agent-sdk` 0.3.299→0.3.304; `semver`→7.8.1; multiple dependencies migrated to catalog references
- **Components & Native Modules**: Electron 44.9.0 brings new Helper binary `Electron Framework.framework/.../Helpers/app_shim_loader`; routine rebuild of smol-bin / iOS Sim; main Info.plist added `ElectronSquirrelPreventDowngrades: true` (preventing Squirrel downgrade updates)
- **Main Process (`app.asar`)**: +420/-375/~40; chunks +395/-357 (count +38); **added named bundle `.vite/build/artifactShell.js`** (implements the fetch bridge for `cowork-artifact://shell` pages: intercepts `/api/` and `/edge-api/` requests and forwards them over a transport port, providing a host network channel for Cowork artifacts); node_modules/@ant/claude-swift updated; 20 named bundles modified
- **Web UI (`ion-dist`)**: Loose files +2699/-2545
- **UI & Experience**: "Anthropic Sans"/"Anthropic Sans Variable" (brand font integration); "Choose your export", "Choose a Claude data folder" (data export); "Your voice is transcribed as you speak" (voice transcription); "Claude can't start in this session's worktree folder"; AppKit sidebar glass strings (adapting to the new macOS Liquid Glass sidebar style)
- **Network & Endpoints**: Added `https://*.microsoft.com`, `https://cognitiveservices.azure.com/.default`, `https://login.microsoftonline.com` (Azure authentication scopes)
