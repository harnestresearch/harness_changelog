## Overview

Three main additions: launched the `computer_use` native module and `teach` preload; added the `node:sqlite` worker (local database foundation for Cowork); bundled 757 `bioknowledge` bioinformatics skill files in a one-off drop (rolled back the next day; see next entry).

- **Components & Native Modules**: Added native module `@ant/claude-swift/build/Release/computer_use.node` (853KB, appearing simultaneously in zip members and `node_modules` inside `asar`) — added 757 files under `Resources/agents/bioknowledge/.claude/skills/`: 10 bioinformatics skill groups (`clinvar-database`, `ena-database`, `ensembl-database`, `etetoolkit`, `gene-database`, `gget`, `gwas-database`, `harmonizome-database`, `kegg-database`, `networkx`), each containing `SKILL.md` + references + Python scripts
