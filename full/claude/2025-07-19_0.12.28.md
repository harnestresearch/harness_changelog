## Overview

Native layer refactoring: temporarily retired the Swift addon while claude-native absorbed system config reading capabilities (registry/plist) and embedded its build dependencies directly; polished in-app updater copy.

## Changes

- **Dependencies**: Switched `claude-native`, `claude-swift`, and `design-system` from `file:` to `link:` (monorepo layout adjustment)
- **Components & Native Modules**: Removed the claude-swift native module (deleted `node_modules/claude-swift/build/*` inside asar as well as unpacked swift_addon.node, libSwiftCode.a, and nothing.a, leaving only claude-native in this build); claude-native now embeds its own node_modules inside asar (+1461 files: @napi-rs/cli, full rxjs, debug, ms, @types/node, etc.)
- **Main Process (`app.asar`)**: +1461 -17 ~19 (renames 0); hashed chunks +14 -10 (net +4 chunks). Named modifications: `node_modules/claude-native/artifacts/index.js` newly exports `readRegistryValues` and `readPlistValue` (cross-platform registry/plist system configuration reading); package.json switched to building with `node --experimental-strip-types`.
- **UI & Experience**: en-US.json +5 updater strings: "Checking for Updates...", "Downloading Update...", "Last update attempt failed...", "Restart to update to {updateVersion}", and "About Claude"
- **Network & Endpoints**: None (newly added URLs in strings are documentation references from embedded npm libraries, with no product endpoint changes)
