## Overview

Electron 40.4.1; VM images are now distributed per CPU architecture (+11MB zip size), remote CLI deployment upgraded to SHA-256 checksum-verified zstd archives, and "VM" was uniformly renamed to "Cowork VM" in user-facing copy.

## Changes

- **Dependencies**: @anthropic-ai/claude-agent-sdk 0.2.40 → 0.2.41; electron 40.4.0 → 40.4.1
- **Components & Native Modules**: Cowork VM image split: removed smol-bin.img (universal) in favor of per-architecture images smol-bin.arm64.img + smol-bin.x64.img (zip +11MB; win32 code updated in lockstep to select smol-bin.\${arch}.vhdx per architecture)
- **Main Process (`app.asar`)**: +7/-7/~13. index.js embeds remote Claude CLI distribution manifest v2.1.41 (sha256 and file sizes for claude.zst / claude.exe.zst across darwin-arm64/x64, linux-arm64/x64, win32-arm64; baseUrl=https://downloads.claude.ai/claude-code-releases), switching remote deployment to verified downloads via claude-ssh `--fetch-url/--fetch-checksum/--fetch-output` (URL itself is not newly added in this version); mainView.js 117010B→120221B (+122/-147, mostly reshuffling).
