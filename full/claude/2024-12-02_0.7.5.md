## Overview

Upgraded MCP SDK to 1.0.1; rewrote the settings page using Tailwind and Phosphor Icons, while slimming down and code-splitting the main-process bundle.

## Changes

- **Dependencies**: @modelcontextprotocol/sdk 0.6.1 → 1.0.1 (MCP 1.0 GA release); react/react-dom 18.2 → 18.3; spawn-rx 3 → 4; added @phosphor-icons/react 2.1.4; removed @types/react(-dom) (build-time only)
- **Main Process (`app.asar`)**: +4 -3 ~11 (renames 0; added two hashed assets: MainWindowPage-BB5pLYHU.js and settings main-B-1kRNCG.js). index.js 1,131,479 → 1,017,967 B (-113KB, dependencies split into chunks); window-shared.css 3.6KB → 4.7KB; settings.html 11KB → 32KB (major settings UI overhaul)
- **UI & Experience**: Comprehensive redesign of the settings page (introduced tailwindcss, substantially expanding rendered HTML/CSS); new string "Error modifying User Agent"; internal Easter egg strings "No window to skooch" / "No skooch needed" (window nudging workaround for a macOS window positioning issue)
- **Network & Endpoints**: No substantive additions (library homepage links such as tailwindcss.com only)
