## Overview

A static binary and bundle diff of the official macOS `arm64` `Qoder.app` builds (`0.5.11` → `0.5.12`; intermediate `0.5.8`–`0.5.10` and `0.5.11` are not yet backfilled in this repository's index, while `0.5.11` → `0.5.12` is an adjacent upstream release pair). Only the official macOS `arm64` packages were unpacked and analyzed—Windows and Linux builds were not reverse-engineered, and the application was not executed at runtime. In static evidence, `0.5.12` advances the bundled Agent SDK by 14 alpha builds (`1.0.60-alpha.36` → `1.0.60-alpha.50`), bumps the `qodercli` worker runtime version and OSS download URL template (`1.1.86-hotfix.4` → `1.1.86-hotfix.5`), adds four `transcript.resume.*` diagnostic strings in the decoded worker runtime string table, and repackages `qoder-office-xlsx` with a recompiled Rust `xlsx-sidecar`, while keeping `app/out/renderer` byte-identical.
