## Overview & Comparison Boundaries

This entry analyzes the **`0.5.18 → 0.5.20`** desktop release pair across macOS `arm64`, Windows `x64`, and Linux `amd64`. Intermediate desktop releases after `0.5.13` (`0.5.14`, `0.5.16`–`0.5.18`) are not yet cataloged in this repository, so `0.5.13` is **not** the comparison baseline. This pair also deliberately skips **`0.5.19`**: official CDN manifests exist for `0.5.19` across macOS, Windows, and Linux (macOS zip `352,687,968` B, built roughly seven hours before `0.5.20` on `2026-11-25`, commit `7c8c8d5c…`), but `changelog.qoder.com/app` jumps directly from `0.5.18` (`November 24, 2026`) to `0.5.20` (`November 25, 2026`) with **no `0.5.19` entry**, and `0.5.19` was neither downloaded nor analyzed. All static observations below reflect the net `0.5.18 → 0.5.20` delta and do not rule out changes having first landed in `0.5.19`.

## Verification Scope & Limitations

- **Per-Platform Depth**: macOS `arm64` (`Qoder-mac-arm64.zip`) underwent full static extraction, bundle inspection, SQLite migration review, and worker string-table decoding. Windows `x64` (`Qoder-win-x64-user.exe` + `Qoder-win-x64-user-app.zip`) and Linux `amd64` (`Qoder-linux-amd64.deb`) archive sizes and SHA-256 digests were verified against `0.5.20-win.yml` and `0.5.20-linux.yml`, while their internal file-tree counts (`1,101 → 1,109` / `1,094 → 1,101`), `system_commit.node` delta, and Windows Authenticode checks are cited from static package inspection without re-unpacking during publication; the Windows NSIS bootstrapper was **not** disassembled, and `Qoder-linux-x86_64.rpm` was neither downloaded nor analyzed (manifest SHA-256 recorded only).
- **Uncovered Targets & No Runtime Execution**: macOS `x64`, Windows `arm64`, Android, and iOS were not analyzed. No client binary or remote worker archive was executed; cloud tasks, cross-device collaboration, `automations.read.v1`/`manage.v1` permission enforcement, and enterprise managed-device policies depend on server-side services/policies and cannot be verified statically.
