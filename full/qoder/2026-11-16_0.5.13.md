## Overview

A static binary and bundle diff of the official macOS `arm64` `Qoder.app` builds ([0.5.12](2026-11-14_0.5.12.md) → `0.5.13`). Only the official macOS `arm64` archives were unpacked and inspected—Windows and Linux builds were not reverse-engineered or analyzed, and no target binaries were executed at runtime. In local static evidence, `0.5.13` reworks renderer `ApplicationTransport.subscribe` handling when the `64`-subscription cap is reached (awaiting in-flight `releaseRequested` releases and adding a 30-second-throttled diagnostic warning rather than removing the cap), adds 6 prompt and telemetry-description strings (`14,169 → 14,175`) in `qoder-worker-runtime.obf.mjs` covering approval verdict boundaries, Bash risk self-assessment, and local Auto gate/blacklist/policy-version telemetry fields, advances the Agent SDK by 12 alpha builds (`1.0.60-alpha.50` → `1.0.60-alpha.62`) alongside `qodercli` `1.1.86-hotfix.5` → `1.1.86-hotfix.5.2`, and repackages `qoder-office-xlsx`.

## Statically Verified Package & Runtime Changes
