## Overview

A read-only static diff of ChatGPT Android `1.2026.307` (`2630718`) → `1.2026.314` (`2631431`) from archived `arm64-v8a` + `en` + `mdpi` split XAPKs (`300 → 307` and iOS are outside scope). On the Codex/MCP client code surface, `2631431` introduces `RmcpHttp2Server` alongside bundled Netty `4.1.140.Final` HTTP/2 artifacts and signed RMCP grant strings (`x-codex-rmcp-grant`), adds MCP `DiscoverRequest*`/`DiscoverResult` and `mcp/skill` identifiers, replaces app-server RPC `thread/realtime/listVoices` with `thread/delete` (`+` `thread/deleted`), and ships Compose UI components/strings for mobile Codex Remote management. On the Android platform surface, `AndroidManifest.xml` adds exactly two `<uses-permission>` entries (`CALL_PHONE` and `FOREGROUND_SERVICE_MEDIA_PLAYBACK`), swaps `MediaAccessNotificationListener` for `DeviceNotificationListener`, registers `ReadAloudPlaybackService` / `ReadAloudPauseReceiver` / `NotificationTapActivity`, adds 3 Valdi modules (`oai_notifications`, `chatgpt_commerce_reporting`, `chatgpt_learning`), and ships static UI copy/assets for QR login, Wallet checkout, price-drop alerts, school tasks, and `"dot"` proactive assistants. All findings below are stratified into **Observed** static package facts, **Inferred** relationships, and **Unknown / Unverified** runtime or server-side states; neither APK was installed or executed.
