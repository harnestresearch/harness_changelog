- **Platforms**: `mac`, `ubuntu`
- **Runtime & Engine**: Chromium `157.0.8103.78` (upgraded from `157.0.8103.39` on Linux / `157.0.8103.51` on macOS `26.1106.51428`), Codex CLI engine `0.169.0-alpha.11.1` (upgraded across two minor versions from `0.167.0-alpha.3.2` / `0.167.0-alpha.4.1`)

## Overview

A major feature and engine release across desktop platforms: the bundled Codex CLI engine jumps two minor versions to `0.169.0-alpha.11.1` (shrinking the engine binary by 26.3 MB while adding lazy stdio MCP startup, WebSocket exec-server upgrades, and skill namespaces) alongside a Chromium `157.0.8103.78` runtime update. On the Electron host and preload layer, MCP Apps gain Web Worker RPC execution, full stream/fetch structured-clone serialization, per-origin permission declarations (`mcp-app-permission-declarations-v2`), and a new `application-websocket-preload.js` bridge; main and renderer bundles introduce external skill import from Claude Code and Cursor, Cloud Previews, expanded Git Worktree workflows, an automation run inbox, Global Search, Spaces, dated November connectors, and Windows `window3` GUI automation in `cua_node`.

## Main Process, Sandbox & Preload Architecture

- **MCP Apps Web Worker Sandbox & Application WebSocket RPC Preload**
  - Expanded `.vite/build/sandbox-preload.js` (`2,217` B → `117,711` B) for `io.modelcontextprotocol/ui` widget sandboxes with Web Worker support (`Symbol("workers-module")` + generation-tracked `RpcTarget` endpoints), a complete structured-clone serializer covering `ReadableStream`, `WritableStream`, `Request`, `Response`, `Headers`, `Blob`, `URL`, TypedArrays, `rpc-target`, and `rpc-promise`, plus `Symbol.dispose` and `Promise.withResolvers` polyfills.
  - Added `.vite/build/application-websocket-preload.js` (`55,745` B) implementing the same `workers-module` RPC and stream/fetch serialization stack over application WebSockets with frame validation (`invalid_websocket_frame`, `frame_too_large`, `unsupported_frame`), connection lifecycle events (`websocket_connection_pending`, `websocket_not_open`), and main-process `admission_cancelled` (`1000`) close handling.
  - Added persisted Zod schema `mcp-app-permission-declarations-v2` in `early-bootstrap.js`, recording MCP App permission grants (`clipboard-write`, `local-network`, `loopback-network`, etc.) scoped per `{partition, origin, owners: [{identity, pluginIds}]}`.
- **External Agent Skill Import (Claude Code & Cursor)**
  - Added synced external skill discovery (`claude-code-local-skills` and provider list `["claude-code", "cursor"]`) performing two-level `lstat` directory scans for `SKILL.md` definitions, gated by `codex-app-synced-skill-import` (`separateSyncedSkills` / `isSyncedSkillImportEnabled`) alongside `externalAgentConfig/detect`.
- **Cloud Previews & Expanded Worktree Management**

- **Lazy Stdio MCP Startup, Feature Gates & Installer Takeover Telemetry**
  - Added experimental gate mapping `mcp_lazy_stdio_startup` (lazy process startup for stdio MCP servers, paired with matching support in the `0.169.0` engine), plus `gateway_auto_reauth` / `reauthentication_required`, `codex-managed-incarnation`, `startup_prefetch`, `home_ambient_suggestions`, `presence_workstreams`, and `pull_request_board` / `pull_requests_page`.

  - Completed migrating the `electron-persisted-atom-state` key registry out of `worker.js` into `early-bootstrap.js`; retired `chrome-plugin-app-server-runtime`, `code-review-activity-notifications`, `head-branch-name`, `sidebar-thread-metadata`, `toggle-terminal`, `electron-custom-runtime-state` / `-outbox-state`, and `allow-this-time`.
