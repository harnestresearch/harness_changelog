- **Release Date**: 2026-11-09 (Linux x64, build `25894`, baseline `26.1103.31037` / build `25241`)
- **Platforms**: `mac`, `ubuntu`
- **Engine Version**: Codex `0.167.0-alpha.3.2`

## Overview

A stability and polish build on the `26.1103` branch: the main process introduces generation concurrency guards for renderer account state persistence to prevent cross-account write races, adds a network-online IPC notification channel and active turn mismatch error mapping, expands composer policy disable reasons, and introduces bottom-panel impression telemetry alongside Page/artifact annotation context modules; the Codex engine binary and built-in MCP toolset remain unchanged.

## Main Process & Worker Threads

- **Generation Guards for Account State Persistence**
  - Introduced `rendererAccountGeneration` and `storedOwnerGeneration` counters in `electron-account-renderer-state-v1` storage, exposing `captureRendererAccount()` for sidebar thread managers (pinning, sorting, group creation, group moves, etc.).
  - Aborts pending asynchronous disk writes or callbacks with an `AbortError` (`Saved account state changed` / `Renderer account changed`) whenever an account switch is detected, preventing multi-account race conditions from corrupting local state.
- **IPC Channels, Error Mapping & Feature Gates**
  - Added preload IPC channel constant `codex_desktop:network-online` for desktop network restoration events.
  - Added active turn validation error mapping in `worker.js`: `expected active turn id` → `active_turn_mismatch`.
  - Added Statsig feature gate `codex_app_daily_mac_push_registration` in the main process.

## Frontend & Interaction Improvements

- **Granular Composer Policy Disable Reasons**
  - Added 6 enterprise/environment policy disable reasons for the composer: `workspace-policy`, `codex-home-policy`, `view-only-seat`, `orbit-access-blocked`, `turn-blocked`, and `starting-state-blocked`; removed the legacy remote-project voice unavailability tooltip.
- **Page & Artifact Annotation Context Modules**
  - Added `ResponseTextAnnotationEditor`, the Page context citation prefix (`The user selected this Page as context: `), `artifact-session`, Granola presentation/whiteboard/workbook modules (`granola_presentation` / `whiteboard` / `workbook`), automation thread heartbeat state changes (`heartbeat-automation-thread-state-changed`), and the `home-announcement` module.
- **Command Menu & Bottom Panel Telemetry**
  - Refactored the command menu with a new `command-menu-first-file-item` identifier (removing the legacy `data-cmdk-root` attribute).
  - Added `protobuf_analytics_events.v1.CodexThreadBottomPanelShown` emitted when expanding the thread bottom panel, and added reset branches for `sandboxPolicy` / `runtimeWorkspaceRoots`.

## Cumulative Configuration & Asset Changes vs. 26.1029.61003

- **MCP Tool Approval Config**: Expanded gated tools in `codex-app-tools.mcp.json` from 6 to 7 entries, adding `"delete_thread": {"approval_mode": "prompt"}` (requiring confirmation before deleting threads).
- **Localized Native Menus**: Added Hindi (Latin script) native menu locale bundle `native-menu-locales/hi-Latn.json`.
- **Built-in MCP & Engine Baseline**:
  - `codex_app` retains 59 dynamic tools (plus 5 Worktree tools when `managedWorktrees` is enabled), with `cua_repl` (`js` / `js_reset` / `turn_ended`) and `node_repl` runtimes unchanged.
  - Bundled model catalog covers the `gpt-6` family (`gpt-6` / `-instant` / `-astra` / `-luna` / `-sol`, `gpt-6.1` / `-sol` / `-terra`), `gpt-5.6` family (`-sol` / `-terra` / `-luna`), `gpt-5.3-codex-spark`, and cybersecurity-specialized `gpt-daybreak-blue-latest` / `gpt-daybreak-red-latest`.
