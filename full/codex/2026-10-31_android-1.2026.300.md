# ChatGPT Android 1.2026.300

- **Release Date**: 2026-10-31 (`com.openai.chatgpt`, `versionCode 2630015`, baseline `1.2026.293` / `2629319`)
- **Platforms**: `android`

## Overview

A milestone release for mobile agent infrastructure: the Android client embeds the official MCP Kotlin SDK and a local Streamable-HTTP MCP server (`android executor`) for the first time, allowing the phone itself to be mounted as a remote execution environment for Codex, backed by a Noise-encrypted chunked relay protocol (`exec-server relay`), end-to-end Elicitation user response loops, and device-key pairing handshakes. On the product layer, it introduces Health Connect integration, the Bazaar shopping agent, browser cookie auth handoff, and post-quantum device key onboarding.

## Codex & MCP Execution Architecture

- **Embedded Local MCP Server (`android executor`)**
  - Embeds a Ktor (`3.5.x`) Streamable-HTTP MCP server listening on `http://127.0.0.1:39801/android-executor/mcp` (`POST` only), dynamically filtering `tools/list` by tool category and feature flags.
  - `environmentConfig/read` returns `{source: "android-native", baseDir: "file:///android-executor/device-executor", hostname, capabilities}` and auto-generates an `[mcp_servers.android_native]` TOML snippet so Codex instances can mount the Android device executor; reserves an `http/request` reverse HTTP proxy method.
- **Official MCP Kotlin SDK & Elicitation Loop**
  - Introduces `io.modelcontextprotocol:kotlin-sdk-core-jvm` / `kotlin-sdk-server-jvm:0.15.0`, supporting protocol versions `2025-03-26`, `2025-06-18`, and `2025-11-25`, the MCP **Tasks extension** (`tasks/get|result|list|cancel`), and SEP-986 tool name validation.
  - Adds `elicitation/create`, `notifications/elicitation/complete`, `UrlElicitationRequiredException`, and the `codexMcpElicitationResponse` callback channel, paired with a translucent `LinkedElicitationActivity` dialog (gated by `native_elicitation_enabled`) to close the loop on interactive mobile MCP authorization and user prompts.
- **Encrypted Relay Transport (`exec-server relay`) & Multi-Host Sync**
  - Adds the `codex.exec_server.relay.v1.{RelayHandshake, RelayAck, RelayData, RelayHeartbeat, RelayMessageFrame, RelayReset, RelayResume}` message family and `codex-exec-server-relay-noise/v1` (`noise_hybrid_ik_v1`) encrypted transport supporting 60 KiB chunking, sequence-based resume, and reconnection recovery.
  - Adds cloud environment endpoint `https://codex-cloud-environments.chatgpt.com/api/` (with a new `CodexCloud` auth session principal).
  - Extends Slingshot remote connections with device-key pairing handshake fields: `deviceKeyProof`, `pairingCode`, and `deviceKeyChallenge`.
  - Adds a `codexHome TEXT` column to local SQLite `DBRemoteThread` for multi-host remote thread caching; adds `thread/readState` read-state sync to AppServer RPC, and removes the deprecated plural `mcp__codex_apps__` prefix (retaining the standard 12 `codex_app` dynamic tools).

## Platform Features & Security Changes

- **ChatGPT Health (Health Connect Integration)**
  - Adds 43 `android.permission.health.READ_*` permissions in `AndroidManifest.xml`, `com.google.android.apps.healthdata` package visibility queries, and `HealthConnectRationaleActivity`, bundling 44 health record readers/sync/permission planners and 3 dedicated Valdi modules (gated by `health_connect_supported`).
- **Ads & Bazaar Shopping Agent**
  - Adds `chatgpt_ads.valdimodule`, `ChatGPTAdsNativeImageCard`, commerce agent launch telemetry, and order/shipping/returns UI flows.
- **Browser Auth Handoff & Credential Autofill**
  - Adds `cookie_handoff_enabled` / `enable_native_reauthentication` flags, browser auth telemetry, password and email OTP autofill authorization prompts, and `start.1password.com` onboarding.
- **Device Keys & Post-Quantum Cryptography Onboarding**
  - Introduces `kotlin-reflect 2.4.20` and `BouncyCastle bcprov 1.86` (including FAEST / SQIsign / AIMER post-quantum signature algorithm identifiers) powering `device_key_authentication` and the `onboarding_v3` registration flow.
- **Everyday Experience Enhancements**
  - Adds Slides/flashcards, Spaces-to-Pages permission inheritance, lock-screen voice assistant (`AssistantUnlockActivity`), phone call / SMS sending actions, the Explore experimental feed (`/backend-api/explore_experimental/generate`, Nova framework), and Valdi pricing & Pro Lite comparison screens.
- **Attack Surface Reduction & Dependency Upgrades**
  - Removes the exported `ChatGptAuthTokenService` and custom `GET_AUTH_TOKEN` permission; adds `/cairn/m/invite` and `/s/i_*` deep links; removes unused `openai_sans_variable.ttf`.
  - Upgrades Datadog `3.14.1 → 3.15.0`, Plaid `6.2.1 → 6.3.1`, `kotlinx-serialization 1.11 → 1.12`, and Metro `1.4.5 → 1.5.0`; bumps `valdi_api_version` to `390` (`libopenai_xplat_export.so` adds Crypto / TypedArray / `requestAnimationFrame` and module OTA receipt support).

## Appendix: Model Serving Variant Suffixes

Desktop and Android clients share a server-supplied `model/list` suffix convention that automatically maps serving variants back to their base model family in UI selectors:

- **`-wm` (Wingman)**: Real-time voice and multimodal call variants (e.g., `gpt-6-astra-wm`, `gpt-5.6-luna-wm`), bound to dedicated RTC audio profiles and the `gpt-reserve` rate-limit bucket.
- **`-priority` / `-ultrafast`**: Priority and ultra-low-latency serving tier variants (corresponding to `service_tier` settings).
- **`-minor`**: Point-release deployment variants within the same model family (e.g., `gpt-6-astra-minor`, composable with voice as `gpt-6-astra-minor-wm`), sharing product family metadata and cybersecurity program eligibility with the base model.
- **`gpt-daybreak-blue-latest` / `gpt-daybreak-red-latest`**: Specialized models reserved for authorized cybersecurity defense and research programs (Daybreak).
