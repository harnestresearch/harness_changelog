## Overview

A static MSIX diff (`26.1106.6628.0` → `26.1111.2228.0`) capturing the Windows `x64` counterpart of the `26.1111.21308` (`build 27194`) desktop release line. The update bumps the bundled Codex engine version string across two minor versions to `0.169.0-alpha.11.1`, upgrades Chromium to `157.0.8103.78` (recompiling all native `.node` and helper binaries and adding `resources/native/shared-texture.node`), ships byte-identical `sandbox-preload.js` and `application-websocket-preload.js` MCP Apps RPC preloads alongside the `cua_node` Windows `window3` GUI automation API, and flips the MSIX `AppxManifest.xml` `StartupTask` default from `Enabled="true"` to `Enabled="false"`. All findings below come strictly from static archive, `asar`, string-set, and binary metadata inspection without installing or executing the Windows client; newly added feature gates and bundle strings do not establish live server-side rollout.
