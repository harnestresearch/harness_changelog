# ChatGPT / Codex Desktop 26.1106.51428

- **Release Date**: 2026-11-11 (macOS arm64, build `26605`, baseline `26.1103.60933` / build `25894`)
- **Platforms**: `mac`, `ubuntu`
- **Runtime & Engine**: Chromium `157.0.8103.51` (upgraded from `157.0.8103.39`), Codex CLI engine `0.167.0-alpha.4.1` (upgraded from `0.167.0-alpha.3.2`)

## Overview

This release advances both the core Codex engine and desktop workflow capabilities: the engine upgrades to `0.167.0-alpha.4.1` alongside a Chromium patch update and full native module recompilation; the desktop shell and frontend introduce multi-account management with a seamless switch transition loader, a reactive Cloud SSH Portal state machine, a main-process `automation_update` handler, Code Review PR panel state persistence, Pages collaborative documents (DIL), in-image text editing, local work search MCP (`local_work_search_mcp`), and the new `gpt-5-t-mini` model entry.

## Main Process & Desktop Infrastructure

- **Renderer Persisted State Expansion & Registry Consolidation**
  - Consolidated 25 `electron-persisted-atom-state` persistence keys previously scattered across `worker.js` into the primary bootstrap bundle `early-bootstrap.js`.
  - Added 10 new state persistence keys: `pinned-content-tabs-v1`, `pinned-content-tab-presentation-v1`, `settings-workspace-tabs-v1`, `composer-retained-documents-v1`, `chatgpt-dictation-feedback-messages-v1`, `codex-dictation-feedback-messages-v1`, `image-text-editing-requests`, `prompt-history`, `electron-renderer-content-owner`, and `signed-out`, backing pinned content tabs, settings workspace tabs, retained composer documents, dictation feedback, in-image text editing, and prompt history.
- **Reactive Cloud SSH Portal State Machine**
  - Refactored `getSshPortal` from a static gate check into a reactive state machine, adding explicit user-facing error codes `cloudPortal.sshDisabled` ("Portal SSH was disabled for this account") and `cloudPortal.sshGateUnavailable`; retained the `codex_desktop_quic_ssh` flag and added `native.ssh.handshakeAccess` and `native.ssh.handshakeFailed` handshake failure copy across all 64 locale bundles.
- **`automation_update` Main-Process Handler & Granular Updater States**
  - Implemented `{namespace: "codex_app", name: "automation_update"}` tool output wrapping and parameter validation in the main process, adding error codes `invalid_automation_schedule`, `automation_update_failed`, and `automation_not_found` as well as a `modelAuthoredPrompt` branch.
  - Expanded RPC auto-update lifecycle telemetry states (`codex-update-attempt`, `already-installed`, `install-failed`, `newer-version` / `older-version` / `same-version`, `primary-download`, `policy-denied`, `policy-blocked-no-offer`, `store-discovery-error`, `service-privilege`, `startup-migrations`, `target-launched`).
- **Seamless Multi-Account / Workspace Switch Loader & System Integration Details**
  - Added an injected preload transition screen `desktop-switch-loader` that preserves visual continuity across renderer replacements during account or workspace switches, removing legacy `.startup-loader--switching` styles; added a `properties` layer to CSS `@layer` in the entry HTML.
  - Added hidden setting `codex-micro-lights-off-when-locked` (automatically turns off Micro lighting when the machine is locked, disabled by default).
  - Added an `admission_cancelled` (close code `1000`) WebSocket close branch; added `local_work_search_mcp` to the built-in feature allowlist; normalized the Deep Research connector resource key from `connector_openai_deep_research_work` to `connector_openai_deep_research_workflow`.

## Frontend & Product Features

- **Multi-Account Management & Tiered Sign-Out**
  - Added comprehensive multi-account state and actor context fields (`actor_id`, `actor_user_id`, `actor_account_user_id`, `actor_email`, `add_account_replacement`, `saved_account`, `accounts_check`, `session_recovery`), along with tiered sign-out actions distinguishing active session, single account, and all accounts (`local_logout`, `federated_logout`, `explicit_logout_all`, `profile_menu_log_out_all_accounts`, `active_session_logout`).
- **Code Review PR Panel Persistence**
  - Added PR review panel persistence keys (`code-review-pinned-prs-v1`, `code-review-recent-prs-v2`, `code-review-sidebar-section-collapsed-v1`, `code-review-sidebar-section-order-v1`) and review queue states (`needs_my_review`, `needs_my_teams_review`, `waiting_for_review`, `new-review-task`, `review-diff-load`, `missing_gitlab_connector_link`).
- **Pages Collaborative Documents (DIL)**
  - Added structured DIL collaborative document rendering and room states (`page_dil_document` / `layout` / `widget` / `inline_widget` / `text_style`, `repository-pages`, `pages_document_download_button`, `page_room_full`, `page_update_rejected`).
- **Environment Configs, Credentials & Cloud Workspaces**
  - Added server-side environment setup configurations and multi-source credentials (`environment-setup-server-configs-v1`, `vault_secret`, `network-secret`, `direct_environment_variable`, `refresh_credential`, Azure `azure_client_id` / `azure_tenant_id`, GCP and gateway login hosts, plus `xaa_enrollment_required`).
  - Expanded cloud workspace and remote desktop states (`devbox_vnc`, `cloud_desktop`, `codex_work_desktop`, `tailscale_up`, `tun_permission` / `tun_unavailable`, `workspace_deactivated`, `slack_workspace_access_pending`).
- **In-Image Text Editing, Worktree Attachments & Quick Launcher**
  - Added an in-image text editing module (`image-text-editing-requests` retaining up to 100 drafts, paired with `image-text-editing-operations`).
  - Added `omni-dot` quick launcher channels (`open-omni-dot`, `focus-omni-dot-launcher`, `open_dot_with_draft`, `dot-hub`).
  - Added `linked_worktree` attachment type with the `worktree-plugin-v1:` identifier prefix and preference onboarding.
  - Integrated the `local_work_search_mcp` branch into tool discovery (carrying `_meta.connector_id`).
- **Model Catalog & Analytics Events**
  - Added `gpt-5-t-mini` to the model catalog (context window: `196,608` tokens paid / `16,384` tokens free).
  - Added Beacon subscription upsell and direct checkout flow fields (`beacon_upsell`, `beacon_checkout_mode`, `direct_checkout`).
  - Expanded Protobuf analytics events to 336 entries, adding `CodexBrowserInteractionsInlineCard`, `CodexBrowserUseBotDetectionReported`, `CodexProfileArtifactCardAction`, and `CodexProfileArtifactCardShown`; removed deprecated workspace credit exhaustion notices and `outlook-calendar` / `outlook-email` keys.

## MCP Tool Surface, Engine & Built-in Plugins

- **MCP Tools & Protocol Surface**: Built-in `codex_app` tools (59 tools plus 5 conditional managed Worktree tools), 11 bundled plugin `.mcp.json` manifests, MCP protocol negotiation versions, and 131 AppServer RPC methods remain unchanged; only the status display description in `update_running_summary` changed from "pet activity pill" to "public goal".
- **Codex Engine & Native Layer**: Updated `CodexCLI` to `0.167.0-alpha.4.1`, recompiling `codex-code-mode-host`, `codex-exec-server`, 7 GStreamer voice pipeline plugin libraries, all 23+ desktop native modules against Chromium `157.0.8103.51`, and the `Codex Computer Use.app` helper bundle.
- **`browser` / `chrome` Plugin Refactoring**: Embedded a full Segment analytics pipeline inside `browser-service.mjs`, updated cloud and in-app browser (IAB) tab cleanup guides (`tab-cleanup-cloud.md` / `tab-cleanup-iab.md`), removed `tab-claiming-dot`, migrated browser bot-detection reporting to renderer-side `CodexBrowserUseBotDetectionReported`, and recompiled the `ChatGPT for Chrome` native extension host.
- **`visualize` Plugin Enhancements**: Added four interactive dashboard scripts (`dashboard-annotations.js`, `dashboard-layout.js`, `dashboard-source-actions.js`, `dashboard-sources.js`); enabled wide mode by default for waterfall charts, error stack traces, flamegraphs, and weekly/monthly calendar widgets, and partitioned Codex-specific chart configuration blocks.
- **`hatch-pet` Skill Pipeline Update**: Replaced local chroma-key background removal with direct native alpha-channel generation via `image_gen` (`transparent_background: true`) paired with native alpha validation and a new `test_native_alpha_pipeline.py` test suite.
