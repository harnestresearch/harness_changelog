## Overview

Antigravity Desktop (`antigravity-hub`) `2.32.0` retains Electron `44.9.1` and the unchanged three-plane MCP baseline (`CHROME_DEVTOOLS_MCP_JS` spawn wiring, `18 + 1` built-in `chrome_devtools` injected tools, and byte-identical bundled `chrome-devtools-mcp` `1.9.0`), while expanding the Electron `dist/` bundle (`59 → 70` top-level entries plus a new `30`-file `dist/remote/` directory) and growing `language_server` from `206.8` MB to `240.0` MB (`+31.6` MiB, ~90% in `.noptrdata` protobuf descriptors). Officially, `2.32.0` announces **Dynamic Workflows**, **Everforest Light/Dark** themes, prompt navigation shortcuts, stronger agent browser tab guardrails, **11 improvements**, and **13 fixes**. Under the hood, static diffing shows that `run_workflow` and the standalone Python runtime were already compiled identically into `2.31.2` (making Dynamic Workflows a rollout/gate graduation), while `2.32.0` lands major new client/backend subsystems: an **SSH remote development stack** (`dist/remote/`), a **three-layer Catcher guest WebContentsView stack**, **cross-site subframe credential stripping & Electron UA sanitization**, replacement of `shell-env`/`execa` (`8 → 7` dependencies), a gated **`cortex/ext/plugins/computer` desktop control plugin** (`ComputerViewerService`), **`CloneGitHubRepo`** Connect-RPC (`374 → 375` real methods), **`+58` feature flags** (`54 → 112` keys), `AgentRemoteSessionMessages` over `WatchTopic`, and `openaiResponsesConverter`.

- **Plane 1 — Electron Shell Spawn Wiring**: `dist/languageServer.js` extracts `baseLsArgs` into pure module `dist/lsDefaults.js` (for reuse by SSH remote LS) with identical CLI flags (`--standalone --override_ide_name antigravity --subclient_type hub --api_server_url … --cloud_code_endpoint … --enable_sidecars`), retains `CHROME_DEVTOOLS_MCP_JS` (`setupNodeModules` around `languageServer.js:271`) as the sole MCP env var, and preserves `tightenActivePortPermissions` (`0o700` / `0o600`) and `dist/guestWebMcpController.js` unchanged.

## Electron Shell Changes (`app.asar/dist`: `59 → 70` Top-Level Entries + `dist/remote/`)

- **SSH Remote Development Stack (`dist/remote/`, `30` New Files)**:
  - Runs Hub's `language_server` on a remote SSH host while turning the local window into a restricted security view (`--ssh-host=` CLI argument on cold start and second-instance; `--agy-backend=ssh` renderer flag exposing `window.sshRemote` / `createLocalSshRemoteAPI` without script jail).
  - `remoteLsArgs.js` launches remote LS with `lsDefaults.baseLsArgs` + `--persistent_mode` + `--workspace_id REMOTE_LS_WORKSPACE_ID` + `--enable_sidecars`, intentionally omitting `--exit_on_stdin_close` and host bridge flags so the remote LS and its agents survive disconnects.
  - `bootstrapScript.js` (`42` KB embedded shell/awk script) + `bootstrapProtocol.js` bootstrap remote installation and discovery (`ls_<sha256(workspaceId)[:16]>.json`, matching `writeDiscoveryFile` in `server.go`) using per-connection random secret markers (`OPEN_URL`, `NEED_UPLOAD(<abi> <reason>)`, `READY`, `agy_fail(UNSUPPORTED_HOST|SHARED_HOME_UNSUPPORTED|INSTALL_FAILED|LS_START_FAILED|LS_STOPPED)`), backed by `sshConnection.js` (`52` KB), `remoteManager.js` (`35` KB), `sshAskpass.js` (UNIX socket + token), `sshConfigHosts.js`, `sshDestination.js`, `sshPrompts.js`, `sshBridge.js`, `sshRecentHosts.js`, `transport.js`, `remoteSidecars.js`, `disconnectedPage.js`, `hostStores.js`, `windowBackends.js`, `privateDir.js`, `localNetwork.js`, `signInCallback.js`/`signInUrls.js`, and `ANTIGRAVITY_SSH_{BIN,ASKPASS_SOCKET,ASKPASS_TOKEN,LS_VERSION,LS_REMOTE_PATH}` env vars.
  - Enforces a `27`-channel IPC allowlist (`remoteIpcChannels.js`: basic window/storage/notification/agent ops + `ssh:{get-state,open-local-window,stop-server,take-intent}`) and a defense-in-depth `localOnly(channel, handler)` wrapper in `ipcHandlers.js` blocking remote windows from dialogs, updater, logs/ports, `plugin://` maps, local files, IDE, WSL, built-in browser, and script jail (`getLocalHubWindows` also excludes SSH windows).
- **Three-Layer Catcher Guest View Stack**:
  - Added `dist/catcherChannels.js` and `dist/catcherPreload.js` (`351` lines) forwarding `9` `wcv:catcher-*` gesture channels (`pointer down/move/up/leave`, `wheel`, `pinch`, `drag`, `set-cursor`), upgrading Hub guest webviews from a dual `WebContentsView` layout to `base UI + clip view + catcher overlay` (gated by storage-backed `isWcvThreeLayerStackEnabled` in `utils.js`, alongside `wcvZOrderController.js` CDP capture fallback/cursor-hole handling and `584` changed lines in `wcvBrowserRegistry.js`).
- **Browser Tab Guardrails & User-Agent Sanitization (Matches Official Browser Improvements & Fix)**:
  - `dist/guestCrossSiteCredentials.js` (`424` lines): strips `Cookie` and `Authorization` on requests (retaining `User-Agent` / `Proxy-Authorization`) and `Set-Cookie` on responses for cross-site subframes in agent-owned guest partitions using an embedded multi-label public suffix table (`co.uk`, `ac.jp`, `com.au`, etc.), aligned with `agentBrowser/subframeProtocol.ts` screenshot/snapshot redaction.
  - `dist/guestRequestHeaders.js`: consolidates per-session `onBeforeSendHeaders` hooks into a single fail-closed rewriter pipeline so Electron listeners do not silently overwrite one another.
  - `dist/webviewBrowser.js` (`stripGuestElectronUserAgentToken`): strips `Electron/<ver>` tokens and reorders app tokens around `Chrome/<ver> Safari/<ver>`, while preserving unmodified official Chrome UAs where Google **BotGuard** checks `window.chrome.app` during Google Sign-In.
- **`shell-env` Removal (`package.json` Dependencies `8 → 7`) & Storage Hardening (Matches Official Quit/Settings Fix)**:
  - Removed `shell-env ^4.0.3` (`−20` `node_modules` packages across `shell-env`/`execa`) and replaced it with custom `dist/loginShellEnvReads.js`, `dist/loginShellEnv.js`, and `dist/loginShellPolicy.js` (`prefetch` + `take` with a `10s` wait cap) because `execa`'s process-level exit/signal hooks reset Electron's `SIGTERM` handler and prevented `before-quit` from shutting down `language_server`.
  - Added `StorageFullError`, Windows `EPERM`/`EACCES` rename-replace retry handling, and `mainStoreScope` per-host settings isolation in `dist/storage.js`, plus manual redirect-following `fetchWithoutFollowing` (`301/302/303/307/308` with session `Set-Cookie` preservation) in `dist/redirects.js`.

## Official `2.32.0` Release Summary (`11` Improvements, `13` Fixes)

- **11 Official Improvements**: Dynamic Workflows (bundled Python runtime); Everforest Light & Dark themes; previous/next prompt navigation shortcuts; optional `Submit Prompt` shortcut; copyable sign-in link & one-time auth code paste fallback; height-adaptive model selector with `Refresh` button; agent notification & download-drawer blocked status on file-type-rejected downloads; signed-out & screenshot/snapshot-hidden cross-site frames in agent browser tabs; MCP server startup errors shown on plugin cards/headers; host terminal-sandbox unavailability notes in permission menus; and local cloning of Cloud GitHub repos + direct PR link sign-in for remote agents.
- **13 Official Fixes**: Built-in browser `Electron` UA token blocking; background process leak on quit & temporary file-lock settings save failures; blank/broken full-page plugin views after plugin restart/update; Google Drive `@` mention sign-in; Linux `Pin Conversation` shortcut conflict with Chrome tab groups; Automations sidebar filter hiding plugin conversations; flattened lists & dropped link pills on queued-message edit / step revert / draft restore; long-conversation upward scroll stalls (smaller/earlier history page prefetch); CJK bold text rendering at regular weight; `Open File` opening transient preview tabs; last-response toolbar/card flicker on conversation revert; long hyphen lines freezing accessibility announcements; and immediate disappearance of project shell setup `Saved` confirmations.
