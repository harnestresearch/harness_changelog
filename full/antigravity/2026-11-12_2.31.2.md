## Overview

Antigravity Desktop (`antigravity-hub`) `2.31.2` upgrades the Electron host to `44.9.1` and expands the Go `language_server` (`third_party/jetski/cortex/*` + embedded Rust `ripgrep`) from `195.9` MB to `206.8` MB while keeping the core three-plane MCP wiring byte-identical to `2.29.0`. On the Electron shell (`dist/` `37 → 56` files), `2.31.2` introduces a CDP-backed **Guest WebMCP bridge** for consuming guest webview page tools and tightens `DevToolsActivePort` filesystem permissions (`0o600` / `0o700`). Inside `language_server`, native tools grow from `~50` to `~60`—adding the `cortex/core/native_swarm/` tool family (`manage_swarm`, `post_message`, `read_board`, `swarm_wait`), `planexecute` `enter`/`exit` gating tools, `update_focus`, `notebook_execution`, persistent terminal parameters on `run_command`, a parallel `oneharness` agent framework (14 tools), the `StartMcpOAuthSignIn` Connect-RPC method, and the `sir_flash_lite` LLM threat pre-screener.
