## Overview

`Antigravity IDE` (`2.6.0` → `2.7.0`; release time unconfirmed—`2026-11-11 12:46` Beijing Time in `product.json` is the build timestamp, not the release timestamp) is a separate Code OSS `1.107.0`-based IDE product line distinct from the standalone Electron `antigravity-hub` app (`2.31.2`). Across all six official packages (`2` versions × `3` platforms), **100% of substantive code changes between `2.6.0` and `2.7.0` reside in 4 files inside `extensions/agy/`** (`package.json` `0.0.1` → `1.11.0`, `package.json.patch`, `vscode/extension.js` `+90,987` B, and `bridge.js` `+9,333` B). The Code OSS workbench/main shell (`out/`), standalone `jetskiAgent` 6-window renderer (`11.8 MB`), VS Code native MCP & `ext-apps` host registration, `102` built-in extensions inventory, and `351`-method `LanguageServerService` protobuf descriptor are substantively identical between `2.6.0` and `2.7.0` (differing only in trailing 37-byte sourcemap commit hashes and version metadata).

## Product-Line Architecture: Antigravity IDE vs. Antigravity Hub (`2.31.2`)

- **Shell & Packaging**: Unpacked Code OSS `1.107.0` layout (`no app.asar`, `28` B empty `node_modules.asar`, `12.9 MB` webpack `out/main.js`, `extensions/` with `102` extensions and `enabledExtensions: ["google.google-antigravity"]`), plus IDE-exclusive `out/jetskiAgent/` (`11,837,046` B renderer bundle + 6 `AgentWindow` types with `Uninitialized → Shadow → Materialized` lifecycle and `uss-lsClientInfos` Unified State Sync).
- **On-Demand `agy --hub` Backend (Zero Bundled `language_server` or MCP Servers)**: Neither `language_server` nor `chrome-devtools-mcp` is bundled in the IDE installer (`node_modules` `400` top-level packages on Linux/macOS and `1,367` unpruned on Windows contain zero MCP server packages). Instead, `extensions/agy` downloads `~/.gemini/bin/agy` from `https://antigravity-cli-auto-updater-974169037036.us-central1.run.app` (or dogfood GCS, verified via `sha512` manifest + `.agy-install.lock`), spawns `agy --hub --hub-port=<N> --app_data_dir=antigravity --csrf_token=<t>`, and reports `{port, csrfToken}` through `ExtHost/MainThreadAntigravityProductInfo` to connect over `http://127.0.0.1:<port>`. _(Note: `--hub` here denotes `agy`'s local loopback Connect-RPC daemon mode, unrelated to the `antigravity-hub` desktop app.)_
- **Auto-Updater Feed**: `product.json` sets `updateUrl: "https://example.com"` purely as a non-empty enablement gate while `out/main.js` (`Zqe()`) hardcodes `https://antigravity-ide-auto-updater-974169037036.us-central1.run.app/api/update/{assetId}/{quality}/{commit}/{sha256(hostname)}` (sharing GCP project `974169037036` with the CLI updater).
