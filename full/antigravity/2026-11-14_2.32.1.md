## Overview

Antigravity Desktop (`antigravity-hub`) `2.32.1` is a next-day point release over [2.32.0](2026-11-13_2.32.0.md) (`cl/1020489536` → `cl/1021296516`). Static comparison confirms that the Electron shell (`app.asar` `dist/` + `node_modules/`, `1,068` files, `18,668,119` B) and unpacked `chrome-devtools-mcp` `1.9.0` are **byte-for-byte identical** to `2.32.0` (only `package.json` `version` updates `2.32.0 → 2.32.1`), while the recompiled `239,952,296`-byte Go `language_server` introduces a single detectable semantic change: adding **`Gemini 4 Hydrogen`** (`low` / `medium` / `high`) to the built-in default model catalog.

## Direct Diff (`2.32.0` → `2.32.1`)

- **Go `language_server` — `Gemini 4 Hydrogen` Default Model Catalog Addition**:
  - Added built-in default model presets `gemini-4-hydrogen-low`, `gemini-4-hydrogen-medium`, and `gemini-4-hydrogen-high` (display name `Gemini 4 Hydrogen (High)`), backed by symbol `google3/third_party/jetski/models/defaults/defaultmodels.Gemini4Hydrogen` and latency telemetry metric `gemini-4-hydrogenaicode_latency_ms` alongside existing `gemini-4-argon-*` and `gemini-4-carbon-*` entries (`2.31.2` and `2.32.0` had `0` `hydrogen` model entries).

- **Electron Shell & Bundled MCP — Byte-for-Byte Identical (`diff -rq` Exit `0`)**:
