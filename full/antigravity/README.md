Multi-platform technical version history for Google **Antigravity** (`https://antigravity.google`) across `mac`, `win`, `ubuntu`, `ios`, and `android`, covering **9** analyzed releases across its two distinct desktop product lines:
- **Antigravity Desktop (`antigravity-hub`)**: standalone Electron `44.9.1` app bundling monolithic Go `language_server` (`2.31.2` → `2.36.0` across `mac`, `win`, `ubuntu`, latest 2026-11-27; `2.31.2`–`2.32.1` static diffs anchored on `linux-x64`, `2.32.2`/`2.35.1`/`2.35.2`/`2.36.0` anchored on `darwin-arm` with cross-platform same-build checks).
- **Antigravity IDE (`Antigravity IDE`)**: Code OSS `1.107.0` / Electron `39.2.3` IDE spawning on-demand `~/.gemini/bin/agy --hub` (`2.7.0` → `2.8.0` across `mac`, `win`, `ubuntu`, latest 2026-11-19).
