## New Features & Architectural Additions

### 1. Git Repository Plugin Sources (`@deepseek-ai/dsh-plugin-market-index`, `@deepseek-ai/dsh-plugin-market`, PR #8159)
- **Gating**: `@deepseek-ai/dsh-experimental-plugin-market-bundle` stays in `OPTIONAL_BUNDLES`, `EXTENSION_BUNDLES`, and `EXPERIMENTAL_BUNDLES` (`packages/util/official-bundles/src/bundles.ts:72`, `plugin-manager.ts:42,81`)—disabled by default until toggled on in Plugins.
- **Address Parsing (`packages/util/plugin-market-index/src/source.ts:1-72`)**: Recognizes `git+https://`, `git+ssh://`, `ssh://`, GitHub SCP-style SSH shorthand (`github.com:<owner>/<repo>`), GitHub HTTPS repository links, and `*.git` HTTPS URLs, normalizing into canonical `git+<remote>?path=…&ref=…` (default `path: 'index.json'`; `ref` accepts branch names or 40-hex commit SHAs; rejects credentials, fragments, traversal `..`, or `HEAD`).
- **Repository Cache & Isolation (`packages/boot/plugin-market/src/repository-cache.ts`)**: Uses locked per-URL bare partial clones (`--depth 1 --filter=blob:none`) under `detailCacheDir`, scrubbing `GIT_*` env vars except SSH program, disabling hooks, fsmonitor, submodule recursion, and non-`https`/`http`/`ssh` transports, monitoring directory size every 200ms against `detailRepositoryMaxBytes` and `detailCacheMaxBytes`. Private repo access uses existing Host Git/SSH credentials; icons in Git indexes must be base64 data URLs or browser-reachable HTTPS URLs.

### 2. Experimental Timeline Plugin (`@deepseek-ai/dsh-timeline`, PR #7973, #8630)
- **Gating**: Added to `OPTIONAL_BUNDLES`, `MORE_BUNDLES`, and `EXPERIMENTAL_BUNDLES` (`packages/util/official-bundles/src/bundles.ts:61`, `plugin-manager.ts:53,69`)—disabled by default under **Plugins → More → Experimental**.
- **Capabilities (`packages/experimental/timeline/src/`)**: Persists task trees, weights, priorities, blockers, change history, discussions, and timed reports in the Session log (`2 MiB` max per tree write; UI window up to 7 days of reports and 512 discussions). Registers model tools `timeline_tree`, `timeline_tasks`, `timeline_pull`, `timeline_read`, and `timeline_reply`, optional **Replace Todo tools** mode, clickable progress strip, `/timeline` command with `.timeline.json` export/import (`--copy`, `--continue`), and **Follow app** vs. **Follow chat** language selection across 8 locales. Timed reports may issue separate model calls (first level reuses the latest eligible request prefix; higher levels summarize saved reports; validation failures can trigger one repair call), consuming extra model tokens.

### 3. Code Review Page, Forge Extension API & GitLab Provider (`packages/experimental/forge*`, PR #8321, #8362, #8228, #8317, #8536, #8297)
- **Gating**: All components load only via `@deepseek-ai/dsh-experimental-forge-bundle` (`OPTIONAL_BUNDLES`, `EXPERIMENTAL_BUNDLES`, `bundles.ts:74`, `plugin-manager.ts:74`, **OFF by default**); `cordis.patch.yml:10-11` now mounts `@deepseek-ai/dsh-forge-gitlab` beside `forge-github`.
- **Code Review Page (`packages/experimental/client-ui-forge/src/viewer-lists.ts`, `src/client/review-page/`)**: Adds a dedicated review page streaming `review-requested`, `authored`, and `involved` change-request lists with sidebar counts, detail view, status column, and in-page agent collaboration (`ReviewChat.tsx`). **Verified provider scope**: `packages/experimental/forge-github/src/provider.ts:75,128,141` implements `viewer` / `listForViewer` / `countForViewer` via Host `gh` CLI; `packages/experimental/forge-gitlab` does **not** implement `viewer` lists, so the global review page lists GitHub PRs only.
- **GitLab Provider (`packages/experimental/forge-gitlab/src/{index,provider,api,status,diff,review,writes,glab}.ts`)**: Uses the Host's signed-in `glab` CLI (`glab api` REST/GraphQL, environment-scrubbed, non-retried writes) for GitLab.com and self-managed GitLab MRs bound to Sessions—supporting polled status/pipelines/approvals/mergeability/unresolved discussions, version-pinned diffs, line-range discussions & draft notes (`submit-pending`/`discard-pending`), approvals, draft-ready, merge, pipeline retry, reviewer requests, and rebase (refusing stale head moves).
- **Extension API & Worktree Upgrades**: Plugins can register custom review lenses, line annotations, toolbar/file-menu/comment-box slot actions, and subscribe to `forge/review-changed` (`packages/experimental/forge/src/index.ts:42,795`). Worktrees support custom branch naming (validated against Git rules and existing branches), remote base branch selection (single-branch tagless fetch), deferred creation after the first message, and tracking PRs created/pushed via `gh` or `git push` inside PTC programs (PR #8297).

### 4. Session Panel & Extracted Session Status (`@deepseek-ai/dsh-client-ui-session-panel`, `@deepseek-ai/dsh-client-ui-session-status`, PR #7965, #7990, #8625, #8609, #8130, #6858)
- **Session Panel (`packages/client/ui-session-panel`, default-on in `dsh-web-app:476-477`)**: Header toggle + extensible floating panel (built-in **Environment** section plus registered sections for change requests, subagents, tasks, and plugins) with drag-to-reorder persistence (`localStorage` `dsh.sessionPanel.pinned`). Docks at `300–360px` when the end gutter reaches `348px` (shifting transcript/composer left on frames ≥`1068px`), and opens as a `280px` Escape-dismissible overlay on narrower viewports.
- **Read/Unread Status (`packages/client/ui-session-status`, default-on in `dsh-web-app:295-296`)**: Moves `SessionStatus`, `SessionStatusSnapshot`, `UseSessionStatus`, and `useSessionStatus` out of `@deepseek-ai/dsh-client-ui-session` into a standalone Host+Client package (`SessionStatusService`, `src/index.ts:25`). Tracks Host-shared reading records across clients of one Host, adds required `completionFailed` field, supports menu/shortcut toggling (`mark(sessionId, unread)`), and preserves recent sessions/sidebar state while skipping off-screen conversation folding (PR #8502).

### 5. Web Remote Login, Device Pairing & Pluggable Connection Auth (`@deepseek-ai/dsh-client-remote-connection`, `@deepseek-ai/dsh-host-authentication-{token,desktop}`, PR #8266, #7675, #8898, #8920)
- **Remote Connection (`packages/client/remote-connection/src/index.ts:60`, default-on in `dsh-web-app:354-355`, omitted in Desktop window)**: Adds **Settings → Remote connection** with one-use QR codes (`ticketLifetimeMs: 120_000`, `cookieMaxAgeDays: 30`), tokenized private login URLs (loopback login URL restored in PR #8920), and owner-approved browser pairing (`requestTtlMs: 300_000`, `maxRequests: 32`, `requestIntervalMs: 1_000`, `pollIntervalMs: 2_000`). Anonymous login page supports English and Chinese.
- **Connection Authentication API & Providers (`docs/upgrade-guide/v0.2.2-rc.2/connection-page-peer`)**:
  - `webServer.register` / `registerFallback` / `registerUpgrade` now accept `auth: 'anonymous' | 'required' | 'deny'` and **default to `'required'`** (previously public endpoints must opt into `'anonymous'`).
  - `@deepseek-ai/dsh-host-authentication-token` (`web-app:258-259`, `src/index.ts:31`, `src/browser-auth.ts:30`) extracts default Token login & `/api/remote.mux` socket claims, and caps retained cross-port cookies on one hostname to **17 authorities** (current + `RETAINED_OTHER_COOKIES = 16` most recently issued) to prevent Node.js `16,384`-byte header HTTP `431` lockouts (PR #8898). Plain-HTTP listeners cannot set `Secure` cookies.
  - `@deepseek-ai/dsh-host-authentication-desktop` (`src/index.ts:23`) authenticates Electron Desktop requests via an in-memory private parent IPC secret (`dsh-desktop-session` cookie) without exposing credentials to the renderer.
