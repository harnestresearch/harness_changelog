## Overview

`dsh-v0.2.3-alpha.2` is a targeted runtime-floor and dependency-alignment **alpha prerelease** succeeding `dsh-v0.2.3-alpha.1` across **`5` commits** (`3` first-parent commits on `master`: PR #8837, PR #8960, PR #8961) and **`488` changed files** (`3` added, `485` modified, `0` deleted; `+806 / -707` lines). PR #8960 (`5d8fdab85ad`) bumps `9` internal vendor packages under `vendor/*` to `*-alpha.1`, and PR #8961 (`4b399c39a6d`) bumps `404` workspace manifests from `0.2.3-alpha.1` to `0.2.3-alpha.2`. ## Exact Node.js Version Range & Enforcement Analysis

### Declared Semver Range Truth Table (`^24.22.3 || >=26.13.1`)

Replaced `">=24.9.0"` in `package.json:9` (`@deepseek-ai/dsh-root`) and `apps/cli/package.json:191` (`@deepseek-ai/dsh`). Under npm `node-semver`, `^24.22.3 || >=26.13.1` expands to `>=24.22.3 <25.0.0-0 || >=26.13.1`:

| Node.js Version / Major Line | Matches `engines.node`? | Equality vs. Range Semantics & CI Verification Status |
|---|---|---|
| `< 24.22.3` (`20.x`, `22.x`, `23.x`, `24.0.0`–`24.22.2`) | **No (Excluded)** | Rejected by `^24.22.3 \|\| >=26.13.1` (note: independent `native/system/packages/*/package.json` remains `">=20"`). |
| `24.22.3` (exact) | **Yes (Allowed)** | Exact floor; also the **only** version accepted by strict `===` checks in `scripts/run-gates.ts:499` (when `DSH_NODE_COMPAT_BUILD=1`), `scripts/primary-runtime/prepare.ts:278` (`lock.json` `24.22.3`), and `pkg --sea` Python SDK exe builds. |
| `24.22.4`, `24.23.0`, newer `24.x` (`< 25.0.0-0`) | **Yes (Allowed)** | **Range `>=24.22.3` within `24.x` (NOT strict equality `==24.22.3`)**. Covered by CI `PRIMARY_NODE_VERSION: '^24.22.3'`. |
| `25.x` (`25.0.0`–`25.x.y`) | **No (Excluded)** | Excluded by the implicit `<25.0.0-0` upper bound of `^24.22.3` combined with the `>=26.13.1` floor on the second branch (previously `>=24.9.0` admitted `25.x`; upgrade guides omit mentioning `25.x` explicitly). |
| `26.0.0`–`26.13.0` | **No (Excluded)** | Newly excluded (previously admitted by `>=24.9.0`) because their bundled `undici` predates `8.12.4` (November 2026 security fixes). |
| `26.13.1` and newer `26.x` | **Yes (Allowed)** | Range `>=26.13.1`. Note CI `node-compat` matrix in `.github/workflows/ci.yml:1034` specifies floating `node: 26` (latest `26.x`), not pinned `26.13.1`. |
| `27.0.0` and higher (`27.x+`, `28.x+`) | **Yes (Allowed by semver)** | Because the second branch uses `>=26.13.1` (not `^26.13.1`), there is **no upper major cap**; however, **CI does not test Node 27+** (unverified beyond `24.x` and `26.x`). |
