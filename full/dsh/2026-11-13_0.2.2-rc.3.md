## Overview

`dsh-v0.2.2-rc.3` is a **prerelease** candidate succeeding `dsh-v0.2.2-rc.2` (`6` commits, `515` files changed, `+10,988 / -669` lines across `135` non-manifest files and `380` workspace `package.json` manifests). It introduces the optional experimental `@deepseek-ai/dsh-deepseek-chat-import` bundle for importing `chat.deepseek.com` `deepseek_data-*.zip` exports as native resumable Sessions, adds the `sidebar.session.action` HOC slot and reusable `workspace.picker` Component Factory in the Web/Desktop client UI, hardens `@deepseek-ai/dsh-session-log-export` against missing/synthetic attachment objects and leaked file iterators, fixes a Windows NSIS update-restart directory lock in `@deepseek-ai/dsh-desktop`, and caches SHA-256-verified `bubblewrap` archives in Linux CI workflows.

## Highlights

- **Experimental DeepSeek Website Chat Export Importer (`@deepseek-ai/dsh-deepseek-chat-import`, PR #8342)**: Ships an off-by-default experimental optional bundle (enabled in **Plugins → More → Experimental plugins**) that uploads a `deepseek_data-*.zip` archive over an owner-only route, validates and unpacks it purely in memory via `fflate`, and converts up to `maxSessions` (`1,000`) recent conversations into native persisted DSH Sessions in a chosen Workspace—complete with protected empty `system/message` surface heads for clean Agent resumption, image attachment extraction, `web_search` / `web_fetch` tool cards, and 8-locale UI translations.
- **Reusable Client UI Extension Seams (`sidebar.session.action` & `workspace.picker`)**: Wraps the sidebar **New session** row in a root-scoped `sidebar.session.action` HOC slot and exposes the hero Workspace selector as a root-scoped `workspace.picker` Component Factory (`workspace.picker.directoryFlow` wired across both `-browse` and `-native` directory pickers).
- **Resilient Session Log ZIP Export & Windows Update Lock Fix**: Prevents deleted, synthetic, or invalid attachment references from aborting `/api/session.export` ZIP downloads (logging them to `attachments-missing.txt` instead and draining open streams via `Promise.allSettled`), and launches the Windows update-restart status `rundll32.exe` child in `GetSystemDirectoryW` so it no longer locks the app installation folder during NSIS replacement (PR #8385).

## New Features

- **Optional Experimental Bundle `@deepseek-ai/dsh-deepseek-chat-import` (`packages/experimental/deepseek-chat-import`, `b8c33a15042` / PR #8342)**:
  - **Bundle & Catalog Registration**: Registered in `OPTIONAL_BUNDLES` (`packages/util/official-bundles/src/bundles.ts`), `MORE_BUNDLES`, and `EXPERIMENTAL_BUNDLES` (`plugin-manager.ts`), with `EXPERIMENTAL_PACKAGE_NAME_EXCEPTIONS` allowing the unprefixed package name, `cordis.patch.yml` (`insert: deepseek-chat-import`), `@deepseek-ai/dsh` dependency wiring, Cordis service catalog entry `ctx.deepseekChatImport` (`DeepseekChatImportService` mapped to `docs/subsystems/persistence.md`), bilingual `docs/DETAIL.{md,zh.md}`, and 8 locale metadata files (`de`, `en`, `es`, `fr`, `ja`, `pt`, `ru`, `zh`).
  - **Owner-Only Upload Route & Dual Transport Client (`src/protocol.ts`, `src/upload.ts`, `src/client/upload.ts`)**:
    - Exposes `@Remote limits(signal)` (throwing `deepseekChatImport/owner-only` for non-owner principals) and exact route `POST /api/deepseek-chat-import/archive?workspaceId=…` (`application/octet-stream`) on `ctx.connection.fetch`, guarded by a single-flight `busy` slot and per-request `AbortController` (unloading the plugin aborts any in-flight import and awaits completion before disposal).
    - Client uploads via `XMLHttpRequest` on served HTTP pages (reporting byte upload percentage) or falls back to pre-boot `__DSH_TRANSPORT__.fetch` when the Host runs in another execution context without an HTTP server (such as static preview shells). Streams responses as `application/x-ndjson` (`{ type: 'progress', done, total }` lines followed by `{ type: 'outcome', outcome }`), validating each line with strict type guards and aborting immediately on malformed JSON.
  - **Bounded In-Memory Archive Validation & Two-Pass Importer (`src/archive.ts`, `src/format.ts`, `src/conversation.ts`, `src/importer.ts`)**:
    - Configurable `Config` limits: `maxSessions = 1000`, `maxUploadBytes = 536_870_912` (`512 MiB`), `maxEntryBytes = 268_435_456` (`256 MiB`), and `maxTitleBytes = 80`.
    - Validates `manifest.json` (`export_format_version: 3`, targeting the `2026-11-12` export schema while treating newer fields as optional) and `chat_session_index.json` (`missing-index` if absent); rejects duplicate central-directory entry names, `ZIP_STORED` compressed/declared size mismatches, and entries exceeding `maxEntryBytes` prior to decompression. Closed failure reason union: `'too-large' | 'unreadable-archive' | 'missing-manifest' | 'missing-index' | 'unsupported-version' | 'no-conversations' | 'workspace-not-found' | 'busy'`.
    - Selects the newest `maxSessions` conversations by `updated_at` (`inserted_at`, then `id` tie-breakers) and backfills from older indexed entries when a chosen conversation fails conversion/validation (`omittedByLimit` counts only unattempted conversations). Pass 1 streams and stores referenced user images (`png`, `jpg`, `jpeg`, `webp`, `gif`) into `ctx.attachments`; Pass 2 converts each conversation one at a time while yielding to the event loop, verifies the target Workspace still exists before each write, validates seeds with `Session.create()`, writes JSONL logs via `sessionPersistence.create()`, updates `sessionProjectionCache.coldSnapshot()`, and calls `workspaceRegistry.attachSession()` (reporting stored-but-unattached IDs in `skipped`).
    - **Session Seed & Fragment Mapping**: Writes an empty `system/message` as protected surface node `0` on the first imported turn so resumed Agents replace it with the live system prompt instead of appending after history and triggering `SessionPersistenceCorruptionError`. Selects the branch ending at `current_message_id` (fallback: greatest message ID); splits steps on `stage_id` changes only when the open step already holds a tool call (keeping call-less steps merged) or when reasoning/text follows a tool call; normalizes titles via `normalizeSessionTitle` pinned as user titles; maps `THINK` + `RESPONSE` to `assistant/message` (`source: 'deepseek-chat-export'`), `SEARCH` → `web_search` (`FAILED` replayed as error result, `WIP` skipped), addressed `TOOL_OPEN` → `web_fetch`, `READ_LINK` → Markdown `[title](url)` lines, and unstored images or non-image files → byte-less synthetic file cards (`brandString<AttachmentId>`). Drops `CONTENT_FILTER` rounds (question + reply), omits `CONTENT_RISK` / `TIP` / `TOOL_FIND` / `PARTIAL_FILE_READ` / `TOOL_IMAGE_SEARCH` / address-less `TOOL_OPEN`, and terminates unfinished/template replies with `turn/end { kind: 'error' }` (`DEEPSEEK_EXPORT_*`, including `DEEPSEEK_EXPORT_UNFINISHED_REPLY`).

## Bug Fixes

- **Windows Update Restart Status Directory Lock (`apps/desktop/installer/restart-status.h`, PR #8385 / `ac904e118e3`)**:
  - `InstallerStartRestartStatus` now passes `GetSystemDirectoryW` (`launch->directory.c_str()`) as `lpCurrentDirectory` to `CreateProcessW` when spawning `rundll32.exe` for `ShowRestartStatus`, preventing the status banner process from inheriting and locking the application installation directory while NSIS renames/replaces it during an update. Verified by `apps/desktop/tests/windows-restart-status.ps1` (`Move-Item` rename test while status window is alive).
- **Session Log ZIP Export Missing-Attachment Resilience & Iterator Cleanup (`packages/session-query/session-log-export/src/archive.ts`, PR #8342 / `b8c33a15042`)**:
  - `sessionLogZipEntries` now catches `UNREADABLE_ATTACHMENT_CODES` (`ATTACHMENT_NOT_FOUND`, `INVALID_ATTACHMENT_REF`) on `readImage` and `readFileStream`—using a new `headOf()` helper to pull the first file chunk before yielding the ZIP entry—and records skipped items in `attachments-missing.txt` (`<archive-path>\t<error.message>`) instead of failing the whole ZIP download, while still propagating integrity/I/O errors such as `ATTACHMENT_CORRUPT`.
  - Tracks active file iterators in an `openStreams` set and closes all remaining streams via `Promise.allSettled` in a `finally` block when a consumer aborts or stops early, preventing file-handle/iterator leaks without masking in-flight exceptions.
- **CI Verified Bubblewrap Archive Caching & Bounded Downloads (`scripts/ci-verified-download.sh`, `scripts/prepare-ci-bubblewrap.sh`, `.github/workflows/{ci,ci-master,e2e}.yml`, PR #8383 / `bbad94f927a` & `68f83cc9926`)**:
  - Added `acquire_verified_archive` supporting both GNU `sha256sum` and macOS `shasum -a 256` (returning exit code `2` when neither exists rather than misreporting a digest mismatch), atomic `.partial` temp-file replacement with `EXIT` trap cleanup, and bounded `curl` flags (`--connect-timeout 15 --max-time 60 --retry 8 --retry-all-errors --retry-max-time 240`).
  - Wired `actions/cache/restore@v6.1.0` and `actions/cache/save@v6.1.0` on `~/.cache/dsh-ci/bubblewrap` (`bubblewrap_0.12.0-1_amd64.deb`) across hosted Linux CI and E2E jobs (explicitly skipped on persistent self-hosted fleet runners).
