## Overview

A cross-platform (`mac`, `win`, `ubuntu`) minor patch release (`3.30.8` → `3.30.14`) upgrading Electron `43.8.4` → `43.8.9`, landing client plumbing for default-off **Deploy App** live web app publishing (`AppPublishService.getAppsEligibility`, `+2` feature gates, `+5` dynamic configs, and `molten` `apps-publish` store/UI), tightening daemon team repository governance from whole-repo URL rules to fail-closed `{url, patterns[]}` glob matching (`team-repo-rules.js`) alongside caller-window identification (`caller-window.ts`), and adding main-process `~/.grok/*.toml` configuration and feedback readers (`grokConfigFiles.js`), while keeping the `agent.v1` tool surface, `mcpProcessMain.js`, `cursor-mcp`, Remote Control, mobile session contracts, and network/security policies completely frozen.
