## Overview

A cross-platform (`mac`, `win`, `ubuntu`) security-governance, MCP policy, Remote Control data-plane, and staged brand-transition release (`3.29.15` → `3.30.8`). Across `78` `aiserver.v1` services, unary RPCs expand from `2,444` to `2,555` (`+111`) and protobuf messages from `5,723` to `5,923` (`+207/-7`), led by `DashboardService` (`+56/-3` for Step-Up authentication, third-party OAuth app governance, API key inventory, and member session revocation) and `GrokBotService` (`+48/-1` paired with a default-off `"Cursor is now Grok Build"` onboarding flow in the `glass` bundle). Client-side enforcement lands for admin MCP allowlist/denylist/tool-access policies (`McpError.policy_blocked_reason`), Remote Control pairing adds cryptographic `pairing_proof` verification while expanding `AgentHostService` (`49 → 59` RPCs), `agent.v1.ToolCall` adds `manage_access_tool_call` (`no:95`) and `execute_tool_call` (`no:1000`), and the Electron main process adds `27` modules spanning idle update relaunches, `secrets.js`, `airlockEngine`, and Remote Control target arbitration.
