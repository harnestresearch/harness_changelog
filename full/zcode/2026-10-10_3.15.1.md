# ZCode Desktop 3.15.1

English | [简体中文](../../zh-CN/full/zcode/2026-10-10_3.15.1.md) · [Highlight](../../zcode/2026-10-10_3.15.1.md) | **Full Detail**

- **Release Date**: 2026-10-10
- **Platforms**: `mac`, `win`, `ubuntu`
- **Summary**: Adds UI Plugins (MCP Apps) and interactive message-stream views, Feishu group chat and topic collaboration, per-subagent model selection and pre-run/live parameter controls in Workflows, dangerous-command confirmation in Autonomous Mode, built-in browser site permission prompts, Linux system tray residency, and Windows deep-link launch security hardening.

## Official Release Notes (`zcode.z.ai/changelog`)

### New Features

- The "Invite Friends · Free Dengdeng" campaign is now live, with shared rewards.
- Subscribers can now be randomly selected for a GLM HighSpeed trial.
- Updated "Autonomous Mode" so that dangerous commands require confirmation before execution.
- Added a visual interactive interface that presents information more intuitively in the message stream.
- Added support for UI plugins (MCP App).
- Workflows now support tuning parameters before creation, changing concurrency during runs, and saving runs for replay.
- Workflows can now specify a separate model for each sub-agent.
- You can now collaborate with the assistant on tasks via Feishu group chats and standalone topics.
- The built-in browser now supports site permission management, with confirmation prompts for permissions such as camera access.
- On Linux, closing the window keeps the app in the system tray.
- The account menu now lets you view plan details and copy your user ID.

### Bug Fixes

- Fixed an issue where messages edited during an accelerated turn could be lost.
- Fixed an issue where task status was displayed incorrectly after a workflow was resumed or modified.
- Fixed an issue where new versions were no longer checked for after an update download failed.
- Fixed a security issue where site permissions were allowed by default in the built-in browser.
- Fixed an issue where opening local files in the default browser from the built-in browser failed.
- Fixed an issue where @mentions in group chats were inaccurately recognized.
- Fixed an issue where group tasks stopped responding after Feishu authorization expired.
- Fixed an issue where the entry point for reset opportunities was not visible when the quota was exhausted.
- Fixed an issue where conversations jumped while scrolling when the window was resized.
- Fixed an issue where certain abnormal messages caused session loading to hang.
- Fixed a security issue with launching the app via links on Windows.
- Fixed an issue where launching multiple workspaces at the same time could cause lag.
