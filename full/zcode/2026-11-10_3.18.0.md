# ZCode Desktop 3.18.0

English | [简体中文](../../zh-CN/full/zcode/2026-11-10_3.18.0.md) · [Highlight](../../zcode/2026-11-10_3.18.0.md) | **Full Detail**

- **Release Date**: 2026-11-10 (build `3.18.0-10300`, baseline `3.17.2-9661`)
- **Platforms**: `mac`, `win`, `ubuntu`
- **Runtime**: Electron `44.7.0` / Chromium `152.0.7977.130` / Node.js `v24.21.0`

## Overview

`3.18.0` is a major feature release: the desktop app introduces composer voice input, managed Git Worktree parallel workflows, a standalone MCP-based Extensions host subsystem, the built-in Design plugin with visual click-to-edit in the built-in browser, message editing, a Share Management page, bulk permanent deletion for archived sessions, UI localization expansion (adding Japanese, Korean, and Russian), and OS keyring credential storage; the agent runtime adds 12 multi-session control tools, proactive plugin marketplace discovery tools, `ReadTopicResource`, subagent `WebSearch` call budgets, and `<total_tokens>` system prompt budget injection.

## New Features

- **Chat Composer Voice Input**
  - Added a host-process `voice-input` service acquiring auth tickets via `/api/v1/asr/tickets` and streaming real-time audio over WebSocket for speech-to-text transcription (supporting `finish` / `cancel` control frames and `viaProxy` routing flags).
  - Covers comprehensive voice error states (unauthorized, rate-limited, timeout, max duration exceeded, recording too short, no speech detected, device disconnected, unsupported HTTP proxy, etc.) alongside per-platform microphone permission prompts and Linux PulseAudio/PipeWire device guidance (`voiceInput.*`, 26 keys).
- **Managed Worktree Parallel Tasks**
  - Supports creating isolated managed Git Worktrees from local/remote branches or current `HEAD` for parallel task execution; supports forking any chat message directly into a new Worktree (`chat.message.fork.toWorktree`), carrying over uncommitted changes, cleaning up/deleting Worktrees, and managing them from a dedicated sidebar `Worktrees` view (`git.managedWorktree.*`, 67 keys).
- **Extensions Subsystem**
  - Added an isolated extension host process (`out/extension-host/`) and `@modelcontextprotocol/server@2.0.0` dependency to run MCP-based extensions (`tools/list`, `tools/call`, `elicitation`, `stdio`).
  - Supports activation confirmation, tiered session permission grants (notifications / read-only / read-write / full access), extension views, extension log inspection, and hot reload, alongside a new Extensions category in the plugin marketplace (`extensions.*`, 94 keys).
- **Built-in Design Plugin (`v0.7.2`) & Design System Linting**
  - Added a 4th official bundled runtime plugin `design` (shipping 74 design skeletons, 24 design system references, 11 craft guides, 8 sub-skills, and `design-lint.mjs`), automatically injecting design context via `SessionStart` hooks for HTML mockups, prototypes, slide decks, and redesign tasks.
- **Built-in Browser Enhancements & Visual Design Editing**
  - Supports clicking page elements (including `Shift` multi-select) inside the built-in browser to inspect and edit alignment, colors, font size, font weight, padding, border radius, and opacity, saving changes directly back to local web files (paired with the Design plugin; `browser.design.*`, 61 keys).
  - Added device viewport presets, PNG/PDF page export, per-session last-visited URL persistence across restarts, auto-reload on local file edits, and an option to open HTML files in the built-in browser on single click (`settings.browser.htmlClickOpensBrowser`).
- **Multi-Session Control Tools (12 Tools)**
  - Exposed 12 self-management tools to root agent sessions: `ListSessions`, `ReadSession`, `CreateSession`, `ForkSession`, `SendToSession`, `WaitSessions`, `InterruptSession`, `RenameSession`, plus desktop-exclusive `ListProjects`, `OpenSession`, `SetSessionArchived`, and `SetSessionPinned`.
  - Scoped under `session_control.<method>` permissions (mutating operations require user approval by default, 60s per-call timeout, 32 KB output cap), paired with 42 `chat.toolCall.session.*` UI status strings.
- **Proactive Plugin Marketplace Discovery Tools & Auto-Recommendation Toggle**
  - Added `SearchPlugins` and `SuggestPluginInstall` tools (root sessions only, disabled for subagents), allowing the agent to query the official marketplace and present an install confirmation card (workspace-scoped only, strictly forbidding `Bash` workarounds, and suppressing repeat prompts once dismissed in a session); added a "Plugin Auto-Recommendation" toggle in Settings (`settings.pluginAutoRecommendation`).
- **`ReadTopicResource` Managed Resource Tool**
  - Added `ReadTopicResource` to download files or images from authorized Topic history resource indices (`A1`, `A2`, etc.) into managed local files, strictly restricted to resources approved for the active Topic.
- **Unified Sign-In Entry, `zai_cn` OAuth Provider & Multi-Account Switching**
  - Unified the sign-in entry flow; added a third built-in runtime OAuth provider `zai_cn` (expanding `auth.provider` to `zai | zai_cn | bigmodel`) along with `oauth:active_provider` and `oauth:linked_bigmodel` credential state keys for multi-account switching.
- **Message Editing & Queued Message Batch Sync**
  - Supports editing the most recently sent user message or queued pending messages directly in the composer, with one-click synchronization of model or permission mode changes across all queued messages (`chat.composerEdit.*`, 23 keys).
- **Session Share Expiration & Share Management Page**
  - Added expiration settings when creating shared links and a new "Share Management" page (`ConversationShareService`: `listManagedShares` / `revokeManagedShare` / `restoreManagedShare` / `deleteManagedShare`) to view active shares and remaining validity, jump to source sessions, suspend/restore/delete shares, and explicitly block revoked shares on import (`conversationShare.manage.*`, 41 keys).
- **Bulk Permanent Deletion for Archived Sessions**
  - Supports bulk permanent deletion of filtered archived sessions, resumable interrupted purge jobs, and automatic reference detection to preserve attachments still referenced by other sessions, forks, or shares (`archives.*` expanded to 54 keys).
  - Added database migration #26 (`0025_session_permanent_deletion`) creating `session_purge` and `session_runtime_presence` tables with SQLite triggers blocking any subsequent writes to purging sessions.
- **UI Localization Expansion**
  - Added Japanese (`ja-JP`), Korean (`ko-KR`), and Russian (`ru-RU`) UI locales alongside Chinese and English, refactoring locale tag parsing and legacy language preference migration.
- **OS Keyring Credential Storage & Recovery Flow**
  - Introduced `@napi-rs/keyring@2.1.2` to migrate login credentials into the OS keyring (`org.freedesktop.secrets` Secret Service on Linux, with headless server fallback via `ZCODE_CREDENTIAL_SECRET` or a 32–4096 byte `ZCODE_CREDENTIAL_SECRET_FILE`) plus a guided "Back Up & Rebuild Credentials" recovery flow when keyring corruption is detected (`login.credentialStore.*`, 8 keys).
- **ZCode Sites Traffic Analytics & Instance Upgrades**
  - Upgraded `zcode-site` plugin to `0.5.1`: added `/site-analytics` slash command, `zcode-site analytics` CLI subcommand, backend `/api/v1/sites/analytics/pv24h` and `/api/v1/sites/{id}/analytics` endpoints, and dashboard analytics views (pageviews, unique visitors, average visit duration, bounce rate).
  - Doubled default site container specs (`0.5 vCPU / 512 MB` → `1 vCPU / 1 GB`, Node `--max-old-space-size` `384` → `768`); added `instance single|multi` mode switching, `prefix` subdomain updates, `delete` permanent site removal, and the `delete_site` MCP tool; extracted unified error mapping into `scripts/errors.mjs` (including new code `3614` prefix review errors and code `3610` deploy-lock resume handling).

## Agent Runtime & Prompt Improvements

- **System Prompt `<total_tokens>` Budget Injection**: Injects a dynamic `<total_tokens>${n} tokens left</total_tokens>` block after the `Context Management` section by default (default cap constant `15,000,000`).
- **Subagent `WebSearch` Call Budget**: Added compile-time validated `budget.webSearch` (`0–1024`, default `128` searches per invocation; out-of-range triggers diagnostic `9013`) on dynamic workflow `agent()` calls; injects a search-termination directive once exhausted at runtime and requires disclosure in the handback.
- **Partial Output Recovery on Subagent Interruption**: Delivers already generated partial output with an incomplete-output warning header to the parent agent via `formatSubagentHandback` when a subagent is terminated early.
- **Session Reading Tool Consolidation**: Retired legacy `ReadSessionContext` and its two-stage internal summarization pipeline (Extract / Synthesize handoff capsule) in favor of `ReadSession`.
- **Expanded `ListModels` Registration Scope**: Registers `ListModels` by default whenever root session control mode (`sessionControlKind`) is active, even if dynamic workflows are inactive.
- **Tightened REPL `js` Tool Security Guidance**: Rewrote `node-repl-host` `js` tool instructions to explicitly warn that it runs unsandboxed and bypasses `Bash` dangerous-command approvals, prohibiting its use for general shell execution, file I/O, package inspection, or routine data processing.
- **Protocol Capabilities & Built-in Model Catalog Updates**:
  - Expanded ZCode Protocol v1 host capability flags from 7 to 13, adding `highspeedCardOwner`, `pluginDiscoveryUi`, `worktreeCwd`, `extensionInputSource`, `conversationQuoteComment`, and `pluginExtensionSummary`.
  - Added runtime environment variables: `ZCODE_CREDENTIAL_SECRET_FILE`, `ZCODE_SUBAGENT_STALL_NOTIFY_MS`, `ZCODE_PLUGIN_SOURCES_CHANGED`, `ZCODE_PLUGIN_STARTUP_TIMEOUT`, `ZCODE_RUNTIME_MODEL_UNAVAILABLE`, and `ZCODE_CLIENT_LANGUAGE`.
  - Added OpenAI template model `gpt-6.1-terra` to `config/provider/zcode-builtin.json` (revision `43 → 44`; context window `1,050,000`, max output `128,000`, supporting image/PDF/JSON Schema output and `none/low/medium/high/xhigh/max` reasoning effort levels).

## UI Experience & Settings Improvements

- **Grouped Consecutive Tool Execution Summaries**: Automatically collapses consecutive tool calls under "Edit / Explore / Run / Reason" summary groups (`chat.summaryGroup.*`, 20 keys).
- **Selection Quote Comments & Annotated Image Attachments**: Supports attaching inline comments when quoting selected assistant text and drawing annotations on images before adding them to chat (`chat.selections.comment*`, 12 keys).
- **Reading & File Interaction Polish**: Added word-by-word fade-in for streaming responses, "Reveal in File Manager" on file cards and inline path links, and a unified "Add to Chat / Copy / Save As" menu in image previews.
- **Permissions & Settings Experience**: Tool approval dialogs now support switching permission modes directly and remembering "Full Access"; Settings adds settings search (`settings.search.title`), a master mobile push notification toggle (`settings.mobilePush` / `mobilePushEnabled`, on by default), project editing, and per-device memory toggles; usage statistics no longer auto-expire.
- **Granular Remote Workspace Status**: Added explicit status messaging when a remote host is upgrading its server (`source-server-update-in-progress` / `remote.error.sourceServerUpdateInProgress`).
- **App Updater & Code-Signing Chain Validation**: Supports background update downloads (persisting across window close) and manual install confirmation; added `pkijs@3.4.3` (`CertificateChainValidationEngine`) in the main process to validate update package code-signing certificate chains.

## Bug Fixes & Security Hardening

- **`android-emulator` Plugin (`0.1.0 → 0.1.1`) Path Hardening**: Added `externalPath()` verifying both literal paths and resolved `realpath` targets reside outside the workspace and carry executable permissions, removing workspace-hijackable `which` / `where` lookups and bare `cmd.exe` / `java` invocations.
- **`node-repl-host` Upgrade Cache Busting Fix**: Added `dist/build-identity.json` (recording pipeline `cuaHelperBuildId`) so bundled server scripts are properly re-extracted when the client upgrades without a plugin semver bump.
- **Workflow & Sandbox Security**: Fixed a vulnerability where workflow scripts could escape the sandbox.
- **Billing & Updater Fixes**: Added a confirmation step before redeeming quota resets (`codingPlan.quotaReset.*` expanded to 37 keys); improved updater support behind proxies, self-signed certificates, and signed-out states; fixed residual cleanup errors after failed Windows installations.
- **UI & Session Stability Fixes**:
  - Fixed broken session back/forward navigation, unclosed associated tabs after deleting or archiving tasks, and chat sync interruptions caused by malformed payloads.
  - Removed the persistent red dot from the tray icon so badges count only newly arrived unread messages.
  - Fixed date/time formatting ignoring UI locale, overlapping settings controls in narrow windows, wrong paths when opening files in default apps, dropped previews when attaching images, and keyboard input focus issues in the built-in browser.
  - Fixed intermittent login CAPTCHA load failures, sluggish or unapplied settings after model switches, duplicate model-deprecation banners, and malformed replies triggered by built-in tools on certain models; bot sessions now support rich text, larger attachments, and automatic reply resumption after service recovery.
