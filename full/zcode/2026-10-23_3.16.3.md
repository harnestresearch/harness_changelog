# ZCode Desktop 3.16.3

English | [简体中文](../../zh-CN/full/zcode/2026-10-23_3.16.3.md) · [Highlight](../../zcode/2026-10-23_3.16.3.md) | **Full Detail**

- **Release Date**: 2026-10-23
- **Platforms**: `mac`, `win`, `ubuntu`
- **Summary**: Isolates document viewing state per session while sharing a single process across document plugins, caps background plugin retention, adds copyable device ID and manual login URL fallback, and resolves 21 IME, terminal, remote session, and concurrent write issues.

## Official Release Notes (`zcode.z.ai/changelog`)

### New Features

- The help menu now includes a copy device ID option, making it easier to report issues.
- When the login link cannot be opened automatically, you can copy it and complete login manually.
- Document viewing state is now independent for each session, so multiple windows no longer interfere with each other.
- Document plugins now share a single process, reducing resource usage when multiple documents are open at the same time.
- Plugin background retention duration now has an upper limit, reducing wasted resources.

### Bug Fixes

- Subagents can now correctly view documents already opened in the current session.
- Built-in component files are automatically rebuilt when missing, instead of repeatedly reporting errors.
- Closing the last terminal tab now actually terminates the background process.
- Fixed input box lag when typing long text or using an IME.
- Uncommitted IME draft text is no longer lost when switching tasks.
- Residual blank tool call cards are no longer displayed in conversations.
- Interrupted conversations no longer show unread notifications.
- Improved remote connection failure messages, which no longer only report a timeout.
- Fixed several remote connection compatibility issues.
- Reduced message sending latency in remote sessions.
- When reading a remote directory fails, the local project list remains visible.
- Fixed issues with the mobile remote terminal.
- Fixed an issue where models could not be tested when only a remote project was open.
- The file tree is once again displayed on the left side of the preview area.
- The sidebar plugin list now shows installed plugins first.
- Fixed multiple UI issues in the plugin marketplace, making the back action clearer.
- Update note bubbles now support hovering, making it easier to view the full content.
- Local folders are now correctly recognized as projects when opened.
- Subdirectories are no longer lost when restoring sessions after a restart.
- Fixed an issue where data could become corrupted when multiple sessions write simultaneously.
- Fixed an issue where the official plugin cache could not be updated in container environments.
