# ZCode Desktop 3.18.1

- **Release Date**: 2026-11-11 (build `3.18.1.10376`, commit `9f7ab4c3`)
- **Platforms**: `mac`, `win`, `ubuntu`
- **Runtime**: Electron `44.7.0` / Chromium `152.0.7977.130`

## Overview

A patch release on top of `3.18.0` completing the macOS voice input microphone permission reset and multi-phase onboarding popover, adding a macOS desktop font smoothing toggle, introducing bounded CLI runtime memory diagnostic snapshots with log export archival, and refining sidebar/session column sizing and mobile history routing.

## New Features

- **Voice Input: macOS Microphone Permission Reset Flow**
  - Added main-process IPC channel `zcode:reset-microphone-access` (`ResetMicrophoneAccess`, exposed via preload `resetMicrophoneAccess()` and registered in CLI protocol command enums).
  - Validates the packaged app's Bundle ID before invoking `/usr/bin/tccutil reset Microphone <bundleId>` to reset macOS TCC microphone authorization, then transitions automatically based on current permission status: takes effect immediately when `granted`, triggers the system authorization prompt when `not-determined`, and returns `restart-required` otherwise—protected throughout by a single-flight concurrency guard.
- **Voice Input: Multi-Phase Permission Guide Popover**
  - Added a permission guide component on the chat composer voice button (`v4-composer-voice-permission-guide`, supporting `data-voice-permission-phase` phase transitions) offering "Reauthorize" (`reauthorize`), "Open System Privacy Settings" (`openPrivacySettings`), and "Relaunch ZCode" (`relaunch`) actions.
  - Added shared UI primitives `PopoverHeader` and `PopoverDescription`; added 8 `voiceInput.permission.*` i18n keys across Chinese, English, Japanese, Korean, and Russian, replacing the static `voiceInput.error.permissionDenied.{mac,windows}` error strings.
- **macOS Font Smoothing Toggle**
  - Added "Font Smoothing" in Settings (`settings.fontSmoothing`, macOS desktop only via `visibility: 'macDesktop'`, enabled by default), persisted under `zcode-macos-font-smoothing`. Toggles the root document's `font-smoothing-enabled` class for grayscale antialiasing and integrates with cross-window state broadcasts and settings search indexing.

## Improvements & Optimizations

- **Bounded CLI Memory Diagnostics & Feedback Log Archival**
  - Added `startCliMemoryDiagnostics` to the protocol resource sampler in the agent runtime (`glm/zcode.cjs`), writing `zcode-cli-memory-v1` snapshots to `~/.zcode/cli/memory-diagnostics/` every 15 seconds (retaining the latest 8 samples and up to 32 V8 `HeapProfiler` allocation stacks filtered strictly to frames inside the CLI bundle).
  - Enforces strict quotas and sanitization: max 2 files per instance, 15 globally, 64 KB per file, and 7-day expiration cleanup; automatically halts sampling with `budget-exceeded` if a single sample exceeds 25 ms or heap usage reaches 80% of the limit; applies allowlist sanitization on both write and desktop read paths (`sanitizeCliMemoryDiagnostic` / `sanitizeCliMemory`).
  - Expanded v4 protocol resource diagnostic fields from 4 to 8, adding `hydrations`, `historyOpenings`, `binaryCacheEntries`, and `binaryCacheBytes` counters.
  - Included `.zcode/cli/memory-diagnostics` (`contentPolicy: "cli-memory"`) in desktop "Export Logs" feedback archives.
- **Layout & Routing Polish**
  - Relaxed maximum sidebar width from `65%` to `100%`; changed minimum session column width from `35%` to a fixed `360px` floor so the chat bar can be dragged narrower without obscuring preview content.
  - Moved Elicitation source badges below titles and added `min-w-0` on message containers to prevent horizontal overflow on long content.
  - Enhanced two-way `replaceState` and `popstate` browser history synchronization on mobile/web views (`zcodeMobilePage`).

## Bug Fixes (Official Release Notes)

- Fixed mainland China users failing to sign in via the website.
- Fixed summary information refreshing repeatedly.
- Prevented clicking to select web page elements in the built-in browser from switching to full view or obstructing page content with a popup panel.
- Fixed unintentional dragging on the project search menu and incomplete/jumbled subagent source descriptions.
- Fixed leftover old processes during updates causing update failures that required restarting the computer, and allowed installation to proceed with clearer error messages even when update backup fails.
