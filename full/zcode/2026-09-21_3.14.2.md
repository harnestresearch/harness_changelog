## Overview

`3.14.2` delivers a focused Dynamic Workflows upgrade (`glm/zcode.cjs` `+23,908` B, `app.asar` `+15,496` B, `bundled-skills` `+4 / −4` file relocation). Although neither `zcode.z.ai/changelog` nor GitHub Releases published a standalone `3.14.2` entry—instead announcing these workflow capabilities ~11 hours later under [3.14.3](2026-09-22_3.14.3.md)—three-way binary diffing (`3.14.1 → 3.14.2 → 3.14.3`) proves that `glm/zcode.cjs` and all i18n/UI workflow additions landed completely in `3.14.2` (`3.14.3` is a pure rebuild with an identical `zcode.cjs` SHA-256).

## Dynamic Workflow Features & Runtime Changes (`3.14.1` → `3.14.2`)

- **In-Place Concurrency Retuning (`AmendWorkflow` + `createWorkflowRunSeatGate`)**
  - `glm/zcode.cjs` adds `resolveConcurrencyRetuneRoute` and `runConcurrencyRetune`: when `AmendWorkflow` receives a concurrency-only payload (`isConcurrencyOnlyAmend`: `max_concurrency` set while `script`/`path`/`subagent_model`/`name` are `undefined`) against a `pending`/`running` predecessor run, it mutates the active run via `setMaxConcurrency` instead of stopping and restarting (`resolveRetuneFallbackAmend` handles settled/non-retunable fallback).
  - `setMaxConcurrency` persists updated caps to the `dwf_event` journal (`updateRunCaps`), emits `{ type: "run-caps-changed", runId, caps, previous }` (with `concurrencyCeiling`), and calls `scheduler.pumpAll()` immediately when raised; `createWorkflowRunSeatGate` (`bindSeatGate`, `{ limit, working, parked }`) parks excess subagents cleanly before their next model turn when lowered.
  - Renderer (`styles` chunk `+6,105` B, `IntlProvider` `+941` B) adds `data-workflow-retune-run-id` live concurrency controls plus `chat.toolCall.workflow.run.settings.consequence.concurrencyLive` and `chat.toolCall.workflow.run.event.runCapsChanged`.
- **Workflow Tool Context Diet & `428` Skill Gate (`requireDynamicWorkflowSkill`)**
  - `CreateWorkflow` (except saved-only launches), `AmendWorkflow` (when carrying `script`/`path`), `SaveWorkflow`, and `EvalWorkflowSnippet` now enforce `requireDynamicWorkflowSkill` (`errorCode: 428`), rejecting script submissions until `Skill("dynamic-workflows")` has been loaded in the session; `recordAuthoredWorkflowDraft` registers compiled drafts in `readFileState` for subsequent file-based edits.
  - `dynamic-workflows/SKILL.md` expands `63,088 → 92,387` B (`+29,299` B, adding `§16 Tool reference` with the full compiler facade and tool schemas) and `examples.md` expands `29,439 → 35,528` B (`5` complete examples), keeping always-injected tool descriptions terse.
- **Relocation to Non-Uninstallable `bundled-skills` & Synthesized `/workflow` Command**
  - Relocated `skills/dynamic-workflows/{SKILL.md,examples.md,patterns.md}` out of `zcode-guide-plugin` (`0.2.0 → 0.3.0`, removing `"commands"` from `.zcode-plugin/plugin.json`) into `opt/ZCode/resources/glm/packages/bundled-skills/` (with `bundled-skills/README.md`).
  - Added `materializeSeaBundledSkillPack` (content-hashed `.zcode-bundled-skills-seed.json` materialization, `findMissingBundledSkillPackPaths` integrity check, and discovery priority `1,000,000` so user/project/plugin overrides still win) plus runtime `/workflow` synthesis (`expandBuiltinWorkflowCommandPrompt`, `path: "builtin:workflow"`).
- **Bounded Real-Time Status & Wire Updates for Large Workflows**
  - Added `clampWorkflowRunsForLegacy` (`clampKeepingLive` prioritizing active actors), `workflowRunTablesForNewLife` (eviction groups with `nodesUnlisted` / `nodesUnlistedSettled` counters), and `workflowRunUpdateWithinWireBounds` / `mergeWorkflowRunUpdates`.
  - Renderer adds `workflow-run-truncated` and `workflow-roll-unlisted` UI components (`chat.toolCall.workflow.timeline.roster.unlisted.{one,many}` and `chat.toolCall.workflow.run.truncated`, bringing `chat.*` i18n keys `1,343 → 1,348`) plus subscription guard `fault.subscription.contentRejected`.
