# ZCode Desktop 3.10.1

English | [简体中文](../../zh-CN/full/zcode/2026-08-28_3.10.1.md) · [Highlight](../../zcode/2026-08-28_3.10.1.md) | **Full Detail**

- **Release Date**: 2026-08-28
- **Platforms**: `mac`, `win`, `ubuntu`
- **Summary**: Initial `3.10` feature release introducing searchable default-expanded thinking traces, configurable MCP server protocol versions, immediate sending for edited messages, end-of-turn execution summaries and durations, composer skills shortcuts, one-click prompt-template plugin installation, Weekend Plan early claiming, and 20 bug fixes.

## Official Release Notes (`zcode.z.ai/changelog`)

### New Features

- Added free early claiming of Weekend Plan — invite friends to claim it together
- Plugins referenced in prompt templates now support one-click installation, with clearer progress indicators
- Added a skills shortcut to the input box menu
- Thinking traces now support content search, with more complete records and expanded by default
- MCP servers now support configuring the protocol version, with guidance prompts when negotiation fails
- Edited messages can now be sent immediately without waiting in the queue
- View an execution summary and duration when a conversation turn ends
- The "Browser" menu in Settings has been renamed to "Browser Control"

### Bug Fixes

- Improved the login authorization flow and fixed occasional callback failures
- Fixed an intermittent mcp oauth failure
- Model responses that occasionally cut off or come back blank now retry automatically
- Fixed an issue where queued messages were lost after an error and interrupted task statuses were displayed incorrectly
- Unified tool execution status wording; thinking process labels are now more concise and clearer
- Fixed issues where task action hints were clipped and task information was jumbled on touchscreens
- Unread markers are now cleared immediately after opening the task timeline
- Raised the threshold for converting pasted long text into attachments, reducing unintended conversions
- Fixed an issue where a single tilde was incorrectly displayed as strikethrough
- The input box no longer loses focus when switching sidebars
- Input box references and command menus are displayed more clearly, and search no longer retries repeatedly
- Fixed an issue where multiple skill directories in a workspace could not be listed at the same time
- Fixed issues where some plugin skills were not recognized and their names displayed inconsistently
- Usage statistics now show the last seven days by default, with clearer charts and value labels
- Fixed an issue where background processes remained after exiting on Windows
- Fixed several issues with Computer Use on macOS and in remote workspaces
- Improved browser control session stability; page script execution now behaves as expected
- Fixed an issue where the remote interface menu overflowed the screen on mobile
- Fixed an issue where model status displayed incorrectly after a plan expired
- Fixed an error when modifying model configuration while a task is running
