## Overview

`3.16.1` is a major application-layer feature release (`i18n` keys `+730 / −110`, `.deb` `+8.89` MB, `glm` packages `+325` files). Official CDN `electron-updater` metadata (`3.16.1/linux-x64/latest.yml`, SHA-512 verified) carries the first-hand bilingual `Release v3.16.1` notes (`14` new features + `18` bug fixes)—which `zcode.z.ai/changelog` later reposted verbatim under `v3.16.2` without giving `3.16.1` its own webpage entry. Three-way binary diffing (`3.15.3 → 3.16.1 → 3.16.2`) proves that the entire feature and UI payload shipped in `3.16.1`.

## New Features & Architecture Changes

- **Unified Remote Devices (`source-server` Replacing `bot-remote-workspace`)**
  - Replaced legacy `bot-remote-workspace` IPC (`84 → 0` occurrences) with `source-server` / `SourceServer` (`0 → 262` in `app.asar`, `out/host/index.js` `+385,526` B), unifying SSH servers, WSL distros, and Docker containers under `settings.source.*` (`161` new keys) and `remote.error.*` (`85` new keys) with persistent remote sessions, `~/.ssh/config` import, 7-day `startupAutoReconnect`, duplex HTTP/WebSocket transport (`connectWebSocketOverDuplex`), SSH credential storage, and local SQLite `remote_project_entries` / `hosts` tables.
  - Added workspace data migration into `out/scheduler/index.js` (`+69,575` B) with `6` new SQLite tables (`workspace_migration_schema_version`, `workspace_migration_ledger_v`, `workspace_migration_conflicts_v`, `workspace_alias`, `controller_remote_identity_migrations`, plus `task_group_admissions`, retiring `tasks_schema_migration`) and phased backup/merge/conflict states (`ZCODE_MIGRATION_BACKUP_SKIPPED`).
- **On-Demand Tool Search (`ToolSearch` & `DeferredToolCall`)**
  - Added `settings.toolSearch*` (`auto` / `local` / `off`, desktop default `"off"`) and CLI `--toolsearch-mode <auto|native|local|off>` (`glm/zcode.cjs`, `resolveToolSearchCapability`, `DeferredToolCall` `0 → 17`, `"tool.search"`, and a second Anthropic `advanced-tool-use-2025-11-20` beta header call site).
- **Document Plugin Viewer Surfaces & MCP Servers (`+325` Files / `+33.1` MB)**
  - Upgraded `documents` (`0.1.8 → 0.2.0`), `pdf` (`0.1.8 → 0.2.1`, `+298` files shipping PDF.js cmaps, `97` Noto Sans SC `woff2` fonts, standard fonts, and WASM), `presentations` (`0.1.8 → 0.2.0`), and `spreadsheets` (`0.1.8 → 0.2.0`) from skill-only packs to full MCP servers (`dist/server.mjs`) + session-scoped sidebar UI surfaces (`ui://*/panel.html`) + `*-viewer` skills, paired with renderer chunk `pptxElementReference-BBtAnwAP.js` (`250,339` B) and `@modelcontextprotocol/ext-apps@2.0.0`.
- **Multi-Folder Local Projects, Side-Pane File Manager & Direct Composer Switchers**
  - Added multi-folder projects (`project.*` `85` new keys, `additionalDirectories` `0 → 163`, primary root selection, and folder trust prompts), side-pane File Manager (`fileManager.*` `5` keys), side-pane **Full View** & Launcher (`sidePane.fullView.*` `11` keys, `toggleSidePaneFullView`), and combined composer model/effort/provider controls (`chat.toolbar.combined.*` + `executionSelection` / `captureHighspeedFallbackSelection`).
- **Popover Sharing, Project-Grouped Archives, Task Groups, Plugin Store & Mobile Remote**
  - Refactored conversation sharing into a popover with range selection, read-only replay badges, and workflow/image artifact previews (`conversationShare.*` `+50 / −14` keys); moved archived sessions into a project-grouped panel (`archives.*` `29` keys); added `taskGroup.*` (`17` keys) and `OffPeakTicketAuthority` runtime lifecycle handlers; added `settings.plugins.store.*` (`12` keys), `preview.image.*` (`6` keys), `settings.machine.*` scope labels, Windows taskbar/tray unread notifications, and mobile remote account login / device management (`webRemoteControl.*` `+6 / −22` keys).
- **Provider Catalog Revision `31 → 33` (MiMo Token Plan & `1M` Default Rule)**
  - Renamed `xiaomi-mimo` to **Xiaomi MiMo API** (adding `mimo-v2.6-pro` / `mimo-v2.6-flash`), added template `xiaomi-mimo-token-plan` (`https://token-plan-cn.xiaomimimo.com/anthropic`), and raised default catch-all `modelRules[0]` limits from `200,000 → 1,000,000` context window and `32,000 → 128,000` max output tokens.

## Bug Fixes (Official `Release v3.16.1` `latest.yml` Notes)

- Fixed network interruptions being misreported as unmet remote environment requirements; fixed sensitive data exposure in connection logs; fixed a Windows security vulnerability allowing out-of-bounds local file reads.
- Fixed lost input and stuck conversations when model creation failed, unresponsive chats after hitting context limits, overwritten composer text when switching models, missing fallback or lost input when accelerated models were unavailable, and lost drafts when switching projects or creating tasks.
- Fixed misplaced or falsely failed attachments when restoring history sessions, excluded `additionalDirectories` in conversation context, errors/blocked task creation when a project directory was missing, reappearing closed workspace tabs after restart, and inaccurate unread/badge counts for background tasks.
- Fixed display/interaction glitches in the model menu and thinking slider, off-screen Run buttons on workflows with many parameters, occasional database lock lag after upgrades, failed calls when an MCP app was not ready, and missing initial terminal output on startup.
