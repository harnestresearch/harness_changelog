## Binary-Verified Incremental Changes (`3.16.1` → `3.16.2`)

- **Remote Linux `glibc >= 2.28` Environment Gate (`assertSupportedGlibc`)**
  - Host process (`out/host/index.js`, `+601` B) adds `assertSupportedGlibc` inside the `SourceServer` environment probe: parses `LIBC` (`/^glibc\s+(\d+)\.(\d+)/iu`) on Linux targets and throws `SourceServerProbeEnvironmentError` (`"Remote glibc X.Y is older than glibc 2.28 required by ZCode Source Server. Use a Linux system with glibc 2.28 or later, such as RHEL 8+, Ubuntu 20.04+ or Debian 10+."`) when `glibc < 2.28`.
- **Antialiased Taskbar & Multi-DPI Tray Badge Compositing**
  - Main process (`out/main/index.js` `+21` B and rebuilt main chunks) replaces `renderTaskbarBadgePixels` with supersampled `renderAntialiasedStatusDotPixels`, Windows 10 (`11.25`) vs Windows 11 (`8`) coordinate-aware `renderTaskbarStatusDotPixels` (`applyTaskbarOverlayToWindows`), and `1x` (`16×16`) + `2x` (`32×32`) `composeTrayBadgeRepresentation` / `composeTrayBadgeImage` with bitmap length sanity checks (`[desktop-tray] unexpected tray bitmap size`).
- **Plugin Install Write Lock & Dynamic Workflow Runtime Fixes**
  - `glm/zcode.cjs` (`+1,005` B) wraps workspace plugin marketplace installation in `withWriteLock`, replaces `isDynamicWorkflowOffered` with `readDynamicWorkflowOfferedMode` (`disabled` / `onDemand` / `alwaysOn` across `ZCODE_DYNAMIC_WORKFLOW_MODE` and remote offer configs), and adds `isWorkflowStopFailure` in `createWorkflowConcurrencyGovernor`.
