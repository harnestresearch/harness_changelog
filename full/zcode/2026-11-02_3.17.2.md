## Overview

`3.17.2` is a compact security, permission, and diagnostics patch on top of [3.17.1](2026-10-29_3.17.1.md). On Linux `x86_64`, only `5` of `2,678` package files changed (`0` added, `0` removed; `app.asar` `+26,104` B, `glm/zcode.cjs` `+1,880` B), with zero Electron runtime or dependency churn. Because `zcode.z.ai/changelog` omitted a standalone `3.17.1` entry, the webpage published cumulative `3.17.1 + 3.17.2` release notes under `3.17.2`; all features that shipped in `3.17.1` are documented in [3.17.1](2026-10-29_3.17.1.md), and only net-new `3.17.1 → 3.17.2` changes are recorded below.

## Binary-Verified Incremental Changes (`3.17.1` → `3.17.2`)

- **MCP Startup Failure Advice UI (`settings.mcp.failureAdvice.*`)**
  - Renderer localization (`IntlProvider`) adds `21` net-new keys (`7,268 → 7,289`, `0` removed): `settings.mcp.failure.{adviceTitle,errorDetails}` plus `19` diagnostic codes (`coding_plan_required`, `config_invalid`, `connection_failed`, `connection_timeout`, `network_unreachable`, `not_authenticated`, `oauth_authorization_failed`, `official_origin_untrusted`, `process_start_failed`, `protocol_error`, `protocol_negotiation_failed`, `rate_limited`, `runtime_unavailable`, `server_internal_error`, `server_not_found`, `server_unavailable`, `status_unavailable`, `tool_list_failed`, `unexpected_disconnect`).
- **Built-in Browser Local Preview URL Allowlisting (`zcode:browser-view-load-url`)**
  - Main process (`out/main/index.js`, `+3,764` B) adds `BrowserViewLoadUrl` handler and `createBrowserLocalPreview`, enforcing an explicit `about:` / `data:` / `file:` / `http:` / `https:` URL scheme allowlist and rejecting invalid targets with `"Invalid browser navigation"` / `"Unsupported browser URL"`; wired across `5` preload bundles (`index`, `codingPlanWebview`, `cuaPermissionPanel`, `embeddedBrowserJavaScriptDialog`, `resourceManager`).
- **Custom Command Dynamic Shell Handoff, Plugin Env Fix & Subtask Plan-Mode Enforcement**
  - `glm/zcode.cjs` (`+1,880` B) replaces direct prompt-time shell execution (`expandCustomCommandShellSyntax` / `runShellExpansion` / `normalizeFencedShellCommand`) with `handOffCustomCommandShellBlocks`, `createBashSessionEnv`, `resolveShellTextVariable`, and `ZCODE_PLUGIN_NAME`—routing dynamic `` !`…` `` and `!` fenced shell blocks in custom commands through the `Bash` tool's permission approval flow (and fixing Windows plugin command path resolution); `zcode-guide-plugin/skills/diagnosing-commands/SKILL.md` (`+314` B) updates Trap 8 accordingly.
  - Added `buildRuntimeModeReminderBodyForTask` and `buildSubagentPlanModeReminder` so subtasks inherit and enforce Plan-mode restrictions consistently with the root session.
- **Session Activation Workspace Validation, Staged Resource Release & Host Fork/Routing Guards**
  - `glm/zcode.cjs` adds `validateSessionActivationWorkspace`, `validateActivation`, and `resolveLegacyRemoteSessionWorkspace` alongside staged session teardown (`close_admission`, `cancel_execution`, `goal_pause`, `execution_finalization`, `mcp_ui_release`, `projection_release`, `runtime_close`, `closeNamedResources`, `getPendingSessionPersistence`, and telemetry `session.resource_close.slow` / `zcode_protocol.session.release_stage_failed`), preventing cross-session ownership mix-ups on session switch/restore.
  - Host process (`out/host/index.js`, `+952` B) adds `prepareForkCreation` (fork-assistant callback) and `workspace-routing` stage validation (`-32602`) for official MCP identity header requests.

## Additional Non-Duplicate Items from Official `3.17.2` Release Notes

The following platform/UI items from `zcode.z.ai/changelog` (`3.17.2`) were not statically localized to `3.17.1`'s Linux `.deb` feature set (including macOS/Windows platform-specific fixes):

- Computer Use adds multi-session cursors; added a draft MCP configuration interface.
- Corrupted configuration files are no longer overwritten to prevent data loss; user-level data migration works even when no project is open; new tasks can be created normally after deleting a project.
- Replies blocked by safety policies fail fast without repeated retries; unproductive repeated executions terminate automatically with a notice; browser attachment links are no longer downloaded repeatedly; WeChat automation result push notifications and occasional unrefreshed artifact cards fixed.
- Platform fixes: restored missing Chinese/English locale resources in macOS installers and fixed blank app icons on macOS; fixed Windows 64-bit installers bundling incompatible components, Windows occluded window display recovery, and opening certain files in default Windows apps; removed the unread red dot from the tray icon (unread status remains on the taskbar) and reduced installer size.
