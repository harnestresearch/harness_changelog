# Grok Bot 0.29.0

English | [简体中文](../../zh-CN/full/grok-bot/2026-08-27_0.29.0.md) · [Highlight](../../grok-bot/2026-08-27_0.29.0.md) | **Full Detail**

- **Release Date**: 2026-08-27
- **Platforms**: `mac`, `win`
- **Summary**: Marketplace (bot store) listing system lands: listing CRUD, review status workflow, and image uploads

## Highlights

- **Features**: Marketplace listing management (`CreateGrokBotMarketplaceListingInternal`, Get/List/Update, `SetGrokBotMarketplaceListingStatusInternal`, `PresignGrokBotMarketplaceImageUploadInternal`); listing state machine (PENDING_REVIEW / DELISTED, delisting timing AFTER_7_DAYS/IMMEDIATELY); default marketplace avatars and image kinds (MarketplaceDefaultAvatar/ImageKind); template ownership type `GrokBotTemplateOwnerType`; Slack app reinstall (`ReinstallGrokBotSlackApp`); onboarding completion reporting (`SandOnboardingCompletionSource`).
- **Protocol / Main Process**: First-party default model allowlist (ModelAllowlist.FirstPartyModelDefault).
- **UI**: computer-pane (computer control panel component).
- **Infrastructure**: No dependency changes.

## Code & Protocol Details

- `main.cjs`: Full suite of Marketplace listing RPCs: `CreateGrokBotMarketplaceListingInternal`, Get/List/Update, `SetGrokBotMarketplaceListingStatusInternal`, and `PresignGrokBotMarketplaceImageUploadInternal` (presigned image upload URLs); listing state machine enum `PENDING_REVIEW/LISTED/DELISTED` and delisting timing `IMMEDIATELY`/`AFTER_7_DAYS`.
- `main.cjs`: Added `ReinstallGrokBotSlackApp` (outcome branches `UPDATED`/`UP_TO_DATE`).
- `main.cjs`: Error catalog adds `SAND-E0417` `botBlock`: "Turn landed on a bot-detection or auth-challenge wall (google.com/sorry, Cloudflare challenge, Akamai, ...); classified from the page URL + title" — bot-blocking detection classification.
- `main.cjs`: Added `GrokBotTeamWireError` and OWNER/TEAM enum mappings; completed Slack connect response fields `oauth_authorize_url`/`workspaces`/`slack_error`/`retry_after_seconds`.
- `main.cjs`: Added `GrokBotTemplateOwnerType` (USER/TEAM) and `listGrokBotTeamAgents`/`setGrokBotAgentVisibility` IPC handlers.
