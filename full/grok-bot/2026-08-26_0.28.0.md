# Grok Bot 0.28.0

English | [简体中文](../../zh-CN/full/grok-bot/2026-08-26_0.28.0.md) · [Highlight](../../grok-bot/2026-08-26_0.28.0.md) | **Full Detail**

- **Release Date**: 2026-08-26
- **Platforms**: `mac`, `win`
- **Summary**: End-to-end Slack app install/uninstall flow + Jira integration + privacy mode — messaging connectors mature into a cohesive system

## Highlights

- **Features**: Slack App lifecycle management (`InstallGrokBotSlackApp`/`UninstallGrokBotSlackApp`/`StartGrokBotSlackConnect`/`GetGrokBotSlackInstallState`, GrokBotSlackWorkspace, bot-token, slack-draft, and email-draft draft channels); Jira integration (`JiraInstallation`, `ListJiraInstallations`); privacy mode (privacy-mode / `aiserver.v1.PrivacyMode`); Agent visibility (`SetGrokBotAgentVisibility`); Origin agent approval (`ResolveOriginAgentApproval`).
- **Protocol / Main Process**: Client online presence reporting `ReportGrokBotClientPresence`; local tool permission reporting `UpdateSandMachineLocalToolPermission`; ClientOS enum (including WINDOWS/LINUX/IOS); deep-link route validation (scheme/route path allowlist, maxUrlLength); new keys agent-probe, seen-probe, local-cli-mode, and waiting-for-browser; status constants SLACK_REJECTED/WORKSPACE_REQUIRED/INSUFFICIENT_SCOPES/RATELIMITED, etc.
- **UI**: Linear panel, emoji translation assets (emoji-messages.tr), and messages/brand-logos updates.
- **Infrastructure**: Added `sand.build` and `sand.render_trace.summary` identifiers.

## Code & Protocol Details

- `main.cjs`: Full suite of new Slack App lifecycle RPCs: `InstallGrokBotSlackApp`, `UninstallGrokBotSlackApp`, `StartGrokBotSlackConnect`, and `GetGrokBotSlackInstallState`, plus `GrokBotSlackWireError` and install state strings `install_conflict`/`insufficient_scopes`/`logged_out`.
- `main.cjs`: Added `SetGrokBotAgentVisibility`, `ReportGrokBotClientPresence`, `UpdateSandMachineLocalToolPermission`, and `ResolveOriginAgentApproval`.
- `main.cjs`: Expanded Jira integration (`JiraInstallation` 6→14 occurrences, formalizing `ListJiraInstallations`, etc.).
- `main.cjs`: Added `SubagentModelOverride` (sub-agent model override) and `CookieOriginGrantStore` (cookie origin grant store).
- `main.cjs`: Updated zod validator error message table ("Array must contain…" / "String must contain…") from a dependency version bump.
