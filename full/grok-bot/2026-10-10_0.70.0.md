# Grok Bot 0.70.0

English | [简体中文](../../zh-CN/full/grok-bot/2026-10-10_0.70.0.md) · [Highlight](../../grok-bot/2026-10-10_0.70.0.md) | **Full Detail**

- **Release Date**: 2026-10-10
- **Platforms**: `mac`, `win`
- **Summary**: Bot outbound email governance (suppression list, limits, and sending state admin APIs) + team service accounts UI + per-tool MCP permissions and conversation rollback

## Highlights

- **Features**: Email sending governance: `AdminAddGrokBotEmailSuppression` (`user_id` / `address` / `reason` / `operator_email`), `AdminList` / `RemoveGrokBotEmailSuppressions`, `AdminGetGrokBotEmailLimits`, `AdminGetGrokBotEmailSendingState` (suppression list, quotas, and sending state -- confirming bots can send outbound emails on behalf of users). Team service accounts: `team-bot-service-accounts` UI family (`tiles` / `dialog` / `shown`), feature flags `grok_bot_service_accounts` and `service_account_spend_limit_enforcement` (enforcing service account spend limits). Per-tool MCP permissions: `Get` / `SetGrokBotMcpToolPermissions` (configuring tool permissions per server). Conversation management: `RollBackGrokBotConversation` and `StartFreshGrokBotConversation` (rolling back / restarting conversations).
- **Protocol / Main Process**: New connector domains `assistant.knowify.com`, `mcp.dealroom.co`, `mcp.northbeam.io`, `services.leadconnectorhq.com` (GoHighLevel), `www.local-mcp.com`; telemetry `mcp_tool.attempt` (splitting failures across payload, HTTP, and other categories), `sand.attachment.commit`; multipart upload state keys `store-preupload`, `store-fallback`, `store-full`, `store-unavailable`, `missing-put`, `missing-part`, `missing-alias`, `length-mismatch`, `no-uploader`, `unsent-commit`, `adopt-sync`; Linux desktop automation constants `NATIVE_X11`, `XDOTOOL`, `notify-send` (extending the `computer` tool to Linux); foreground/background and focus states `APP_BACKGROUND`, `APP_FOREGROUND`, `CHAT_OPEN`, `COMPOSER_FOCUS`, `COMPUTER_OPEN`, `FILE_OPEN`, `UPLOAD_START`, `PRETHAW`, `IN_FLIGHT`; request header `x-cursor-timezone`; setting keys `cursor-canvas-find`, `grok-bot-document`, `meeting-chat-draft`, `notify-send`, `session-expired`, `invalid-agent-id`, `unknown-mode`, `unfetchable-url`, `sand-dark`, `sand-light`.
- **UI**: `auto-review-rule-notice`, `sand-auto-review-instructions` (auto-review rule notices/instructions), `provider-local-tool-permission` (tool provider permissions), `markdown-table-card`, `grok-bot-team-custom-mcp`, `team-bot-setup-dialog-shell`, `draft-composer-bubble`, `list-item`.
- **Infrastructure**: Dependencies 93 -> 94 (+`@anysphere/file-kind-icons`, file kind icons).

## Code & Protocol Details

- `main-app.cjs`: Reusable staged attachment commits: maps `stagedPath` to `{agentId, sessionId, controller, committed, release}`, routing duplicate commit hits through `route:"reused", outcome:"store"`; throws `new It({code: i8, detail:"the agent's attachment storage is full"})` when storage is full, and degrades Box route failures to `store-unavailable`.
- `main-app.cjs`: Per-tool MCP permissions RPC: `setGrokBotMcpToolPermissions({serverId, tools: fromEntries(...map(xne)), reads, ...})`, supporting `keepDisabledTools:!0` (preserving previously disabled tools).
- `main-app.cjs`: Conversation management RPCs: `startFreshConversation: k().args({id: rpcString(), sessionId: rpcOptional(rpcString())})` and `rollBackConversation` (restarting/rolling back conversations, optionally targeting a `sessionId`).
- `main-app.cjs`: MCP read-only tool evaluation: `Rlt(e){ let t=e.lookupVerb?.(e.serverHost, e.toolName); if(t!==void 0) return t==="read"; ... return e.declaresReadOnly && ewn.has(n) }` (prioritizing verb mapping, otherwise requiring both a read-only declaration and an allowlisted host).
- `main-app.cjs`: Canvas artifact resolution `artifactType==="canvas" ? ["artifactType","canvasId"] : ["artifactType","storeId","documentId"]`; Box agent media paths routed through a dedicated gateway branch (`isBoxAgentMediaPath`).
- `proto.cjs`: `SetGrokBotMcpToolPermissionsRequest{serverId, disabledTools:[]}`, canvas message `{storeId, canvasId, slug}`, and new enum `SlackConnectSite{UNSPECIFIED, CURSOR, GROK}` (splitting Slack connection site attribution).
