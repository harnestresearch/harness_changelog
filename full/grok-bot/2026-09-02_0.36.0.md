# Grok Bot 0.36.0

English | [简体中文](../../zh-CN/full/grok-bot/2026-09-02_0.36.0.md) · [Highlight](../../grok-bot/2026-09-02_0.36.0.md) | **Full Detail**

- **Release Date**: 2026-09-02
- **Platforms**: `mac`, `win`, `ubuntu`
- **Summary**: Multi-agent rooms (group chat), Agent automation listing, and preset functional role categories (customer support / finance / recruiting)

## Highlights

- **Features**: Rooms / group chat (`CreateGrokBotRoom`, `SetGrokBotRoomMembers`); Agent automations (`GrokBotAgentAutomation`, ListGrokBotAgentAutomations, GrokBotAgentKind); preset functional role categories customer-support, ops-finance, and recruiting-people; private inference configuration (`PrivateInferenceModel`/`PrivateInferenceSettings`/`PrivateInferenceReasoning`); call interruption handling (caller-interrupted); voice selection dialog (voice-picker-dialog).
- **Protocol / Main Process**: `PrivateWorkerPoolRequestCounts` (private worker pool request counts); "Sand machine roster unread" (roster unread reporting).
- **UI**: voice-picker-dialog and new agents/view/layout panels; removed provider-cloud-agents component (merged into main UI).
- **Infrastructure**: No dependency changes; local browser cookie enumeration consent copy ("The user did not allow listing which local browser cookies are available.") and disk usage audit description ("Audits disk usage on Grok Bot") appear.

## Code & Protocol Details

- `main-app.cjs`: Added machine-binding guard to local tool permission writes — after `updateMachineLocalToolPermission` RPC returns, local settings updates now check `if(r===await e.getMachineId()&&e.settingsStore.setLocalToolPermission(s))` (replacing the unconditional write in 0.35.0 to prevent overwriting local permissions with another machine's state on multi-device accounts); exposed new IPC handlers `getLocalToolPermissionGeneration` and `setLocalToolPermission`.
- `proto.cjs`: Multi-agent room protocol: `CreateGrokBotRoomRequest` adds `kind` enum (`GrokBotAgentKind`: AGENT/ROOM) and `member_agent_ids` (repeated), plus `SetGrokBotRoomMembers`.
- `proto.cjs`: Private inference configuration: `PrivateInferenceModel` (models/default_model_id/can_enable) and `PrivateInferenceSettings`, attaching `private_inference` fields (no:68/no:70) to two configuration messages.
- `proto.cjs`: Agent automations: `GrokBotAgentAutomation` and `ListGrokBotAgentAutomations`; hooks expanded with `team_owned_hook_steps` (team-level hooks) and `configured_variable_keys`.
- `main-app.cjs`/`proto.cjs`: Preset functional role categories `customer-support`/`ops-finance`/`recruiting-people`; new experiment keys `grok_bot_stable_prompt_prefix`, `sand_less_subagent_fanout`, and `grok_bot_server_automations`.
- Pure removal: Removed experiment gates `sand_computer_use_playwright` and `nudge_main_agent`.
