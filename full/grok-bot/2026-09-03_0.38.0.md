# Grok Bot 0.38.0

English | [简体中文](../../zh-CN/full/grok-bot/2026-09-03_0.38.0.md) · [Highlight](../../grok-bot/2026-09-03_0.38.0.md) | **Full Detail**

- **Release Date**: 2026-09-03
- **Platforms**: `mac`, `win`
- **Summary**: Introduces persistent per-agent memory shard (Memory Shard/Folder) protocols

## Highlights

- **Features**: Per-agent memory storage — `GrokBotMemoryShard` (agent_id/harness/version) organized under `GrokBotMemoryFolder`, laying the groundwork for upcoming AgentDefinition memory fields.
- **Protocol / Main Process**: `aiserver.v1.ListGrokBotMemoryShards` / `PutGrokBotMemoryShard`.
- **UI**: No significant changes (chunk reshuffle only).
- **Infrastructure**: Minor edits across 4 main-process files; added `run-failed` status string.

## Code & Protocol Details

- `main-app.cjs`: Refactored auth profile fetching — replaced one-shot `settleProfileInBackground` (2→0 occurrences) with retry-backed `profileRetry = createRetryPolicy({ name:"cursor-auth-profile-fetch", maxAttempts:5, initialDelayMs:2e3, maxDelayMs:16e3 })`; removed zod validation schema on `SandVoiceCallCredentials` (`m.object({clientSecret, expiresAtUnixSeconds, model, websocketUrl}).readonly()`, keeping the class itself: `DEFAULT_MODEL:"grok-voice-latest"`, `DIALABLE_ORIGIN:"wss://api.x.ai/"`); settings store adds `hasMigratedFromLocalStorage()` (0→2 occurrences).
- `proto.cjs`: Added `GrokBotMemoryFolder` message — memory shard folder protocol paired with `GrokBotMemoryShard` for per-agent archiving.
- `renderer/prompt-editor`: Large-scale rebuild of the rich-text editor chunk (1814 substantive edits, 2956 relocated symbols, including reorganization of a ~14k-token TipTap shortcut/list input-rule block and a new embedded `sand-*` CSS module class mapping table); remaining renderer chunks are import hash rotations (`index-C4A09xYf`→`BmC1R63Z`, etc.).
