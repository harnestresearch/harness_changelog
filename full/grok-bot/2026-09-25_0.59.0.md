# Grok Bot 0.59.0

English | [简体中文](../../zh-CN/full/grok-bot/2026-09-25_0.59.0.md) · [Highlight](../../grok-bot/2026-09-25_0.59.0.md) | **Full Detail**

- **Release Date**: 2026-09-25
- **Platforms**: `mac`
- **Summary**: Major release: meeting agent (`meetings-main.cjs` for Google Meet / Zoom joining, transcription, and STT) and xAI prepaid commerce module launched

## Highlights

- **Features**: Dedicated main-process module `MeetingsService`: recognizes `meet.google.com` (meeting code `xxx-xxxx-xxx`) and `zoom.us/j/<9-12 digits>` links, joins meetings for real-time transcription (`stt.open` / `close` / `segment` / `error`, `pcm.first`, `join.start` / `ack` / `typed`), generates summaries (`summary.due`, `meeting-report`), and presents them in a standalone `meeting-window` (`sand.desktop.meetings`, `sand.transcript.*` renderer telemetry); new dependency `@anysphere/xai-commerce-prepaid` corresponding to `xai-commerce-bearer` credentials and `PRODUCT_CREATE` (xAI commerce/prepaid).
- **Protocol / Main Process**: New API host `https://api2.cursor.sh`; connector OAuth callbacks `https://x.com/i/connectors/oauth_callback` (X integration) and `mcp.hubspot.com`; `onepassword-oauth` (1Password OAuth flow); cloud sandbox offline/parking state machine `client-pause`, `away-park`, `network-return`, `SAND_AWAY_PARK`; 53 new keys including `usage-breakdown`, `create-team-bot`, `google-meet`, `in-call`, `unread-divider`, `send-task`, `agent-exchange`, `cloud-agent-infos`, `mcp-servers-updated`, `package-download`, `linux-x64` / `linux-arm64` / `win32-x64` / `win32-arm64` (per-platform distribution), etc.; `EnsureGrokBotDefaultMainAgentResponse.Outcome`.
- **UI**: `team-bot-learned-context` (learned context), `team-setup-new-skill-dialog` (new skill dialog), `team-bot-details-pane/rows`, `SegmentedControl`, and `X-VF` / `XMono` variable font assets.
- **Infrastructure**: Added dependency `@anysphere/xai-commerce-prepaid`; added `meetings-main.cjs` and `preload-meeting.cjs` processes; `asar` file count 552 -> 585; removed CI constants and keys like `turn-tasks` introduced in the previous release (consolidated elsewhere).

## Code & Protocol Details

- `meetings-main.cjs` (new file, 32,384 B): Standalone meeting service process (`MeetingsService`).
- `main-app.cjs`: Local loopback HTTP server added observability endpoints `["GET /meetings"]` and `["GET /meetings/capture"]` (returning 400 `"meetingId is required"` when `meetingId` is missing); MCP OAuth client metadata `kte="/oauth/mcp-client.json"`, `n6e="https://cursor.com/oauth/mcp-client.json"`; download manifest supports Linux package distribution -- `d6e(e,"deb")` matches `/download/stable/<platform>/grok-bot-<hash>` by `platform+linuxPackage`; cloud agent publish proposal RPCs `getCloudAgentPublishProposals` / `confirmCloudAgentPublishProposal({agentId, bcId, proposalId, slug, visibility})`; `cloneToTeam` -> `cloneGrokBotAgentToTeam({agentId, offerEntryId, personalSecretNames})` (handling `CLONED` and other outcomes); updater hardening -- `keepStagedZip` / `keptZips.verify` (failure copy `` `"The kept ${i} update..."` ``) and `isPastMaxAge()` (evaluating update package expiration against `getMaxAgeDays()`); attachment image deduplication by `` `${mime} ${sha256}` `` (`attachmentImageUrl`).
- `main-core.cjs` (1,862,395 -> 754,636 B, -59%): Major main-process slimming -- externalized i18n locale data to `electron-main/locales/` (30 locale files `af` / `ar` / `bn` / `cs` / `da` / `de` / `el` / `es` / `fi` / `fr`...), with extensive code deduplication and consolidation; error type mapping table (`error` / `type_error` / `range_error` / `reference_error` / `syntax_error` / `eval_error`).
- `main.cjs` (11,998 -> 6,930 B): Extracted bundled dependencies such as `signal-exit`.
- `proto.cjs`: Meeting transcript messages (`text` / `isFinal` / `kind`), `shareId`, `returnTo`; `ClientActionResponse` added `confirmation{title, message, confirmLabel}`; added internal RPCs `GetGrokBotChangelogInternal` / `UpdateGrokBotChangelogInternal` / `SetGrokBotChangelogStatusInternal`; memory field `learnedAtMs`.
- Other: Split 1Password connection types into `oauth-broker` (including `brokerState` mappings such as `reconnect_required`) and `service-account`; virtual card payments added passkey ceremony states (`needs_enrollment` / `needs_passkey` + `enrolledCredentialIds`).
