# Grok Bot 0.79.0

English | [简体中文](../../zh-CN/full/grok-bot/2026-11-05_0.79.0.md) · [Highlight](../../grok-bot/2026-11-05_0.79.0.md) | **Full Detail**

- **Release Date**: 2026-11-05
- **Platforms**: `mac`, `win`
- **Summary**: Launched end-to-end e-commerce flows, the Agent Store marketplace, calendar/meeting and messaging card protocols, and the Realtime voice event stream

## Key New Features

- **End-to-End E-Commerce & Travel**
  - Added server-side per-Agent shopping cart and product lookup protocols: `LookupGrokBotShoppingProduct`, `SearchGrokBotSimilarProducts`, `Set/List/RemoveGrokBotCartItems` (with variants, inventory, and strikethrough pricing), alongside the `cart-stage` / `receipt-shell` UI.
  - Added gift order validation (`gift.recipientName` / `message` / `arrivesBy` / `deliverBy`), promo codes (`promo.code` / `note` / `saved`), and return policy display (`returnPolicy.summary` / `url`).
  - Added flight booking link resolution (`ResolveGrokBotFlightBookingLink`, `sand.flights.book_on_click`, flight number validation) and virtual try-on (`Generate/ListGrokBotTryOnImages`, `reference-photos` selfie reference settings, returning `needs-selfie` / `NO_SELFIE` when no selfie is on file).
- **Agent Store Marketplace**
  - Added `agent-stores` / `shared-agent-stores` settings panels, `@agentstore(/cursor/stores/...)` deep link parsing, paginated `ListSharedAgentStores` queries, store visibility (`private | team-view | public`), `publish_app.publish` publishing permissions, and the `shared-bots-browse` browse view.
- **Calendar, Meetings & Interactive iMessage Approval Cards**
  - Added calendar event watch and polling protocols (`WatchGrokBotCalendarEvents`, `PollGrokBotCalendarEvents`, `GrokBotCalendarEventFrame`) and meeting prompt actions (`ActOnGrokBotMeetingPrompt`, `UpdateGrokBotMeetingSettings`, covering Google Meet / Zoom / Microsoft Teams / Webex), bundled with a built-in Google Calendar MCP connector (`calendarmcp.googleapis.com`) and mobile calendar read/write tool definitions.
  - Added the interactive iMessage messaging card protocol (`Get/AnswerGrokBotMessagingCard`, `ReportGrokBotMessagingCapabilities`), supporting five card types — approval, single-select, form, page, and payment (spanning auto-review, meeting join consent, local tool authorization, credential/secret requests, and other subtypes).
- **Realtime Voice Event Stream & In-Call Cards**
  - Introduced the Realtime API event stream for voice calls (`session.created/updated`, `conversation.created`, `response.audio.delta`, `response.output_audio.delta`), spoken language prompt injection (`spokenLanguage`), proactive 15-second idle call briefings/questions (`situation-brief` / `situation-ask`), and in-call card sending (`phone-call-send-card`); standardized the voice silence tool name to `stay_silent`.
- **Transcript Search, User Profiles & Places**
  - Added full-text transcript search across messages and files via `SearchGrokBotTranscripts`, user avatar/selfie profile management (`GetGrokBotUserProfile`, `Set/DeleteGrokBotUserProfilePhoto`), place details lookup via `GetGrokBotPlaceDetails` (Yelp result rendering), and labeler Q&A via `AnswerGrokBotLabelerQuestion`.

## Protocol, Governance & Infrastructure

- **Standing Local Tool Grants & Write Tool Plan Mode**: Added main process APIs for managing standing local tool authorizations (`recordLocalToolStandingGrant`, `getLocalToolActionGrant`, `setLocalToolActionGrant`, `clearLocalToolApprovals`, `retireMacMailSendApproval`); added `plan_mode` flag to `WriteArgs`; added `mcp_app_document` return content type for MCP responses.
- **Usage, Session Governance & Account Migration Protocols**: Added `GetGrokBotUsageBreakdown` alongside `usage-limits` / `my-plan` / `additional-usage` limit keys; added `team.member_sessions.read/manage` and `organization.member_sessions.*` permissions, untrusted team memory (`GrokBotAgentDefinitionUntrustedTeamMemory`), and a full suite of admin account migration RPCs (`Admin*GrokBotAccountMigration*`).
- **Sandbox, Networking & Connectors**: Added the `dev-box-docker` executor, in-box identity token issuance for isolated deployments (`getValidXaiIdentityAccessTokenForBox`), private destination allow rules in egress policies (`private_destination_rules`), sandbox guest rootfs initialization flag (`run_on_guest_rootfs`), granular Tailscale error code mappings, and `mcp.asana.com` plus `setup.shopify.com` in the hosted connector registry; added missing-command, insufficient-permission, and stdout-pollution diagnostic hints for MCP `stdio` connectors.
