# Grok Bot 1.1.0

English | [简体中文](../../zh-CN/full/grok-bot/2026-11-14_1.1.0.md) · [Highlight](../../grok-bot/2026-11-14_1.1.0.md) | **Full Detail**

- **Release Date**: 2026-11-14 (UTC+8 package timestamps: Linux AppImage `03:15`, Windows `03:28`, macOS `08:35`, Ubuntu/Debian `.deb` `08:42`)
- **Platforms**: `mac`, `win`, `ubuntu`
- **Summary**: Major `1.1` feature release expanding `GrokBotService` to 515 methods (`+22 / −0`), adding 4 ConnectRPC services (`7 → 11`) and 258 protobuf messages with zero removals, introducing YAML Factories, Cloud Agent Apps & Page publishing, Cursor ↔ xAI unification, Local Pitman & Spotlight element picking, STT speaker diarization, and upgrading Electron to `43.8.9`

## Overview

Built from unified commit `83d46d618ef4c12afa17edd8e3c29d6caf046d17` (`sandBuiltAt`: `2026-11-13T19:10:26.558Z`), `1.1.0` is a purely additive protocol and feature expansion across `mac`, `win`, and `ubuntu`. `dist/electron-main/proto.cjs` grows `1,589,070 → 1,730,908` B (`+141` KB, `+8.9%`; identical SHA-256 `e9139710fe188967…` across macOS, Windows, AppImage, and `.deb`), expanding protobuf messages from `2,829 → 3,087` (`+258 / −0`), enums from `411 → 470` (`+59 / −0`), `aiserver.v1.GrokBotService` from `493 → 515` Unary methods (`+22 / −0`), and ConnectRPC service descriptors from `7 → 11` (`+AppPublishService`, `+UnifiedDashboardService`, `+XaiAccountClosurePartnerService`, `+XaiUnificationPartnerService`), while upgrading Electron `43.8.4 → 43.8.9` (Chromium `150.0.7871.250`).

## Key New Features

- **Runtime, Packaging & Desktop Subsystems**
  - **Upgraded Electron `43.8.4 → 43.8.9`** (Chromium `150.0.7871.250`); added AppImage update signature verification (`verifySignature`) and `+@anysphere/cursor-icons` in `package.json`.
  - Bundle size deltas (`1.0.3 → 1.1.0`): `main-app.cjs` `3,606,029 → 3,770,636` B (`+165` KB), `proto.cjs` `1,589,070 → 1,730,908` B (`+141` KB), `node-agent-coordinator/main.cjs` `1,379,189 → 1,428,758` B (`+50` KB, `+3.6%`), `main-core.cjs` `1,179,502 → 1,214,411` B (`+35` KB), `preload.cjs` `149,773 → 160,046` B (`+10` KB; main edge `658 → 701` entries, `+46 / −3`), while `local-exec-daemon/main.cjs` shrank `3,539,924 → 3,472,851` B (`−67` KB, `−1.9%`) and `messages-worker.cjs` (`121,022` B) remained byte-identical.
  - Added **Spotlight Element Picker Overlay** (`dist/electron-preload/preload-spotlight-element-pick-overlay.cjs`, `17,989` B + `element-pick-overlay.html` + `spotlight-element-pick-overlay` renderer bundle) and **Local Meeting Recorder** (`dist/electron-main/local-meeting-recorder.cjs`, `135,396` B); updated `sand_notification_settings.node` (`watch_scroll_finger_lift` trackpad gesture hook on macOS) and `onepassword-connection-service.cjs` (`107,751 → 107,785` B).
- **Factories (Declarative YAML Agent Pipelines)**
  - Added 4 `GrokBotService` RPCs—`ListGrokBotFactories`, `SaveGrokBotFactory`, `RunGrokBotFactory`, and `DeleteGrokBotFactory`—backed by `GrokBotFactory{1 id, 2 yaml}` with step-count, name-length, and schedule validation in `main-core.cjs`, run/delete outcome enums (`ALREADY_RUNNING`, `REFUSED`, etc.), agent tool `UpdateFactory`, runtime capability `helper_and_dev_creation_enabled`, `chunk-factory-layout` UI, 4 preload telemetry hooks, and feature gate `grok_bot_factories`.
- **Cloud Agent Apps Hosting, `AppSecrets` & Page Publishing**
  - Added `aiserver.v1.AppPublishService` (~60 messages covering `PublishApp`/`UnpublishApp`, `AppDeployment`, `AppServedTarget`, `AppAccessList`, `AppVisibility`, `ResolvePublishedApp`/`ResolveDraftApp`, `GetAppsEligibility`, `CreateAppsGateTicket`) and 8 `CloudAgentPublish*` preload methods (with `requireConfirmationForUpdates` and `muteRedeployPrompts`).
  - Added the **`AppSecrets` subsystem** (`Create/List/Set/Delete/Bind/Unbind/Widen/Sync/Decline/Request/ApplyAppSecrets`, `AvailableAppSecret`, `AppSecretScope`, `BindingNames`, `SyncOutcome`).
  - Added **Page Publishing, Security Review & Sharing** (`ProposePublish`, `Confirm/DismissPublishProposal`, `PublishReview`, `PublishReviewFinding`, `Request/CancelReviewOverride`, `Get/UpdatePublishedPageShare`, `PageShareRoster`, `OrganizationAudience`, `PrepareDefaultBranchPublish`, `PublishMerge`, `MergeRepublish`).
- **Cursor ↔ xAI Account & Team Unification**
  - Added `UnifiedDashboardService`, `XaiUnificationPartnerService`, and `XaiAccountClosurePartnerService`: team merge & checkout flows (`Start/Get/CancelCursorTeamMerge`, `Prepare/FinalizeCursorTeamMergeCheckout`, `CreateUnifiedDashboardTeam`, `Add/List/RemoveCursorTeamMember`, `GetTeamMembersResponse.xai_team_membership_holds[]`), post-purchase unification (`CompleteXaiUnificationAfterPurchase`), account closure/reopen (`XaiCloseAccount`, `XaiReopenAccount`), `GetSandAccessStatusResponse.account_merge_prompt`, `TeamGroup.cursor_enabled`, `CursorGroupAccessMode`, preload `getCursorStorageAllowed` / `reportXaiCommerce`, and allowed URL host `x.ai`.
- **Account Phone Verification, SMS Form Links, QR Pairing & Purchase Governance**
  - Added `SendGrokBotAccountPhoneCode`, `ConfirmGrokBotAccountPhoneCode`, and `GetGrokBotAccountPhoneStatus` (with `tries_left`, `retry_after_ms`, `created_account`, `texting`), SMS owner verification & form submission (`StartFormLinkOwnerCode`, `SubmitTextedFormLink`, `StartPageOwnerCode`, gate `grok_bot_phone_verification_card`), and mobile-to-desktop QR pairing (`getPhoneAppQrUrl`, `chunk-phone-app-qr-sheet`, `chunk-sms-qr-code`).
  - Added `GetGrokBotPurchaseAutoApprove`, `SetGrokBotPurchaseAutoApprove`, and `SetGrokBotPurchaseSpendLimit` (`GrokBotPurchaseAutoApprove{enabled, decided, spend_limit{amount, currency}, spend_limit_is_default}`), extended `GetSandUsageStatusResponse` (`prepaid_balance_unknown`, `managed_by_team_admin`, `plan_upgrades[]`, `would_refuse_send`, `additional_usage_limit`), localized `"Approve in the X app"` across all 37 embedded locales, and added gates `grok_bot_purchase_auto_approve`, `grok_bot_prepaid_auto_top_up_default`, `grok_bot_x_money_spend_challenge_desktop`, `grok_bot_link_token_charged_via_link_desktop`, and `grok_bot_desktop_free_user_upgrade_cta`.
- **Enterprise Network Blocklists, Tailscale Exit Nodes, Enforced Sandboxing & MCP Governance**
  - Added `TeamOrganizationNetworkBlocklist` (`GetTeamAdminSettingsResponse` field `108 organization_network_blocklist` enforcing `site` and `address` rules), team-managed Tailscale exit nodes (`TeamTailnetExitNode{magic_dns_suffix, node_id, node_name, cidrs[]}`, `exit_nodes`, `GrokBotTurnFailureCode.TAILNET_BOX_REFUSED` / `TAILNET_VIEWER_BOX_REFUSED`), and `SandboxingMode.ENFORCED` (`sandboxing_enforced_available`) plus `EnsureSandBoxResponse.credentials_refresh_after_seconds` and `BackgroundAgentSettings.reject_static_pool_credentials`.
  - Added plugin-level `GrokBotAgentPlugin.policy_block`, `McpArgs.refuse_saved_secrets`, `MintSandBoxPluginSyncGitToken`, admin `off_mcp_server_rules_allowed`, `verifyPasskeyEnrollmentCode`, `SandAccessBlockReason.UNDER_MINIMUM_AGE`, and gate `grok_bot_mcp_app_unsafe_eval_desktop` (`allowEval`).
- **STT Speaker Diarization, Local Pitman, Task↔Transcript Linking, SCM Connect & Agent Tools**
  - Added server-side STT speaker diarization (`SttConfig.diarize`, `SttServerMessage.turns[]` with `SttSpeakerTurn{speaker, text}`, and `session_started`) while keeping `MintSandVoiceCallSecret` and voice call harness schemas byte-identical.
  - Added `StartGrokBotLocalPitman` + 5 preload `LocalPitman*` lifecycle/consent methods (gate `sand_pitman_local`).
  - Linked tracked tasks and transcripts (`GrokBotAgentTask` fields `22..26`: `legacy_task_id`, `tag_ids[]`, `pull_requests[]`, `transcript_start_seq`, `transcript_end_seq`; `ListGrokBotTranscriptEntriesRequest.task_id`; `GrokBotTranscriptEntry.task_numbers[]`), added GitHub SCM connection flows (`Prepare/CompleteGithubConnectFlow`, `GetScmConnectionStatus`, preload `prepareScmConnect`/`completeScmConnect`/`readScmConnections`), threaded chat & thinking narration (`ConversationMessage.thread_id`, `SendMessageArgs.to_main_chat`, `ThinkingMessage.narration`, `SideChatInfo.subagent_type`), `ExecServerMessage` flags `record_agent_view` (`58`) & `refuse_unread_changes` (`59`), `AdminExplainGrokBotSlackAccess`, `ListGrokBotOutcomes`/`ListGrokBotUpdates`, 6 `*GrokBotChangelogEntry*Internal` RPCs, and `+8` agent tools (`194 → 202`: `MacReadPhotos`, `ReadGroupChat`, `SendOrderUpdate`, `SendPlaces`, `SendShoppingProducts`, `UpdateFactory`, `UpdateTrackedTaskTags`, `UpdateVoiceSettings`).
  - **`UserComputer` & Bridge Compatibility**: `GrokBotUserComputerRequestFrame` and `GrokBotUserComputerResponseFrame` descriptors remain byte-identical across `proto.cjs`, `node-agent-coordinator`, and `local-exec-daemon`, with 0 field or enum removals across the entire protocol surface.
