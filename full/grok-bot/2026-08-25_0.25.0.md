# Grok Bot 0.25.0

English | [简体中文](../../zh-CN/full/grok-bot/2026-08-25_0.25.0.md) · [Highlight](../../grok-bot/2026-08-25_0.25.0.md) | **Full Detail**

- **Release Date**: 2026-08-25
- **Platforms**: `mac`, `win`
- **Summary**: Introduces the Agent template system, a remote "user computer" control channel, and Chrome data import — evolving the product from single-agent chat toward a distributable, remotely controllable bot platform

## Highlights

- **Features**: Agent template system launches (`CreateGrokBotAgentFromTemplate`, `ActivateGrokBotTemplateVersion`, `GetGrokBotTemplateImportDetails`, templates-pane UI); desktop notification sounds (5 built-in WAV files: ping-open-blip/tick/double-tick/chime-a/chime-b, notification-sound setting); voice model makes its first appearance (setting key `grok-voice-latest`).
- **Protocol / Main Process**: Large batch of new GrokBot protocols: remote user computer control family `GrokBotUserComputer{Hello,Exec,File,Download,Cancel,ControlMessage,…}`, streaming transcript subscription family `GrokBotTranscriptWatch{Frame,Rows,Heartbeat,Cursor,…}`, multi-member room turn family `GrokBotRoomMemberTurn*` (SpeakerKind distinguishing agent vs. human), box handoff `EndGrokBotBoxHandoff`, `GetGrokBotSendStatus`, `DismissGrokBotWidget`, and `GetEffectiveUserAgentStoreSkillsSettings`; status constants ACCEPTED_BOX/DELIVERED_TEMPORAL/NOT_TEMPORAL, etc. (Temporal durable delivery semantics).
- **UI**: onboarding-flow, automation-detail-panel, agent-avatar-editor, templates-pane, and Markdown math rendering (inlined KaTeX fonts).
- **Infrastructure**: Added `dist/electron-main/chrome-import-worker.cjs` (imports host Chrome profile/cookies, paired with profile-cookies); removed rehype-katex dependency (KaTeX bundled directly instead); dev-controls and several workers under dist/host (agent-store-worker, transcript-mirror-worker, box-store-vacuum-worker, search-index-worker) consolidated into the main bundle; dependencies 82→81.

## Code & Protocol Details

- `dist/electron-main/chrome-import-worker.cjs` (new file, 0→11445 bytes): Brand-new Chrome import worker (profile collection logic such as collectProfileCookies), with matching references added to `main.cjs` in the main process — landing the "host Chrome profile/cookie import" subsystem.
- `main.cjs`: Brand-new Agent template RPC family (0 occurrences in 0.24.0): `CreateGrokBotAgentFromTemplate`, `ActivateGrokBotTemplateVersion`, `GetGrokBotTemplateImportDetails`, `GetGrokBotTemplateForSourceAgent`, and error `BotTemplateImportRecipeError` ("GetGrokBotTemplateImportDetails returned an unusable recipe").
- `main.cjs`: New remote "user computer" control channel protocol family: `GrokBotUserComputerHello`, `GrokBotTranscriptWatchFrame` (transcript stream subscription), `GrokBotRoomMemberTurnRequest` (multi-member room turns), `EndGrokBotBoxHandoff`, `GetGrokBotSendStatus`, and `DismissGrokBotWidget`.
- `main.cjs` (proto): Added `{no:57,name:"machine_id"}` field to exec streaming messages (in the same oneof message as shell_args/write_args/delete_args).
- `main.cjs` (pure removal): Removed the EXIF metadata table (InteropIndex/OldSubfileType/PhotometricInterpretation…) and the image-q image quantization library (Igor Bezkrovnyi copyright header) in their entirety — shrinking `main.cjs` from 8.68MB to 7.49MB.
- `main.cjs`: New setting key `notification-sound` and voice model ID `grok-voice-latest` appear for the first time.
