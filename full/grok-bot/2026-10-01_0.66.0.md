# Grok Bot 0.66.0

English | [简体中文](../../zh-CN/full/grok-bot/2026-10-01_0.66.0.md) · [Highlight](../../grok-bot/2026-10-01_0.66.0.md) | **Full Detail**

- **Release Date**: 2026-10-01
- **Platforms**: `mac`, `win`, `ubuntu`
- **Summary**: Agent access principals and cloud sandbox storage stats APIs; Box egress tunnel (`sand_box_egress_tunnel`) enabled by default

## Highlights

- **Features**: Agent access control `AddGrokBotAgentAccessPrincipalRequest` (granting access by principal); cloud sandbox storage governance: `AdminStatSandBoxStoreObjectRequest` (stats by `s3_link`, `AdminStatSandBoxStoreObjectExpectedKey.Source`), `CheckAgentStoreVersionsResponse.Status`.
- **Protocol / Main Process**: Feature flag `sand_box_egress_tunnel` defaults to `true` (routing Box sandbox egress traffic through the tunnel); permission scope `grok_bot_agent.use`; telemetry `sand.chip.first_content`, `sand.desktop.egress_tunnel`; constants `ShellOomKill.Kind` (shell OOM kill classification), `COMMAND_FAILED` / `COMMAND_KILLED`, KMS key field `kmsKeyId`; new keys `sand-update-place`, `public-web`, `viewer-user`, `move-required`, `unsupported-type`, `last-modified`.
- **UI**: `marketplace-browse-model` (plugin marketplace browse model), `team-bot-setup-grid`, `interaction-scope`.
- **Infrastructure**: No dependency additions or removals; Electron unchanged.

## Code & Protocol Details

- `main-app.cjs`: Added `updateProfilePicture` (0 occurrences in 0.65): guarded against concurrency by `authOperationEpoch`, updating avatars only when `logged-in` and `authId!=null`.
- `main-app.cjs`: Viewer identity facts: `createViewerPublisherFacts` -> `getMe(new GetMeRequest({}), {timeoutMs})`, returning `{kind:"known", userId: t.userId>0 ? t.userId : null}` (attaching real `userId` in telemetry, with degraded fallback reporting on failure).
- `main-app.cjs`: Updater "Move to Applications" flow: when `state.type==="move-required"`, checks `state.version!==t` (`superseded`), `canMove`, and `bundleLocation`, invoking `bundleLocation.moveToApplications()` and returning `{status:"requested"}`.
- `main-app.cjs`: Expanded telemetry schema dictionary (`replica_resync` added `bufferOverflowed` / `epochChanged`, `send_journal_restore`, `transcript_store_parity`, reconnect `settleBasis` / `siteBlockConfidence`, typing receipt `ackMs` / `commitOffsetMs` / `clientOnlineAtTimeout`, etc. -- mostly new columns on existing schemas).
- `main-core.cjs`: Token storage error classification map `sre={damaged:"parse","unsupported-version":"parse","write-failed":"write"}` and `V0` / `H0` reporting wrappers (`"unsupported-version"` occurrences 6 -> 10).
- `proto.cjs`: S3 object metadata messages (`bucket` / `key` / `versionId` / `sizeBytes` / `lastModifiedMs` / `etag` / `serverSideEncryption` / `kmsKeyId` / `storageClass`...) and diff messages (`conflictedPaths` / `hunks` / `files`) -- field carriers for cloud sandbox storage governance APIs.
