# Grok Bot 0.40.0

English | [简体中文](../../zh-CN/full/grok-bot/2026-09-03_0.40.0.md) · [Highlight](../../grok-bot/2026-09-03_0.40.0.md) | **Full Detail**

- **Release Date**: 2026-09-03
- **Platforms**: `mac`, `win`
- **Summary**: Cloud session box (Session Box/Pod) management framework and team prepaid billing launch

## Highlights

- **Features**: Team prepaid balances and auto top-ups (`CreatePrepaidTopUp`, `PrepaidAutoTopUpRule` threshold/amount, `PrepaidBillingMode`, `PrepaidTopUpEntry`); cloud session box pod state machine (`GrokBotSessionBox` / `GrokBotSessionBoxPod` / `PodState` / `CredentialState`, supporting hibernation management); team Grok Bot eligible user lookup (`GetTeamGrokBotEligibleUserIds`).
- **Protocol / Main Process**: Admin session box RPCs — `AdminForceDeleteGrokBotSessionBox`, `AdminGetGrokBotSessionBox`, `AdminListGrokBotSessionBoxes`, `AdminHibernateGrokBotSessionBox`, and `AdminReapGrokBotSessionBoxNow` (force delete / get / list / hibernate / reap immediately); `GetTeamPrepaidBilling`, `SetTeamPrepaidBillingMode`, and `SetTeamPrepaidAutoTopUp`; dedicated auth path carrying `getGrokBotAccessToken` appears on `aiserver.v1.InferenceService.Stream`; telemetry event `sand.policy.stopped`; status enums `PREPAID` / `REACHABLE` / `REVOKED` / `STARTING` / `SOURCE_GROK_BOT`.
- **UI**: `voice-picker-dialog` voice selection dialog; added Urdu (`ur`) locale resource `emoji-messages.ur`.
- **Infrastructure**: No dependency changes.

- `proto.cjs`: Admin session box RPCs `AdminGetGrokBotSessionBox` / `AdminListGrokBotSessionBoxes` (0→5 occurrences); prepaid billing `CreatePrepaidTopUp` (0→5 occurrences) and `PrepaidTopUpEntry` (`ticket/origin/amount_cents/status/created_at_ms`); messages add `context_injection_order` / `delivery_deadline_started_at_ms`; `GrokBotSlackReinstallOutcome` enum and team settings fields realigned.
- `renderer/DefaultCode`: Reorganized Shiki syntax highlighting chunk (343625→333780B, 236 substantive edits, rewritten lazy-loaded language grammar table); remaining renderer chunks are hash rotations.
