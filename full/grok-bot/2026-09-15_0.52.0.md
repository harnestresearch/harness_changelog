# Grok Bot 0.52.0

English | [简体中文](../../zh-CN/full/grok-bot/2026-09-15_0.52.0.md) · [Highlight](../../grok-bot/2026-09-15_0.52.0.md) | **Full Detail**

- **Release Date**: 2026-09-15
- **Platforms**: `mac`, `win`
- **Summary**: Connector and plugin settings pages take shape: adds `@anysphere/marketplace-category`, landing connector cards, native plugin details, Slack install wizard, and credential management sections

## Highlights

- **Features**: Full "Connectors" and plugin management UI in Settings: connector-card-view, native-connector-card, mcp-connector-status, native-plugin-detail/native-plugin-state, plugin-detail-view, and provider-credentials/credentials-section credential management panes; team-bot-slack-flow-dialog (Slack installation wizard dialog) replaces legacy team-bot-context-ingest.
- **Protocol / Main Process**: Large batch of new GrokBot admin RPCs: AdminGetGrokBotAgentDefinition, AdminDeleteGrokBotAgent, AdminForceDeleteGrokBotSessionBox, AdminForceRecreateSandBox, ActivateGrokBotTemplateVersion, AddGrokBotRoomPeople, and AdminCommandDenylist; cloud sandbox store multipart upload abort `AbortSandBoxStoreMultipartWritesRequest/Response`; `GetSandTrialClaimStatusResponse.SandTrialClaimStatus` (trial claim status); `GrokBotRoomMemberTurnMessage.SpeakerKind`. Added session address kind `handoff-resume` (alongside `turn` and `voice-call`, used to resume calls/sessions across handoffs) and request header `x-cursor-client-os`; telemetry events `sand.cloud_agent.artifact_clicked` / `artifact_load_failed`.
- **UI**: `AvailableModelsResponse` adds `ConfirmationDialogue`, `ModelPickerBadge`, and named model view configurations (confirmation dialogs and badges in the model picker); updates to shared `settings-row` and `scroll-pane` components.
- **Infrastructure**: Added dependency `@anysphere/marketplace-category` (plugin marketplace categories); asar file count 504→514; extensive UI string localization.

## Code & Protocol Details

- `main-app.cjs`: Added GrokBot Terms of Service module `{fetchGrokBotTermsRecord, markGrokBotTermsSeen}` (fetching ToS records and marking them seen); added voice session address class — `Xj="voice:"` prefix, `wmt=["turn","voice-call","handoff-resume"]`, `static address(t){return "voice:"+t}` / `callIdOf` / `isOwnerStarted` (landing the `handoff-resume` session address); added `addRoomPeople` RPC (`addGrokBotRoomPeople({agentId, userIds})`, throwing `"AddGrokBotRoomPeople returned no room"` on empty response); exposed `listGrokBotEmailInboxes` / `createGrokBotEmailInbox`; added error class `SandGenerateImageError` constructed with `{statusCode, contentSafetyBlocked}` (carrying provider status and content-safety block flag on image generation errors); added `sendTaskStampsTheLoopOnTheBackend(t,r)=t.kind==="package" && t.loop==="temporal" && r===pt` (routing specific tool calls in Temporal-loop package tasks through the backend harness); loads `teamPolicy.load()` prior to reading auth status (reporting `"cursor-auth"`/`"auth-status-read"` on failure); removed a batch of legacy UI state constants (`["approved","denied","always"]`, `["up","down","submit","revert"]`, `"auto-review/stale"`, etc.).
- `main-core.cjs`: Attachment kind classifier `z4(e)` routes by `mimeType` into `{kind:"image"|"video"|"document"}`; added error `SAND-E0220 credentialSubmitFailed` ("Browser credential fill wrote the password but the sign-in form could not be submitted safely, so the filled values were cleared..." — clearing auto-filled credentials when the sign-in form cannot be submitted safely).
- `proto.cjs`: Full proto regeneration (741KB→473KB), reflecting newly added GrokBot admin RPCs and field realignments.
