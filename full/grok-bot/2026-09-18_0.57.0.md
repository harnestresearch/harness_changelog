# Grok Bot 0.57.0

English | [简体中文](../../zh-CN/full/grok-bot/2026-09-18_0.57.0.md) · [Highlight](../../grok-bot/2026-09-18_0.57.0.md) | **Full Detail**

- **Release Date**: 2026-09-18
- **Platforms**: `mac`, `ubuntu`
- **Summary**: Major release: Notion/Slack/GitHub connector domain recognition and `notion-fetch` tool in the main process; cloud agent task type system (babysit PR, BugBot autofix, parallel multitasking) and `BackgroundComposer` / `Dashboard` services take shape

## Highlights

- **Features**: Connector awareness: built-in domain attribution in the main process for `mcp.notion.com` / `mcp.slack.com` / `notion.com` / `notion.so` / `slack.com` / `github.com` / `gitlab.com` / `dev.azure.com` / `api.cursor.com`, plus the `notion-fetch` link title tool and `link-preview` `gate-read` gating; expanded cloud agent task type enums including `BABYSIT_PR_IN_CLOUD` (babysit PR in cloud), `BUGBOT_AUTOFIX`, `CI_PANEL_INVESTIGATE_FAILURE`, `MULTITASK`, `BUILD_IN_PARALLEL`, `CALL_MCP_TOOL`, `CLEAN_SLATE`, etc.; skill source classification `CURSOR_PROJECT` / `CURSOR_PERSONAL` / `CLAUDE_SKILL` / `CLAUDE_PLUGIN` (paving the way for a skill marketplace).
- **Protocol / Main Process**: New RPC services `aiserver.v1.BackgroundComposerService` (`GetBackgroundComposerInfo`, etc.) and `aiserver.v1.DashboardService`; new setting keys/channels: `cloud-agent`, `pull-request`, `turn-tasks`, `notion-fetch`, `connector-title`, `cursor-title`, `gate-read`; client OS enum `CLIENT_OS_ANDROID` / `IOS` / `LINUX` / `MACOS` / `WINDOWS`; 174 new constants (mostly agent task/tool/approval enums, amplified by full proto rebuild).
- **UI**: Added `team-bot-starter-tasks` (starter tasks component); removed `team-bot-slack-flow-dialog` and `grok-bot-team-context` (consolidated into other components).
- **Infrastructure**: No dependency additions or removals; Electron unchanged.

## Code & Protocol Details

- `main-app.cjs`: Added canvas storage module -- `Nh="/cursor/stores"`, `Lh="canvases"`, user path `/cursor/stores/user/canvases`, automation path `/cursor/stores/automation/canvases`, capacity cap `KU=100*1024*1024`, store ID validation `N5=/^store-<uuid>$/i` (`ZU(e)=N5.test(e)`), rendering `"Canvas unavailable"` on failure; upgraded link preview cache to v4 (`e.cacheVersion===4` + `imageDataUrl` / `faviconDataUrl` validation and `settledAt` / metadata structure); removed GitHub IP allowlist error handling (`"GitHub blocked repository access because this organization or repository uses an IP allow list."` and `cursor.com/docs/integrations/github#ip-allow-list-configuration`); removed `none` / `single` / `double` threshold policy parser `mP`; added experiment exposure `logGroupChatDiscouragementExperimentExposure()`; added Slack approval field `cursorApprovalRequired: {slackTeamId}` (validating tag `"cursor_approval_required"`); added `brand` field to theme serialization.
- `main-core.cjs`: Added `SAND_USAGE_WARNING_EXPERIMENT_POLICIES` / `sandUsageWarningExperimentAssignmentOf` accessors (usage warning experiment).
- `proto.cjs`: Full proto regeneration -- new services `BackgroundComposerService` / `DashboardService`, `MarketplaceAccessPrincipalKind` (`USER` / `TEAM_MEMBER_GROUP` / `TEAM_ADMIN_GROUP` / `GROUP`), `TeamMarketplacePluginInstallMode` (`OPTIONAL` / `DEFAULT` / `REQUIRED`), `ShellCommand` (`command` / `workingDirectory` / `timeout` / `simpleCommands` / `hasInputRedirect` / `isBackground` / `skipApproval` / `closeStdin`, etc.), expanded `GetTeamAdminSettingsResponse` fields, and added `skills` / `subagents` / `hooks` / `rules` / `mcpServers` / `commands` / `lifecycleState` / `publishedByUser` to agent definitions.
