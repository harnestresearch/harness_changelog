# Grok Bot 0.49.0

English | [简体中文](../../zh-CN/full/grok-bot/2026-09-11_0.49.0.md) · [Highlight](../../grok-bot/2026-09-11_0.49.0.md) | **Full Detail**

- **Release Date**: 2026-09-11
- **Platforms**: `mac`, `win`
- **Summary**: Canvas read/write becomes an agent tool, alongside team agent management UI, skill/secret CRUD, and Linear and BigQuery connector expansions

## Highlights

- **Features**: Agents can read and write canvases (`agent.v1.ReadCanvasToolCall` / `WriteCanvasToolCall` plus diagnostic `CloudCanvasToolDiagnostic`); comprehensive team agent management (`grokBot.team.listAgents` channel, `AdminGetGrokBotTeamAgentSharedState`); agent skill CRUD (`AddGrokBotAgentSkill`, `GrokBotAgentPluginSkill`, plugin files `GetGrokBotAgentPluginFile`) and secret management (`DeleteGrokBotSecret`, `DeleteGrokBotMarketplaceListingInternal`); Linear integration (`BatchGetLinearIssueSummaries`); Google connector adds BigQuery and Presentations scopes (`https://www.googleapis.com/auth/bigquery`); usage snapshot (`GetXaiUserUsageSnapshot`: current billing cycle); marketing identity (`GetSandMarketingIdentity` → xai_user_id); organization remote control settings (`GetOrganizationRemoteControlSettings`); bulk team member SandBox operations (`BulkTeamMemberSandBox*` family); auto-review rules `GrokBotAutoReviewRules`; organization/team group MCP settings (`GetOrganizationGroupMcpSettings` / `GetTeamGroupMcpSettings`).
- **Protocol / Main Process**: `agent.v1.SubscriptionRemovedEntry`; setting keys `client-presence` / `digest-framed` / `encoded-key` / `gateway-events-live` / `team-policy-refresh`; new status enums including AWAITING_PAYMENT / BUDGET_RESERVED / RATE_LIMIT / USAGE_LIMIT / PARTIALLY_SUCCEEDED.
- **UI**: Team management UI trio `grok-bot-team-context` / `grok-bot-team-plugins` / `grok-bot-team-secrets-section`, `team-bot-context-ingest` / `team-bot-empty-stage-live` / `use-team-bot-access`, `marketplace-search`, and `credentials-pane`; localized "Return to Grok Bot" copy (`nl`/`id`, etc.).
- **Infrastructure**: 2 native module files updated; dependency count unchanged (84).

## Code & Protocol Details

- `main-app.cjs`: Agent skill CRUD client — `addGrokBotAgentSkill` (agentId + name/description/content/files, 0→3 occurrences) and `updateGrokBotAgentSkill`; MCP secret CRUD channels `listGrokBotSecrets({serverId})` / `putGrokBotSecret` / `deleteGrokBotSecret` (0→3 occurrences each); Messages allowed-recipient allowlist — `listMessagesAllowedRecipients` / `revokeMessagesAllowedRecipient` (standing grants sorted by `grantedAtMs`, filtered by subject scope); voice call prompt rewrite — added constant `" the written chat between you and this caller : \"you\" is what you sent them..."` (retaining end_the_call/send_task/recall_text_messages/stay_silent tools); OAuth callback failure page adds `returnLabel:"Return to Grok Bot"`; quit flush — `app.on("will-quit")` hooks `sand-client-persistence-requit` task boundary (2s deadline).
- `main-core.cjs`: System accent color tracking — `resolveSystemAccentColor()` (normalizing `system.getAccentColor()` to `#RRGGBB`) + listeners on `accent-color-changed` and macOS `AppleColorPreferencesChangedNotification`; path safety validation helper (rejecting empty paths, paths >4096 chars, or paths containing `\0`/`` ` ``/`\r`, converting `file:` prefixes to absolute paths, and rejecting backslashes).
- Also landed: OAuth callback routes for GitLab / Bitbucket / Azure DevOps (`gitlab-connect-callback` / `bitbucket-connect-callback` / `azure-devops-connect-callback`; `0.46.0` introduced catalog entries only, making live OAuth connection flows operational here).
- `onepassword-connection-service.cjs`: Granular launcher error classification (launcher-unsupported/launcher-untrusted/launcher-security/launcher-runtime, with user-facing guidance "Grok Bot's secure 1Password launcher rejected this operation...") and friendly 403 service account error messaging ("This 1Password account can't create service accounts. Ask a 1Password administrator to enable service-account creation...").
- `proto.cjs`: Large-scale proto reorganization — agent marketplace (publisher/publisher_id/is_deprecated), followup system (followup_id/created_at_ms/source/is_simulated/synchronous/pending_make_pr_requests/pending_open_pr_requests), team member spend reporting (team_member_spend/subscription_cycle_start/total_by_role), and team policy boolean flags (data_sharing_discount_eligible/dashboard_analytics_requires_admin/individual_spend_limits_blocked/allow_domain_join).
