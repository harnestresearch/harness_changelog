- **Release Date**: 2026-10-22
- **Platforms**: `mac`, `win`, `ubuntu`
- **Summary**: Fixed an account-switching race condition during Canvas store resolution

## Highlights

- **Features**: No new features.
- **Protocol / Main Process**: Wired error messages `"Canvas store resolution returned no store."` and `"The signed-in account changed while its canvas store was being resolved."` (fixing an account-switch race during Canvas store resolution).
- **UI**: Renderer chunk rotation (`app-copy`, `elevated-draft-fields`, `template-editor-dialog`, `pointer-release`).
- **Infrastructure**: No dependencies added or removed.

## Code & Protocol Details

- `main-app.cjs`: Canvas store account-switch race fix — added ownership check `isOwnStore:async(d,c)=>{…}` (x3) comparing the resolved store against the current account scope (`HH(f.scope,u)`), throwing `throw new iu("The signed-in account changed while its canvas store was being resolved.")` on mismatch; paired with an abortable wrapper `t.addEventListener("abort",r,{once:!0})` and the `TR(e,{getAccountScope,getTeamId})` account scope provider. Both error message strings already existed in `0.75.0`; this release fills in the ownership verification logic itself.
- `renderer/*`: Minor cleanup in `index.eager` (+0.8KB); remaining chunks are `dbid`/hash rotations (the `chat` chunk includes an Urdu-to-Hebrew locale data swap from localization reshuffling).
