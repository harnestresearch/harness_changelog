# Grok Bot 0.37.0

English | [简体中文](../../zh-CN/full/grok-bot/2026-09-03_0.37.0.md) · [Highlight](../../grok-bot/2026-09-03_0.37.0.md) | **Full Detail**

- **Release Date**: 2026-09-03
- **Platforms**: `mac`, `win`
- **Summary**: Integrates X Money connector and `mcp.money.x.com` MCP service, adding email/Slack draft sending protocols and multi-agent room turn delivery

## Highlights

- **Features**: X Money integration (connector provider `"x-money"`, static client registration, backend-tunnel-only); Grok Bot download portal (`https://cursor.com/download/bot`, paired with `grokbot://` deep-link share/onboarding cards); connector card views.
- **Protocol / Main Process**: MCP endpoints `mcp.money.x.com` / `mcp.money-staging.x.com` / `mcp.money-dev.x.com`; `aiserver.v1.SendGrokBotDraft` / `DiscardGrokBotDraft` (carrying `GrokBotEmailDraft` (from/to/cc/subject/body) and `GrokBotSlackDraft` (workspace/target/body)); `DeliverGrokBotRoomMemberTurnResult` (delivering room member agent turn results with replay-protection nonces); `Get/SetGrokBotUserMcpSettings` (cloud sync for user-level MCP server settings); `GetGrokBotMarketplaceListingSourceTemplateInternal` (source template for marketplace listings); anyrun-side `PersistedCdcVmSnapshotSource` / `PersistedCdcFileChunk` / `SnapshotStartupProfileCommand` (cloud box VM snapshot persistence + startup command profiling).
- **UI**: Added `connector-card-view` (connector cards) and `listener-integrations` (listener integrations) components.
- **Infrastructure**: Dependency count unchanged (83); removed legacy identifiers `computer-use-mac`, `automation-message`, and `local-build`.

## Code & Protocol Details

- `main-app.cjs`: Landed cloud sync for MCP server settings — added `pushServerSettings()` (0 occurrences in 0.36 → 7) and `serverMcpSettings()` reader; sync ledger adds batched `readMany()` + `BMt()` longest-prefix include/exclude matching (`Math.max(-1,...t.startsWith(s).map(s=>s.length))`, pushing keys only when matching an include prefix at least as long as any exclude prefix), marking `"remove-sync"` on catch failure; proto side consumes `getMcpCustomInstructionsByServerId` / `getMcpDisabledToolsByServerId`; deleted the entire parameter validation block for `automation-message` notifications (`typeof t.automationId==="string" && ...`).
- `main-core.cjs`: Local tool approval persistence — added `getLocalToolApprovalsPath()` (`local-tool-approvals.json`), `clearLocalToolApprovals` (0→4 occurrences), and `onLocalToolPermissionNever` callback (0→3 occurrences) to clear saved local tool approvals when "Never allow" is selected.
- `chrome-import-worker.cjs`: Added `chromeUtcNow()` = `BigInt(Date.now()) * BigInt(1e3) + J` for microsecond-precision UTC timestamps.
- `proto.cjs`: Added usage fields `spend_cents` / `included_spend_cents` / `overall_spend_cents` / `fast_premium_requests`; box device fields `is_root_device` / `jail_relative_path`; account fields `is_pooled_plan` / `has_token_based_pricing`, `first_project_onboarding`, and `active_group_member_id`; OAuth fields `oauth_authorize_url` / `approval_request_filed` / `app_removed` (all 0 occurrences in 0.36); removed `private_inference` from two messages (returning in 0.41).
