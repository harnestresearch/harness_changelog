# Grok Bot 0.62.0

English | [简体中文](../../zh-CN/full/grok-bot/2026-09-28_0.62.0.md) · [Highlight](../../grok-bot/2026-09-28_0.62.0.md) | **Full Detail**

- **Release Date**: 2026-09-28
- **Platforms**: `mac`, `win`
- **Summary**: Bots join Google Meet / Zoom meetings with an avatar persona; introduced the `dune` reliability telemetry subsystem

## Highlights

- **Features**: Landed local meeting participation: added `dist/electron-main/meetings-main.cjs` with built-in providers for Google Meet (`meet.google.com`, meeting code regex) and Zoom (`zoom.us`, 9-12 digit meeting IDs); renders avatar personas via offscreen page `pitman-avatar/pitman-avatar-output.html`, paired with events `sand-meeting-stamp` / `sand-meeting-wake` / `sand-meeting-hear` / `sand-meeting-idle` / `sand-meeting-camera` (listening, idle wake, camera ready). Also added group chat connect waiting (`group-chat-connect-waiting`) and team bot teammate intro page (`team-bot-teammate-intro`).
- **Protocol / Main Process**: New dependency `@anysphere/dune-reliability` (user-agent `"dune-reliability"`), new setting keys `dune-otlp-export`, `dune-reliability`, `dune-render-trace` and attributes `dune.app` / `arch` / `install_id` / `platform` / `session_id` / `track`, plus local telemetry outbox file `outbox.v1.jsonl` (temp file + retries, capped at 10 attempts / 1 MB / 1-week expiration). Approval outcome branch accessors: `ConnectScmRequestResponse.Approved`, `McpAuthRequestResponse.Approved`, `SwitchModeRequestResponse.Approved`, `WebFetchRequestResponse.Approved`, `WebSearchRequestResponse.Approved` (`approved` / `rejected` / `failed` breakdown). Additional new keys: `slack-link`, `install-id`, `install-url`, `store-id`, `spell-check`, `scroll-gesture`; locale detection added `zh-hans` / `zh-hant` / `yue-hans` / `yue-hant` (Simplified/Traditional Chinese and Cantonese).
- **UI**: `"Add to Dictionary"` (spell-check dictionary addition); Slack reinstall outcome copy family (`INSUFFICIENT_SCOPES` / `UNSUPPORTED_HARNESS` / `SLACK_REJECTED` / `MANAGER_REAUTH_REQUIRED` / `RECREATE_REQUIRED` / `UP_TO_DATE`); `"Messages is turned off in the user..."` (iMessage disabled prompt); `CloneGrokBotAgentToTeam` (clone agent to team).
- **Infrastructure**: Dependencies 87 -> 88 (+`@anysphere/dune-reliability`); `asar` 587 -> 595 files (most of the 344 "new files" in the diff are renamed renderer chunks); Electron version unchanged.

## Code & Protocol Details

- `main-core.cjs`: Added durable machine ID: `var mT="cursor-machine-id", lte={readSecret,writeSecret,waitForEncryptedStorage}` -- reads keychain secret first, re-reads once encrypted storage is ready, and falls back to generating and writing back `randomUUID()` if still absent (`WeakMap` memoized). Provides a durable machine ID source alongside `install-id`.
- `main-app.cjs`: Landed Slack integration client: `isSlackLinked()` reads `GetSlackUserSettingsRequest().hasSlackAuth`, and `slackLinkUrl()` builds `${dashboardUrlOf(...)}/dashboard?tab=integrations` + `GetSlackInstallUrl`; built-in Connect browser transport stack in the main process (`ConnectError`, envelope framing `"protocol error: incomplete envelope"`, `crypto.webcrypto`).
- `main-app.cjs`: Added cross-account race guard to `getAutoReviewInstructions`: validates `getActiveAccountScope()===t && settingsStore.getWriteGeneration()===r` before and after reads, plus `sameSandAutoReviewInstructions` comparator -- preventing stale instructions from being applied if the account or settings change across an `await`.
- `proto.cjs`: Added enum `SlackConnectSource`: `UNSPECIFIED` / `LEGACY_UNKNOWN` / `GLASS_CHECKLIST` / `GLASS_SETTINGS` / `GLASS_AUTOMATIONS` / `IDE_SETTINGS` / `IDE_IN_APP_AD` / `DASHBOARD_INTEGRATIONS` / `DASHBOARD_OVERVIEW` / `DASHBOARD_SETUP_*` (Slack connection source attribution).
- `meetings-main.cjs`: Major local meeting avatar overhaul: avatar output JSON added an `"ink"` field (whiteboard stroke SVG path, `"ink" in e && typeof e.ink=="string" && e.ink.length>0`), color palette `[{id:"black",...,"#000"},{id:"brown","#936439"},{id:"red","#FF263C"},{id:"orange","#FF6700"}...]`, `avatarFrameChannel` frame forwarding/replay, `lookupAvatar` lookup, and `hear()` / `idle()` event bridge; permission handler restricted to `"storage-access"` and `mediaTypes` `audio|video` only.
- `main.cjs`: `process.getBuiltinModule("node:fs")` fallback (compatibility with newer Node APIs).
