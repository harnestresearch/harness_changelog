# Grok Bot 0.72.1

English | [简体中文](../../zh-CN/full/grok-bot/2026-10-20_0.72.1.md) · [Highlight](../../grok-bot/2026-10-20_0.72.1.md) | **Full Detail**

- **Release Date**: 2026-10-20
- **Platforms**: `mac`, `win`, `ubuntu`
- **Summary**: Added system proxy resolution (including SOCKS detection) in the networking layer alongside bug fixes

## Highlights

- **Features**: No new user-facing features.
- **Protocol / Main Process**: Added `system-proxy` (reading `system-proxy.json`, `[sand] system-proxy` logging, SOCKS proxy detection, and `setGlobalProxyFromEnv` global proxy configuration for routing WebSocket/HTTP connections through the system proxy).
- **UI**: Renderer chunk rotation (`bot-template-details-dialog`, `card-item`, `connector-auth-telemetry`).
- **Infrastructure**: No dependencies added or removed.

## Code & Protocol Details

- `main-app.cjs`: Removed the special case routing `system_proxy` telemetry through the anonymous sign-in transport — `0.72.0` used `report=o0n((t,n,o)=>{if(n===CR/*"sand.desktop.system_proxy"*/){this.anonymousSigninTransport.enqueue(t,n,o);return} this.enqueue(t,n,o)})`, simplified in `0.72.1` to `report=d0n((t,n,o)=>this.enqueue(t,n,o))` (system proxy telemetry now flows through the regular authenticated transport).
- `main-core.cjs`: Substantially simplified system proxy resolution (-5KB) — removed route classifications (`"proxy"/"socks_unsupported"/"unresolved"/"direct"`) and outcome telemetry strings (`proxy_ok/proxy_fail/direct_ok/direct_fallback/tls_error/proxy_auth_407/system-proxy-fallback` all removed); `SAND_NO_PROXY` is no longer injected into proxy config as `extraNoProxy` and is instead recorded as an ignored environment variable warning `(t.SAND_NO_PROXY??"")!==""&&o===void 0&&i.push("SAND_NO_PROXY")`; deduplicated loopback bypass list `"localhost,127.0.0.1,::1,[::1]"->"localhost,127.0.0.1,::1"`; moved the errno-to-error-class mapping table (ECONNREFUSED/EAI_AGAIN/ETIMEDOUT...) into `main-app.cjs`.
- `renderer/*`: Buildkite virtual store UUID, `sentry-dbid`, and chunk hash rotation only.
