# Grok Bot 0.58.0

English | [简体中文](../../zh-CN/full/grok-bot/2026-09-22_0.58.0.md) · [Highlight](../../grok-bot/2026-09-22_0.58.0.md) | **Full Detail**

- **Release Date**: 2026-09-22
- **Platforms**: `mac`, `win`, `ubuntu`
- **Summary**: Desktop mount panel (`desktop-mount` panel) landed: agents can be pinned as persistent 320x176 desktop widgets; bot templates support publishing/unpublishing to organizations

## Highlights

- **Features**: New window `preload-desktop-mount-panel.cjs` + `desktop-mount/panel/panel.html`: the `desktop-mount` channel provides `mount(agentId, name, markSvgDataUrl)` / `unmount` / `read` / `submitPrompt` to pin an agent to the desktop as a compact card for sending prompts directly; bot template publishing state machine `PublishGrokBotAgent` (`PUBLISHED` / `ALREADY_PUBLISHED` / `UNPUBLISHED` / `NOT_PUBLISHED` / `NOT_SHARED`) and share cards (`team-bot-share-card`, `bot-template-share-card-frame`); redesigned team setup wizard (`team-setup-pills`, `team-setup-new-secret-dialog`, `team-bot-carry-over-plugin-selection`).
- **Protocol / Main Process**: Real-time voice protocol strings `conversation.item.create` / `response.cancel` / `async_update.add` and `seeded-nudge` channel (`SEEDED_TOOL` / `OVERHEARD_TOOL`: injecting preset tool-call "nudges" during voice calls); `grok-connectors` OAuth provider (scope `grok-plugins:*`); CI environment detection constants `GITHUB_ACTIONS` / `GITLAB_CI` / `GITEA_ACTIONS` / `BUILDKITE` / `CIRCLECI` / `TEAMCITY_VERSION` / `TF_BUILD` / `APPVEYOR`; new keys `desktop-mount`, `desktop-online-edge`, `async-update`, `plugin-logo-cache`, `xterm-ghostty` / `xterm-kitty` (terminal keyboard protocols), `complete-roster`, `written-turn`, `ready-to-show`, `renderer-booting`; audit sequence `sand.action-audit.event-sequence`.
- **UI**: `team-bot-details-dialog`, `team-bot-files-copy`, `get-file-icon`, and `index.eager-*` preload bundle splitting; new `emoji-messages.cs` locale pack.
- **Infrastructure**: `asar` file count 501 -> 552 (370 new files, primarily from eager bundle splitting and panel assets); no dependency additions or removals.

## Code & Protocol Details

- `main-app.cjs`: Bot publishing RPCs -- outcome mapping for `publishGrokBotAgent({agentId})` (`PUBLISHED -> {kind:"published"}`, `ALREADY_PUBLISHED`, etc.) + `unpublishGrokBotAgent`; link preview decode throttling -- `createTaskBoundaryPolicy({name:"sand-link-preview-decode"})` with max concurrency 8 and 8 MB total decoded character budget; startup MCP legacy credential scrub `cleanupLegacyMcpAuthCredentials(e.sandRootDir())` (reporting `"mcp-auth-cleanup"` / `"startup-scrub"`) + `onMcpDiagnostic` (`"mcp-manager"` `leg` / `errorClass`); refactored credential approval RPCs -- `approve` / `deny` now carry `entryId/requestId/resolution/agentId/sessionId` (`rpcObject` `ybe`); ICO icon decoder iterates directory frames to pick the largest `width*height` (`RJ` catches `RangeError` for resilience when picking highest-resolution avatar/icon frames); Chrome cookie import telemetry `reportChromeCookieImport({outcome:"failed", stage, errorClass})` (`undecryptable` / `dbscWarning` / `skipReason` dimensions); removed renderer-side secrets RPCs (`revealSecret` / `upsertSecrets` / `removeSecrets`).
- `main-core.cjs`: Startup metric `app_ready_wait` (`hw_accel` / `os_sandbox` / `bootLanguage` cohort); process classification `utility_coordinator` vs `utility_other` (Electron `UtilityProcess` `NodeService` identifier); updater marker file schema `{version:1, pid, appVersion, startedAtMs, aliveAtMs, crashSeen}` + `markerPidAlive` check; added locales `cs` / `hu` / `nb` / `da`.
- `onepassword-connection-service.cjs`: Built-in full `SandError` registry (`"SAND-E0001" unregistered...`); 1Password service account token validation message (`"That doesn't look like a 1Password service account token. Paste the whole token, which starts with \"ops_\"."`); `connectWithToken` flow reporting (phase `"callback_received"`); `probeMintReadiness` probe.
- `proto.cjs`: Added `ListFinancialConnectionsRequest` (financial account connections), `AdminBreakGlassDeleteSandBoxPod`, payment fields (`amountCents` / `currency` / `merchantName`), and ceremony fields (`creationOptionsJson` / `ceremonyPath` / `ceremonyToken` for passkey/WebAuthn ceremonies).
