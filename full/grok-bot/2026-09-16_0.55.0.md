- **Release Date**: 2026-09-16
- **Platforms**: `mac`, `win`, `ubuntu`
- **Summary**: Minor release: added voice memo telemetry channel `sand.voice_memo` and GitHub disconnect support

## Highlights

- **Features**: Added `sand.*` channel `sand.voice_memo`; `DisconnectGithubResponse` returns `removed_connections_count` (bulk GitHub connection disconnect).
- **Protocol / Main Process**: Only the two items above; no other new protocol strings.
- **UI**: No changes (routine asset chunk recompilation only).
- **Infrastructure**: No dependency additions or removals.

## Code & Protocol Details

- `main-app.cjs`: Added sidebar section persistence `writeSidebarSections` -> `updateGrokBotUserRuntimeSettings({sidebarSections: o.map(({id,name,agentIds})=>...)})`, reporting failures via `reportDesktopEdgeFailure("host-settings","write")`; text-to-speech (TTS) now supports character-level timestamps -- requests pass `withTimestamps: !0` and `voiceId`, validating `charStartMs.length===text.length===charEndMs.length` before mapping to `[{startMs, endMs}]` segments; added RPC `disconnectScmConnection({platform})` -> `scmConnections.disconnect`; account runtime switch now calls `resetMcpManager() + refreshHostMcp()`; settings object passes through `currentBuiltAt`.
- `proto.cjs`: Added `ghe_application` / `user_only` fields to `DisconnectGithubRequest`, and `removedConnectionsCount` to the response.
