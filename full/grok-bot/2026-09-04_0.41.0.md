# Grok Bot 0.41.0

English | [简体中文](../../zh-CN/full/grok-bot/2026-09-04_0.41.0.md) · [Highlight](../../grok-bot/2026-09-04_0.41.0.md) | **Full Detail**

- **Release Date**: 2026-09-04
- **Platforms**: `mac`, `win`
- **Summary**: Shared Canvas rendering lands (@anysphere/canvas-shared, bundle-v1 format + canvas-frame service) alongside the AgentDefinition blueprint protocol

## Highlights

- **Features**: Canvas sharing and rendering — `decodeSandCanvasBundle` supports the `bundle-v1` format (upgraded from `legacy-esm`), `canvas-frame` serves gzipped canvas bundles (with `data.json` parsing and themed 404/422 responses), and configures a full CSP directive set for canvas frames (`default-src` / `script-src` / `connect-src` / `frame-src` / `worker-src`, etc.); Agent definition blueprint `GrokBotAgentDefinition` (comprising Identity/Session/Skill/MemoryShard/Slack/McpServer/AgentRef/TemplateImport substructures, readable by admins); GitHub App installation tenant grants (`Grant/RevokeGithubInstallationTenant`, with GHE support); user-level prepaid billing (`CreateUserPrepaidTopUp`, `GetUserPrepaidBilling`, `SetUserPrepaidBillingMode`, `SetUserPrepaidAutoTopUp`).
- **Protocol / Main Process**: `PrivateInferenceSettings` (private inference toggle); `EventCodeCreditDestination` (promo/event code credit routing: USAGE_GRANT / STRIPE_CUSTOMER_BALANCE); `GetGithubInstallationTenantGrants`; anyrun-side `BearerEgressProxyAuth` (outbound proxy Bearer authentication); avatar pipeline keys `roster-avatars` / `roster-photo-fetch` / `sand-avatar`; credential type constants PASSWORD/PASSPHRASE/CREDENTIAL(S).
- **UI**: No major additions (Mermaid diagram chunk filename rotations only).
- **Infrastructure**: Added dependency `@anysphere/canvas-shared` (dependencies 83→84); persistence/experiment keys introduced in the previous release (account-slot/bot-templates/voice-settings, etc.) disappear from this version's main-process bundle (returning in 0.44 due to bundle migration).

## Code & Protocol Details

- `main-app.cjs`: Substantive addition is canvas share store ID validation — `she(e)` matches `/^store-[0-9a-f]{8}-[0-9a-f]{4}-[1-57][0-9a-f]{3}-[89ab][0-9a-f]{3}-[0-9a-f]{12}$/i` adjacent to `isCanvasShareBundleV1` and bundle root path construction, accompanied by UUID v1–5/7 validation regexes.
- `main-core.cjs`: Avatar pipeline key constants `sand-avatar` / `roster-avatars` (0→1 occurrence), 32-char hex ID regex `/^[0-9a-f]{32}$/`, and `x-amz-`/`x-id` header filtering regexes; Sentry DSN builder `dsnFromComponents` (publicKey/pass/host/port/path/projectId).
- `proto.cjs`: Added `RepoArchiveEnvironmentScope` (selector + `include_sources`, 0→2 occurrences) and repo archive `repos`/`can_enable` lists; `GrantGithubInstallationTenantResponse` (0→5 occurrences, GitHub App installation tenant authorization); `private_inference` fields return (no:68/70, restored after removal in 0.37); BugBot settings fields (`run_only_once`/`suppress_no_bugs_comments`, etc.) realigned.
- `renderer/*`: Mermaid/Shiki library chunk hash rotations with no substantive changes.
