# Grok Bot 0.51.0

English | [简体中文](../../zh-CN/full/grok-bot/2026-09-14_0.51.0.md) · [Highlight](../../grok-bot/2026-09-14_0.51.0.md) | **Full Detail**

- **Release Date**: 2026-09-14
- **Platforms**: `mac`, `win`, `ubuntu`
- **Summary**: Cloud sync for user runtime settings (pinned agents / sidebar sections), agent todo lists, and voice call turn-taking prompt system

## Highlights

- **Features**: Cloud sync for user runtime settings (`Get/UpdateGrokBotUserRuntimeSettings`: `GrokBotPinnedAgents` pinned agents, `GrokBotSidebarSections` sidebar sections, and fields TIME_ZONE / MCP_SERVERS / PINNED_AGENTS / SIDEBAR_SECTIONS); agent todos (`ListGrokBotAgentTodos`); account automation listing (`ListGrokBotAccountAutomations`, grouped by `time_zone` into `GrokBotAccountAutomationGroup`); voice call maturation — feature flag `sand_voice_call` and feedback card, telemetry `sand.voice_call` / `voice_call_connect` / `voice_call_fault` / `voice_call_delivery`, and a full built-in suite of voice turn-taking rule prompts ("Any confirming noise is agreement…", "Never chase or poll the work; it reports back on its own", "An empty tool result is not news", etc.).
- **Protocol / Main Process**: `BackgroundComposerApprovalKind/State`; `GrokBotGroupTriState`; `GrokBotRoomPerson`; `SandCredentialDecisionHarness.BOX`; return of persistence keys (account-slot / veto-roster / veto-seen / fail-open-probes / fail-open-deadline / slack-draft, etc.); telemetry `sand.desktop.log` and `sand.cloud_agent.artifact_opened` / `artifact_rendered`.
- **UI**: Full team-bot dialog suite (`team-bot-context-dialog` / `team-bot-plugins-dialog` / `team-bot-slack-flow-dialog` / `team-bot-overview-panel`), `grok-bot-slack-dialog-live`, `network-debugger-dialog`, `fullscreen-file-viewer-body` fullscreen file viewer, and `voice-memo-bubble` voice message bubble; localized usage check copy ("Comprobando el uso", etc.).
- **Infrastructure**: Major cleanup of main-process protocol constants — removed 457 legacy enum constants (ABORTED_NOT_CHARGED, ADD_FILE_TO_CONTEXT, APPLY_AGENT_DIFF, etc., split into standalone protocol modules); dependency count unchanged (84).

## Code & Protocol Details

- `main-app.cjs`: Voice call telemetry reporting — added phase/call_id/telemetry_version event mappings (`telemetry_version` 0→6 occurrences; structured per-phase fields for `started` / `connected` (elapsed_ms) / `usage` (active_ms, sequence)); cloud artifact tracking `cloudAgentArtifact.ingest` → `sand.cloud_agent.artifact_rendered` / `artifact_opened` (agent_id/bc_id/kind/state); room agent member display — maps `displayName/avatarPhoto/isViewer` when `GrokBotAgentKind.ROOM && people.length>0`, paired with `Intl.ListFormat` (long/narrow/unit styles + `az`–`sv` locale data tables) for localized member list formatting; deep-link logging `desktopLog` (`[sand] deep-link: ${e} reason=... origin=...`, 0→5 occurrences); reduced `listTeamMemberships` call sites (4→2 occurrences).
- `main-core.cjs`: Error reporting wrapper refactor — added `X/Wr` (area/leg/errorClass triple) and mount point `wv(e)` (backed by a 32-entry `drop-newest` ring buffer); new error code `SAND-E0116 gatewayPodHibernated` (retryable, "Gateway route answered that the box pod is hibernated or mid-transition on its node.").
- `proto.cjs`: **`proto.cjs` shrunk from 3.97MB to 0.74MB (-81%)** — bulk removal of generic Cursor tool protocol definitions (`read_semsearch_files_params` 3→0, `ripgrep_search_*`, `create_diagram_stream`/`fix_lints_stream`, and Tool enum values FILE_SEARCH/SEMANTIC_SEARCH_FULL/DELETE_FILE/REAPPLY/RUN_TERMINAL_COMMAND_V2, etc., moved to separate module loading); added `UpdateGrokBotUserRuntimeSettings` (0→3 occurrences) and `GrokBotPinnedAgents`.
