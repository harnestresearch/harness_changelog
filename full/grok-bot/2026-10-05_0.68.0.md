- **Platforms**: `mac`, `win`
- **Summary**: Real-time voice call protocol (OpenAI Realtime-style command/event stream) + ElevenLabs and Cloudflare/Runway MCP connectors; unified billing "Buy Credits" entry point

## Highlights

- **Features**: Landed real-time voice session protocol: commands `session.update`, `input_audio_buffer.append`, `conversation.item.create`, `conversation.item.truncate`, `response.create`, events `assistant-delta`, `response-created`, `response-ended`, `speech-started`, `speech-stopped`, and `caller-speech-started` / `stopped` / `interrupted` RPCs; ElevenLabs connector (`api.us.elevenlabs.io`). New MCP connector domains: `bindings` / `builds` / `docs` / `observability.mcp.cloudflare.com` (Cloudflare suite of four), `mcp.runwayml.com` (Runway video), `mcp.tubealfred.com`, `connector.get-ryze.ai`. Notion write tool suite `notion-create-pages` / `notion-duplicate-page` / `notion-create-database` / `API-post-page`.
- **Protocol / Main Process**: Buy credits command `cursor.unifiedSkuBilling.openBuyCredits` + setting key `open-buy-credits` + URLs `cursor.com/dashboard/spending`, `cursor.com/dashboard?tab=billing`, `cursor.com/grok-bot/link/v1/finance`; `AdminMintGrokBotMeetingAvatarLinksResponse.links` and `AdminGrokBotMeetingAvatarCustomLink` (custom meeting avatar links); `GrokBotSecretForwardingControls` (secret forwarding `allowed` field); link preview guards (`"Link preview redirect left the hosts..."`, `"Link preview response exceeded its byte limit."`); new `preload-avatar-source.cjs` (offscreen `WebContentsView` rendering avatar bitmaps via IPC channel `sand:avatar-source`); connector requests carry `serverIdentifier` / `requestingAgentId`; process type set `crashpad-handler`, `gpu-process`, `ppapi-broker`, etc., plus telemetry `dune.gpu_compositing` and keys `sand-encode-png`, `gpu-info-update`; `NODE_USE_SYSTEM_CA`-class notification environment constants returned. Box route account validation (rejecting routes resolved using another user's token).
- **UI**: `unify-cta-individual` / `unify-cta-team` (individual/team unified subscription upgrade CTAs); `card-dialog`, `card-item`; document viewer family `docx-loader`, `text-viewer`, `file-markdown.worker`, `markdown-structure`, `file-stage`; `working-daisy` progress animation; `"Grok Bot could not open your browser. Try again."`; `emoji-messages` added 5 locales (`ha` / `mr` / `sw` / `ta` / `te`).
- **Infrastructure**: Dependencies 90 -> 91 (+`@anysphere/browser-smoke`); `asar` 607 -> 651; Electron unchanged.

## Code & Protocol Details

- `main-app.cjs`: Established remote MCP connector recognition: trusted host set `var $tr=new Set(["api.cursor.com","connectors-gateway.grok.com"])`, known host map `Htr=new Map([["gmailmcp.googleapis.com",{...vp,scopes:["...gmail.readonly","...gmail.compose","...gmail.modify"]}],["drivemcp.googleapis.com",...],["mcp.money.x.com","xmoney"],["mcp.runwayml.com","runway"],...])`, falling back to the second-level domain label for unknown hosts (`ztr(o[o.length-2])`); path regex `/^\/(?:rest-mcp|gateway\/v1)\/([^/]+)\/mcp\/?$/`.
- `main-app.cjs`: Server-pushed async update frame: `static frame({topic,eventId,texts,atMs}){return {type:"async_update.add", event_id, async_update:{topic, payload: texts.map(i=>({message:{type:"text",content:i},timestampMs:o}})}}}` + `static TOPIC` subscription class (asynchronously injecting system messages within a session).
- `main-app.cjs`: Per-machine local tool permission resolution: `resolveSandLocalToolPermission(n.localToolPermission ?? SAND_DEFAULT_LOCAL_TOOL_PERMISSION, e.ceiling)` applies a ceiling per machine, tags the source via `localToolPermissionMachineId`, and falls back to the default when `currentMachineId` is absent from the list.
- `main-app.cjs`: Attachment storage error mapping: `case Code.PermissionDenied: return "storage_off"; case ResourceExhausted: "rate_limited"; case NotFound: "not_found"` (`ConnectError` -> storage status); link preview failure categories `page-http-5xx` / `page-timeout` / `page-network` / `image-cap` / `image-timeout`.
- `main-core.cjs`: Granular startup phase telemetry: `nativeBootMs()` computes the delta between `app.getAppMetrics().creationTime` and `performance.timeOrigin`, with phase list `["native_boot","process_start","app_ready_wait","move_check","main_handoff",...,"renderer"]`; tool instructions added Shopify rules (`"Before any Shopify write, name the store it will change...call graphql_schema first and validate_graphql_codeblocks"`).
- `onepassword-connection-service.cjs`: Non-retryable error code set `Zo=new Set([NotFound, InvalidArgument, PermissionDenied, FailedPrecondition])`.
