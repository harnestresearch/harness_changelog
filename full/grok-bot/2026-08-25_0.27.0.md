- **Release Date**: 2026-08-25
- **Platforms**: `mac`, `win`
- **Summary**: Refined template permission model: visibility controls and four-tier read/write/share/delete ACLs

## Highlights

- **Features**: Template visibility controls (`SetGrokBotTemplateVisibility`, GrokBotTemplateVisibility); box handoff lineage tracking (`GrokBotHandoffLineage`).
- **Protocol / Main Process**: Added permission paths grok_bot_template.read/write/share/delete; new channels hand-off, send-journal, ui-agent-refs, and ui-layout, plus return of composer-drafts and computer-demo.
- **UI**: Chart component hash updates only.
- **Infrastructure**: No dependency changes; fast patch release shipped just 3 hours after the previous version.

## Code & Protocol Details

- `chrome-import-worker.cjs`: Added `chromeUserDataDir` (darwin: `Library/Application Support/Google/Chrome`, linux: `.config/google-chrome`) — extracting Chrome user data directory resolution into a standalone function.
- `main.cjs`: Landed Chrome CDP injection state machine `boxChromeStateFromInject` (`e>0&&t===0?"open-cdp-missing":…?"open-cdp-ok":"unknown"`), paired with error strings `chrome-closed`/`host-chrome-locked`/`inject-rejected` (all 0 occurrences in 0.26.0) — marking the first appearance of web automation via host Chrome injection.
- `main.cjs`: Added template visibility RPC `SetGrokBotTemplateVisibility` and box handoff lineage `GrokBotHandoffLineage`.
- `main.cjs` (pure removal): Removed `ListGrindModeComposers` RPC.
- `main.cjs`: Added statsig feature gate keys `first_party_models_additional_budget_unlimited` / `per_user_…` / `clear_…` (additional budget controls for first-party models).
