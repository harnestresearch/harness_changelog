- **Release Date**: 2026-10-11
- **Platforms**: `mac`, `win`
- **Summary**: Optimized credential minting order and fallback degradation for the local execution daemon

## Main Process Fixes

- **Local Execution Daemon Credential Minting Optimization**: Reordered `mintLocalExecDaemonCredential` to issue cloud sandbox Box credentials (`issueBoxCredential`) first, adding an optional `skipUserComputerMint` parameter to return Box credentials directly; when `user-computer` credential minting fails, it now automatically falls back to returning Box credentials only and records failure telemetry, preventing total daemon unavailability.
