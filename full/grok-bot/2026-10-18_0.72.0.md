# Grok Bot 0.72.0

English | [简体中文](../../zh-CN/full/grok-bot/2026-10-18_0.72.0.md) · [Highlight](../../grok-bot/2026-10-18_0.72.0.md) | **Full Detail**

- **Release Date**: 2026-10-18
- **Platforms**: `mac`, `win`, `ubuntu`
- **Summary**: Major release (asar 668->874 files): three new native modules introducing device attestation, card OCR, and window capture, plus a menu bar tray Bot avatar system and a major connector catalog expansion

## Highlights

- **Features**: Device-level trial claiming — `ClaimSandTrialWithDeviceAttestation` (including an iOS DeviceCheck channel), paired with the `token-mint`/`trial-claim`/`trial-bundle-id` flow and request headers `x-sand-devicecheck-supported` and `x-sand-hv-vmm-present` (reporting whether the app is running inside a VM for anti-abuse); payment card vault — `grok_bot_vault`/`grok_bot_vault_cards`/`grok_bot_vault_card_scan_on_device` feature gates + `card-photo-scan`/`card-image-screen` (darwin only, scanning cards from screenshots/photos with OCR vocabulary including CARDHOLDER/CITIBANK/BARCLAYS/CASHBACK, etc.), plus new proto `XaiCommerceBearerPurpose=BROWSER_COMMERCE/PREPAID_TOP_UP` (xAI commerce payment tokens); menu bar tray Bot avatar system (24 style x expression PNG assets, roster avatar fetching, and `blink-*`/`glance-left/right-up` blink and glance animations with gaze coordinates); REST-MCP hosted connectors (`api.cursor.com/rest-mcp/<provider>/mcp`, initial batch covering gmail/outlook/google_calendar, with sendTools including send_message/send_email, etc.); Mermaid diagram rendering (dagre/graphlib/gitgraph/eventmodeling, etc.).
- **Protocol / Main Process**: New endpoints `https://api.stqa.cursor.sh` + `https://portal.stqa.cursor.sh` (secondary backend environment with id=2); new setting keys `sand-devicecheck`, `sand-window-capture`, `sand-gpu-info`, `card-photo-scan`, `card-image-screen`, `menubar-tray`, `capture-ready`, `displays-changed`/`display-added`/`display-removed`, `token-mint`, `trial-claim`, `rest-mcp`, `google-calendar`, `outlook-calendar`, `quickbooks-online`, `screen-saver`, `quit-cause`, `support-probe`, `cloud-agent-update`, `listing-watch`, `auth-watch-note`, `thinking-note`, `session-created`, `session-end-spill`; large batch of new MCP hosts added to the connector catalog (mcp.api.getguru.com, mcp.api.harmonic.ai, mcp.incident.io, mcp.mail.superhuman.com, mcp.quickbooks.intuit.com, mcp.public-api.etoro.com, mcp.slides.com, mcp2.readwise.io, mcp.ws.sonos.com, mcp.tryprofound.com, mcp.futunn.com, mcp.sandbox.airwallex.com, etc.) along with Amex business permission scopes (`foundations.tools.bi-dashboard/businessreports/companyprofile.*`, `payroll.tools.employee/employer.*`, `lending.tools.servicing.read`, `contact.tools.customer.*`); OAuth error classification table (access_blocked/fresh_token_rejected/rate_limited, etc.) and `CheckHttpMcpStatusRequest`; dev/experimental bundle IDs `com.anysphere.sand.dev`/`com.anysphere.sand.lab`.
- **UI**: Renderer added `bot-configure-dialog`, `bot-share-control`, `bot-store-files-library`, `connector-card`/`connector-data-center`/`connector-sign-in-copy`, `mcp-connector-status`, `desktop-mount-capture-overlay` (screen capture mount overlay), `elevated-draft-fields`, `library-visual-viewer`, `fullscreen-file-viewer`, and `card-field`.
- **Infrastructure**: Added dependencies `@anysphere/card-photo-text`, `@anysphere/slack-app-setup`, `mdast-util-from-markdown`, `sand-card-text-recognition` (native OCR `.node`), `sand-devicecheck` (native Apple DeviceCheck `.node`), and `sand-window-capture` (native window capture `.node`); 744 files added to asar (largely tray avatar assets); Electron version unchanged.

## Code & Protocol Details

- `main-app.cjs`: Chunked attachment read/write pipeline — `readAttachmentChunk` RPC with `if(ge>X)return{kind:"too-large",size:ge,…}` size guard and chunked `Buffer.alloc` reads, paired with `readAttachmentChunkIfAwake/uploadAttachmentChunk`; new tool access level table `getAgentTranscript:"background", openAgentWindowed:"background", openAgentTail:"person", sendPrompt:"person", promptAcceptanceStatus:"person", respondToWidget:"person", resolveAutoReviewApproval:"person"` (distinguishing background-executable actions from those requiring live human presence); device-level trial attestation `ClaimSandTrialWithDeviceAttestation` (x2) and request header `x-sand-devicecheck-supported`; `menubar-tray` (x3); `post_connect` disconnect watchdog telemetry (`Zct` validating phase/stallMs/keys/clicks/moves/inBytes); Zod v4 upgrade signature string `"Async schemas not supported in object keys currently"`.
- `main-core.cjs`: System proxy resolution landed in this release — errno/TLS classification regexes including `/(?:HTTP\/1\.[01]|Proxy response\()(\d{3})\b/`, `/proxy tunnel timed out/`, and `/^(?:ERR_TLS_|ERR_SSL_|UNABLE_TO_|SELF_SIGNED_…)/`, paired with `reportDesktopSystemProxy` reporting; quit-cause observation table `u4={none_observed,wm_close,sc_close,renderer_close_window}`.
- `main.cjs`: Added `deps` loader `process.env.NODE_PATH=__depsDir+…; __mod.Module._initPaths()` — paving the way for the new native modules under `dist/deps` (devicecheck, card OCR, window capture).
- `proto.cjs`: Added `McpSignOutReason` enum (EXPIRED/REVOKED/ORGANIZATION_POLICY/MFA_REQUIRED/ADMIN_BLOCKED/ACCOUNT_DISABLED/CLIENT_INVALID/ACCOUNT_RESTRICTED/PROVIDER_UNAVAILABLE...); Bot routine/automation model (`routineId/triggerDescription/triggerPresentationJson/schedule/isEnabled/runAsUserId/runAsIsViewer`).
- `onepassword-connection-service.cjs`: Domain validation regex `^[a-z0-9](?:[a-z0-9-]{0,61}[a-z0-9])?` and RPC status code list cleanup.
