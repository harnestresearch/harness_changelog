# Grok Bot 0.60.0

English | [简体中文](../../zh-CN/full/grok-bot/2026-09-26_0.60.0.md) · [Highlight](../../grok-bot/2026-09-26_0.60.0.md) | **Full Detail**

- **Release Date**: 2026-09-26
- **Platforms**: `mac`
- **Summary**: Agent/Skill Store (`aiserver.v1.AgentStoreService` + multipart upload publishing) and cloud sandbox "park/sleep" state machine launched; added `@anysphere/orbit-client`

## Highlights

- **Features**: Skill/Agent Store: `AgentStoreService` (`ListAgentStores` / `ListAgentStoreEntries`) and `AgentStoreMultipart*` chunked write protocol (`Abort` / `Complete` / `Write`, including `etag` and `already_finished`), enabling publishing skills to teams -- with copy `"Add a description before publishing -- it is how teammates and agents know when to use this skill"`; cloud sandbox lifecycle added parking/hibernation: `box-asleep`, `x-sand-box-park`, `present-park`, `away-parked`, `SAND_PRESENT_PARK`, `has-box-agent`, `backend-return` (saving cloud instance costs); seat restriction copy (`"Ask a team admin to move this account to a Premium seat"`).
- **Protocol / Main Process**: New RPC service `aiserver.v1.AgentStoreService`; new keys `team-bot-slack-link`, `parent-link` / `target-link` (directory page links), `all-temporal`, `not-a-file`; `report.drop` / `sand.dropped_count` telemetry; `UNPAID_INVOICE` / `RECONNECT_REQUIRED` and related states.
- **UI**: `document-page`, `DIRECTORY_PAGE` (store directory page), `team-bot-details-model`, `ToggleIconButton`.
- **Infrastructure**: Added dependency `@anysphere/orbit-client`; refactored 36 `electron-main` files (module splitting); `asar` file count 585 -> 587.

## Code & Protocol Details

- `main-app.cjs`: Webview/VNC cloud sandbox auth header injection -- converts URL query parameters into request headers: `{queryParam:"port_token", header:"x-anyrun-port-token"}`, `{queryParam:"network_token", header:"x-anyrun-network-token"}`, plus `x-anyrun-hibernation-lower-bound-s/upper-bound-s` for hibernation recovery windows (paired with `preload-webview.cjs` / `preload-vnc.cjs`, cached per host with an LRU cap); Slack unlinking `disconnect("slack") -> unlinkSlackAccess(new UnlinkSlackAccessRequest)` (`DashboardService`); document service RPCs `getDocument({locator})` / `saveDocument({locator, source})` + `setCanvasVisibility`; meetings demand validation (`"request.args is missing"`, requiring `demand` to be `"person"` / `"background"`); removed `getGrokBotTeamContextSummary` RPC and `revokeRefusedAccount` flow (`"refused account credentials could not be removed"`); added `setComputerViewOpen({isOpen})` -> `clientPresence.noteComputerViewOpen` (desktop computer view presence state).
- `main-core.cjs`: Sentry deferred capture drop alert (`captureMessage` `"sand sentry deferred captures dropped"`, tag `sand.dropped_count`); bot capability classification constants `hN=["all-temporal","has-box-agent"]` (`e.every(t=>t.harness==="temporal") -> "all-temporal"`).
- `main.cjs`: Switched zip extraction to read via `` `/proc/self/fd/${fd}/${name}` `` (secure temporary directory reading).
- `meetings-main.cjs`: Meeting end reason enum (`"Grok Bot closed on the user's computer"` / `"the bot left the meeting"` / `"everyone else left the meeting"`), `ENDED` state enqueueing, and `report.drop` (dropped transcript count alert).
- `proto.cjs`: `SharedAgentStoreListing` (`share_id` / `agent_id` / `store_id` / `path_prefix` / `visibility` / `created_at_ms` / `revoked_at_ms` / `owning_user_id` / `owning_team_id` / `owner_display_name` / `store_kind` / `kind` / `source`); credential fields `credential` / `expiresAtMs` / `credentialHeld`.
