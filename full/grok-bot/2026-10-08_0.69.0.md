# Grok Bot 0.69.0

English | [简体中文](../../zh-CN/full/grok-bot/2026-10-08_0.69.0.md) · [Highlight](../../grok-bot/2026-10-08_0.69.0.md) | **Full Detail**

- **Release Date**: 2026-10-08
- **Platforms**: `mac`, `win`
- **Summary**: Microsoft Teams integration officially launched (Teams app installation, DMs, group chats, and threads); tri-state tool permission modes, local tool scope system, and recurring calendar event validation completed

## Highlights

- **Features**: Teams integration: `AddGrokBotTeamsAppToTeamRequest` (`agent_id` + `team_id`, returning `failure_reason`), message types `TEAMS_DM` / `TEAMS_GROUP_CHAT` / `TEAMS_THREAD`, constants `REMOVED_IN_TEAMS`, `MICROSOFT` enum, and `microsoft-teams-brand-logo`. Meeting join consent: `AdminGetGrokBotMeetingJoinConsent` (`consent_at_ms`), `MeetingJoinAnswer.Remember`, call nudge counters (`nudgeCount` / `answeredNudgeCount`). Recurring calendar event validation (`zod`): `weekly` requires `daysOfWeek`, `monthly` requires either `monthDay` or `weekdayOfMonth`, `yearly` requires `month` + `monthDay`, `interval` upper bound, and IANA time zone validation. Tool permission modes `GrokBotToolPermission = UNSPECIFIED / ALWAYS_ALLOW / NEEDS_APPROVAL / BLOCKED` (paired with `approval-mode-switcher` in UI). Local tool permission scope table: `run-command`, `send-input`, `read-file`, `list-directory`, `write-file`, `read-ai-tool-setup` (`global`), `read-messages` (`setting`), `send-imessage` (`subject`), `run-phone-tool` (`call`, phone call tool); responses `allow-once` / `deny` / `always` / `never`.
- **Protocol / Main Process**: New dependencies `@anysphere/link-preview` (standalone link preview package) and `@tiptap/extensions`; `AbortGrokBotAttachmentUploadRequest` (abort attachment upload); permission scopes `organization.private_inference.manage`, `grok_bot_agent.share` / `view`; telemetry `sand.team_invite.invites_sent` / `link_copied`; setting keys `renderer-recovery` + `crash-loop-dialog` (renderer crash-loop recovery dialog), `system-proxy`, `plugin-data`, `plugin-native`, `team-fresh`, `widget-prompt`, `link-favicon-cache`, `page-http-4xx/5xx/other`, `page-timeout`, `page-network`, `image-cap/network/timeout`, `allow-popups`, `sand-host-bundle`, `store-unusable`, `not-in-store`, `us-east-1`; directory constants `CLAUDE_PLUGIN_DATA` / `CURSOR_PLUGIN_DATA` (reading Claude plugin data directories for Claude plugin ecosystem compatibility); 1Password OAuth copy (`"1Password connection was cancelled."`); environment variable `SAND_NODE_PROXY_ENV`.
- **UI**: `grok-bot-secrets` (secret management page), `top-up-modal-host` (top-up modal host), `team-bot-custom-plugins`, `team-bot-plugins-dialog-list`, `auto-review-selector`, `thread-card`, `gallery-loop` audio, `use-clamp-overflow`.
- **Infrastructure**: Dependencies 91 -> 93 (+`link-preview`, +`@tiptap/extensions`).

## Code & Protocol Details

- `main-app.cjs`: Switched computer-use (`Opt`) MCP app to IPC transport: `ipcMainTransport({ipcMain, senderFacts: D=>({isBoxVncPartition: D.sender.session===t.session.fromPartition(Ij), frameUrl: D.senderFrame?.url??null}), ...})` -- authenticating tool invocations by Box VNC partition session and sender frame URL.
- `main-app.cjs`: Claude plugin ecosystem compatibility: directory constants `zbn=["CLAUDE_PLUGIN_DATA","CURSOR_PLUGIN_DATA"]`, path template `/(?:CURSOR|CLAUDE)_PLUGIN_ROOT\}/g` substitution, and `"plugin-data"` key (reading Claude plugin data directories).
- `main-app.cjs`: Attachment pipeline refactor: chunked reads via `readAttachmentChunk({path, offset...})`, staged commit/drop (`commitStaged` / `dropStaged`), and download failure classification (`invalid-source`, `page-timeout`, and related `errorClass` values reported under `leg:"download"`).
- `main-core.cjs`: Thumbnail service `function qw({decoders={}, removeDir=...rm(recursive,force,maxRetries:3)}={})`: injectable decoders + `createThumbnailFromPath`, returning per-platform `canDecode` / `decode`; page load retry helper `e1` (`did-finish-load` / `did-fail-load`, ignoring error code `-3` and subframes); Sentry log/metric batch flush threshold (800 KB accumulated or periodic flush).
- `onepassword-connection-service.cjs`: Item reference pattern `Zt=/^ops_[A-Za-z0-9_-]+$/`, max length 4096, operation timeouts `sand-onepassword-backend 3e4` / `sand-onepassword-mint 24e4`; removed legacy error code entries (`SAND-E0409` `memorySynthesisInvalidOutput` and `SAND-E0603/0610/0613` desktop series).
- `proto.cjs`: Multipart upload session fields `limitBytes` / `uploadToken` / `sessionExpiresAtMs` / `partSizeBytes` / `partCount`; Teams-related enums (`AnthropicCyberVerificationStatus` / `AnthropicEfsStatus` / `GroupVisibility`) and VM disk pressure fields `diskPressure` / `recreateInFlight` / `updatedAtMs`.
