- **Summary**: First 1.0 GA release: branded release cut from the 0.78.1 stable baseline

## Overview

`1.0.0` is the first `1.0` GA build on the stable channel, locking its code baseline to the `0.78.0` / `0.78.1` milestone (`GrokBotService` at 414 methods, `app.asar` at 894 files, and 115 runtime dependencies) and focusing on stability freeze without introducing exclusive new features.

## Capability Scope & Branch Notes

- **Included capability set**: Covers the full feature set accumulated through `0.78.1`, including cross-device QR code linking, the local execution daemon (`local-exec-daemon`), Orbit computer-use service, iMessage and outbound phone calls, Team Bot credential Vault, JWKS token verification and ML-DSA post-quantum signatures, macOS Mail and Microsoft Teams integrations, and Stripe Link / Shop Pay payment wallets.
- **Subsequent branch merge notes**: Features developed concurrently on the `0.78.2` through `0.79.4` branch — including privacy mode, the training data opt-in popup, e-commerce shopping cart / virtual try-on / flight booking, the Agent Store marketplace, the Realtime voice event stream, and the revamped 1Password vault connector — were not included in this frozen build and were merged together in [1.0.1](2026-11-11_1.0.1.md).
