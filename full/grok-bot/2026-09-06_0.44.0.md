# Grok Bot 0.44.0

English | [简体中文](../../zh-CN/full/grok-bot/2026-09-06_0.44.0.md) · [Highlight](../../grok-bot/2026-09-06_0.44.0.md) | **Full Detail**

- **Release Date**: 2026-09-06
- **Platforms**: `mac`, `win`, `ubuntu`
- **Summary**: Account merging (Account Collapse), team-level agents, and agent secret submission workflow

## Highlights

- **Features**: Account merge runs (`StartAccountCollapseRun`: target_user_id + source_user_ids; `ListCollapseCandidates` candidates / mergeability / match and recommendation reasons; `GetAccountCollapseRun`); team-level agents (`GrokBotTeamAgent` with Session/Routine counts, `AdminListGrokBotTeamAgents` / `AdminDeleteGrokBotAgent`); agent secret request-and-submit workflow (`SubmitGrokBotSecret`: agent_id + entry_id + value + session_id); cloud onboarding heuristic environment setup (`StartCloudOnboardingHeuristicEnvSetup`: scm_provider + excluded repository list, `CloudOnboardingAutoEnvSetupAcceptResult`); team member SandBox migration status and recreation (`GetTeamMemberSandBoxMigrationStatus` / `RecreateTeamMemberSandBox`); `SandAutoReviewControls` (auto-review enforcement toggle).
- **Protocol / Main Process**: Large batch of new channels and keys — `egress-tunnel` (outbound tunnel with reconnect policy `sand-egress-tunnel-reconnect`), `health-probe`, `login-poll`, `marketplace-fetch` / `marketplace-token`, `spend-initiation` (spend-initiated transcript entry kind), `weekly-usage`, `secret-request`, `auth-policy-recheck`, `auth-cleanup-remove`, `daemon-discovery`, `desktop-status`, `dev-controls` / `dev-restart-exit`, `box-env`, and `channel-credential` / `credential-post`; persistence keys `roster.agent-avatars` / `roster.last-roster` / `selection.last-agent` / `sidebar.last-sections` / `transcript.replicas`; anyrun-side `RawEgressProxyAuth`; Linux desktop integration `grok-bot-appimage` / `xdg-mime` / `mimeapps.list`.
- **UI**: `anchored-popup`, `settled-message-card`, and `provider-local-tool-permission` (local tool authorization card) components; refined Slack reinstall/uninstall outcomes (RECREATE_REQUIRED / PENDING_ADMIN_APPROVAL / RATELIMITED / MANAGER_REAUTH_REQUIRED, etc.).
- **Infrastructure**: Added `STEP0_BAKE_OVERLAY` / `STEP0_LIVE` (box environment baking steps) and SSO_SCIM / DOMAIN_CAPTURE organization account classification constants; removed `SAND_DATA_ROOT`, `binding-cleanup`, and `confirmation-failed`.

## Code & Protocol Details

- `main-app.cjs`: Linux AppImage self-update subsystem — added `SandAppImageInstaller` (staging directory prefix `.sand-update-`), `appImagePathFromEnv()`, and startup wiring `appImage: new MN({ appImagePath, relaunchArgs: process.argv.slice(1), quit })`; added `SandCursorSecureStorageSettlement` (`storedSignInTimeoutMs` timeout, `decideForNullPair()` resolving signed-out/signed-in state, `[sand] dev-login: ${kind} as ${email}` log reporting); expanded WebAuthn (`requestWebAuthnConsent/requestWebAuthnPin`, PIN-related references 4→12 occurrences); token refresh circuit breaker `refreshPauseHolds()` — skipping refresh while `refreshFailureStreak.pausedUntilMs` has not elapsed; on ConnectError `Unauthenticated`, invokes credential re-fetch callback before rethrowing.
- `main-core.cjs`: Sentry/OTel additions (`spanToTransactionTraceContext`, `dsnFromComponents`, replay failure wrapper, `shouldContinueTrace`); platform diagnostics add `APPIMAGE`/`XDG_DATA_HOME`/`XDG_DATA_DIRS`/`XDG_CONFIG_HOME`; file type classification helper (`"pdf"→pdf`, remaining extensions mapped via sets to table/json/markdown/html).
- `proto.cjs`: Account merge `StartAccountCollapseRunRequest` (target_user_id + source_user_ids, match reason enum SESSION/PREVIOUSLY_LINKED/MATCHING_EMAIL/SAME_WORKOS_ID, 0→6 occurrences); `GrokBotPluginScope` (agent_id + session_kind); box environment baking enum `STEP0_LIVE`/`STEP0_BAKE_OVERLAY`/`TURN_DONE_RECOMPUTE`; onboarding fields `setup_handled_by_server`/`conversational_setup_enabled`/`getting_started_trusted`; removed PR agent cost control fields (`max_main_agent_cost_cents` 2→0, `cost_controls_available` 1→0, `max_runs_per_pr` 2→0).
