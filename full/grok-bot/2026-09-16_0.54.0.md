# Grok Bot 0.54.0

English | [简体中文](../../zh-CN/full/grok-bot/2026-09-16_0.54.0.md) · [Highlight](../../grok-bot/2026-09-16_0.54.0.md) | **Full Detail**

- **Release Date**: 2026-09-16
- **Platforms**: `mac`, `win`
- **Summary**: Bots can read email attachment contents (`ReadGrokBotEmailAttachment`); added credential change notifications

## Highlights

- **Features**: Extended email integration to attachments: `ReadGrokBotEmailAttachmentRequest` / `Response` returns attachment text or bytes, with `GrokBotEmailAttachmentText` carrying a `truncated` flag.
- **Protocol / Main Process**: Added setting key/event `credentials-changed` (credential change broadcast); added `ProjectsSettings` (`enabled` field) in proto; added error messages `"MCP server ID must be a decimal string."` and `"The secret was not saved."`.
- **UI**: No major changes.
- **Infrastructure**: No dependency additions or removals.

## Code & Protocol Details

- `main-app.cjs`: No functional changes in the main process.
- `proto.cjs`.
- `renderer/prompt-editor`: TipTap node schema added HTML attribute serialization for `label` / `status` (`parseHTML: n=>n.getAttribute("data-label"/"data-status")`, written back via `renderHTML`) and `id` (`data-id`), allowing prompt editor nodes to carry rich-text label/status/ID attributes.
