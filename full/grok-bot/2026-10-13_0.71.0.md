# Grok Bot 0.71.0

English | [简体中文](../../zh-CN/full/grok-bot/2026-10-13_0.71.0.md) · [Highlight](../../grok-bot/2026-10-13_0.71.0.md) | **Full Detail**

- **Release Date**: 2026-10-13
- **Platforms**: `mac`, `win`
- **Summary**: Added disconnect watchdog and messages worker to the local execution daemon, laying the groundwork for local Computer Use (CUA)

## Highlights

- **Features**: Added `@anysphere/agent-store-ids` dependency (Bot store ID system); added `messages-worker.cjs` messages worker to `local-exec-daemon`; added `SendToAgentRecipient.Kind=MAIN_BOT` in proto (recipient model for "Send to Agent"); added `GLASS_CLOUD_AGENT` / `GLASS_DIFF` / `GLASS_AUTOMATIONS` source enum values to the GitHub connection flow (Glass-initiated GitHub connections).
- **Protocol / Main Process**: Added telemetry event `sand.local_exec_daemon.watch_outage` (outage reason enum: `lifetime` / `stall` / `silent` / `network-change` / `error` / `unauthorized` / `channel-missing` / `gateway-unreachable`); added attachment protocol string `sand.attachment.read` (forming the attachment read/write pipeline alongside `commit` / `edge_failed`); added internal endpoint `https://gtm-api.corp.anysphere.co` (co-located with the `google-workspace` connector OAuth registry as the Google Workspace connector gateway); added feature gate `sand_enable_local_cua` and `admin-group-check` (checking admin group membership as a prerequisite for local Computer Use); added `deb` / `rpm` package update checks (`apt-cache policy grok-bot` / `dnf`).
- **UI**: Added `auto-review-approval` (auto-review approval) and `provider-computer-use` components in the renderer; expanded Slack copy (`"Connect Slack"`, error prompts when recovery fails after sending a Bot draft or adding a reaction); added Canvas sharing principals (`CanvasAccessPrincipal` `user_id` / `group_id`) and corresponding error copy.
- **Infrastructure**: Added `@anysphere/agent-store-ids`; Electron version unchanged.

## Code & Protocol Details

- `proto.cjs`: Landed payment card vault data models ahead of UI -- added `GrokBotVaultCard|brand/last4/exp_month/exp_year/holder_name/billing_address`, `GrokBotVaultCardBillingAddress|line1...phone`, `UpdateGrokBotVaultCardRequest|id/holder_name/expiry/billing_address`; added `SendToAgentRecipient` (`Kind` including `MAIN_BOT`) and `SendToAgentArgs/Success` (`worker_bc_id/delivered_as/recipient`); added full `tracked-tasks` proto suite (`NewTrackedTask` / `TrackedTaskView` / `TrackedTaskUpdate` / `TrackedTaskConflict` / `TrackedTaskLink*` / `ListTrackedTasks*` / `DeleteTrackedTasksSuccess`); added Canvas sharing permission models `CanvasShareAccessState` / `UpdateCanvasShareAccessRequest` / `GrokBotAccessPrincipal` (`user_id` / `group_id` / `organization+role`); added enum `McpConnectorAuthState` (`SIGNED_IN` / `SIGNED_OUT` / `UNAVAILABLE`); added `|8 local_tool_app_consent|9 local_tool_grant_seen` to `GrokBotUserComputerCapabilities` (local tool grant confirmation bits).
- `main-app.cjs`: Built card data payload `{card:{brand,last4,expMonth,expYear,holderName,billingAddress:{line1,line2...}}}` (`holderName` / `billingAddress` had 0 occurrences in 0.70.2); changed `SetGrokBotAgentVisibilityOutcome.UNSPECIFIED` from a silent return to `throw new vi("SetGrokBotAgentVisibility returned no outcome")`; added `prefers-color-scheme` media query parser (determining `light` / `dark` from CSS media strings); removed `|7 meeting_join` field from `ResolveGrokBotAutoReviewApprovalRequest`; extended Slack installation status proto for multi-workspace support (`needs_manifest_update` / `pending_reinstall_approval` / `oauth_authorize_url`).
- `main-core.cjs`: Three-variant configuration for the Computer Use helper app -- prod `grok-bot-computer-use/CUGrokBotService`, `lab:{appName:"Grok Bot Lab Computer Use",bundleId:"co.anysphere.grok-bot-lab-computer-use",executable:"CUGrokBotLabService"}`, and an isomorphic dev variant; added window navigation guard `Dg(e,{openExternalUrl})` (`setWindowOpenHandler` + `will-navigate` + `will-frame-nav` blocking all external navigation); added crash-loop counters `case "blank_window":return{}` / `case "crash_loop":return{[FO.key]:e.reloads}`.
- Other: Feature gates `sand_enable_local_cua` (x3) and `admin-group-check` are new in this release; `watch_outage` telemetry resides inside the unextracted `local-exec-daemon`.
