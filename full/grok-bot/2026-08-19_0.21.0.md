# Grok Bot 0.21.0

- **Release Date**: 2026-08-19
- **Platforms**: `mac`, `win`
- **Summary**: First release of the Windows channel (`win` begins at 0.21.0 per the desktop release index); no per-version release notes were published.

## Release Notes / Findings

- The Grok Bot desktop client (internal package name `sand`, bundle id `co.anysphere.sand`) shipped through a fast preview cadence in August 2026: versions 0.16.0 through 0.23.0 were published between 2026-08-11 and 2026-08-20, in the ten days before 0.24.0 (2026-08-21), which is the first build captured by the stable-CDN reverse-engineering archive and the baseline of that archive. No per-version release notes for these preview builds were found in any public source consulted (see Data Source & Limitations).
- Distribution scheme: the desktop installer is served from `downloads.cursor.com` (updater feed base `https://api2.cursor.sh/updates`, update path pattern `/api/update/<os>/<arch>/<version>/stable`; CDN package paths of the form `grokbot/stable/<platform>/<version>/Grok_Bot_<version>.dmg` and, for the current channel, `sand/stable/darwin-arm64/<version>/Grok_Bot_<version>.dmg` as tracked by the Homebrew cask `grok-bot`).
- Per the desktop release index, the `win` channel begins with this version (Windows package path family `grokbot/stable/win32-x64/<version>/Grok_Bot_<version>_Setup.exe`; the path scheme is confirmed by Wayback observations for adjacent versions).
- Nearest documented successor: the 0.24.0 baseline (first archived stable build, 2026-08-21) already contained the full agent runtime suite (`@anysphere/agent` / `agent-core` / `agent-exec` / `agent-kv` / `agent-store-sync` / `agent-summarization` / `agent-transcript`), chat inference, local and MCP execution (`local-exec` / `shell-exec` / `mcp-agent-exec` / `mcp-core`), box sandbox, virtual filesystem, the full Google Workspace OAuth scope suite, Slack, and an MCP server directory (memory/notion/playwright/salesforce/stripe/telegram/todoist/zoominfo etc.), plus early foundations for connector, marketplace, computer-use, and secret-store domains. These domains were present in 0.24.0, so the 0.16.0-0.23.0 window plausibly carried earlier forms of the same app; attributing any specific change to this release alone is not possible from available sources.

## Data Source & Limitations

- Reverse-engineering cross-reference (binary archive, supporting evidence only): the stable-CDN archive begins at 0.24.0 (2026-08-21), so 0.16.0-0.23.0 binaries are not available for per-version diffing.
- winget (`microsoft/winget-pkgs`, package `xAI.GrokBot`): manifests begin at 0.57.1 — no release notes exist for pre-0.57 versions (GitHub contents API listing, checked 2026-11-12).
- Wayback Machine CDX for the desktop distribution hosts (queried 2026-11-12): snapshots exist for the `downloads.cursor.com/grokbot/stable/...` package path family (partial listing — the full listing query was cut off by repeated Internet Archive temporary outages); no snapshots found for the official pages `cursor.com/grok-bot*`, `cursor.com/download/bot*`, or `docs.x.ai/grok-bot*` (queried while the archive was reachable); the `grok.com/changelog*` and update-feed (`api2.cursor.sh/updates/*`) queries could not be completed because of those outages and a DNS-restricted querying environment.
- Homebrew cask `grok-bot` (token exists; homepage `https://x.ai/bot`; autobump; tracks the same CDN) confirms the distribution URL scheme but carries no release notes.
- Conclusion: no per-version release notes were published for this build; the entry above is deliberately limited to verifiable release-context facts (better to omit than to fabricate).
