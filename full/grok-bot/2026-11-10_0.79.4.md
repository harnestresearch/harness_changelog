# Grok Bot 0.79.4

English | [简体中文](../../zh-CN/full/grok-bot/2026-11-10_0.79.4.md) · [Highlight](../../grok-bot/2026-11-10_0.79.4.md) | **Full Detail**

- **Release Date**: 2026-11-10
- **Platforms**: `mac`, `win`, `ubuntu`
- **Summary**: Fixed MCP Loopback OAuth Google sign-in callback timeouts and added a feature flag to preserve the plugin catalog across team switches

## Protocol & Main Process

- **MCP Loopback OAuth callback timeout fix**: Refactored the main process loopback OAuth completion path and `ConnectError` classifier (distinguishing `completion_timeout`, `admin_blocked`, `fresh_sign_in_required` [with `stepUpUrl`], `provider_account_required`, and `client_rejected`); added a `continuation` expiration branch that logs `[sand:mcp] loopback OAuth Google sign-in follow-up expired with no callback` and sets `expired = true` to abort waiting promptly when the Google sign-in follow-up times out without receiving a callback.
- **Team-switch plugin catalog flag**: Added feature flag `grok_bot_desktop_catalog_team_switch` (`keepsNewerTeamCatalog`) plumbed through to the plugin marketplace client to control whether a newer team plugin catalog is retained when switching teams.
- **Metadata validation refinements**: Tightened the OAuth protected resource metadata schema (`resource` / `authorization_servers` / `jwks_uri` / `scopes_supported` / `bearer_methods_supported`) and missing required plugin field error copy.

## UI & Connector Assets

- Added a `noteTeamChanged` callback to the frontend plugin catalog store to automatically refresh the catalog after switching teams.
- Added built-in icon mappings for the `outlook`, `outlook-calendar`, and `onedrive` connectors.
