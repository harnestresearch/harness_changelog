# Grok Bot 0.46.0

English | [简体中文](../../zh-CN/full/grok-bot/2026-09-09_0.46.0.md) · [Highlight](../../grok-bot/2026-09-09_0.46.0.md) | **Full Detail**

- **Release Date**: 2026-09-09
- **Platforms**: `mac`, `win`
- **Summary**: Major release: 1Password credential integration, GitLab/Bitbucket/Azure DevOps connectors, `sand-canvas`/`sand-media` custom protocols, and app auto-update infrastructure (+269 files in zip)

## Highlights

- **Features**: 1Password connection (new main-process file `onepassword-connection-service.cjs`: `BeginOnePasswordConnection` / `CompleteOnePasswordConnection` / `DeleteOnePasswordConnection`, credential request approval/denial `ApproveOnePasswordCredentialRequest` / `DenyOnePasswordCredentialRequest`, `setOnePasswordAlwaysAllow`); SCM connectors expanded with `gitlab` / `bitbucket` / `azure-devops` (previously github/origin/slack only); webhook notifications (config keys `webhook-url` / `webhook-key` / `webhook-header`, events pr-opened/pushed/merged/closed, review-requested/approved/commented, ci-passed/failed, issue-assigned); Cursor/Grok account unification flow (`CompleteUnifyGrokOAuth`, `GetUnificationIntent`, `FinalizeIndividualUnification`); Background Composer desktop lease (`BackgroundComposerDesktopLease` ACQUIRE/RELEASE); box harness migration (`EnsureGrokBotBoxHarnessMigrationPass` plus status/clear-hold suite); PR agent (`GetPrAgentContext`); team data export (`CreateTeamDataExportDownloadUrl`); cloud agent plugin marketplace (`GrokBotAgentPlugin` / `GrokBotAgentMarketplace`, `GetGrokBotAgentPlugins`).
- **Protocol / Main Process**: Enum `MCP_SERVED_BY_GROK` (alongside `MCP_SERVED_BY_CURSOR`); `voice-realtime` channel (allowing HTTPS real-time voice connections to DIALABLE_ORIGIN); custom URL schemes `sand-canvas` and `sand-media` (registerSchemesAsPrivileged); auth domains `https://authenticator.cursor.sh`, `https://prod.authentication.cursor.sh`, and `https://downloads.cursor.com`; updater keys `update-status` / `update-channel` / `automatic-updates` / `update-computer` / `reset-computer`; network diagnostics `network-debugger` and probe keys `api-dns` / `api-tls` / `computer-dns` / `computer-tls`; five notification sound cues (ping-1-open-blip … ping-5-chime-b); user form dismissal `DismissGrokBotUserForm` (DESKTOP/IOS); cloud computer Messages consent (`GrokBotUserComputerMessagesConsent` family).
- **UI**: `plugins-rows` and `provider-credentials` components, plus `auth-page` / `auth-ui` authentication screens.
- **Infrastructure**: Removed `https://api2.cursor.sh`, K8s attribute constants (ATTR_K8S_*), and `cursor-box-computer` / `cursor-box-shared` identifiers; added numerous policy classification constants including TEAM_POLICY / REGISTRABLE_DOMAIN / ESCALATED.

## Code & Protocol Details

- `onepassword-connection-service.cjs`: Brand-new file (0→65550 bytes) implementing the end-to-end 1Password service account connection flow (Begin/Complete/Delete Connection, credential request approval/denial).
- `main-app.cjs`: Plugin marketplace client takes shape — `GrokBotPluginsWireError` (extending `SandDomainError`) and plugin listing mapping (displayName/description summaries); `recordLocalToolStandingGrant` (0→2 occurrences) persisting local tool "always allow" standing grants after machineId + action(subject) validation; trimmed enterprise usage panel — removed `fetchEnterpriseUsage` (1→0), enterpriseTeamIdOf/dailySpendOf, and the `Date.parse("2025-11-20T08:00:00Z")` monthly cycle calculation (`GetSandTrialClaimStatus` retained).
- `main-core.cjs`: Diagnostics enhancements — moved `open-cdp-missing` detection from `main-app` into `core` (monitors-reached check: `t>0 && r===0` indicates Chrome is open with CDP missing); new error code `SAND-E0418 turnBackendUnreachable` (retryable, "Turn never reached the Cursor backend: the transport failed on a Node system error..."); OTel span symbol constants (`otel.span`/`otel.root_span`/`otel.suppress_child_spans`).
- `proto.cjs`: `BeginOnePasswordConnection` (0→4 occurrences), 1Password credential entries (`credential_id/title/category/sites/target_rules`), and credential lifecycle fields (`credential_generation/issued_at_ms/expires_at_ms/renew_by_at_ms/reminder_at_ms`); `GetUnificationIntent` (enabled + intent{mintTicket, connectionId, expectedGeneration, expirationMode, providerExpiresInSeconds...}); `BackgroundComposerDesktopLease`; `InstallGrokBotSlackAppResponse` (outcome + slack_team_id + workspaces + needs_manifest_update).
