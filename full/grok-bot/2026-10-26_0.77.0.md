# Grok Bot 0.77.0

English | [简体中文](../../zh-CN/full/grok-bot/2026-10-26_0.77.0.md) · [Highlight](../../grok-bot/2026-10-26_0.77.0.md) | **Full Detail**

- **Release Date**: 2026-10-26
- **Platforms**: `mac`, `win`, `ubuntu`
- **Summary**: Connected cross-device capabilities ("device linking + local execution daemon + iMessage / outbound phone calls") and launched Bot share invites alongside the usage and billing page

## Highlights

- **Features**: Device linking (QR code + `https://cursor.com/grok-bot/link/v1/` deep links supporting `agent`/`bot-template`/`marketplace`/`plugin`/`add`/`prompt`/`referral`/`settings` paths, plus a `/finance` endpoint routed through `StartFinancialLink` financial account linking); iMessage draft sending tool (`imessage-draft`, carrying a `machineId`/`approvalId` approval flow); outbound phone call recording (RPC `/aiserver.v1.GrokBotService/OutboundCallRecording`); voice dictation (`dictation-text` event, dedicated `TranscriptionManager` dictation entry point); standalone computer-use service **Grok Bot Orbit Computer Use** (`bundleId` `co.anysphere.grok-bot-orbit-computer-use`, executable `CUGrokBotOrbitService`); xAI commerce payments (`XaiCommerceBearerPurpose` = `BROWSER_COMMERCE`/`PREPAID_TOP_UP`), order tracking state machine (`placed`/`in_transit`/`arriving_today`/`delivered`/`delayed`/`cancelled`), and structured `merchant`/`shipTo`/`tracking` fields.
- **Protocol / Main Process**: New permission keys `messages-send`, `messages-send-without-asking`, `messages-allowed-recipients`, and `read-messages`; new settings sections `linked-numbers`, `your-computer`, `manage-devices`, `computer-use`, `team-bots`, `contacts`, `usage-and-billing`, `usage-resets`, `personal-usage`, `unified-plan`, and `call-recording`; background service descriptors `gateway`, `passkey-provider`, and `local-exec-refresh`; `device-tools/<op>` RPC (with `installDir`/`launch` for invoking local device tools remotely); full `sand.bot_share.invite_*` telemetry suite (Bot share invites), `sand.desktop.referral_code_shared`, and `sand.desktop.sidecar_launch`; protocol additions `ConversationMessage.ThinkingStyle` and `conversation.item.delete`.
- **UI**: `agent-invite-dialog`, `bot-share-popover`/`trigger`/`invite-popover`, `bonfire-dialog`, `desktop-mount-panel`, `agent-avatar-editor`, `sand-store-page`, and `manage-plan` / usage & billing page.
- **Infrastructure**: Added dependencies `@anysphere/attention-count`, `@anysphere/device-local-tools`, `@anysphere/jpeg-napi` (native JPEG module), `@anysphere/sand-playwright-runtime`, `@sand/local-exec-daemon`, `@sand/local-exec-protocol`, `@sand/primitives`, `@sand/shared-node`, `qrcode`, and `sand-address-lookup` (native URL/address parser accompanied by URL standard error strings such as `dot-segment`/`percent-encoding`); removed `mermaid`; **retired Chrome data import** (deleted `chrome-import-worker.cjs`, removing `chrome-safe-storage`/`profile-cookies`/`list-profiles`/`open-cdp-*` strings across the board).

## Code & Protocol Details

- `main-app.cjs`: (1) Enveloped tool execution results — the runner now returns `{ok:!0, value: await u.run(E,h,r)}` / `{ok:!1, failure:{code, detail}}`, structuring errors by `dt` class `code`/`detail` instead of throwing directly; (2) added 1Password keyless OAuth callback handler `EOt` with `createDeadlinePolicy({name:"sand-onepassword-oauth-keyless-callback", timeoutMs: keylessCallbackGraceMs ?? wsr})` and open/abort lifecycle; (3) integration catalog data `[{platform:"github", displayName:"GitHub", blurb:"Let automations watch a repo's PRs, comments, issues, and CI."}, {platform:"origin", ...}, Slack/...]`; (4) Markdown tag allowlist mapping `[["strong","strong"],["i","em"],["s","del"],["strike","del"],["sub","sub"],["sup","sup"],["mark","mark"],["br","br"]]` replacing the legacy Slack thread return-value parser block; (5) passkey ceremony state machine: `pending/completed->null, failed, expired` mapping + `createDeadlinePolicy({name:"passkey-ceremo..."})`; (6) OS notification read state `{readings, unreadThreads}` and `reportDesktopEdgeFailure("os-notifications","read",...)` (net new); (7) Bot share invite telemetry `invite_sent/invite_link_opened/invite_dialog_shown -> sand.bot_share.*` (net new); (8) `listSharedAgentStores` cursor pagination (`ListSharedAgentStoresScope.TEAM` + `createdBeforeMs/createdBeforeShareId`, ~174 tokens); (9) removed `presentCookieOriginApproval` (`chromeCookieImport` approval entry point on the main process side of the Chrome import retirement).
- `main-core.cjs`: Landed account-scoped settings storage — `settingsOwnerScope/getHoldingAccountScope/accountScopedSettingsFor` (with `signedOutHeir` fallback); `open-url` event wrapper (normalizing handler inputs via `jb` to unify deep link entry points); window geometry persistence schema `ETe = {version:1, normalBounds, isMaximized}` (`safeParse` validation).
- `main.cjs`: Added `X(e){return e.sandOrbit===!0}` (Orbit service instance check) and `new URL(t.backendUrl).host.replace(/[^A-Za-z0-9.-]/g,"_")` (`backendUrl` hostname sanitization).
- `proto.cjs`: `ListGrokBotUserStoreFilesResponse`, `GrokBotAgentAccessInviteState` (`OPEN`/`ACCEPTED`/`EXPIRED`/`REVOKED`) + `RecipientMatch` (invite state machine), shipping address message (`line1`/`line2`/`city`/`region`/`postalCode`/`country`/`name`/`phone`), `PluginTeamAdminInstallBlockReason` (`MCP_ADMIN_POLICY`/`FIRST_PARTY_ALLOWLIST`/`TEAM_LIST`/`SHAREPOINT_TEAM_ONLY`), and `expectedCurrentPeriodStartMs` (billing-period drift guard).
- `proto.cjs`: Connector credential state machine took shape — three credential sources (`per-user` / `service-account` / `delegated`), states (`active` / `needs-reconnect` / `turned-off-by-admin` / `delegator-inactive` / `delegator-disconnected`), and credential actions (`connect-service-account` / `use-delegated-auth` / `replace-delegated-auth` / `remove-credential`), completing the protocol for delegated team connector credential management.
