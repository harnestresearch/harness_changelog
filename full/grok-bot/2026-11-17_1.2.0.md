## Overview & Evidence Scope

Official update API endpoints (`https://api2.cursor.sh/updates/api/download/stable/{linux-x64|win32-x64-user|darwin-arm64}/sand`) report `version: "1.2.0"` and unified commit `cf0aa5097b8fdfea8f2ecd33ce9f71a72655ef08` (`package.json` `name: "sand"`, `version: "1.2.0"`). On Linux, `downloads.cursor.com/aptrepo` `dists/stable/main/binary-amd64/Packages` currently no longer lists `grok-bot` (listing only `cursor` packages), so `grok-bot_1.2.0_amd64.deb` (`117,298,800` B) is served via the update API's `debUrl`.

All technical findings below derive strictly from static comparison of the downloaded **Linux `x64` `.deb`** and **macOS `arm64` `.dmg`** packages against `1.1.0` without executing the application; Windows `Setup.exe` was verified only via update API + `HEAD` metadata, `darwin-x64` and Linux `AppImage` were not analyzed, and static presence of client RPC descriptors, preload bindings, Statsig gates, or i18n strings does **not** establish backend rollout or live runtime availability. Inside `app.asar` (`860 → 868` files: raw `+499 / −491`, including `484` Vite renderer chunk hash rotations; net `+15` additions and `−6` removals), `proto.cjs` grows `1,730,908 → 1,754,188` B (`+23` KB), `main-core.cjs` expands `1,214,411 → 1,647,849` B (`+433` KB, `+36%`), `main-app.cjs` shrinks `3,770,636 → 3,261,318` B (`−509` KB, `−13.5%`), `preload.cjs` grows `160,046 → 173,889` B (`+14` KB), `node-agent-coordinator/main.cjs` grows `1,428,758 → 1,451,909` B (`+23` KB), `local-exec-daemon/main.cjs` grows `3,472,851 → 3,503,466` B (`+31` KB), and `messages-worker.cjs` moves `121,022 → 121,313` B (`+291` B).

## Key Static Changes by Subsystem

- **Slack Workspace Install State Machine & Per-Bot Third-Party Connections**
  - Added 3 `GrokBotService` `Unary` RPCs—`GetGrokBotSlackWorkspaceInstall`, `StartGrokBotSlackWorkspaceInstall`, and `UninstallGrokBotSlackWorkspaceInstall`—with messages `GrokBotSlackWorkspaceInstallRow`, `GrokBotSlackWorkspaceInstallTeamState`, and `GrokBotSlackWorkspaceInstallPendingStart`, enums `GrokBotSlackWorkspaceInstallStartOutcome` (`STARTED`, `ALREADY_INSTALLED`, `NOT_CONFIGURED`), `GrokBotSlackWorkspaceInstallState` (`INSTALLED`, `UNINSTALLED`), and `GrokBotSlackWorkspaceInstallUninstallOutcome` (`UNINSTALLED`, `NOT_INSTALLED`, `RATELIMITED`, `SLACK_REJECTED`), plus i18n copy `"Connect Slack"` and `"Return to Slack"`.
  - Added 2 `Unary` RPCs—`ListGrokBotThirdPartyConnections` and `DisconnectGrokBotThirdPartyConnection`—with `GrokBotThirdPartyConnection`, `GrokBotThirdPartyConnectableApp`, and `GrokBotThirdPartyConnectionBot` for per-Bot listing/revocation of third-party app authorizations, paired with Statsig gate `grok_bot_connected_apps_settings` and renderer chunks `chunk-connector-auth-action` and `chunk-link-flow`.
- **Skill Revisions, Rollback & Team Publishing Surfaces**
  - Added 2 `Unary` RPCs—`ListGrokBotSkillRevisions` and `RevertGrokBotSkill`—backed by `GrokBotSkillRevision` and enum `GrokBotSkillRevisionAuthor` (`BOT`, `PERSON`), renderer chunk `chunk-skill-change-diff`, Statsig gate `grok_bot_skill_links_in_chat`, and i18n strings `"Imported skill"`, `"Publishing a skill needs a Cursor team…"`, `"Your team admin has turned off publishing for members…"`, `"Add a description before publishing — it is how teammates and agents know when to use this skill"`, and `Publish {slug}?`.
- **Public Changelog RPC, Paper Terms, Shopping Order State, Messaging & Agent File Store**
  - **Public Changelog**: Added `ListPublicGrokBotChangelog` (`Unary`) with `PublicGrokBotChangelogEntry` and `PublicGrokBotChangelogItem`, introducing a client-facing read-only counterpart to `1.1.0`'s 6 internal `*GrokBotChangelogEntry*Internal` operator RPCs.
  - **Paper Terms**: Added internal `GetGrokBotPaperTermsInternal` / `SetGrokBotPaperTermsInternal` (`Unary`) + `GrokBotPaperTerms`, and exposed `GetGrokBotTermsSeenResponse.2 covered_by_paper_addendum` to clients.
  - **Shopping & Messaging**: Added `GetGrokBotShoppingOrderState` (`GrokBotShoppingOrderState`, complementing existing `"Order placed"` / `"Order cancelled"` / `"Track package"` / `{merchant} order {orderNumber}` copy), `GetGrokBotMessagingContactPhoto`, and internal admin line-migration `AdminMoveGrokBotMessagingUserLines` (`AdminGrokBotMessagingUserLineMove`, `AdminGrokBotMessagingLineMoveTarget`).
  - **Agent File Reads & File Store**: Added `ResolveGrokBotAgentFileReads` (`Unary`), enum `GrokBotAgentFileStore` (`BOT`, `USER`), `GrokBotAgentDefinition.12 profile_records[]` (`GrokBotAgentDefinitionProfileRecord` / `GrokBotAgentDefinitionProfileOutcome`), Statsig gates `grok_bot_files_open_preview`, `grok_bot_library_tree`, and `grok_bot_library_writes` (`grok_bot_files_in_agent_store` already existed in `1.1.0`), and renderer chunks `chunk-file`, `chunk-file-type-vsc`, and `chunk-file-icon-component-table`.
- **MCP Security, Team Allowlists, Connectors-Only Mode, Microsoft 365 Admin Consent & Squarespace**
  - **SSO & Block Reason Metadata**: Extended `GetAvailableMcpServersResponse.McpServerInfo` with `35 grok_sso_sign_in` (`bool`) and `36 blocked_reason_text` (`McpBlockedReasonText`), `CheckHttpMcpStatusResponse.ServerStatus` with `15 grok_sso_sign_in`, and `McpServerAddSurfaceCheck` with `3 by_off_rule`.
  - **Team Allowlist & Connectors-Only Access**: Extended `GetTeamAdminSettingsResponse` with `115 mcp_allowlist_enabled_stored` and `116 mcp_allowlist_rule_save_turns_on`, and `GetSandAccessStatusResponse` with `22 grok_connectors_only_allows` (`repeated string`) and `23 grok_connectors_only_builtin_entries[]` (`SandBuiltinCatalogEntry`), consumed by `grokConnectorsOnly` in `main-app.cjs` (`31914–31938`) to populate connector configuration.
  - **Built-in Connectors & Microsoft 365**: Added `mcp.squarespace.com` to the built-in connector host registry in `main-app.cjs`; added 5 Microsoft 365 SVG icons (`microsoft-excel` and `onedrive` / `outlook` / `power-bi` / `sharepoint` SVGs) plus `messages-app-icon.png`, tenant admin-consent i18n copy (`"Your organization's Microsoft 365 admin needs to approve this app. Send them this approval link…"` with `adminConsentUrl`, `"Continue to Microsoft sign-in"`, `{serverName} is blocked by your organization`), gates `grok_bot_connector_account_sheet` and `grok_bot_hide_custom_connector_add`, and `chunk-gallery-connector-actions`.
