# Grok Bot 0.63.0

English | [简体中文](../../zh-CN/full/grok-bot/2026-09-29_0.63.0.md) · [Highlight](../../grok-bot/2026-09-29_0.63.0.md) | **Full Detail**

- **Release Date**: 2026-09-29
- **Platforms**: `mac`, `win`, `ubuntu`
- **Summary**: Generalized rename of voice call harness; added agent library docs API and conversational "queued acknowledgment" prompts

## Highlights

- **Features**: Renamed `@anysphere/grok-bot-voice-call-harness` to `@anysphere/voice-call-harness` (extracting the voice call domain from Grok Bot-specific code into a general-purpose harness). Added `TEMPLATE_IMPORT` / `TEMPLATE_SHARE` / `CARD_ACTION` / `PLUGIN_SETUP` / `TEACH_RECORDING` (template import/share, card actions, plugin setup, and "teach it" recording) to `GrokBotUserMessageInitiator`.
- **Protocol / Main Process**: New RPCs: `ListGrokBotLibraryDocs` (agent document library), `ReadGrokBotGroupChatDocument` (group chat document, including `assets`), `McpRecovery.Outcome` (MCP recovery outcome), `CheckHttpMcpStatus` (HTTP MCP health check). New keys: `dune-telemetry`, `dune-submit-rows`, `dune-submit-trace` (replacing `dune-otlp-export` / `render-trace`), `open-external`, `server-name-lookup`, `component-effects`; environment variable `NODE_USE_SYSTEM_CA` (Node using system CA store). Embedded voice call behavioral prompts in the main process: `"The job is under way. Keep talking with a natural question or a suggestion. Do not announce that you started."` and `"This request is waiting behind work already on the call..."` (guiding spoken responses while work is queued).
- **UI**: Agent capability self-description copy `"Files, the web, the browser, mail, chat, and their computer"`.
- **Infrastructure**: Dependency count unchanged at 88 (+1 / -1); Electron unchanged.

## Code & Protocol Details

- `main-core.cjs`: System certificate reader launched: child process returns certificate list (error handling for `"The system certificate reader returned a non-string list."` / `"...exited"`), injecting results into the Electron session via `setDefaultCACertificates([...o])` -- implementing `NODE_USE_SYSTEM_CA` in the main process.
- `proto.cjs`: Added new request type in `agent.v1`: `query` + `allowedXHandles:[]` + `excludedXHandles:[]` (search requests filtered by X handle allowlist/blocklist).
- `main-app.cjs`: Added `VoiceCallSessionTools.worded(t,r)`: overrides voice tool `description` and per-parameter descriptions from configuration (active only for allowlisted `CO(t.name)`) -- enabling server-customizable voice call tool wording; refactored `callTool` dispatcher from `this.args.tools` to constructor-injected `this.tools` (dependency injection refactor with unchanged `unknown_tool` / `invalid_input` / `served` branches).
