# Grok Bot 0.78.0

English | [简体中文](../../zh-CN/full/grok-bot/2026-10-27_0.78.0.md) · [Highlight](../../grok-bot/2026-10-27_0.78.0.md) | **Full Detail**

- **Release Date**: 2026-10-27
- **Platforms**: `mac`, `win`
- **Summary**: Introduced `jose`/JWKS token verification and ML-DSA post-quantum signatures, expanding the tool permission model to mail, phone, and app control

## Highlights

- **Features**: macOS Mail setup wizard (`mac-mail-setup-dialog`) and Microsoft Teams integration components; expanded `GrokBotPaymentWallet` payment wallet enum with `STRIPE_LINK` and `SHOP_PAY`; added `@sand/sand-eval-runner` (evaluation runner) and `tldts` (domain / public suffix parsing for commerce and domain security validation).
- **Protocol / Main Process**: Added `send-mail`, `use-app`, and `run-phone-tool` to the tool permission catalog (paired with `allow-once`/`deny`/`always`/`never` approvals); embedded ES256 JWKS with `kid="oauth2-sx-grok-prod"` for JWT verification (adding `jose` error codes such as `ERR_JWT_EXPIRED`/`ERR_JWKS_INVALID` in support of MCP OAuth step-up: `mcp_tool.oauth_scope_step_up`); added `ml-dsa-44/65/87` (FIPS 204 post-quantum signature) signing and verification support; telemetry `sand.desktop.gpu_info`, `sand.onboarding.attribution_answered`, and `sand.flights` groundwork (`flightNumber` validation regex); added `restart-to-update` (ShipIt handoff failure) and `rosetta-warning` to update diagnostics.
- **UI**: `mac-app-tile`, `team-bot-details-pane`/`line-render`, `group-chat-connect-waiting`, `places-stage`, `window-chrome`, and `scroll-pane`; "How did you hear about us?" onboarding attribution survey (`youtube`/`tiktok`/`reddit`/`linkedin`/`search-engine`/`app-stores`/`tv-outdoor-ad`/`influencer-creator`/`friend-colleague`/`ai-assistant`).
- **Infrastructure**: Added dependencies `@anysphere/usage-banner`, `@sand/host`, `@sand/sand-eval-runner`, and `tldts`.

## Code & Protocol Details

- `main-app.cjs`: (1) Hosted MCP connector catalog + alias normalization `new Map([["ado","azuredevops"],["agentrobinhoodcom","robinhood"],["ahrefskey","ahrefs"],["asanalocal","asana"],["asanaoauth","asana"]...])`, with catalog entries spanning `1inch`/`1password`/`21st`/`2chat`/`aave`/`airtable`...; (2) embedded full `smol-toml` module suite (`smol-toml/dist/parse.js/stringify.js/...`, ~394 tokens); (3) `acceptXaiIdentityLogin` — xAI identity sign-in session (`"xAI identity was returned outside a supported tenant backend"`, `xaiIdentitySessionActive`, ~209 tokens); (4) expanded `undici` export surface (`WebSocket`/`CloseEvent`/`ErrorEvent`/`MessageEvent`/`request`/`stream`/`pipeline`/`connect`); (5) Zod-style deep JSON validators `Hae/iJe` (net new).
- `main-core.cjs`: Persistent `getMacMailSendEnabled/setMacMailSendEnabled` settings; cleanup hook `this.#d()` triggered when `messagesSendEnabled` transitions from `true` to `false`; control-character and lone-surrogate detectors `Pg/Ng` (`charCodeAt <= 31`, `D800-DBFF` lone high surrogates); `spentIds` deduplication file for local tool sends (`"The spent local-tool sends file is unreadable."`).
- `proto.cjs`: **`GrokBotUserComputerRequestFrame`/`ResponseFrame` multiplexed frame protocol** (`request_id` + `exec`/`upload`/`download`/`retire_approval`/`cancel`/`messages_op`/`local_tool`/`discover_ai_tool`/`put_file_to_url`/`get_file_from_url` request frames; responses including `file_error`/`messages_result`/`messages_consent_result`/`messages_accepted`/`local_tool_accepted`/`local_tool_result`, etc.), replacing the legacy single-op `GrokBotUserComputerMessagesOp`; `SlackInboundInstallMode` (`OPEN`/`LOCKED`); file metadata fields (`sha256`/`sizeBytes`/`originalFilename`/`createdByUserId`/`createdAtMs`).
- `onepassword-connection-service.cjs`: `AbortError` helper (`name==="AbortError" || code==="ABORT_ERR"`).
