- **Release Date**: 2026-11-13
- **Platforms**: `mac`, `win`
- **Summary**: Client-side hotfix and settings update wiring up `GrokBotXToolAccess` (`own` vs. `shared`) across preload, main process, coordinator watch dispatch, and Settings UI with zero protobuf wire-schema changes

## Overview

`1.0.2` (`sandBuiltAt`: `2026-11-12T19:24:34.222Z`; CDN `Last-Modified`: macOS `2026-11-13 03:34` UTC+8, Windows `2026-11-13 03:39` UTC+8) is a focused client-side update on top of `1.0.1` (`Electron 43.8.4`, `asar` `842` files). All `2,829` protobuf message descriptors, `411` enums, `493` `GrokBotService` RPCs, and Statsig feature-gate allowlists remain wire-identical to `1.0.1`, while the desktop client exposes and synchronizes the existing `GrokBotXToolAccess` user runtime setting end to end. No Ubuntu/Debian `.deb` artifact was published to `aptrepo` for `1.0.2` (`HTTP 403`; Linux APT received the identical codebase ~4 hours later in `1.0.3`).

## Key Changes

- **X Tool Read-Access Runtime Setting (`getXToolAccess` / `setXToolAccess`)**
  - **Preload & Main-Core RPC Edge**: Added `getXToolAccess` (`noArgs`) and `setXToolAccess` (`{ access: "own" | "shared" }`) on the main preload RPC edge (`dist/electron-preload/preload.cjs` `149,689 → 149,773` B, `+84` B; `dist/electron-main/main-core.cjs` `1,179,417 → 1,179,502` B, `+85` B).
  - **Main-App Persistence & Protobuf Export**: Re-exported `GrokBotXToolAccess` (`UNSPECIFIED = 0`, `OWN = 1`, `SHARED = 2`) from `dist/electron-main/proto.cjs` (`1,589,025 → 1,589,070` B, `+45` B) and wired `runtimeSettings.readXToolAccess()` / `writeXToolAccess()` in `dist/electron-main/main-app.cjs` (`3,605,354 → 3,606,029` B, `+675` B, verifying server persistence and throwing `"the server did not store X access"` on mismatch).
  - **Coordinator Change Watch**: Registered user runtime setting change key `8: "xToolAccess"` in `dist/node-agent-coordinator/main.cjs` (`1,379,159 → 1,379,189` B, `+30` B) so active coordinator sessions resync when X read access changes.
  - **Settings UI & Localization**: Added the *"Use my X account for reads"* toggle and description (*"Off: Grok Bot reads public X data with its own access, within shared limits. On: reads use your X account."*, Lingui IDs `UpRouI` / `zzPxEZ`) in the General settings pane across bundled locales.
