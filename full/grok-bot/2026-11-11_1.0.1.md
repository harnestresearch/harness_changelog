# Grok Bot 1.0.1

English | [简体中文](../../zh-CN/full/grok-bot/2026-11-11_1.0.1.md) · [Highlight](../../grok-bot/2026-11-11_1.0.1.md) | **Full Detail**

- **Release Date**: 2026-11-11
- **Platforms**: `mac`, `win`, `ubuntu`
- **Summary**: Dual-line convergence release: merged the entire 0.79.x feature line, upgraded Electron for the first time to 43.8.4, and expanded `GrokBotService` to 493 methods

## Overview

`1.0.1` merges the previously parallel `0.79.x` feature branch into the `1.0` stable channel (`GrokBotService` grows from 414 methods in `1.0.0` to 493 methods, incorporating all `0.79.4` capabilities plus 30 net-new methods while removing only the legacy `ListGrokBotTeamsJoinedTeams`), and delivers the desktop app's first major Electron upgrade (`42.11.16 -> 43.8.4`).

## Key New Features (New in 1.0.1)

- **Runtime & Desktop Foundation Upgrade**
  - **Upgraded Electron to `43.8.4`** (from `42.11.16`), recompiling all 13 native modules (dual `tree-sitter` modules, the `sand` native module suite, `jpeg-napi`, `cursor-proclist`, `sand-op-launcher`, and `sand-webauthn-signer`).
  - Added chat code syntax highlighting provider `CodeTokenizerProvider` (powered by `tree-sitter`, with `sand.code_highlight` tracing).
  - Added a Spotlight-style quick input panel (with `spotlight-pending-press`, `blur-grace`, and `dismiss-fallback` focus expiration policies) and window geometry persistence (`normalBounds` / `isMaximized`).
  - Added dependency `country-flag-icons` (language selector flag icons), unified `entry.cjs` entry points for both `local-exec-daemon` and `node-agent-coordinator`, and QUIC reachability probing (`cloudflare-quic.com/cdn-cgi/trace`) in network diagnostics.
- **Voice Reachability Probing & Status Chimes**
  - Added real-time voice reachability probing for `api.x.ai/v1/realtime` (`probeVoiceCallReachability`), classifying block causes across `region_refusal`, `tunnel_refused`, `certificate`, `foreign_response`, and `connection_reset`.
  - Added **Status Chimes** settings that play subtle audio cues across four events: task sent, result returned, awaiting user decision, and execution error.
  - Extended the voice call system prompt with a `## This call` context block (injecting `spokenLanguage`, `hasSpeedSetting`, and `surface`).
- **iMessage Group Chats & Phone Number Linking**
  - Added iMessage group chat log and leave APIs: `GetGrokBotMessagingGroupChatLog` (distinguishing `BOT` / `MEMBER` authors and `HOST_LEFT` / `ENDED` / `STILL_IN_CHAT` states) and `LeaveGrokBotMessagingGroup`.
  - Added SMS verification code linking (`SendGrokBotMessagingPhoneCode` / `ConfirmGrokBotMessagingPhoneCode`) and messaging prompt card read tracking (`Get/MarkGrokBotMessagingPromptSeen`).
- **E-Commerce Checkout Flow & Car Rental / Travel Expansion**
  - Added cart checkout lifecycle RPCs on top of shopping carts: `StartGrokBotCartCheckout` and `CancelGrokBotCartCheckout`.
  - Added car rental rendering cards (`car_rentals`, `car_rental_locations`, `car_rental_detail`) and airline logo/site assets (`airline-logos`, `airline-sites`), refined gift delivery timing fields (`gift.arrivesBy` / `deliverBy` / `recipientName`), promo code saving (`promo.saved` / `note`), and click-to-book flights (`sand.flights.book_on_click`), and added support for deleting virtual try-on photos (`DeleteGrokBotTryOnImage`).
- **Agent Preference Layers, Governance & Team Evaluation**
  - Added multi-layer Agent preferences (`Get/SetGrokBotAgentPreference`: covering `preference` / `executor_preference` / `layers`), auto-review toggles (`SetGrokBotAgentAutoReview`), file and skill privatization (`MakeGrokBotAgentFilePrivate` / `SkillPrivate`), Slack workspace sharing governance (`UpdateGrokBotAgentSlackSharing`), user skill listing (`ListGrokBotUserSkills`), and immediate automation run / card rerun (`RunGrokBotAgentAutomationNow` / `RerunGrokBotAgentAutomationFromCard`).
  - Added an admin side-by-side dual-model evaluation suite (`AdminStart/Stop/Get/List/GetOptionsGrokBotModelComparison`, `AdminSendGrokBotModelComparisonFollowUp`, `ModelComparisonLane`).
  - Added team sandbox infrastructure self-tests (`Start/Get/StopTeamSandSetupTest`), enterprise spend limits (`enterprise-spend-limit`), connector policy gates (`connector_policy.blocked` / `MCP_ALLOWLIST` / `blocked-connectors-gate`), and presigned custom connector icon uploads (`PresignXaiConnectorIconUploadInternal`).
  - Added Bonfire email invite sending (`SendBonfireInvite`) and past meeting lookup (`HasGrokBotAgentPastMeetings`).

## 0.78.2 – 0.79.4 Features Merged into 1.0 Mainline

- **Security & Privacy**: User privacy mode (`SetUserPrivacyMode`), training data opt-in popup, Passkey sign-in ceremony (`/grok-bot/passkey/` routes and state events), MCP Loopback OAuth Google sign-in callback timeout fix, and 1Password vault service account connections alongside the previous-integration fallback toggle.
- **Calendar, Meetings & Messaging Cards**: Server-side calendar event stream and meeting prompt actions (`ActOnGrokBotMeetingPrompt`, `UpdateGrokBotMeetingSettings`), interactive iMessage approval cards (`Get/AnswerGrokBotMessagingCard`), and full-text transcript search (`SearchGrokBotTranscripts`).
- **E-Commerce & Agent Store**: Shopping cart, virtual try-on, flight booking link resolution, Agent Store marketplace and publishing governance (`plugin-publish` / `skill-publish`), and QuickBooks MCP plus Tailscale connector support.
