# Grok Bot 0.65.0

English | [简体中文](../../zh-CN/full/grok-bot/2026-09-30_0.65.0.md) · [Highlight](../../grok-bot/2026-09-30_0.65.0.md) | **Full Detail**

- **Release Date**: 2026-09-30
- **Platforms**: `mac`, `win`
- **Summary**: Added native notification settings module and Microsoft Teams meeting provider; meeting transcript/record APIs and finance connector launched

## Highlights

- **Features**: New native module `sand-notification-settings` (`build/Release/sand_notification_settings.node`, reading macOS notification permissions via `notification_settings_async`, reporting under key `sand.desktop.notification.permission`, paired with setting key `os-notifications`). Added `MICROSOFT_TEAMS` meeting provider (alongside `GOOGLE_MEET` / `ZOOM`), plus server-side meeting list polling (`meeting-server-list`, `meetings-enablement` toggle). Finance connector OAuth link flow (`startFinanceLink`, including `reportLinkStart` stage telemetry); Shopify connector registration (`setup.shopify.com`, `clientRegistration: static`).
- **Protocol / Main Process**: Meeting record/transcript RPCs: `AdminGetGrokBotMeetingTranscript` (`lines` + `truncated`), `AdminGrokBotMeetingTranscriptLine(at_ms,text)`, `GetGrokBotMeetingRecord`, `LeaveGrokBotServerMeeting`, `GrokBotMeetingTranscriptLine`; background summary composer `GetTurnSummaryBackgroundComposer` / `ListBackgroundComposerArtifacts`; `GrokBotUserComputerLocalTool` (local tool status reporting). New setting keys: `mcp-app`, `sand-mcp-app`, `time-zone-override`, `language-preference`, `theme-preference`, `local-egress-policy`, `permissions-policy`, `screen-locked`, `agent-activity`, `team-agent-activity`, `box-roster-census`, `browser-backward`, `browser-forward`, `message-history`, `single-shot`, `unsafe-path`, `sand-html-preview`, `app-command`, `before-mouse-event`; `store.notify`, `sand.request-recovery`; `xterm-kitty` / `xterm-ghostty` / `TERM_PROGRAM` (terminal truecolor detection) and CI environment detection constants (`GITHUB_ACTIONS`, `GITLAB_CI`, `CIRCLECI`, `TEAMCITY`, `BUILDKITE`, `APPVEYOR`, `TF_BUILD`, `GITEA_ACTIONS`).
- **UI**: Finance connector page components.
- **Infrastructure**: Dependencies 88 -> 89 (+`sand-notification-settings`, including `.node` native binary); `asar` 601 -> 611.

## Code & Protocol Details

- `main-app.cjs`: Expanded meeting providers to three: `var Por=["GOOGLE_MEET","ZOOM","MICROSOFT_TEAMS"]` (adding Teams), plus `ServerMeetingRecordError` (`class extends SandDomainError`) and server-side meeting record client (`static timeoutMs=1e4, last=[]`) -- beginning migration of local meetings to server-side infrastructure.
- `main-app.cjs`: OS notification server gate sync: `readServerFeedGate()` (reads `isServerFeedOn()`, routing failures to `reportDesktopEdgeFailure("os-notifications","gate-read")`) + `syncGate()` state machine.
- `main-app.cjs`: Box roster merging: `keepOnlyAgents(t)` prunes local `boxAgents`, `serverRosterAgents` / `serverRosterRead` / `wantsServerReread` merges the server roster, `isTeamRoom(t)` classifies via `groupChatRoomOf`, and `moveHistory(t, this.boxLane)` migrates history.
- `meetings-main.cjs`: Join failure copy table `f={cancelled:"the join was cancelled", joinFailed:"couldn't join the meeting", notAdmitted:"wasn't let into the meeting", disconnected:"lost the connection to the meeting"}`; bot name suffix `` `(${t}'s Bot)` `` length truncation (`suffixOf`).
- `main-core.cjs`: Added `var Gs="sand-html-preview", Vs="text/html; charset=utf-8", Hs="sand-mcp-app"` (custom protocol/partition constants for HTML preview and MCP apps) and system CA certificate error classification set (6 categories including `UNABLE_TO_GET_ISSUER_CERT` / `SELF_SIGNED_CERT_IN_CHAIN`, unwrapping up to 4 nested `cause` levels).
- `proto.cjs`: Added `ManagerSpawnKind`: `UNSPECIFIED` / `CREATED` / `ADOPTED` / `CREATED_SAME_VM` (manager process adoption semantics); registered `getTurnSummaryBackgroundComposer` / `listBackgroundComposerArtifacts` / `listWorkersForManager`.
