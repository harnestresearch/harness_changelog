# Grok Bot 0.78.1

English | [简体中文](../../zh-CN/full/grok-bot/2026-10-28_0.78.1.md) · [Highlight](../../grok-bot/2026-10-28_0.78.1.md) | **Full Detail**

- **Release Date**: 2026-10-28
- **Platforms**: `mac`, `win`, `ubuntu`
- **Summary**: Landed Team Bot credential vault UI

## Highlights

- **Features**: Renderer components `team-bot-vault` / `team-bot-vault-access` / `team-bot-vault-slot` / `grok-bot-vault-login-dialogs` (enabling Bots to store and retrieve credentials via vault slots alongside sign-in dialogs).
- **Protocol / Main Process**: Exposed `DeleteGrokBotVaultCredentialRequest` (deleting vault credentials by `agent_id`) in the main process interface; added `GrokBotBoxIntent.COMPUTER_OPEN`; filled out Tailscale error copy (`"Open the Tailscale plugin in Grok Bot to see how to fix it."`, etc.).
- **UI**: `bot-manage-section` and `team-bot-setup-dialog-shell`.
- **Infrastructure**: No dependency or native module changes.

## Code & Protocol Details

- `main-app.cjs`: Reshuffle only.
- `main-core.cjs`: Refactored isolated `user-data` directory setup — extracted the inline `app.setPath("userData"/"sessionData")` logic into `_Ae(e,t)` + wrapper `fY(e,t)` (validating via `ku(t)` first, writing back to the environment variable cache, and logging `[sand] using isolated user-data dir: ${n}`).
- `proto.cjs`: Added enum `GrokBotUserFormVaultTarget` (`PERSONAL`/`AGENT`) specifying which vault receives form autofill writes.
- `renderer/index.eager`: Added `listTeamBotVaultLogins/putTeamBotVaultLogin` IPC wrappers (listing/writing Team Bot vault login credentials, absent from the `0.78.0` asar); refactored the `useDraft` editing hook (`setDraft`/`setIsFocused` cache layout).
