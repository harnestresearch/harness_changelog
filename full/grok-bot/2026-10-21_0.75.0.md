# Grok Bot 0.75.0

English | [简体中文](../../zh-CN/full/grok-bot/2026-10-21_0.75.0.md) · [Highlight](../../grok-bot/2026-10-21_0.75.0.md) | **Full Detail**

- **Release Date**: 2026-10-21
- **Platforms**: `mac`, `win`, `ubuntu`
- **Summary**: Added X, Shop, and Cloudflare connectors alongside the pele diagram engine, memory import, admin RPCs, and a login watchdog

## Highlights

- **Features**: X (Twitter/Grok) connector OAuth callbacks (`https://chat.x.com/connectors/oauth_callback`, `https://lite.x.com/i/connectors/oauth_callback`, `https://grok.com/connectors-oauth-exchange-code/`, provider `grok-connectors`, scopes `openid`/`personal_agent`); Shop connector (`mcp.shop.com`); Cloudflare connector (`mcp.cloudflare.com`, permissions `d1.read/write`, `dns.read/write`, `zone.read/write`); memory import (`import-memory` setting key + `sand.memory_import_action` telemetry); cloud Agent deployment management permissions (`agent_serve_deployment.delete/manage_access/rotate_credentials/manage_slack`); `pele` diagram rendering engine (dependency `pele`, `glass_mermaid_renderer` selectable between `beautiful-mermaid` and `pele`, feature gate `sand_enable_pele_diagrams`, telemetry `sand.diagram.rendered`); expanded tray avatar state machine (`dictating`/`sending`/`receiving`/`writing`/`powering-down`/`humming`, etc.) and `presence-return` window focus event.
- **Protocol / Main Process**: Added admin RPCs `AdminGetGrokBotAgentStoreContents`, `AdminGetGrokBotAgentTransfers`, and `AdminGrokBotEmailInboxMoveAddress`; added team review item RPC `AddGrokBotTeamReviewItem`; added setting keys `missed-login-check`/`missed-login-store` (`cursor-auth` login watchdog), `mark-state-changed`, `request-permission`, `asset-read`, `any-origin`, `env-debug`, `team-fresh`, and `chosen-off`; added constants `GOOGLE_MEET`/`MICROSOFT_TEAMS` (meeting integrations), `MY_MACHINE`, and `CURSOR_SUPPORT`.
- **UI**: Renderer added `chat-widget`, `custom-mcp-form`, `device-action`, `card-dialog`/`card-item`, Amex icon, and multiple wallpaper/lamp illustration assets; removed `vault-card-fields` and `team-bot-access-plan`.
- **Infrastructure**: Added dependency `pele@1.3.0`; 2 files changed under `dist/native`; Electron version unchanged.

## Code & Protocol Details

- `main-app.cjs`: Login link recovery — `async reopenLoginLink(){let t=this.loginFlightUrl; if(t==null){let n=this.missingLoginLink(); return n==="idle"&&this.publishedStatusKind==="logged-in"?"signed-in":n} return await this.openExternal(t),"reopened"}` and `copyLoginLink`; egress tunnel attach generation conflict check `jAn(e,t){return e==="released"?"released":e==="occupied"&&t!==void 0?"held-by-another-client":"retry"}` (`held-by-another-client` x3 newly added); login watchdog state machine `missedLogin={loginManager,metadata,operationEpoch,missedAtMs}` (x20); local device tool nudge — `nudgeDaemon`/`writeLocalDeviceToolNudge`, paired with gate files `local-computer-use-gate.json`/`mac-device-tools-gate.json`/`local-device-tool-nudge.json` in `main-core`; Google Drive hosted tool rename table `renamedHostedTools` (`hostedHost` `drivemcp.googleapis.com`, `search->search_files`, `read_file->read_file_content`).
- `main-core.cjs`: Persistent `egressTunnelCommittedBoxUrls` read/write (`get`/`set` + state merging, x7); MIME/extension mapping table (`image/avif`...`video/quicktime`).
- `onepassword-connection-service.cjs`: Cross-vault 1Password item moves — `vaultMovePlans`/`moveItem({accountUuid,itemId,currentVaultId,destinationVaultId})`, `"The vaults must differ"`, `"Check the vault again before moving this item."`, and personal vault uniqueness check (`isPersonal` with exactly one match).
- `proto.cjs`: Added field `|24 reply_quote` (quoted message replies) to `SendGrokBotUserMessageRequest`; added `GrokBotTeamReview*` (`MemoryAction` WRITE/FORGET, `SkillAction` ADD/UPDATE/REMOVE, `ItemStatus`); email inbox statistics fields `email/domain/provider/messageCount/inboundCount/outboundCount/unindexedCount`.
