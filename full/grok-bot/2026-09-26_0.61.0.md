# Grok Bot 0.61.0

English | [简体中文](../../zh-CN/full/grok-bot/2026-09-26_0.61.0.md) · [Highlight](../../grok-bot/2026-09-26_0.61.0.md) | **Full Detail**

- **Release Date**: 2026-09-26
- **Platforms**: `mac`, `win`, `ubuntu`
- **Summary**: Minor release: expanded attachment rendering in the `desktop-mount` panel (image/tile rendition)

## Highlights

- **Features**: Added a `rendition` parameter to the `desktop-mount` panel `read` channel, supporting both `image rendition` and `tile rendition` attachment display modes (rendering images and tiled content inside mounted desktop widgets).
- **Protocol / Main Process**: No new setting keys or URLs.
- **UI**: Updated `document-page`, `SegmentedControl`, and `team-bot-teammate-intro` components.
- **Infrastructure**: No dependency additions or removals; 3 preload files updated.

## Code & Protocol Details

- `main-app.cjs`: Attachment media rendition validation -- `$P(e)= e==="preview" || e==="original" || zP(e)`, where `Mvt` parses `tile-N` (`N` bounded to 16-1024) via `/^tile-([1-9]\d{1,3})$/` and expands `tile-N` to `{rendition:"preview", tile}`; added `rendition("preview"/"original") + tile` parameters to `readAttachmentImage` and `rendition` parameter to `resolveAttachmentMedia` -- allowing image attachments to be read at preview, original, or tiled resolution; new RPC `getDocumentEditRight({locator})` -> `{locator, canEdit: <evaluated by storeId>}` -- determining document edit permissions per store (gating read-only canvas documents), with `saveDocument` routed through `writeAgentStoreDocument`.
- `main-core.cjs`: Render performance telemetry -- `"long-animation-frame"` (`blockingMs` / `renderMs` / `styleAndLayoutMs` / `scripts`), `renderSelfMs` sampling rate, and `interaction` / `selection` / `entrypointId` dimensions.
