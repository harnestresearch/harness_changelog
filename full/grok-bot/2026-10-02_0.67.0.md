# Grok Bot 0.67.0

English | [简体中文](../../zh-CN/full/grok-bot/2026-10-02_0.67.0.md) · [Highlight](../../grok-bot/2026-10-02_0.67.0.md) | **Full Detail**

- **Release Date**: 2026-10-02
- **Platforms**: `mac`, `win`
- **Summary**: Retired local meeting windows entirely (`meetings-main` / `preload-meeting*` removed in favor of server-side meetings); added draft revision highlighting

## Highlights

- **Features**: Removed local meeting implementation: deleted `meetings-main.cjs`, `preload-meeting.cjs`, `preload-meeting-avatar.cjs`, and `pitman-avatar-output.html`, along with `sand-meeting-camera` / `hear` / `idle` / `stamp` / `wake`, `meeting-load` / `pull` / `report` / `window`, `stt-stream` / `stt-stop`, `meetings-enablement`, `in-call`, `summary-due`, and Google Meet / Zoom sample URLs; retained only the local diagnostic endpoint `GET /meetings/record` and server-side `AdminMintGrokBotMeetingAvatarLinks` (avatar links are now minted server-side). Added dependency `@anysphere/draft-revision` + `use-draft-revision-highlight` (draft revision highlighting).
- **Protocol / Main Process**: `GetGrokBotAgentLinkAccess` (agent share link access permissions); team invite links `GetTeamInviteLinkResponse` / `SendTeamInviteResponse` (`valid_until` expiration); local tool invocation records `GrokBotUserComputerLocalToolCall` (`tool_id` + `input_json`) / `GrokBotUserComputerLocalToolResult` (`status` / `output_json` / `error`); `MessageSender.Kind`; telemetry `sand.connector_card.rendered`; new keys `bot-identifier`, `permission-report`.
- **UI**: Local tool permission button `"Always allow"`; in-progress status phrase set (i18n table): `"Chipping away"`, `"Clicking through pages"`, `"Connecting the dots"`, `"Jotting it down"`, `"Making progress"`, `"Reading the file"`, `"Sending a message"`, `"Checking with another Bot"`, `"Needs your input"`; `"Could not store the secret"`; `teach-recording-controls` ("teach it" recording controls) and `agent-character-picker` (agent persona picker).
- **Infrastructure**: Dependencies 89 -> 90 (+`@anysphere/draft-revision`).

## Code & Protocol Details

- Full file removal: `meetings-main.cjs` (45,314 bytes -> removed) deleted from `dist/electron-main`; `main-app.cjs` removed the `"src/electron-renderer/pitman-avatar/pitman-avatar-output.html"` constant, avatar `lookup` class (`listAgents` avatar lookup), and diagnostic routes `["POST /meetings/join",...]` and `["GET /meetings/capture",...]` (along with the `"meeting join is not wired"` fallback), keeping only `GET /meetings/record`.
- `main-app.cjs`: GitHub issue URL normalization: `function a3t(e){let t=e.searchParams.get("p"); return t!=null&&t3t.test(t)?t:r3t.exec(e.pathname)?.[1]??e.toString()}` and `s3t` (splitting `pathname` by `/` and checking `n!=="issues"`) -- sanitizing issue deep links for the connector link registry.
- `main-app.cjs`: Team collaboration trio: `getTeamInviteEligibility` (unauthenticated / missing `teamId` -> `{kind:"ineligible"}`), `getSharepointSignIn` (probing SharePoint OAuth status via `backendMcpExec.checkAuthStatus({statusOnly:!0})`, 8 references), and `listGrokBotAgentAccessPrincipals` / `addAllowedUser` / `removeAllowedUser` (agent access allowlist returning `userIds+creatorUserId`).
- `main-app.cjs`: MCP tool input coercion: `function h7e(e,t){let r=t.find(a=>a.providerIdentifier===e.providerIdentifier&&a.toolName===e.toolName)?.inputSchema, ... i.args=io.fromJsonString(JSON.stringify(o)).fields}` -- coercing tool call arguments against the server `inputSchema`.
- `main-app.cjs`: Notification permission prompt persistence: `store: Att({filePath: join(app.getPath("userData"),"notification-permission-sent.json")})`, with `isPersistEnabled` / `platform` / `deviceId:getDurableMachineId()` fields.
- `proto.cjs`: Added `announceInstructions` / `maxOffers` / `eligibilityGate` / `minClientVersion` fields to team invite messages (server-side gating for invite issuance); `main-core.cjs`: new RPC method name enum table (`AddMcpServer` / `AuthenticateMcpServer` / `AwaitShell` / `ChatItems` / `CheckIMessagePermissions` / ...).
