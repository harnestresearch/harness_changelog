# Grok Bot 0.53.0

English | [简体中文](../../zh-CN/full/grok-bot/2026-09-15_0.53.0.md) · [Highlight](../../grok-bot/2026-09-15_0.53.0.md) | **Full Detail**

- **Release Date**: 2026-09-15
- **Platforms**: `mac`, `win`, `ubuntu`
- **Summary**: Pull Request chat rooms and granular OAuth scopes launched; admins can enumerate email inboxes and sync 1Password connections

## Highlights

- **Features**: Chat rooms for GitHub PRs (`EnsureGrokBotPullRequestChatRequest` / `SendGrokBotPullRequestChatMessageResponse`, including `GrokBotPullRequestChatBlocked` block reasons such as unshared author); team group sandbox setup manifests (`ListTeamGroupSandSetupManifests` / `SaveTeamGroupSandSetupManifest` / `DeleteTeamGroupSandSetupManifest`).
- **Protocol / Main Process**: Added OAuth scope constants `dm.read` / `dm.write` (Slack DM read/write) and `team.github_identity_mappings.read` (GitHub identity mappings); `AdminListGrokBotEmailInboxesRequest` / `AdminListGrokBotEmailMessagesResponse` (admin enumeration of email inboxes and messages); `SyncOnePasswordConnectionsRequest` (1Password connection sync); `ClientLlmGatewayCredential` (containing `bearer_token`); `EnsureGrokBotBoxHarnessMigrationPassRequest`. Added channel/setting key `app-focus`; room access gate constants `OWNER_GATE_OFF` / `VIEWER_GATE_OFF` / `ROOM_CLOSED` / `ROOM_UNAVAILABLE`.
- **UI**: No major UI changes.
- **Infrastructure**: No dependency additions or removals; Electron version unchanged.

## Code & Protocol Details

- `main-app.cjs`: Added 1Password focus sync controller `nHt` (`noteWindowFocused` / `noteAuthChanged` / `dispose`), triggering a debounced `sync()` when signed in, service is enabled, and window is focused, routing failures to `reportFailure`; `getListenerConnectUrl` parameters added `forceOauth: rpcOptional(rpcBoolean())` (allowing listener connection URLs such as Slack to force OAuth).
- `proto.cjs`: Added `GrokBotPullRequestChatBlockReason` enum (`AUTHOR_IS_USER / AUTHOR_IS_APP / AUTHOR_SERVICE_ACCOUNT_NOT_GROK_BOT / BOT_NOT_FOUND / BOT_HARNESS_UNSUPPORTED / BOT_NOT_SHARED / OWNER_GATE_OFF / ROOM_UNAVAILABLE`); added `OnePasswordSyncTrigger` (`MANUAL / APP_FOCUS`), invoked via `syncOnePasswordConnections({trigger: o==="app-focus" ? APP_FOCUS : MANUAL})`; landed PR chat message types.
- `renderer/markdown-math`: Added a `unist-util-visit`-style AST walker (`function Pi(e,t,n,r){... u(e,void 0,[])()}` recursive walker).
