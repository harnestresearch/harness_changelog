# Grok Bot 0.32.0

English | [简体中文](../../zh-CN/full/grok-bot/2026-09-01_0.32.0.md) · [Highlight](../../grok-bot/2026-09-01_0.32.0.md) | **Full Detail**

- **Release Date**: 2026-09-01
- **Platforms**: `mac`, `win`
- **Summary**: Minor macOS permission onboarding update: Full Disk Access, Finder Automation, and Chrome Safe Storage authorization checks

## Highlights

- **Features**: macOS authorization items paving the way for Messages and Chrome data import — full-disk-access, finder-automation, and chrome-safe-storage; cloud-onboarding.
- **Protocol / Main Process**: electron-main continues splitting out `proto.cjs` (standalone bundle for protocol definitions).
- **UI**: Chart component hash updates only.
- **Infrastructure**: Shipped 1.5 hours after the previous version with no dependency changes; `v8-code-cache` key removed (returning in a new form in the next release).

## Code & Protocol Details

- **Standalone proto bundle**: Added `dist/electron-main/proto.cjs` (3.96MB), migrating all `aiserver.v1`/`agent.v1` protocol definitions out of `main-app`; `main-app` now contains a proto reflection registration list `["AgentSkill","AiService","AnalyticsEvent",…]` (~200 type names).
- `main-app.cjs`: Landed three macOS authorization checks: `full-disk-access`, `finder-automation`, and `chrome-safe-storage`, along with error classes `MacFullDiskAccessPendingError`/`MacFinderAutomationPendingError`/`ChromeSafeStoragePermissionError` and grant record key `sand-chrome-cookie-fda-grant`.
- `main-app.cjs`: Added local tool permission ceiling `LocalToolPermissionCeiling` (getLocalToolPermissionCeiling, etc., 9 occurrences); refined Slack state machines into the `GrokBotSlack{Install,Uninstall,Reinstall,Connect}Outcome` enum family.
- `main-app.cjs`: Added `cloud-onboarding`.
- `main.cjs` (loader, 3 occurrences): Rewrote code-cache entry matching to `d.startsWith(\`\${r}-\`)&&Ke.test(d)` ("isCodeCacheEntry") — updating the V8 code cache naming scheme alongside the bundle split.
