# Grok Bot 0.33.0

English | [简体中文](../../zh-CN/full/grok-bot/2026-09-01_0.33.0.md) · [Highlight](../../grok-bot/2026-09-01_0.33.0.md) | **Full Detail**

- **Release Date**: 2026-09-01
- **Platforms**: `mac`, `win`
- **Summary**: Three-tier main-process split (main/main-app/main-core) + Mac remote computer control and voice process routing wired up

## Highlights

- **Features**: Mac computer control (computer-use-mac); voice process message routing (to-voice/to-main); iMessage enablement and retry (messages-enable/messages-retry, `GetSandMachineMessagesEnabled`); sub-agent dispatch (`SubagentDispatchStep`/`SubagentDispatchTool`); WebAuthn retry (webauthn-retry); one-time agent approval (approve-once).
- **Protocol / Main Process**: Added `sand.main-core.handoff` and `sand.main-core.modules` module loading protocols; `CarriedRequestContext` (cross-request context propagation), `SandGroupAccessMode`, `x-grok-bot-refusal` response header, and return of `x-anyrun-port-token`; new keys response-create, automation-message, local-build, local-tool-retry, and profile-list.
- **UI**: prompt-editor component.
- **Infrastructure**: Split `main-core.cjs` out of electron-main; safeStorage encryption/decryption functions (encryptString/decryptString) for credential storage.

## Code & Protocol Details

- **Three-tier split completed**: Added `dist/electron-main/main-core.cjs` (1.43MB); `main.cjs` loader adds guard `isMainCoreExports` (verifying that exports include a `remainderDue` Promise and `noteStartupFailed` function, otherwise throwing "main-core.cjs does not export remainderDue and noteStartupFailed.").
- `proto.cjs`: Sub-agent dispatch protocol: `SubagentDispatchTool` enum (TASK/CREATE_AGENT/SEND_TO_AGENT), `subagent_dispatch_steps` field (repeated), `was_complete`, and `conversation_rewind_epoch`; cross-request context `CarriedRequestContext` (carried_request_context); `sand_group_access_mode` field.
- `main-app.cjs`: Voice routing wired end-to-end: events `agent-speech-started/stopped` and `caller-speech-started/stopped`, inter-process routing keys `to-voice`/`to-main`, and `SandTranscriptionManager`/`SandTranscribeEmptyAudioError`.
- `main-app.cjs`: iMessage enablement pipeline: `GetSandMachineMessagesEnabled` RPC, channels `messages-enable`/`messages-retry`, `check-messages-permissions`, and `snapshot-messages-db`.
- `main-app.cjs`: Added `computer-use-mac` (Mac remote control) and `update_sand_group_access_groups`/`sand_group_access_enabled_group_ids`.
- `main-app.cjs`: New prompt string "how much they would like to oversee the changes the agent is making. What is their workflow…" (supervision level onboarding question).
