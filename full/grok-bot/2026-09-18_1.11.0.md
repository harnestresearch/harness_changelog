# Grok Bot 1.11.0

English | [简体中文](../../zh-CN/full/grok-bot/2026-09-18_1.11.0.md) · [Highlight](../../grok-bot/2026-09-18_1.11.0.md) | **Full Detail**

- **Release Date**: 2026-09-18
- **Platforms**: `ios`
- **Summary**: Full-screen photo preview before sending, per-chat saved drafts, improved multi-photo display, and faster first sign-in.

## Release Notes (App Store)

- Added the ability to tap a photo you've attached to preview it full screen before sending.
- Added saved drafts: unsent message text is kept per chat when you leave and come back.
- Improved how several photos in one message are shown: two photos stack, three or more fan out with a count you can tap to see them all in a grid, and a full-screen photo now shows a loading or "couldn't load" state instead of staying black.
- Improved first sign-in time.
