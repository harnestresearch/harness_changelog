# Grok Bot 0.24.0

English | [简体中文](../../zh-CN/full/grok-bot/2026-08-21_0.24.0.md) · [Highlight](../../grok-bot/2026-08-21_0.24.0.md) | **Full Detail**

- **Release Date**: 2026-08-21
- **Platforms**: `mac`, `win`
- **Summary**: Baseline release: initial desktop version of Grok Bot (internal package name `sand`, author SpaceXAI) — a single-bundle main-process desktop agent already equipped with sandbox execution, MCP, Slack/Google integrations, and an early template marketplace

## Highlights

- **Features**: Initial functional domains are outlined by 33 internal `@anysphere/*` packages out of 82 dependencies: the full agent runtime suite (agent / agent-client / agent-core / agent-exec / agent-kv / agent-store-sync / agent-summarization / agent-transcript), chat inference (chat-inference + chat-inference-proto), local and MCP execution (local-exec / shell-exec / mcp-agent-exec / mcp-core), grok-bot core and harness, virtual filesystem (virtual), model selection (model-selection), Cursor configuration and plugins (cursor-config / cursor-plugins), dune, context-rpc, and redacted-protos, alongside @sand/client and @sand/shared. Integration capabilities already include the full Google Workspace OAuth scope suite (gmail.\* / calendar.events / drive / documents / spreadsheets / presentations), Slack, an MCP server directory (memory/notion/playwright/salesforce/slack/stripe/telegram/todoist/zoominfo, etc.), and early foundations for connector, marketplace, computer-use, secret-store/user-secrets, and box sandbox (readHostSettingsFromBox, etc.) domains.
- **Protocol / Main Process**: The main process is a single 8.7MB minified `dist/electron-main/main.cjs`, paired with electron-preload, dist/host (agent-isolation worker, extensions: box-store-sync/content-search), local-exec-daemon, node-agent-coordinator, and native (cursor-proclist native process list module). RPC runs over connectrpc + protobuf (aiserver.v1 / agent.v1), with telemetry powered by statsig + sentry + opentelemetry.
- **UI**: React 19 + tiptap rich-text editor + lingui i18n + stylex; Markdown rendering with KaTeX/mermaid, and document parsing with xlsx/mammoth(docx)/pdfjs-dist.
- **Infrastructure**: Electron app (sandTrack: stable channel), Google s2 favicons icon source, cursor.com homepage.
