- **Release Date**: 2026-11-06
- **Platforms**: `mac`, `win`, `ubuntu`
- **Summary**: Added fallback toggle to revert to the previous 1Password integration and removed the sandbox attachment pre-upload dual-write cache

## Features & Protocol

- **1Password previous integration fallback toggle**: Added the `SetOnePasswordPreviousIntegration` RPC (`use_previous_integration` boolean toggle), wiring `setPreviousIntegration` state switching across the main process and `onepassword-connection-service.cjs`.
- **Dashboard client account-scope routing**: Separated `account`-level client instances from explicit `expectedAccountScope` instances by policy, adding a pre-dispatch account-change guard (`Machine privacy check account changed before dispatch.`).
- **Removed sandbox attachment pre-upload cache**: Retired `box-attachment-preupload-release` pre-upload staging reuse and the `doubleWriteStore` subsystem from `main-app.cjs`.

## UI & Rendering

- Added adaptive background contrast calculation for connector brand badges (automatically switching foreground and backing plate contrast by background luminance for non-Google logos).
- Updated the `sand-form-dialog` and `wipe-navigation` components.
