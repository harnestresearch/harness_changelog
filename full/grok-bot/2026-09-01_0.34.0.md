# Grok Bot 0.34.0

English | [简体中文](../../zh-CN/full/grok-bot/2026-09-01_0.34.0.md) · [Highlight](../../grok-bot/2026-09-01_0.34.0.md) | **Full Detail**

- **Release Date**: 2026-09-01
- **Platforms**: `mac`, `win`
- **Summary**: Major UI update for new-agent creation and template editing; `messages-helper` helper process takes over iMessage

## Highlights

- **Features**: Agent character picker (agent-character-picker), new-agent pane and chat bar (new-agent-pane/new-chat-bar), cloud agent provider (provider-cloud-agents), remote control screen preview (computer-screen-preview), template editor dialogs and visibility controls (template-editor-dialog/bot-template-details-dialog/bot-template-visibility-controls), data wipe navigation (wipe-navigation), and box-desktop-modal.
- **Protocol / Main Process**: Internal marketplace template read/write (`GetGrokBotMarketplaceListingTemplateInternal`/`UpdateGrokBotMarketplaceListingTemplateInternal`); new channels messages-helper (iMessage helper process), lookup-failed, and prompt-unavailable.
- **UI**: macOS Automation consent prompt copy ("The macOS Automation consent prompt did not run").
- **Infrastructure**: No dependency changes.

## Code & Protocol Details

- `main-app.cjs`: Origin PR status lookup lands: `narrowOriginPrStatus`/`originPrStatusRow`/`originPrLookupFailed` and error class `SandOriginPrStatusRequestError` (with message `` `batch-get-pull-request-status-${t}` ``), plus new IPC `getCursorOriginPrStatus({prUrl})` — calling `cursorAccount.getOriginPrStatus` with the `"connect-protocol-version":"1"` HTTP header.
- `main-app.cjs`: `messages-helper` helper process takes over iMessage, with macOS Automation consent failure handling: reports `reportDesktopEdgeFailureClass("messages-helper","messages-grant-prompt","prompt-unavailable")` upon detecting "The macOS Automation consent prompt did not run.".
- `proto.cjs`: Internal marketplace template read/write `Get/UpdateGrokBotMarketplaceListingTemplateInternal`; request context adds `request_context_pod_id`/`request_context_conversation_rewind_epoch`; added `superseded_request_id`.
- `renderer/prompt-editor`: Small-scale substantive updates (rearrangement of constants such as `const Rk="everyone"`); `renderer/automation-detail-panel`: extracted brand-logos icons into standalone chunk `chunk-brand-logos-Ba-PnuM3.js` via ES import.
