# Grok Bot 0.79.1

English | [简体中文](../../zh-CN/full/grok-bot/2026-11-05_0.79.1.md) · [Highlight](../../grok-bot/2026-11-05_0.79.1.md) | **Full Detail**

- **Release Date**: 2026-11-05
- **Platforms**: `mac`, `win`
- **Summary**: Launched the 1Password vault connector

## Highlights

- **Features**: `BeginOnePasswordConnectionRequest` (`connection_id`, `vault_id`, `service_account_token`) — enabling Bots to connect to a designated 1Password vault using a service account token.
- **Protocol / Main Process**: Corresponding `vault-card-dialog` protocol wiring; remaining changes are chunk reorganizations.
- **UI**: `vault-card-dialog`, `team-bot-memories-list` (Bot memories list), and `usage-review-target`.
- **Infrastructure**: No dependency changes.

## Code & Protocol Details

- `main-app.cjs`: Re-attached the `begin(o,a){ await beginOnePasswordConnection({connectionId: o.connectionId??"", vaultId: o.vaultId??"", serviceAccountToken: o.serviceAccountToken??""}) -> mintTicket/connectionId }` wrapper; added `detectMint/startMint` entry points to the credentials bridge.
- `onepassword-connection-service.cjs`: Restored and completed the 1Password mint flow removed in `0.79.0`: `probeMintReadiness` (`reportFlow({phase:'clicked', outcome: ready?'ok':'failed', error: credentialProviderSetupNotReady({reason})})`), `mintAndDeliver`, `connectWithToken`, `createVault` fallback (`E=!0` creation flag) when `findVault` cannot find `vaultName`, and normalized error codes `missing-cli/unsupported-platform/integration-off/app-unreachable/denied/permission/cancelled/timeout/invalid-token/conflict`.
- `proto.cjs`: Added `BeginOnePasswordConnectionRequest` message (`connectionId`/`vaultId`/`serviceAccountToken`, 495 tokens).
- Remaining changes are build rotations.
