# Grok Bot 0.39.0

English | [简体中文](../../zh-CN/full/grok-bot/2026-09-03_0.39.0.md) · [Highlight](../../grok-bot/2026-09-03_0.39.0.md) | **Full Detail**

- **Release Date**: 2026-09-03
- **Platforms**: `mac`, `win`, `ubuntu`
- **Summary**: Desktop real-time voice credential minting (MintDesktopRealtimeVoiceSecret), Anthropic EFS approval flow, and local UI state persistence keys

## Highlights

- **Features**: Real-time voice mode infrastructure — minting secrets for desktop voice sessions (`MintDesktopRealtimeVoiceSecret`) alongside the `voice-settings` setting key; enhanced Messages (iMessage) integration — added `find-contacts` tool (mapped to `messages/find-contacts`, querying contacts by region alongside `snapshot-messages-db`, `copy-attachment`, etc.).
- **Protocol / Main Process**: `MintDesktopRealtimeVoiceSecretRequest/Response`; Anthropic EFS suite — `GetOrganizationAnthropicEfsStatus`, `GetTeamAnthropicEfsStatus`, `RequestOrganizationAnthropicEfs`, `RequestOrganizationGroupAnthropicEfs`, `RequestTeamGroupAnthropicEfs`, and `ReviewAnthropicEfsRequestInternal` (decisions APPROVE/REQUESTED/REJECTED); telemetry event `sand.client.restore`; client persistence key family `account-slot` / `ui-state` / `voice-settings` / `sidebar-sections` / `last-selection` / `last-roster` / `transcript-replicas` / `bot-templates` / `computer-use`, etc.
- **UI**: Added Indonesian (`id`) locale resource `emoji-messages.id`.
- **Infrastructure**: No dependency changes.

## Code & Protocol Details

- `main-app.cjs`: Removed i18n string bundle and parameter serialization for `bot_template_publish` template publication notifications (two sections present in 0.38 → 0 in 0.39); removed `sand_multi_machine_local_exec` feature gate across the board (three `checkGate/checkFeatureGate` call sites, absent from 0.40 onward as well); added `onLocalExecSupervisorFailed` (0→3 occurrences, reporting local exec supervisor failure reason) and `SandError.clientRestoreFailed / clientRestoreStuck({stage})` (stage-tagged telemetry for failed or stuck client state restores).
- `main-core.cjs`: Added Vietnamese (Tiếng Việt), Indonesian (Bahasa Indonesia), and `vi-*`/`id-*`/`in-*`/`yue` (Cantonese variant) locale normalization branches to the i18n language table; added authorization classification helper — `authorizedByApproval → {kind:"approval"}`, `authorizedByStanding → {kind:"standing"}` (displayable only for `"global"` scope), else `{kind:"none"}`.
- `proto.cjs`: Team messages add `owning_team_name` / `joined_at` / `archived`; reverse cleanup removes `expected_visibility`, `group_id+user_ids`, `monthly_spending_limit_dollars`, `total_groups/total_pages`, `ant_cyber_approved/ant_cyber_verification_status`, and `first_name/last_name`.
