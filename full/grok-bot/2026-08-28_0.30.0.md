# Grok Bot 0.30.0

English | [简体中文](../../zh-CN/full/grok-bot/2026-08-28_0.30.0.md) · [Highlight](../../grok-bot/2026-08-28_0.30.0.md) | **Full Detail**

- **Release Date**: 2026-08-28
- **Platforms**: `mac`, `win`, `ubuntu`
- **Summary**: Major release: iMessage read/write (@anysphere/messages-mac) and voice call harness (wss://api.x.ai/) land together, alongside local agent mailboxes and virtual cards

## Highlights

- **Features**: iMessage/local messaging integration — local tool actions `send-imessage`, read-messages, and resolve-media (alongside host Chrome CDP injection states: open-cdp-ok/open-cdp-missing, chrome-closed, host-chrome-locked, inject-rejected); voice calls (+@anysphere/grok-bot-voice-call-harness, DIALABLE_ORIGIN=wss://api.x.ai/, mintable models grok-voice-latest / grok-voice-think-fast-2.0); local agent mailbox stream (`StreamLocalAgentMailbox`, `LocalSubscriptionTool` definition and invocation); Bugbot setup (BugbotSetupAction); Canvas workspace (CanvasStoreRoot/CanvasVisibility); virtual confirmation cards (GrokBotVirtualCard{Outcome,RaiseOutcome,Resolution}); xAI-Cursor team merge (`ConfirmXaiCursorTeamMerge`/CancelProposal/GetStatus/MembershipPreview); MCP OAuth browser flow (mcp-auth-completed/mcp-auth-watch/mcp-tools-discovery).
- **Protocol / Main Process**: `GetGrokBotRuntimeCapabilities`, `GetGrokBotTemplateExportPolicy`, `GetTeamSandShareBotExportSettings`, and `GetTeamOffboardingConfigInternal`; connector catalog expanded to 14 entries (workspace/slack/notion/salesforce/microsoft-365/linkedin/zoom/github/jira/figma/hubspot/canva/trello/monday…); new keys enterprise-usage, team-server, shared-docker, toggle-sync, install-backfill, and link-preview-cache.
- **UI**: usage-pane usage dashboard; localized emoji-messages (af/ar/el/he).
- **Infrastructure**: +@anysphere/grok-bot-voice-call-harness, +@anysphere/messages-mac (dependencies 81→83); added URL wss://api.x.ai/ and resident ajv JSON-schema validator.

## Code & Protocol Details

- `main.cjs`: Local agent mailbox stream protocol family: `StreamLocalAgentMailboxRequest/Response`, `LocalAgentMailbox{Delivery,Ended,Entry,Gap}`, and end-reason enum `MIGRATED_TO_CLOUD`/`NO_ACTIVE_SUBSCRIPTIONS`/`STORE_DELETED`.
- `main.cjs`: Virtual confirmation card RPCs: `RaiseGrokBotVirtualCard` and `ResolveGrokBotVirtualCardApproval`.
- `main.cjs`: Full xAI-Cursor team merge suite: `ConfirmXaiCursorTeamMerge`, `CancelXaiCursorTeamMergeProposal`, `GetXaiCursorTeamMergeStatus`, and `GetXaiCursorTeamMembershipPreview`.
- `main.cjs`: Marketplace operations expansion: `Create/GetGrokBotMarketplaceCategoryInternal`, `Create/GetGrokBotMarketplaceCreatorInternal`, and `GetPublicGrokBotMarketplaceListing`; plus `GetGrokBotRuntimeCapabilities`, `GetGrokBotTemplateExportPolicy`, `CreateGrokBotTemporalAgent`, and `BugbotSetupAction`.
- `main.cjs`: Resident ajv JSON-schema validator ("\$schema must be a string", "keyword is always validated", and full message suite) + AnyCode parser token name table (`BlockCommentTrivia`/`CloseBraceExpected`…).
