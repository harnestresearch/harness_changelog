# Grok Bot 0.64.0

English | [简体中文](../../zh-CN/full/grok-bot/2026-09-30_0.64.0.md) · [Highlight](../../grok-bot/2026-09-30_0.64.0.md) | **Full Detail**

- **Release Date**: 2026-09-30
- **Platforms**: `mac`, `win`
- **Summary**: Connector document deep-link type registry established (16 types across GitHub/Jira/Linear/Google/Slack, etc.); agents support manager assignment and disabling drafting

## Highlights

- **Features**: Connector document type registry (resolving URL deep links into `provider+id`): `confluence-page`, `figma-slides`, `github-file`, `github-gist`, `github-issue`, `github-pull-request`, `gmail-draft`, `google-docs`, `google-drive`, `google-sheets`, `google-slides`, `jira-issue`, `linear-document`, `linear-issue`, `slack-canvas`, `slack-message` (plus `box` / `dropbox` / `airtable` / `coda` / `miro` / `canva` / `hex` / `google-calendar-event`, etc.). Agent governance: `AddGrokBotAgentManager` / `ListGrokBotAgentManagers` / `RemoveGrokBotAgentManager` (assigning manager users), `SetGrokBotAgentDraftingDisabled` (disabling agent drafting), and `RemoveGrokBotRoomPeople`.
- **Protocol / Main Process**: New permission scopes: `agent_serve_deployment.deploy` / `read` / `secrets` / `manage_access` and `grok_bot_agent.manage` (OAuth-style authorization model for "agent serve" deployments); admin meeting lookup RPCs `AdminLookupGrokBotMeetings` / `AdminLookupGrokBotMeetingsByAgent`; artifact telemetry `sand.artifact.opened` / `edit_attempted` / `edit_saved` / `link_copied` / `revisited_from_library`; added `linear.app` to known domains.
- **UI**: New components `card-check-row`, `link-brand-logo`, `member-chip`, `team-setup-pills`, `team-setup-row`, `voice-memo-waveform` (voice memo waveform), `reference-menu`, `plugin-detail-view`.
- **Infrastructure**: No dependency additions or removals; large-scale renderer rebuild (192 files).

## Code & Protocol Details

- `main-app.cjs`: Expanded connector deep-link parsing: Jira (`hostname.endsWith(".atlassian.net")` + `/browse/<key>` -> `provider:"jira-issue", id:\`\${t}/\${a}\``), Confluence pages paths, GitHub issues (`\${r}/\${n}#\${i}`), and blob file path reassembly (`n0e=/^[A-Za-z0-9_.-]+\$/` validating `owner/repo`).
- `main-app.cjs`: Agent identity management client: `updateIdentity(id, {avatarPngBase64, ...})` -> `updateGrokBotAgent({...partialUpdate:!0, avatarChange})`, `listManagers` / `addManager`, plus `creationRoute` reporting field on agent creation.
- `main-core.cjs`: Added Finance/Plaid usage guidelines to prompts: `"Finance holds the user's bank, credit card, loan and brokerage accounts linked through Plaid...list Finance's connections and accounts and use them before opening that institution's website"`, explicitly instructing agents to read underlying chart data rather than relying on computer-use chart reading.
- `main-app.cjs`: Added telemetry `artifactEngagement: {ingest: a => {... trackEvent(c,d)}}` (reporting artifact open/edit engagement).
- `proto.cjs`: Registered `SetGrokBotAgentDraftingDisabled` and `RemoveGrokBotRoomPeople` service methods; removed `AdminDeleteSandBoxStoreManifest`.
