# Grok Bot 0.26.0

English | [简体中文](../../zh-CN/full/grok-bot/2026-08-25_0.26.0.md) · [Highlight](../../grok-bot/2026-08-25_0.26.0.md) | **Full Detail**

- **Release Date**: 2026-08-25
- **Platforms**: `mac`, `win`
- **Summary**: Packaging overhaul cutting asar size in half + organization/team management protocols + PR Code Tour — a major same-day architecture and team-collaboration release

## Highlights

- **Features**: Organization service account management (`OrganizationServiceAccount`, Add/Remove/GetOrganizationGroupServiceAccounts); team credit grants (`CreateTeamCreditGrantInternal`/`ListTeamCreditGrantsInternal`); AgentStore recycle bin (`ListAgentStoreTombstones`, `UndeleteAgentStoreFiles`); PR Code Tour generation (`GeneratePrCodeTourForStack`, `GetPrCodeTourStackContext`); PrivateWorker cloud execution (`PrivateWorkerRequestRepo`, `ReleasePrivateWorkerClaim`); AutoReview mode reset (ResetTeam/GroupAgentRunModeToAutoReview); web link previews (link-preview); Slack connection object `GrokBotSlackConnection`.
- **Protocol / Main Process**: Embedded OpenTelemetry export protocol (full `opentelemetry.proto.trace.v1` Span/ResourceSpans/ExportTraceServiceRequest suite); new setting keys cookie-allow-items and open-settings; removed a batch of legacy channels (auth-watch-poll, box-config-push, composer-drafts, computer-demo, etc., some of which return in later versions).
- **UI**: Migrated syntax highlighting from highlight.js to Shiki (renderer adds 80+ language grammar assets: asm/astro/clojure/rust…).
- **Infrastructure**: +@anysphere/otel-proto, replaced @sentry/node with @sentry/node-core, -highlight.js; asar file count dropped 783→349: all 511 native and pure-JS dependency files under dist/deps (better-sqlite3, tree-chunk-napi, etc.) externalized outside the asar archive.

## Code & Protocol Details

- `chrome-import-worker.cjs`: Added `listCookieAllowItems` / `listCookieAllowItemsInDir` / `parseCookieAllowIdentityRow` (parsing host_key/name/path from SQLite cookie rows), plus message branch `kind==="list-cookie-allow-items" ? {kind:"cookie-allow-items", items:…}` — enabling enumeration of host Chrome cookies eligible for authorization.
- `main.cjs`: Added organization service account management RPC family: `Add/RemoveOrganizationGroupServiceAccounts`, `GetOrganizationServiceAccounts`, and `GetOrganizationGroupServiceAccountMembers`.
- `main.cjs`: AgentStore recycle bin (`ListAgentStoreTombstones`/`UndeleteAgentStoreFiles`), PR Code Tour (`GeneratePrCodeTourForStack`/`GetPrCodeTourStackContext`), cloud execution worker (`ReleasePrivateWorkerClaim`), and team credit grants (`CreateTeamCreditGrantInternal`/`ListTeamCreditGrantsInternal`) are all brand-new RPCs absent in 0.25.0.
- `main.cjs`: Added `ReadGrokBotAgentAttachmentChunk` (chunked reading of agent attachments).
- Packaging overhaul: Externalized all of dist/deps out of asar, shrinking `main.cjs` 7.49MB→6.25MB; large encoding table / wasm base64 blocks appearing in the diff were verified as present in both versions.
