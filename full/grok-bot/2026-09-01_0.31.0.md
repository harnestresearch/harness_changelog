# Grok Bot 0.31.0

English | [简体中文](../../zh-CN/full/grok-bot/2026-09-01_0.31.0.md) · [Highlight](../../grok-bot/2026-09-01_0.31.0.md) | **Full Detail**

- **Release Date**: 2026-09-01
- **Platforms**: `mac`, `win`
- **Summary**: Payments and team administration: Stripe Link payment methods, form vault, and team settings copy/invites/checklists

## Highlights

- **Features**: Payments — `ListGrokBotStripeLinkPaymentMethods` (Stripe Link), `GetGooglePlayBillingAccountId`, and virtual card spending limit semantics (SPENDING_LIMITS/BANK_ACCOUNT); form vault (`UpsertGrokBotUserFormVaultEntry`/Delete/List, FormVaultEntry/Key — centralized storage for user form credentials); team administration — `OrganizationTeamSettingsCopy` (with Preview), `RemoveOrganizationMember`, `SendTeamSandOnboardingInvites`, `UpdateTeamSandSetupChecklistItem` (SandSetupChecklistItemState), `GetTeamGrokBotTrial`, and `GetTeamOriginDisabled`; Agent session list (`GrokBotAgentSession`/List); messaging toggle reporting (`UpdateSandMachineMessagesEnabled`); outbound proxy rules (anyrun.v1 EgressProxyRule/BasicEgressProxyAuth/OidcEgressProxyAuth).
- **Protocol / Main Process**: `SCMRemovePullRequestFromMergeQueue`, `SetPrCodeTourSectionReviewed`, and `ReconcileLocalAgentMailboxWatches`; new keys access-key/api-key/private-key (credential types), shipit-diagnostics, sand-html-preview, code-cache-read/write, and until-signal.
- **UI**: bot-template-share-card-frame, mcp-connector-status, and local-tools-row.
- **Infrastructure**: Split `main-app.cjs` out of electron-main (ending the single-file main bundle era); ShipIt updater diagnostic logs (ShipIt_stderr.log/sanitized.log); expanded sandbox signal handling (SIGALRM/SIGPOLL/SIGUSR2, etc.); bundle ID `com.anysphere.sand` appears; build system starts prefixing shared chunks with `chunk-`.

## Code & Protocol Details

- **Bundle split**: Added `dist/electron-main/main-app.cjs` (7.3MB, carrying all application logic), shrinking `main.cjs` into a ~12KB loader — NODE_PATH/deps initialization and account/onboarding/cookie-import IPC handlers were all migrated out of `main.cjs` (accounting for the 20 diff hunks in `main.cjs`).
- `main-app.cjs`: Form vault RPCs: `GrokBotUserFormVaultEntry/Key` and Upsert/Delete/ListGrokBotUserFormVaultEntries(ListKeys) — centralized storage and retrieval for user form credentials.
- `main-app.cjs`: Payments and teams: `ListGrokBotStripeLinkPaymentMethods` (Stripe Link, 5 occurrences), `GetGooglePlayBillingAccountId`, `OrganizationTeamSettingsCopy(Preview)`, `RemoveOrganizationMember`, `GetTeamGrokBotTrial`, `GetTeamOriginDisabled`, and `GrokBotAgentSession(List)` (agent session listing).
- `main-app.cjs`: Outbound proxy rule protocols: anyrun.v1 `EgressProxyRule`/`BasicEgressProxyAuth`/`OidcEgressProxyAuth`.
- `main-app.cjs`: Added `MainLoopVoicePrompt` with static system prompt body `SHARED_BODY=["The user can call you. On a call you speak with them over your own voice side…"]` — behavioral prompt for voice calls injected into the main loop.
- `renderer/*`: Build system begins adding `chunk-` prefixes to shared chunks (`"./dagre-…"`→`"./chunk-dagre-…"`).
