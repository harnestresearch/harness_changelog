# Grok Bot 0.56.0

English | [简体中文](../../zh-CN/full/grok-bot/2026-09-17_0.56.0.md) · [Highlight](../../grok-bot/2026-09-17_0.56.0.md) | **Full Detail**

- **Release Date**: 2026-09-17
- **Platforms**: `mac`, `win`
- **Summary**: GitHub connection flow and connector OAuth code exchange launched (`grok.com/connectors-oauth-exchange-code`); main process adds proxy environment variable support

## Highlights

- **Features**: SCM connections: `prepareGithubConnectFlow` / `CompleteGithubConnectFlow` (outcomes include `CONNECTED` / `PENDING_APPROVAL` / `NEEDS_CONFIRMATION`), `GetGithubRepoAccessStatus`, and `ScmConnectIntentTarget.User`; connector OAuth code exchange routed through the cloud. Team policy (`provider-team-policy`, `"The team policy has not been read."`), email inbox settings section (`email-section`, `provider-grok-bot-email-inbox`), and teammate intro (`team-bot-teammate-intro`) added to Settings.
- **Protocol / Main Process**: Added URLs `https://grok.com/connectors-oauth-exchange-code/` and `https://www.cursor.com/agents/mcp/oauth/callback`, mapping `gb` / `gw` / `gd` prefixes to callbacks (including the `grokbot://mcp/oauth/callback` deep link); added proxy support (`HTTP_PROXY` / `HTTPS_PROXY` / `ALL_PROXY` / `NO_PROXY`) in the main process; added setting keys `box-unreachable`, `carry-over` (carrying user secrets/plugins over with bots), and `invalid-name` / `invalid-value` / `reserved-name` / `reserved-prefix` / `reserved-sandbox` (bot secret naming validation).
- **UI**: Settings page added email section, team policy section, and team agent rows (`team-agent-rows`); localized strings added copy such as "Configure team bot".
- **Infrastructure**: `asar` file count 515 -> 506; no dependency additions or removals.

## Code & Protocol Details

- `main-app.cjs`: Added SCM connect RPCs `prepareCursorScmConnect({provider, forceOauth})` / `completeCursorScmConnect(state, code)` / `getCursorGithubRepoAccess(repoSlug)`; added user secret migration `carryUserSecretsToGrokBot({serverId, names})` -- reading values via `userSecrets.reveal` and writing to `grokBot.secrets.put` / `boxSecrets`, enumerating `personalSecretNames` first in team scenarios (reporting failures under `"user-secrets"` / `"carry-over"`); removed `userFormVault` RPCs (`getUserFormPrefill` / `listUserFormVaultEntries` / `updateUserFormVaultEntry`) and two auto-review admin gates (`sand_auto_review_admin_enforce` / `sand_auto_review_admin_rules`); merged Slack connection mappings into the agent list (`new Map(i.slackConnections.map(c=>[c.agentId, c]))`); added `logComposerTriggerExperimentExposure({trigger})`; switched process detection to reading `` `/proc/${pid}/comm` `` (`attemptSync`).
- `main-core.cjs`: Made process name detection cross-platform -- `win32` uses PowerShell `(Get-CimInstance Win32_Process -Filter 'ProcessId=...').Name`, while other platforms use `ps -p <pid> -o comm=`; added prefix truncation constant `l6=15`.
- `proto.cjs`: Added `PrepareGithubConnectFlowRequest` (`githubRepo` / `source` / `verifierHash` / `forceOauth` / `completionBinding`) and `ScmConnectIntentSource` enum (`PORTAL / GLASS_CLOUD_AGENT / GLASS_DIFF / GLASS_AUTOMATIONS`).
- `renderer/prompt-editor`: Added experiment flags for slash commands and `@` mention triggers (`hr = {slash: Ne.isExperimentStarted, at: Ae.isExperimentStarted}`).
