# ZCode Desktop 3.12.3

English | [简体中文](../zh-CN/zcode/2026-09-16_3.12.3.md) · **Highlight** | [Full Detail](../full/zcode/2026-09-16_3.12.3.md)

- **Release Date**: 2026-09-16
- **Platforms**: `mac`, `win`, `ubuntu`

## Highlights

- **Plan Mode & Queued Messages**: Improved coordination between Plan Mode and queued messages, fixed missing Plan Mode menu descriptions, and refined tool usage limits for idle-time tasks.
- **OpenCode Go Provider & Plan Banner Polish**: Added the OpenCode Go provider template and site mapping, improved provider names/icons/plan banners, and added a direct re-login action with forced API key refresh when plan retrieval fails.
- **Database, Startup & Untracked File Performance**: Streamlined database initialization and schema upgrades, accelerated session startup, and sped up untracked Git file counting.
- **Streaming, OpenRouter & Linux Auto-Update Fixes**: Fixed Provider config read blocking/errors, interrupted streaming response retries, OpenRouter compatibility and connection tests, resumed subagents leaking into the main task list, and Linux auto-update failures.
