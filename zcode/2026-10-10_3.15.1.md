# ZCode Desktop 3.15.1

English | [简体中文](../zh-CN/zcode/2026-10-10_3.15.1.md) · **Highlight** | [Full Detail](../full/zcode/2026-10-10_3.15.1.md)

- **Release Date**: 2026-10-10
- **Platforms**: `mac`, `win`, `ubuntu`

## Highlights

- **UI Plugins (MCP Apps) & Interactive Message Views**: Added support for rich UI plugins (MCP Apps) and visual interactive components directly inside the conversation stream.
- **Smarter Workflows & Safer Autonomous Mode**: Workflows now support pre-creation parameter tuning, live concurrency adjustments, saved replay runs, and per-subagent model assignment; Autonomous Mode now prompts for confirmation before executing dangerous commands.
- **Feishu Collaboration & Account Perks**: Collaborate with ZCode in Feishu group chats and standalone topics; added account menu plan inspection/user ID copy, GLM HighSpeed subscriber trials, and the referral rewards campaign.
- **Browser Permissions, Linux Tray & Security Fixes**: Added site permission prompts (such as camera access) in the built-in browser—closing a default-allow security gap—patched a Windows deep-link launch vulnerability, and enabled closing to the system tray on Linux.
