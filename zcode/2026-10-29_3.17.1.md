# ZCode Desktop 3.17.1

English | [简体中文](../zh-CN/zcode/2026-10-29_3.17.1.md) · **Highlight** | [Full Detail](../full/zcode/2026-10-29_3.17.1.md)

- **Release Date**: 2026-10-29
- **Platforms**: `mac`, `win`, `ubuntu`

## Highlights

- **Electron 44 / Chromium 152 Runtime Upgrade**: Upgraded the desktop engine from Electron 41 (Chromium 146) to Electron 44.7.0 (Chromium 152, Node.js 24.21; macOS minimum requirement raised to macOS 13 Ventura from the `3.17.x` line onward).
- **ZCode Sites Official Plugin & One-Click Plugin Updates**: Added the built-in `zcode-site` plugin (`v0.4.2`) with a sidebar **Sites** panel and `/site-*` commands to publish projects as live preview/shareable websites; added one-click **Update All** in Plugin Settings plus risk confirmation before adding unofficial marketplaces.
- **Image Preview Annotation Editor**: Added brush, rectangle, ellipse, arrow, text, eraser, selection/move, color picker, and undo/redo tools directly in image previews, saving annotated images straight into the active chat composer.
- **Unified Remote Data Sync & Remote Server Controls**: Consolidated remote syncing into a unified Settings view (pushing commands, hooks, MCP servers, plugins, skills, subagents, and auto-synced model providers to remote hosts); converted remote devices into a compact searchable list with menu actions to **Stop**, **Restart**, or **Reinstall** ZCode Server.
- **Batch Project Management, Unread Filter & Task Runtime Restart**: Added multi-select project removal in Settings with optional ZCode session/checkpoint/memory data deletion (size preview + typed confirmation) and local project restoration; added an **Unread** task filter, task/agent process recovery restart, and the `/reload` slash command.
- **Node-less MCP Startup, Workspace Trust Gate & Full Access Confirmation**: Bundled `npm 12.2.0` so stdio MCP servers launch on machines without a local Node.js installation; added a workspace MCP/Hook trust gate, a **Full Access** confirmation dialog, and a **Personalization** Settings section for custom local agent instructions.
- **Workflow Quota Auto-Resume, `CronPauseSelf` & 39 New Model Presets**: Dynamic workflows paused by quota exhaustion automatically resume once quota resets; scheduled automations can pause themselves when user-defined stop conditions are met; added 13 provider templates and 39 model presets (`Kimi K3.1 Pro`, `MiniMax M3.1 Flash`, `GLM-5.3`, `DeepSeek-V4-Flash`, `Doubao Seed 2.1`, `Grok 4.7`, etc.), full-card preview click-to-open, file card **Save As / Open With** menus, and complete display of built-in model tool calls.
