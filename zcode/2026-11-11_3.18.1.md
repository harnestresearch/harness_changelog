# ZCode Desktop 3.18.1

English | [简体中文](../zh-CN/zcode/2026-11-11_3.18.1.md) · **Highlight** | [Full Detail](../full/zcode/2026-11-11_3.18.1.md)

- **Release Date**: 2026-11-11
- **Platforms**: `mac`, `win`, `ubuntu`

## Highlights

- **Guided Microphone Permission Reset (macOS)**: Added a step-by-step permission guide popover on the voice input button supporting one-click microphone permission reset, direct jump to System Privacy Settings, and app relaunch prompts across all 5 UI languages.
- **macOS Font Smoothing Setting**: Added a dedicated "Font Smoothing" toggle in macOS desktop Settings (enabled by default) with instant updates across open windows.
- **Flexible Sidebar Layout & Browser Picker Polish**: Expanded maximum sidebar width, allowed dragging the chat bar narrower to reduce page obstruction, prevented clicking web page elements from switching to full view or covering content with popups, and stopped accidental dragging on the project search menu.
- **Login, Updater & Diagnostic Log Fixes**: Fixed mainland China website login failures, leftover old processes causing update failures, update installation aborting on backup failure, repeated summary refreshes, and subagent source label glitches, while automatically bundling sanitized memory diagnostic snapshots into exported logs.
