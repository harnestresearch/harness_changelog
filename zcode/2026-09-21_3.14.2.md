# ZCode Desktop 3.14.2

English | [简体中文](../zh-CN/zcode/2026-09-21_3.14.2.md) · **Highlight** | [Full Detail](../full/zcode/2026-09-21_3.14.2.md)

- **Release Date**: 2026-09-21
- **Platforms**: `mac`, `win`, `ubuntu`

## Highlights

- **Live Concurrency Tuning on Running Workflows**: Adjusts the maximum subagent concurrency of an active workflow run directly in place—releasing waiting subagents immediately when raised or parking excess subagents at their next turn boundary when lowered—without stopping or restarting the task.
- **Workflow Context Diet & Faster Script Iteration**: Moves the full workflow authoring API contract out of always-on tool descriptions into the on-demand `dynamic-workflows` skill (loaded only when authoring workflows) and tracks compiled workflow drafts as editable files, substantially cutting token usage.
- **Non-Uninstallable Built-in Workflow Skill & `/workflow` Command**: Relocates `dynamic-workflows` and `/workflow` from the optional `zcode-guide` plugin into built-in CLI capabilities (`bundled-skills`) so workflow tools never lose their documentation if plugins are disabled.
- **Bounded Real-Time Status for Large Workflows**: Caps displayed workflow steps and subagent roster rows with clear `"N more subagents unlisted"` and `"Showing X/Y steps"` indicators, preventing large runs from overwhelming context or UI rendering.
