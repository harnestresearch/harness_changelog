Official release notes accumulate all features and fixes introduced across preview builds [3.18.0](2026-11-10_3.18.0.md) and [3.18.1](2026-11-11_3.18.1.md) alongside the four net-new `3.18.2` fixes below.

## Highlights

- **Seamless Sign-In Preservation After Data Directory Migration**: Automatically shares the OS keyring decryption key with the newly copied credentials folder when switching data storage directories, fixing sign-in loss and forced re-authentication after migration.
- **Linux Login Fallback Without System Keyring**: Automatically falls back to a permission-hardened (`0600`) local private key file on Linux desktops when no system Secret Service keyring is available, resolving login failures on minimal or headless Linux setups.
- **Standalone Start Plan Access for Mainland China (`zai_cn`) Accounts**: Decouples Start Plan credential loading from full OAuth access tokens and maps `zai_cn` accounts into the BigModel Start Plan family so China accounts can use Start Plan benefits without linking BigModel first.
- **Windows Update Check Reliability**: Fixed an issue where checking for updates on Windows could fail under system restrictions or when installation/user paths contained special characters.
