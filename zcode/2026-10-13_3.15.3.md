# ZCode Desktop 3.15.3

English | [简体中文](../zh-CN/zcode/2026-10-13_3.15.3.md) · **Highlight** | [Full Detail](../full/zcode/2026-10-13_3.15.3.md)

- **Release Date**: 2026-10-13
- **Platforms**: `mac`, `win`, `ubuntu`

## Highlights

- **Auto-Updater Exit Hang Fix & Upgrade Recovery Guidance**: Fixes the `3.15.1`/`3.15.2` updater hang where clicking update closed the UI without terminating the process, and automatically relaunches the app if an update install fails after shutdown starts (users upgrading *from* `3.15.1`/`3.15.2` may still need one final Force Quit / process kill—or a fresh full installer download—because the older build runs its own shutdown handler).
- **Parallel Agent & Rapid Model Call Stability**: Prevents intermittent request signing failures when multiple Agents run in parallel or call models rapidly across credential refreshes.
- **Onboarding Guide & Slow-Network Fixes**: Stops repeatedly showing the onboarding guide to users who already completed or skipped it, and prevents slow networks from blocking entry to the main interface.
