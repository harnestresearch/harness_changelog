# ZCode Desktop 3.16.1

English | [简体中文](../zh-CN/zcode/2026-10-17_3.16.1.md) · **Highlight** | [Full Detail](../full/zcode/2026-10-17_3.16.1.md)

- **Release Date**: 2026-10-17
- **Platforms**: `mac`, `win`, `ubuntu`

## Highlights

- **Unified Remote Devices & Persistent Remote Sessions**: Added Remote Device management in Settings unifying SSH servers, WSL distributions, and Docker containers (with `~/.ssh/config` import, 7-day auto-reconnect on startup, and local-to-remote workspace data migration); remote sessions now run persistently so local disconnects no longer interrupt active tasks.
- **On-Demand Tool Search (`ToolSearch`)**: Added Tool Search (`Auto` / `Local` / `Off`, plus CLI `--toolsearch-mode`) so the assistant dynamically searches and loads tools on demand instead of sending the entire tool catalog upfront.
- **Sidebar Document Viewers & Multi-Tab File Browser**: Upgraded Word, PDF, PowerPoint, and Excel plugins (`0.2.0`/`0.2.1`) with built-in MCP servers and sidebar viewer panels supporting content references into chat; moved file browsing into a multi-tab side panel with **Full View** mode.
- **Multi-Folder Local Projects & Direct Composer Controls**: Local projects now attach multiple source folders (with a designated primary directory) and support renaming; the chat input toolbar switches models, adjusts thinking effort, and selects team plans directly.
- **Plugin Marketplace, Popover Sharing, Project-Grouped Archives & Mobile Remote Auth**: Added a plugin marketplace, popover conversation sharing with range selection and workflow/image previews, project-grouped collapsible archived sessions, image preview copy/download/chat-reference actions, account login & device management for mobile remote control, Windows taskbar/tray unread reminders, and MiMo API + Token Plan access.
- **Security & Stability Fixes**: Fixed a Windows local file out-of-bounds read vulnerability, sensitive connection log leaks, lost drafts/inputs during model switches or creation failures, unresponsive chats at context limits, misplaced attachments on session restore, database upgrade lock lag, and missing initial terminal output.
