# ZCode Desktop 3.17.2

English | [简体中文](../zh-CN/zcode/2026-11-02_3.17.2.md) · **Highlight** | [Full Detail](../full/zcode/2026-11-02_3.17.2.md)

- **Release Date**: 2026-11-02
- **Platforms**: `mac`, `win`, `ubuntu`

## Highlights

- **Actionable MCP Startup Failure Diagnostics**: Shows specific failure causes and step-by-step troubleshooting guidance across 19 error categories when an MCP server fails to start.
- **Plan-Mode & Custom Command Script Permission Hardening**: Enforces Plan-mode restrictions consistently across main sessions and subtasks so high-risk operations cannot slip through, and routes embedded `!` shell blocks in custom commands through standard `Bash` permission confirmation instead of executing them silently during prompt expansion.
- **Restricted Local Web Preview Scope**: Tightens built-in browser local preview navigation (`zcode:browser-view-load-url`) with explicit URL scheme validation to prevent unauthorized local resource access.
- **Session Ownership, Plugin Path & Platform Fixes**: Fixes cross-session mix-ups when switching or restoring sessions, Windows plugin command path script errors, missing Chinese/English locale resources in macOS installers, Windows 64-bit installer component issues, occluded Windows window restoration, and Computer Use multi-session cursors / draft MCP configuration UI polish.
