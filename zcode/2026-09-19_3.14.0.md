# ZCode Desktop 3.14.0

English | [简体中文](../zh-CN/zcode/2026-09-19_3.14.0.md) · **Highlight** | [Full Detail](../full/zcode/2026-09-19_3.14.0.md)

- **Release Date**: 2026-09-19
- **Platforms**: `mac`, `win`, `ubuntu`

## Highlights

- **Dynamic Multi-Agent Workflows (`/workflow`)**: Orchestrate multiple subagents to collaborate on complex tasks using a single workflow script, launched directly from the composer `+` menu or `/workflow`.
- **Office & Coding Modes + Custom Shortcuts**: Switch between dedicated Office and Coding interface modes, record custom keyboard shortcuts that apply immediately, and get tailored task/plugin recommendations via a new 3-step onboarding flow.
- **Standalone Start Plan, Batch Cleanup & Perks**: Use Start Plan independently, grant Full Access directly from approval dialogs, batch-delete archived tasks, check updates from the Help menu, and access the new Invitation Rewards Center alongside refined CUA and phone remote control.
- **Stability & Platform Polish**: Fixed post-upgrade black screens, Windows custom model config loading and duplicate Explorer windows, remote built-in browser tab closing, Start Plan balance display, and background-workflow sessions vanishing from the task list.
