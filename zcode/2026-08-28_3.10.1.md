- **Platforms**: `mac`, `win`, `ubuntu`

## Highlights

- **Searchable Thinking Traces & Turn Summaries**: Expanded thinking traces by default with full-text search, plus an execution summary and duration view when each conversation turn finishes.
- **Faster Editing, Skills Shortcut & One-Click Plugins**: Send edited messages immediately without queuing, jump to skills from the composer menu, and install prompt-template plugins in one click.
- **Configurable MCP Protocol Versions & Weekend Plan**: Configure MCP server protocol versions with clear fallback guidance, rename Settings "Browser" to "Browser Control", and claim the Weekend Plan early.
- **Resilience & Cross-Platform Fixes**: Automatic retry on interrupted/blank model responses, fixes for login callback and MCP OAuth glitches, multi-directory workspace skill listing, macOS/remote Computer Use fixes, and Windows background process cleanup.
