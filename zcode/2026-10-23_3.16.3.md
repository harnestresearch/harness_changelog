# ZCode Desktop 3.16.3

English | [简体中文](../zh-CN/zcode/2026-10-23_3.16.3.md) · **Highlight** | [Full Detail](../full/zcode/2026-10-23_3.16.3.md)

- **Release Date**: 2026-10-23
- **Platforms**: `mac`, `win`, `ubuntu`

## Highlights

- **Independent Session Docs & Lower Plugin Memory**: Document viewing state is now isolated per session so multiple windows never interfere, while document plugins share a single process with a capped background retention timeout.
- **Easier Login Fallback & Issue Reporting**: Added a manual copy-link fallback when browser login links fail to open automatically, plus a "Copy Device ID" option in the Help menu.
- **IME, Terminal & Subagent Reliability**: Fixed input box lag on long text/IME input, preserved uncommitted IME text across task switches, enabled subagents to inspect open session documents, auto-rebuilt missing built-in component files, and ensured closing the last terminal tab terminates its background process.
- **Remote Control & Data Integrity Fixes**: Reduced message latency and improved error reporting in remote sessions, fixed mobile remote terminal and remote-only model testing issues, and resolved concurrent multi-session write corruption and container plugin cache update failures.
