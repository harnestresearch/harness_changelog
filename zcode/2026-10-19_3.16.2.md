# ZCode Desktop 3.16.2

English | [简体中文](../zh-CN/zcode/2026-10-19_3.16.2.md) · **Highlight** | [Full Detail](../full/zcode/2026-10-19_3.16.2.md)

- **Release Date**: 2026-10-19
- **Platforms**: `mac`, `win`, `ubuntu`

## Highlights

- **Remote Linux `glibc >= 2.28` Pre-Flight Compatibility Check**: Validates the remote host's `glibc` version during connection probing and displays clear OS upgrade guidance (`RHEL 8+`, `Ubuntu 20.04+`, or `Debian 10+`) when connecting to older Linux distributions.
- **Taskbar & System Tray Unread Status Dot Polish**: Replaces raw taskbar badge pixels with antialiased unread status dots (tailored for Windows 10 and Windows 11 positioning) and adds multi-DPI (`1x` / `2x`) system tray badge compositing.
- **Plugin Install Locking & Dynamic Workflow Refinements**: Serializes workspace plugin installations behind a write lock and refines dynamic workflow mode negotiation and stop-failure classification.
