# ZCode Desktop 3.18.0

English | [简体中文](../zh-CN/zcode/2026-11-10_3.18.0.md) · **Highlight** | [Full Detail](../full/zcode/2026-11-10_3.18.0.md)

- **Release Date**: 2026-11-10
- **Platforms**: `mac`, `win`, `ubuntu`

## Highlights

- **Composer Voice Input**: Dictate prompts directly in the chat input box with real-time speech-to-text streaming and clear microphone/audio device guidance.
- **Parallel Tasks with Managed Git Worktrees**: Spin up isolated Git Worktrees from any branch or fork any chat message into its own Worktree to run parallel tasks side by side, managed from a dedicated Worktrees sidebar view.
- **Extensions Marketplace & Tiered Permissions**: Browse, install, and hot-reload extensions with clear activation prompts and granular session permission levels (notifications, read-only, read-write, or full access).
- **Built-in Design System & Visual Browser Editing**: Shipped a built-in Design capability paired with visual click-to-edit inside the built-in browser—select elements to tweak colors, spacing, typography, alignment, and border radius directly back to local code, plus device viewport presets and PNG/PDF export.
- **Multi-Session Orchestration & Proactive Plugin Suggestions**: Let root sessions create, fork, coordinate, and monitor sub-sessions (with approval safeguards on changes) and recommend relevant workspace plugins with one-click install cards.
- **Message Editing, Share Management & Archive Cleanup**: Edit recent or queued messages in place, set expiration times and revoke/restore links from a central Share Management page, and bulk-purge archived sessions without breaking shared attachments.
- **Multi-Account Sign-In, OS Keyring & New Languages**: Added `zai_cn` sign-in and multi-account switching, OS keyring credential protection, Japanese/Korean/Russian UI languages, grouped tool call summaries, quote comments, image annotation, and ZCode Sites traffic analytics with doubled container resources.
