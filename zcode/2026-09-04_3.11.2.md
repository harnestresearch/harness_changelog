# ZCode Desktop 3.11.2

English | [简体中文](../zh-CN/zcode/2026-09-04_3.11.2.md) · **Highlight** | [Full Detail](../full/zcode/2026-09-04_3.11.2.md)

- **Release Date**: 2026-09-04
- **Platforms**: `mac`, `win`, `ubuntu`

## Highlights

- **PDF & Media Previews in Conversations**: Upload, read, and preview PDF files alongside in-chat previews for images, videos, and other media.
- **Per-Workspace Plugins & Action Transparency**: Install plugins per workspace with direct update notifications, and inspect specific reasons whenever an operation is blocked.
- **Sidebar, Drafts & Browser Isolation**: Close sidebar tabs via middle-click, view draft tasks in the sidebar, remember built-in browser window sizes, open local links in the default browser, and isolate browser windows across tasks.
- **Remote, WSL & Linux Reliability**: Fixed mid-conversation model switching/context loss, improved SSH and WSL remote workspace stability, isolated session recovery from plugin timeouts, auto-truncated overly long command outputs, and lowered Linux file-watching overhead.
