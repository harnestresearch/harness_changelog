## Highlights

- **Unified Connector Accounts, MCP OAuth & Seven Optional Connectors** _(Infrastructure Default-On; Connectors Standalone Opt-In)_: The Plugins page gains a unified connector account surface with MCP OAuth authorization, automatic token refresh, and shared CLI account / upstream skill management (`ctx.connectorAccounts`, `ctx.mcpAccounts`, `ctx.cliAccounts`, `ctx.upstreamSkills`), plus opt-in on-demand MCP tool loading (`toolLoading: 'on-demand'`). Seven new optional standalone connector plugins ship for **Linear**, **Notion**, **Tencent Docs** (hosted MCP OAuth, defaulting to on-demand tool loading), **Feishu**, **WeCom**, **Tencent Meeting**, and **DingTalk** (vendor CLI wrappers; **Feishu** and **WeCom** support macOS & Windows `x64` only). None of the seven are pre-enabled; each is installed separately via the Plugins page or `dsh plugin add`.
- **Web Remote Login, Device Pairing & Standard Connection Auth API** _(Default-On in Web Mode; Omitted in Desktop Window)_: Web mode adds **Settings → Remote connection** for one-use QR invitations, private tokenized login links, and owner-approved browser pairing, backed by a pluggable `connection.authentication` provider API, extracted Token/Desktop auth providers, default-authenticated `webServer` routes (`auth: 'required'`), and a multi-port cookie cap (retaining up to 17 authorities per hostname to prevent HTTP 431 lockouts).
- **Session Status Area & Shared Read/Unread Reminders** _(Default-On in Web & Desktop)_: Adds a dockable, drag-to-reorder **Session panel** (showing working directory, change requests, subagents, tasks, and plugin sections; collapses to a 280px overlay on narrow viewports) and Host-synchronized **read/unread session status** with completion/failure indicators and menu/keyboard toggles.
- **Code Review Page, Forge Extension API & GitLab MR Support** _(Experimental Bundle, Disabled by Default)_: Under the optional experimental **Change requests & worktrees** bundle (`@deepseek-ai/dsh-experimental-forge-bundle`), adds a **Code review** page for browsing and reviewing PRs with an in-page agent, plugin extension seams (custom lenses, line annotations, toolbar/file-menu/comment-box actions), and `@deepseek-ai/dsh-forge-gitlab` for reviewing and merging GitLab.com / self-managed MRs. **Verified Scope Boundary**: the global Code review page viewer inbox lists **GitHub PRs only** (requiring Host `gh` CLI), while GitLab support covers **Session-bound MRs** via Host `glab` CLI.
- **Git Repository Plugin Sources & Experimental Timeline Plugin** _(Both Experimental Bundles, Disabled by Default)_: The optional experimental **Custom plugin indexes** bundle (`@deepseek-ai/dsh-experimental-plugin-market-bundle`) now accepts Git repositories (`git+https://`, `git+ssh://`, GitHub URLs, private repos using Host Git/SSH credentials) as plugin sources. A new optional experimental **Timeline** bundle (`@deepseek-ai/dsh-timeline`) adds task trees, blockers, a clickable progress bar, `.timeline.json` checkpoints, and timed progress reports (separate model calls consuming extra tokens) with a **Follow chat** language option.
- **Major Security, Runtime & UX Changes**: Tightens `workspace-write` and file views to follow live Session `cwd` (removing `working_directory` and subagent `cwd`, switching worktrees to `enter_worktree`/`exit_worktree`, requiring extra authorization for `.git` writes in linked worktrees, and running archive worktree cleanup outside read-only sandboxes); promotes **Personalized recommendations** to default-on in Web/Desktop; consolidates `/office` and bundles `pypdf`; adds experimental Windows Computer Use, `cua-mcp`, and `cua_run_code` in Standard/SDK/headless when Computer Use is enabled; switches Node PTC to persistent scoped REPL by default and **removes Python PTC**; enables `cordis_inspect` by default in Standard mode; and adds an opt-in experimental SQLite session storage backend (JSONL remains default).

## Notable Improvements & Bug Fixes

- **Conversation, Sidebar & Composer UX**: Press `↑` in an empty composer to recall sent messages (`↑`/`↓` to browse without overwriting drafts); right-click files for **Add to chat**; drag any regular session into the right sidebar to chat side-by-side; preview manual/auto compaction summaries in the right sidebar; customize reasoning levels for built-in catalog models in Model settings; faster session list and `@` candidate loading; cross-language fuzzy matching (e.g., `cpt` → `/compact`) and workspace name/path search; inherited-history dividers in subagent/branched sessions; expanded LiveShare viewer capabilities; Desktop app menu **Settings** entry with live shortcut display; compact collapsible CR lists and deferred worktree creation with custom branch names and remote base branches.
- **Office, Models, Subagents & Performance**: Unified `/office` skill (Word/PowerPoint/Excel) plus bundled `pypdf` for PDF handling; **Personalized recommendations** enabled by default (controlled in Settings → General); persistent terminal plugin restored in Plugins → More (still off by default); DeepSeek image uploads run with 3-way concurrency and 429 retries, with unresponsive-service timeout and safe cancellation; `pi`-routed models resize oversized images before upload without altering originals; readable `web_fetch` network failure causes; reduced lag on long histories, large Markdown tables, and sidebar resizing; lower memory retention after large `read`/`glob` runs.
- **Platform & Reliability Fixes**: Context-overflow recovery after model switch summarizes with the last answering model; single-file runtimes (Python wheel) load the session migration worker reliably; PRs touched via `gh` or `git push` inside PTC appear in the forge panel; macOS composer `Home`/`End` moves within the line; clipboard copy fallback when browser blocks clipboard writes; Windows NSIS installer drag-freeze and uninstall registry cleanup fixes; Windows **Open in app** strips `ELECTRON_RUN_AS_NODE` so VS Code/Cursor launch cleanly; `Cmd+W` closes Desktop window on usage/top-up pages; draft attachments persist across session switches; file references/tabs stay anchored after session directory moves; multi-port Web cookie eviction prevents HTTP 431 lockouts; Desktop diagnostic history and typed `@` path cursor/order fixes.

## Breaking Changes & Security Migrations

`dsh-v0.2.3-alpha.1` introduces **`55` new and `2` updated** entries in `docs/upgrade-guide/` (spanning changes accumulated on `master` alongside the `0.2.2-rc.*` branch). Key user- and operator-facing migrations:

- **Workspace-Write & Worktree Security Boundary**: `working_directory` and subagent `cwd` parameters are removed; `enter_worktree` / `exit_worktree` replace `create_worktree`. `workspace-write` now follows live Session `cwd`: worktree Sessions can no longer write to the original project, and `git add`/`git commit` inside linked worktrees require extra approval or `additionalWritableRoots` covering `.git` (ignored on Windows). Stored legacy `working-directory/change` records are ignored on resume. Archiving a worktree Session now runs `git worktree remove` outside the sandbox regardless of read-only policy (`retainOnArchive: true` opts out).
- **WebServer Default-Authenticated Routes & Auth Provider Extraction**: `webServer` routes default to `auth: 'required'`; custom public endpoints must declare `auth: 'anonymous'`. Token login moves to `@deepseek-ai/dsh-host-authentication-token` (`cookieMaxAgeDays` moves from `connection` config).
- **Unified `ctx.deepseekAuth` & API-Key Provider Rename**: Custom compositions mounting DeepSeek LLM/search/fetch plugins without `dsh-base`/`dsh-sdk-minimal` must mount `@deepseek-ai/dsh-deepseek-auth`; sign-out now aborts in-flight account requests.
- **Node PTC Scoped REPL Default & Python PTC Removal**: Node PTC defaults to `persistent-in-memory` scoped REPL (top-level `return` rejected; set `executionMode: per-call` to keep old behavior). `@deepseek-ai/dsh-experimental-ptc-runtime-python` and all `language: 'python'` PTC support are removed (Python SDK in `python/sdk` is unaffected).
- **Cordis Core `4.0.0-rc.12` / Loader `1.0.0-rc.9` / Include `1.2.0` & Plugin Contracts**: Replaces `ctx.root` with `ctx[Context.root]`, switches YAML parsing to YAML 1.2 core schema, enforces strict entry validation (`group: true` requires `config: []`), retires `/office-docx`/`/office-pptx`/`/office-xlsx`, moves `SessionStatus` to `@deepseek-ai/dsh-client-ui-session-status` (requiring `inject`), updates client bundle mount-time stylesheets and CSS Modules class names, standardizes package exports and structured tool error codes, updates `fileAddressFor` to return absolute paths, requires `parentSource` on custom session forks, wraps `list_agents` results under `{ running, limit, agents }`, replaces `cordis_inspect_list`/`cordis_inspect_query` with `cordis_inspect`, renames macOS CUA package/entry to `@deepseek-ai/dsh-cua-macos` / `cua-macos` and `useSystemPointer` → `useSystemInput`, and requires custom integrations to adapt to incremental system-prompt sections and SDK per-message time zones.
- **Experimental SQLite Session Storage**: `@deepseek-ai/dsh-session-persistence-sqlite` is opt-in via manual profile config; JSONL remains the default persistence backend.
