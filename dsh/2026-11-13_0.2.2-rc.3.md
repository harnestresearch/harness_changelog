## Highlights

- **DeepSeek Website Chat Export Importer (Experimental Plugin)**: Added an optional experimental plugin ("DeepSeek chat import", enabled under **Plugins → More → Experimental plugins**) that adds an upload button right of **New session** to import `deepseek_data-*.zip` exports from `chat.deepseek.com` directly into a chosen Workspace as native, resumable DSH Sessions—preserving conversation titles, timestamps, reasoning traces, web search/fetch cards, read links, and image attachments across 8 UI languages.
- **Resilient Session Log ZIP Exports**: Exporting a session log as a ZIP archive no longer aborts the entire download when a referenced image or file attachment was deleted or has no stored bytes; unreadable references are now recorded in `attachments-missing.txt` while the rest of the archive downloads cleanly.
- **Windows Desktop Update Directory Lock Fix**: Fixed a Windows installer issue where the detached update-restart status notice window could hold a working-directory lock on the installation folder and block directory replacement during an update.

## New Features

- **Experimental DeepSeek Chat Export Import (`@deepseek-ai/dsh-deepseek-chat-import`)**:
  - Uploads `deepseek_data-*.zip` archives in memory (default limits: up to `512 MiB` per archive, `256 MiB` per entry, and the `1,000` most recently updated conversations from `chat_session_index.json`) with live upload/import progress (`Importing n/K`), cancellation on dialog close, and automatic backfill from older indexed conversations when an entry is skipped.
  - Linearizes each conversation branch to `current_message_id` (or latest message fallback), stores exported user images (`png`, `jpg`, `jpeg`, `webp`, `gif`) as attachments, renders non-image or unavailable files as file cards, converts `SEARCH` and `TOOL_OPEN` records into native `web_search` / `web_fetch` cards and `READ_LINK` items into Markdown links, excludes content-filtered (`CONTENT_FILTER`) rounds from model context, and marks unfinished/template replies with explicit error endings so imported sessions can be resumed seamlessly.
- **Sidebar Session Action Slot & Reusable Workspace Picker**:
  - Added the `sidebar.session.action` extension slot next to **New session** (supporting both expanded sidebar and collapsed `56px` rail layouts with synchronized rail-in animations), a reusable `workspace.picker` component factory with inline **Add workspace…** directory selection for plugin dialogs, and upload outline icons (`IconUploadOutlineRegular` / `IconUploadOutlineMedium`).

## Bug Fixes

- **Windows Update Restart Status Working Directory**: Launched the Windows NSIS update-restart status process (`rundll32.exe`) with the Windows system directory as its working directory so it cannot pin the application installation folder during staged upgrade replacement.
- **Session Log Export Missing Attachment Handling & Stream Cleanup**: Updated Session ZIP export to skip missing or invalid attachment references into `attachments-missing.txt` instead of failing mid-download, pre-check the first file chunk before yielding entries so genuine storage corruption still fails fast, and close open file streams cleanly when a download is cancelled early.
- **CI Sandbox Archive Caching & Bounded Downloads**: Cached the SHA-256-verified `bubblewrap` sandbox `.deb` archive on hosted Linux CI/E2E runners with bounded curl timeouts and retries so transient Launchpad stalls no longer block CI pipelines.

## Breaking Changes

- **None**: No user-facing or configuration/session-format breaking changes relative to `dsh-v0.2.2-rc.2` (`0` `docs/upgrade-guide` entries).
