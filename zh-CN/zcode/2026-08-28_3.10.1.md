# ZCode Desktop 3.10.1

[English](../../zcode/2026-08-28_3.10.1.md) | 简体中文 · **精简版 (Highlight)** | [完整详情 (Full Detail)](../full/zcode/2026-08-28_3.10.1.md)

- **发布日期**：2026-08-28
- **覆盖平台**：`mac`、`win`、`ubuntu`

## 核心亮点

- **思考轨迹内容搜索与回合摘要**：思考轨迹默认展开并支持内容搜索；对话回合结束时可直观查看执行摘要与耗时。
- **编辑消息立发、技能快捷入口与插件一键安装**：编辑后的消息无需排队即可立即发送；输入框菜单新增技能入口；提示词模板引用的插件支持一键安装。
- **MCP 协议版本配置与 Weekend Plan**：支持为 MCP 服务器配置协议版本并提供协商失败引导，设置项「浏览器」更名为「浏览器控制」，上线 Weekend Plan 免费提前领取。
- **自动重试与跨平台修复**：模型回复偶发中断或空白时自动重试，修复登录授权回调与偶现 MCP OAuth 失败、多技能目录并列识别、macOS/远程工作区 Computer Use 异常及 Windows 后台残留进程问题。
