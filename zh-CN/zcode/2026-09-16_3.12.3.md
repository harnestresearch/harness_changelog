- **发布日期**：2026-09-16
- **覆盖平台**：`mac`、`win`、`ubuntu`

## 核心亮点

- **计划模式与排队消息协同**：优化计划模式和排队消息交互体验，补全计划模式菜单说明，并优化闲时任务的工具使用限制。
- **OpenCode Go 模板与套餐状态刷新**：新增 OpenCode Go 服务商模板与站点映射，优化服务商名称、图标与套餐横幅展示；套餐获取失败时增加重新登录入口并修复登录后未触发 Key 强制刷新的问题。
- **数据库升级与启动性能优化**：优化数据库初始化与升级流程、会话启动速度及未跟踪文件统计性能。
- **流式重试、OpenRouter 与 Linux 自动更新修复**：修复 Provider 配置读取阻塞与异常、流式响应中断后的重试、OpenRouter 兼容性与连接测试、恢复后的子 Agent 混入任务列表，以及 Linux 自动更新失败的问题。
