# ZCode Desktop 3.14.2

[English](../../zcode/2026-09-21_3.14.2.md) | 简体中文 · **精简版 (Highlight)** | [完整详情 (Full Detail)](../full/zcode/2026-09-21_3.14.2.md)

- **发布日期**：2026-09-21
- **覆盖平台**：`mac`、`win`、`ubuntu`

## 核心亮点

- **运行中工作流就地调整并发上限**：无需停止或重启任务即可直接修改在途工作流的并发上限（调高时立即放行等待座位的子代理，调低时在下一回合边界平滑停驻超出上限的子代理），并在时间线卡片提供调参控件与事件记录。
- **工作流工具上下文瘦身与脚本高效迭代**：将完整的工作流 API 契约从常驻工具描述迁入按需加载的 `dynamic-workflows` 技能文档，结合草稿文件态跟踪显著降低上下文占用与提交/修改脚本的 Token 消耗。
- **`dynamic-workflows` 技能与 `/workflow` 命令内置化**：将动态工作流技能与 `/workflow` 斜杠命令从可卸载的 `zcode-guide` 插件迁入内置 `bundled-skills` 包，避免关闭或卸载插件后工作流失去契约说明。
- **大型工作流实时状态有界化展示**：对超大规模工作流的节点与子代理列表实行有界截断，并以「另有 N 个子代理未列出」「仅展示 X/Y 步的详情」清晰呈现，兼顾流畅度与上下文体积。
