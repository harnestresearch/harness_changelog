# ZCode Desktop 3.18.0

[English](../../zcode/2026-11-10_3.18.0.md) | 简体中文 · **精简版 (Highlight)** | [完整详情 (Full Detail)](../full/zcode/2026-11-10_3.18.0.md)

- **发布日期**：2026-11-10
- **覆盖平台**：`mac`、`win`、`ubuntu`

## 核心亮点

- **聊天框实时语音输入**：支持在输入框直接语音口述提示词，实时流式转写为文字，并提供清晰的麦克风权限与音频设备排查提示。
- **受管 Git Worktree 并行任务与消息分叉**：支持基于任意分支创建独立 Worktree，或将任意历史消息一键分叉至新 Worktree 并行推进多项开发任务，配套侧栏专属 `Worktrees` 管理视图。
- **扩展（Extensions）市场与分级授权**：新增扩展中心，支持按通知、只读、读写或完全访问分级授予会话权限，并支持查看扩展视图、日志与热重载。
- **内置设计系统与浏览器点选可视化编辑**：内置专业界面设计规范，并支持在内置浏览器中直接点选（含多选）页面元素可视化调整对齐、颜色、字号、间距、圆角与透明度并实时写回源码，同时提供设备视口预设与 PNG/PDF 导出。
- **多会话协同编排与智能插件推荐**：主会话可创建、分叉、调度并等待多个子会话协同工作（修改类操作默认需用户审批），并可根据任务场景主动推荐合适的工作区插件卡片。
- **消息重编辑、分享管理页与归档批量清理**：支持直接编辑刚发送或排队中的消息；分享链接支持设置有效期并在「分享管理」页集中暂停/恢复/删除；支持安全批量永久清理归档会话且自动保护被引用附件。
- **多账号切换、系统密钥环保护与多语言扩容**：新增 `zai_cn` 登录与多账号切换、凭据迁移至操作系统密钥环加密保存、新增日语/韩语/俄语界面，并上线工具调用分组折叠、划词引用批注、发图前涂鸦标注以及 ZCode Sites 访问统计与容器规格翻倍。
