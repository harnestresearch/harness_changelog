# ZCode Desktop 3.16.1

[English](../../zcode/2026-10-17_3.16.1.md) | 简体中文 · **精简版 (Highlight)** | [完整详情 (Full Detail)](../full/zcode/2026-10-17_3.16.1.md)

- **发布日期**：2026-10-17
- **覆盖平台**：`mac`、`win`、`ubuntu`

## 核心亮点

- **统一远程设备管理与常驻远程会话**：设置页新增「远程设备」统一管理 SSH 服务器、WSL 发行版与 Docker 容器（支持导入 `~/.ssh/config`、启动自动重连最近 7 天设备及本地工作区数据迁移）；远程会话支持常驻进程，本地断连不再影响远端任务执行。
- **智能体按需工具搜索（`ToolSearch`）**：新增工具搜索设置（自动 / 本地 / 关闭，及 CLI `--toolsearch-mode`），助手可按需查找和加载工具而无需每轮携带完整工具目录。
- **侧边栏 Office/PDF 文档查看面板与多标签文件浏览**：Word、PDF、演示文稿、电子表格四大文档插件升级至 `0.2.0`/`0.2.1`，内置 MCP 服务与侧栏查看面板并支持将文档内容引用到对话；文件浏览移至侧边面板，支持多标签页与「完整视图」模式。
- **本地多文件夹项目与输入框直切控件**：本地项目支持一次挂载多个源文件夹（指定主要目录）并修改名称；输入框工具栏可直接切换模型、调节思考力度并选择团队套餐。
- **插件市场、弹层对话分享、按项目归档与手机远控升级**：新增插件市场、支持范围选择与工作流/图片预览的弹层对话分享、按项目默认折叠的归档会话管理、图片预览复制/下载/引用到对话、手机远控账号登录与设备管理、Windows 任务栏与托盘未读提醒，以及 MiMo 模型 API 与 Token 套餐双接入方式。
- **安全加固与 18 项稳定性修复**：修复 Windows 本地文件越界读取安全漏洞、连接日志敏感信息泄露、模型创建失败或切换模型时输入/草稿丢失、达上下文上限后无响应、恢复会话附件错乱、数据库升级偶发锁卡顿及终端启动开头输出丢失等问题。
