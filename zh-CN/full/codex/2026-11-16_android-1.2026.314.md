## 概述

本条目为基于 APKPure 归档 `arm64-v8a` + `en` + `mdpi` XAPK 样本的 ChatGPT Android `1.2026.307`（`2630718`）→ `1.2026.314`（`2631431`）只读静态差分（不包含 `300 → 307` 与 iOS）。在 Codex / MCP 客户端静态代码层面，`2631431` 引入 `RmcpHttp2Server`、首次打包 Netty `4.1.140.Final` HTTP/2 组件并新增签名 RMCP grant 握手字符串（`x-codex-rmcp-grant`），扩展 MCP `DiscoverRequest*`/`DiscoverResult` 与 `mcp/skill` 标识，在 app-server RPC 中新增 `thread/delete`（`+` `thread/deleted`）并移除 `thread/realtime/listVoices`，同时补齐一批移动端 Codex Remote Compose 组件与提示串。在 Android 平台层面，`AndroidManifest.xml` 真正新增 `CALL_PHONE` 与 `FOREGROUND_SERVICE_MEDIA_PLAYBACK` 两项权限声明，以 `DeviceNotificationListener` 替换 `MediaAccessNotificationListener`，注册 `ReadAloudPlaybackService` / `ReadAloudPauseReceiver` / `NotificationTapActivity`，新增 `oai_notifications`、`chatgpt_commerce_reporting`、`chatgpt_learning` 三个 Valdi 模块，并携带扫码登录、Wallet 结账、比价提醒、学校场景与 `"dot"` 助手相关静态文案与资源。全文严格按**静态观测**、**推断**与**未知/未核验**分层记录，未安装或执行任何 APK。
