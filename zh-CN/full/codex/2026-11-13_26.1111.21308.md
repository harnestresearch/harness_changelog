## 概述

本次更新为桌面端跨代功能与引擎大版本升级：内置 Codex CLI 引擎连跨两个 minor 升至 `0.169.0-alpha.11.1`（二进制精简 `26.3` MB，新增 stdio MCP 懒启动、`exec-server` WebSocket 升级与技能命名空间等能力），Chromium 运行时升级至 `157.0.8103.78`。Electron 宿主与预加载层为 MCP Apps 沙箱引入 Web Worker RPC 执行、完整流与 Fetch 对象结构化克隆序列化、按来源细粒度权限声明（`mcp-app-permission-declarations-v2`）及全新 `application-websocket-preload.js` 通道；主进程与渲染端上线 Claude Code / Cursor 外部技能同步导入、云端预览（Cloud Previews）、Git Worktree 管理流扩展、自动化运行收件箱、全局搜索、Spaces 空间、2026-11 批次连接器，以及 `cua_node` Windows `window3` 桌面自动化接口。

## 主进程、沙箱与预加载层架构

- **MCP Apps Web Worker 沙箱与 Application WebSocket RPC 预加载层**
  - `.vite/build/sandbox-preload.js` 大幅扩容（`2,217` B → `117,711` B），为 `io.modelcontextprotocol/ui` 小组件沙箱引入 **Web Worker 支持**（`Symbol("workers-module")` + 带世代追踪的 `RpcTarget`）与**完整结构化克隆序列化器**（覆盖 `ReadableStream`、`WritableStream`、`Request`、`Response`、`Headers`、`Blob`、`URL`、TypedArrays、`rpc-target`、`rpc-promise` 全型别），并内置 `Symbol.dispose` 与 `Promise.withResolvers` polyfill。
