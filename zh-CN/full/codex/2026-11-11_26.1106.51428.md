# ChatGPT / Codex Desktop 26.1106.51428

[English](../../../full/codex/2026-11-11_26.1106.51428.md) | 简体中文 · [精简版 (Highlight)](../../codex/2026-11-11_26.1106.51428.md) | **完整详情 (Full Detail)**

- **发布日期**：2026-11-11（macOS arm64，构建号 `26605`，基线版本 `26.1103.60933` / 构建号 `25894`）
- **覆盖平台**：`mac`、`ubuntu`
- **运行时与引擎**：Chromium `157.0.8103.51`（自 `157.0.8103.39` 升级），Codex CLI 引擎 `0.167.0-alpha.4.1`（自 `0.167.0-alpha.3.2` 升级）

## 概述

本次更新同步推进了 Codex 核心引擎与桌面端多项工作流能力：引擎升至 `0.167.0-alpha.4.1`，Chromium 补丁升级并重编全套原生模块；桌面与前端上线多账号管理及平滑切换过渡屏、云端 SSH Portal 响应式状态机、主进程 `automation_update` 处理器、Code Review PR 面板持久化、Pages 协作文档（DIL）、图片文字编辑、本地工具搜索 MCP（`local_work_search_mcp`）以及新模型标识 `gpt-5-t-mini`。

## 主进程与桌面基础设施

- **渲染端持久化状态扩容与注册表整合**
  - 将原先分散在 `worker.js` 中的 25 个 `electron-persisted-atom-state` 持久化键统一收敛至主引导包 `early-bootstrap.js`。
  - 新增 10 个状态持久化键：`pinned-content-tabs-v1`、`pinned-content-tab-presentation-v1`、`settings-workspace-tabs-v1`、`composer-retained-documents-v1`、`chatgpt-dictation-feedback-messages-v1`、`codex-dictation-feedback-messages-v1`、`image-text-editing-requests`、`prompt-history`、`electron-renderer-content-owner`、`signed-out`，支撑固定内容标签页、设置工作区标签页、输入框保留文档、听写反馈、图片文字编辑与历史提示词记录。
- **云端 SSH Portal 响应式状态机**
  - `getSshPortal` 由静态门控检查重构为响应式状态机，新增面向用户的明确错误提示 `cloudPortal.sshDisabled`（“Portal SSH was disabled for this account”）与 `cloudPortal.sshGateUnavailable`；保留 `codex_desktop_quic_ssh` 开关，并在 64 个语言包中同步补齐 `native.ssh.handshakeAccess` 与 `native.ssh.handshakeFailed` 握手异常文案。
- **`automation_update` 主进程处理器与更新状态细化**
  - 主进程落地 `{namespace: "codex_app", name: "automation_update"}` 工具输出封装与参数校验，新增错误码枚举 `invalid_automation_schedule`、`automation_update_failed`、`automation_not_found` 以及 `modelAuthoredPrompt` 分支。
  - RPC 协议层扩充自动更新生命周期遥测状态（`codex-update-attempt`、`already-installed`、`install-failed`、`newer-version` / `older-version` / `same-version`、`primary-download`、`policy-denied`、`policy-blocked-no-offer`、`store-discovery-error`、`service-privilege`、`startup-migrations`、`target-launched`）。
- **多账号/工作区无缝切换屏与系统集成细节**
  - 预加载层新增注入式过渡屏 `desktop-switch-loader`，在多账号或工作区切换导致渲染进程替换前后维持同一视觉画面，移除旧版 `.startup-loader--switching` 样式；入口 HTML 的 CSS `@layer` 新增 `properties` 层。
  - 新增隐藏设置项 `codex-micro-lights-off-when-locked`（电脑锁屏时自动关闭 Micro 灯光，默认关闭）。
  - WebSocket 连接层新增 `admission_cancelled`（状态码 `1000`）关闭分支；内置特性允许集新增 `local_work_search_mcp`；深研连接器资源键由 `connector_openai_deep_research_work` 规范化为 `connector_openai_deep_research_workflow`。

## 前端与产品功能

- **多账号管理与分级登出**
  - 主界面新增完整多账号状态与身份上下文字段（`actor_id`、`actor_user_id`、`actor_account_user_id`、`actor_email`、`add_account_replacement`、`saved_account`、`accounts_check`、`session_recovery`），并提供区分当前会话、单账号与全部账号的分级登出操作（`local_logout`、`federated_logout`、`explicit_logout_all`、`profile_menu_log_out_all_accounts`、`active_session_logout`）。
- **Code Review PR 面板持久化**

- **Pages 协作文档（DIL）**

- **环境配置、凭据与云端工作区**
  - 新增服务端环境配置与多源凭据支持（`environment-setup-server-configs-v1`、`vault_secret`、`network-secret`、`direct_environment_variable`、`refresh_credential`、Azure `azure_client_id` / `azure_tenant_id`、GCP 与网关登录宿主及 `xaa_enrollment_required`）。
  - 扩展云端工作区与远程桌面状态（`devbox_vnc`、`cloud_desktop`、`codex_work_desktop`、`tailscale_up`、`tun_permission` / `tun_unavailable`、`workspace_deactivated`、`slack_workspace_access_pending`）。
- **图片文字编辑、Worktree 附件与快捷启动器**
  - 新增图片内文字编辑模块（`image-text-editing-requests` 最多保留 100 份草稿，配合 `image-text-editing-operations`）。
  - 新增 `omni-dot` 快捷启动器通道（`open-omni-dot`、`focus-omni-dot-launcher`、`open_dot_with_draft`、`dot-hub`）。
  - Worktree 附件新增 `linked_worktree` 类型与 `worktree-plugin-v1:` 标识前缀及偏好引导。

- **模型目录与分析事件**
  - 模型目录新增 `gpt-5-t-mini`（上下文窗口：付费档 `196,608` tokens / 免费档 `16,384` tokens）。
  - 新增 Beacon 订阅升级与直通结账流字段（`beacon_upsell`、`beacon_checkout_mode`、`direct_checkout`）。
  - Protobuf 分析事件扩展至 336 项，新增 `CodexBrowserInteractionsInlineCard`、`CodexBrowserUseBotDetectionReported`、`CodexProfileArtifactCardAction`、`CodexProfileArtifactCardShown`；清理旧版工作区积分耗尽提示与 `outlook-calendar` / `outlook-email` 键。

- **MCP 工具与协议面**：内置 `codex_app` 59 个工具（及 5 个受管 Worktree 条件工具）、11 个内置插件 `.mcp.json`、MCP 协议协商版本及 AppServer 131 个 RPC 方法保持不变；仅 `update_running_summary` 工具说明中的状态展示文案由“pet activity pill”调整为“public goal”。
- **Codex 引擎与原生层**：`CodexCLI` 引擎更新至 `0.167.0-alpha.4.1`，同步重编 `codex-code-mode-host`、`codex-exec-server`、语音管线 7 个 GStreamer 插件库，以及随 Chromium `157.0.8103.51` 重编的全部 23+ 个桌面原生模块与 `Codex Computer Use.app` 辅助组件。
- **`browser` / `chrome` 插件重构**：`browser-service.mjs` 内置完整 Segment 分析管线，更新云端与内置浏览器（IAB）标签页清理文档（`tab-cleanup-cloud.md` / `tab-cleanup-iab.md`），移除 `tab-claiming-dot`，并将浏览器反爬拦截事件统一迁移至渲染端 `CodexBrowserUseBotDetectionReported`，同步重编 `ChatGPT for Chrome` 原生扩展宿主。
- **`visualize` 插件增强**：新增 `dashboard-annotations.js`、`dashboard-layout.js`、`dashboard-source-actions.js`、`dashboard-sources.js` 四个仪表盘交互脚本；瀑布图、错误堆栈、火焰图与周/月日历小组件默认启用宽屏模式，并划分 Codex 专属图表配置块。
