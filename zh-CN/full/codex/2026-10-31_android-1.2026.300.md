# ChatGPT Android 1.2026.300

[English](../../../full/codex/2026-10-31_android-1.2026.300.md) | 简体中文 · [精简版 (Highlight)](../../codex/2026-10-31_android-1.2026.300.md) | **完整详情 (Full Detail)**

- **发布日期**：2026-10-31（`com.openai.chatgpt`，`versionCode 2630015`，基线版本 `1.2026.293` / `2629319`）
- **覆盖平台**：`android`

## 概述

一次移动端智能体基础设施跃迁版本：Android 客户端首次内建官方 MCP Kotlin SDK 与本地 Streamable-HTTP MCP 服务器（`android executor`），支持将手机自身挂载为 Codex 的远端执行环境，配套落地 Noise 加密分块中继协议（`exec-server relay`）、Elicitation 用户交互回传闭环与设备密钥配对握手；应用层同步上线 Health Connect 健康数据接入、Bazaar 商业购物代理、浏览器 Cookie 交接与后量子设备密钥引导。

## Codex 与 MCP 执行架构

- **内嵌本地 MCP 服务器（`android executor`）**
  - 客户端内置基于 Ktor（`3.5.x`）的 Streamable-HTTP MCP 服务，监听 `http://127.0.0.1:39801/android-executor/mcp`（仅接受 `POST`），`tools/list` 按工具类别与实验开关动态过滤。
  - `environmentConfig/read` 返回 `{source: "android-native", baseDir: "file:///android-executor/device-executor", hostname, capabilities}`，并自动生成 `[mcp_servers.android_native]` TOML 配置片段供 Codex 实例挂载手机执行环境；协议同时预留 `http/request` 反向 HTTP 代理方法。
- **官方 MCP Kotlin SDK 与 Elicitation 闭环**
  - 首次引入 `io.modelcontextprotocol:kotlin-sdk-core-jvm` / `kotlin-sdk-server-jvm:0.15.0`，支持协议版本协商 `2025-03-26`、`2025-06-18`、`2025-11-25`、MCP **Tasks 扩展**（`tasks/get|result|list|cancel`）及 SEP-986 工具名校验。
  - 新增 `elicitation/create`、`notifications/elicitation/complete`、`UrlElicitationRequiredException` 与 `codexMcpElicitationResponse` 回传通道，配合新增透明弹窗 `LinkedElicitationActivity`（受 `native_elicitation_enabled` 开关控制）补全移动端 MCP 交互式授权/提问的作答闭环。
- **加密中继传输（`exec-server relay`）与多宿主同步**
  - 新增 `codex.exec_server.relay.v1.{RelayHandshake, RelayAck, RelayData, RelayHeartbeat, RelayMessageFrame, RelayReset, RelayResume}` 消息族与 `codex-exec-server-relay-noise/v1`（`noise_hybrid_ik_v1`）加密传输层，支持 60 KiB 分块、序号断点续传与断线重连恢复。
  - 新增云端环境端点 `https://codex-cloud-environments.chatgpt.com/api/`（认证会话新增 `CodexCloud` 主体）。
  - Slingshot 远端连接扩展设备密钥配对握手字段：`deviceKeyProof`、`pairingCode`、`deviceKeyChallenge`。
  - 本地 SQLite `DBRemoteThread` 表新增 `codexHome TEXT` 列以支持多宿主远端线程缓存；AppServer RPC 新增 `thread/readState` 已读状态同步，并清理废弃的复数前缀 `mcp__codex_apps__`（保留标准 12 项 `codex_app` 动态工具）。

## 平台功能与安全变更

- **ChatGPT Health（Health Connect 集成）**
  - AndroidManifest 新增 43 项 `android.permission.health.READ_*` 权限、`com.google.android.apps.healthdata` 包可见性查询与 `HealthConnectRationaleActivity`，内置 44 类健康记录读取/同步/权限规划实现及 3 个专属 Valdi 模块（受 `health_connect_supported` 开关分级控制）。
- **广告与 Bazaar 购物代理**
  - 新增 `chatgpt_ads.valdimodule`、`ChatGPTAdsNativeImageCard`、商业代理启动埋点及订单/配送/退货交互流程。
- **浏览器认证交接与代填登录**
  - 新增 `cookie_handoff_enabled` / `enable_native_reauthentication` 开关、浏览器认证事件埋点、密码与邮箱验证码代填授权提示，以及 `start.1password.com` 1Password 接入引导。
- **设备密钥与后量子密码 Onboarding**
  - 引入 `kotlin-reflect 2.4.20` 与 `BouncyCastle bcprov 1.86`（含 FAEST / SQIsign / AIMER 后量子签名算法标识），支撑 `device_key_authentication` 与 `onboarding_v3` 新注册认证流。
- **日常体验扩展**
  - 新增幻灯片（Slides）/闪卡、Spaces-Pages 访问权限继承、锁屏语音助手（`AssistantUnlockActivity`）、电话/短信代发、Explore 实验信息流（`/backend-api/explore_experimental/generate`、Nova 体系）及 Valdi 版定价与 Pro Lite 比价页。
- **安全暴露面收缩与依赖升级**
  - 移除对外导出的 `ChatGptAuthTokenService` 服务及自定义权限 `GET_AUTH_TOKEN`；新增 `/cairn/m/invite` 与 `/s/i_*` 深链；移除未使用的 `openai_sans_variable.ttf` 字体。
  - 升级 Datadog `3.14.1 → 3.15.0`、Plaid `6.2.1 → 6.3.1`、`kotlinx-serialization 1.11 → 1.12`、Metro `1.4.5 → 1.5.0`；`valdi_api_version` 升至 `390`（`libopenai_xplat_export.so` 新增 Crypto / TypedArray / `requestAnimationFrame` 与模块 OTA 回执支持）。

## 附：模型服务变体后缀体系

桌面与 Android 客户端共享同一套由服务端 `model/list` 下发的模型变体后缀约定（客户端自动映射至同族基础模型展示）：

- **`-wm`（Wingman）**：实时语音与多模态通话会话变体（如 `gpt-6-astra-wm`、`gpt-5.6-luna-wm`），绑定独立 RTC 音频配置与 `gpt-reserve` 限流额度桶。
- **`-priority` / `-ultrafast`**：高优先级与极速推理服务档位变体（对应 `service_tier` 配置）。
- **`-minor`**：同族模型的点版本部署变体（如 `gpt-6-astra-minor`、可与语音叠加为 `gpt-6-astra-minor-wm`），在客户端与主模型共享产品族及网络安全计划资格判定。
- **`gpt-daybreak-blue-latest` / `gpt-daybreak-red-latest`**：面向授权网络安全防御与研究计划（Daybreak）的专项模型。

- **内嵌服务栈、协议与原生库明细**：
