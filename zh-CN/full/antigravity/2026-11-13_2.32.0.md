## 概述

Antigravity 桌面端（`antigravity-hub`）`2.32.0` 保持 Electron `44.9.1` 与三链路 MCP 核心基线（`CHROME_DEVTOOLS_MCP_JS` 启动注入、内置 `chrome_devtools` `18 + 1` 工具注入及逐字节不变的随包 `chrome-devtools-mcp` `1.9.0`）完全稳定，同时将 Electron 壳层 `dist/` 顶层条目由 `59` 扩充至 `70`（并新增含 `30` 个文件的 `dist/remote/` 目录），Go 单体后端 `language_server` 由 `206.8` MB 扩容至 `240.0` MB（`+31.6` MiB，约 90% 增量位于 `.noptrdata` 内嵌 protobuf 描述符）。官方公告在 `2.32.0` 推出 **Dynamic Workflows**、**Everforest 亮/暗主题**、提示词跳转快捷键、智能体浏览器标签页防护增强及 **11 项改进、13 项修复**。静态逆向核验表明：`run_workflow` 与内置 Python 运行时代码早在 `2.31.2` 已逐字节完整存在（本次属实验门控转正/GA 公告）；而代码层真正新增的重磅子系统包括 **SSH 远程开发栈**（`dist/remote/`）、**Catcher 三层访客视图栈**、**跨站子框架凭据剥离与 Electron UA 清洗**、移除 `shell-env`/`execa` 依赖（`8 → 7`）、受门控的 **`cortex/ext/plugins/computer` 桌面控制插件**（`ComputerViewerService`）、新增 **`CloneGitHubRepo`** Connect-RPC（真实方法 `374 → 375`）、**`+58` 个特性开关**（`54 → 112`）、`WatchTopic` 远端会话消息流 `AgentRemoteSessionMessages` 以及 `openaiResponsesConverter`。

## 三平面 MCP 架构基线（`2.32.0` 复核仍完全成立）

- **平面 1 — Electron 壳层启动接线**：`dist/languageServer.js` 将 `baseLsArgs` 抽离为无 Electron 依赖的纯模块 `dist/lsDefaults.js`（供 SSH 远程 LS 复用），启动参数（`--standalone --override_ide_name antigravity --subclient_type hub --api_server_url … --cloud_code_endpoint … --enable_sidecars`）与 `2.31.2` 逐项一致；`CHROME_DEVTOOLS_MCP_JS`（`languageServer.js:271` 附近 `setupNodeModules`）仍为唯一 MCP 环境变量，`tightenActivePortPermissions`（`0o700` / `0o600`）与 `dist/guestWebMcpController.js` 均保持未变。
- **平面 2 — Go `language_server` MCP 与原生工具面**：内置 `chrome_devtools` 注入名仍为 **18 个** `mcp_chrome_devtools_*` 工具 + `mcp_chrome_devtools_agy_stitched_` 录屏前缀（`mcp_chrome_devtools_evaluate_script` 仍为 `0`），保留 `chrome-devtools-mcp@1.12.0` 与 `@latest` 回退串；proto `cortex_pb.*ToolConfig` 仍为 **49** 项（`RunWorkflow` 自 `2.31.2` 起已在列），`ToolConverter` 同正则匹配 **174** 条（去粘连主类型 **35** 个），`agy_tool_safety` 头部 `9,000` 字节逐字节一致，`sir_flash_lite` / `monitor_config` 安全监视器计数不变（`2 / 528 / 2`）。

## Electron 壳层变更（`app.asar/dist`：顶层 `59 → 70` + 新增 `dist/remote/`）

- **新增 SSH 远程开发栈（`dist/remote/`，`30` 个文件）**：
  - 支持将 Hub 的 `language_server` 部署运行于远程 SSH 主机，本地桌面窗口仅作为受限安全视图（`main.js` 新增冷启动与二实例 `--ssh-host=` 参数；`preload.js` 以 `--agy-backend=ssh` 判定远程窗口并暴露 `window.sshRemote` / `createLocalSshRemoteAPI`，不加载本地 script jail）。
  - `remoteLsArgs.js` 以 `lsDefaults.baseLsArgs` + `--persistent_mode` + `--workspace_id REMOTE_LS_WORKSPACE_ID` + `--enable_sidecars` 启动远端 LS，刻意省略 `--exit_on_stdin_close` 与 host bridge flag，使远端 LS 及其智能体在断连后继续存活并支持重连。
  - `bootstrapScript.js`（`42` KB 内嵌 shell/awk 脚本）与 `bootstrapProtocol.js` 负责远端安装、拉起与发现文件 `ls_<sha256(workspaceId)[:16]>.json`（对齐 `server.go` 的 `writeDiscoveryFile`），采用每连接随机 secret marker 防御 MOTD/rc 输出伪造（事件含 `OPEN_URL`、`NEED_UPLOAD(<abi> <reason>)`、`READY`、`agy_fail(UNSUPPORTED_HOST|SHARED_HOME_UNSUPPORTED|INSTALL_FAILED|LS_START_FAILED|LS_STOPPED)`）；配套 `sshConnection.js`（`52` KB）、`remoteManager.js`（`35` KB）、`sshAskpass.js`（经 UNIX socket + token）、`sshConfigHosts.js`、`sshDestination.js`、`sshPrompts.js`、`sshBridge.js`、`sshRecentHosts.js`、`transport.js`、`remoteSidecars.js`、`disconnectedPage.js`、`hostStores.js`、`windowBackends.js`、`privateDir.js`、`localNetwork.js`、`signInCallback.js`/`signInUrls.js` 及 `ANTIGRAVITY_SSH_{BIN,ASKPASS_SOCKET,ASKPASS_TOKEN,LS_VERSION,LS_REMOTE_PATH}` 环境变量族。

## 官方 `2.32.0` 更新日志对照汇总（`11` 项改进，`13` 项修复）

- **11 项官方改进**：Dynamic Workflows（随包 Python 运行时编排并行子代理与多步任务）；Everforest Light / Dark 主题；上/下一条提示词跳转快捷键；可选 `Submit Prompt` 发送快捷键；登录自动跳转未完成时复制登录链接或粘贴一次性授权码；模型选择菜单自适应高度与加载失败 `Refresh` 按钮；智能体浏览器下载因文件类型被拒时通知智能体并在下载抽屉显示拦截状态；智能体浏览器跨站子框架默认未登录加载并默认对截图/快照隐藏；已安装插件卡片与详情页头展示 MCP Server 启动错误；宿主不支持终端沙箱时在权限菜单说明隐藏 Default / Auto 模式的原因；远程智能体支持本地克隆云端 GitHub 仓库并在应用内直接登录 PR 链接。
- **13 项官方修复**：内置浏览器暴露 `Electron` UA 导致站点拦截；退出桌面应用遗留后台进程与临时文件锁阻碍设置保存；插件重启或更新后全屏插件视图空白/破坏已开标签页；点击 Google Drive `@` 提及建议未触发登录；Linux 下固定会话快捷键与 Chrome 标签组冲突且无法改键；侧边栏按 Automations 筛选隐藏插件会话；编辑排队消息、回退步骤或恢复草稿时列表扁平化与链接胶囊丢失；长对话上滚卡顿跳位（提前加载更小历史分页）；默认字体下中日韩（CJK）粗体显示为常规字重；`Open File` 菜单打开的文件变成临时预览标签页被后续文件顶替；回退会话时末条回复工具栏与卡片短暂闪烁消失；长连字符行导致无障碍朗读卡死；项目 Shell 初始化脚本保存后 `Saved` 确认提示立即消失。
