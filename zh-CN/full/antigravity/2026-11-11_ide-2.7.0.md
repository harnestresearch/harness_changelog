## 概述

`Antigravity IDE`（`2.6.0` → `2.7.0`；发布时间未确认，正文注记：`product.json` 所载北京时间 `2026-11-11 12:46` 为构建时间而非发布时间）是基于 Code OSS `1.107.0` 的独立 IDE 产品线，与独立 Electron 应用 `antigravity-hub`（`2.31.2`）采用互不交叉的两套版本号。跨两版本 × 三平台共 6 个官方安装包静态复核确证：**`2.6.0` → `2.7.0` 的全部代码级实质变更仅集中在 `extensions/agy/` 内置扩展的 4 个文件**（`package.json` `0.0.1` → `1.11.0`、`package.json.patch`、`vscode/extension.js` `+90,987` B、`bridge.js` `+9,333` B）。Code OSS 壳层与工作台（`out/`）、IDE 独有的 `jetskiAgent` 独立渲染器（`11.8 MB`）、VS Code 原生 MCP 与 `ext-apps` 宿主注册面、`102` 项内置扩展清单以及 `351` 个方法的 `LanguageServerService` Protobuf 描述符在两版之间**实质零变化**（仅末尾 sourcemap 注释中 37 字节 commit 哈希轮换与版本号载体更新）。

## 双产品线架构对照：Antigravity IDE vs. Antigravity Hub（`2.31.2`）

- **壳层载体与独立渲染器**：无 `app.asar` 平铺目录结构（唯一 `.asar` 为六包同哈希的 `28` B 空壳 `node_modules.asar`）、`12.9 MB` webpack 单体 `out/main.js`、`extensions/` 内置 `102` 项扩展（`enabledExtensions: ["google.google-antigravity"]`），并独有 `out/jetskiAgent/` 独立渲染子系统（`11,837,046` B 渲染 bundle + 6 类 `AgentWindow` 窗口 + `Uninitialized → Shadow → Materialized` 状态机 + `uss-lsClientInfos` 统一状态同步）。
- **按需下载 `agy --hub` 后端（不随包分发 `language_server` 或内置 MCP Server）**：六包均不内置 `language_server` 或 `chrome-devtools-mcp`（Linux/macOS 顶层 `400` 项、Windows 未剪枝 `1,367` 项 `node_modules` 均无 MCP 包）。由 `extensions/agy` 在运行时从 `https://antigravity-cli-auto-updater-974169037036.us-central1.run.app`（或 dogfood GCS，经 `sha512` 清单校验与 `.agy-install.lock` 锁保护）下载 `~/.gemini/bin/agy`，以 `agy --hub --hub-port=<N> --app_data_dir=antigravity --csrf_token=<t>` 启动本地回环 Connect-RPC 服务，再经 `ExtHost/MainThreadAntigravityProductInfo` 上报端口与 CSRF 令牌连接 `http://127.0.0.1:<port>`。_（注：此处 `--hub` 指 `agy` 自身的本地守护服务模式，与 `antigravity-hub` 桌面应用产品线无关。）_
- **更新通道**：`product.json` 中 `updateUrl: "https://example.com"` 仅作非空启用门禁，`out/main.js`（`Zqe()`）硬编码真实更新源 `https://antigravity-ide-auto-updater-974169037036.us-central1.run.app/api/update/{assetId}/{quality}/{commit}/{sha256(hostname)}`（与 CLI 更新器共享 Cloud Run 项目号 `974169037036`）。

## 内置 `agy` 扩展实质变更（`0.0.1` → `1.11.0`）

- **登录态感知三态状态栏、`signIn`/`signOut` 与跨窗口认证同步**
  - `vscode/extension.js`（`+90,987` B）将 `2.6.0` 静态 `"Antigravity - Settings"` 状态栏按钮升级为登录态三态按钮：`signedOut` 态直接绑定 `antigravity.signIn`（点击即登录），`unknown` 与 `signedIn` 态绑定 `antigravity.statusMenu` QuickPick 菜单。
  - 新增 `antigravity.signIn` 与 `antigravity.signOut` 命令、跨窗口密钥同步键 `antigravity.authSync`（`AUTH_SYNC` `0 → 4` 处）、GCP/企业条款标识 `agy.onboarding.lastLoginIsGcpTos`（`isGcpTos` `0 → 13` 处），以及新窗口打开 5 秒后的本地回环探测 `fetch POST /exa.language_server_pb.LanguageServerService/GetAuthStatus`（限定 `127.0.0.1`/`localhost`/`::1`/`[::1]` 白名单并附带 `x-codeium-csrf-token`，驱动 `onDidChangeAuthStatus` 广播）。
- **Manifest 扩容（命令 `25` → `33`）与差异审阅语义重排**
  - 新增 `8` 个命令（`signIn`、`signOut`、`statusMenu`、`startNewConversation`、`toggleChatFocus`、`insertTerminalOutput`、`acceptAllChanges`、`rejectAllChanges`），快捷键由 `18` 增至 `20`（终端 `Ctrl+L` 与 `Ctrl+Alt+L` 分流代码片段与终端输出），新增 `2` 个子菜单（`editorContextSubmenu`、`panelMoreSubmenu`）与 `configurationDefaults: terminal.integrated.commandsToSkipShell`，配置项由 `15` 增至 `16`。
  - 将 `inlineDiff`/`sideBySide` 的 `acceptAll|rejectAll` 标题改为 *"...in Current File"*，同时将跨文件 *"...in All Files"* 独立拆为新命令 `acceptAllChanges` / `rejectAllChanges`；`autoAcceptOnChat` 描述改写为非累积（non-cumulative）审阅语义。
- **Iframe 桥接 Proto 扩容（`+35` Schema）与 `isAntigravityIde` 遥测分流**
  - `vscode/extension.js`（去重 Schema `2,103 → 2,138`）与 `bridge.js`（`+9,333` B，去重 Schema `2,102 → 2,137`）两侧完全同步新增 `35` 个 iframe 消息 Schema（`74` 个 `file_*` proto 文件集不变、`0` 删除），覆盖认证/焦点族、后台任务 `ManageTask` 族（引用 `1 → 28`）、媒体处理与浏览器录制。
  - `package.json.patch` 唯一新增 `antigravity.isAntigravityIde`（默认 `true`），控制一键反馈 `productId` 由 `5398468`（`vs-code`）切换为 `5372208`（`ideName: "antigravity-ide"`），并在 webview URL 附加 `hostVariant=antigravity-ide`。

## `agy` CLI 分发、云开发环境（CDE）预装路径与 Connect-RPC 基线

- **CDE `/usr/bin/agy` 预装二进制优先与端口碰撞重试（`2.7.0` 新增）**
  - 新增常量 `CDE_PREINSTALLED_BINARY_PATH = "/usr/bin/agy"`：当 `CdeAuthService.isCdeEnvironment()` 检测到 `GOOGLE_CLOUD_WORKSTATIONS === "true"`、`CLOUD_SHELL === "true"` 或对应云端扩展已安装时，优先直接采用 `/usr/bin/agy` 并跳过更新下载（日志 `[INSTALL] Using CDE pre-installed binary at /usr/bin/agy. Skipping upda…`）。
  - `agy --hub` 启动新增端口碰撞重试逻辑（`canRetryPortCollision` `0 → 3` 处、`PortCollision` `2 → 5` 处）。
- **Connect-RPC 描述符与工具配置面冻结**
  - `out/main.js` 内联 base64 `language_server.proto` `FileDescriptorProto`（`181,134` 字符，SHA-256 `a9f7b6f4e20c3cc9…`）两版完全一致，声明 `exa.language_server_pb.LanguageServerService` **351 个方法 = 327 unary + 23 server-streaming + 1 client-streaming**（唯一客户端流式方法为 `StreamTerminalShellCommand`；与 Hub `2.31.2` 的 374 条字符串提取方法对照：共享 350 条，`StartMcpOAuthSignIn`、`CallMcpAppTool` 等 23 条新方法为 Hub `2.31.2` 独有）。
  - `extensions/agy/dist/extension.js`（`1,462,852` B，仅末尾 37 字节哈希注释差异）中的 `AntigravityServerClient` 固定调用 **10 个 RPC**（`HandleStreamingCommand`、`ProvideCompletionFeedback`、`GetUserSettings`、`SetUserSettings`、`GenerateCommitMessage`、`RecordCommitMessageSave`、`Login`、`GetAuthStatus`、`AuthLogout`、`GetBuildWithGooglePlugins`），内嵌 **45 类 `*ToolConfigSchema`**（对应 `2.29.0` 工具集合，不含 Hub `2.31.2` 新增的 `FileEdit`/`GrepSearch`/`ManageTask`/`RunWorkflow` 4 类）。
