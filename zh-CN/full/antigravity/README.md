# Antigravity 版本变更历史

[English](../../../full/antigravity/README.md) | 简体中文 · [精简版 (Highlight)](../../antigravity/README.md) | **完整详情 (Full Detail)**

覆盖 Google **Antigravity**（`https://antigravity.google`）在 `mac`、`win`、`ubuntu`、`ios`、`android` 五端的技术版本演进索引，当前共收录 **9** 个深度逆向版本，分属两条独立桌面产品线：
- **Antigravity Desktop（`antigravity-hub`）**：内置单体 Go `language_server` 的独立 Electron `44.9.1` 客户端（`2.31.2` → `2.36.0`，覆盖 `mac`、`win`、`ubuntu`，最新 2026-11-27；`2.31.2`–`2.32.1` 以 `linux-x64` 为锚点，`2.32.2`/`2.35.1`/`2.35.2`/`2.36.0` 采用官方 `darwin-arm` 主分析并配合跨端同构建核对）。
- **Antigravity IDE（`Antigravity IDE`）**：基于 Code OSS `1.107.0` / Electron `39.2.3`、按需下载拉起 `~/.gemini/bin/agy --hub` 的 IDE 产品线（`2.7.0` → `2.8.0`，覆盖 `mac`、`win`、`ubuntu`，最新 2026-11-19）。
