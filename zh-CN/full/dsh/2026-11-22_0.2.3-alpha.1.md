## 新增功能与架构演进

### 1. Git 仓库插件来源（`@deepseek-ai/dsh-plugin-market-index`、`@deepseek-ai/dsh-plugin-market`，PR #8159）
- **门控状态**：`@deepseek-ai/dsh-experimental-plugin-market-bundle` 仍位于 `OPTIONAL_BUNDLES`、`EXTENSION_BUNDLES` 与 `EXPERIMENTAL_BUNDLES`（`packages/util/official-bundles/src/bundles.ts:72`、`plugin-manager.ts:42,81`），默认关闭。
- **地址解析（`packages/util/plugin-market-index/src/source.ts:1-72`）**：识别 `git+https://`、`git+ssh://`、`ssh://`、GitHub SCP 风格 SSH 简写（`github.com:<owner>/<repo>`）、GitHub HTTPS 仓库链接与 `*.git` HTTPS URL，规范化为 `git+<remote>?path=…&ref=…`（默认 `path: 'index.json'`；`ref` 接受分支名或 40 位十六进制 SHA；拒绝内嵌凭据、`#fragment`、`..` 路径穿越或 `HEAD`）。
- **仓库缓存与隔离（`packages/boot/plugin-market/src/repository-cache.ts`）**：在 `detailCacheDir` 下按 URL 哈希建立加锁裸仓库并执行 `--depth 1 --filter=blob:none` 部分克隆；清除除 SSH 程序外的继承 `GIT_*` 环境变量，禁用 hooks、fsmonitor、子模块递归及 `https`/`http`/`ssh` 之外的所有传输协议，每 200ms 轮询目录体积对照 `detailRepositoryMaxBytes`/`detailCacheMaxBytes` 限额。私有仓库复用宿主 Git/SSH 凭据；Git 索引图标须为 base64 data URL 或浏览器可达的 HTTPS URL。

### 2. 实验性时间线插件（`@deepseek-ai/dsh-timeline`，PR #7973、#8630）
- **门控状态**：新增至 `OPTIONAL_BUNDLES`、`MORE_BUNDLES` 与 `EXPERIMENTAL_BUNDLES`（`packages/util/official-bundles/src/bundles.ts:61`、`plugin-manager.ts:53,69`），在 **插件 → 更多 → 实验性插件** 中手动启用。
- **核心机制（`packages/experimental/timeline/src/`）**：将会话任务树、权重、优先级、阻塞项、变更历史、讨论与定时进展报告写入 Session 日志（单次树写入上限 `2 MiB`，UI 展示最近 7 天报告与至多 512 条讨论）；提供 `timeline_tree`/`timeline_tasks`/`timeline_pull`/`timeline_read`/`timeline_reply` 五个工具、可选「替换 Todo 工具」、可点击展开任务树的进度条、`/timeline` 命令与 `.timeline.json` 检查点导出/导入（支持 `--copy`/`--continue`）以及 8 语种下的「跟随应用 / 跟随对话」语言选项。定时报告可独立调用当前会话模型（首层复用最近合规请求前缀，高层汇总下层报告，校验失败可发一次修复请求），额外消耗模型 token。

### 3. 代码审阅页面、扩展 API 与 GitLab 提供方（`packages/experimental/forge*`，PR #8321、#8362、#8228、#8317、#8536、#8297）
- **门控状态**：全部由可选实验组合包 `@deepseek-ai/dsh-experimental-forge-bundle`（`OPTIONAL_BUNDLES`/`EXPERIMENTAL_BUNDLES`，`bundles.ts:74`、`plugin-manager.ts:74`，**默认关闭**）加载；其 `cordis.patch.yml:10-11` 新增挂载 `@deepseek-ai/dsh-forge-gitlab`。
- **代码审阅页面（`packages/experimental/client-ui-forge/src/viewer-lists.ts`、`src/client/review-page/`）**：按 `review-requested`、`authored`、`involved` 三类流式拉取本人相关变更请求与侧栏计数，提供详情、状态列与页内智能体对话（`ReviewChat.tsx`）。**提供方边界**：`packages/experimental/forge-github/src/provider.ts:75,128,141` 经本机 `gh` 实现了 `viewer`/`listForViewer`/`countForViewer`；`packages/experimental/forge-gitlab` **未实现** `viewer` 列表，因此全局代码审阅页面仅展示 GitHub PR。
- **GitLab 提供方（`packages/experimental/forge-gitlab/src/{index,provider,api,status,diff,review,writes,glab}.ts`）**：通过经环境变量清理的本机 `glab api`（REST/GraphQL，写操作不重试）接入 GitLab.com 与自托管 GitLab 的会话关联 MR，支持状态/流水线/审批/可合并性/未解决讨论轮询、按版本固定的 diff、行区间讨论与草稿批注（`submit-pending`/`discard-pending`）、审批、解除草稿、合并、重试流水线、邀请评审人及基于最新 head 校验的 rebase。
- **扩展机制与工作树改进**：插件可注册自定义审阅视图（lens）、行注解以及工具栏/文件菜单/评论框槽位操作，并监听 `forge/review-changed` 事件（`packages/experimental/forge/src/index.ts:42,795`）。工作树支持自定义分支名校验、按远端分支单分支无标签抓取创建、首条消息发送后延迟创建，以及追踪 PTC 程序内 `gh`/`git push` 关联的 PR（PR #8297）。

### 4. 会话状态面板与独立会话状态服务（`@deepseek-ai/dsh-client-ui-session-panel`、`@deepseek-ai/dsh-client-ui-session-status`，PR #7965、#7990、#8625、#8609、#8130、#6858）
- **会话状态面板（`packages/client/ui-session-panel`，`dsh-web-app:476-477` 默认启用）**：标题栏开关 + 可扩展浮层面板（内置工作目录「环境」区，由各插件注册变更请求、子智能体、任务与插件状态分区），支持拖拽调整分区顺序与 `localStorage`（`dsh.sessionPanel.pinned`）记忆；右槽 ≥`348px` 时以 `300–360px` 停靠（帧宽 ≥`1068px` 时自动左移正文与输入框让位），窄窗或右侧栏展开时退化为 `280px` 浮层并支持 `Escape` 关闭。
- **已读/未读状态（`packages/client/ui-session-status`，`dsh-web-app:295-296` 默认启用）**：将 `SessionStatus`、`SessionStatusSnapshot`、`UseSessionStatus` 及 `useSessionStatus` 从 `@deepseek-ai/dsh-client-ui-session` 迁出为独立包（`SessionStatusService`，`src/index.ts:25`）；基于 Host 内存阅读记录在同一 Host 的多客户端间同步未读提醒，新增必填 `completionFailed` 字段，提供行菜单/快捷键切换（`mark(sessionId, unread)`），并优化最近会话保留与未渲染会话折叠跳过（PR #8502）。

### 5. Web 远程登录、设备配对与可插拔连接鉴权（`@deepseek-ai/dsh-client-remote-connection`、`@deepseek-ai/dsh-host-authentication-{token,desktop}`，PR #8266、#7675、#8898、#8920）
- **远程连接（`packages/client/remote-connection/src/index.ts:60`，`dsh-web-app:354-355` 默认启用，桌面端窗口隐藏）**：在 **设置 → 远程连接** 提供一次性二维码登录（`ticketLifetimeMs: 120_000`、`cookieMaxAgeDays: 30`）、私有令牌登录链接（PR #8920 恢复回环地址登录链接）以及已登录端审批的设备配对（`requestTtlMs: 300_000`、`maxRequests: 32`、`requestIntervalMs: 1_000`、`pollIntervalMs: 2_000`），匿名登录页支持中英文。
- **标准化连接鉴权 API 与提供方（`docs/upgrade-guide/v0.2.2-rc.2/connection-page-peer`）**：
  - `webServer.register`/`registerFallback`/`registerUpgrade` 新增 `auth: 'anonymous' | 'required' | 'deny'`，**默认改为 `'required'`**，原先公开路由与静态资产须显式声明 `'anonymous'`。
  - `@deepseek-ai/dsh-host-authentication-token`（`web-app:258-259`、`src/index.ts:31`、`src/browser-auth.ts:30`）承载默认 Token 交换与 `/api/remote.mux` 单 Socket 认领，并在登录时清理同主机旧端口 Cookie，最多保留 **17 个端口**（当前 + `RETAINED_OTHER_COOKIES = 16` 个最近签发），防止超过 Node `16,384` 字节请求头上限触发 HTTP `431`（PR #8898）；明文 HTTP 监听下 Cookie 无 `Secure` 属性且明文传输。
  - `@deepseek-ai/dsh-host-authentication-desktop`（`src/index.ts:23`）通过 Electron 主进程与宿主私有 IPC 通道传递内存密钥（`dsh-desktop-session` Cookie），不向渲染层或浏览器 Cookie 存储暴露凭据。

### 6. 连接器账号体系、MCP OAuth、按需加载与 7 个独立连接器
