## 概述

`3.17.2` 是建立在 [3.17.1](2026-10-29_3.17.1.md) 之上的轻量级安全、权限与诊断修复补丁。Linux `x86_64` 全包 `2,678` 个文件中仅 `5` 个文件发生变化（`0` 新增、`0` 移除；`app.asar` `+26,104` B、`glm/zcode.cjs` `+1,880` B），Electron 运行时与依赖树零变动。由于官网 `zcode.z.ai/changelog` 未单列 `3.17.1`，其 `3.17.2` 页面合并刊载了 `3.17.1 + 3.17.2` 的累计说明；所有已在 `3.17.1` 落地的特性均已归入 [3.17.1](2026-10-29_3.17.1.md)，下文仅记录 `3.17.1 → 3.17.2` 的真实净增变更。

## 二进制核实的净增变更（`3.17.1` → `3.17.2`）

- **MCP 启动失败建议面板（`settings.mcp.failureAdvice.*`）**
  - 渲染层国际化包（`IntlProvider`）净增 `21` 个键（`7,268 → 7,289`，移除 `0`）：新增 `settings.mcp.failure.{adviceTitle,errorDetails}` 及 `19` 类启动失败诊断建议文案（`coding_plan_required`、`config_invalid`、`connection_failed`、`connection_timeout`、`network_unreachable`、`not_authenticated`、`oauth_authorization_failed`、`official_origin_untrusted`、`process_start_failed`、`protocol_error`、`protocol_negotiation_failed`、`rate_limited`、`runtime_unavailable`、`server_internal_error`、`server_not_found`、`server_unavailable`、`status_unavailable`、`tool_list_failed`、`unexpected_disconnect`）。
- **内置浏览器本地网页预览 URL 白名单（`zcode:browser-view-load-url`）**
  - 主进程（`out/main/index.js`，`+3,764` B）新增 `BrowserViewLoadUrl` 处理器与 `createBrowserLocalPreview`，对内置浏览器预览实行显式 `about:` / `data:` / `file:` / `http:` / `https:` 协议白名单校验（非法导航拒绝并返回 `"Invalid browser navigation"` / `"Unsupported browser URL"`），并同步接线至 `5` 个 preload 脚本（`index`、`codingPlanWebview`、`cuaPermissionPanel`、`embeddedBrowserJavaScriptDialog`、`resourceManager`）。
- **自定义命令动态脚本审批交接、插件环境修复与子任务计划模式限制**
  - `glm/zcode.cjs`（`+1,880` B）移除提示词展开阶段直接执行动态脚本的 `expandCustomCommandShellSyntax` / `runShellExpansion` / `normalizeFencedShellCommand`，改为 `handOffCustomCommandShellBlocks`、`createBashSessionEnv`、`resolveShellTextVariable` 与 `ZCODE_PLUGIN_NAME`——将自定义命令中的 `` !`…` `` 与 `!` 围栏块改写为经 `Bash` 工具执行的指令（纳入正常权限审批并在计划模式下可被拒绝，同时修复 Windows 插件命令路径出错问题）；`zcode-guide-plugin/skills/diagnosing-commands/SKILL.md`（`+314` B）同步改写陷阱说明。
  - 新增 `buildRuntimeModeReminderBodyForTask` 与 `buildSubagentPlanModeReminder`，确保子任务继承并与主会话保持一致的计划模式（Plan mode）权限限制。
- **会话激活工作区归属校验、分阶段资源释放与宿主分叉/路由校验**
  - `glm/zcode.cjs` 新增 `validateSessionActivationWorkspace`、`validateActivation` 与 `resolveLegacyRemoteSessionWorkspace` 工作区归属校验，并将单次超时关闭重构为分阶段会话释放管线（`close_admission`、`cancel_execution`、`goal_pause`、`execution_finalization`、`mcp_ui_release`、`projection_release`、`runtime_close`、`closeNamedResources`、`getPendingSessionPersistence` 及遥测 `session.resource_close.slow` / `zcode_protocol.session.release_stage_failed`），修复切换与恢复会话时串到其他会话的问题。
  - 宿主进程（`out/host/index.js`，`+952` B）新增 `prepareForkCreation` 分叉准备回调及官方 MCP 身份头请求的 `workspace-routing`（`-32602`）路由阶段校验。

## 官网 `3.17.2` 说明中其余非重复项（多端与运行期修复）

以下官网 `3.17.2` 条目不属于 `3.17.1` Linux 包已定位特性集（含 macOS / Windows 平台专属修复）：

- Computer Use 新增多会话光标；新增 MCP 配置界面（草稿版）。
- 配置文件损坏时不再被覆盖以避免数据丢失；未打开项目时也能完成用户级数据迁移；删除项目后可正常新建任务。
- 回复被安全策略拦截时快速报错不再反复重试；无进展的重复执行自动结束并提示；浏览器附件链接不再被反复下载；修复微信自动化任务结果推送与产物卡片偶发不刷新问题。
- 平台专属项：修复 macOS 安装包丢失中英文语言资源与部分应用图标空白问题；修复 Windows 64 位安装包混入不兼容组件、窗口被遮挡后恢复显示异常及部分文件无法用默认应用打开问题；托盘图标移除未读红点（保留任务栏未读状态）并缩减安装包体积。
