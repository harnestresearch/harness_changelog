# ZCode Desktop 3.15.1

[English](../../../full/zcode/2026-10-10_3.15.1.md) | 简体中文 · [精简版 (Highlight)](../../zcode/2026-10-10_3.15.1.md) | **完整详情 (Full Detail)**

- **发布日期**：2026-10-10
- **覆盖平台**：`mac`、`win`、`ubuntu`
- **版本摘要**：上线 UI 插件（MCP App）与消息流可视化交互界面、飞书群及独立话题任务协作、工作流按子代理指定模型与创建前调参/运行中改并发/保存复跑、自主模式危险命令执行前确认、内置浏览器站点权限管理、Linux 关闭窗口驻留系统托盘，并修复内置浏览器默认放行权限与 Windows 链接启动安全隐患。

## 官方更新说明（`zcode.z.ai/changelog`）

### 新功能

- 邀请好友·免费蹬蹬，共得权益活动上线。
- 支持订阅用户随机获得 GLM HighSpeed 体验。
- 更新“自主模式”，危险命令执行前会先征求确认。
- 新增可视化交互界面，在消息流中更直观的展示信息。
- 新增支持 UI 插件（MCP App）。
- 工作流支持创建前调参、运行中改并发和保存复跑。
- 工作流可为每个子代理单独指定模型。
- 支持通过飞书群和独立话题与助手协作处理任务。
- 内置浏览器支持网站权限管理，摄像头等权限确认。
- Linux 下关闭窗口可驻留系统托盘。
- 账户菜单可查看套餐信息并复制用户 ID。

### 问题修复

- 修复加速回合中编辑的消息可能丢失的问题。
- 修复工作流恢复或修改后任务状态显示错误的问题。
- 修复更新下载失败后不再复查新版本的问题。
- 修复内置浏览器网站权限默认放行的安全隐患。
- 修复内置浏览器用默认浏览器打开本地文件失败的问题。
- 修复群聊中@提及识别不准的问题。
- 修复飞书授权过期后群任务失去响应的问题。
- 修复额度已满时看不到重置机会入口的问题。
- 修复窗口大小变化时对话滚动跳动的问题。
- 修复个别异常消息导致会话加载卡住的问题。
- 修复 Windows 下通过链接启动应用的安全问题。
- 修复多个工作区同时启动时可能卡顿的问题。
