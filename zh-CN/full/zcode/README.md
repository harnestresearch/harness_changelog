# ZCode 版本变更历史

[English](../../../full/zcode/README.md) | 简体中文 · [精简版 (Highlight)](../../zcode/README.md) | **完整详情 (Full Detail)**

| `ubuntu` | Ubuntu / Linux（`ZCode` `.deb` & AppImage CDN / AUR） | 54 | `2.13.0` → `3.18.2` | [3.18.2](2026-11-13_3.18.2.md) |
