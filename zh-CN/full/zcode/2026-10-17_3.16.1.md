## 概述

`3.16.1` 是应用层重磅特性版本（i18n 键 `+730 / −110`、`.deb` `+8.89` MB、`glm` 插件资产 `+325` 个文件）。官方更新清单 `3.16.1/linux-x64/latest.yml`（SHA-512 校验一致）下发了完整的中英双语 `Release v3.16.1` 发行说明（`14` 条新功能 + `18` 条问题修复）——官网 `zcode.z.ai/changelog` 未单列 `3.16.1`，而是将同一份说明原封不动挂在后续 `3.16.2` 名下。经 `3.15.3 → 3.16.1 → 3.16.2` 三版二进制差分核实，该发布线的全部新特性与界面重构均在 `3.16.1` 落地。

## 新增功能与架构变更

- **统一远程设备管理（`source-server` 替代 `bot-remote-workspace`）**
  - 移除旧版 `bot-remote-workspace` 协议族（整包 `84 → 0`），全面切换至 `source-server` / `SourceServer`（`app.asar` 内 `0 → 262`，`out/host/index.js` `+385,526` B），通过 `settings.source.*`（`161` 键）与 `remote.error.*`（`85` 键）统一纳管 SSH 服务器、WSL 发行版与 Docker 容器；支持常驻远程会话、导入 `~/.ssh/config`、启动自动重连 7 天内设备、双工通道承载 HTTP/WebSocket（`connectWebSocketOverDuplex`）、SSH 凭据存储及本地 SQLite `remote_project_entries` / `hosts` 表。
  - 调度器（`out/scheduler/index.js`，`+69,575` B）新增远程工作区数据迁移机制与 `6` 张 SQLite 表（`workspace_migration_schema_version`、`workspace_migration_ledger_v`、`workspace_migration_conflicts_v`、`workspace_alias`、`controller_remote_identity_migrations` 及 `task_group_admissions`，移除旧 `tasks_schema_migration`），支持分阶段备份合并与冲突检测（`ZCODE_MIGRATION_BACKUP_SKIPPED`）。
- **按需工具搜索（`ToolSearch` 与 `DeferredToolCall`）**
  - 新增桌面设置 `settings.toolSearch*`（自动 / 本地 / 关闭，默认关闭）与 CLI 旗标 `--toolsearch-mode <auto|native|local|off>`（`glm/zcode.cjs` 新增 `resolveToolSearchCapability`、`DeferredToolCall` `0 → 17`、`"tool.search"` 及第二处 Anthropic `advanced-tool-use-2025-11-20` beta 头调用点）。
- **文档类插件侧栏查看面板与 MCP 服务（`+325` 个文件 / `+33.1` MB）**
  - `documents`（`0.1.8 → 0.2.0`）、`pdf`（`0.1.8 → 0.2.1`，新增 `298` 个文件，含完整 PDF.js cmaps、`97` 个 Noto Sans SC `woff2` 字体、标准字体与 WASM）、`presentations`（`0.1.8 → 0.2.0`）、`spreadsheets`（`0.1.8 → 0.2.0`）由纯技能包升级为「技能 + MCP 服务（`dist/server.mjs`）+ 会话级侧栏 UI 面板（`ui://*/panel.html`）」，配套新增渲染层独立块 `pptxElementReference-BBtAnwAP.js`（`250,339` B）与 `@modelcontextprotocol/ext-apps@2.0.0`。
- **本地项目多文件夹、侧栏文件浏览与输入框组合切换控件**
  - 新增项目多源文件夹管理（`project.*` `85` 键、`additionalDirectories` `0 → 163`、主要目录指定与信任确认）、侧边面板文件管理器（`fileManager.*` `5` 键）与侧栏「完整视图」/启动器（`sidePane.fullView.*` `11` 键、`toggleSidePaneFullView`），以及输入框模型/思考力度/团队套餐直切工具栏（`chat.toolbar.combined.*` + `executionSelection` / `captureHighspeedFallbackSelection`）。
- **弹层对话分享、按项目归档、任务分组、插件市场与手机远控**
  - 对话分享重构为弹层操作并支持内容范围选择、只读回放标注及工作流产物/图片预览（`conversationShare.*` `+50 / −14` 键）；历史归档独立为按项目分组折叠面板（`archives.*` `29` 键）；新增任务分组视图（`taskGroup.*` `17` 键）与闲时任务运行时控制器（`OffPeakTicketAuthority`）；新增插件市场界面键（`settings.plugins.store.*` `12` 键）、图片预览复制/下载/引用（`preview.image.*` `6` 键）、本机/远端机器作用域标签（`settings.machine.*`）、Windows 任务栏/托盘未读提醒，以及手机远控账号登录与设备管理入口重构（`webRemoteControl.*` `+6 / −22` 键）。
- **内置模型供应商配置更新（revision `31 → 33`：MiMo Token 套餐与 `1M` 默认规则）**
  - `xiaomi-mimo` 更名为 **Xiaomi MiMo API**（新增 `mimo-v2.6-pro` / `mimo-v2.6-flash`），新增 **Xiaomi MiMo Token Plan** 模板（`xiaomi-mimo-token-plan`，`https://token-plan-cn.xiaomimimo.com/anthropic`），并将默认兜底规则 `modelRules[0]` 的上下文窗口由 `200,000` 提升至 `1,000,000`、最大输出 Token 由 `32,000` 提升至 `128,000`。

## 问题修复（官方 `Release v3.16.1` `latest.yml` 清单）

- 修复网络中断被误报为远端环境不满足要求的问题；修复连接日志可能泄露敏感信息的问题；修复 Windows 下可能越界读取本地文件的安全问题。
- 修复模型创建失败时输入丢失与对话卡住、达到上下文上限后对话无响应、模型切换时编辑中输入被覆盖、加速模型不可用时无法回退或输入丢失，以及切换项目或新建任务时草稿丢失的问题。
- 修复恢复历史会话时附件错乱或误判失败、添加的附加目录未包含进对话上下文、项目目录缺失时列表报错且无法新建任务、重启后已关闭工作区标签再次出现，以及后台完成任务未读数与角标计数不正确的问题。
- 修复模型菜单与思考滑杆显示交互异常、工作流参数过多时运行按钮被挤出屏幕、数据库升级后偶发锁定卡顿、MCP 应用未就绪时调用失败，以及终端启动时开头输出丢失的问题。
