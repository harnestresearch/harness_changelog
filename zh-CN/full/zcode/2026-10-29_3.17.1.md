# ZCode Desktop 3.17.1

- **发布日期**：2026-10-29（构建号 `3.17.1-9553`，commit `025f7f39`，GitHub tag `v3.17.1` / `a60ba6a7` 发布于 `2026-10-30T09:35:41Z`）

## 概述

`3.17.1` 是桌面底座与功能面的重磅大版本（官方从未发布 `3.17.0`；官网 `zcode.z.ai/changelog` 未单列 `3.17.1` 条目，而是将其累计说明并入后续 `3.17.2` 页面）。经 `3.16.3 → 3.17.1 → 3.17.2` 三版二进制对齐逆向核实：Electron 44 主版本升级、随包分发的 `npm 12.2.0` 运行时（`+1,677` 个文件）、`zcode-site` 官方建站插件、基于 `sharp` 原生模块的图片标注编辑器、统一远程数据同步、项目批量管理与绝大多数 `3.17.x` 桌面/智能体新特性均在 `3.17.1` 实际落地。

## 桌面与界面新增功能

- **图片标注编辑器（`imageEditor`）与 `sharp` 原生模块**
  - 图片预览新增画笔、矩形、椭圆、箭头、文字、橡皮擦、选择移动、颜色调节及撤销/重做工具，支持将标注结果直接「保存到对话」发送（`imageEditor.*` 新增 `17` 个 i18n 键及 `data-image-preview-*` 锚点）。
  - `app.asar.unpacked` 新增 `@img/sharp-linux-x64/lib/sharp-linux-x64.node`（`410,952` B），`app.asar` 同步打入 `node_modules/@img`（`12` 个文件，`+17.1` MB）。
- **统一远程数据同步（`remoteSync` 重构）**
  - 移除旧版分散的 `69` 个 `settings.{mcp,plugins,skills}.remoteSync.*` 与 `settings.remoteSync.*` 键，统一重构为 `remoteSync.*`（`101` 键），支持按命令、钩子、MCP 服务器、插件、技能（父子技能一并同步）、子智能体与模型提供商单类或全量推送，并支持打开远端设备项目后自动同步提供商配置。
  - 协议层新增 `user-config-sync`、`plugin-data-sync`、`skill-data-sync`、`subagent-data-sync` 四条同步通道。
- **设置页项目批量管理与数据清理（`projectManagement`）**
  - 新增 `projectManagement.*`（`106` 键）与 `project.data*` 处理逻辑：支持多选移除项目、可选同时删除会话/会话文件/检查点/记忆数据（删除前计算体积并要求输入「删除」确认）、在「已移除的项目」中恢复本机项目，以及按未读筛选排序。
- **远端服务停止 / 重启 / 重装与紧凑可搜索设备列表**
  - 扩充 `settings.source.*`（`+24` 键）与 `sourceServer.*`（`6 → 12` 键），支持对远端 ZCode Server 执行停止、重启与保留项目/任务的重新安装，设备列表支持按设备名/地址/项目过滤并隐藏项目行设备名；新增 `source-server-control-unresponsive` / `downgrade-unconfirmed` / `stop-failed` / `operation-in-progress` 协议错误码。
- **内置 `zcode-site` 官方建站插件（`v0.4.2`，第 16 个内置插件）**
  - 新增 `resources/glm/packages/zcode-site-plugin/`（`25` 个文件）：含 `zcode_official` JWT 鉴权的 MCP 服务 `dist/server.mjs`（`595,415` B）、侧边栏 `sites`（「部署」）UI 面板（`panel.html` `872,302` B）、`7` 个斜杠命令（`site-badge/deploy/logs/offline/online/status/usage`）与 `site-deploy` 技能。
- **插件一键全部更新与非官方市场风险提示**
  - 新增 `settings.plugins.updateAll*`（完成/部分失败/范围切换中止）及 `marketplaces.riskWarning` / `riskAcknowledgement`（共 `6` 键）。
- **内置供应商与模型配置扩容（revision `33 → 43`）**
  - 新增 `13` 个供应商模板（`kimi-code-cn`、`kimi-code-intl`、`minimax-m-plan-cn`、`qwen-coding-plan-cn`、`qwen-token-plan-team-cn`、`siliconflow-cn`、`stepfun`、`stepfun-step-plan`、`tencent-tokenhub-cn`、`tencent-tokenhub-intl`、`volcengine-agent-plan`、`volcengine-ark`、`volcengine-coding-plan`）；内置模型 ID 由 `167` 增至 `203`（新增 `39` 款：含 `kimi-k3.1-pro`、`MiniMax-M3.1-Flash`、`GLM-5.3`、`glm-5.3-flashx`、`DeepSeek-V4-Flash`、`doubao-seed-2.1`、`claude-haiku/opus/sonnet-5-5`、`gpt-6-luna`、`gpt-6.1-sol`、`grok-4.7`、`step-3.7-flash`、`step-5-preview`、`mimo-v2.6` 等；下线 `MiniMax-M2`、`MiniMax-M2.1`、`MiniMax-M2.1-highspeed` `3` 款）。
- **个性化指令、完全访问确认页与工作区 MCP/Hook 信任门控**
  - 设置新增「个性化」本机自定义指令（`settings.personalization.*` `11` 键，`100` KB 上限）、启用完全访问（YOLO）前的风险确认弹窗（`mode.yoloConfirmation.*` `11` 键），以及工作区 MCP 服务器与 Hook 信任门控（`settings.mcp.trust.*` `8` 键 + 聊天侧待信任横幅 `workspaceMcpPending` / `workspaceHookPending`）。
- **文件卡片操作菜单、预览整卡打开、未读筛选、`/reload` 与拉取手机日志**
  - 扩充 `fileActions.*`（`2 → 12` 键：支持 `50` MiB 上限「另存为…」、「在 {application} 中打开」与更多打开方式，配套主进程 `readFileIcon` 与应用定位器），新增预览卡片整卡点击打开（`chat.previewCards.openCard`）与正文链接「在 ZCode 中打开」，新增未读任务筛选（`viewUnread`）与任务/Agent 进程重启恢复（`recoverWorkspace`），新增 `/reload` 斜杠命令、桌面 `pullMobileLogs`（`mobile-log-pull-*` 协议）、发送前请求校验配置读取重试（`chat.configRead*`）及闲时任务错误码细化（`3102` 排到离线退回额度 / `3106` 超单次最长运行时间 / `offPeakTicketExpired`）。

## 智能体运行时、协议与内置插件变更

- **MCP 无 Node 回退（随包分发 `npm 12.2.0` + shim）**
  - 新增 `resources/glm/node-runtime/npm/`（`npm@12.2.0`，共 `1,677` 个文件）及 `renderNodeFallbackShims`（通过 `ZCODE_NODE_FALLBACK_EXEC_PATH` / `ZCODE_NODE_FALLBACK_NPM_ROOT` 生成 POSIX/Windows 回退垫片），未安装 Node.js 的机器亦可直接启动 MCP 服务器。
- **动态工作流配额自动续跑与 `world.run` 输出整形**
  - 新增 `startWorkflowQuotaAutoResume` 管线（`isPlausibleQuotaResetAt` 与 `dynamic_workflow.quota_resume.{scheduled,failed,gave_up,refused}`），在配额重置时自动续跑因配额暂停的工作流；`dynamic-workflows/SKILL.md`（`+1,099` B）新增 `world.run` 的 `opts.output`（`"full"` / `"discard"` / `{ tail: n }`，`16` MiB 上限）与 `run.id` / `run.resumedFrom`。
- **`CronPauseSelf` 定时自动化自我暂停工具**
  - 新增仅在计划任务触发运行期间可用的 `CronPauseSelf`（`cronPauseSelfHandler`），支持自动化在满足用户设定停止条件时将自身置为暂停。
- **官方命令本地端点、输入预测、内置工具流改写与会话常驻控制**
  - `glm/zcode.cjs`（`+163,797` B）新增 `createOfficialCommandEndpoint`（本地 Unix `endpoint.sock` + Bearer 令牌，`ZCODE_OFFICIAL_ENDPOINT` / `ZCODE_OFFICIAL_ENDPOINT_TOKEN`）、Protocol v4 `ConversationInputPredictionHandler`、`ProviderBuiltinToolStreamRewriter`（将供应商内置 `web_fetch`/`web_search`/`code_execution`/`tool_search_tool_*`/`advisor` 块改写为可完整展示调用过程与结果的 MCP 风格工具块）、`SessionLifecycleController`（`residency: "resident-only"` / `V4SessionNotResidentError`）、`x-zcode-session-features` 请求头、本地 `ttft.*` 遥测键，以及绕过仓库自定义 Git 钩子的自动快照加固（`26` 个钩子名 + `automaticGitArgs/Config/Env`）。
- **桌面↔宿主新协议与内置插件更新**
  - 新增 `task-pin`、`task-archive`、`workspace-create` 与 `provider-provisioning-lane` 请求/响应协议。
  - `node-repl-host`（`0.6.1 → 0.7.0`，因嵌套依赖去重由 `5,618,452` 缩减至 `4,884,244` B，`−734,208` B）：加固 Computer Use Helper 安装器（`O_EXLOCK` 租约锁、`ZCODE_CUA_HELPER_BUILD_ID` 钉定、Apple `TeamIdentifier` 签名校验、符号链接/zip 路径校验及 browser broker 鉴权）并重写 observe-then-act 指引。
  - `zcode-cua`（`0.6.5`）：修复 `left_click_drag` 的 `strategy` 参数透传、移除死键映射 `greater: ">"`、修正 `get_app_state` 的 `tree_shown_to_model: true` 记账。
  - 四款文档插件（`documents` `0.2.1` / `pdf` `0.2.2` / `presentations` `0.2.1` / `spreadsheets` `0.2.1`）去重瘦身（各约 `−224` KB）并新增 `open_document` MCP 工具；`visualize`（`0.1.0 → 0.1.1`）CSP 白名单加入 `zcode.z.ai`；`electron-updater` 升至 `^6.8.10`；`.deb` 的 `postrm` 修复 `update-alternatives --remove` 真实二进制路径并在删除前卸载 AppArmor 配置。
