## 概述

`3.14.2` 是围绕「动态工作流（Dynamic Workflows）」展开的功能版本（`glm/zcode.cjs` `+23,908` B、`app.asar` `+15,496` B、`bundled-skills` `+4 / −4` 文件搬迁）。尽管官网 `zcode.z.ai/changelog` 与 GitHub Releases 均未单列 `3.14.2`，而是在约 11 小时后将该批工作流说明挂在 [3.14.3](2026-09-22_3.14.3.md) 名下发布，经 `3.14.1 → 3.14.2 → 3.14.3` 三版二进制对齐核实：全部智能体运行时与渲染层工作流改动均已在 `3.14.2` 落地（`3.14.3` 为 `zcode.cjs` 逐字节相同的纯重建包）。

## 动态工作流新特性与运行时变更（`3.14.1` → `3.14.2`）

- **运行中工作流就地调整并发上限（`AmendWorkflow` + `createWorkflowRunSeatGate`）**
  - `glm/zcode.cjs` 新增 `resolveConcurrencyRetuneRoute` 与 `runConcurrencyRetune`：当 `AmendWorkflow` 入参仅修改 `max_concurrency`（`isConcurrencyOnlyAmend`）且前驱运行处于 `pending`/`running` 时，直接调用 `setMaxConcurrency` 原地生效而无需停止重建（已结算或不可调整时由 `resolveRetuneFallbackAmend` 回落至修订重启）。
  - `setMaxConcurrency` 将新并发写入 `dwf_event` 日志表（`updateRunCaps`）、发射带 `concurrencyCeiling` 的 `run-caps-changed` 事件，并在调高上限时立即调用 `scheduler.pumpAll()` 放行等待子代理；新增 `createWorkflowRunSeatGate`（`bindSeatGate`，维护 `{ limit, working, parked }`）在调低上限时让超出座位的子代理于下一模型回合前平滑停驻。
  - 渲染层（`styles` 块 `+6,105` B、`IntlProvider` `+941` B）新增 `data-workflow-retune-run-id` 就地调参按钮及 `chat.toolCall.workflow.run.settings.consequence.concurrencyLive` / `event.runCapsChanged` 文案。
- **工作流工具上下文瘦身与 `428` 技能门控（`requireDynamicWorkflowSkill`）**
  - `CreateWorkflow`（纯按名运行已保存工作流除外）、带脚本的 `AmendWorkflow`、`SaveWorkflow` 与 `EvalWorkflowSnippet` 新增 `requireDynamicWorkflowSkill`（错误码 `428`）：当前会话未加载 `dynamic-workflows` 技能时直接拒绝并指引先调用 `Skill("dynamic-workflows")`；编译通过后经 `recordAuthoredWorkflowDraft` 写入文件读取态以便增量编辑。
  - `dynamic-workflows/SKILL.md` 由 `63,088` 扩充至 `92,387` B（`+29,299` B，新增 `§16 Tool reference` 承载完整编译器 facade 与工具契约），`examples.md` 扩充至 `35,528` B（含 `5` 个完整示例），大幅缩减常驻工具描述的上下文占用。
- **`dynamic-workflows` 迁入不可卸载 `bundled-skills` 包与内置 `/workflow` 命令合成**
  - 将 `skills/dynamic-workflows/{SKILL.md,examples.md,patterns.md}` 从 `zcode-guide-plugin`（`0.2.0 → 0.3.0`，移除 `plugin.json` 的 `"commands"` 字段）迁入 `opt/ZCode/resources/glm/packages/bundled-skills/`。
  - 新增 `materializeSeaBundledSkillPack`（SEA 形态按内容哈希解压 `.zcode-bundled-skills-seed.json`、`findMissingBundledSkillPackPaths` 完整性校验、发现优先级设为 `1,000,000` 以保证用户/项目/插件同名技能优先）及运行时合成的内置 `/workflow` 命令（`expandBuiltinWorkflowCommandPrompt`，`path: "builtin:workflow"`）。
- **大型工作流实时状态有界截断与传输保护**
  - 新增 `clampWorkflowRunsForLegacy`（优先保留活跃子代理）、带驱逐组与 `nodesUnlisted` / `nodesUnlistedSettled` 计数的 `workflowRunTablesForNewLife`，以及限制单次更新帧体积的 `workflowRunUpdateWithinWireBounds` / `mergeWorkflowRunUpdates`。
  - 渲染层新增 `workflow-run-truncated` 与 `workflow-roll-unlisted` 组件（`chat.toolCall.workflow.timeline.roster.unlisted.{one,many}` 与 `run.truncated`，`chat.*` i18n 键 `1,343 → 1,348`）及订阅超界故障码 `fault.subscription.contentRejected`。
