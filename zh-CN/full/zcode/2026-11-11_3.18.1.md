# ZCode Desktop 3.18.1

[English](../../../full/zcode/2026-11-11_3.18.1.md) | 简体中文 · [精简版 (Highlight)](../../zcode/2026-11-11_3.18.1.md) | **完整详情 (Full Detail)**

- **发布日期**：2026-11-11（构建号 `3.18.1.10376`，commit `9f7ab4c3`）
- **覆盖平台**：`mac`、`win`、`ubuntu`
- **运行时**：Electron `44.7.0` / Chromium `152.0.7977.130`

## 概述

基于 `3.18.0` 的补丁更新，重点补全 macOS 语音输入麦克风权限重置与分阶段引导弹窗，新增 macOS 桌面字体平滑开关，引入 CLI 运行时有界内存诊断快照及日志导出归档支持，并微调侧栏/会话列布局与移动端历史路由同步。

## 新增功能

- **语音输入：macOS 麦克风权限重置流程**
  - 新增主进程 IPC 通道 `zcode:reset-microphone-access`（`ResetMicrophoneAccess`，预加载层暴露 `resetMicrophoneAccess()`，CLI 协议命令枚举同步注册）。
  - 在打包环境下校验自身 Bundle ID 后调用 `/usr/bin/tccutil reset Microphone <bundleId>` 重置应用的 macOS TCC 麦克风授权，并按当前权限状态自动流转：`granted` 直接生效、`not-determined` 自动拉起系统授权弹窗，其余状态返回 `restart-required` 提示重启生效；全程带单飞（single-flight）并发保护。
- **语音输入：分阶段权限引导弹窗**
  - 聊天输入框语音入口新增权限引导组件（`v4-composer-voice-permission-guide`，支持 `data-voice-permission-phase` 阶段切换），提供「重新授权」（`reauthorize`）、「打开系统隐私设置」（`openPrivacySettings`）与「重启 ZCode」（`relaunch`）三项操作。
  - 新增共享 UI 基元 `PopoverHeader` 与 `PopoverDescription`；多语言词条新增 `voiceInput.permission.*` 共 8 键（中/英/日/韩/俄五语齐全），替代原有的 `voiceInput.error.permissionDenied.{mac,windows}` 静态报错提示。
- **macOS 字体平滑开关**
  - 设置页新增「字体平滑」（`settings.fontSmoothing`，仅 macOS 桌面端显示 `visibility: 'macDesktop'`，默认开启），持久化于 `zcode-macos-font-smoothing`，开启时为根文档切换 `font-smoothing-enabled` 样式类以启用灰度字体平滑，并纳入跨窗口状态广播与设置搜索索引。

## 改进与优化

- **CLI 有界内存诊断与反馈日志归档**
  - 智能体运行时（`glm/zcode.cjs`）在协议资源采样器上新增 `startCliMemoryDiagnostics`：每 15 秒向 `~/.zcode/cli/memory-diagnostics/` 写入 `zcode-cli-memory-v1` 格式快照（记录最近 8 个样本与最多 32 条 V8 `HeapProfiler` 分配栈，仅保留 CLI bundle 内调用帧）。
  - 内置严格配额与脱敏策略：单实例最多 2 份、全局上限 15 份、单文件上限 64 KB、7 天过期清理；单次采样耗时超 25 ms 或堆占用达上限 80% 时自动转入 `budget-exceeded` 停止采样；写入端与桌面读取端分别通过 `sanitizeCliMemoryDiagnostic` / `sanitizeCliMemory` 执行字段白名单校验。
  - v4 协议资源诊断返回字段由 4 项扩展至 8 项，新增 `hydrations`、`historyOpenings`、`binaryCacheEntries`、`binaryCacheBytes` 计数。
  - 桌面端「导出日志」反馈归档新增收集 `.zcode/cli/memory-diagnostics` 目录（`contentPolicy: "cli-memory"`）。
- **界面布局与路由细节**
  - 侧栏面板最大宽度上限由 `65%` 放宽至 `100%`；会话列最小尺寸由百分比 `35%` 改为固定像素下限 `360px`，支持在宽窗口下将对话栏拖得更窄以减少对预览页面的遮挡。
  - Elicitation 来源徽标调整至标题下方展示；消息容器补充 `min-w-0` 防止长内容横向溢出。
  - 手机/网页端视图路由（`zcodeMobilePage`）增强 `replaceState` 与 `popstate` 双向历史同步。

## 问题修复（官方发行说明）

- 修复国内用户通过网站登录失败的问题。
- 修复摘要信息反复刷新的问题。
- 内置浏览器点选网页元素时不再切换到完整视图或弹出面板遮挡内容。
- 修复项目搜索菜单可被误拖动，以及子代理来源说明显示不全或错乱的问题。
- 修复更新时残留旧进程导致更新失败、需重启电脑的问题；更新备份失败时仍可继续安装并提供更准确的失败提示。
