# ZCode Desktop 3.14.0

[English](../../../full/zcode/2026-09-19_3.14.0.md) | 简体中文 · [精简版 (Highlight)](../../zcode/2026-09-19_3.14.0.md) | **完整详情 (Full Detail)**

- **发布日期**：2026-09-19
- **覆盖平台**：`mac`、`win`、`ubuntu`
- **版本摘要**：重要功能大版本（同时为 `zai-org/ZCode` 首个开源源码同步基线），推出基于单段脚本编排多子代理协作的动态工作流（`/workflow`）、办公与编程双模式切换、实时生效的新版自定义快捷键录制、三步身份化新手引导、Start Plan 独立使用、归档任务批量删除及邀请奖励中心。

## 官方更新说明（`zcode.z.ai/changelog`）

### 新功能

- 新增动态工作流，用一段脚本编排多个子代理协作完成复杂任务
- 输入框加号菜单与 /workflow 命令可快速发起工作流
- 新增办公和编程两种模式切换
- 新版快捷键设置，可录制自定义按键并即时生效
- 新增三步新手引导，按身份推荐任务和插件
- 归档任务支持批量删除
- 优化手机远控服务
- 帮助菜单新增关于与检查更新入口
- 审批弹窗支持直接授予完全访问权限
- Start Plan 支持独立使用
- 新增邀请奖励中心
- 优化 CUA 调用方式

### 问题修复

- 修复仓库百科异常上传的问题
- 修复登录时偶发失败的问题
- 修复远程内置浏览器标签页无法关闭的问题
- Windows 上定位文件不再重复打开多个窗口
- 闲时任务运行超限时改用友好提示
- 修复插件更新角标显示不全的问题
- 修复模型选择菜单宽度不适配的问题
- 工具调用异常时正确显示错误，不再残留不完整卡片
- 有后台工作流运行的会话不再从任务列表消失
- 取消或恢复工作流被拒绝时，会说明具体原因
- 修复 Start Plan 权益与余额显示不准确的问题
- 修复升级后界面偶发黑屏的问题
- 修复 Windows 上自定义模型配置加载失败的问题
- 修复切换界面模式后输入框位置跳动的问题
