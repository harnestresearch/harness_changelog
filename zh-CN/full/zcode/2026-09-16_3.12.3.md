# ZCode Desktop 3.12.3

- **发布日期**：2026-09-16
- **覆盖平台**：`mac`、`win`、`ubuntu`
- **版本摘要**：相对 `3.11.2` 的增量更新：优化计划模式与排队消息交互、服务商模板图标/套餐横幅及数据库初始化与升级流程，新增 OpenCode Go 服务商模板与站点映射，并修复 Provider 读取阻塞、登录后密钥强制刷新、流式中断重试、OpenRouter 兼容性及 Linux 自动更新等 11 项问题。

## 官方更新说明（`zcode.z.ai/changelog`）

### 新功能

- 优化计划模式和排队消息交互
- 新增 OpenCode Go 服务商模板与站点映射
- 优化服务商模板名称、图标及套餐横幅展示
- 优化数据库初始化与升级流程

### 问题修复

- 修复 Provider 配置读取阻塞的问题
- 套餐获取失败时增加重新登录入口，修复登录后未触发 Key 强制刷新的问题
- 优化未跟踪文件统计性能
- 修复流式响应中断后的重试问题
- 修复服务商配置读取异常的问题
- 修复 OpenRouter 兼容性问题，优化连接测试
- 修复恢复后的子 Agent 出现在任务列表中的问题
- 修复计划模式菜单说明缺失的问题
- 优化闲时任务的工具使用限制
- 优化会话启动速度
- 修复 Linux 自动更新的问题
