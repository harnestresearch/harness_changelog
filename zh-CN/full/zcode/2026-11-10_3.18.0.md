# ZCode Desktop 3.18.0

[English](../../../full/zcode/2026-11-10_3.18.0.md) | 简体中文 · [精简版 (Highlight)](../../zcode/2026-11-10_3.18.0.md) | **完整详情 (Full Detail)**

- **发布日期**：2026-11-10（构建号 `3.18.0-10300`，基线版本 `3.17.2-9661`）
- **覆盖平台**：`mac`、`win`、`ubuntu`
- **运行时**：Electron `44.7.0` / Chromium `152.0.7977.130` / Node.js `v24.21.0`

## 概述

`3.18.0` 是一次大型功能迭代版本：桌面端上线语音输入、受管 Git Worktree 并行开发、基于 MCP 协议的独立扩展宿主子系统、内置 Design 插件与浏览器可视化点选编辑、消息编辑、分享管理页、归档会话批量永久删除、多语言扩展（新增日/韩/俄语）以及操作系统密钥环凭据存储；智能体运行时新增 12 个多会话控制工具、插件市场主动发现工具、`ReadTopicResource` 工具、子代理 `WebSearch` 预算控制与 `<total_tokens>` 系统提示词注入。

## 新增功能

- **聊天输入框语音输入**
  - 宿主进程新增语音输入服务（`voice-input`），通过 `/api/v1/asr/tickets` 获取鉴权票据并经 WebSocket 实时传输音频流以转写文字（支持 `finish` / `cancel` 控制帧与 `viaProxy` 代理标记）。
  - 覆盖完整的语音异常状态提示（未授权、限流、超时、时长超限、录音过短、无有效语音、设备断开、HTTP 代理不支持等）及各平台麦克风权限与 Linux PulseAudio/PipeWire 设备引导（`voiceInput.*` 26 键）。
- **受管 Worktree 并行任务**
  - 支持从本地/远端分支或当前 `HEAD` 创建受管 Git Worktree 独立副本并行执行任务；支持将任意对话消息直接分叉至新 Worktree（`chat.message.fork.toWorktree`）、携带未提交改动迁移，以及清理/删除 Worktree，侧边栏新增专属 `Worktrees` 视图（`git.managedWorktree.*` 67 键）。
- **扩展（Extensions）子系统**
  - 新增独立扩展宿主进程（`out/extension-host/`）与 `@modelcontextprotocol/server@2.0.0` 依赖，承载基于 MCP 协议（`tools/list`、`tools/call`、`elicitation`、`stdio`）的扩展运行。
  - 支持激活确认、会话分级权限授予（通知 / 只读 / 读写 / 完全访问）、扩展视图、扩展日志查看与热重载，插件商店同步上线扩展分类（`extensions.*` 94 键）。
- **内置 Design 插件（`v0.7.2`）与设计系统检查**
  - 运行时内置插件目录新增第 4 个官方插件 `design`（含 74 个设计骨架、24 份设计系统参考、11 篇工艺指南、8 个子技能及 `design-lint.mjs` 设计系统检查脚本），通过 `SessionStart` 钩子自动为 HTML 设计稿、原型、演示文稿及重设计任务注入引导上下文。
- **内置浏览器增强与可视化设计编辑**
  - 内置浏览器支持点选页面元素（支持 `Shift` 多选）直接查看与修改对齐、颜色、字号、字重、内边距、圆角及不透明度并保存回本地网页（配合 Design 插件，`browser.design.*` 61 键）。
  - 新增设备尺寸预设、页面导出为 PNG 或 PDF、跨重启保留各会话最近访问页面，以及本地网页改动后自动刷新与「单击 HTML 文件时在内置浏览器中打开」（`settings.browser.htmlClickOpensBrowser`）选项。
- **多会话控制工具（12 个）**
  - 智能体运行时面向根会话新增 12 个会话自管理工具：`ListSessions`、`ReadSession`、`CreateSession`、`ForkSession`、`SendToSession`、`WaitSessions`、`InterruptSession`、`RenameSession`，以及桌面端专属的 `ListProjects`、`OpenSession`、`SetSessionArchived`、`SetSessionPinned`。
  - 权限命名空间为 `session_control.<method>`，非只读操作默认需用户授权，单次调用超时 60 秒、输出上限 32 KB；对话界面配套新增 `chat.toolCall.session.*` 42 个工具状态展示词条。
- **插件市场主动发现工具与自动推荐开关**
  - 新增 `SearchPlugins` 与 `SuggestPluginInstall` 工具（主会话可用，子代理禁用），允许智能体检索官方插件市场并弹出安装确认卡片（仅当前工作区启用，严禁通过 `Bash` 等工具绕过确认，且用户跳过后同一会话不再重复推荐）；设置页同步增加「插件自动推荐」开关（`settings.pluginAutoRecommendation`）。
- **`ReadTopicResource` 受管资源工具**
  - 新增 `ReadTopicResource` 工具，支持将当前任务已授权 Topic 历史资源索引（`A1`、`A2` 等）中的文件或图片下载为受管本地文件，严格限定仅可读取当前已获准的 Topic 资源。
- **统一登录入口、`zai_cn` OAuth 提供者与多账号切换**
  - 统一登录授权入口；运行时新增第三个内置 OAuth 提供者 `zai_cn`（`auth.provider` 扩展为 `zai | zai_cn | bigmodel`），新增 `oauth:active_provider` 与 `oauth:linked_bigmodel` 凭据状态键以支持多账号切换。
- **消息编辑与排队消息批量同步**
  - 支持在输入框直接编辑最近发送的上一条用户消息或排队中的消息；切换模型或权限模式时支持一键同步应用至队列中的所有待发消息（`chat.composerEdit.*` 23 键）。
- **会话分享有效期与分享管理页**
  - 创建分享支持设置有效期；新增「分享管理」页面（`ConversationShareService` 新增 `listManagedShares` / `revokeManagedShare` / `restoreManagedShare` / `deleteManagedShare`），集中查看所有已发布分享及剩余有效期、跳转原会话、停止/恢复/删除分享，被撤销的分享在导入时明确拦截提示（`conversationShare.manage.*` 41 键）。
- **归档会话批量永久删除**
  - 归档列表支持按筛选结果批量永久删除、支持中断后续接未完成的删除任务，并自动检测与保留仍被其他会话、分叉或分享引用的附件文件（`archives.*` 扩充至 54 键）。
  - 数据库新增第 26 号迁移 `0025_session_permanent_deletion`，建立 `session_purge` 与 `session_runtime_presence` 表，并通过 SQLite 触发器阻断对删除态会话的任何后续写入。
- **多语言界面扩展**
  - 界面语言在中文、英文基础上新增日语（`ja-JP`）、韩语（`ko-KR`）、俄语（`ru-RU`），并重构语言标签解析与旧版持久化语言偏好迁移逻辑。
- **操作系统密钥环凭据存储与恢复流程**
  - 引入原生模块 `@napi-rs/keyring@2.1.2`，将登录凭据迁移至操作系统级密钥环（Linux 使用 `org.freedesktop.secrets` Secret Service，无桌面环境服务器支持通过 `ZCODE_CREDENTIAL_SECRET` 或 32–4096 字节的 `ZCODE_CREDENTIAL_SECRET_FILE` 回退），并提供密钥环损坏时的「备份并重建凭据」引导流程（`login.credentialStore.*` 8 键）。
- **ZCode Sites 访问统计与实例管理升级**
  - `zcode-site` 插件升级至 `0.5.1`：新增 `/site-analytics` 斜杠命令、`zcode-site analytics` CLI 子命令、服务端 `/api/v1/sites/analytics/pv24h` 与 `/api/v1/sites/{id}/analytics` 接口及面板访问统计视图（PV、访客数、平均停留时长、跳出率）。
  - 站点容器默认规格翻倍（`0.5 vCPU / 512 MB` 提升至 `1 vCPU / 1 GB`，Node `--max-old-space-size` 由 `384` 升至 `768`）；新增 `instance single|multi` 实例模式切换、`prefix` 域名更换、`delete` 永久删站命令及 `delete_site` MCP 工具；拆出统一错误码映射模块 `scripts/errors.mjs`（含新增 3614 前缀审核码与 3610 部署锁续传处理）。

## 智能体运行时与提示词改进

- **系统提示词注入 `<total_tokens>` 预算提醒**：默认在系统提示词 `Context Management` 段后注入动态 `<total_tokens>${n} tokens left</total_tokens>` 段落（默认上限常量 `15,000,000`）。
- **子代理 `WebSearch` 调用预算**：动态工作流 `agent()` 新增静态编译期可判定的 `budget.webSearch` 参数（整数 `0–1024`，默认每次调用最多 `128` 次搜索，超范围报编译诊断码 `9013`）；运行期耗尽预算后向子代理注入终止搜索指令并要求在返回结果中声明。
- **子代理中断后的部分输出恢复**：子代理被提前切断时，运行时通过 `formatSubagentHandback` 将已生成的部分内容附带未完成警示头交付给父代理，避免工作成果丢失。
- **会话读取工具演进**：下线旧版 `ReadSessionContext` 工具及其两阶段内部摘要管线（Extract / Synthesize handoff capsule），统一由新版 `ReadSession` 工具替代。
- **`ListModels` 工具注册范围扩展**：在启用根会话控制模式（`sessionControlKind` 存在）时，即使动态工作流未激活也默认注册 `ListModels` 工具。
- **REPL `js` 工具安全说明收紧**：重写 `node-repl-host` 的 `js` 工具描述，明确警示该环境免沙箱且绕过 `Bash` 危险命令审批，禁止用于常规 Shell、文件读写、包检查与通用数据处理。
- **协议能力与内置模型目录更新**：
  - ZCode Protocol v1 宿主能力协商标志由 7 项扩至 13 项，新增 `highspeedCardOwner`、`pluginDiscoveryUi`、`worktreeCwd`、`extensionInputSource`、`conversationQuoteComment`、`pluginExtensionSummary`。
  - 新增运行时环境变量：`ZCODE_CREDENTIAL_SECRET_FILE`、`ZCODE_SUBAGENT_STALL_NOTIFY_MS`、`ZCODE_PLUGIN_SOURCES_CHANGED`、`ZCODE_PLUGIN_STARTUP_TIMEOUT`、`ZCODE_RUNTIME_MODEL_UNAVAILABLE`、`ZCODE_CLIENT_LANGUAGE`。
  - 内置提供商配置 `config/provider/zcode-builtin.json`（revision `43 → 44`）新增 OpenAI 模板模型 `gpt-6.1-terra`（上下文窗口 `1,050,000`，最大输出 `128,000`，支持图片/PDF/JSON Schema 输出及 `none/low/medium/high/xhigh/max` 推理档位）。

## 界面体验与设置改进

- **连续工具执行分组摘要**：连续工具调用自动按「更改 / 探索 / 运行 / 推理」折叠汇总（`chat.summaryGroup.*` 20 键）。
- **选区引用批注与圈画附图**：选中回复文本引用时可附加批注评论，图片支持圈画标注后直接加入对话（`chat.selections.comment*` 12 键）。
- **阅读与文件交互优化**：流式回复支持逐词渐显；文件卡片与正文路径链接支持在系统文件管理器中定位；图片预览整合「添加到对话 / 复制 / 另存」操作菜单。
- **权限与设置体验**：工具授权弹窗支持直接切换权限模式并记住「完全访问」；设置页新增设置搜索（`settings.search.title`）、手机推送通知总开关（`settings.mobilePush` / `mobilePushEnabled`，默认开启）、项目编辑与每设备记忆开关；使用统计记录不再自动过期清除。
- **远程工作区状态细化**：新增远端设备正在升级服务端时的明确状态提示（`source-server-update-in-progress` / `remote.error.sourceServerUpdateInProgress`）。
- **应用更新与代码签名链校验**：更新支持后台下载（关闭窗口不中断）与手动确认安装；主进程新增 `pkijs@3.4.3`（`CertificateChainValidationEngine`）实现更新包代码签名证书链校验。

## 问题修复与安全加固

- **`android-emulator` 插件（`0.1.0 → 0.1.1`）路径安全加固**：新增 `externalPath()` 同时校验字面路径与 `realpath` 真实路径须位于工作区外部且具备可执行位，移除易被当前目录或工作区 `PATH` 劫持的 `which` / `where` 查找及裸 `cmd.exe` / `java` 调用。
- **`node-repl-host` 升级缓存刷新修复**：新增 `dist/build-identity.json`（记录流水线 `cuaHelperBuildId`），解决客户端升级但插件版本号不变时未重新释放内置服务端脚本的问题。
- **工作流与沙箱安全**：修复工作流脚本可能绕出沙箱的安全漏洞。
- **计费与更新器修复**：额度重置核销前新增二次确认页（`codingPlan.quotaReset.*` 扩至 37 键）；更新器完善代理、自签名证书及退出登录状态下的更新检查支持；修复 Windows 安装失败后残留清理报错问题。
- **界面与会话稳定性修复**：
  - 修复会话前进/后退导航失效、删除或归档任务后关联页面未关闭、异常数据导致对话同步中断的问题。
  - 托盘图标取消常驻红点，角标仅统计本次新增未读消息。
  - 修复时间与日期格式未跟随界面语言、窄窗口下设置控件重叠、默认应用打开文件路径错误、添加图片时预览偶发丢失、内置浏览器无法接收键盘输入的问题。
  - 修复登录验证码偶发加载失败、切换模型后设置偶发卡顿或不生效、模型失效时横幅重复误弹、部分模型内置工具导致回复异常的问题；机器人会话支持富文本与更大附件并在服务恢复后自动续答。
