## 版本概览与对比边界

本条目覆盖 **`0.5.18 → 0.5.20`** 三端桌面版本（macOS `arm64` / Windows `x64` / Linux `amd64`）的静态对比。`0.5.13` 之后的中间桌面版本（`0.5.14`、`0.5.16`–`0.5.18`）尚未入仓，因此本篇**不以 `0.5.13` 作为对比基线**。此外，本对刻意跨过已发布的 **`0.5.19`**：官方 CDN 上存在 `0.5.19` 的 macOS / Windows / Linux 更新清单（其中 macOS zip 为 `352,687,968` B，构建早于 `0.5.20` 约 7 小时，commit `7c8c8d5c…`），但官方 `changelog.qoder.com/app` 从 `0.5.18`（`November 24, 2026`）直接跳至 `0.5.20`（`November 25, 2026`），**无 `0.5.19` 条目**，且 `0.5.19` 未下载未分析。下文所有静态差分均反映 `0.5.18 → 0.5.20` 的净变化，不排除部分改动最先出现在 `0.5.19`。
