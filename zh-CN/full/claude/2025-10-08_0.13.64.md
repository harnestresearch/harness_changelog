## 概述

Electron 37.6.0；字体切换为 AnthropicSans/AnthropicSerif 新品牌字族；引入 JWT 依赖（组织扩展签名验证）；宣布 Claude for Chrome 集成。

## 变更详情

- **依赖**：新增 `jsonwebtoken` ^9.0.2（连同 jwks-rsa、ecdsa-sig-formatter、buffer-equal-constant-time、semver、lodash 等随 asar 分发——JWT 校验用于扩展/组织信任链）
- **组件与原生模块**：品牌字体整体换代：Resources/fonts 与各 renderer assets 中 StyreneBLC/TiemposText/Copernicus 全部移除，替换为可变字体 AnthropicSans-Italics/Romans-Variable-25x258.ttf、AnthropicSerif-Italics/Romans-Variable-25x258.ttf
- **主进程（`app.asar`）**：+154 -59 ~12（renames 0）。index.js +321 行（JWT/组织扩展逻辑）；claude-swift 新增 `quickEntryError` 事件（提交失败可反馈 UI）。
- **用户界面与体验**：en-US.json +8："Install Claude for Chrome"、"Open Chrome Web Store"、"Copy Link"、"Open App Features"、"To use browser tools, install the Claude for Chrome extension, enable Native app integration in the extension settings, and restart browser." —— Claude for Chrome 浏览器扩展联动首次出现
