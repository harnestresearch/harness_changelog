## 概述

覆盖 `mac`、`win`、`ubuntu` 三端的功能演进、企业治理扩面与安全加固版本（合并 `5.11492.0` 与 `5.11492.2` 沙箱热修）：全平台新增 `ConfigTemplateExport` 企业受管配置模板导出窗口，将沙箱联网拆分为独立的 `SandboxNetworkAccess` 工具权限规则类型，新增 `ssh_host_settings` 主机级设置与本地会话大文件分块续读 `readOpenedFileChunk`；`ion-dist` 补齐 Claude for Chrome 逐动作级授权提示、MCP 连接器四类 OAuth 客户端凭据模式、按流量计费网络更新推迟及应用内积分购买流；Windows 端加固 `claude://` 协议 `--` 参数防注入，Linux 端收紧主二进制权限位（`04755` → `0755`）并追平 macOS 的 Artifact CDN 白名单。

## 主进程、桥接协议与工具权限面

- **企业受管配置模板导出（`ConfigTemplateExport`）**
  - 全平台新增 `.vite/build/configTemplateWindow.js` 与完整独立渲染窗口 `.vite/renderer/config_template_window/`（含 HTML/CSS/JS/字体共约 20 个文件），通过 eipc 桥方法 `ConfigTemplateExport_$_exportTemplates(selection)`（`app.asar` 新增 18 处引用）导出企业受管配置模板，并配套支持文档 `support.claude.com/articles/12622667-enterprise-configuration-for-claude-desktop`。
- **`SandboxNetworkAccess` 独立工具权限规则类型**
  - 新增与 `WebFetch` 并列的 `SandboxNetworkAccess` 规则类型（`new Set(["WebFetch", "SandboxNetworkAccess"])`），支持将 `WebFetch` 规则映射或替换为独立的沙箱网络访问权限。
  - Schema 内置工具权限白名单更新为核心集 `{Bash, PowerShell, Read, Write, Edit, MultiEdit, NotebookEdit, Grep, Glob, WebFetch, SandboxNetworkAccess}` 与受限集 `{Skill, Workflow, ClaudeInChromeDomain}`（其中 `ClaudeInChromeDomain` 由数字开关 `"1927384307"` 控制）。
- **SSH 主机级设置与传输诊断扩充**
  - `app.asar` 新增 `ssh_host_settings` 主机级配置，`ion-dist` 同步新增 `"SSH hosts"`、`"Not in your SSH connections"`、`"Sessions on this computer"` 等连接管理界面。
  - 扩充 SSH host-key 校验豁免三态语义（`posture` 配置 `accept-new`、`redial` 严格重拨以触发交互登录、`redial_unverified` 重拨仍未能完成校验）以及 macOS 本地网络隐私提示 `local_network_app_suspected`（`"macOS may keep Claude itself off the local network"` 与 `"built-in ssh (macOS local-network host, remembered)"` 记忆重拨）。
- **本地会话大文件分块续读与 macOS 麦克风设置跳转**
  - `LocalAgentModeSessions` 桥新增 `readOpenedFileChunk(readId)` 方法，支持对大文件按分块续读（此前仅支持 `readOpenedFiles` 一次性整读，同桥保留 `setMcpServers`、`replaceRemoteMcpServers`、`replaceEnabledMcpTools`、`addFolderToSession`、`autoSaveDeliveredFiles`、`syncSkills`）。
  - macOS `ComputerUseTcc` 权限桥在既有 `getState` / `requestAccessibility` / `requestScreenRecording` / `requestMicrophone` / `revokeGrant` / `listInstalledApps` 基础上新增 `openMicrophoneSettings` 快捷打开系统麦克风权限设置入口。
- **多媒体嵌入预览 Provider 与渲染层依赖升级**
  - `app.asar` 新增 Loom（`embed`/`oembed`/`thumbnail`）、Vimeo（`player`/`oembed`）、YouTube 与 `youtube-nocookie`、Google Drive 文件缩略图预览支持，并引入 Artifact Frame 新字体域 `fonts.frame.claudeusercontent.com`。
  - 升级渲染层依赖：`react`（`19.2.4` 与 `19.2.7`）、`happy-dom` `20.9.0`、`mediabunny` `1.27.3`、`jszip` `3.10.1`、`jquery` `4.0.0`（许可证引用）以及 `floating-ui`、`base-ui`、`tailwind-merge` 等组件库。

## 安全加固、打包分发与三端差异

- **Windows `claude://` 协议防注入加固与 MSIX 分发通道**
  - `AppxManifest.xml.in` 中协议调用参数由 `Parameters='"%1"'` 加固为 `Parameters='-- "%1"'`，在 URL 参数前显式插入 `--` 分隔符防止命令行参数注入（本次 Windows 端唯一清单变更）。
  - Windows `x64` MSIX 包（174 个成员，与 `darwin` 共享构建哈希 `b1edc633…`）通过 `claude.ai/api/desktop/win32/x64/msix/latest/redirect`（`307` 跳转至 `downloads.claude.ai/releases/win32/x64/5.11492.2/Claude-b1edc633….msix`）分发。
- **Linux 主程序权限位收紧与 Artifact CDN 白名单追平**
  - Linux `.deb`（99 个成员）中主可执行文件 `/usr/lib/claude-desktop/claude-desktop` 权限由 `04755` 收紧为标准 `0755`（`chrome-sandbox` 保持 `04755` `setuid root`）；GNOME search provider、`TrayIconLinux` 与 MIME 配置保持不变。
  - `5.11492.2-linux` 补齐此前在 `5.1231.2-linux` 中缺失的 `esm.sh`、`cdn.jsdelivr.net`、`cdnjs.cloudflare.com`、`unpkg.com`、`fonts.googleapis.com/gstatic` 等 Artifact 外链 CDN 白名单，与 macOS 构建对齐。
- **原生 MCP、Cowork 沙箱镜像重建与跨平台组件拓扑差异**
  - 全平台重建内置原生组件：`github-mcp-server`（Linux `24.9 MB` / Windows `.exe`）、`office365-mcp`（macOS 含 `libmsalruntime` dylib + `msal-node-runtime.node`、Windows 含 `msalruntime.dll`，**Linux 仅含 JS 代码而无原生 MSAL 运行时**，SSO 登录能力受限）、`@ant/claude-native`、`node-pty`（含 Windows ConPTY 双二进制）以及 macOS 专属 `Claude iOS Sim.app` 与 `resources/quick-actions/`。
  - 重建 SSH 辅助进程（Windows 为 `claude-ssh-askpass/broker/proxy.exe` 三件套，Linux 仅独立 `claude-ssh-askpass` 并将 broker/proxy 并入主二进制）及全平台 Cowork 虚拟机镜像（macOS `smol-bin.{arm64,x64}.img`、Linux `smol-bin.x64.img` `28.3 MB` + `virtiofsd` + `cowork-linux-helper`、Windows `smol-bin.x64.vhdx` + `cowork-svc.exe`）。
  - 同版本 `5.11492.2` `darwin` ↔ `linux` `app.asar` 基线对比显示文件名哈希漂移约 `+542/-566`，真实平台守卫编译差异文件共 `28` 个（macOS `compile-cache/*.jsc` 含 `arm64+x64` 双架构缓存，Linux 仅含 `x64`）。
- **`5.11492.0` → `5.11492.2` 热修差异（Linux APT 视角）**
  - 对比 `5.11492.0`（`2026-11-12`，`183.4 MB`）与 `5.11492.2`（`2026-11-13`，`183.3 MB`），仅 `app.asar`（约 47 个文件）、`claude-desktop` 主二进制与 `smol-bin.x64.img` 发生变化，无新增 UI 字符串批次，属针对沙箱与运行稳定性的定向热修。
