## 概述

紧随 `5.11492.2` 发布的内嵌 Claude Code 引擎功能小版本、内置 Office 技能安全加固、多语种翻译补齐与沙箱/原生件轮换重建更新（相较于 `5.11492.0` → `.2` 的沙箱与稳定性热修，`.2` → `.5` 重心在于引擎存储完整性与企业受管配置，**桌面 UI 层零新增功能**）：主进程内嵌引擎新增本地会话存储键 schema 校验层（`index.chunk-BDY2-Sqh.js`，含新 `jobs-root` 命名空间与 `setSessionArchived` 归档接口）及企业受管设置键 `blockFileToolReadsOutsideWorkingDirectories`；`ion-dist` 补全 `env.CLAUDE_CODE_AUTO_MODE_MODEL` 机器级受管配置文档说明并为 10 个非英语语种补齐约 48 个翻译键；内置 `docx`/`pptx`/`xlsx` 技能校验器落地路径穿越与大文档 diff 资源耗尽防护，并全端轮换 `smol-bin` 沙箱镜像。

## 内嵌引擎、企业受管设置与 Web 端（`ion-dist`）

- **会话存储键型 Schema（`index.chunk-BDY2-Sqh.js`）**
  - 新模块 `index.chunk-BDY2-Sqh.js` 由 `5.11492.2` 的 `739 B` 旧 chunk 扩充至 `21 KB`，为引擎本地存储定义统一 key 校验层，覆盖命名空间：`transcript`、`sessionJournal`、`agentMemory`、`tasks`（`listId` / `taskId` / `highWaterMark` / `.meta` 保留）、`drafts`（`draftKey`）、**`jobs-root`**（新增，pins 文件与 draft 二选一互斥）、恢复副本 recovery copies（`stamp`）、tree file（`relPath`）、`pluginRegistry` / `pluginAssetCache`（`sha256` 摘要）以及 `settings`（`user` / `project` / `local` 三层，其中 `user` 层不带 `projectKey`）。
  - 配套严格校验报错文案，如 `"a transcript key names an agent transcript or the run journal, never both"`、`"must be 8 lowercase hex characters"`。
  - 存量会话 API（`deleteSession`、`tagSession`、`tryAppend`，错误路径 `5.11492.2` 已有）被重写整合进该 schema，并新增 `setSessionArchived` 与归档错误提示（`"Archiving is not supported with sessionStore…"`），为云端↔本机任务同步（配合 `5.11492.2` 已有的 `"A cloud copy of this task was made"`）补齐底层存储键完整性地基。
- **新企业受管设置键 `blockFileToolReadsOutsideWorkingDirectories`**
  - 新增 `blockFileToolReadsOutsideWorkingDirectories`，与既有 `blockWritesOutsideWorkingDirectories` 并存（旧键命名写 `"Writes"` 实则管控读取，新键正名为文件工具读取），作用于 auto-mode 一次性授权提示，进一步扩容企业受管配置面。
- **`ion-dist` 受管设置文档说明更新（`c6f6cf4c2`）**
  - `c6f6cf4c2`（`454 KB` 设置页 bundle，本轮唯一有真实内容变化的 `ion-dist` JS 文件）在 auto-mode 审阅模型说明中新增 `"env.CLAUDE_CODE_AUTO_MODE_MODEL in a computer's machine-wide Claude Code managed settings replaces it there"`（环境变量名本身 `5.11492.2` 已有，此处为管理文档指引补全）。
- **`ion-dist` 非英语多语言翻译追赶**
  - 10 个非英语 locale 各新增约 `48` 个键（`0` 删除），覆盖内置浏览器扩展安装/删除/权限确认及 CRX 内容校验提示（如 `"Claude が審査していない拡張機能…"`、`"ダウンロードした内容がこれと異なるものを要求する場合、拡張機能は追加されません"`），以及购买/订阅同意文案（自动充值、年度订阅、VAT 与 `2026-09-10` 积分过期政策）；英文源串在 `5.11492.2` 已存在于 `app.asar` 中，`ion-dist` `i18n/en-US.json` 逐 key 零变化。

## 内置 Office 技能包（`bundled-skills`）安全加固

- **`docx` / `pptx` / `xlsx` 校验器安全加固（`agentSkillsRef` `1794527255` → `1794592614`）**
  - **Windows 形态根路径与盘符穿越拦截**：新增 `names_another_root()`，使用 `PureWindowsPath` 拒绝带盘符或根锚点的 OOXML part name 与压缩包条目。
  - **OOXML Relationship 层 Zip-Slip 包含检查**：关系目标解析改为 `os.path.normpath` + `is_relative_to(unpacked_dir)` 目录包含校验，越界目标记入 `broken_refs`。
  - **修订比对（Redlining）防资源耗尽**：`redlining.py` 弃用 `subprocess` 调用外部 `git diff`，改用带工作量上限（超限抛出 `_WorkSpent` 异常）的 `SequenceMatcher`，防止超大文档 diff 引发资源耗尽（DoS）；`xlsx` 另有 `recalc.py` 小幅调整。
