# Claude Desktop 1.0.2768

[English](../../../full/claude/2026-01-05_1.0.2768.md) | 简体中文 · [精简版 (Highlight)](../../claude/2026-01-05_1.0.2768.md) | **完整详情 (Full Detail)**

- **发布日期**：2026-01-05
- **覆盖平台**：`mac`、`win`
- **安装包体积**：213 MB
- **Electron 版本**：37.10.3（自 37.10.0 升级）
- **内置组件**：`app.asar, claude-native, claude-swift, node-pty`

## 概述

功能大版本：终端（node-pty）、Claude in Chrome 改名 + 独立 helper、Echo 设备窗口（API key 配对/通知）落地；同时旧内部更新体系文案清除。

## 变更详情

- **依赖**：新增 `@ant/claude-for-chrome-mcp "*"`（Claude in Chrome 的 MCP 服务）；移除 form-data（其 node_modules 19 包 286 文件从 asar 删除，改为打进 bundle）
- **组件与原生模块**：
  - 新增原生模块 **node-pty**（app.asar.unpacked：pty.node 111,896B + spawn-helper 67,104B；JS 库 19 文件同时进 asar）—— 终端/Pty 支持
  - 新增 `Contents/Helpers/chrome-native-host`（Mach-O helper，Chrome native messaging 宿主）与 `Contents/Helpers/disclaimer`（Mach-O helper：macOS 上主进程所有 spawn 的命令都经 `disclaimer [cmd, ...args]` 包装执行，即命令执行"免责声明/确认"守门人）
  - 新增 EchoTray 托盘图标 6 个（EchoTrayActive/Template ×1x/2x/3x）—— Echo 设备托盘资源（app.asar JS 中暂无引用，与 echoWindows 配套逐步启用）
- **主进程（`app.asar`）**：+26 -293 ~14。新增具名 bundle：**echoWindows.js**（Echo 预加载：claude-echo-api-key、echo-onboarding-*、echo-settings-*、通知 dismiss/chat 等 IPC）、**shell-path-worker/shellPathWorker.js**（+window-shared.css）；index.js 2,131,357 → 2,973,264B（+39%，Chrome 扩展机制 Chrome 关键词 4→40、terminal/pty 接入）；4 个 preload bundle 因共享代码合并统一涨到 ~137-150KB
- **Web UI（`ion-dist`）**：无
  - **用户可见**（en-US.json +5 -16）:
  - "Claude for Chrome" 改名为 **"Claude in Chrome"**，并新增安装引导："Install Claude in Chrome Extension"、"To use browser tools, install the Claude in Chrome extension from the Chrome Web Store."（扩展改为从 Web Store 拉取）
  - 删除整组 Claude Nest 内部更新文案（"Claude Nest is getting dusty!"、"Update Script Not Found"、Kandji、"open a Terminal window..."）—— 旧 osprey 内部更新机制随渠道切换退役
- **网络与端点**：新增 `https://preview.claude.ai`、`https://preview.claude.com`（预览环境）；其余为 node-pty/ws 库文档链接
