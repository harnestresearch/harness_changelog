## 概述

2.0 里程碑版本。版本号第二段改为内部 build 号（110，用于发布列车号）；核心新能力是模型目录（catalog.json + 默认模型/effort 设置）与自托管第三方推理（Azure AI Foundry / Microsoft Entra OIDC / 凭据 helper 脚本全家族设置），并新增 iOS 模拟器桥二进制、强化 MCP/文件系统安全；Web 前端同步换用新构建管线并大幅扩文案。Claude Code 云会话等能力在此版尚未出现在设置中（见 2.2553.0）。
