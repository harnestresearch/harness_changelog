## 版本概览

本条目基于 `com.anthropic.claude` 两份 Uptodown 第三方镜像 Play-split XAPK（`1.261123.19` → `1.261124.19`）的只读静态解包、清单、资源、DEX 字符串池（`171,650 → 173,615`，`+23,574 / −21,609`）与 jadx `1.5.6` 反编译对比，未安装或执行 APK。打包层面，XAPK 成员数由 `37` 降至 `30`（语言分包 `28 → 21`），全部 `20` 个原生 `.so` 库逐字节未变，权限（`66`）与组件（`83`）零增删。功能代码层面，本版重点落地 GitHub 深度集成（`connect_github_card` 遥测、Claude GitHub App 安装引导、PR/plan/工具调用审批失败分类与云环境引导）、约 12 条 safeguards 模型级换模型文案、`places_list` Places 面板，以及 usage 分区、默认 tab、含 PHI 排除声明的项目指令编辑、朗读限额与约 20 条登录/错误文案，同时移除 `continue_on_cloud.*`（`8 → 1`）、`ready_made_card.rated` 与 `money.message_box.*`；**网络 API 端点无增删**。
