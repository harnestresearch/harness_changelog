# Claude Desktop 1.0.734

[English](../../../full/claude/2025-11-21_1.0.734.md) | 简体中文 · [精简版 (Highlight)](../../claude/2025-11-21_1.0.734.md) | **完整详情 (Full Detail)**

- **发布日期**：2025-11-21
- **覆盖平台**：`mac`、`win`
- **安装包体积**：209 MB
- **Electron 版本**：37.10.0（自 37.6.0 升级）
- **内置组件**：`app.asar, claude-native, claude-swift`

## 概述

1.0 首版 = 渠道迁移 + 工程大清理：包名改 @ant/* 体系、252 个构建工具包移出分发物、IPC 通道签名轮换，同时预置 Clod 宠物资源包、Claude for Chrome 集成入口与 macOS 13 门槛。功能面变化不大，但发行结构完全换代。

## 变更详情

- **组件与原生模块**：
  - 原生模块包名整体迁移：`node_modules/claude-native` → `node_modules/@ant/claude-native`（claude-native-binding.node，2,383,824B 未变）；`@anthropic-ai/claude-swift` → `@ant/claude-swift`（swift_addon.node 3,660,408 → 3,976,248B，+316KB，有实际更新）
  - 新增 `Claude.app/Contents/Resources/default.clod`（48,796B）：ZIP 内含 `personality.txt`（"You are Clod, a minimalist AI assistant..."）+ `idling_0.png`/`working_0.png` 动画帧，即 "Clod" 桌面小宠物资源包；app.asar 全部 JS 中无任何引用（为后续版本的宠物/吉祥物功能预置）
  - Anthropic Sans/Serif Variable 字体重新切片（25x258 系列替换为新版，Serif Roman 824KB → 504KB，总体变小）
- **主进程（`app.asar`）**：+248 -3735 ~12（renames 11）
  - 最大变化是瘦身：移除 252 个 node_modules 包、3,735 个文件 —— 全部为构建/打包工具链（@electron/get、@electron/rebuild、node-gyp、@electron/notarize、@electron/windows-sign、electron-windows-msix、@electron-forge/maker-msix 等），旧版把 CI 工具链打进了正式包，本版起不再分发；zip 由 216MB 降到 209MB
  - 新增 node_modules 仅 16 个包（214 文件，+248 中其余 23 个为 .vite/renderer 哈希块）：form-data 及其依赖栈（asynckit、combined-stream、delayed-stream、mime-db、dunder-proto、es-object-atoms、es-set-tostringtag、get-intrinsic、get-proto、has-symbols、has-tostringtag、math-intrimitives 等）
  - 具名 bundle 无增删；index.js 2,131,357B（1.84MB→2.13MB，+16%），index.pre.js 669,526 → 588,108B（-12%）；4 个 preload（aboutWindow/findInPage/mainWindow/quickWindow）同步小改
  - preload↔主进程 IPC 命名空间 UUID 轮换：`$eipc_message$_3aebb0c8-...` → `$eipc_message$_fe8e247e-...`（通道签名换新，用于安全加固）
  - index.js 新增主进程字符串："an update to Claude Desktop"（更新提示）、"Menu item for copying the current Claude.ai URL to clipboard"；index.pre.js 新增启动失败兜底对话框 "Claude Desktop failed to Launch"（含写 debug 信息逻辑）
- **Web UI（`ion-dist`）**：无（此版本尚未打包 ion-dist.asar）
  - **用户可见**（en-US.json +7 -4）:
  - 新增 Claude for Chrome 集成文案："Login to Claude for Chrome Extension"、"Login & Enable native app integration"、"Make sure you're authenticated in Claude for Chrome settings."
  - 最低系统要求提升："This feature requires macOS 12.0 or higher" → "macOS 13.0 or higher"
  - 新增 "Copy URL"（复制当前 claude.ai 页面地址的菜单项）
- **网络与端点**：新增 `https://claude.com`（与 claude.ai 并存的正式域名）；其余约 180 条新 URL 全部来自新打包的 node_modules（mime-db、es-shims、Sentry SDK 的 README 徽章链接等），非运行时端点
