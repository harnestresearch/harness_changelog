## 概述

MCP SDK 升到 1.0.1；设置页用 Tailwind + Phosphor 图标重写，主进程 bundle 瘦身拆块。

## 变更详情

- **依赖**：@modelcontextprotocol/sdk 0.6.1 → 1.0.1（MCP 1.0 正式版）；react/react-dom 18.2 → 18.3；spawn-rx 3 → 4；新增 @phosphor-icons/react 2.1.4；移除 @types/react(-dom)（构建期）
- **主进程（`app.asar`）**：+4 -3 ~11（renames 0；新增 MainWindowPage-BB5pLYHU.js、settings main-B-1kRNCG.js 两个哈希资产）。index.js 1,131,479 → 1,017,967 B（-113KB，依赖拆入分块）；window-shared.css 3.6KB → 4.7KB；settings.html 11KB → 32KB（设置页 UI 大改）
- **用户界面与体验**：设置页全面重做（tailwindcss 引入，渲染 html/CSS 大幅扩容）；新文案 "Error modifying User Agent"；内部彩蛋字符串 "No window to skooch" / "No skooch needed"（窗口微移 workaround，修复 macOS 窗口定位问题）
- **网络与端点**：无实质新增（tailwindcss.com 等库主页链接）
