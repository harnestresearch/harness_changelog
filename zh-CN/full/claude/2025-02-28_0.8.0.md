- **发布日期**：2025-02-28
- **覆盖平台**：`mac`、`win`
- **安装包体积**：187 MB

## 概述

国际化版本：react-intl + 16 个语言包入包，所有菜单与设置文案改为词条化；同时升级 Electron 34。

## 变更详情

- **依赖**：新增 @formatjs/intl ^2.10.7、react-intl ^6.7.2
- **组件与原生模块**：Electron 33.3.1 → 34.0.2（79 个二进制成员更新）；Resources 下新增 16 个语言包 JSON：de-DE、en-US、en-XA/XB（伪语言）、es-419、es-ES、fr-FR、hi-IN、id-ID、it-IT、ja-JP、ko-KR、pt-BR、xx-AC/HA/LS（占位）
- **主进程（`app.asar`）**：+4 -4 ~7（renames 0）。index.js 1,038,060 → 1,124,246 B（+86KB，react-intl 运行时）；mainWindow.js +0.3KB
- **用户界面与体验**：应用全面 i18n 化——菜单栏（File/Edit/View/Developer/Window/Help）、MCP 设置（"Are you sure you want to remove the MCP server \"{serverKey}\"?"）、更新提示（"A new version is available. It will be downloaded and installed automatically."）等全部走 react-intl 词条；新增 "Start New Chat"、"Show Main Window"、"Set shortcut"、"Open Documentation" 等菜单文案
- **网络与端点**：新增 formatjs.io 文档链接（库自身）
