## 概述

阶段性重大更新：内置 GitHub MCP server 二进制与 permission-fixer helper；主进程新增本地执行授权窗口（localExecConsent）与 stall-sampler worker；bundle 双 chunk 命名空间化并打入 node-forge/rxjs/winston；端点层面引入 Claude Code/Claude SSH 官方二进制下载、M365/Box/Slack/Bedrock/Google OAuth 等大量企业集成入口；语言目录改名。

## 变更详情

- **依赖**：无（package.json deps 不变）
- **组件与原生模块**：新增原生二进制 `resources/github-mcp/github-mcp-server`（39.7MB，同时存在于 app.asar 与 app.asar.unpacked）；新增 helper `Claude.app/Contents/Helpers/permission-fixer`；iOS Sim helper 的 FBC 框架以 Xcode 2660 重建；Localizable.strings 目录由 de-DE/es-419/es-ES/fr-FR/hi-IN/id-ID/it-IT/ja-JP/ko-KR/pt-BR 改名为 de/es_419/es/fr/hi/id/it/ja/ko/pt_BR 等（10 个语言目录更名，内容不变）。
