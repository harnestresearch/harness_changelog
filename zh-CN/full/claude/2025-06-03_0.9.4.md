- **安装包体积**：207 MB

## 概述

跨一个月的大版本：升级 Electron 36、引入 Swift 原生插件实验与 claude-studio 包（内含 MCP 权限服务器 + React 渲染端 + 随包 TypeScript 全套），zip 体积 +18MB。

## 变更详情

- **依赖**：新增 claude-swift（file:../packages/claude-swift-node）、claude-studio（link:../packages/claude-studio）；devDeps electron 34.0.2 → 36.2.1；新增 resolutions node-abi 3.75.0
- **组件与原生模块**：新增 claude-swift 原生模块：swift_addon.node（93KB，x64/arm64 之外的通用产物）+ libSwiftCode.a + nothing.a 随 zip 分发（app.asar.unpacked）。js/index.js 显示为实验脚手架：helloWorldClaudeSwift/helloWorldClaudeSwiftUI + "magicMade" 事件（Swift/SwiftUI 桥接 PoC）。Electron 直接跳过 35 升到 36.2.1（zip +18MB 主要来自此）
- **主进程（`app.asar`）**：+83 -8 ~10（renames 0）。新增 node_modules/claude-studio/（dist/main、dist/mcp/mcpPermissionServer.js、renderer index.html 等 78 个具名文件 + 5 哈希块）；index.js 1,129,784 → 1,134,201 B
- **用户界面与体验**：无新桌面 UI 文案；claude-studio 的 MCP 权限服务器为后台组件（见下）
- **网络与端点**：新增 http://localhost:3456/requestPermission 与 /makePermissionDecision
