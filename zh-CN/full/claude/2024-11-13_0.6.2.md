# Claude Desktop 0.6.2

[English](../../../full/claude/2024-11-13_0.6.2.md) | 简体中文 · [精简版 (Highlight)](../../claude/2024-11-13_0.6.2.md) | **完整详情 (Full Detail)**

- **发布日期**：2024-11-13
- **覆盖平台**：`mac`、`win`
- **安装包体积**：185 MB

## 概述

MCP SDK 升至 0.4.0 并引入 rxjs；claude-native 增加一整套窗口/无障碍 API，Quick Window 支持多行输入与点击外部关闭。

## 变更详情

- **依赖**：@modelcontextprotocol/sdk ^0.1.0 → ^0.4.0；新增 debug ^4.3.6、rxjs ^7.8.1
- **组件与原生模块**：claude-native 原生模块新增导出：requestAccessibility、getWindowInfo、getActiveWindowHandle、getMonitorInfo、focusWindow——窗口管理/辅助功能 API 首次进入桌面端（computer-use 与 Quick Window 焦点管理的基础）
- **主进程（`app.asar`）**：+5 -3 ~10（renames 0）。新增 node_modules/claude-native/{package.json,tsconfig.json}；`.vite/build/index.js` 837,013 → 849,331 B；mainWindow.js +1.6KB；mainView.js（preload）+0.7KB；bundle 中出现 OTEL_TRACES_SAMPLER 等 OpenTelemetry 字符串（随新依赖带入的遥测基础设施）
- **用户界面与体验**：Quick Window 输入框从单行 input 改为 textarea（支持多行），并支持点击窗口外部关闭（quick-window.html diff：`-webkit-app-region: no-drag` "click outside of the window to close it"）
