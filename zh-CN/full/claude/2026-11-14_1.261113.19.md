## 版本概览

本条目基于 `com.anthropic.claude` 两份 Play-split XAPK（`1.261112.18` → `1.261113.19`）的静态清单、资源、DEX 字符串池与 jadx 反编译对比，未安装或运行 APK。打包层面，`1.261113.19` 将 `minSdkVersion` 从 `29`（Android 10）提升至 `32`（Android 12L），语言 split 由 `27` 个扩至 `30` 个；代码与资源层面（jadx `.java` 输出 `55,431` → `55,804`；去重 DEX 字符串池 `161,929` → `163,593`，`+6,649 / -4,985`；非混淆 `com.anthropic.*` 类文件 `1,707` → `2,130`，`+452 / -29`），本版将语音听写（含离线听写）与朗读拆分为 `com.anthropic.voice.internal` 独立模块（旧 `bell.tts` 仍保留 `TTSPlaybackService`），扩充 Claude Code Remote（CCR）项目设置表单、GitHub SSO 仓库源、后台任务完成通知与 49 类底部导航目的地并下线旧 Threads 视图，同时引入促销转额度迁移提示、语音额度提示及 KYC 状态/内购结果的客户端静态代码。

## 打包、清单与分包（Split）核验

- **最低系统版本与清单不变量**
  - 解码 `AndroidManifest.xml` 确认 `minSdkVersion` 由 `29`（Android 10）升至 **`32`（Android 12L，API 32）**，`targetSdkVersion="37"` 与 `compileSdkVersion="37"` 不变（`com.android.vending.derived.apk.id` `3` → `4`）。
  - 全部 `66` 项 `<uses-permission>`（含 `ACCESS_FINE_LOCATION` 与 `ACCESS_COARSE_LOCATION`）、四大组件集合（`activity`、`service`、`receiver`、`provider`，`MessageSseService` 仅声明顺序移动）及深链 `<intent-filter>` 均无增删。
- **XAPK 总条目数（`37` → `39`）与语言/ABI 分包口径修正**
  - 两份 XAPK 归档**总条目数由 `37` 变为 `39`**：
    - `1.261112.18`（共 `37` 项）：`1` 个 base APK（`com.anthropic.claude.apk`）+ `3` 个 ABI split（`config.arm64_v8a.apk`、`config.armeabi_v7a.apk`、`config.x86_64.apk`）+ `6` 个屏幕密度 split（`mdpi`、`tvdpi`、`hdpi`、`xhdpi`、`xxhdpi`、`xxxhdpi`）+ **`27` 个语言 split**。
    - `1.261113.19`（共 `39` 项）：`1` 个 base APK + `2` 个 ABI split（`config.arm64_v8a.apk`、`config.armeabi_v7a.apk`）+ `6` 个屏幕密度 split + **`30` 个语言 split**（移除 `config.bho.apk`；新增 `config.gu.apk`、`config.nb.apk`、`config.ta.apk`、`config.te.apk`）。
  - **ABI 分包样本边界说明**：`1.261113.19` 这份 Uptodown Play-split XAPK 样本仅含 `arm64_v8a` 与 `armeabi_v7a`（两份 ARM 分包内原生 `.so` 字节一致，仅 split 清单 `versionCode` 更新），未包含 `config.x86_64.apk`。由于 Play App Bundle 分包采集受抓取端设备画像影响，**只能说明该份 Uptodown Play-split XAPK 样本未含 `x86_64`，绝不能据此得出官方停止支持 `x86_64` 的结论**。
  - Base APK 条目数保持 `1,409` → `1,409`（`META-INF/services/` 4 个混淆服务声明文件名轮换 `d1f`/`e1k`/`hjg`/`kt0` → `nt0`/`qdg`/`rve`/`wwj`，字节长度一一对应；`resources.arsc` `831,808` B → `676,624` B，`-155,184` B；DEX 总量保持约 `56.45` MB，`classes3.dex` `-2.88` MB、`classes4.dex` `+3.44` MB 再平衡）。

## 语音听写与朗读（`dictation` / `readaloud`）模块重构

- **旧 `bell.tts` 类清理与残留 `TTSPlaybackService`**
  - `com.anthropic.claude.bell.tts` 由 `13` 个类缩减为 `1` 个：移除了 `AudioDecoderException`、`AudioPlaybackException`、`DecodeAheadGaveUp`、`ReadAloudPieceFailure`、`ReadAloudPieceUnavailable` 及 `a`–`g` 共 12 个旧朗读辅助/异常类，但 **`com.anthropic.claude.bell.tts.TTSPlaybackService` 仍保留在 DEX 与 `AndroidManifest.xml` 中**（与 `BellModeService` 及 `bell.assist.Claude*Service` 并存，并非整个旧 TTS 包全删）。
- **新增 `readaloud`、`dictation` 与 `dictation/offline` 模块**
  - 在 `com.anthropic.voice.internal` 下新增 `readaloud/`（`189` 个反编译文件，含携带状态码与双布尔标记的 `readaloud/api/TextToSpeechUpgradeRejectedException`）、`dictation/`（`116` 个文件）、`dictation/offline/`（`105` 个文件，离线听写）及配套 `com.anthropic.claude.stt.repo`（`VoiceSdkDictationException` 下的 `RecorderBusy`、`EncoderUnavailable`、`LanguageNotFound`、`ServerClosed`、`ConnectionStalled` 等细分异常与 `MicrophoneInputLostException`），`voice.internal.conversation/` 由 `737` 扩至 `767` 个文件。
  - 内嵌第一方语音 SDK 开发者注释字符串显示：工具挂载由 `ConversationHost.tools` 切换至 `CallHooks.tools`（`"A call takes tools from CallHooks.tools or from ConversationOptions.tools, not both."`），新增 `ConversationOptions.attachingLimit`，并新增 `ConversationOptions.newChatPermissionMode`——其内嵌注释明确写道 **`"not open yet: the server does not verify it, and a stated Auto can let a tool run with no approval.
