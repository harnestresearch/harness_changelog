## 概述

扩展系统（CDX）与内置 MCP Node Host 落地的关键版本：.cdx 文件关联、扩展安装 UI、API Key 管理、完整 auto-updater（定时+空闲感知+自动重启）与主进程 Sentry 崩溃上报同时上线；claude-studio 独立包被移除。

## 变更详情

- **依赖**：新增 @anthropic-ai/claude-cli ^1.0.22-dev（Claude Code CLI/SDK）、@anthropic-ai/cdx、@anthropic-ai/cdx-registry（link）、semver ^7.7.2、fs-extra ^11.3.0；@modelcontextprotocol/sdk 1.4.1 → 1.11.3
- **组件与原生模块**：新增 `.vite/build/mcp-runtime/nodeHost.js`（"Claude Desktop MCP Node Host"——用内置 Node 子进程承载 MCP 服务器，对应配置项 isUsingBuiltInNodeForMcp）；Info.plist 注册 .cdx 文件类型（"Claude Desktop Extension"，cdx.icns）。注意：@anthropic-ai/claude-cli 只在 package.json 声明，zip/asar 快照中未找到 cli.js 文件（代码会报 "CLI not found at path"该功能此版被 flag 门控未随包分发）
- **主进程（`app.asar`）**：+10 -569 ~11（renames 0）。移除 claude-studio 全部 562 个 dist/node_modules 文件（studio 逻辑并入主 bundle 或暂缓分发）；index.js 1,154,328 → 1,639,211 B（+485KB，扩展系统 + auto-updater + Sentry 主进程上报 + Claude SDK 启动器并入）；settings.html +195 行（设置页 sticky/滚动条等样式重做）
- **用户界面与体验**：Claude Desktop Extensions（CDX）扩展系统上线：安装/预览/兼容性检查（"Are you sure you want to install MCP servers?" 复用、"Checking compatibility..."、"Button to install an extension from a file"、"Add to Claude"）；API Key 管理（"API Key Updated"、"Change API Key..."）；自动更新 UX
- **网络与端点**：新增 Sentry ingest DSN https://o1158394.ingest.us.sentry.io/4507368973008896（主进程崩溃上报启用）；https://docs.anthropic.com/en/docs/agents-and-tools/mcp；更新 feed 指向 osprey GCS bucket（nest/update_manifest.json）；https://support.anthropic.com、claude.ai、反馈 Google Form
