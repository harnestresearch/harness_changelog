## 概述

claude-studio大规模扩容；桌面端加入硬件加速开关与缓存清理/重置对话框。

## 变更详情

- **依赖**：debug 4.3.6 → 4.4.1；新增 fflate ^0.8.2
- **组件与原生模块**：Electron 36.2.1 → 36.4.0
- **主进程（`app.asar`）**：+526 -31 ~13（renames 1：update-browserslist-db/picocolors 提升）。新增大头是 claude-studio node_modules 开发依赖（eslint、radix-ui/react-slot、class-variance-authority、framer-motion（"A simple and powerful JavaScript animation library"）、react-markdown 等 ~500 文件）+ Anthropic 品牌字体 woff2（AnthropicSans/AnthropicSerif VF）；index.js 1,134,201 → 1,154,328 B；mainView.js -1.8KB（preload 清理）
- **用户界面与体验**：claude-studio UI 文案首次大量出现：任务系统（"Cannot switch tasks while Claude is processing"、"Delete this task and all its messages?"、"Close tab"）、技能学习（"Claude has learned the new skill from your project."、"An error occurred while learning the skill"、"Failed to create skill zip"）、文件上传（"Claude Studio is more fun with files!"、"Failed to load uploads"）、"Board creation feature will be available in a future update."（预告）；桌面端新增 "Disable Hardware Acceleration"、"Clear Cache and Restart"、重置完成对话框
- **网络与端点**：无新增外部端点（大量库主页链接）
