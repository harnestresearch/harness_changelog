# Grok Bot 0.66.0

[English](../../../full/grok-bot/2026-10-01_0.66.0.md) | 简体中文 · [精简版 (Highlight)](../../grok-bot/2026-10-01_0.66.0.md) | **完整详情 (Full Detail)**

- **发布日期**：2026-10-01
- **覆盖平台**：`mac`、`win`、`ubuntu`
- **版本摘要**：agent 访问主体与云沙盒存储统计 API，Box 出站隧道（sand_box_egress_tunnel）默认开启

## 变更要点

- **功能**：agent 访问控制 AddGrokBotAgentAccessPrincipalRequest（按 principal 授权）；云沙盒存储治理：AdminStatSandBoxStoreObjectRequest（按 s3_link 统计，AdminStatSandBoxStoreObjectExpectedKey.Source）、CheckAgentStoreVersionsResponse.Status。
- **协议/主进程**：功能开关 sand_box_egress_tunnel 默认 true（Box 沙盒出站流量走隧道）；权限 scope grok_bot_agent.use；遥测 sand.chip.first_content、sand.desktop.egress_tunnel；常量 ShellOomKill.Kind（shell 被 OOM 击杀分类）、COMMAND_FAILED / COMMAND_KILLED、KMS 密钥字段 kmsKeyId；新键 sand-update-place、public-web、viewer-user、move-required、unsupported-type、last-modified。
- **UI**：marketplace-browse-model（插件市场浏览模型）、team-bot-setup-grid、interaction-scope。
- **底层**：无依赖增删；Electron 不变。


## 代码与协议细节

- `main-app.cjs`：`updateProfilePicture` 新增（0.65 为 0 处）：走 auth 操作纪元 `authOperationEpoch` 防并发，仅 `logged-in` 且 `authId!=null` 时更新头像。
- `main-app.cjs`：查看者身份事实：`createViewerPublisherFacts` → `getMe(new GetMeRequest({}), {timeoutMs})`，返回 `{kind:"known", userId: t.userId>0 ? t.userId : null}`（遥测里带真实 userId，失败降级报告）。
- `main-app.cjs`：更新器"移动到 Applications"流程：`state.type==="move-required"` 时检查 `state.version!==t`（superseded）、`canMove` 与 `bundleLocation`，调用 `bundleLocation.moveToApplications()` 返回 `{status:"requested"}`。
- `main-app.cjs`：遥测 schema 字典扩容（`replica_resync` 加 `bufferOverflowed/epochChanged`、`send_journal_restore`、`transcript_store_parity`、重连 `settleBasis/siteBlockConfidence`、打字回执 `ackMs/commitOffsetMs/clientOnlineAtTimeout` 等——多为既有 schema 增列）。
- `main-core.cjs`：令牌存储错误归类表 `sre={damaged:"parse","unsupported-version":"parse","write-failed":"write"}` 与 `V0/H0` 上报包装（"unsupported-version" 出现次数 6→10）。
- `proto.cjs`：S3 对象元数据消息（`bucket/key/versionId/sizeBytes/lastModifiedMs/etag/serverSideEncryption/kmsKeyId/storageClass...`）与 diff 消息（`conflictedPaths/hunks/files`）——云沙盒存储治理 API 的字段载体。
