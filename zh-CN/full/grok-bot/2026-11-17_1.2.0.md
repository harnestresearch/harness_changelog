## 概述与证据范围

官方更新接口（`https://api2.cursor.sh/updates/api/download/stable/{linux-x64|win32-x64-user|darwin-arm64}/sand`）三端 JSON 均返回 `version: "1.2.0"` 与统一提交哈希 `cf0aa5097b8fdfea8f2ecd33ce9f71a72655ef08`（`package.json` 为 `name: "sand"`、`version: "1.2.0"`）。Linux 侧 `downloads.cursor.com/aptrepo` 的 `dists/stable/main/binary-amd64/Packages` 当前不再列出 `grok-bot`（仅列出 `cursor` 系列），`grok-bot_1.2.0_amd64.deb`（`117,298,800` B）改由 update API 的 `debUrl` 获取。

本文所有结论严格来自已下载的 **Linux `x64` `.deb`** 与 **macOS `arm64` `.dmg`** 双包相对 `1.1.0` 的纯静态解包对比，未运行被测程序；Windows `Setup.exe` 仅完成 API + `HEAD` 元数据核对，`darwin-x64` 与 Linux `AppImage` 未取包分析；静态代码、RPC 描述符、preload 绑定、Statsig 门控开关（gate）与多语言文案的存在**不代表**后端已开放或线上功能已实际可用。`app.asar` 文件总数由 `860` 增至 `868`（原始 `+499 / −491`，其中 `484` 项为渲染层 Vite chunk 哈希重命名；归一化净新增 `15` 项、净移除 `6` 项）：`proto.cjs` `1,730,908 → 1,754,188` B（`+23` KB），`main-core.cjs` `1,214,411 → 1,647,849` B（`+433` KB，`+36%`），`main-app.cjs` `3,770,636 → 3,261,318` B（`−509` KB，`−13.5%`），`preload.cjs` `160,046 → 173,889` B（`+14` KB），`node-agent-coordinator/main.cjs` `1,428,758 → 1,451,909` B（`+23` KB），`local-exec-daemon/main.cjs` `3,472,851 → 3,503,466` B（`+31` KB），`messages-worker.cjs` `121,022 → 121,313` B（`+291` B）。
