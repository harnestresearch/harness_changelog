# Grok Bot 0.46.0

[English](../../../full/grok-bot/2026-09-09_0.46.0.md) | 简体中文 · [精简版 (Highlight)](../../grok-bot/2026-09-09_0.46.0.md) | **完整详情 (Full Detail)**

- **发布日期**：2026-09-09
- **覆盖平台**：`mac`、`win`
- **版本摘要**：大版本：1Password 凭据集成、GitLab/Bitbucket/Azure DevOps 连接器、sand-canvas/sand-media 私有协议与应用自动更新体系（zip 内新增 269 个文件）

## 变更要点

- **功能**：1Password 连接（新主进程文件 `onepassword-connection-service.cjs`：`BeginOnePasswordConnection` / `CompleteOnePasswordConnection` / `DeleteOnePasswordConnection`，凭据请求批准/拒绝 `ApproveOnePasswordCredentialRequest` / `DenyOnePasswordCredentialRequest`、`setOnePasswordAlwaysAllow`）；SCM 连接器扩展 `gitlab` / `bitbucket` / `azure-devops`（此前仅 github/origin/slack）；webhook 通知（配置键 `webhook-url` / `webhook-key` / `webhook-header`，事件 pr-opened/pushed/merged/closed、review-requested/approved/commented、ci-passed/failed、issue-assigned）；Cursor/Grok 账号统一流程（`CompleteUnifyGrokOAuth`、`GetUnificationIntent`、`FinalizeIndividualUnification`）；后台 Composer 桌面租约（`BackgroundComposerDesktopLease` ACQUIRE/RELEASE）；盒 harness 迁移（`EnsureGrokBotBoxHarnessMigrationPass` 及状态/清除 hold 系列）；PR agent（`GetPrAgentContext`）；团队数据导出（`CreateTeamDataExportDownloadUrl`）；云 agent 插件市场（`GrokBotAgentPlugin` / `GrokBotAgentMarketplace`、`GetGrokBotAgentPlugins`）。
- **协议/主进程**：枚举 `MCP_SERVED_BY_GROK`（相对 `MCP_SERVED_BY_CURSOR`）；`voice-realtime` 通道（放行 DIALABLE_ORIGIN 的 https 实时语音连接）；自定义 URL 协议 `sand-canvas`、`sand-media`（registerSchemesAsPrivileged）；认证域名 `https://authenticator.cursor.sh`、`https://prod.authentication.cursor.sh`、`https://downloads.cursor.com`；更新体系键 `update-status` / `update-channel` / `automatic-updates` / `update-computer` / `reset-computer`；网络诊断 `network-debugger` 与 `api-dns` / `api-tls` / `computer-dns` / `computer-tls` 探测键；通知提示音五种（ping-1-open-blip … ping-5-chime-b）；用户表单 `DismissGrokBotUserForm`（DESKTOP/IOS 双端）；云端计算机 Messages 许可（`GrokBotUserComputerMessagesConsent` 系列）。
- **UI**：`plugins-rows`、`provider-credentials` 组件与 `auth-page` / `auth-ui` 认证界面。
- **底层**：移除 `https://api2.cursor.sh`、K8S 属性常量（ATTR_K8S_*）与 `cursor-box-computer` / `cursor-box-shared` 标识；新增 TEAM_POLICY / REGISTRABLE_DOMAIN / ESCALATED 等大量判定常量。


## 代码与协议细节

- `onepassword-connection-service.cjs`：全新文件（0→65550 字节）——1Password 服务账户连接全流程（Begin/Complete/Delete Connection、凭据请求批准/拒绝）。
- `main-app.cjs`：插件市场客户端成形——`GrokBotPluginsWireError`（继承 `SandDomainError`）与插件 listing 映射（displayName/description 摘要）；`recordLocalToolStandingGrant`（0→2 处）——本地工具"always allow"常设授权按 machineId + action(subject) 校验后持久化；企业用量面板收缩——删除 `fetchEnterpriseUsage`（1→0）与 enterpriseTeamIdOf/dailySpendOf 及 `Date.parse("2025-11-20T08:00:00Z")` 月度周期计算（`GetSandTrialClaimStatus` 保留）。
- `main-core.cjs`：诊断增强——`open-cdp-missing` 判定从 main-app 移入 core（monitors reached 统计：`t>0 && r===0` 即 open 但 CDP 缺失）；新错误码 `SAND-E0418 turnBackendUnreachable`（retryable，"Turn never reached the Cursor backend: the transport failed on a Node system error..."）；OTel span symbol 常量（`otel.span`/`otel.root_span`/`otel.suppress_child_spans`）。
- `proto.cjs`：`BeginOnePasswordConnection`（0→4 处）与 1Password 凭据条目（`credential_id/title/category/sites/target_rules`）及凭据生命周期字段（`credential_generation/issued_at_ms/expires_at_ms/renew_by_at_ms/reminder_at_ms`）；`GetUnificationIntent`（enabled + intent{mintTicket, connectionId, expectedGeneration, expirationMode, providerExpiresInSeconds...}）；`BackgroundComposerDesktopLease`；`InstallGrokBotSlackAppResponse`（outcome + slack_team_id + workspaces + needs_manifest_update）。
