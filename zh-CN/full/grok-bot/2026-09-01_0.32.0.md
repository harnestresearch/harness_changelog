# Grok Bot 0.32.0

[English](../../../full/grok-bot/2026-09-01_0.32.0.md) | 简体中文 · [精简版 (Highlight)](../../grok-bot/2026-09-01_0.32.0.md) | **完整详情 (Full Detail)**

- **发布日期**：2026-09-01
- **覆盖平台**：`mac`、`win`
- **版本摘要**：macOS 权限引导小版本：完全磁盘访问、Finder 自动化、Chrome Safe Storage 授权检查

## 变更要点

- **功能**：为消息/Chrome 数据导入铺路的 macOS 授权项——full-disk-access、finder-automation、chrome-safe-storage；cloud-onboarding（云端引导）。
- **协议/主进程**：electron-main 继续拆分出 proto.cjs（协议定义独立 bundle）。
- **UI**：仅图表组件哈希更新。
- **底层**：发布距上版 1.5 小时，无依赖变化；v8-code-cache 键移除（下版以新形态回归）。


## 代码与协议细节

- **proto 独立**：新增 `dist/electron-main/proto.cjs`（3.96MB），全部 aiserver.v1/agent.v1 协议定义从 main-app 迁入；main-app 中出现 proto 反射注册名单 `["AgentSkill","AiService","AnalyticsEvent",…]`（约 200 个类型名）。
- `main-app.cjs`：macOS 授权检查三项落地：`full-disk-access`、`finder-automation`、`chrome-safe-storage`，及错误类 `MacFullDiskAccessPendingError`/`MacFinderAutomationPendingError`/`ChromeSafeStoragePermissionError` 与授权记录键 `sand-chrome-cookie-fda-grant`。
- `main-app.cjs`：新增本地工具权限上限 `LocalToolPermissionCeiling`（getLocalToolPermissionCeiling 等 9 处）；Slack 状态机细化为 `GrokBotSlack{Install,Uninstall,Reinstall,Connect}Outcome` 枚举族。
- `main-app.cjs`：新增 `cloud-onboarding`（云端引导）。
- `main.cjs`（加载器，3 处）：code-cache 条目判定重写为 `d.startsWith(\`\${r}-\`)&&Ke.test(d)`（"isCodeCacheEntry"）——v8 code cache 命名方案随拆分变更。

## 技术变更明细

- **各子系统变更文件分布**：`dist/electron-main`（3 个文件）、`dist/local-exec-daemon`（1 个文件）、`dist/renderer`（1 个文件）、`dist/deps`（1 个文件）、`dist/native`（1 个文件）、`package.json`（1 个文件）、`dist/electron-preload`（1 个文件）、`dist/node-agent-coordinator`（1 个文件）。
- **具名入口与模块文件增删**：`+dist/electron-main/proto.cjs`。
- **新增 IPC 通道、设置键与特性开关**：`chrome-safe-storage`、`cloud-onboarding`、`finder-automation`、`full-disk-access`、`sand-chrome-cookie-fda-grant`、`sand-chrome-cookie-finder-automation-grant`。
- **新增协议路径与 RPC/Proto 标识**：`proto.cjs`。
