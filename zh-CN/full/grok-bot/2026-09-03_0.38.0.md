# Grok Bot 0.38.0

[English](../../../full/grok-bot/2026-09-03_0.38.0.md) | 简体中文 · [精简版 (Highlight)](../../grok-bot/2026-09-03_0.38.0.md) | **完整详情 (Full Detail)**

- **发布日期**：2026-09-03
- **覆盖平台**：`mac`、`win`
- **版本摘要**：引入 agent 持久记忆分片（Memory Shard/Folder）协议

## 变更要点

- **功能**：按 agent 维度的记忆存储——`GrokBotMemoryShard`（agent_id/harness/version）归属 `GrokBotMemoryFolder`，为后续 AgentDefinition 记忆字段铺路。
- **协议/主进程**：`aiserver.v1.ListGrokBotMemoryShards` / `PutGrokBotMemoryShard`。
- **UI**：无显著变化（仅 chunk 重排）。
- **底层**：4 个主进程文件小改；新增 `run-failed` 状态字符串。


## 代码与协议细节

- `main-app.cjs`：认证 profile 拉取重构——删除一次性的 `settleProfileInBackground`（2→0 处），改为带重试策略的 `profileRetry = createRetryPolicy({ name:"cursor-auth-profile-fetch", maxAttempts:5, initialDelayMs:2e3, maxDelayMs:16e3 })`；删除 `SandVoiceCallCredentials` 的 zod 校验 schema（`m.object({clientSecret, expiresAtUnixSeconds, model, websocketUrl}).readonly()`，类本身保留：`DEFAULT_MODEL:"grok-voice-latest"`、`DIALABLE_ORIGIN:"wss://api.x.ai/"`）；设置存储新增 `hasMigratedFromLocalStorage()`（0→2 处）。
- `proto.cjs`：新增 `GrokBotMemoryFolder` 消息——记忆分片文件夹协议，配合 `GrokBotMemoryShard` 按 agent 归档。
- `renderer/prompt-editor`：富文本编辑器 chunk 大规模重建（真修改 1814 处、搬家 2956 处，最大一块约 1.4 万 token 的 TipTap 快捷键/列表输入规则代码重组，并内嵌新的 `sand-*` CSS module 类名映射表）；其余 renderer chunk 均为 import hash 轮换（index-C4A09xYf→BmC1R63Z 等）。

## 技术变更明细

- **各子系统变更文件分布**：`dist/electron-main`（4 个文件）、`dist/electron-preload`（3 个文件）、`dist/deps`（1 个文件）、`dist/native`（1 个文件）、`dist/renderer`（1 个文件）、`dist/local-exec-daemon`（1 个文件）、`package.json`（1 个文件）、`dist/node-agent-coordinator`（1 个文件）。
- **新增 IPC 通道、设置键与特性开关**：`cursor-auth-profile-fetch`、`cursor-profile-unread`、`run-failed`。
- **新增协议路径与 RPC/Proto 标识**：`aiserver.v1.GrokBotMemoryFolder`、`aiserver.v1.GrokBotMemoryShard`、`aiserver.v1.ListGrokBotMemoryShardsRequest`、`aiserver.v1.ListGrokBotMemoryShardsResponse`、`aiserver.v1.PutGrokBotMemoryShardRequest`、`aiserver.v1.PutGrokBotMemoryShardResponse`。
