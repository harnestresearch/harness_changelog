## 概述

`1.0.2`（`sandBuiltAt`：`2026-11-12T19:24:34.222Z`；CDN `Last-Modified`：macOS 北京时间 `2026-11-13 03:34`、Windows `2026-11-13 03:39`）是在 `1.0.1` 基线（`Electron 43.8.4`，`asar` 维持 `842` 个文件）之上的客户端小版本更新。全包 `2,829` 个 Protobuf 消息描述符、`411` 个枚举、`GrokBotService` 全部 `493` 个 RPC 方法及 Statsig 特性开关白名单与 `1.0.1` 100% 一致，主要改动是在桌面端完整接线既有的 `GrokBotXToolAccess` 用户运行时设置。`aptrepo` 软件源池未上架 `1.0.2` 的 `.deb` 包（`HTTP 403`；约 4 小时后发布的 `1.0.3` 将同一份代码同步推至 Linux APT）。

## 核心变更

- **X 工具读取访问模式设置（`getXToolAccess` / `setXToolAccess`）**
  - **Preload 与 Main-Core RPC 边缘层**：在主窗口 preload RPC 边缘新增 `getXToolAccess`（无参）与 `setXToolAccess`（`{ access: "own" | "shared" }`）（`dist/electron-preload/preload.cjs` `149,689 → 149,773` B，`+84` B；`dist/electron-main/main-core.cjs` `1,179,417 → 1,179,502` B，`+85` B）。
  - **Main-App 持久化与 Protobuf 导出**：在 `dist/electron-main/proto.cjs`（`1,589,025 → 1,589,070` B，`+45` B）补齐 `GrokBotXToolAccess`（`UNSPECIFIED = 0`、`OWN = 1`、`SHARED = 2`）模块导出，并在 `dist/electron-main/main-app.cjs`（`3,605,354 → 3,606,029` B，`+675` B）接入 `runtimeSettings.readXToolAccess()` / `writeXToolAccess()`（写后校验服务端回执，未落库时抛出 `"the server did not store X access"`）。
  - **协调器状态变更同步**：在 `dist/node-agent-coordinator/main.cjs`（`1,379,159 → 1,379,189` B，`+30` B）的用户运行时设置变更映射表中注册编号 `8: "xToolAccess"`，确保切换 X 读取访问模式后实时触发会话同步。
  - **设置页 UI 与多语言文案**：在通用设置面板（`chunk-core.js` / `chunk-general-pane.js`）新增 *“Use my X account for reads”* 开关与说明文案（*“Off: Grok Bot reads public X data with its own access, within shared limits. On: reads use your X account.”*，Lingui 词条 ID `UpRouI` / `zzPxEZ`）。
