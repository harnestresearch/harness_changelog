# Grok Bot 0.75.0

[English](../../../full/grok-bot/2026-10-21_0.75.0.md) | 简体中文 · [精简版 (Highlight)](../../grok-bot/2026-10-21_0.75.0.md) | **完整详情 (Full Detail)**

- **发布日期**：2026-10-21
- **覆盖平台**：`mac`、`win`、`ubuntu`
- **版本摘要**：新增 X/Shop/Cloudflare 连接器与 pele 图表引擎，引入记忆导入、管理员 RPC 与登录看门狗

## 变更要点

- **功能**：X（Twitter/Grok）连接器 OAuth 回调（`https://chat.x.com/connectors/oauth_callback`、`https://lite.x.com/i/connectors/oauth_callback`、`https://grok.com/connectors-oauth-exchange-code/`，provider `grok-connectors`，scopes openid/personal_agent）；Shop 连接器（`mcp.shop.com`）；Cloudflare 连接器（`mcp.cloudflare.com`，权限 `d1.read/write`、`dns.read/write`、`zone.read/write`）；记忆导入（`import-memory` 设置键 + `sand.memory_import_action` 遥测）；云端 Agent 部署管理权限（`agent_serve_deployment.delete/manage_access/rotate_credentials/manage_slack`）；pele 图表渲染引擎（依赖 `pele`，`glass_mermaid_renderer` 可选 beautiful-mermaid/pele，门 `sand_enable_pele_diagrams`，遥测 `sand.diagram.rendered`）；托盘头像状态机扩展（dictating/sending/receiving/writing/powering-down/humming 等）与 `presence-return` 窗口聚焦事件。
- **协议/主进程**：新增管理员 RPC：`AdminGetGrokBotAgentStoreContents`、`AdminGetGrokBotAgentTransfers`、`AdminGrokBotEmailInboxMoveAddress`；新增团队审查条目 RPC `AddGrokBotTeamReviewItem`；新增设置键 `missed-login-check`/`missed-login-store`（cursor-auth 登录看门狗）、`mark-state-changed`、`request-permission`、`asset-read`、`any-origin`、`env-debug`、`team-fresh`、`chosen-off`；新增常量 GOOGLE_MEET/MICROSOFT_TEAMS（会议集成）、MY_MACHINE、CURSOR_SUPPORT。
- **UI**：renderer 新增 `chat-widget`、`custom-mcp-form`（自定义 MCP 表单）、`device-action`、`card-dialog`/`card-item`、amex 图标、多张壁纸/灯具插画资源；移除 `vault-card-fields`、`team-bot-access-plan`。
- **底层**：新增依赖 `pele@1.3.0`；dist/native 2 个文件变化；Electron 版本不变。


## 代码与协议细节

- `main-app.cjs`：登录链接恢复——`async reopenLoginLink(){let t=this.loginFlightUrl; if(t==null){let n=this.missingLoginLink(); return n==="idle"&&this.publishedStatusKind==="logged-in"?"signed-in":n} return await this.openExternal(t),"reopened"}` 及 `copyLoginLink`；egress 隧道 attach 代际冲突判定 `jAn(e,t){return e==="released"?"released":e==="occupied"&&t!==void 0?"held-by-another-client":"retry"}`（`held-by-another-client` ×3 为新增）；登录看门狗状态机 `missedLogin={loginManager,metadata,operationEpoch,missedAtMs}`（×20）；本地设备工具 nudge——`nudgeDaemon`/`writeLocalDeviceToolNudge`，配合 main-core 的 `local-computer-use-gate.json/mac-device-tools-gate.json/local-device-tool-nudge.json` 门文件；Google Drive 托管工具改名表 `renamedHostedTools`（hostedHost `drivemcp.googleapis.com`，`search→search_files`、`read_file→read_file_content`）。
- `main-core.cjs`：`egressTunnelCommittedBoxUrls` 持久化读写（get/set + 状态合并，×7）；MIME/扩展名映射表（image/avif…video/quicktime）。
- `onepassword-connection-service.cjs`：1Password 条目跨 vault 移动——`vaultMovePlans`/`moveItem({accountUuid,itemId,currentVaultId,destinationVaultId})`、`"The vaults must differ"`、`"Check the vault again before moving this item."`、个人 vault 唯一性探测（`isPersonal` 且恰有一个）。
- `proto.cjs`：`SendGrokBotUserMessageRequest` 新增字段 `|24 reply_quote`（消息引用回复）；新增 `GrokBotTeamReview*`（MemoryAction WRITE/FORGET、SkillAction ADD/UPDATE/REMOVE、ItemStatus）；邮箱收件箱统计字段 `email/domain/provider/messageCount/inboundCount/outboundCount/unindexedCount`。
