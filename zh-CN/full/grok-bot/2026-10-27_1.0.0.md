# Grok Bot 1.0.0

[English](../../../full/grok-bot/2026-10-27_1.0.0.md) | 简体中文 · [精简版 (Highlight)](../../grok-bot/2026-10-27_1.0.0.md) | **完整详情 (Full Detail)**

- **发布日期**：2026-10-27
- **覆盖平台**：`mac`、`win`
- **版本摘要**：首个 1.0 正式版：基于 0.78.1 稳定基线品牌化发布

## 概述

`1.0.0` 为稳定通道首个 `1.0` 正式版本号构建，代码基线锁定于 `0.78.0` / `0.78.1` 版本阶段（`GrokBotService` 414 个方法，`app.asar` 894 个文件，115 项运行时依赖），聚焦稳定性冻结，未引入额外独有新功能。

## 版本能力范围与分支说明

- **包含能力集**：完整涵盖至 `0.78.1` 积累的跨设备二维码链接、本地执行守护进程（`local-exec-daemon`）、Orbit 电脑操控服务、iMessage 与电话外呼、团队 Bot 凭据保险库（Vault）、JWKS 令牌校验与 ML-DSA 后量子签名、macOS 邮件与 Microsoft Teams 集成，以及 Stripe Link / Shop Pay 支付钱包。
- **后续分支合流说明**：同期在 `0.78.2` 至 `0.79.4` 分支演进的隐私模式、训练数据授权弹窗、电商购物车/试穿/机票、Agent Store 市场、Realtime 语音事件流及 1Password 新版保险库连接器未包含在本冻结版本中，已于后续 [1.0.1](2026-11-11_1.0.1.md) 统一合入。
