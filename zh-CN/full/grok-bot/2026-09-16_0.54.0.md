# Grok Bot 0.54.0

[English](../../../full/grok-bot/2026-09-16_0.54.0.md) | 简体中文 · [精简版 (Highlight)](../../grok-bot/2026-09-16_0.54.0.md) | **完整详情 (Full Detail)**

- **发布日期**：2026-09-16
- **覆盖平台**：`mac`、`win`
- **版本摘要**：机器人可读取邮件附件内容（ReadGrokBotEmailAttachment），新增凭证变更通知

## 变更要点

- **功能**：邮件集成扩展到附件：ReadGrokBotEmailAttachmentRequest/Response 返回附件文本或字节，GrokBotEmailAttachmentText 带 truncated 截断标志。
- **协议/主进程**：新增设置键/事件 `credentials-changed`（凭证变更广播）；proto 新增 ProjectsSettings（enabled 字段）；错误文案 "MCP server ID must be a decimal string."、"The secret was not saved."。
- **UI**：无重大变化。
- **底层**：无依赖增删。


## 代码与协议细节

- `main-app.cjs`：主进程无功能改动。
- `proto.cjs`。
- `renderer/prompt-editor`：TipTap 节点 schema 新增 HTML 属性序列化——`label/status`（`parseHTML: n=>n.getAttribute("data-label"/"data-status")`，`renderHTML` 回写）、`id`（`data-id`），提示词编辑器节点支持携带标签/状态/ID 的富文本属性。

## 技术变更明细

- **各子系统变更文件分布**：`dist/electron-main`（4 个文件）、`dist/local-exec-daemon`（1 个文件）、`dist/renderer`（1 个文件）、`dist/deps`（1 个文件）、`dist/native`（1 个文件）、`package.json`（1 个文件）、`dist/electron-preload`（1 个文件）、`dist/node-agent-coordinator`（1 个文件）。
- **新增渲染层组件与资源模块**：`cynefin-VYW2F7L2`、`stateDiagram-2N3HPSRC`。
- **新增环境变量与常量标识**：`PERMANENT_DELETE`。
- **新增 IPC 通道、设置键与特性开关**：`credentials-changed`。
