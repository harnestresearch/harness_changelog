# Grok Bot 0.34.0

[English](../../../full/grok-bot/2026-09-01_0.34.0.md) | 简体中文 · [精简版 (Highlight)](../../grok-bot/2026-09-01_0.34.0.md) | **完整详情 (Full Detail)**

- **发布日期**：2026-09-01
- **覆盖平台**：`mac`、`win`
- **版本摘要**：新建 agent 体验与模板编辑器 UI 大更新；messages-helper 辅助进程接管 iMessage

## 变更要点

- **功能**：agent 角色选择器（agent-character-picker）、新建 agent 面板与聊天栏（new-agent-pane/new-chat-bar）、云端 agent 提供商（provider-cloud-agents）、远程控制屏幕预览（computer-screen-preview）、模板编辑对话框与可见性控制（template-editor-dialog/bot-template-details-dialog/bot-template-visibility-controls）、数据擦除导航（wipe-navigation）、box-desktop-modal。
- **协议/主进程**：marketplace 模板内部读写（`GetGrokBotMarketplaceListingTemplateInternal`/`UpdateGrokBotMarketplaceListingTemplateInternal`）；新通道 messages-helper（iMessage 辅助进程）、lookup-failed、prompt-unavailable。
- **UI**：macOS 自动化授权提示文案（"The macOS Automation consent prompt did not run"）。
- **底层**：无依赖变化。


## 代码与协议细节

- `main-app.cjs`：Origin PR 状态查询落地：`narrowOriginPrStatus`/`originPrStatusRow`/`originPrLookupFailed` 与错误类 `SandOriginPrStatusRequestError`（message 为 `` `batch-get-pull-request-status-${t}` ``），新增 IPC `getCursorOriginPrStatus({prUrl})`——走 `cursorAccount.getOriginPrStatus`，HTTP 请求带 `"connect-protocol-version":"1"` 头。
- `main-app.cjs`：messages-helper 辅助进程接管 iMessage，macOS 自动化授权失败处理：检测到 "The macOS Automation consent prompt did not run." 时上报 `reportDesktopEdgeFailureClass("messages-helper","messages-grant-prompt","prompt-unavailable")`。
- `proto.cjs`：marketplace 模板内部读写 `Get/UpdateGrokBotMarketplaceListingTemplateInternal`；请求上下文补 `request_context_pod_id`/`request_context_conversation_rewind_epoch`；新增 `superseded_request_id`。

- `renderer/prompt-editor`：小规模真修改（`const Rk="everyone"` 等常量重排）；`renderer/automation-detail-panel`：brand-logos 图标拆出独立 chunk `chunk-brand-logos-Ba-PnuM3.js` 并改为 import。
