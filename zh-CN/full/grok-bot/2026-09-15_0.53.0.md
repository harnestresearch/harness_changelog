# Grok Bot 0.53.0

[English](../../../full/grok-bot/2026-09-15_0.53.0.md) | 简体中文 · [精简版 (Highlight)](../../grok-bot/2026-09-15_0.53.0.md) | **完整详情 (Full Detail)**

- **发布日期**：2026-09-15
- **覆盖平台**：`mac`、`win`、`ubuntu`
- **版本摘要**：Pull Request 聊天房间与细粒度 OAuth scope 体系上线，管理员可枚举邮箱收件箱并同步 1Password 连接

## 变更要点

- **功能**：为 GitHub PR 开设聊天房间（EnsureGrokBotPullRequestChatRequest/SendGrokBotPullRequestChatMessageResponse，含 GrokBotPullRequestChatBlocked 阻止原因如作者未共享）；团队组沙盒部署清单（ListTeamGroupSandSetupManifests/SaveTeamGroupSandSetupManifest/DeleteTeamGroupSandSetupManifest）。
- **协议/主进程**：新增 OAuth scope 常量 `dm.read`/`dm.write`（Slack 私信读写）与 `team.github_identity_mappings.read`（GitHub 身份映射）；AdminListGrokBotEmailInboxesRequest / AdminListGrokBotEmailMessagesResponse（管理端枚举邮件收件箱与邮件）；SyncOnePasswordConnectionsRequest（1Password 连接同步）；ClientLlmGatewayCredential（内含 bearer_token）；EnsureGrokBotBoxHarnessMigrationPassRequest。新增通道/设置键 `app-focus`；房间访问门控常量 OWNER_GATE_OFF/VIEWER_GATE_OFF/ROOM_CLOSED/ROOM_UNAVAILABLE。
- **UI**：无重大界面变化。
- **底层**：无依赖增删；Electron 版本不变。


## 代码与协议细节

- `main-app.cjs`：新增 1Password 焦点同步控制器 `nHt`：`noteWindowFocused` / `noteAuthChanged` / `dispose`，在"已登录 + 服务启用 + 窗口聚焦"时去抖触发 `sync()`，失败走 `reportFailure`；`getListenerConnectUrl` 参数新增 `forceOauth: rpcOptional(rpcBoolean())`（Slack 等监听器连接 URL 可强制 OAuth）。
- `proto.cjs`：新增 `GrokBotPullRequestChatBlockReason` 枚举（`AUTHOR_IS_USER / AUTHOR_IS_APP / AUTHOR_SERVICE_ACCOUNT_NOT_GROK_BOT / BOT_NOT_FOUND / BOT_HARNESS_UNSUPPORTED / BOT_NOT_SHARED / OWNER_GATE_OFF / ROOM_UNAVAILABLE`）；新增 `OnePasswordSyncTrigger`（`MANUAL / APP_FOCUS`），实际调用为 `syncOnePasswordConnections({trigger: o==="app-focus" ? APP_FOCUS : MANUAL})`；PR 聊天消息类型落地。
- `renderer/markdown-math`：新增 unist-util-visit 风格的 AST 遍历器（`function Pi(e,t,n,r){... u(e,void 0,[])()}` 递归 walker）。

## 技术变更明细

- **各子系统变更文件分布**：`dist/electron-main`（6 个文件）、`dist/electron-preload`（2 个文件）、`dist/local-exec-daemon`（1 个文件）、`dist/renderer`（1 个文件）、`dist/deps`（1 个文件）、`dist/native`（1 个文件）、`package.json`（1 个文件）、`dist/node-agent-coordinator`（1 个文件）。

- **新增环境变量与常量标识**：`APP_FOCUS`、`AUTHOR_IS_APP`、`AUTHOR_IS_USER`、`BOT_NOT_FOUND`、`BOT_NOT_SHARED`、`OWNER_GATE_OFF`、`ROOM_CLOSED`、`ROOM_UNAVAILABLE`、`VIEWER_GATE_OFF`。
- **新增 IPC 通道、设置键与特性开关**：`app-focus`。
