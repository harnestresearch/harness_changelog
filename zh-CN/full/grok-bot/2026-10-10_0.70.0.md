# Grok Bot 0.70.0

[English](../../../full/grok-bot/2026-10-10_0.70.0.md) | 简体中文 · [精简版 (Highlight)](../../grok-bot/2026-10-10_0.70.0.md) | **完整详情 (Full Detail)**

- **发布日期**：2026-10-10
- **覆盖平台**：`mac`、`win`
- **版本摘要**：机器人外发邮件治理（抑制名单/限额/发送状态管理 API）+ 团队服务账号界面 + MCP 工具级权限与会话回滚

## 变更要点

- **功能**：邮件发送管理：AdminAddGrokBotEmailSuppression（user_id/address/reason/operator_email）、AdminList/RemoveGrokBotEmailSuppressions、AdminGetGrokBotEmailLimits、AdminGetGrokBotEmailSendingState（抑制名单、限额、发送状态——印证 bot 可代发邮件）。团队服务账号：team-bot-service-accounts 界面族（tiles/dialog/shown），功能开关 grok_bot_service_accounts、service_account_spend_limit_enforcement（服务账号消费限额强制）。MCP 工具级权限：Get/SetGrokBotMcpToolPermissions（按 server 配置工具权限）。会话管理：RollBackGrokBotConversation、StartFreshGrokBotConversation（回滚/重开对话）。
- **协议/主进程**：新连接器域名 assistant.knowify.com、mcp.dealroom.co、mcp.northbeam.io、services.leadconnectorhq.com（GoHighLevel）、www.local-mcp.com；遥测 mcp_tool.attempt（含 payload/HTTP/其他三类失败拆分）、sand.attachment.commit；分片上传状态键 store-preupload、store-fallback、store-full、store-unavailable、missing-put、missing-part、missing-alias、length-mismatch、no-uploader、unsent-commit、adopt-sync；Linux 桌面自动化常量 NATIVE_X11、XDOTOOL、notify-send（computer 工具向 Linux 扩展）；前后台/焦点状态 APP_BACKGROUND、APP_FOREGROUND、CHAT_OPEN、COMPOSER_FOCUS、COMPUTER_OPEN、FILE_OPEN、UPLOAD_START、PRETHAW、IN_FLIGHT；请求头 x-cursor-timezone；设置键 cursor-canvas-find、grok-bot-document、meeting-chat-draft、notify-send、session-expired、invalid-agent-id、unknown-mode、unfetchable-url、sand-dark、sand-light。
- **UI**：auto-review-rule-notice、sand-auto-review-instructions（自动审查规则提示/指令）、provider-local-tool-permission（工具提供方权限）、markdown-table-card、grok-bot-team-custom-mcp、team-bot-setup-dialog-shell、draft-composer-bubble、list-item。
- **底层**：依赖 93→94（+`@anysphere/file-kind-icons`，文件类型图标）。


## 代码与协议细节

- `main-app.cjs`：附件暂存提交可复用：按 `stagedPath` 建映射 `{agentId, sessionId, controller, committed, release}`，重复提交命中时走 `route:"reused", outcome:"store"`；存储满报 `throw new It({code: i8, detail:"the agent's attachment storage is full"})`，box 路由失败降级 `store-unavailable`。
- `main-app.cjs`：MCP 工具级权限 RPC：`setGrokBotMcpToolPermissions({serverId, tools: fromEntries(...map(xne)), reads, ...})`，请求支持 `keepDisabledTools:!0`（保留已禁用工具）。
- `main-app.cjs`：会话管理 RPC：`startFreshConversation: k().args({id: rpcString(), sessionId: rpcOptional(rpcString())})` 与 `rollBackConversation`（重开/回滚对话，可指定 sessionId）。
- `main-app.cjs`：MCP 只读工具判定：`Rlt(e){ let t=e.lookupVerb?.(e.serverHost, e.toolName); if(t!==void 0) return t==="read"; ... return e.declaresReadOnly && ewn.has(n) }`（verb 映射优先，声明只读且主机在白名单才认）。
- `main-app.cjs`：canvas artifact 判定 `artifactType==="canvas" ? ["artifactType","canvasId"] : ["artifactType","storeId","documentId"]`；box agent 媒体路径走独立网关分支（`isBoxAgentMediaPath`）。
- `proto.cjs`：`SetGrokBotMcpToolPermissionsRequest{serverId, disabledTools:[]}`、canvas 消息 `{storeId, canvasId, slug}`、新枚举 `SlackConnectSite{UNSPECIFIED, CURSOR, GROK}`（Slack 连接归属站点拆分）。
