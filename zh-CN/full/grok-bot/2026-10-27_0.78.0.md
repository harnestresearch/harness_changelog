# Grok Bot 0.78.0

[English](../../../full/grok-bot/2026-10-27_0.78.0.md) | 简体中文 · [精简版 (Highlight)](../../grok-bot/2026-10-27_0.78.0.md) | **完整详情 (Full Detail)**

- **发布日期**：2026-10-27
- **覆盖平台**：`mac`、`win`
- **版本摘要**：引入 jose/JWKS 令牌校验与 ML-DSA 后量子签名，工具权限模型扩展到邮件/电话/应用操控

## 变更要点

- **功能**：macOS 邮件设置向导（mac-mail-setup-dialog）与 Microsoft Teams 集成组件；支付钱包枚举扩展 STRIPE_LINK、SHOP_PAY（`GrokBotPaymentWallet`）；新增 @sand/sand-eval-runner（评估运行器）与 tldts（域名/公共后缀解析，用于商务与域名安全校验）。
- **协议/主进程**：工具权限目录新增 `send-mail`、`use-app`、`run-phone-tool`（配 allow-once/deny/always/never 审批）；内嵌 kid=`oauth2-sx-grok-prod` 的 ES256 JWKS 做 JWT 校验（新增 ERR_JWT_EXPIRED/ERR_JWKS_INVALID 等 jose 错误码，服务于 MCP OAuth step-up：`mcp_tool.oauth_scope_step_up`）；新增 `ml-dsa-44/65/87`（FIPS 204 后量子签名）签名/验签支持；遥测 `sand.desktop.gpu_info`、`sand.onboarding.attribution_answered`、`sand.flights` 前置（flightNumber 校验正则）；更新诊断新增 restart-to-update（ShipIt 交接失败）与 rosetta-warning。
- **UI**：mac-app-tile、team-bot-details-pane/line-render、group-chat-connect-waiting、places-stage、window-chrome、scroll-pane；"从哪听说我们"归因问卷（youtube/tiktok/reddit/linkedin/search-engine/app-stores/tv-outdoor-ad/influencer-creator/friend-colleague/ai-assistant）。
- **底层**：新增依赖 `@anysphere/usage-banner`、`@sand/host`、`@sand/sand-eval-runner`、`tldts`。


## 代码与协议细节

- `main-app.cjs`：① 托管 MCP connector 目录 + 别名归一化 `new Map([["ado","azuredevops"],["agentrobinhoodcom","robinhood"],["ahrefskey","ahrefs"],["asanalocal","asana"],["asanaoauth","asana"]...])`，目录含 1inch/1password/21st/2chat/aave/airtable... ；② 内嵌 smol-toml 全套模块（`smol-toml/dist/parse.js/stringify.js/...`，约 394 token）；③ `acceptXaiIdentityLogin`——xAI identity 登录会话（`"xAI identity was returned outside a supported tenant backend"`、xaiIdentitySessionActive，约 209 token）；④ undici 导出面扩展（WebSocket/CloseEvent/ErrorEvent/MessageEvent/request/stream/pipeline/connect）；⑤ zod 风格 JSON 深校验器 `Hae/iJe`（纯新增）。
- `main-core.cjs`：`getMacMailSendEnabled/setMacMailSendEnabled` 设置持久化；`messagesSendEnabled` 从 true→false 时触发清理 `this.#d()`；控制字符/孤立代理项检测 `Pg/Ng`（charCodeAt ≤31、D800-DBFF 孤立高代理）；`spentIds` 本地工具发送去重文件（`"The spent local-tool sends file is unreadable."`）。
- `proto.cjs`：**GrokBotUserComputerRequestFrame/ResponseFrame 帧多路复用协议**（request_id + exec/upload/download/retire_approval/cancel/messages_op/local_tool/discover_ai_tool/put_file_to_url/get_file_from_url 帧；响应含 file_error/messages_result/messages_consent_result/messages_accepted/local_tool_accepted/local_tool_result 等），替换旧的单条 `GrokBotUserComputerMessagesOp`；`SlackInboundInstallMode`（OPEN/LOCKED）；文件元数据字段（sha256/sizeBytes/originalFilename/createdByUserId/createdAtMs）。
- `onepassword-connection-service.cjs`：AbortError 判定助手（`name==="AbortError" || code==="ABORT_ERR"`）。
