# Grok Bot 0.62.0

[English](../../../full/grok-bot/2026-09-28_0.62.0.md) | 简体中文 · [精简版 (Highlight)](../../grok-bot/2026-09-28_0.62.0.md) | **完整详情 (Full Detail)**

- **发布日期**：2026-09-28
- **覆盖平台**：`mac`、`win`
- **版本摘要**：机器人以"头像分身"加入 Google Meet / Zoom 会议，同时引入 dune 可靠性遥测子系统

## 变更要点

- **功能**：本地会议参会能力落地：新增 `dist/electron-main/meetings-main.cjs`，内置 Google Meet（meet.google.com，会议码正则）与 Zoom（zoom.us，9-12 位会议号）两个提供方；通过离屏页 `pitman-avatar/pitman-avatar-output.html` 渲染头像形象，配套事件 sand-meeting-stamp / sand-meeting-wake / sand-meeting-hear / sand-meeting-idle / sand-meeting-camera（听会、闲时唤醒、摄像头就绪）。另有群聊连接等待（group-chat-connect-waiting）与团队 bot 队友介绍页（team-bot-teammate-intro）。
- **协议/主进程**：新依赖 `@anysphere/dune-reliability`（user-agent 即 "dune-reliability"），新增设置键 dune-otlp-export、dune-reliability、dune-render-trace 与属性 dune.app/arch/install_id/platform/session_id/track，本地遥测发件箱文件 outbox.v1.jsonl（临时文件+重试，上限 10 次 / 1MB / 一周过期）。审批结果分支访问器：ConnectScmRequestResponse.Approved、McpAuthRequestResponse.Approved、SwitchModeRequestResponse.Approved、WebFetchRequestResponse.Approved、WebSearchRequestResponse.Approved（approved/rejected/failed 细分）。其余新键：slack-link、install-id、install-url、store-id、spell-check、scroll-gesture；语言识别加入 zh-hans/zh-hant/yue-hans/yue-hant（简繁中文与粤语）。
- **UI**："Add to Dictionary"（拼写检查加词典）；Slack 重装结果文案族（INSUFFICIENT_SCOPES / UNSUPPORTED_HARNESS / SLACK_REJECTED / MANAGER_REAUTH_REQUIRED / RECREATE_REQUIRED / UP_TO_DATE）；"Messages is turned off in the user…"（iMessage 关闭提示）；CloneGrokBotAgentToTeam（克隆 agent 到团队）。
- **底层**：依赖 87→88（+@anysphere/dune-reliability）；asar 587→595 文件（diff 中 344 个"新增文件"多为 renderer chunk 改名）；Electron 版本不变。


## 代码与协议细节

- `main-core.cjs`：新增持久机器标识：`var mT="cursor-machine-id", lte={readSecret,writeSecret,waitForEncryptedStorage}`——优先读钥匙串密钥，等加密存储就绪后二次读取，仍缺失则 `randomUUID()` 写回（WeakMap 记忆化）。这是 install-id 之外的新"耐用"机器 ID 来源。
- `main-app.cjs`：Slack 集成客户端落地：`isSlackLinked()` 调 `GetSlackUserSettingsRequest().hasSlackAuth`、`slackLinkUrl()` 拼 `${dashboardUrlOf(...)}/dashboard?tab=integrations` + `GetSlackInstallUrl`；主进程内置 Connect 浏览器传输栈（`ConnectError`、envelope 分帧 `"protocol error: incomplete envelope"`、`crypto.webcrypto`）。
- `main-app.cjs`：`getAutoReviewInstructions` 读回加了防串号守卫：读取前后校验 `getActiveAccountScope()===t && settingsStore.getWriteGeneration()===r`，并新增 `sameSandAutoReviewInstructions` 比较器——防止 await 期间切换账号/设置后应用旧指令。
- `proto.cjs`：新增枚举 `SlackConnectSource`：UNSPECIFIED/LEGACY_UNKNOWN/GLASS_CHECKLIST/GLASS_SETTINGS/GLASS_AUTOMATIONS/IDE_SETTINGS/IDE_IN_APP_AD/DASHBOARD_INTEGRATIONS/DASHBOARD_OVERVIEW/DASHBOARD_SETUP_*（Slack 连接来源归因）。
- `meetings-main.cjs`：本地会议头像大改：avatar 输出 JSON 增加 `"ink"` 字段（白板笔画 SVG path，`"ink" in e && typeof e.ink=="string" && e.ink.length>0`）、颜色调色板 `[{id:"black",...,"#000"},{id:"brown","#936439"},{id:"red","#FF263C"},{id:"orange","#FF6700"}...]`、`avatarFrameChannel` 帧转发/重放、`lookupAvatar` 头像查找与 `hear()/idle()` 事件桥；权限处理器限定 `"storage-access"` 与 mediaTypes 仅 audio|video。
- `main.cjs`：`process.getBuiltinModule("node:fs")` 兜底（Node 新 API 兼容）。
