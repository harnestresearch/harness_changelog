# Grok Bot 0.27.0

[English](../../../full/grok-bot/2026-08-25_0.27.0.md) | 简体中文 · [精简版 (Highlight)](../../grok-bot/2026-08-25_0.27.0.md) | **完整详情 (Full Detail)**

- **发布日期**：2026-08-25
- **覆盖平台**：`mac`、`win`
- **版本摘要**：模板权限模型细化：可见性与 read/write/share/delete 四级 ACL

## 变更要点

- **功能**：模板可见性控制（`SetGrokBotTemplateVisibility`、GrokBotTemplateVisibility）；box 交接血统追踪（`GrokBotHandoffLineage`）。
- **协议/主进程**：新增权限点路径 grok_bot_template.read/write/share/delete；新通道 hand-off、send-journal、ui-agent-refs、ui-layout、composer-drafts 与 computer-demo 回归。
- **UI**：仅图表组件哈希更新。
- **底层**：无依赖变化；发布时间距上版仅 3 小时，为快速修补版。


## 代码与协议细节

- `chrome-import-worker.cjs`：新增 `chromeUserDataDir`（darwin: `Library/Application Support/Google/Chrome`，linux: `.config/google-chrome`）——Chrome 用户数据目录定位逻辑独立成函数。
- `main.cjs`：Chrome CDP 注入状态机 `boxChromeStateFromInject` 落地（`e>0&&t===0?"open-cdp-missing":…?"open-cdp-ok":"unknown"`），配套错误串 `chrome-closed`/`host-chrome-locked`/`inject-rejected`（0.26.0 中全部 0 处）——经宿主 Chrome 注入实现网页操作的首次出现。
- `main.cjs`：模板可见性 RPC `SetGrokBotTemplateVisibility`与 box 交接血统 `GrokBotHandoffLineage` 新增。
- `main.cjs`（纯删除）：移除 `ListGrindModeComposers` RPC。
- `main.cjs`：新增 statsig 门键 `first_party_models_additional_budget_unlimited` / `per_user_…` / `clear_…`（第一方模型额外额度控制）。
