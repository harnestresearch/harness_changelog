# Grok Bot 1.0.1

[English](../../../full/grok-bot/2026-11-11_1.0.1.md) | 简体中文 · [精简版 (Highlight)](../../grok-bot/2026-11-11_1.0.1.md) | **完整详情 (Full Detail)**

- **发布日期**：2026-11-11
- **覆盖平台**：`mac`、`win`、`ubuntu`
- **版本摘要**：双线合流版本：合入 0.79.x 全部功能线并首次升级 Electron 至 43.8.4，`GrokBotService` 扩展至 493 个方法

## 概述

`1.0.1` 将此前独立推进的 `0.79.x` 功能分支整体并入 `1.0` 正式通道（`GrokBotService` 由 `1.0.0` 的 414 个方法增至 493 个，涵盖 `0.79.4` 既有能力并净增 30 个新方法；仅移除旧 `ListGrokBotTeamsJoinedTeams`），同时完成桌面端历史上首次 Electron 大版本升级（`42.11.16 → 43.8.4`）。

## 核心新增功能（1.0.1 新增）

- **运行时与桌面底座升级**
  - **Electron 升级至 `43.8.4`**（自 `42.11.16` 升级），重编译全部 13 个原生模块（`tree-sitter` 双模块、`sand` 原生模块组、`jpeg-napi`、`cursor-proclist`、`sand-op-launcher`、`sand-webauthn-signer`）。
  - 新增聊天代码语法高亮提供器 `CodeTokenizerProvider`（基于 `tree-sitter`，附 `sand.code_highlight` 追踪）。
  - 新增 Spotlight 式快捷输入面板（含 `spotlight-pending-press`、`blur-grace`、`dismiss-fallback` 焦点过期策略）与窗口几何状态持久化（`normalBounds` / `isMaximized`）。
  - 新增依赖 `country-flag-icons`（语言选择器旗帜图标），`local-exec-daemon` 与 `node-agent-coordinator` 各新增 `entry.cjs` 统一入口，网络诊断新增 QUIC 可达性探测（`cloudflare-quic.com/cdn-cgi/trace`）。
- **语音可达性探测与状态提示音（Status Chimes）**
  - 新增 `api.x.ai/v1/realtime` 实时语音连接可达性探测（`probeVoiceCallReachability`），支持按 `region_refusal`、`tunnel_refused`、`certificate`、`foreign_response`、`connection_reset` 细分阻断原因。
  - 新增 **Status Chimes 状态提示音**设置，在任务发送、结果返回、等待用户决策及执行出错四类事件时播放轻提示音。
  - 语音通话系统提示词扩展 `## This call` 上下文块（注入 `spokenLanguage`、`hasSpeedSetting`、`surface`）。
- **iMessage 群聊与手机号绑定**
  - 新增 iMessage 群聊日志与退群接口：`GetGrokBotMessagingGroupChatLog`（区分 `BOT` / `MEMBER` 作者与 `HOST_LEFT` / `ENDED` / `STILL_IN_CHAT` 状态）与 `LeaveGrokBotMessagingGroup`。
  - 新增手机号验证码绑定流程（`SendGrokBotMessagingPhoneCode` / `ConfirmGrokBotMessagingPhoneCode`）及消息提示卡已读标记（`Get/MarkGrokBotMessagingPromptSeen`）。
- **电商结账流与租车/出行扩展**
  - 在购物车基础上补齐结账控制：`StartGrokBotCartCheckout` 与 `CancelGrokBotCartCheckout`。
  - 新增租车业务渲染卡片（`car_rentals`、`car_rental_locations`、`car_rental_detail`）与航司图标/站点资源（`airline-logos`、`airline-sites`），完善礼品配送时间字段（`gift.arrivesBy` / `deliverBy` / `recipientName`）、优惠码保存（`promo.saved` / `note`）及机票点击预订（`sand.flights.book_on_click`），支持删除试穿照片（`DeleteGrokBotTryOnImage`）。
- **Agent 偏好层、治理与团队评测**
  - 新增多层 Agent 偏好配置（`Get/SetGrokBotAgentPreference`：含 `preference` / `executor_preference` / `layers`）、自动审查开关（`SetGrokBotAgentAutoReview`）、文件与技能私有化（`MakeGrokBotAgentFilePrivate` / `SkillPrivate`）、Slack 工作区分享治理（`UpdateGrokBotAgentSlackSharing`）、用户技能列表（`ListGrokBotUserSkills`）以及自动化立即执行/卡片重跑（`RunGrokBotAgentAutomationNow` / `RerunGrokBotAgentAutomationFromCard`）。
  - 新增管理端双模型并行对比评测工具族（`AdminStart/Stop/Get/List/GetOptionsGrokBotModelComparison`、`AdminSendGrokBotModelComparisonFollowUp`、`ModelComparisonLane`）。
  - 新增团队基础设施沙盒自检（`Start/Get/StopTeamSandSetupTest`）、企业消费限额（`enterprise-spend-limit`）、连接器策略门控（`connector_policy.blocked` / `MCP_ALLOWLIST` / `blocked-connectors-gate`）与自定义连接器图标预签名上传（`PresignXaiConnectorIconUploadInternal`）。
  - 新增 Bonfire 邮箱邀请发送（`SendBonfireInvite`）与历史会议查询（`HasGrokBotAgentPastMeetings`）。

## 合入 1.0 主线的 0.78.2 – 0.79.4 功能集

- **安全与隐私**：用户隐私模式（`SetUserPrivacyMode`）、训练数据授权弹窗、Passkey 登录仪式（`/grok-bot/passkey/` 路由与状态事件）、MCP Loopback OAuth 谷歌登录回调超时修复、1Password 保险库服务账户连接与旧版集成切换开关。
- **日历、会议与消息卡**：服务端日历事件流与会议提示操作（`ActOnGrokBotMeetingPrompt`、`UpdateGrokBotMeetingSettings`）、iMessage 交互审批消息卡（`Get/AnswerGrokBotMessagingCard`）与全文转写搜索（`SearchGrokBotTranscripts`）。
- **电商与 Agent Store**：购物车、虚拟试穿、机票解析、Agent Store 市场与发布治理（`plugin-publish` / `skill-publish`）、QuickBooks MCP 与 Tailscale 连接器支持。
