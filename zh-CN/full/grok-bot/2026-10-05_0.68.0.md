# Grok Bot 0.68.0

[English](../../../full/grok-bot/2026-10-05_0.68.0.md) | 简体中文 · [精简版 (Highlight)](../../grok-bot/2026-10-05_0.68.0.md) | **完整详情 (Full Detail)**

- **发布日期**：2026-10-05
- **覆盖平台**：`mac`、`win`
- **版本摘要**：实时语音通话协议（OpenAI Realtime 风格指令/事件流）+ ElevenLabs 与 Cloudflare/Runway 等 MCP 连接器，统一计费"购买积分"入口

## 变更要点

- **功能**：实时语音会话协议落地：指令 session.update、input_audio_buffer.append、conversation.item.create、conversation.item.truncate、response.create，事件 assistant-delta、response-created、response-ended、speech-started、speech-stopped，以及 caller-speech-started/stopped/interrupted RPC；ElevenLabs 连接器（api.us.elevenlabs.io）。新 MCP 连接器域名：bindings/builds/docs/observability.mcp.cloudflare.com（Cloudflare 四件套）、mcp.runwayml.com（Runway 视频）、mcp.tubealfred.com、connector.get-ryze.ai。Notion 写入工具族 notion-create-pages / notion-duplicate-page / notion-create-database / API-post-page。
- **协议/主进程**：购买积分命令 cursor.unifiedSkuBilling.openBuyCredits + 设置键 open-buy-credits + URL cursor.com/dashboard/spending、cursor.com/dashboard?tab=billing、cursor.com/grok-bot/link/v1/finance；AdminMintGrokBotMeetingAvatarLinksResponse.links 与 AdminGrokBotMeetingAvatarCustomLink（自定义会议头像链接）；GrokBotSecretForwardingControls（密钥转发控制 allowed 字段）；链接预览防护（"Link preview redirect left the hosts…"、"Link preview response exceeded its byte limit."）；新 preload-avatar-source.cjs（离屏 WebContentsView 渲染头像位图，IPC 通道 sand:avatar-source）；connector 请求带 serverIdentifier/requestingAgentId；进程类型集合 crashpad-handler、gpu-process、ppapi-broker 等与遥测 dune.gpu_compositing、键 sand-encode-png、gpu-info-update；通知环境变量 NODE_USE_SYSTEM_CA 类常量回归。Box 路由账号校验（拒绝用他人 token 解析的路由）。
- **UI**：unify-cta-individual / unify-cta-team（个人版/团队版统一订阅升级 CTA）；card-dialog、card-item；文档查看器族 docx-loader、text-viewer、file-markdown.worker、markdown-structure、file-stage；working-daisy 进度动画；"Grok Bot could not open your browser. Try again."；emoji-messages 新增 ha/mr/sw/ta/te 五语。
- **底层**：依赖 90→91（+`@anysphere/browser-smoke`）；asar 607→651；Electron 不变。


## 代码与协议细节

- `main-app.cjs`：远程 MCP 连接器识别成形：可信主机集 `var $tr=new Set(["api.cursor.com","connectors-gateway.grok.com"])`、已知主机映射 `Htr=new Map([["gmailmcp.googleapis.com",{...vp,scopes:["...gmail.readonly","...gmail.compose","...gmail.modify"]}],["drivemcp.googleapis.com",...],["mcp.money.x.com","xmoney"],["mcp.runwayml.com","runway"],...])`，未知名退化为取域名二级标签（`ztr(o[o.length-2])`）；路径正则 `/^\/(?:rest-mcp|gateway\/v1)\/([^/]+)\/mcp\/?$/`。
- `main-app.cjs`：服务端异步推送帧：`static frame({topic,eventId,texts,atMs}){return {type:"async_update.add", event_id, async_update:{topic, payload: texts.map(i=>({message:{type:"text",content:i},timestampMs:o}})}}}` + `static TOPIC` 订阅类（会话内异步插入系统消息）。
- `main-app.cjs`：本地工具权限按机器解析：`resolveSandLocalToolPermission(n.localToolPermission ?? SAND_DEFAULT_LOCAL_TOOL_PERMISSION, e.ceiling)` 逐机器应用上限，`localToolPermissionMachineId` 标记来源，`currentMachineId` 不在列表时回退默认。
- `main-app.cjs`：附件存储错误映射：`case Code.PermissionDenied: return "storage_off"; case ResourceExhausted: "rate_limited"; case NotFound: "not_found"`（ConnectError → 存储状态）；链接预览失败分类 `page-http-5xx/page-timeout/page-network/image-cap/image-timeout`。
- `main-core.cjs`：启动阶段遥测细化：`nativeBootMs()` 用 `app.getAppMetrics().creationTime` 与 `performance.timeOrigin` 差值，阶段清单 `["native_boot","process_start","app_ready_wait","move_check","main_handoff",...,"renderer"]`；工具指引新增 Shopify 规则（"Before any Shopify write, name the store it will change...call graphql_schema first and validate_graphql_codeblocks"）。
- `onepassword-connection-service.cjs`：不可重试错误码集 `Zo=new Set([NotFound, InvalidArgument, PermissionDenied, FailedPrecondition])`。
