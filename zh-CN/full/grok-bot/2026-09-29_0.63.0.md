# Grok Bot 0.63.0

[English](../../../full/grok-bot/2026-09-29_0.63.0.md) | 简体中文 · [精简版 (Highlight)](../../grok-bot/2026-09-29_0.63.0.md) | **完整详情 (Full Detail)**

- **发布日期**：2026-09-29
- **覆盖平台**：`mac`、`win`、`ubuntu`
- **版本摘要**：语音通话 harness 通用化更名，新增 agent 文档库 API 与口语化"排队回执"提示词

## 变更要点

- **功能**：`@anysphere/grok-bot-voice-call-harness` 更名为 `@anysphere/voice-call-harness`（语音通话域从 Grok Bot 专用抽成通用 harness）。消息来源枚举 GrokBotUserMessageInitiator 新增 TEMPLATE_IMPORT / TEMPLATE_SHARE / CARD_ACTION / PLUGIN_SETUP / TEACH_RECORDING（模板导入/分享、卡片动作、插件设置、"教它"录制）。
- **协议/主进程**：新 RPC：ListGrokBotLibraryDocs（agent 文档库）、ReadGrokBotGroupChatDocument（群聊文档，含 assets）、McpRecovery.Outcome（MCP 恢复结果）、CheckHttpMcpStatus（HTTP MCP 健康检查）。新键：dune-telemetry、dune-submit-rows、dune-submit-trace（替代 dune-otlp-export/render-trace）、open-external、server-name-lookup、component-effects；环境变量 NODE_USE_SYSTEM_CA（Node 走系统 CA）。语音通话行为提示词内嵌主进程："The job is under way. Keep talking with a natural question or a suggestion. Do not announce that you started." 与 "This request is waiting behind work already on the call…"（排队时如何口头回应用户）。
- **UI**：agent 能力自述文案 "Files, the web, the browser, mail, chat, and their computer"。
- **底层**：依赖数 88 不变（一增一删）；Electron 不变。


## 代码与协议细节

- `main-core.cjs`：系统证书读取器上线：子进程返回证书列表（`"The system certificate reader returned a non-string list."` / `"...exited"` 错误处理），结果经 `setDefaultCACertificates([...o])` 注入 Electron session——对应环境变量 NODE_USE_SYSTEM_CA 的主进程实现。
- `proto.cjs`：agent.v1 新增请求类型：`query` + `allowedXHandles:[]` + `excludedXHandles:[]`（按 X handle 白/黑名单过滤的搜索请求）。
- `main-app.cjs`：`VoiceCallSessionTools.worded(t,r)` 新增：按配置覆盖语音工具的 `description` 与逐参数 description（`CO(t.name)` 白名单内才生效）——服务端可定制语音通话工具措辞；`callTool` 分发器从 `this.args.tools` 改为构造器注入 `this.tools`（依赖注入重构，逻辑不变：unknown_tool/invalid_input/served 三分支）。
