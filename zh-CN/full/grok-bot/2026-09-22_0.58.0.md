# Grok Bot 0.58.0

[English](../../../full/grok-bot/2026-09-22_0.58.0.md) | 简体中文 · [精简版 (Highlight)](../../grok-bot/2026-09-22_0.58.0.md) | **完整详情 (Full Detail)**

- **发布日期**：2026-09-22
- **覆盖平台**：`mac`、`win`、`ubuntu`
- **版本摘要**：桌面挂载面板（desktop-mount panel）落地：agent 可挂载为 320x176 常驻桌面小组件；bot 模板支持发布/取消发布到组织

## 变更要点

- **功能**：新窗口 preload-desktop-mount-panel.cjs + desktop-mount/panel/panel.html：desktop-mount 通道提供 mount(agentId, name, markSvgDataUrl)/unmount/read/submitPrompt，把 agent 以小卡片挂到桌面直接发提示词；bot 模板发布状态机 PublishGrokBotAgent（PUBLISHED/ALREADY_PUBLISHED/UNPUBLISHED/NOT_PUBLISHED/NOT_SHARED）与分享卡片（team-bot-share-card、bot-template-share-card-frame）；团队 setup 向导重做（team-setup-pills、team-setup-new-secret-dialog、team-bot-carry-over-plugin-selection）。
- **协议/主进程**：语音实时协议字符串 conversation.item.create / response.cancel / async_update.add 与 seeded-nudge 通道（SEEDED_TOOL/OVERHEARD_TOOL：语音通话中注入预设工具调用"轻推"）；grok-connectors OAuth provider（scope grok-plugins:*）；CI 环境探测常量 GITHUB_ACTIONS/GITLAB_CI/GITEA_ACTIONS/BUILDKITE/CIRCLECI/TEAMCITY_VERSION/TF_BUILD/APPVEYOR；新键 desktop-mount、desktop-online-edge、async-update、plugin-logo-cache、xterm-ghostty/xterm-kitty（终端键盘协议）、complete-roster、written-turn、ready-to-show、renderer-booting；审计序列 sand.action-audit.event-sequence。
- **UI**：team-bot-details-dialog、team-bot-files-copy、get-file-icon、index.eager-* 预载 bundle 拆分；emoji-messages.cs 新语言包。
- **底层**：asar 文件数 501→552（新增 370 个文件，主因 eager bundle 拆分与 panel 资源）；无依赖增删。


## 代码与协议细节

- `main-app.cjs`：bot 发布 RPC——`publishGrokBotAgent({agentId})` 的 outcome 映射（`PUBLISHED → {kind:"published"}`、ALREADY_PUBLISHED 等）+ `unpublishGrokBotAgent`；链接预览解码限流——`createTaskBoundaryPolicy({name:"sand-link-preview-decode"})`，最大并发 8、总解码字符预算 8MB；启动时 MCP 遗留凭证清理 `cleanupLegacyMcpAuthCredentials(e.sandRootDir())`（上报 "mcp-auth-cleanup"/"startup-scrub"）+ 新增 `onMcpDiagnostic`（"mcp-manager" leg/errorClass）；凭证审批 RPC 改造——approve/deny 带 `entryId/requestId/resolution/agentId/sessionId`（rpcObject `ybe`）；ICO 图标解码遍历目录帧取最大 `width*height`（`RJ` 捕获 RangeError 容错，用于头像/图标取最高分辨率帧）；Chrome cookie 导入遥测 `reportChromeCookieImport({outcome:"failed", stage, errorClass})`（undecryptable/dbscWarning/skipReason 维度）；删除 renderer 侧 secrets RPC（revealSecret/upsertSecrets/removeSecrets）。
- `main-core.cjs`：启动指标 `app_ready_wait`（hw_accel/os_sandbox/bootLanguage cohort）；进程分类 `utility_coordinator` vs `utility_other`（Electron UtilityProcess NodeService 标识）；更新器 marker 文件 schema `{version:1, pid, appVersion, startedAtMs, aliveAtMs, crashSeen}` + markerPidAlive 判定；新增语言 cs/hu/nb/da。
- `onepassword-connection-service.cjs`：内置完整 SandError 注册表（`"SAND-E0001" unregistered...`）；1Password 服务账户 token 校验文案（"That doesn't look like a 1Password service account token. Paste the whole token, which starts with “ops_”."）；`connectWithToken` 流程上报（phase "callback_received"）；`probeMintReadiness` 探测。
- `proto.cjs`：新增 `ListFinancialConnectionsRequest`（金融账户连接）、`AdminBreakGlassDeleteSandBoxPod`、支付字段（amountCents/currency/merchantName）、仪式字段（creationOptionsJson/ceremonyPath/ceremonyToken，passkey/WebAuthn ceremony）。
