# Grok Bot 0.49.0

[English](../../../full/grok-bot/2026-09-11_0.49.0.md) | 简体中文 · [精简版 (Highlight)](../../grok-bot/2026-09-11_0.49.0.md) | **完整详情 (Full Detail)**

- **发布日期**：2026-09-11
- **覆盖平台**：`mac`、`win`
- **版本摘要**：Canvas 读写成为 agent 工具，团队 agent 管理界面、技能/密钥 CRUD 与 Linear、BigQuery 连接器扩展

## 变更要点

- **功能**：agent 可读写画布（`agent.v1.ReadCanvasToolCall` / `WriteCanvasToolCall` 及诊断 `CloudCanvasToolDiagnostic`）；团队 agent 全面管理（`grokBot.team.listAgents` 通道、`AdminGetGrokBotTeamAgentSharedState`）；agent 技能 CRUD（`AddGrokBotAgentSkill`、`GrokBotAgentPluginSkill`、插件文件 `GetGrokBotAgentPluginFile`）与密钥管理（`DeleteGrokBotSecret`、`DeleteGrokBotMarketplaceListingInternal`）；Linear 集成（`BatchGetLinearIssueSummaries`）；Google 连接器新增 BigQuery / Presentations scope（`https://www.googleapis.com/auth/bigquery`）；用量快照（`GetXaiUserUsageSnapshot`：当前计费周期）；营销身份（`GetSandMarketingIdentity` → xai_user_id）；组织远程控制设置（`GetOrganizationRemoteControlSettings`）；团队成员 SandBox 批量操作（`BulkTeamMemberSandBox*` 系列）；自动审查规则 `GrokBotAutoReviewRules`；组织/团队组 MCP 设置（`GetOrganizationGroupMcpSettings` / `GetTeamGroupMcpSettings`）。
- **协议/主进程**：`agent.v1.SubscriptionRemovedEntry`；设置键 `client-presence` / `digest-framed` / `encoded-key` / `gateway-events-live` / `team-policy-refresh`；新增 AWAITING_PAYMENT / BUDGET_RESERVED / RATE_LIMIT / USAGE_LIMIT / PARTIALLY_SUCCEEDED 等状态枚举。
- **UI**：团队管理界面三件套 `grok-bot-team-context` / `grok-bot-team-plugins` / `grok-bot-team-secrets-section`，`team-bot-context-ingest` / `team-bot-empty-stage-live` / `use-team-bot-access`，`marketplace-search` 市场搜索、`credentials-pane` 凭据面板；新增 "Return to Grok Bot"（nl/id 等多语言返回文案）。
- **底层**：2 个原生模块文件变更；依赖数不变（84）。


## 代码与协议细节

- `main-app.cjs`：agent 技能 CRUD 客户端——`addGrokBotAgentSkill`（agentId + name/description/content/files，0→3 处）与 `updateGrokBotAgentSkill`；MCP 密钥 CRUD 通道 `listGrokBotSecrets({serverId})` / `putGrokBotSecret` / `deleteGrokBotSecret`（各 0→3 处）；Messages 收件人白名单——`listMessagesAllowedRecipients` / `revokeMessagesAllowedRecipient`（standing grants 按 `grantedAtMs` 排序、subject 作用域过滤）；语音通话提示词重写——新增 `" the written chat between you and this caller : \"you\" is what you sent them..."` 常量（end_the_call/send_task/recall_text_messages/stay_silent 工具组保留）；OAuth 回调失败页新增 `returnLabel:"Return to Grok Bot"`；退出 flush——`app.on("will-quit")` 挂接 `sand-client-persistence-requit` 任务边界（deadline 2s）。
- `main-core.cjs`：系统强调色跟随——`resolveSystemAccentColor()`（`system.getAccentColor()` 归一化为 `#RRGGBB`）+ 监听 `accent-color-changed` 与 macOS `AppleColorPreferencesChangedNotification`；路径安全校验 helper（拒绝空/超 4096 字符/含 `\0`/`` ` ``/`\r`、`file:` 前缀转绝对路径、拒绝反斜杠）。
- 另：GitLab / Bitbucket / Azure DevOps 的 OAuth 回调路由本版落地（`gitlab-connect-callback` / `bitbucket-connect-callback` / `azure-devops-connect-callback`，0.46.0 仅引入连接器目录项，实际 OAuth 连接流程至此可用）。
- `onepassword-connection-service.cjs`：启动器错误细分（launcher-unsupported/launcher-untrusted/launcher-security/launcher-runtime，含人话提示 "Grok Bot's secure 1Password launcher rejected this operation..."）与服务账户 403 友好提示（"This 1Password account can't create service accounts. Ask a 1Password administrator to enable service-account creation..."）。
- `proto.cjs`：大规模 proto 重组——agent 市场（publisher/publisher_id/is_deprecated）、followup 体系（followup_id/created_at_ms/source/is_simulated/synchronous/pending_make_pr_requests/pending_open_pr_requests）、团队成员消费报表（team_member_spend/subscription_cycle_start/total_by_role）、团队策略布尔族（data_sharing_discount_eligible/dashboard_analytics_requires_admin/individual_spend_limits_blocked/allow_domain_join）。
