# Grok Bot 0.57.0

[English](../../../full/grok-bot/2026-09-18_0.57.0.md) | 简体中文 · [精简版 (Highlight)](../../grok-bot/2026-09-18_0.57.0.md) | **完整详情 (Full Detail)**

- **发布日期**：2026-09-18
- **覆盖平台**：`mac`、`ubuntu`
- **版本摘要**：大版本：Notion/Slack/GitHub 等连接器域名识别与 notion-fetch 工具进入主进程，云代理任务类型体系（ babysit PR、BugBot 自动修复、多任务并行）与 BackgroundComposer/Dashboard 服务成型

## 变更要点

- **功能**：连接器感知能力：主进程内置 mcp.notion.com / mcp.slack.com / notion.com / notion.so / slack.com / github.com / gitlab.com / dev.azure.com / api.cursor.com 域名归属，新增 notion-fetch 链接标题工具与 link-preview gate-read 门控；云代理任务类型枚举大量新增：BABYSIT_PR_IN_CLOUD（云端看护 PR）、BUGBOT_AUTOFIX、CI_PANEL_INVESTIGATE_FAILURE、MULTITASK、BUILD_IN_PARALLEL、CALL_MCP_TOOL、CLEAN_SLATE 等；技能来源分类 CURSOR_PROJECT/CURSOR_PERSONAL/CLAUDE_SKILL/CLAUDE_PLUGIN（为技能商店铺路）。
- **协议/主进程**：新 RPC 服务 `aiserver.v1.BackgroundComposerService`（GetBackgroundComposerInfo 等）与 `aiserver.v1.DashboardService`；新设置键/通道：cloud-agent、pull-request、turn-tasks、notion-fetch、connector-title、cursor-title、gate-read；客户端平台枚举 CLIENT_OS_ANDROID/IOS/LINUX/MACOS/WINDOWS；新增 174 个常量（多为 agent 任务/工具/审批枚举，重构建放大）。
- **UI**：team-bot-starter-tasks（入门任务组件）；移除 team-bot-slack-flow-dialog 与 grok-bot-team-context（整合进其他组件）。
- **底层**：无依赖增删；Electron 不变。


## 代码与协议细节

- `main-app.cjs`：新增 canvas 存储模块——`Nh="/cursor/stores"`、`Lh="canvases"`、用户路径 `/cursor/stores/user/canvases`、自动化路径 `/cursor/stores/automation/canvases`、容量上限 `KU=100*1024*1024`，store ID 校验 `N5=/^store-<uuid>$/i`（`ZU(e)=N5.test(e)`），失败渲染 "Canvas unavailable"；链接预览缓存升级 v4（`e.cacheVersion===4` + `imageDataUrl/faviconDataUrl` 校验、`settledAt`/metadata 结构）；删除 GitHub IP 白名单错误处理（"GitHub blocked repository access because this organization or repository uses an IP allow list." 及 `cursor.com/docs/integrations/github#ip-allow-list-configuration`）；删除 none/single/double 阈值策略解析函数 `mP`；新增实验曝光 `logGroupChatDiscouragementExperimentExposure()`；Slack 审批字段 `cursorApprovalRequired: {slackTeamId}`（校验标签 "cursor_approval_required"）；主题序列化加入 `brand` 字段。
- `main-core.cjs`：新增 `SAND_USAGE_WARNING_EXPERIMENT_POLICIES` / `sandUsageWarningExperimentAssignmentOf` 访问器（用量警告实验）。
- `proto.cjs`：proto 全面重生成——新服务 `BackgroundComposerService` / `DashboardService`、`MarketplaceAccessPrincipalKind`（USER/TEAM_MEMBER_GROUP/TEAM_ADMIN_GROUP/GROUP）、`TeamMarketplacePluginInstallMode`（OPTIONAL/DEFAULT/REQUIRED）、`ShellCommand`（command/workingDirectory/timeout/simpleCommands/hasInputRedirect/isBackground/skipApproval/closeStdin 等）、`GetTeamAdminSettingsResponse` 字段扩容、agent 定义新增 skills/subagents/hooks/rules/mcpServers/commands/lifecycleState/publishedByUser。
