# Grok Bot 0.26.0

[English](../../../full/grok-bot/2026-08-25_0.26.0.md) | 简体中文 · [精简版 (Highlight)](../../grok-bot/2026-08-25_0.26.0.md) | **完整详情 (Full Detail)**

- **发布日期**：2026-08-25
- **覆盖平台**：`mac`、`win`
- **版本摘要**：asar 体积砍半的打包重构 + 组织/团队管理协议 + PR Code Tour——同日连发的架构与团队化大版本

## 变更要点

- **功能**：组织服务账号管理（`OrganizationServiceAccount`、Add/Remove/GetOrganizationGroupServiceAccounts）；团队信用额度（`CreateTeamCreditGrantInternal`/`ListTeamCreditGrantsInternal`）；AgentStore 回收站（`ListAgentStoreTombstones`、`UndeleteAgentStoreFiles`）；PR Code Tour 生成（`GeneratePrCodeTourForStack`、`GetPrCodeTourStackContext`）；PrivateWorker 云执行（`PrivateWorkerRequestRepo`、`ReleasePrivateWorkerClaim`）；AutoReview 模式重置（ResetTeam/GroupAgentRunModeToAutoReview）；网页链接预览（link-preview）；Slack 连接对象 `GrokBotSlackConnection`。
- **协议/主进程**：内嵌 OpenTelemetry 导出协议（opentelemetry.proto.trace.v1 全套 Span/ResourceSpans/ExportTraceServiceRequest）；新设置键 cookie-allow-items、open-settings；移除一批旧通道（auth-watch-poll、box-config-push、composer-drafts、computer-demo 等，部分后续版本回归）。
- **UI**：代码高亮从 highlight.js 迁移到 Shiki（renderer 新增 80+ 语言名资源 asm/astro/clojure/rust…）。
- **底层**：+@anysphere/otel-proto、@sentry/node 换 @sentry/node-core、-highlight.js；asar 文件数 783→349：dist/deps（better-sqlite3、tree-chunk-napi 等原生/纯 JS 依赖共 511 个文件）全部外置出 asar，改为打包外提供。


## 代码与协议细节

- `chrome-import-worker.cjs`：新增 `listCookieAllowItems` / `listCookieAllowItemsInDir` / `parseCookieAllowIdentityRow`（从 SQLite cookie 行解析 host_key/name/path），并新增消息分支 `kind==="list-cookie-allow-items" ? {kind:"cookie-allow-items", items:…}`——枚举本机 Chrome 可授权 cookie 清单的能力。
- `main.cjs`：组织服务账号管理 RPC 族新增：`Add/RemoveOrganizationGroupServiceAccounts`、`GetOrganizationServiceAccounts`、`GetOrganizationGroupServiceAccountMembers`。
- `main.cjs`：AgentStore 回收站（`ListAgentStoreTombstones`/`UndeleteAgentStoreFiles`）、PR Code Tour（`GeneratePrCodeTourForStack`/`GetPrCodeTourStackContext`）、云执行 worker（`ReleasePrivateWorkerClaim`）、团队信用额度（`CreateTeamCreditGrantInternal`/`ListTeamCreditGrantsInternal`）全部为 0.25.0 中不存在的新 RPC。
- `main.cjs`：新增 `ReadGrokBotAgentAttachmentChunk`（agent 附件分块读取）。
- 打包重构：dist/deps 全部外置出 asar，main.cjs 7.49MB→6.25MB；diff 中的 encoding 表/wasm base64 大块经核对在两版均存在。
