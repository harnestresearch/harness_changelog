# Grok Bot 0.28.0

[English](../../../full/grok-bot/2026-08-26_0.28.0.md) | 简体中文 · [精简版 (Highlight)](../../grok-bot/2026-08-26_0.28.0.md) | **完整详情 (Full Detail)**

- **发布日期**：2026-08-26
- **覆盖平台**：`mac`、`win`
- **版本摘要**：Slack 应用安装/卸载全流程 + Jira 集成 + 隐私模式——通讯类连接器正式成体系

## 变更要点

- **功能**：Slack App 生命周期管理（`InstallGrokBotSlackApp`/`UninstallGrokBotSlackApp`/`StartGrokBotSlackConnect`/`GetGrokBotSlackInstallState`、GrokBotSlackWorkspace、bot-token、slack-draft、email-draft 草稿通道）；Jira 集成（`JiraInstallation`、`ListJiraInstallations`）；隐私模式（privacy-mode / `aiserver.v1.PrivacyMode`）；Agent 可见性（`SetGrokBotAgentVisibility`）；Origin agent 审批（`ResolveOriginAgentApproval`）。
- **协议/主进程**：客户端在线状态上报 `ReportGrokBotClientPresence`；本地工具权限上报 `UpdateSandMachineLocalToolPermission`；ClientOS 枚举（含 WINDOWS/LINUX/IOS）；深度链接路由校验（scheme/route path 白名单、maxUrlLength）；新键 agent-probe、seen-probe、local-cli-mode、waiting-for-browser；状态常量 SLACK_REJECTED/WORKSPACE_REQUIRED/INSUFFICIENT_SCOPES/RATELIMITED 等。
- **UI**：linear 面板、emoji 翻译资源（emoji-messages.tr）、messages/brand-logos 更新。
- **底层**：新增 sand.build、sand.render_trace.summary 标识。


## 代码与协议细节

- `main.cjs`：Slack App 生命周期 RPC 全套新增：`InstallGrokBotSlackApp`、`UninstallGrokBotSlackApp`、`StartGrokBotSlackConnect`、`GetGrokBotSlackInstallState`，及 `GrokBotSlackWireError` 与安装状态串 `install_conflict`/`insufficient_scopes`/`logged_out`。
- `main.cjs`：新增 `SetGrokBotAgentVisibility`、`ReportGrokBotClientPresence`、`UpdateSandMachineLocalToolPermission`、`ResolveOriginAgentApproval`。
- `main.cjs`：Jira 集成扩容（`JiraInstallation` 6→14 处，`ListJiraInstallations` 等成形）。
- `main.cjs`：新增 `SubagentModelOverride`（子 agent 模型覆盖）、`CookieOriginGrantStore`（cookie 来源授权存储）。
- `main.cjs`：zod 校验器错误文案表更新（"Array must contain…" / "String must contain…"），属依赖版本升级。
