# Grok Bot 0.56.0

[English](../../../full/grok-bot/2026-09-17_0.56.0.md) | 简体中文 · [精简版 (Highlight)](../../grok-bot/2026-09-17_0.56.0.md) | **完整详情 (Full Detail)**

- **发布日期**：2026-09-17
- **覆盖平台**：`mac`、`win`
- **版本摘要**：GitHub 连接流程与连接器 OAuth 交换上线（grok.com/connectors-oauth-exchange-code），主进程支持代理环境变量

## 变更要点

- **功能**：SCM 连接：prepareGithubConnectFlow / CompleteGithubConnectFlow（结果含 CONNECTED / PENDING_APPROVAL / NEEDS_CONFIRMATION）、GetGithubRepoAccessStatus、ScmConnectIntentTarget.User；连接器 OAuth 代码交换走云端。团队策略（provider-team-policy、The team policy has not been read.）与邮箱收件箱设置区（email-section、provider-grok-bot-email-inbox）、队友介绍（team-bot-teammate-intro）进入设置页。
- **协议/主进程**：新增 URL `https://grok.com/connectors-oauth-exchange-code/`、`https://www.cursor.com/agents/mcp/oauth/callback`，并建立 gb/gw/gd 前缀到回调的映射（含 grokbot://mcp/oauth/callback 深链）；主进程新增代理支持 HTTP_PROXY/HTTPS_PROXY/ALL_PROXY/NO_PROXY；新增设置键 box-unreachable、carry-over（用户密钥/插件随 bot 迁移）、invalid-name/invalid-value/reserved-name/reserved-prefix/reserved-sandbox（bot 密钥命名校验）。
- **UI**：设置页新增邮箱区、团队策略区、团队 agent 行（team-agent-rows）；多语言新增"配置团队机器人"等文案。
- **底层**：asar 文件数 515→506；无依赖增删。


## 代码与协议细节

- `main-app.cjs`：新增 SCM 连接 RPC `prepareCursorScmConnect({provider, forceOauth})` / `completeCursorScmConnect(state, code)` / `getCursorGithubRepoAccess(repoSlug)`；新增用户密钥迁移 `carryUserSecretsToGrokBot({serverId, names})`——经 `userSecrets.reveal` 取值写入 `grokBot.secrets.put` / `boxSecrets`，团队场景先枚举 `personalSecretNames`（失败上报 "user-secrets"/"carry-over"）；删除 userFormVault RPC（getUserFormPrefill / listUserFormVaultEntries / updateUserFormVaultEntry）与两个 auto-review 管理门控（`sand_auto_review_admin_enforce` / `sand_auto_review_admin_rules`）；agent 列表合并 Slack 连接映射（`new Map(i.slackConnections.map(c=>[c.agentId, c]))`）；新增 `logComposerTriggerExperimentExposure({trigger})`；进程检测改读 `` `/proc/${pid}/comm` ``（attemptSync）。
- `main-core.cjs`：进程名检测跨平台化——win32 走 PowerShell `(Get-CimInstance Win32_Process -Filter 'ProcessId=...').Name`，其余平台 `ps -p <pid> -o comm=`；新增前缀截断常量 `l6=15`。
- `proto.cjs`：`PrepareGithubConnectFlowRequest`（githubRepo / source / verifierHash / forceOauth / completionBinding）与 `ScmConnectIntentSource` 枚举（`PORTAL / GLASS_CLOUD_AGENT / GLASS_DIFF / GLASS_AUTOMATIONS`）。
- `renderer/prompt-editor`：slash 命令与 @ 提及触发实验开关（`hr = {slash: Ne.isExperimentStarted, at: Ae.isExperimentStarted}`）。
