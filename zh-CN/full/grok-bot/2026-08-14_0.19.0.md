## 发布说明 / 分析发现

- Grok Bot 桌面客户端（内部包名 `sand`，bundle id `co.anysphere.sand`）在 2026 年 8 月以极快的预览节奏发版：0.16.0 至 0.23.0 于 2026-08-11 至 2026-08-20 间发布，紧接其后的是 0.24.0（2026-08-21）——它是 stable CDN 逆向归档捕获的第一个构建，也是该归档的基线。在所有已核查的公开渠道中（见"数据来源与限制"），均未找到这批预览构建的逐版本发布说明。
- 分发方案：桌面安装包由 `downloads.cursor.com` 提供（更新器 feed 基址 `https://api2.cursor.sh/updates`，更新路径模式 `/api/update/<os>/<arch>/<version>/stable`；CDN 包路径形如 `grokbot/stable/<platform>/<version>/Grok_Bot_<version>.dmg`，当前渠道为 `sand/stable/darwin-arm64/<version>/Grok_Bot_<version>.dmg`，与 Homebrew cask `grok-bot` 所跟踪的地址一致）。
- 最近的可用参照：0.24.0 基线（stable 归档首个构建，2026-08-21）已包含完整 agent 运行时套件（`@anysphere/agent` / `agent-core` / `agent-exec` / `agent-kv` / `agent-store-sync` / `agent-summarization` / `agent-transcript`）、chat inference、本地与 MCP 执行（`local-exec` / `shell-exec` / `mcp-agent-exec` / `mcp-core`）、box 沙箱、虚拟文件系统、完整 Google Workspace OAuth scope 套件、Slack，以及 MCP server 目录（memory/notion/playwright/salesforce/stripe/telegram/todoist/zoominfo 等），并已具备 connector、marketplace、computer-use、secret-store 域的早期雏形。这些功能域在 0.24.0 中即已存在，因此 0.16.0-0.23.0 窗口大概率承载同一应用的更早形态；但基于现有来源无法把任何具体变更单独归因到本版本。

## 数据来源与限制

- 逆向交叉参考（安装包归档，仅作旁证）：stable CDN 归档自 0.24.0（2026-08-21）开始，因此 0.16.0-0.23.0 的安装包不可用于逐版本差分。
- winget（`microsoft/winget-pkgs`，包 `xAI.GrokBot`）：manifest 自 0.57.1 开始——0.57 之前的版本没有 ReleaseNotes（GitHub contents API 列举，核查于 2026-11-12）。
- Wayback Machine CDX（桌面分发域名，2026-11-12 查询）：`downloads.cursor.com/grokbot/stable/...` 包路径族存在快照（部分列表——完整列举查询被 Internet Archive 多次临时故障打断）；未发现官方网页 `cursor.com/grok-bot*`、`cursor.com/download/bot*`、`docs.x.ai/grok-bot*` 的快照（归档可达时查询）；`grok.com/changelog*` 与更新 feed（`api2.cursor.sh/updates/*`）的查询因上述故障及查询环境的 DNS 限制未能完成。
- Homebrew cask `grok-bot`（token 存在；主页 `https://x.ai/bot`；autobump；跟踪同一 CDN）可佐证分发 URL 方案，但不携带发布说明。
- 结论：官方未发布本构建的逐版本说明；上文刻意只写入可验证的发布背景事实（宁缺毋滥，不虚构功能）。
