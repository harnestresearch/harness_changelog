# Grok Bot 0.64.0

[English](../../../full/grok-bot/2026-09-30_0.64.0.md) | 简体中文 · [精简版 (Highlight)](../../grok-bot/2026-09-30_0.64.0.md) | **完整详情 (Full Detail)**

- **发布日期**：2026-09-30
- **覆盖平台**：`mac`、`win`
- **版本摘要**：连接器文档深链类型注册表成形（GitHub/Jira/Linear/Google/Slack 等 16 类），agent 支持指派管理员与停用草稿

## 变更要点

- **功能**：连接器文档类型注册（URL 深链解析为 provider+id）：confluence-page、figma-slides、github-file、github-gist、github-issue、github-pull-request、gmail-draft、google-docs、google-drive、google-sheets、google-slides、jira-issue、linear-document、linear-issue、slack-canvas、slack-message（另有 box/dropbox/airtable/coda/miro/canva/hex/google-calendar-event 等）。agent 治理：AddGrokBotAgentManager / ListGrokBotAgentManagers / RemoveGrokBotAgentManager（指派管理员用户）、SetGrokBotAgentDraftingDisabled（停用 agent 草拟）、RemoveGrokBotRoomPeople。
- **协议/主进程**：新权限 scope：agent_serve_deployment.deploy / read / secrets / manage_access 与 grok_bot_agent.manage（"agent serve" 部署的 OAuth 式授权模型）；管理端会议查询 AdminLookupGrokBotMeetings / AdminLookupGrokBotMeetingsByAgent；artifact 埋点 sand.artifact.opened / edit_attempted / edit_saved / link_copied / revisited_from_library；linear.app 进入已知域名表。
- **UI**：新组件 card-check-row、link-brand-logo、member-chip、team-setup-pills、team-setup-row、voice-memo-waveform（语音备忘录波形）、reference-menu、plugin-detail-view。
- **底层**：无依赖增删；renderer 大规模重构建（192 个文件）。


## 代码与协议细节

- `main-app.cjs`：连接器深链解析扩充：Jira（`hostname.endsWith(".atlassian.net")` + `/browse/<key>` → `provider:"jira-issue", id:\`\${t}/\${a}\``）、Confluence pages 路径、GitHub issue（`\${r}/\${n}#\${i}`）与 blob 文件路径重组（`n0e=/^[A-Za-z0-9_.-]+\$/` 校验 owner/repo）。
- `main-app.cjs`：agent 身份管理客户端：`updateIdentity(id, {avatarPngBase64, ...})` → `updateGrokBotAgent({...partialUpdate:!0, avatarChange})`、`listManagers/addManager`、agent 创建增加 `creationRoute` 上报字段。
- `main-core.cjs`：Finance/Plaid 使用守则进提示词：`"Finance holds the user's bank, credit card, loan and brokerage accounts linked through Plaid...list Finance's connections and accounts and use them before opening that institution's website"`，并明确图表读取走真实数据（computer-use 读图不可靠）。
- `main-app.cjs`：新增遥测 `artifactEngagement: {ingest: a => {... trackEvent(c,d)}}`（artifact 打开/编辑行为上报）。
- `proto.cjs`：注册 `SetGrokBotAgentDraftingDisabled`、`RemoveGrokBotRoomPeople` 服务方法；`AdminDeleteSandBoxStoreManifest` 移除。
