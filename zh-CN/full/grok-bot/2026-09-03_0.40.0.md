# Grok Bot 0.40.0

[English](../../../full/grok-bot/2026-09-03_0.40.0.md) | 简体中文 · [精简版 (Highlight)](../../grok-bot/2026-09-03_0.40.0.md) | **完整详情 (Full Detail)**

- **发布日期**：2026-09-03
- **覆盖平台**：`mac`、`win`
- **版本摘要**：云端会话盒（Session Box/Pod）管理体系与团队预付费计费上线

## 变更要点

- **功能**：团队预付费余额与自动充值（`CreatePrepaidTopUp`、`PrepaidAutoTopUpRule` 阈值/金额、`PrepaidBillingMode`、`PrepaidTopUpEntry`）；云端会话盒 pod 状态机（`GrokBotSessionBox` / `GrokBotSessionBoxPod` / `PodState` / `CredentialState`，支持休眠管理）；团队 Grok Bot 适用用户查询（`GetTeamGrokBotEligibleUserIds`）。
- **协议/主进程**：管理端会话盒 RPC——`AdminForceDeleteGrokBotSessionBox`、`AdminGetGrokBotSessionBox`、`AdminListGrokBotSessionBoxes`、`AdminHibernateGrokBotSessionBox`、`AdminReapGrokBotSessionBoxNow`（强制删除/查询/列出/休眠/立即回收）；`GetTeamPrepaidBilling`、`SetTeamPrepaidBillingMode`、`SetTeamPrepaidAutoTopUp`；`aiserver.v1.InferenceService.Stream` 出现携带 `getGrokBotAccessToken` 的专用鉴权路径；遥测事件 `sand.policy.stopped`；状态枚举 `PREPAID` / `REACHABLE` / `REVOKED` / `STARTING` / `SOURCE_GROK_BOT`。
- **UI**：`voice-picker-dialog` 语音选择对话框；新增乌尔都语（ur）资源 `emoji-messages.ur`。
- **底层**：无依赖变化。


## 代码与协议细节

- `main-app.cjs`：新增 `onPolicyStopped` 处理——`SandError.policyStopped({reason})` 并上报 `"policyStopped"` 遥测（0.39 为 0 处 → 6 处引用）；连接器授权埋点 `productAnalytics.trackEvent("sand.connector_auth", ..., "desktop")`（1→4 处）。
- `main-core.cjs`：新增 GitHub 连接回调路由 `/v1/github-connect-callback` 的参数校验——`state` 必须匹配 `/cursor_grok_bot_github_v1\.[0-9a-f]{32}\.[0-9a-f]{32}/`、`installationId` 限 1–19 位数字、`code` 限 `[A-Za-z0-9_-]{1,200}`；语言表新增 Urdu（اردو，rtl）、Thai（ไทย）、Bengali（বাংলা）。
- `proto.cjs`：管理端会话盒 RPC `AdminGetGrokBotSessionBox` / `AdminListGrokBotSessionBoxes`（0→5 处）；预付费计费 `CreatePrepaidTopUp`（0→5 处）与 `PrepaidTopUpEntry`（`ticket/origin/amount_cents/status/created_at_ms`）；消息新增 `context_injection_order` / `delivery_deadline_started_at_ms`；Slack 重装枚举 `GrokBotSlackReinstallOutcome` 与团队设置字段为重排对齐。
- `renderer/DefaultCode`：shiki 代码高亮 chunk 重组（343625→333780B，236 处真修改，懒加载语言表改写），其余 renderer 为 hash 轮换。
