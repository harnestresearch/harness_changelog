# Grok Bot 0.44.0

[English](../../../full/grok-bot/2026-09-06_0.44.0.md) | 简体中文 · [精简版 (Highlight)](../../grok-bot/2026-09-06_0.44.0.md) | **完整详情 (Full Detail)**

- **发布日期**：2026-09-06
- **覆盖平台**：`mac`、`win`、`ubuntu`
- **版本摘要**：账号合并（Account Collapse）、团队级 agent 与 agent 密钥提交流程

## 变更要点

- **功能**：账号合并运行（`StartAccountCollapseRun`：target_user_id + source_user_ids；`ListCollapseCandidates` 候选/可合并性/匹配与建议理由；`GetAccountCollapseRun`）；团队级 agent（`GrokBotTeamAgent` 及 Session/Routine 计数，`AdminListGrokBotTeamAgents` / `AdminDeleteGrokBotAgent`）；agent 密钥请求-提交流程（`SubmitGrokBotSecret`：agent_id + entry_id + value + session_id）；云端 onboarding 启发式环境搭建（`StartCloudOnboardingHeuristicEnvSetup`：scm_provider + 排除仓库清单，`CloudOnboardingAutoEnvSetupAcceptResult`）；团队成员 SandBox 迁移状态与重建（`GetTeamMemberSandBoxMigrationStatus` / `RecreateTeamMemberSandBox`）；`SandAutoReviewControls`（auto-review 强制执行开关）。
- **协议/主进程**：新增大量通道/键——`egress-tunnel`（出口隧道，重连策略 `sand-egress-tunnel-reconnect`）、`health-probe`、`login-poll`、`marketplace-fetch` / `marketplace-token`、`spend-initiation`（消费发起的 transcript 条目类型）、`weekly-usage`、`secret-request`、`auth-policy-recheck`、`auth-cleanup-remove`、`daemon-discovery`、`desktop-status`、`dev-controls` / `dev-restart-exit`、`box-env`、`channel-credential` / `credential-post`；持久化键 `roster.agent-avatars` / `roster.last-roster` / `selection.last-agent` / `sidebar.last-sections` / `transcript.replicas`；anyrun 侧 `RawEgressProxyAuth`；Linux 桌面集成 `grok-bot-appimage` / `xdg-mime` / `mimeapps.list`。
- **UI**：`anchored-popup`、`settled-message-card`、`provider-local-tool-permission`（本地工具授权卡片）组件；Slack 重装/卸载结果细化（RECREATE_REQUIRED / PENDING_ADMIN_APPROVAL / RATELIMITED / MANAGER_REAUTH_REQUIRED 等）。
- **底层**：新增 `STEP0_BAKE_OVERLAY` / `STEP0_LIVE`（盒环境烘焙步骤）与 SSO_SCIM / DOMAIN_CAPTURE 等组织账号判定常量；移除 `SAND_DATA_ROOT`、`binding-cleanup`、`confirmation-failed`。


## 代码与协议细节

- `main-app.cjs`：Linux AppImage 自更新体系——新增 `SandAppImageInstaller`（staging 目录前缀 `.sand-update-`）、`appImagePathFromEnv()` 与启动装配 `appImage: new MN({ appImagePath, relaunchArgs: process.argv.slice(1), quit })`；新增 `SandCursorSecureStorageSettlement` 类（`storedSignInTimeoutMs` 超时、`decideForNullPair()` 判定 signed-out/signed-in、`[sand] dev-login: ${kind} as ${email}` 日志上报）；WebAuthn 扩容（`requestWebAuthnConsent/requestWebAuthnPin`，PIN 相关引用 4→12 处）；token 刷新熔断 `refreshPauseHolds()`——`refreshFailureStreak.pausedUntilMs` 未到期即跳过；ConnectError `Unauthenticated` 时先回调重取凭据再重抛。
- `main-core.cjs`：Sentry/OTel 追加（`spanToTransactionTraceContext`、`dsnFromComponents`、replay 失败包装器、`shouldContinueTrace`）；平台诊断信息加入 `APPIMAGE`/`XDG_DATA_HOME`/`XDG_DATA_DIRS`/`XDG_CONFIG_HOME`；文件类型判定 helper（`"pdf"→pdf`，其余按集合映射 table/json/markdown/html）。
- `proto.cjs`：账号合并 `StartAccountCollapseRunRequest`（target_user_id + source_user_ids，匹配理由枚举 SESSION/PREVIOUSLY_LINKED/MATCHING_EMAIL/SAME_WORKOS_ID，0→6 处）；`GrokBotPluginScope`（agent_id + session_kind）；盒环境烘焙枚举 `STEP0_LIVE`/`STEP0_BAKE_OVERLAY`/`TURN_DONE_RECOMPUTE`；onboarding 字段 `setup_handled_by_server`/`conversational_setup_enabled`/`getting_started_trusted`；移除 PR agent 成本控制字段（`max_main_agent_cost_cents` 2→0、`cost_controls_available` 1→0、`max_runs_per_pr` 2→0）。
