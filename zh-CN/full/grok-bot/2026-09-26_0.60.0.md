# Grok Bot 0.60.0

[English](../../../full/grok-bot/2026-09-26_0.60.0.md) | 简体中文 · [精简版 (Highlight)](../../grok-bot/2026-09-26_0.60.0.md) | **完整详情 (Full Detail)**

- **发布日期**：2026-09-26
- **覆盖平台**：`mac`
- **版本摘要**：Agent/Skill 商店（aiserver.v1.AgentStoreService + 分片上传发布）与云沙盒"停车/休眠"状态机上线，新增 @anysphere/orbit-client

## 变更要点

- **功能**：技能/代理商店：AgentStoreService（ListAgentStores/ListAgentStoreEntries）与 AgentStoreMultipart* 分片写入协议（Abort/Complete/Write，含 etag、already_finished），支持把技能发布给团队——文案 "Add a description before publishing — it is how teammates and agents know when to use this skill"；云沙盒生命周期新增停车/休眠：box-asleep、x-sand-box-park、present-park、away-parked、SAND_PRESENT_PARK、has-box-agent、backend-return（节省云实例成本）；席位限制文案（"Ask a team admin to move this account to a Premium seat"）。
- **协议/主进程**：新 RPC `aiserver.v1.AgentStoreService`；新键 team-bot-slack-link、parent-link/target-link（目录页面链接）、all-temporal、not-a-file；report.drop / sand.dropped_count 遥测；UNPAID_INVOICE/RECONNECT_REQUIRED 等状态。
- **UI**：document-page、DIRECTORY_PAGE（商店目录页）、team-bot-details-model、ToggleIconButton。
- **底层**：新增依赖 `@anysphere/orbit-client`；electron-main 36 个文件重构（模块拆分）；asar 585→587。


## 代码与协议细节

- `main-app.cjs`：webview/VNC 云沙盒鉴权头注入——把 URL 查询参数转为请求头：`{queryParam:"port_token", header:"x-anyrun-port-token"}`、`{queryParam:"network_token", header:"x-anyrun-network-token"}`，休眠恢复窗口还有 `x-anyrun-hibernation-lower-bound-s/upper-bound-s`（配合 preload-webview.cjs / preload-vnc.cjs，按 host 缓存 + LRU 上限）；Slack 解绑 `disconnect("slack") → unlinkSlackAccess(new UnlinkSlackAccessRequest)`（DashboardService）；文档服务 RPC `getDocument({locator})` / `saveDocument({locator, source})` + `setCanvasVisibility`；meetings 需求校验（`"request.args is missing"`，demand 须为 "person"/"background"）；删除 `getGrokBotTeamContextSummary` RPC 与 revokeRefusedAccount 流程（"refused account credentials could not be removed"）；新增 `setComputerViewOpen({isOpen})` → `clientPresence.noteComputerViewOpen`（电脑端在场状态）。
- `main-core.cjs`：Sentry 延迟上报丢弃告警（captureMessage "sand sentry deferred captures dropped"，tag `sand.dropped_count`）；bot 能力分类常量 `hN=["all-temporal","has-box-agent"]`（`e.every(t=>t.harness==="temporal") → "all-temporal"`）。
- `main.cjs`：zip 解压改走 `` `/proc/self/fd/${fd}/${name}` ``（安全临时目录读取）。
- `meetings-main.cjs`：会议结束原因枚举（`"Grok Bot closed on the user's computer"` / `"the bot left the meeting"` / `"everyone else left the meeting"`）、ENDED 状态入队、`report.drop`（丢弃转写计数告警）。
- `proto.cjs`：`SharedAgentStoreListing`（share_id/agent_id/store_id/path_prefix/visibility/created_at_ms/revoked_at_ms/owning_user_id/owning_team_id/owner_display_name/store_kind/kind/source）；凭证字段 credential/expiresAtMs/credentialHeld。
