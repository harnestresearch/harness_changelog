# Grok Bot 0.59.0

[English](../../../full/grok-bot/2026-09-25_0.59.0.md) | 简体中文 · [精简版 (Highlight)](../../grok-bot/2026-09-25_0.59.0.md) | **完整详情 (Full Detail)**

- **发布日期**：2026-09-25
- **覆盖平台**：`mac`
- **版本摘要**：大版本：会议智能体（meetings-main.cjs，Google Meet/Zoom 加入、转写、STT）与 xAI 预付费商务模块上线

## 变更要点

- **功能**：独立主进程模块 MeetingsService：识别 meet.google.com（会议码 xxx-xxxx-xxx）与 zoom.us/j/<9-12 位> 链接，加入会议做实时转写（stt.open/close/segment/error、pcm.first、join.start/ack/typed）、生成摘要（summary.due、meeting-report）并以 meeting-window 独立窗口展示（sand.desktop.meetings、sand.transcript.* 渲染遥测）；新依赖 `@anysphere/xai-commerce-prepaid` 对应 xai-commerce-bearer 凭证与 PRODUCT_CREATE（xAI 侧商务/预付费）。
- **协议/主进程**：新 API 主机 `https://api2.cursor.sh`；连接器 OAuth 回调 `https://x.com/i/connectors/oauth_callback`（X 集成）与 mcp.hubspot.com；onepassword-oauth（1Password OAuth 流程）；云沙盒离线/驻留状态机 client-pause、away-park、network-return、SAND_AWAY_PARK；大量新键：usage-breakdown、create-team-bot、google-meet、in-call、unread-divider、send-task、agent-exchange、cloud-agent-infos、mcp-servers-updated、package-download、linux-x64/linux-arm64/win32-x64/win32-arm64（按平台分发）等 53 个；EnsureGrokBotDefaultMainAgentResponse.Outcome。
- **UI**：team-bot-learned-context（习得上下文）、team-setup-new-skill-dialog（新技能对话框）、team-bot-details-pane/rows、SegmentedControl、X-VF/XMono 可变字体资源。
- **底层**：新增依赖 `@anysphere/xai-commerce-prepaid`；新增 meetings-main.cjs 与 preload-meeting.cjs 进程；asar 文件数 552→585；移除上版引入的 CI 常量与 turn-tasks 等键（收编进其他形式）。


## 代码与协议细节

- `meetings-main.cjs`（新增文件，32384B）：独立会议服务进程（MeetingsService）。
- `main-app.cjs`：本地回环 HTTP 服务新增观测端点 `["GET /meetings"]` 与 `["GET /meetings/capture"]`（缺 meetingId 返回 400 `"meetingId is required"`）；MCP OAuth 客户端元数据 `kte="/oauth/mcp-client.json"`、`n6e="https://cursor.com/oauth/mcp-client.json"`；下载清单支持 Linux 包分发——`d6e(e,"deb")` 按 platform+linuxPackage 匹配 `/download/stable/<platform>/grok-bot-<hash>`；云代理发布提案 RPC `getCloudAgentPublishProposals` / `confirmCloudAgentPublishProposal({agentId, bcId, proposalId, slug, visibility})`；`cloneToTeam` → `cloneGrokBotAgentToTeam({agentId, offerEntryId, personalSecretNames})`（处理 CLONED 等 outcome）；更新器强化——`keepStagedZip`/keptZips.verify（失败文案 `"The kept ${i} update..."`）与 `isPastMaxAge()`（按 `getMaxAgeDays()` 判定更新包过期）；附件图片按 `` `${mime} ${sha256}` `` 去重（attachmentImageUrl）。
- `main-core.cjs`（1862395→754636B，-59%）：主进程大瘦身——i18n 语言数据外置为 `electron-main/locales/` 目录（30 个语言文件 af/ar/bn/cs/da/de/el/es/fi/fr...），大量代码去重合并；错误类型映射表（error/type_error/range_error/reference_error/syntax_error/eval_error）。
- `main.cjs`（11998→6930B）：剥离 signal-exit 等内嵌依赖。
- `proto.cjs`：会议转写消息（text/isFinal/kind）、shareId、returnTo；`ClientActionResponse` 新增 `confirmation{title, message, confirmLabel}`；新增内部 RPC `GetGrokBotChangelogInternal` / `UpdateGrokBotChangelogInternal` / `SetGrokBotChangelogStatusInternal`；记忆字段 `learnedAtMs`。
- 另：1Password 连接类型细分为 `oauth-broker`（含 brokerState 的 reconnect_required 等映射）与 `service-account` 两类；虚拟卡支付增加 passkey 仪式状态（`needs_enrollment` / `needs_passkey` + enrolledCredentialIds）。
