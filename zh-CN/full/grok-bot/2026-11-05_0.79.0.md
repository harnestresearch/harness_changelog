# Grok Bot 0.79.0

[English](../../../full/grok-bot/2026-11-05_0.79.0.md) | 简体中文 · [精简版 (Highlight)](../../grok-bot/2026-11-05_0.79.0.md) | **完整详情 (Full Detail)**

- **发布日期**：2026-11-05
- **覆盖平台**：`mac`、`win`
- **版本摘要**：上线电商全流程、Agent Store 市场、日历/会议与消息卡协议及 Realtime 语音事件流

## 核心新功能

- **电商与出行全流程**
  - 新增服务端按 Agent 维度的购物车与商品检索协议：`LookupGrokBotShoppingProduct`、`SearchGrokBotSimilarProducts`、`Set/List/RemoveGrokBotCartItems`（含变体、库存与划线价）及 `cart-stage` / `receipt-shell` 界面。
  - 支持礼品订单信息校验（`gift.recipientName` / `message` / `arrivesBy` / `deliverBy`）、优惠码（`promo.code` / `note` / `saved`）与退货政策展示（`returnPolicy.summary` / `url`）。
  - 新增机票预订链接解析（`ResolveGrokBotFlightBookingLink`、`sand.flights.book_on_click`、航班号校验）与虚拟试穿（`Generate/ListGrokBotTryOnImages`、`reference-photos` 自拍参考图设置，缺失自拍时返回 `needs-selfie` / `NO_SELFIE`）。
- **Agent Store 市场**
  - 新增 `agent-stores` / `shared-agent-stores` 设置面板、`@agentstore(/cursor/stores/...)` 深链解析、`ListSharedAgentStores` 分页查询、店铺可见性（`private | team-view | public`）、`publish_app.publish` 发布权限与 `shared-bots-browse` 浏览页。
- **日历、会议与 iMessage 交互审批卡**
  - 新增日历事件监听与轮询协议（`WatchGrokBotCalendarEvents`、`PollGrokBotCalendarEvents`、`GrokBotCalendarEventFrame`）及会议提示响应（`ActOnGrokBotMeetingPrompt`、`UpdateGrokBotMeetingSettings`，覆盖 Google Meet / Zoom / Microsoft Teams / Webex），内置 Google Calendar MCP 连接器（`calendarmcp.googleapis.com`）与移动端日历读写工具定义。
  - 新增 iMessage 交互式消息卡协议（`Get/AnswerGrokBotMessagingCard`、`ReportGrokBotMessagingCapabilities`），支持审批、单选、表单、页面与支付五类卡片（涵盖自动审查、入会同意、本地工具授权、凭据/密钥请求等子类型）。
- **Realtime 语音事件流与通话卡片**
  - 语音通话引入 Realtime API 事件流（`session.created/updated`、`conversation.created`、`response.audio.delta`、`response.output_audio.delta`）、口语语言提示词注入（`spokenLanguage`）、通话空闲 15 秒主动简报/提问（`situation-brief` / `situation-ask`）及通话中发送卡片（`phone-call-send-card`）；语音静默工具统一命名为 `stay_silent`。
- **转写检索、资料与地点服务**
  - 新增跨消息与文件的全文转写搜索 `SearchGrokBotTranscripts`、用户头像/自拍资料管理（`GetGrokBotUserProfile`、`Set/DeleteGrokBotUserProfilePhoto`）、地点详情查询 `GetGrokBotPlaceDetails`（Yelp 结果展示）与标注问答 `AnswerGrokBotLabelerQuestion`。

## 协议、治理与底层改进

- **本地工具长期授权与写工具计划模式**：主进程新增本地工具常设授权管理接口（`recordLocalToolStandingGrant`、`getLocalToolActionGrant`、`setLocalToolActionGrant`、`clearLocalToolApprovals`、`retireMacMailSendApproval`）；`WriteArgs` 新增 `plan_mode` 标志；MCP 返回体新增 `mcp_app_document` 类型。
- **用量、会话治理与账号迁移协议**：新增 `GetGrokBotUsageBreakdown` 与 `usage-limits` / `my-plan` / `additional-usage` 限额键；新增 `team.member_sessions.read/manage` 与 `organization.member_sessions.*` 权限、非受信任团队记忆（`GrokBotAgentDefinitionUntrustedTeamMemory`）以及全套管理端账号迁移 RPC（`Admin*GrokBotAccountMigration*`）。
- **沙盒、网络与连接器**：新增 `dev-box-docker` 执行器、隔离部署盒内身份令牌签发（`getValidXaiIdentityAccessTokenForBox`）、出站策略私网放行规则（`private_destination_rules`）、沙盒客户机根文件系统初始化开关（`run_on_guest_rootfs`）、Tailscale 细分错误码映射，以及托管连接器注册表新增 `mcp.asana.com` 与 `setup.shopify.com`；MCP stdio 连接器补充命令缺失、权限不足与标准输出污染诊断提示。
