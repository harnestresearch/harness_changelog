# Grok Bot 0.25.0

[English](../../../full/grok-bot/2026-08-25_0.25.0.md) | 简体中文 · [精简版 (Highlight)](../../grok-bot/2026-08-25_0.25.0.md) | **完整详情 (Full Detail)**

- **发布日期**：2026-08-25
- **覆盖平台**：`mac`、`win`
- **版本摘要**：引入 Agent 模板体系、远程"用户计算机"控制通道与 Chrome 数据导入——产品从单 agent 对话走向可分发、可遥控的 bot 平台

## 变更要点

- **功能**：Agent 模板系统上线（`CreateGrokBotAgentFromTemplate`、`ActivateGrokBotTemplateVersion`、`GetGrokBotTemplateImportDetails`、templates-pane 界面）；桌面通知音效（5 个内置 wav：ping-open-blip/tick/double-tick/chime-a/chime-b，notification-sound 设置）；语音模型首次出现（设置键 `grok-voice-latest`）。
- **协议/主进程**：新增大批 GrokBot 协议：远程用户计算机控制族 `GrokBotUserComputer{Hello,Exec,File,Download,Cancel,ControlMessage,…}`、转录流式订阅族 `GrokBotTranscriptWatch{Frame,Rows,Heartbeat,Cursor,…}`、多成员房间轮次族 `GrokBotRoomMemberTurn*`（SpeakerKind 区分 agent/人类）、box 交接 `EndGrokBotBoxHandoff`、`GetGrokBotSendStatus`、`DismissGrokBotWidget`、`GetEffectiveUserAgentStoreSkillsSettings`；状态常量 ACCEPTED_BOX/DELIVERED_TEMPORAL/NOT_TEMPORAL 等（temporal 持久化投递语义）。
- **UI**：onboarding-flow、automation-detail-panel、agent-avatar-editor、templates-pane、markdown 数学渲染（KaTeX 字体内联）。
- **底层**：新增 `dist/electron-main/chrome-import-worker.cjs`（导入宿主 Chrome 配置/Cookie，配套 profile-cookies）；移除 rehype-katex 依赖（KaTeX 改为整包内置）；dev-controls 与 dist/host 下若干 worker（agent-store-worker、transcript-mirror-worker、box-store-vacuum-worker、search-index-worker）收敛进主 bundle；依赖 82→81。


## 代码与协议细节

- `dist/electron-main/chrome-import-worker.cjs`（新增文件，0→11445 字节）：全新 Chrome 导入 worker（collectProfileCookies 等 profile 采集逻辑），主进程 main.cjs 同步出现对该 worker 的引用——"宿主 Chrome 配置/Cookie 导入"子系统落地。
- `main.cjs`：Agent 模板 RPC 族全新出现（0.24.0 中均为 0 处）：`CreateGrokBotAgentFromTemplate`、`ActivateGrokBotTemplateVersion`、`GetGrokBotTemplateImportDetails`、`GetGrokBotTemplateForSourceAgent`，及错误 `BotTemplateImportRecipeError`（"GetGrokBotTemplateImportDetails returned an unusable recipe"）。
- `main.cjs`：远程"用户计算机"控制通道协议族新增：`GrokBotUserComputerHello`、`GrokBotTranscriptWatchFrame`（转录流订阅）、`GrokBotRoomMemberTurnRequest`（多成员房间轮次）、`EndGrokBotBoxHandoff`、`GetGrokBotSendStatus`、`DismissGrokBotWidget`。
- `main.cjs`（proto）：exec 流式消息新增 `{no:57,name:"machine_id"}` 字段（与 shell_args/write_args/delete_args 同一 oneof 消息）。
- `main.cjs`（纯删除）：EXIF 元数据表（InteropIndex/OldSubfileType/PhotometricInterpretation…）与 image-q 图像量化库（Igor Bezkrovnyi 版权头）整体移除——main.cjs 由 8.68MB 缩至 7.49MB。
- `main.cjs`：新设置键 `notification-sound`与语音模型 id `grok-voice-latest` 首次出现。
