# Grok Bot 0.67.0

[English](../../../full/grok-bot/2026-10-02_0.67.0.md) | 简体中文 · [精简版 (Highlight)](../../grok-bot/2026-10-02_0.67.0.md) | **完整详情 (Full Detail)**

- **发布日期**：2026-10-02
- **覆盖平台**：`mac`、`win`
- **版本摘要**：整体下线本地会议窗口（meetings-main/preload-meeting* 全删，转向服务端会议），新增草稿修订高亮

## 变更要点

- **功能**：删除本地参会实现：meetings-main.cjs、preload-meeting.cjs、preload-meeting-avatar.cjs、pitman-avatar-output.html 全部移除，sand-meeting-camera/hear/idle/stamp/wake、meeting-load/pull/report/window、stt-stream/stt-stop、meetings-enablement、in-call、summary-due 及 Google Meet/Zoom 示例 URL 一并消失；仅保留本地诊断端点 GET /meetings/record 和服务端 AdminMintGrokBotMeetingAvatarLinks（头像链接改由服务端铸造）。新依赖 `@anysphere/draft-revision` + use-draft-revision-highlight（草稿修订高亮）。
- **协议/主进程**：GetGrokBotAgentLinkAccess（agent 分享链接访问权）；团队邀请链接 GetTeamInviteLinkResponse / SendTeamInviteResponse（valid_until 有效期）；本地工具调用记录 GrokBotUserComputerLocalToolCall（tool_id+input_json）/ GrokBotUserComputerLocalToolResult（status/output_json/error）；MessageSender.Kind；遥测 sand.connector_card.rendered；新键 bot-identifier、permission-report。
- **UI**：本地工具权限按钮 "Always allow"（始终允许）；一组进行中状态短语（i18n 表）："Chipping away"、"Clicking through pages"、"Connecting the dots"、"Jotting it down"、"Making progress"、"Reading the file"、"Sending a message"、"Checking with another Bot"、"Needs your input"；"Could not store the secret"（密钥保存失败）；teach-recording-controls（"教它"录制控制）、agent-character-picker（agent 形象挑选）。
- **底层**：依赖 89→90（+@anysphere/draft-revision）。


## 代码与协议细节

- 整文件删除：`meetings-main.cjs`（45314 字节→无）从 dist/electron-main 消失；`main-app.cjs`同步删除 `"src/electron-renderer/pitman-avatar/pitman-avatar-output.html"` 常量、头像 `lookup` 类（listAgents 查头像）、诊断路由 `["POST /meetings/join",...]` 与 `["GET /meetings/capture",...]`（`"meeting join is not wired"` 兜底也一并移除）；仅保留 `GET /meetings/record`。
- `main-app.cjs`：GitHub issue URL 规范化：`function a3t(e){let t=e.searchParams.get("p"); return t!=null&&t3t.test(t)?t:r3t.exec(e.pathname)?.[1]??e.toString()}` 与 `s3t`（pathname 按 `/` 拆分、校验 `n!=="issues"`）——连接器链接注册表的 issue 深链清洗。
- `main-app.cjs`：团队协作三件套：`getTeamInviteEligibility`（未登录/无 teamId → `{kind:"ineligible"}`）、`getSharepointSignIn`（经 `backendMcpExec.checkAuthStatus({statusOnly:!0})` 探测 SharePoint OAuth 状态，8 处引用）、`listGrokBotAgentAccessPrincipals`/`addAllowedUser`/`removeAllowedUser`（agent 访问白名单，返回 `userIds+creatorUserId`）。
- `main-app.cjs`：MCP 工具入参矫正：`function h7e(e,t){let r=t.find(a=>a.providerIdentifier===e.providerIdentifier&&a.toolName===e.toolName)?.inputSchema, ... i.args=io.fromJsonString(JSON.stringify(o)).fields}`——按服务端 inputSchema 强制转换工具调用参数。
- `main-app.cjs`：通知权限询问持久化：`store: Att({filePath: join(app.getPath("userData"),"notification-permission-sent.json")})`，含 `isPersistEnabled/platform/deviceId:getDurableMachineId()` 字段。
- `proto.cjs`：团队邀请消息新增 `announceInstructions/maxOffers/eligibilityGate/minClientVersion` 字段（邀请发放的服务端门槛）；`main-core.cjs`：新 RPC 方法名枚举表（AddMcpServer/AuthenticateMcpServer/AwaitShell/ChatItems/CheckIMessagePermissions/...）。
