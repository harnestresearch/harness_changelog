# Grok Bot 0.65.0

[English](../../../full/grok-bot/2026-09-30_0.65.0.md) | 简体中文 · [精简版 (Highlight)](../../grok-bot/2026-09-30_0.65.0.md) | **完整详情 (Full Detail)**

- **发布日期**：2026-09-30
- **覆盖平台**：`mac`、`win`
- **版本摘要**：新增原生通知设置模块与 Microsoft Teams 会议提供方；会议转录/记录 API 与 finance 连接器上线

## 变更要点

- **功能**：新原生模块 sand-notification-settings（build/Release/sand_notification_settings.node，经 notification_settings_async 读取 macOS 通知权限，结果键 sand.desktop.notification.permission，配合设置键 os-notifications）。会议提供方新增 MICROSOFT_TEAMS（与 GOOGLE_MEET / ZOOM 并列），并出现服务端会议列表轮询（meeting-server-list、meetings-enablement 开关）。finance 连接器 OAuth 连流（startFinanceLink，含 reportLinkStart 阶段遥测）；Shopify 连接器注册（setup.shopify.com，clientRegistration: static）。
- **协议/主进程**：会议记录/转录 RPC：AdminGetGrokBotMeetingTranscript（lines + truncated）、AdminGrokBotMeetingTranscriptLine(at_ms,text)、GetGrokBotMeetingRecord、LeaveGrokBotServerMeeting、GrokBotMeetingTranscriptLine；后台摘要编写器 GetTurnSummaryBackgroundComposer / ListBackgroundComposerArtifacts；GrokBotUserComputerLocalTool（本地工具状态上报）。新设置键：mcp-app、sand-mcp-app、time-zone-override、language-preference、theme-preference、local-egress-policy、permissions-policy、screen-locked、agent-activity、team-agent-activity、box-roster-census、browser-backward、browser-forward、message-history、single-shot、unsafe-path、sand-html-preview、app-command、before-mouse-event；store.notify、sand.request-recovery；xterm-kitty/xterm-ghostty/TERM_PROGRAM（终端 truecolor 探测）及一批 CI 环境识别常量（GITHUB_ACTIONS、GITLAB_CI、CIRCLECI、TEAMCITY、BUILDKITE、APPVEYOR、TF_BUILD、GITEA_ACTIONS）。
- **UI**：finance 连接器页面组件。
- **底层**：依赖 88→89（+sand-notification-settings，含 .node 原生二进制）；asar 601→611。


## 代码与协议细节

- `main-app.cjs`：会议提供方扩为三方：`var Por=["GOOGLE_MEET","ZOOM","MICROSOFT_TEAMS"]`（Teams 加入），新增 `ServerMeetingRecordError`（`class extends SandDomainError`）与服务端会议记录客户端（`static timeoutMs=1e4, last=[]`）——本地会议开始向服务端迁移。
- `main-app.cjs`：OS 通知服务端开关同步：`readServerFeedGate()`（读 `isServerFeedOn()`，异常走 `reportDesktopEdgeFailure("os-notifications","gate-read")`）+ `syncGate()` 状态机。
- `main-app.cjs`：Box 花名册合并：`keepOnlyAgents(t)` 清理本地 boxAgents、`serverRosterAgents/serverRosterRead/wantsServerReread` 合并服务端名册，`isTeamRoom(t)` 按 `groupChatRoomOf` 归类、`moveHistory(t, this.boxLane)` 迁移历史。
- `meetings-main.cjs`：入会失败文案表 `f={cancelled:"the join was cancelled", joinFailed:"couldn't join the meeting", notAdmitted:"wasn't let into the meeting", disconnected:"lost the connection to the meeting"}`；bot 名后缀 `` `(${t}'s Bot)` `` 超长截断（`suffixOf`）。
- `main-core.cjs`：新增 `var Gs="sand-html-preview", Vs="text/html; charset=utf-8", Hs="sand-mcp-app"`（HTML 预览与 MCP app 的自定义协议/分区常量）与系统 CA 证书错误分类集合（`UNABLE_TO_GET_ISSUER_CERT`/`SELF_SIGNED_CERT_IN_CHAIN` 等 6 类，最多 4 层 cause 解包）。
- `proto.cjs`：新增 `ManagerSpawnKind`：UNSPECIFIED/CREATED/ADOPTED/`CREATED_SAME_VM`（管理器进程领养语义）；注册 `getTurnSummaryBackgroundComposer`/`listBackgroundComposerArtifacts`/`listWorkersForManager`。
