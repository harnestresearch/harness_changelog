# Grok Bot 0.77.0

[English](../../../full/grok-bot/2026-10-26_0.77.0.md) | 简体中文 · [精简版 (Highlight)](../../grok-bot/2026-10-26_0.77.0.md) | **完整详情 (Full Detail)**

- **发布日期**：2026-10-26
- **覆盖平台**：`mac`、`win`、`ubuntu`
- **版本摘要**：打通"设备链接 + 本地执行守护进程 + iMessage/电话外呼"跨设备能力，上线 Bot 分享邀请与用量账单页

## 变更要点

- **功能**：设备链接（QR 码 + `https://cursor.com/grok-bot/link/v1/` 深链，支持 agent/bot-template/marketplace/plugin/add/prompt/referral/settings 路径，另有 `/finance` 端点走 `StartFinancialLink` 金融账户链接）；iMessage 草稿发送工具（`imessage-draft`，携带 machineId/approvalId 审批流）；电话外呼录音（RPC `/aiserver.v1.GrokBotService/OutboundCallRecording`）；语音听写（`dictation-text` 事件，TranscriptionManager 独立听写入口）；独立"电脑操控"服务 **Grok Bot Orbit Computer Use**（bundleId `co.anysphere.grok-bot-orbit-computer-use`，可执行文件 CUGrokBotOrbitService）；xAI 商务支付（`XaiCommerceBearerPurpose` = BROWSER_COMMERCE/PREPAID_TOP_UP）、订单跟踪状态机（placed/in_transit/arriving_today/delivered/delayed/cancelled）及 merchant/shipTo/tracking 结构化字段。
- **协议/主进程**：新权限键 `messages-send`、`messages-send-without-asking`、`messages-allowed-recipients`、`read-messages`；新设置区 `linked-numbers`、`your-computer`、`manage-devices`、`computer-use`、`team-bots`、`contacts`、`usage-and-billing`、`usage-resets`、`personal-usage`、`unified-plan`、`call-recording`；后台服务描述符 `gateway`、`passkey-provider`、`local-exec-refresh`；`device-tools/<op>` RPC（带 installDir/launch，远程调用设备本地工具）；遥测 `sand.bot_share.invite_*` 全套（Bot 分享邀请）、`sand.desktop.referral_code_shared`、`sand.desktop.sidecar_launch`；协议新增 `ConversationMessage.ThinkingStyle`、`conversation.item.delete`。
- **UI**：agent-invite-dialog、bot-share-popover/trigger/invite-popover、bonfire-dialog、desktop-mount-panel、agent-avatar-editor、sand-store-page、manage-plan/用量账单页。
- **底层**：新增依赖 `@anysphere/attention-count`、`@anysphere/device-local-tools`、`@anysphere/jpeg-napi`（原生 JPEG 模块）、`@anysphere/sand-playwright-runtime`、`@sand/local-exec-daemon`、`@sand/local-exec-protocol`、`@sand/primitives`、`@sand/shared-node`、`qrcode`、`sand-address-lookup`（原生 URL/地址解析，伴随 dot-segment/percent-encoding 等 URL 标准错误串）；移除 `mermaid`；**下线 Chrome 数据导入**（删除 chrome-import-worker.cjs，chrome-safe-storage/profile-cookies/list-profiles/open-cdp-* 等字符串整体消失）。


## 代码与协议细节

- `main-app.cjs`：① 工具执行结果信封化——runner 改为返回 `{ok:!0, value: await u.run(E,h,r)}` / `{ok:!1, failure:{code, detail}}`，错误按 dt 类的 code/detail 结构化，替代直接抛异常；② 新增 1Password keyless OAuth 回调处理器 EOt，`createDeadlinePolicy({name:"sand-onepassword-oauth-keyless-callback", timeoutMs: keylessCallbackGraceMs ?? wsr})` + open/abort 生命周期；③ 集成目录数据 `[{platform:"github", displayName:"GitHub", blurb:"Let automations watch a repo's PRs, comments, issues, and CI."}, {platform:"origin", ...}, Slack/...]`；④ markdown 标签白名单映射 `[["strong","strong"],["i","em"],["s","del"],["strike","del"],["sub","sub"],["sup","sup"],["mark","mark"],["br","br"]]` 替换旧的 Slack thread 返回值解析块；⑤ passkey 仪式状态机：`pending/completed→null, failed, expired` 映射 + `createDeadlinePolicy({name:"passkey-ceremo..."})`；⑥ OS 通知已读状态 `{readings, unreadThreads}` 与 `reportDesktopEdgeFailure("os-notifications","read",...)`（纯新增）；⑦ Bot 分享邀请遥测 `invite_sent/invite_link_opened/invite_dialog_shown → sand.bot_share.*`（纯新增）；⑧ `listSharedAgentStores` 游标分页（`ListSharedAgentStoresScope.TEAM` + `createdBeforeMs/createdBeforeShareId`，约 174 token）；⑨ 删除 `presentCookieOriginApproval`（chromeCookieImport 审批入口，Chrome 导入下线的主进程侧）。
- `main-core.cjs`：账号作用域设置存储落地——`settingsOwnerScope/getHoldingAccountScope/accountScopedSettingsFor`（signedOutHeir 兜底）；`open-url` 事件包装器（handler 入参经 jb 规范化，深链入口统一）；窗口几何持久化 schema `ETe = {version:1, normalBounds, isMaximized}`（safeParse 校验）。
- `main.cjs`：纯新增 `X(e){return e.sandOrbit===!0}`（Orbit 服务实例判定）；`new URL(t.backendUrl).host.replace(/[^A-Za-z0-9.-]/g,"_")`（backendUrl 主机名清洗）。
- `proto.cjs`：`ListGrokBotUserStoreFilesResponse`、`GrokBotAgentAccessInviteState`（OPEN/ACCEPTED/EXPIRED/REVOKED）+ `RecipientMatch`（邀请状态机）、收货地址消息（line1/line2/city/region/postalCode/country/name/phone）、`PluginTeamAdminInstallBlockReason`（MCP_ADMIN_POLICY/FIRST_PARTY_ALLOWLIST/TEAM_LIST/SHAREPOINT_TEAM_ONLY）、`expectedCurrentPeriodStartMs`（账期防错位）。
- `proto.cjs`：connector 凭据状态机成形——凭据来源 `per-user / service-account / delegated` 三类，状态 `active / needs-reconnect / turned-off-by-admin / delegator-inactive / delegator-disconnected`，凭据操作 `connect-service-account / use-delegated-auth / replace-delegated-auth / remove-credential`（团队连接器凭据委托管理的完整协议）。
