# Grok Bot 0.78.1

[English](../../../full/grok-bot/2026-10-28_0.78.1.md) | 简体中文 · [精简版 (Highlight)](../../grok-bot/2026-10-28_0.78.1.md) | **完整详情 (Full Detail)**

- **发布日期**：2026-10-28
- **覆盖平台**：`mac`、`win`、`ubuntu`
- **版本摘要**：团队 Bot 凭据保险库（Vault）UI 落地

## 变更要点

- **功能**：team-bot-vault / team-bot-vault-access / team-bot-vault-slot / grok-bot-vault-login-dialogs 渲染组件（Bot 以保险库槽位存取凭据，登录对话框）。
- **协议/主进程**：`DeleteGrokBotVaultCredentialRequest`（按 agent_id 删除保险库凭据）进入主进程接口；`GrokBotBoxIntent.COMPUTER_OPEN`；Tailscale 报错文案补全（"Open the Tailscale plugin in Grok Bot to see how to fix it." 等）。
- **UI**：bot-manage-section、team-bot-setup-dialog-shell。
- **底层**：无依赖/原生模块变化。


## 代码与协议细节

- `main-app.cjs`：仅重排。
- `main-core.cjs`：隔离 user-data 目录逻辑重构——旧的内联 `app.setPath("userData"/"sessionData")` 抽成 `_Ae(e,t)` + 包装函数 `fY(e,t)`（先 `ku(t)` 校验、写回环境变量缓存、打印 `[sand] using isolated user-data dir: ${n}`）。
- `proto.cjs`：新枚举 `GrokBotUserFormVaultTarget`（PERSONAL/AGENT）——表单自动填充写入哪个保险库。
- `renderer/index.eager`：纯新增 `listTeamBotVaultLogins/putTeamBotVaultLogin` IPC 包装（团队 Bot 保险库登录凭据的列表/写入，0.78.0 asar 中无此符号）；useDraft 编辑草稿 hook 重构（setDraft/setIsFocused 缓存结构）。

## 技术变更明细

- **各子系统变更文件分布**：`dist/deps`（8 个文件）、`dist/electron-main`（4 个文件）、`dist/renderer`（3 个文件）、`dist/native`（1 个文件）、`dist/local-exec-daemon`（1 个文件）、`package.json`（1 个文件）、`dist/electron-preload`（1 个文件）、`dist/node-agent-coordinator`（1 个文件）。
- **新增渲染层组件与资源模块**：`Button`、`CompositeRoot`、`bot-manage-section`、`grok-bot-vault-login-dialogs`、`group-chat-connect-waiting`、`index.eager-platform`、`shiki-grammars`、`shiki-incremental-tokenizer`、`team-bot-setup-dialog-shell`、`team-bot-vault`、`team-bot-vault-access`、`team-bot-vault-slot`。
