# Grok Bot 1.1.0

[English](../../../full/grok-bot/2026-11-14_1.1.0.md) | 简体中文 · [精简版 (Highlight)](../../grok-bot/2026-11-14_1.1.0.md) | **完整详情 (Full Detail)**

- **发布日期**：2026-11-14（北京时间各端包时间：Linux AppImage `03:15`、Windows `03:28`、macOS `08:35`、Ubuntu/Debian `.deb` `08:42`）
- **覆盖平台**：`mac`、`win`、`ubuntu`
- **版本摘要**：`1.1` 系列首个功能大版本：`GrokBotService` 扩充至 515 个方法（`+22 / −0`），新增 4 个 ConnectRPC 服务（`7 → 11`）与 258 条 Protobuf 消息（零字段/枚举删除），上线 YAML Factories 流水线、Cloud Agent 应用与页面发布平台、Cursor ↔ xAI 账号团队合并、Local Pitman 本地会议助手与 Spotlight 元素拾取器、STT 说话人分离，并将 Electron 升级至 `43.8.9`

## 概述

`1.1.0` 基于统一构建提交 `83d46d618ef4c12afa17edd8e3c29d6caf046d17`（`sandBuiltAt`：`2026-11-13T19:10:26.558Z`）在 `mac`、`win`、`ubuntu` 三端同步发布，协议层呈纯加法演进。`dist/electron-main/proto.cjs` 由 `1,589,070` 增至 `1,730,908` B（`+141` KB，`+8.9%`；macOS、Windows、AppImage 与 `.deb` 四份产物 SHA-256 均为 `e9139710fe188967…`），消息描述符 `2,829 → 3,087`（`+258 / −0`）、枚举 `411 → 470`（`+59 / −0`）、`aiserver.v1.GrokBotService` `493 → 515` 个 Unary 方法（`+22 / −0`）、ConnectRPC 服务定义 `7 → 11`（新增 `AppPublishService`、`UnifiedDashboardService`、`XaiAccountClosurePartnerService`、`XaiUnificationPartnerService`），同时桌面运行时 Electron 由 `43.8.4` 升级至 `43.8.9`（Chromium `150.0.7871.250`）。

## 核心新增功能

- **运行时、打包产物与桌面子系统升级**
  - **Electron 升级至 `43.8.9`**（自 `43.8.4` 升级，Chromium `150.0.7871.250`），新增 AppImage 更新签名校验（`verifySignature`），`package.json` 新增 `@anysphere/cursor-icons`。
  - 核心模块体积变化（`1.0.3 → 1.1.0`）：`main-app.cjs` `3,606,029 → 3,770,636` B（`+165` KB）、`proto.cjs` `1,589,070 → 1,730,908` B（`+141` KB）、`node-agent-coordinator/main.cjs` `1,379,189 → 1,428,758` B（`+50` KB，`+3.6%`）、`main-core.cjs` `1,179,502 → 1,214,411` B（`+35` KB）、`preload.cjs` `149,773 → 160,046` B（`+10` KB，主边缘条目 `658 → 701`，`+46 / −3`）；`local-exec-daemon/main.cjs` 进一步缩减 `3,539,924 → 3,472,851` B（`−67` KB，`−1.9%`），`messages-worker.cjs`（`121,022` B）逐字节不变。
  - 新增 **Spotlight 屏幕元素拾取覆盖层**（`dist/electron-preload/preload-spotlight-element-pick-overlay.cjs` `17,989` B + `element-pick-overlay.html` + `spotlight-element-pick-overlay` 渲染包）与主进程**本地会议录制模块**（`dist/electron-main/local-meeting-recorder.cjs` `135,396` B）；更新原生模块 `sand_notification_settings.node`（新增 macOS 触控板抬指监听 `watch_scroll_finger_lift`）与 `onepassword-connection-service.cjs`（`107,751 → 107,785` B）。
- **Factories（YAML 声明式多步骤 Agent 流水线）**
  - 新增 4 个 `GrokBotService` RPC：`ListGrokBotFactories`、`SaveGrokBotFactory`、`RunGrokBotFactory`、`DeleteGrokBotFactory`，以 `GrokBotFactory{1 id, 2 yaml}` 承载多步骤与调度定义，在 `main-core.cjs` 内置步骤上限、名称长度与定时表达式校验，配齐运行/删除结果枚举（`ALREADY_RUNNING`、`REFUSED` 等）、代理工具 `UpdateFactory`、运行时能力位 `helper_and_dev_creation_enabled`、`chunk-factory-layout` 界面、4 个 preload 遥测方法及特性开关 `grok_bot_factories`。
- **Cloud Agent 应用托管、`AppSecrets` 与页面发布审查体系**
  - 新增 `aiserver.v1.AppPublishService`（约 60 条新消息，涵盖 `PublishApp`/`UnpublishApp`、`AppDeployment`、`AppServedTarget`、`AppAccessList`、`AppVisibility`、`ResolvePublishedApp`/`ResolveDraftApp`、`GetAppsEligibility`、`CreateAppsGateTicket`）及 preload 侧 8 个 `CloudAgentPublish*` 方法（支持 `requireConfirmationForUpdates` 与 `muteRedeployPrompts`）。
  - 新增 **`AppSecrets` 密钥管理子系统**（`Create/List/Set/Delete/Bind/Unbind/Widen/Sync/Decline/Request/ApplyAppSecrets`、`AvailableAppSecret`、`AppSecretScope`、`BindingNames`、`SyncOutcome`）。
  - 新增 **Page 页面发布、安全审查与分享体系**（`ProposePublish`、`Confirm/DismissPublishProposal`、`PublishReview`、`PublishReviewFinding`、`Request/CancelReviewOverride`、`Get/UpdatePublishedPageShare`、`PageShareRoster`、`OrganizationAudience`、`PrepareDefaultBranchPublish`、`PublishMerge`、`MergeRepublish`）。
- **Cursor ↔ xAI 账号与团队统一（Unification）**
  - 新增 `UnifiedDashboardService`、`XaiUnificationPartnerService` 与 `XaiAccountClosurePartnerService`：支持团队合并与结账结算（`Start/Get/CancelCursorTeamMerge`、`Prepare/FinalizeCursorTeamMergeCheckout`、`CreateUnifiedDashboardTeam`、`Add/List/RemoveCursorTeamMember`、`GetTeamMembersResponse.xai_team_membership_holds[]`）、购后账号统一（`CompleteXaiUnificationAfterPurchase`）、销户与恢复（`XaiCloseAccount`、`XaiReopenAccount`）、`GetSandAccessStatusResponse.account_merge_prompt`、`TeamGroup.cursor_enabled`、`CursorGroupAccessMode`、preload `getCursorStorageAllowed` / `reportXaiCommerce` 以及允许域名 `x.ai`。
- **账户手机验证、短信表单、手机扫码配对与消费管控**
  - 新增账户手机号绑定 RPC（`SendGrokBotAccountPhoneCode`、`ConfirmGrokBotAccountPhoneCode`、`GetGrokBotAccountPhoneStatus`，含 `tries_left`、`retry_after_ms`、`created_account`、`texting`）、短信验证码 Owner 认证与表单提交（`StartFormLinkOwnerCode`、`SubmitTextedFormLink`、`StartPageOwnerCode`，开关 `grok_bot_phone_verification_card`）及手机 App 扫码绑定桌面端流程（`getPhoneAppQrUrl`、`chunk-phone-app-qr-sheet`、`chunk-sms-qr-code`）。
  - 新增消费自动批准与限额接口 `GetGrokBotPurchaseAutoApprove`、`SetGrokBotPurchaseAutoApprove`、`SetGrokBotPurchaseSpendLimit`（`GrokBotPurchaseAutoApprove{enabled, decided, spend_limit{amount, currency}, spend_limit_is_default}`），扩展 `GetSandUsageStatusResponse`（`prepaid_balance_unknown`、`managed_by_team_admin`、`plan_upgrades[]`、`would_refuse_send`、`additional_usage_limit`），在全部 37 种内嵌语言包中新增 `"Approve in the X app"` 审批文案，并上线 `grok_bot_purchase_auto_approve`、`grok_bot_prepaid_auto_top_up_default`、`grok_bot_x_money_spend_challenge_desktop`、`grok_bot_link_token_charged_via_link_desktop` 与 `grok_bot_desktop_free_user_upgrade_cta` 开关。
- **企业网络黑名单、Tailscale 出口节点、强制沙箱与 MCP 插件治理**
  - `GetTeamAdminSettingsResponse` 新增字段 `108 organization_network_blocklist`（`TeamOrganizationNetworkBlocklist`，支持 `site` 与 `address` 两类强制拦截规则），新增团队级 Tailscale 出口节点下发（`TeamTailnetExitNode{magic_dns_suffix, node_id, node_name, cidrs[]}`、`exit_nodes`、`GrokBotTurnFailureCode.TAILNET_BOX_REFUSED` / `TAILNET_VIEWER_BOX_REFUSED`），以及强制沙箱模式 `SandboxingMode.ENFORCED`（`sandboxing_enforced_available`）、`EnsureSandBoxResponse.credentials_refresh_after_seconds` 与 `BackgroundAgentSettings.reject_static_pool_credentials`。
  - 新增插件级策略封禁 `GrokBotAgentPlugin.policy_block`、`McpArgs.refuse_saved_secrets`、临时插件同步令牌铸造 `MintSandBoxPluginSyncGitToken`、管理端 `off_mcp_server_rules_allowed`、Passkey 注册码校验 `verifyPasskeyEnrollmentCode`、最低年龄准入拦截枚举 `SandAccessBlockReason.UNDER_MINIMUM_AGE`，以及按开关解锁 MCP 应用 iframe `eval` 的 `grok_bot_mcp_app_unsafe_eval_desktop`（`allowEval`）。
- **STT 说话人分离、Local Pitman、任务↔转写关联、SCM 接入与代理工具**
  - 服务端语音转写（STT）新增说话人分离支持（`SttConfig.diarize`、`SttServerMessage.turns[]` `SttSpeakerTurn{speaker, text}` 与 `session_started`），而实时语音通话 `MintSandVoiceCallSecret` 及语音工具参数 schema 保持逐字节不变。
  - 新增本地会议助手 RPC `StartGrokBotLocalPitman` 及 preload 侧 5 个启动/停止/授权方法（开关 `sand_pitman_local`）。
  - 打通任务跟踪与会话转写双向关联（`GrokBotAgentTask` 新增 `legacy_task_id`、`tag_ids[]`、`pull_requests[]`、`transcript_start_seq`、`transcript_end_seq`；`ListGrokBotTranscriptEntriesRequest.task_id`；`GrokBotTranscriptEntry.task_numbers[]`），新增 GitHub / SCM 连接流程（`Prepare/CompleteGithubConnectFlow`、`GetScmConnectionStatus`、preload `prepareScmConnect`/`completeScmConnect`/`readScmConnections`）、线程化回复与推理旁白（`ConversationMessage.thread_id`、`SendMessageArgs.to_main_chat`、`ThinkingMessage.narration`、`SideChatInfo.subagent_type`）、`ExecServerMessage` 布尔位 `record_agent_view`（`58`）与 `refuse_unread_changes`（`59`）、`AdminExplainGrokBotSlackAccess`、`ListGrokBotOutcomes`/`ListGrokBotUpdates`、6 个 `*GrokBotChangelogEntry*Internal` 内部运营 RPC，以及 `+8` 个代理工具（`194 → 202`：`MacReadPhotos`、`ReadGroupChat`、`SendOrderUpdate`、`SendPlaces`、`SendShoppingProducts`、`UpdateFactory`、`UpdateTrackedTaskTags`、`UpdateVoiceSettings`）。
  - **`UserComputer` 与桥接协议零破坏兼容**：`GrokBotUserComputerRequestFrame` 与 `GrokBotUserComputerResponseFrame` 在 `proto.cjs`、`node-agent-coordinator` 与 `local-exec-daemon` 三处包内逐字节一致，全量协议 0 字段删除、0 枚举值删除。
