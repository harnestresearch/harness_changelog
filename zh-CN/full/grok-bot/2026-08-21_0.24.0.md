# Grok Bot 0.24.0

[English](../../../full/grok-bot/2026-08-21_0.24.0.md) | 简体中文 · [精简版 (Highlight)](../../grok-bot/2026-08-21_0.24.0.md) | **完整详情 (Full Detail)**

- **发布日期**：2026-08-21
- **覆盖平台**：`mac`、`win`
- **版本摘要**：基线版本：Grok Bot（内部包名 sand，作者 SpaceXAI）初始桌面版本——单 bundle 主进程的桌面 agent，已具备沙箱执行、MCP、Slack/Google 集成与模板商店雏形

## 变更要点

- **功能**：初始功能域由 82 个依赖中的 33 个 `@anysphere/*` 内部包勾勒：agent 运行时全家桶（agent / agent-client / agent-core / agent-exec / agent-kv / agent-store-sync / agent-summarization / agent-transcript）、聊天推理（chat-inference + chat-inference-proto）、本地与 MCP 执行（local-exec / shell-exec / mcp-agent-exec / mcp-core）、grok-bot 本体与 harness、虚拟文件系统（virtual）、模型选择（model-selection）、Cursor 配置与插件（cursor-config / cursor-plugins）、dune、context-rpc、redacted-protos，另有 @sand/client、@sand/shared。集成能力已含 Google Workspace 全家桶 OAuth scope（gmail.\* / calendar.events / drive / documents / spreadsheets / presentations）、Slack、MCP 服务器目录（memory/notion/playwright/salesforce/slack/stripe/telegram/todoist/zoominfo 等），以及 connector、marketplace、computer-use、secret-store/user-secrets、box 沙箱（readHostSettingsFromBox 等）等能力域的雏形。
- **协议/主进程**：主进程为单个 8.7MB 压缩的 `dist/electron-main/main.cjs`，配合 electron-preload、dist/host（agent-isolation worker、extensions：box-store-sync/content-search）、local-exec-daemon、node-agent-coordinator、native（cursor-proclist 原生进程列表模块）。RPC 走 connectrpc + protobuf（aiserver.v1 / agent.v1），遥测为 statsig + sentry + opentelemetry。
- **UI**：React 19 + tiptap 富文本编辑器 + lingui i18n + stylex；markdown 渲染带 KaTeX/mermaid，文档解析含 xlsx/mammoth(docx)/pdfjs-dist。
- **底层**：Electron 应用（sandTrack: stable 渠道），Google s2 favicons 图标源，cursor.com 主页。
