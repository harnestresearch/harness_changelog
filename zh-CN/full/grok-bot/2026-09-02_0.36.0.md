# Grok Bot 0.36.0

[English](../../../full/grok-bot/2026-09-02_0.36.0.md) | 简体中文 · [精简版 (Highlight)](../../grok-bot/2026-09-02_0.36.0.md) | **完整详情 (Full Detail)**

- **发布日期**：2026-09-02
- **覆盖平台**：`mac`、`win`、`ubuntu`
- **版本摘要**：多 agent 房间（群聊）、Agent 自动化列表与预置职能角色（客服/财务/招聘）

## 变更要点

- **功能**：房间/群聊（`CreateGrokBotRoom`、`SetGrokBotRoomMembers`）；Agent 自动化（`GrokBotAgentAutomation`、ListGrokBotAgentAutomations、GrokBotAgentKind）；预置职能角色类别 customer-support、ops-finance、recruiting-people；私有推理配置（`PrivateInferenceModel`/`PrivateInferenceSettings`/`PrivateInferenceReasoning`）；通话被打断处理（caller-interrupted）；语音音色选择界面（voice-picker-dialog）。
- **协议/主进程**：`PrivateWorkerPoolRequestCounts`（私有 worker 池计数）；"Sand machine roster unread"（roster 未读上报）。
- **UI**：voice-picker-dialog、新 agents/view/layout 面板；provider-cloud-agents 组件移除（并入主界面）。
- **底层**：无依赖变化；本地浏览器 Cookie 枚举授权文案（"The user did not allow listing which local browser cookies are available."）与磁盘用量审计描述（"Audits disk usage on Grok Bot"）出现。


## 代码与协议细节

- `main-app.cjs`：本地工具权限写入加机器绑定门禁——`updateMachineLocalToolPermission` RPC 返回后，本地 settings 写入改为 `if(r===await e.getMachineId()&&e.settingsStore.setLocalToolPermission(s))`（0.35.0 为无条件写入，多机账号下避免把别机的权限写进本机）；新增 IPC `getLocalToolPermissionGeneration`与 `setLocalToolPermission` 暴露。
- `proto.cjs`：多 agent 房间协议：`CreateGrokBotRoomRequest` 补 `kind` 枚举（`GrokBotAgentKind`: AGENT/ROOM）与 `member_agent_ids`（repeated），新增 `SetGrokBotRoomMembers`。
- `proto.cjs`：私有推理配置：`PrivateInferenceModel`（models/default_model_id/can_enable）、`PrivateInferenceSettings`，并在两个配置消息挂 `private_inference` 字段（no:68/no:70）。
- `proto.cjs`：Agent 自动化：`GrokBotAgentAutomation`、`ListGrokBotAgentAutomations`；hooks 扩展 `team_owned_hook_steps`（团队级 hook）与 `configured_variable_keys`。
- `main-app.cjs`/`proto.cjs`：预置职能角色类别 `customer-support`/`ops-finance`/`recruiting-people`；新增实验键 `grok_bot_stable_prompt_prefix`、`sand_less_subagent_fanout`、`grok_bot_server_automations`。
- 纯删除：实验门 `sand_computer_use_playwright` 与 `nudge_main_agent` 移除。
