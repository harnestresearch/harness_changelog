# Grok Bot 0.37.0

[English](../../../full/grok-bot/2026-09-03_0.37.0.md) | 简体中文 · [精简版 (Highlight)](../../grok-bot/2026-09-03_0.37.0.md) | **完整详情 (Full Detail)**

- **发布日期**：2026-09-03
- **覆盖平台**：`mac`、`win`
- **版本摘要**：接入 X Money 连接器与 mcp.money.x.com MCP 服务，新增邮件/Slack 草稿发送协议与多 agent 房间回合机制

## 变更要点

- **功能**：X Money 集成（connector provider `"x-money"`，静态客户端注册、仅后端隧道）；Grok Bot 官网下载入口（`https://cursor.com/download/bot`，配合 `grokbot://` 深链的分享/引导卡片）；连接器卡片展示。
- **协议/主进程**：MCP 端点 `mcp.money.x.com` / `mcp.money-staging.x.com` / `mcp.money-dev.x.com`；`aiserver.v1.SendGrokBotDraft` / `DiscardGrokBotDraft`（携带 `GrokBotEmailDraft`（from/to/cc/subject/body）与 `GrokBotSlackDraft`（workspace/target/body））；`DeliverGrokBotRoomMemberTurnResult`（房间成员 agent 回合结果投递，含 nonce 防重放）；`Get/SetGrokBotUserMcpSettings`（用户级 MCP 服务器设置云端同步）；`GetGrokBotMarketplaceListingSourceTemplateInternal`（市场 listing 源码模板）；anyrun 侧 `PersistedCdcVmSnapshotSource` / `PersistedCdcFileChunk` / `SnapshotStartupProfileCommand`（云端盒子 VM 快照持久化 + 启动命令画像）。
- **UI**：新增 `connector-card-view`（连接器卡片）、`listener-integrations`（监听器集成）组件。
- **底层**：依赖数不变（83）；移除旧标识 `computer-use-mac`、`automation-message`、`local-build`。


## 代码与协议细节

- `main-app.cjs`：MCP 服务器设置云端同步落地——新增 `pushServerSettings()`（0.36 中 0 处 → 7 处）与 `serverMcpSettings()` 读取器，同步 ledger 新增 `readMany()` 批量读取 + `BMt()` include/exclude 最长前缀匹配（`Math.max(-1,...t.startsWith(s).map(s=>s.length))`，命中 include 且前缀不短于 exclude 的键才推送），失败时 catch 标记 `"remove-sync"`；proto 侧消费 `getMcpCustomInstructionsByServerId` / `getMcpDisabledToolsByServerId`；删除 `automation-message` 通知类型的整段参数校验（`typeof t.automationId==="string" && ...`）。
- `main-core.cjs`：本地工具授权持久化——新增 `getLocalToolApprovalsPath()`（`local-tool-approvals.json`）、`clearLocalToolApprovals`（0→4 处）、`onLocalToolPermissionNever` 回调（0→3 处），即"不再询问"时清空已存的本地工具授权。
- `chrome-import-worker.cjs`：新增 `chromeUtcNow()` = `BigInt(Date.now()) * BigInt(1e3) + J`，微秒级 UTC 时间戳。
- `proto.cjs`：新增用量字段 `spend_cents` / `included_spend_cents` / `overall_spend_cents` / `fast_premium_requests`；盒子设备字段 `is_root_device` / `jail_relative_path`；账号字段 `is_pooled_plan` / `has_token_based_pricing`、`first_project_onboarding`、`active_group_member_id`；OAuth 字段 `oauth_authorize_url` / `approval_request_filed` / `app_removed`（0.36 均为 0 处）；同时从两条消息上移除 `private_inference` 字段（0.41 才回归）。
