# Grok Bot 0.41.0

[English](../../../full/grok-bot/2026-09-04_0.41.0.md) | 简体中文 · [精简版 (Highlight)](../../grok-bot/2026-09-04_0.41.0.md) | **完整详情 (Full Detail)**

- **发布日期**：2026-09-04
- **覆盖平台**：`mac`、`win`
- **版本摘要**：Canvas 画布共享落地（@anysphere/canvas-shared，bundle-v1 格式 + canvas-frame 渲染）与 AgentDefinition 蓝图协议

## 变更要点

- **功能**：Canvas 画布分享/渲染——`decodeSandCanvasBundle` 支持 `bundle-v1` 格式（升级自 `legacy-esm`），`canvas-frame` 服务渲染 gzip 画布 bundle（含 data.json 解析、404/422 主题化响应），并为画布框架配置完整 CSP 指令集（`default-src` / `script-src` / `connect-src` / `frame-src` / `worker-src` 等）；Agent 定义蓝图 `GrokBotAgentDefinition`（含 Identity/Session/Skill/MemoryShard/Slack/McpServer/AgentRef/TemplateImport 子结构，admin 可读取）；GitHub App 安装租户授权（`Grant/RevokeGithubInstallationTenant`，支持 GHE）；用户级预付费计费（`CreateUserPrepaidTopUp`、`GetUserPrepaidBilling`、`SetUserPrepaidBillingMode`、`SetUserPrepaidAutoTopUp`）。
- **协议/主进程**：`PrivateInferenceSettings`（私有推理开关）；`EventCodeCreditDestination`（活动码积分去向：USAGE_GRANT / STRIPE_CUSTOMER_BALANCE）；`GetGithubInstallationTenantGrants`；anyrun 侧 `BearerEgressProxyAuth`（出口代理 Bearer 鉴权）；头像链路键 `roster-avatars` / `roster-photo-fetch` / `sand-avatar`；凭据类型常量 PASSWORD/PASSPHRASE/CREDENTIAL(S)。
- **UI**：无重大新增（仅 mermaid 图表分块文件名轮换）。
- **底层**：新增依赖 `@anysphere/canvas-shared`（依赖数 83→84）；上一版引入的实验键（account-slot/bot-templates/voice-settings 等）在本版主进程 bundle 中消失（后于 0.44 回归，属 bundle 迁移）。


## 代码与协议细节

- `main-app.cjs`：真实新增为 canvas 分享 store ID 校验——`she(e)` 使用 `/^store-[0-9a-f]{8}-[0-9a-f]{4}-[1-57][0-9a-f]{3}-[89ab][0-9a-f]{3}-[0-9a-f]{12}$/i`，紧邻 `isCanvasShareBundleV1` 与 bundle 根路径拼接；同处伴随 UUID v1–5/7 校验正则。
- `main-core.cjs`：头像链路键常量 `sand-avatar` / `roster-avatars`（0→1 处）及 32 位 hex ID 校验 `/^[0-9a-f]{32}$/`、`x-amz-`/`x-id` 头部过滤正则；Sentry DSN 组装 `dsnFromComponents`（publicKey/pass/host/port/path/projectId）。
- `proto.cjs`：新增 `RepoArchiveEnvironmentScope`（selector + `include_sources`，0→2 处）与仓库归档 `repos`/`can_enable` 列表；`GrantGithubInstallationTenantResponse`（0→5 处，GitHub App 安装租户授权）；`private_inference` 字段回归（no:68/70，0.37 移除后恢复）；BugBot 设置字段（`run_only_once`/`suppress_no_bugs_comments` 等）为重排对齐。
- `renderer/*`：mermaid/shiki 库 chunk 引用轮换，无实质变化。
