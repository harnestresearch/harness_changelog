# Grok Bot 0.72.0

[English](../../../full/grok-bot/2026-10-18_0.72.0.md) | 简体中文 · [精简版 (Highlight)](../../grok-bot/2026-10-18_0.72.0.md) | **完整详情 (Full Detail)**

- **发布日期**：2026-10-18
- **覆盖平台**：`mac`、`win`、`ubuntu`
- **版本摘要**：大型版本（asar 668→874 文件）：三个新原生模块带来设备认证、卡片 OCR 与窗口捕获，落地菜单栏托盘 Bot 头像系统，并大幅扩张连接器目录

## 变更要点

- **功能**：设备级试用领取——`ClaimSandTrialWithDeviceAttestation`（含 iOS DeviceCheck 通道），配合 `token-mint`/`trial-claim`/`trial-bundle-id` 流程与请求头 `x-sand-devicecheck-supported`、`x-sand-hv-vmm-present`（上报是否运行在虚拟机，反滥用）；支付卡金库（vault）——`grok_bot_vault`/`grok_bot_vault_cards`/`grok_bot_vault_card_scan_on_device` 门 + `card-photo-scan`/`card-image-screen`（仅 darwin，截图/照片识别卡片，OCR 词汇含 CARDHOLDER/CITIBANK/BARCLAYS/CASHBACK 等），proto 新增 `XaiCommerceBearerPurpose=BROWSER_COMMERCE/PREPAID_TOP_UP`（xAI 商务支付令牌）；菜单栏托盘 Bot 头像系统（24 种造型×表情 PNG 资源，roster 头像拉取，`blink-*`/`glance-left/right-up` 眨眼瞥视动画带 gaze 坐标）；REST-MCP 托管连接器（`api.cursor.com/rest-mcp/<provider>/mcp`，首批 gmail/outlook/google_calendar，sendTools 含 send_message/send_email 等）；Mermaid 图表渲染（dagre/graphlib/gitgraph/eventmodeling 等）。
- **协议/主进程**：新端点 `https://api.stqa.cursor.sh` + `https://portal.stqa.cursor.sh`（id=2 的第二后端环境）；新增设置键 `sand-devicecheck`、`sand-window-capture`、`sand-gpu-info`、`card-photo-scan`、`card-image-screen`、`menubar-tray`、`capture-ready`、`displays-changed`/`display-added`/`display-removed`、`token-mint`、`trial-claim`、`rest-mcp`、`google-calendar`、`outlook-calendar`、`quickbooks-online`、`screen-saver`、`quit-cause`、`support-probe`、`cloud-agent-update`、`listing-watch`、`auth-watch-note`、`thinking-note`、`session-created`、`session-end-spill`；连接器目录大批新增 MCP 主机（mcp.api.getguru.com、mcp.api.harmonic.ai、mcp.incident.io、mcp.mail.superhuman.com、mcp.quickbooks.intuit.com、mcp.public-api.etoro.com、mcp.slides.com、mcp2.readwise.io、mcp.ws.sonos.com、mcp.tryprofound.com、mcp.futunn.com、mcp.sandbox.airwallex.com 等）及 Amex 业务权限域（`foundations.tools.bi-dashboard/businessreports/companyprofile.*`、`payroll.tools.employee/employer.*`、`lending.tools.servicing.read`、`contact.tools.customer.*`）；OAuth 错误分类表（access_blocked/fresh_token_rejected/rate_limited 等）与 `CheckHttpMcpStatusRequest`；开发/实验 bundle id `com.anysphere.sand.dev`/`com.anysphere.sand.lab`。
- **UI**：renderer 新增 `bot-configure-dialog`、`bot-share-control`、`bot-store-files-library`、`connector-card`/`connector-data-center`/`connector-sign-in-copy`、`mcp-connector-status`、`desktop-mount-capture-overlay`（屏幕捕获挂载遮罩）、`elevated-draft-fields`、`library-visual-viewer`、`fullscreen-file-viewer`、`card-field`。
- **底层**：新增依赖 `@anysphere/card-photo-text`、`@anysphere/slack-app-setup`、`mdast-util-from-markdown`、`sand-card-text-recognition`（原生 OCR .node）、`sand-devicecheck`（原生 Apple DeviceCheck .node）、`sand-window-capture`（原生窗口捕获 .node）；asar 新增 744 文件（大量托盘头像资源）；Electron 版本不变。


## 代码与协议细节

- `main-app.cjs`：附件分块读写管线——`readAttachmentChunk` RPC 与 `if(ge>X)return{kind:"too-large",size:ge,…}` 尺寸守卫、按块 `Buffer.alloc` 读取，配套 `readAttachmentChunkIfAwake/uploadAttachmentChunk`；新增工具访问级别表 `getAgentTranscript:"background", openAgentWindowed:"background", openAgentTail:"person", sendPrompt:"person", promptAcceptanceStatus:"person", respondToWidget:"person", resolveAutoReviewApproval:"person"`（区分后台可执行与需真人在场的操作）；设备级试用认证 `ClaimSandTrialWithDeviceAttestation`（×2）与请求头 `x-sand-devicecheck-supported`；`menubar-tray`（×3）；post_connect 断线看门狗遥测（`Zct` 校验 phase/stallMs/keys/clicks/moves/inBytes）；zod v4 升级特征串 "Async schemas not supported in object keys currently"。
- `main-core.cjs`：系统代理解析实际在本版落地——`/(?:HTTP\/1\.[01]|Proxy response\()(\d{3})\b/`、`/proxy tunnel timed out/`、`/^(?:ERR_TLS_|ERR_SSL_|UNABLE_TO_|SELF_SIGNED_…)/` 等 errno/TLS 分类正则与 `reportDesktopSystemProxy` 上报；退出原因观测表 `u4={none_observed,wm_close,sc_close,renderer_close_window}`。
- `main.cjs`：新增 deps 加载器 `process.env.NODE_PATH=__depsDir+…; __mod.Module._initPaths()`——为 dist/deps 下新增原生模块（devicecheck、卡片 OCR、窗口捕获）铺路。
- `proto.cjs`：新增 `McpSignOutReason` 枚举（EXPIRED/REVOKED/ORGANIZATION_POLICY/MFA_REQUIRED/ADMIN_BLOCKED/ACCOUNT_DISABLED/CLIENT_INVALID/ACCOUNT_RESTRICTED/PROVIDER_UNAVAILABLE…）；Bot routine/automation 模型（`routineId/triggerDescription/triggerPresentationJson/schedule/isEnabled/runAsUserId/runAsIsViewer`）。
- `onepassword-connection-service.cjs`：域名合法性正则 `^[a-z0-9](?:[a-z0-9-]{0,61}[a-z0-9])?` 及 RPC 状态码列表整理。
