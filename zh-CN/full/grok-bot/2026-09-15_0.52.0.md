# Grok Bot 0.52.0

[English](../../../full/grok-bot/2026-09-15_0.52.0.md) | 简体中文 · [精简版 (Highlight)](../../grok-bot/2026-09-15_0.52.0.md) | **完整详情 (Full Detail)**

- **发布日期**：2026-09-15
- **覆盖平台**：`mac`、`win`
- **版本摘要**：连接器/插件设置页成形：新增 @anysphere/marketplace-category，连接器卡片、原生插件详情、Slack 安装流程等一批设置组件落地

## 变更要点

- **功能**：设置中新增完整的"连接器"（connector）与插件管理界面：connector-card-view、native-connector-card、mcp-connector-status、native-plugin-detail/native-plugin-state、plugin-detail-view，以及 provider-credentials/credentials-section 凭证管理区；team-bot-slack-flow-dialog（Slack 安装向导对话框）替代旧的 team-bot-context-ingest。
- **协议/主进程**：新增大量 GrokBot 管理端 RPC：AdminGetGrokBotAgentDefinition、AdminDeleteGrokBotAgent、AdminForceDeleteGrokBotSessionBox、AdminForceRecreateSandBox、ActivateGrokBotTemplateVersion、AddGrokBotRoomPeople、AdminCommandDenylist；云沙盒存储分片写入 AbortSandBoxStoreMultipartWritesRequest/Response；GetSandTrialClaimStatusResponse.SandTrialClaimStatus（试用申领状态）；GrokBotRoomMemberTurnMessage.SpeakerKind。新增会话地址类型 `handoff-resume`（与 turn、voice-call 并列，用于接力恢复通话/会话）及请求头 `x-cursor-client-os`；遥测事件 sand.cloud_agent.artifact_clicked / artifact_load_failed。
- **UI**：AvailableModelsResponse 新增 ConfirmationDialogue、ModelPickerBadge、命名模型视图配置（模型选择器确认对话框与徽章）；settings-row、scroll-pane 通用组件更新。
- **底层**：新增依赖 `@anysphere/marketplace-category`（插件市场分类）；asar 文件数 504→514；大量 UI 文案多语言化。


## 代码与协议细节

- `main-app.cjs`：新增 GrokBot 服务条款模块 `{fetchGrokBotTermsRecord, markGrokBotTermsSeen}`（条款记录拉取/"已读"标记）；新增语音会话地址类——`Xj="voice:"` 前缀、`wmt=["turn","voice-call","handoff-resume"]`，`static address(t){return "voice:"+t}` / `callIdOf` / `isOwnerStarted`（handoff-resume 会话地址即由此落地）；新增 `addRoomPeople` RPC（`addGrokBotRoomPeople({agentId, userIds})`，失败抛 `"AddGrokBotRoomPeople returned no room"`）；暴露 `listGrokBotEmailInboxes` / `createGrokBotEmailInbox`；新增错误类 `SandGenerateImageError`，构造参数 `{statusCode, contentSafetyBlocked}`（生图错误携带 provider 状态与内容安全拦截标志）；新增 `sendTaskStampsTheLoopOnTheBackend(t,r)=t.kind==="package" && t.loop==="temporal" && r===pt`（temporal 循环打包任务的特定工具调用改走后端 harness）；auth 状态读取前先 `teamPolicy.load()`（失败上报 "cursor-auth"/"auth-status-read"）；删除一批旧 UI 状态常量（`["approved","denied","always"]`、`["up","down","submit","revert"]`、`"auto-review/stale"` 等）。
- `main-core.cjs`：附件类型识别 `z4(e)` 按 mimeType 分流为 `{kind:"image"|"video"|"document"}`；新增错误 `SAND-E0220 credentialSubmitFailed`（"Browser credential fill wrote the password but the sign-in form could not be submitted safely, so the filled values were cleared..."——浏览器代填密码后无法安全提交表单）。
- `proto.cjs`：proto 全面重新生成（741KB→473KB），对应版本级新增的 GrokBot 管理 RPC 与字段重排。
