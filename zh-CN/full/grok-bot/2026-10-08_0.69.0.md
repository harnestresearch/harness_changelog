# Grok Bot 0.69.0

[English](../../../full/grok-bot/2026-10-08_0.69.0.md) | 简体中文 · [精简版 (Highlight)](../../grok-bot/2026-10-08_0.69.0.md) | **完整详情 (Full Detail)**

- **发布日期**：2026-10-08
- **覆盖平台**：`mac`、`win`
- **版本摘要**：Microsoft Teams 集成正式落地（Teams 应用安装/DM/群聊/线程），工具权限三态模式与本地工具 scope 体系、日历重复事件校验齐备

## 变更要点

- **功能**：Teams 集成：AddGrokBotTeamsAppToTeamRequest（agent_id+team_id，返回 failure_reason）、消息类型 TEAMS_DM / TEAMS_GROUP_CHAT / TEAMS_THREAD、常量 REMOVED_IN_TEAMS、MICROSOFT 枚举与 microsoft-teams-brand-logo。会议加入征询：AdminGetGrokBotMeetingJoinConsent（consent_at_ms）、MeetingJoinAnswer.Remember、通话 nudge 计数（nudgeCount/answeredNudgeCount）。日历重复事件校验（zod）：weekly 必填 daysOfWeek、monthly 需 monthDay 或 weekdayOfMonth 之一、yearly 需 month+monthDay、interval 上限、时区须为 IANA。工具权限模式 GrokBotToolPermission = UNSPECIFIED / ALWAYS_ALLOW / NEEDS_APPROVAL / BLOCKED（UI 对应 approval-mode-switcher）。本地工具权限 scope 表：run-command、send-input、read-file、list-directory、write-file、read-ai-tool-setup（global），read-messages（setting）、send-imessage（subject）、run-phone-tool（call，电话呼叫工具）；应答 allow-once / deny / always / never。
- **协议/主进程**：新依赖 `@anysphere/link-preview`（链接预览独立成包）与 `@tiptap/extensions`；AbortGrokBotAttachmentUploadRequest（附件上传中止）；权限 scope organization.private_inference.manage、grok_bot_agent.share / view；遥测 sand.team_invite.invites_sent / link_copied；设置键 renderer-recovery + crash-loop-dialog（渲染器崩溃循环恢复对话框）、system-proxy、plugin-data、plugin-native、team-fresh、widget-prompt、link-favicon-cache、page-http-4xx/5xx/other、page-timeout、page-network、image-cap/network/timeout、allow-popups、sand-host-bundle、store-unusable、not-in-store、us-east-1；目录常量 CLAUDE_PLUGIN_DATA / CURSOR_PLUGIN_DATA（读取 Claude 插件数据目录，兼容 Claude 插件生态）；1Password OAuth 回归（"1Password connection was cancelled."）；环境变量 SAND_NODE_PROXY_ENV。
- **UI**：grok-bot-secrets（密钥管理页）、top-up-modal-host（充值弹窗宿主）、team-bot-custom-plugins、team-bot-plugins-dialog-list、auto-review-selector、thread-card、gallery-loop 音频、use-clamp-overflow。
- **底层**：依赖 91→93（+link-preview、+@tiptap/extensions）。


## 代码与协议细节

- `main-app.cjs`：computer-use（Opt）MCP app 换 IPC 传输：`ipcMainTransport({ipcMain, senderFacts: D=>({isBoxVncPartition: D.sender.session===t.session.fromPartition(Ij), frameUrl: D.senderFrame?.url??null}), ...})`——按 Box VNC 分区会话与来源 frame URL 鉴权工具调用。
- `main-app.cjs`：Claude 插件生态兼容：目录常量 `zbn=["CLAUDE_PLUGIN_DATA","CURSOR_PLUGIN_DATA"]` 与路径模板 `/(?:CURSOR|CLAUDE)_PLUGIN_ROOT\}/g` 替换、"plugin-data" 键（读取 Claude 插件数据目录）。
- `main-app.cjs`：附件管线重构：`readAttachmentChunk({path, offset...})` 分块读、staged 提交/丢弃（`commitStaged/dropStaged`）、下载失败分类（`invalid-source`、`page-timeout` 等 errorClass + `leg:"download"` 上报）。
- `main-core.cjs`：缩略图服务 `function qw({decoders={}, removeDir=...rm(recursive,force,maxRetries:3)}={})`：注入式解码器 + `createThumbnailFromPath`，按平台返回 `canDecode/decode`；页面加载重试助手 `e1`（`did-finish-load`/`did-fail-load`，忽略错误码 -3 与子 frame）；Sentry 日志/指标批量刷写阈值（累计 8e5 字节或定时 flush）。
- `onepassword-connection-service.cjs`：item 引用模式 `Zt=/^ops_[A-Za-z0-9_-]+$/`、长度上限 4096、操作超时 `sand-onepassword-backend 3e4 / sand-onepassword-mint 24e4`；删除旧错误码条目（SAND-E0409 memorySynthesisInvalidOutput、SAND-E0603/0610/0613 desktop 系列）。
- `proto.cjs`：分片上传会话字段 `limitBytes/uploadToken/sessionExpiresAtMs/partSizeBytes/partCount`；Teams 相关枚举（`AnthropicCyberVerificationStatus/AnthropicEfsStatus/GroupVisibility`）与虚拟机磁盘压力 `diskPressure/recreateInFlight/updatedAtMs`。
