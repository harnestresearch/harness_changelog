# Grok Bot 0.39.0

[English](../../../full/grok-bot/2026-09-03_0.39.0.md) | 简体中文 · [精简版 (Highlight)](../../grok-bot/2026-09-03_0.39.0.md) | **完整详情 (Full Detail)**

- **发布日期**：2026-09-03
- **覆盖平台**：`mac`、`win`、`ubuntu`
- **版本摘要**：桌面实时语音凭证铸造（MintDesktopRealtimeVoiceSecret）、Anthropic EFS 审批流与本地 UI 状态持久化键族

## 变更要点

- **功能**：实时语音模式基建——为桌面语音会话签发密钥（`MintDesktopRealtimeVoiceSecret`），并出现 `voice-settings` 设置键；Messages（iMessage）集成增强——新增 `find-contacts` 工具（映射 `messages/find-contacts`，配合 `snapshot-messages-db`、`copy-attachment` 等工具族按 region 查询联系人）。
- **协议/主进程**：`MintDesktopRealtimeVoiceSecretRequest/Response`；Anthropic EFS 组——`GetOrganizationAnthropicEfsStatus`、`GetTeamAnthropicEfsStatus`、`RequestOrganizationAnthropicEfs`、`RequestOrganizationGroupAnthropicEfs`、`RequestTeamGroupAnthropicEfs`、`ReviewAnthropicEfsRequestInternal`（决策 APPROVE/REQUESTED/REJECTED）；遥测事件 `sand.client.restore`；客户端持久化键族 `account-slot` / `ui-state` / `voice-settings` / `sidebar-sections` / `last-selection` / `last-roster` / `transcript-replicas` / `bot-templates` / `computer-use` 等。
- **UI**：新增印尼语（id）语言资源 `emoji-messages.id`。
- **底层**：无依赖变化。


## 代码与协议细节

- `main-app.cjs`：删除 `bot_template_publish` 模板发布通知的 i18n 文案组与参数序列化（两段，0.38 尚存 → 0.39 归零）；整体移除 `sand_multi_machine_local_exec` feature gate（三处 `checkGate/checkFeatureGate` 调用，0.40 起亦无）；新增 `onLocalExecSupervisorFailed`（0→3 处，上报本地执行 supervisor 失败 reason）与 `SandError.clientRestoreFailed / clientRestoreStuck({stage})`（客户端恢复失败/卡住按 stage 上报遥测）。
- `main-core.cjs`：i18n 语言表新增 Vietnamese（Tiếng Việt）、Indonesian（Bahasa Indonesia）及 `vi-*`/`id-*`/`in-*`/`yue`（粤语变体）归一化分支；新增授权归类 helper——`authorizedByApproval → {kind:"approval"}`、`authorizedByStanding → {kind:"standing"}`（仅 `"global"` 作用域可展示）、否则 `{kind:"none"}`。
- `proto.cjs`：团队消息增 `owning_team_name` / `joined_at` / `archived`；反向清理——移除 `expected_visibility`、`group_id+user_ids`、`monthly_spending_limit_dollars`、`total_groups/total_pages`、`ant_cyber_approved/ant_cyber_verification_status`、`first_name/last_name` 等字段。
