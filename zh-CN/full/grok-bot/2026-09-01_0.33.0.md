# Grok Bot 0.33.0

[English](../../../full/grok-bot/2026-09-01_0.33.0.md) | 简体中文 · [精简版 (Highlight)](../../grok-bot/2026-09-01_0.33.0.md) | **完整详情 (Full Detail)**

- **发布日期**：2026-09-01
- **覆盖平台**：`mac`、`win`
- **版本摘要**：主进程三层拆分（main/main-app/main-core）+ mac 远程控制与语音进程路由打通

## 变更要点

- **功能**：mac 计算机控制（computer-use-mac）；语音进程消息路由（to-voice/to-main）；iMessage 启用与重试（messages-enable/messages-retry、`GetSandMachineMessagesEnabled`）；子 agent 调度（`SubagentDispatchStep`/`SubagentDispatchTool`）；WebAuthn 重试（webauthn-retry）；agent 审批一次通过（approve-once）。
- **协议/主进程**：新增 sand.main-core.handoff、sand.main-core.modules 模块加载协议；`CarriedRequestContext`（跨请求上下文携带）、`SandGroupAccessMode`、x-grok-bot-refusal 响应头、x-anyrun-port-token 回归；新键 response-create、automation-message、local-build、local-tool-retry、profile-list。
- **UI**：prompt-editor 组件。
- **底层**：electron-main 拆出 main-core.cjs；safeStorage 加解密函数（encryptString/decryptString）用于凭据存储。


## 代码与协议细节

- **三层拆分完成**：新增 `dist/electron-main/main-core.cjs`（1.43MB）；`main.cjs` 加载器新增守卫 `isMainCoreExports`（校验导出含 `remainderDue` Promise 与 `noteStartupFailed` 函数，否则抛 "main-core.cjs does not export remainderDue and noteStartupFailed."）。
- `proto.cjs`：子 agent 调度协议：`SubagentDispatchTool` 枚举（TASK/CREATE_AGENT/SEND_TO_AGENT）、`subagent_dispatch_steps` 字段（repeated）、`was_complete` 与 `conversation_rewind_epoch`；跨请求上下文 `CarriedRequestContext`（carried_request_context）；`sand_group_access_mode` 字段。
- `main-app.cjs`：语音路由打通：事件 `agent-speech-started/stopped`、`caller-speech-started/stopped`，进程间路由键 `to-voice`/`to-main`，`SandTranscriptionManager`/`SandTranscribeEmptyAudioError`。
- `main-app.cjs`：iMessage 使能链路：`GetSandMachineMessagesEnabled` RPC、通道 `messages-enable`/`messages-retry`、`check-messages-permissions`、`snapshot-messages-db`。
- `main-app.cjs`：新增 `computer-use-mac`（mac 远程控制）与 `update_sand_group_access_groups`/`sand_group_access_enabled_group_ids`。
- `main-app.cjs`：新提示词串 "how much they would like to oversee the changes the agent is making. What is their workflow…"（监督级别 onboarding 问题）。
