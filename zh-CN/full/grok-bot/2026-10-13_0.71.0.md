# Grok Bot 0.71.0

[English](../../../full/grok-bot/2026-10-13_0.71.0.md) | 简体中文 · [精简版 (Highlight)](../../grok-bot/2026-10-13_0.71.0.md) | **完整详情 (Full Detail)**

- **发布日期**：2026-10-13
- **覆盖平台**：`mac`、`win`
- **版本摘要**：本地执行守护进程增加断线看门狗与消息 worker，并为本地 Computer Use（CUA）打下地基

## 变更要点

- **功能**：新增 `@anysphere/agent-store-ids` 依赖（Bot 商店 ID 体系）；`local-exec-daemon` 新增 `messages-worker.cjs` 消息 worker；proto 新增 `SendToAgentRecipient.Kind=MAIN_BOT`（"发送给 Agent"的收件人模型）；GitHub 连接流程新增 `GLASS_CLOUD_AGENT`/`GLASS_DIFF`/`GLASS_AUTOMATIONS` 来源枚举（Glass 侧发起 GitHub 连接）。
- **协议/主进程**：新增遥测事件 `sand.local_exec_daemon.watch_outage`（断线原因枚举：`lifetime/stall/silent/network-change/error/unauthorized/channel-missing/gateway-unreachable`）；新增附件协议串 `sand.attachment.read`（与既有 commit/edge_failed 构成附件读写管线）；新增内部端点 `https://gtm-api.corp.anysphere.co`（与 google-workspace 连接器 OAuth 注册表同区，Google Workspace 连接器网关）；新增设置门 `sand_enable_local_cua` 及 `admin-group-check`（检查用户是否在管理员组，本地 Computer Use 前置检查）；新增 deb/rpm 包更新检查（`apt-cache policy grok-bot` / `dnf`）。
- **UI**：renderer 新增 `auto-review-approval`（自动审查批准）与 `provider-computer-use` 组件；Slack 文案扩充（"Connect Slack"、Bot 草稿发送/表情回应后恢复失败的错误提示）；Canvas 分享主体（`CanvasAccessPrincipal` user_id/group_id）与相应错误文案。
- **底层**：新增 `@anysphere/agent-store-ids`；Electron 版本不变。


## 代码与协议细节

- `proto.cjs`：支付卡金库数据模型先于 UI 落地——新增 `GrokBotVaultCard|brand/last4/exp_month/exp_year/holder_name/billing_address`、`GrokBotVaultCardBillingAddress|line1…phone`、`UpdateGrokBotVaultCardRequest|id/holder_name/expiry/billing_address`；新增 `SendToAgentRecipient`（Kind 含 `MAIN_BOT`）及 `SendToAgentArgs/Success`（`worker_bc_id/delivered_as/recipient`）；新增 tracked-tasks 全套 proto（`NewTrackedTask/TrackedTaskView/TrackedTaskUpdate/TrackedTaskConflict/TrackedTaskLink*/ListTrackedTasks*/DeleteTrackedTasksSuccess`）；新增 Canvas 分享权限模型 `CanvasShareAccessState/UpdateCanvasShareAccessRequest/GrokBotAccessPrincipal`（user_id/group_id/organization+role）；新增枚举 `McpConnectorAuthState`（SIGNED_IN/SIGNED_OUT/UNAVAILABLE）；`GrokBotUserComputerCapabilities` 增加 `|8 local_tool_app_consent|9 local_tool_grant_seen`（本地工具授权确认位）。
- `main-app.cjs`：构造卡数据载荷 `{card:{brand,last4,expMonth,expYear,holderName,billingAddress:{line1,line2…}}}`（`holderName`/`billingAddress` 在 0.70.2 中为 0 处）；`SetGrokBotAgentVisibilityOutcome.UNSPECIFIED` 从静默返回改为 `throw new vi("SetGrokBotAgentVisibility returned no outcome")`；新增 `prefers-color-scheme` 媒体查询解析函数（从 CSS 媒体串判断 light/dark）；`ResolveGrokBotAutoReviewApprovalRequest` 删除 `|7 meeting_join` 字段；Slack 安装状态 proto 扩展多 workspace（`needs_manifest_update/pending_reinstall_approval/oauth_authorize_url`）。
- `main-core.cjs`：Computer Use 辅助 App 三变体配置——prod `grok-bot-computer-use/CUGrokBotService`、`lab:{appName:"Grok Bot Lab Computer Use",bundleId:"co.anysphere.grok-bot-lab-computer-use",executable:"CUGrokBotLabService"}`、dev 同构；新增窗口导航守卫 `Dg(e,{openExternalUrl})`（`setWindowOpenHandler`+`will-navigate`+`will-frame-nav` 全拦外部导航）；新增 `case "blank_window":return{}` / `case "crash_loop":return{[FO.key]:e.reloads}` 崩溃循环计数。
- 另：`sand_enable_local_cua`（×3）与 `admin-group-check` 设置门为本版新增，`watch_outage` 遥测在未随包提取的 local-exec-daemon 内。
