# Grok Bot 0.51.0

[English](../../../full/grok-bot/2026-09-14_0.51.0.md) | 简体中文 · [精简版 (Highlight)](../../grok-bot/2026-09-14_0.51.0.md) | **完整详情 (Full Detail)**

- **发布日期**：2026-09-14
- **覆盖平台**：`mac`、`win`、`ubuntu`
- **版本摘要**：用户运行时设置云同步（置顶 agent/侧栏分区）、agent 待办清单与语音通话轮转提示词体系

## 变更要点

- **功能**：用户运行时设置云同步（`Get/UpdateGrokBotUserRuntimeSettings`：`GrokBotPinnedAgents` 置顶 agent、`GrokBotSidebarSections` 侧栏分区、TIME_ZONE / MCP_SERVERS / PINNED_AGENTS / SIDEBAR_SECTIONS 等字段）；agent 待办（`ListGrokBotAgentTodos`）；账号自动化列表（`ListGrokBotAccountAutomations`，按 time_zone 分组，`GrokBotAccountAutomationGroup`）；语音通话成型——feature flag `sand_voice_call` 及反馈卡，遥测 `sand.voice_call` / `voice_call_connect` / `voice_call_fault` / `voice_call_delivery`，并内置整套语音对话轮转规则提示词（"Any confirming noise is agreement…"、"Never chase or poll the work; it reports back on its own"、"An empty tool result is not news" 等）。
- **协议/主进程**：`BackgroundComposerApprovalKind/State`；`GrokBotGroupTriState`；`GrokBotRoomPerson`；`SandCredentialDecisionHarness.BOX`；持久化键回归（account-slot / veto-roster / veto-seen / fail-open-probes / fail-open-deadline / slack-draft 等）；遥测 `sand.desktop.log`、`sand.cloud_agent.artifact_opened` / `artifact_rendered`。
- **UI**：team-bot 对话框全家桶（`team-bot-context-dialog` / `team-bot-plugins-dialog` / `team-bot-slack-flow-dialog` / `team-bot-overview-panel`）、`grok-bot-slack-dialog-live`、`network-debugger-dialog`、`fullscreen-file-viewer-body` 全屏文件查看、`voice-memo-bubble` 语音条；多语言用量检查文案（"Comprobando el uso" 等）。
- **底层**：主进程协议常量大清理——移除 457 个旧枚举常量（ABORTED_NOT_CHARGED、ADD_FILE_TO_CONTEXT、APPLY_AGENT_DIFF 等，协议模块独立拆分）；依赖数不变（84）。


## 代码与协议细节

- `main-app.cjs`：语音通话遥测上报——新增 phase/call_id/telemetry_version 事件映射（`telemetry_version` 0→6 处；`started`/`connected`(elapsed_ms)/`usage`(active_ms, sequence) 分 phase 字段化）；云端 artifact 埋点 `cloudAgentArtifact.ingest` → `sand.cloud_agent.artifact_rendered` / `artifact_opened`（agent_id/bc_id/kind/state）；房间 agent 成员展示——`GrokBotAgentKind.ROOM && people.length>0` 时映射 `displayName/avatarPhoto/isViewer`，配合 `Intl.ListFormat`（long/narrow/unit 三风格 + az–sv 语言数据表）做成员名单本地化拼接；深链日志 `desktopLog`（`[sand] deep-link: ${e} reason=... origin=...`，0→5 处）；`listTeamMemberships` 调用缩减（4→2 处）。
- `main-core.cjs`：错误上报包装重构——新增 `X/Wr`（area/leg/errorClass 三元组）与安装点 `wv(e)`（底层为 32 容量 `drop-newest` 环形缓冲）；新错误码 `SAND-E0116 gatewayPodHibernated`（retryable，"Gateway route answered that the box pod is hibernated or mid-transition on its node."）。
- `proto.cjs`：**proto.cjs 从 3.97MB 缩至 0.74MB（-81%）**——成批移除 Cursor 通用工具协议定义（`read_semsearch_files_params` 3→0、`ripgrep_search_*`、`create_diagram_stream`/`fix_lints_stream`、Tool 枚举的 FILE_SEARCH/SEMANTIC_SEARCH_FULL/DELETE_FILE/REAPPLY/RUN_TERMINAL_COMMAND_V2 等，改为独立模块加载）；新增 `UpdateGrokBotUserRuntimeSettings`（0→3 处）与 `GrokBotPinnedAgents`。
