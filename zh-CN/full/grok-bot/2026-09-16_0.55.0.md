# Grok Bot 0.55.0

[English](../../../full/grok-bot/2026-09-16_0.55.0.md) | 简体中文 · [精简版 (Highlight)](../../grok-bot/2026-09-16_0.55.0.md) | **完整详情 (Full Detail)**

- **发布日期**：2026-09-16
- **覆盖平台**：`mac`、`win`、`ubuntu`
- **版本摘要**：小版本：新增语音备忘录遥测通道 sand.voice_memo，GitHub 断连支持

## 变更要点

- **功能**：新增 sand.* 通道 `sand.voice_memo`；DisconnectGithubResponse 返回 removed_connections_count（GitHub 连接批量断开）。
- **协议/主进程**：仅上述两项，无其他新协议字符串。
- **UI**：无变化（仅常规资源分块重编译）。
- **底层**：无依赖增删。


## 代码与协议细节

- `main-app.cjs`：新增侧栏分节持久化 `writeSidebarSections` → `updateGrokBotUserRuntimeSettings({sidebarSections: o.map(({id,name,agentIds})=>...)})`，失败上报 `reportDesktopEdgeFailure("host-settings","write")`；语音合成（TTS）支持字级时间戳——请求带 `withTimestamps: !0` 与 `voiceId`，`charStartMs.length===text.length===charEndMs.length` 校验后映射为 `[{startMs, endMs}]` 段；新增 RPC `disconnectScmConnection({platform})` → `scmConnections.disconnect`；账户运行时切换后 `resetMcpManager() + refreshHostMcp()`；设置对象透传 `currentBuiltAt`。
- `proto.cjs`：`DisconnectGithubRequest` 新增 `ghe_application` / `user_only` 字段，响应新增 `removedConnectionsCount`。

## 技术变更明细

- **各子系统变更文件分布**：`dist/electron-main`（4 个文件）、`dist/local-exec-daemon`（1 个文件）、`dist/renderer`（1 个文件）、`dist/deps`（1 个文件）、`dist/native`（1 个文件）、`package.json`（1 个文件）、`dist/electron-preload`（1 个文件）、`dist/node-agent-coordinator`（1 个文件）。
- **新增渲染层组件与资源模块**：`chunk-EX3LRPZG`、`timeline-definition-FHXFAJF6`。
- **新增协议路径与 RPC/Proto 标识**：`sand.voice_memo`。
