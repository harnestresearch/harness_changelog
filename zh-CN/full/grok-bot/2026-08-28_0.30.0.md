# Grok Bot 0.30.0

[English](../../../full/grok-bot/2026-08-28_0.30.0.md) | 简体中文 · [精简版 (Highlight)](../../grok-bot/2026-08-28_0.30.0.md) | **完整详情 (Full Detail)**

- **发布日期**：2026-08-28
- **覆盖平台**：`mac`、`win`、`ubuntu`
- **版本摘要**：重量级：iMessage 读写（@anysphere/messages-mac）与语音通话 harness（wss://api.x.ai/）双落地，本地 agent 邮箱与虚拟卡同场登场

## 变更要点

- **功能**：iMessage/本地消息集成——本地工具动作 `send-imessage`、read-messages、resolve-media（经宿主 Chrome CDP 注入实现：open-cdp-ok/open-cdp-missing、chrome-closed、host-chrome-locked、inject-rejected）；语音通话（+@anysphere/grok-bot-voice-call-harness，DIALABLE_ORIGIN=wss://api.x.ai/，可铸模型 grok-voice-latest / grok-voice-think-fast-2.0）；本地 agent 邮箱流（`StreamLocalAgentMailbox`、`LocalSubscriptionTool` 定义与调用）；Bugbot 设置（BugbotSetupAction）；Canvas 画布（CanvasStoreRoot/CanvasVisibility）；虚拟确认卡（GrokBotVirtualCard{Outcome,RaiseOutcome,Resolution}）；xAI-Cursor 团队合并（`ConfirmXaiCursorTeamMerge`/CancelProposal/GetStatus/MembershipPreview）；MCP OAuth 浏览器流程（mcp-auth-completed/mcp-auth-watch/mcp-tools-discovery）。
- **协议/主进程**：`GetGrokBotRuntimeCapabilities`、`GetGrokBotTemplateExportPolicy`、`GetTeamSandShareBotExportSettings`、`GetTeamOffboardingConfigInternal`；连接器目录扩展为 14 项（workspace/slack/notion/salesforce/microsoft-365/linkedin/zoom/github/jira/figma/hubspot/canva/trello/monday…）；新键 enterprise-usage、team-server、shared-docker、toggle-sync、install-backfill、link-preview-cache。
- **UI**：usage-pane 用量面板；多语言 emoji-messages（af/ar/el/he）。
- **底层**：+@anysphere/grok-bot-voice-call-harness、+@anysphere/messages-mac（依赖 81→83）；新增 URL wss://api.x.ai/ 与 ajv JSON-schema 校验器常驻。


## 代码与协议细节

- `main.cjs`：本地 agent 邮箱流协议族：`StreamLocalAgentMailboxRequest/Response`、`LocalAgentMailbox{Delivery,Ended,Entry,Gap}`、结束原因枚举 `MIGRATED_TO_CLOUD`/`NO_ACTIVE_SUBSCRIPTIONS`/`STORE_DELETED`。
- `main.cjs`：虚拟确认卡 RPC：`RaiseGrokBotVirtualCard`、`ResolveGrokBotVirtualCardApproval`。
- `main.cjs`：xAI-Cursor 团队合并全家桶：`ConfirmXaiCursorTeamMerge`、`CancelXaiCursorTeamMergeProposal`、`GetXaiCursorTeamMergeStatus`、`GetXaiCursorTeamMembershipPreview`。
- `main.cjs`：Marketplace 运营侧扩展：`Create/GetGrokBotMarketplaceCategoryInternal`、`Create/GetGrokBotMarketplaceCreatorInternal`、`GetPublicGrokBotMarketplaceListing`；另有 `GetGrokBotRuntimeCapabilities`、`GetGrokBotTemplateExportPolicy`、`CreateGrokBotTemporalAgent`、`BugbotSetupAction`。
- `main.cjs`：ajv JSON-schema 校验器常驻（"\$schema must be a string"、"keyword is always validated" 等全套文案）+ AnyCode 解析器 token 名表（`BlockCommentTrivia`/`CloseBraceExpected`…）。
