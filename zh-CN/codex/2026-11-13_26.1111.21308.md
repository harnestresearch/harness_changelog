## 核心亮点

- **外部智能体技能导入（Claude Code 与 Cursor）**：支持自动检测并导入本地 Claude Code 与 Cursor 目录下的自定义技能（`SKILL.md`），并与原生技能分组管理。
- **云端实时预览与 Git Worktree 全面升级**：支持在桌面端直接列出、打开与关闭云端预览（Cloud Previews）；新增 Worktree 专属设置页、分支初始化弹窗、迁移至 Worktree 对话框与 Git 关联检出挂载，并支持子智能体读取父会话附件。
- **自动化任务收件箱与停止轮次确认**：新增自动化运行收件箱（支持未读运行计数与一键全部已读），并支持在中止正在执行的智能体轮次前弹出确认提示，防止误触中断任务。
- **全局搜索、Spaces 空间与本地项目转对话**：上线跨会话全局搜索（Global Search），支持 Spaces 页面缩略图与侧栏自定义排序、将本地项目一键转为对话以及侧栏会话速览。
- **交互式 MCP 应用增强与 11 月连接器更新**：MCP 应用小组件支持后台多线程（Web Worker）运行与按来源细粒度权限控制（剪贴板写入、局域网与本地回环网络访问），支持手动重载 MCP 扩展服务；更新 DocuSign、HubSpot、Klaviyo（2026-11）连接器，支持恢复 Office 工作簿，新增 Quartz 应用图标（及 Financial Charts、FinData、Ledger 深色图标），并焕新启动流光动画。
- **本地 MCP 按需懒启动与 Linux 功能对齐**：支持本地 stdio MCP 服务按需懒启动以加快桌面冷启动响应，并在 Linux 端同步补齐 64 语种 Cloud SSH 握手异常诊断、宽屏交互图表与宠物原生透明背景生成能力。
