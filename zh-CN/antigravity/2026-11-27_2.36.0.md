## 核心亮点

- **壳层连续第三个纯版本号变更，但后端 `language_server` 为 rebase 功能版**：相对 [2.35.2](2026-11-25_2.35.2.md)，Electron `44.9.1` 桌面壳层（`app.asar` 共 `1,167` 文件、`20,690,656` B）**唯一差异**仍是 `package.json` 版本号（`2.35.2` → `2.36.0`），随包 `chrome-devtools-mcp` `1.12.0` 不变且六端 `app.asar` 逐字节同哈希。与之相对，Go `language_server` 发生发布分支 rebase（`cl/1029311855` → `cl/1031268331`，基线 `1027784732` → `1030397722`；`darwin-arm` `−717,648` B、`strings` `+58,899 / −58,470`），macOS 副件 `agy-desktop-rtc` 同步增大 `+22,592` B（约 `+22.6` KB），呼应后端远程控制 Mesh 传输接入。
- **官方 `v2.36.0` 变更（`13` 项改进 + `26` 项修复）—— 包内实证与 webapp 侧区分**：
  - **安装包静态实证**：桌面端发起**远程智能体云端自动化授权**（`language_server` 新增 Trigger 族 RPC 及 `JetskiRemoteAgentProxyService` 代理面，系统浏览器 Google 登录授权 UI 在包外）与 **`~/.agents/skills` 自定义技能发现**（同名时 `~/.gemini` 优先，`language_server` 发现路径及迁移文档实证）。
  - **归属 Hub webapp / 服务端（安装包静态不可证）**：标题级 UI 与策略特性——包括最大化侧栏底部的**浮动输入框（floating composer）**、**Auto mode 扩展**（跨仓库安全编辑与项目外非覆盖新增免确认）、**语音通话口语上下文带入本地会话**（`language_server` 仅见 `voice` 字符串弱旁证增长）、**MCP Server OAuth 离线刷新令牌**、**Windows/Linux 应用菜单 File/Zoom 子菜单**、**Installed 标签页 16 项分页**、**子代理回复 LaTeX 公式渲染**、**会话摘要磁盘/内存优化**，以及 **26 项修复**（如 `localhost` 默认 HTTPS、macOS 快捷键 `Option+Cmd+/`、Orchestrator 同模型单智能体回退、麦克风 `System default`、长轮次 OAuth 过期重试、Windows 跨盘插件查找等）——因壳层仅改版本号，均无法从静态安装包逐条证实。
- **官方未单列的后端扩容（远程智能体管理、Mesh 传输、安全与可观测面）**：静态检出的未公告面包括 Connect-RPC 新增 `+34` 项（`338` → `372`，覆盖远程智能体生命周期、文件/工作区权限、Sidecar、Trigger 与 Blueprint，其中一批挂在新服务 `JetskiRemoteAgentProxyService` 下）、**RemoteControl Mesh 传输**（WebChannel 为回退）、**敏感度分级**（`policyguardian/sensitivity`）与 **Proctor J1/C8** 供应链/防火墙规则（查询 `deps.dev` 与 GitHub 漏洞公告）、**Sentry Go SDK** 入列、`4` 个新具名特性开关（含对应 `2.35.1` 两条功能的 `enable-resume-conversations-from-restart` 与 `enable-sidecar-pill-auto-open`），以及模型资格标签改名（`neonccpa` → `neondefault`；模型 `44`、`*ToolConfig` `65` 与 CUA `19` 均保持零变化）。
- **六端同构建对齐（首次覆盖 `windows-arm64`）**：六端官方包（`darwin-arm`、`darwin-x64`、`linux-x64`、`linux-arm`［根目录 `Antigravity-arm64/`］、`windows-x64`［`app-64.7z`］与 `windows-arm64`［`app-arm64.7z`］）内嵌 `app.asar` 哈希（`d2bc25ea…`）逐字节一致，macOS/Linux 四端均核实为 `cl/1031268331`（Windows `x64`/`arm64` 两端 `language_server` PE 仍为已知缺口）。
