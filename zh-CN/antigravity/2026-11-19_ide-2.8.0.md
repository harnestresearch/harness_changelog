## 核心亮点

- **后台周期更新检查、即刻启动与防降级保护**：内置 `agy` 扩展（`1.11.0` → `1.12.0`）新增后端周期更新检查与就绪后的 **“Restart Agent Server”** 重启提示，在已安装后端时推迟启动期 release 检查以减少激活阻塞，并引入 `downgrade_skipped`、`same_version_rebuild`、`staged_promoted`、`check_deferred` 等更新决策遥测与保护机制，避免多窗口共享通道降级及恢复超时后重复下载。
- **远程登录端口转发、授权码回退与自定义根证书 / 代理支持**：面向 `ssh-remote`、`dev-container`、`attached-container`、`cloud-shell`、`cloud-workstations`、`codespaces` 六类远程环境新增登录端口转发与 OOB 授权码回退（扩展侧直连 `SwitchLoginToAuthCode` RPC 指向运行时 `agy` 后端）；新增配置项 `antigravity.caCertificates`，并补齐企业自定义根证书与代理配置读取（`AGY_*`、`NODE_EXTRA_CA_CERTS`、`SSL_CERT_FILE`、VS Code `http.proxy*` 及 `geminicodeassist` 双前缀可信证书）。
- **Agent 面板会话内搜索快捷键与桥接协议扩容（`+26` Schema）**：在 Agent 面板或聊天聚焦时新增 `Ctrl+F`（macOS `Cmd+F`）会话内搜索转发快捷键（搜索 UI 位于 webview 侧），并同步扩展 IDE 与智能体 webview 桥接协议 `+26` 个 Schema，覆盖已解析定制项（技能、规则、子代理、钩子）、Harness/实验工具调用步骤、模型目录/规划执行配置以及文档/表格/嵌入内容层。
- **Code OSS 基座连续三版冻结与官方说明核对**：全部实质代码改动仍仅集中于 `extensions/agy/`（`3` 文件、`+66.9` KB）与 macOS 独有的两件 MSAL 原生库重编译，`out/`、`11.8 MB` `jetskiAgent` 渲染器、`351` 方法 `LanguageServerService` 描述符及 `node_modules/` 跨 `2.6.0` → `2.7.0` → `2.8.0` 保持零实质代码变更。官方 `v2.8.0` `12` 条变更中，`4` 条获 `extensions/agy/` 包内实证、`3` 条获静态线索或入口实证，另有 `3` 条（*后端就绪超时 30→60 秒*、*Windows 注销/关机恢复死循环修复*、*Windows 多窗口任务通知聚焦修复*）不在 IDE 静态包面内（归属运行时下载的 `agy` CLI 或远程 webview）。
