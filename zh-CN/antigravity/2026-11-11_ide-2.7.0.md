## 核心亮点

- **登录态感知状态栏与多窗口认证同步**：底部状态栏按钮由静态设置入口升级为登录态感知三态指示器（未登录时点击直接触发登录，已登录或检测中打开快捷状态菜单），新增登录（Sign In）/ 登出（Sign Out）命令与跨窗口登录状态自动同步，并支持区分 Google Cloud / 企业服务条款状态。
- **区分「当前文件」与「全部文件」的差异审阅及新快捷键**：将行内与并排 Diff 接受/拒绝操作文案明确收窄为「当前文件（in Current File）」，同时拆出独立的「接受/拒绝全部文件改动（in All Files）」命令；新增新建对话、切换聊天焦点与插入终端输出命令，区分 `Ctrl+L` 与 `Ctrl+Alt+L` 插入代码片段与终端输出快捷键，并将 `autoAcceptOnChat` 更新为非累积审阅语义。
- **后台任务、多媒体处理与浏览器录制桥接扩展**：同步扩展编辑器宿主与智能体界面之间的消息桥接能力，补齐后台任务管理（`ManageTask`）、多媒体处理、浏览器录制及焦点/认证状态同步支持。
- **云端工作站预装 CLI 自动识别与本地端口冲突重试**：在 Google Cloud Workstations 与 Cloud Shell 等云开发环境中自动优先复用预装的 `/usr/bin/agy`（跳过运行时自动更新下载），为本地 `agy` 服务启动新增端口冲突重试机制，并通过新增配置项 `antigravity.isAntigravityIde` 将应用内一键反馈精准归属至 Antigravity IDE。
