## 核心亮点

- **统一连接器账号管理、MCP OAuth 与 7 个可选连接器插件** _（底层能力默认挂载；7 个连接器为独立可选安装包）_：插件页支持统一管理连接器账号，MCP 支持显式 OAuth 授权与凭据自动刷新，并新增按需加载 MCP 工具模式（`toolLoading: 'on-demand'`）；CLI 应用插件共用账号管理与上游技能下载能力。新增 **Linear**、**Notion**、**腾讯文档**（托管 MCP OAuth，默认按需加载工具）以及 **飞书**、**企业微信**、**腾讯会议**、**钉钉**（封装官方 CLI；其中**飞书**与**企业微信**仅支持 macOS 与 Windows `x64`）共 7 个可选连接器，均未预装预启，需按需通过插件页或 `dsh plugin add` 单独安装。
- **Web 远程登录、设备配对与标准化连接鉴权 API** _（Web 模式默认启用；桌面端窗口不显示远程连接设置页）_：Web 模式新增 **设置 → 远程连接**，支持一次性二维码登录、独立带令牌登录链接与已登录端审批的浏览器设备配对；底层引入可插拔 `connection.authentication` 提供方接口、独立 Token/Desktop 鉴权插件、`webServer` 路由默认强制鉴权（`auth: 'required'`）以及单主机多端口 Cookie 上限（保留最多 17 个端口避免 HTTP 431 无法打开）。
- **会话状态区域与跨端共享已读/未读提醒** _（Web 与桌面端默认启用）_：新增可停靠在对话侧边或窄窗口弹出（280px 浮层）、支持拖动重排分区的 **会话状态面板**（集中展示工作目录、变更请求、子智能体、任务与插件状态）；新增基于 Host 共享记录的 **会话已读/未读状态**（含失败未读标记、菜单与快捷键切换）。
- **代码审阅页面、扩展机制与 GitLab MR 支持** _（归属实验性组合包，默认关闭）_：均位于可选实验性组合包 **变更请求与工作树**（`@deepseek-ai/dsh-experimental-forge-bundle`）内，新增集中查看 PR 与页内智能体协作审阅的 **代码审阅页面**、插件扩展接缝（自定义审阅视图、行注解及工具栏/文件菜单/评论框操作）以及 `@deepseek-ai/dsh-forge-gitlab`。**实证范围边界**：全局代码审阅页面列表目前**仅支持 GitHub PR**（需本机安装并登录 `gh`），GitLab 支持面向**会话关联的 MR**（需本机安装并登录 `glab`）。
- **Git 仓库插件来源与实验性时间线插件** _（均为实验性组合包，默认关闭）_：既有的可选实验性 **自定义插件索引**（`@deepseek-ai/dsh-experimental-plugin-market-bundle`）支持添加 Git 仓库（含基于宿主 Git/SSH 凭据访问的私有仓库）作为索引来源；新增可选实验性 **时间线**（`@deepseek-ai/dsh-timeline`），提供任务树、阻塞事项、可点击进度条、`.timeline.json` 导入导出与定时进展报告（额外发起模型请求消耗 token），支持「跟随对话」语言选项。
- **重点安全迁移、运行时与体验演进**：`workspace-write` 边界与文件视图现随会话实时 `cwd` 切换（移除 `working_directory` 工具与子代理 `cwd` 参数，改用 `enter_worktree`/`exit_worktree`，工作树内 Git 写入需额外授权，归档清理不再受只读沙箱阻拦）；**个性化推荐**升为 Web/桌面端默认开启；Office 技能合并为 `/office` 并内置 `pypdf`；Computer Use 新增实验性 Windows 支持、`cua-mcp` 及启用后的标准模式/SDK/headless 默认 `cua_run_code`；Node PTC 默认启用持久作用域 REPL 并**移除 Python PTC**；标准模式默认启用 `cordis_inspect`；新增需手动配置的实验性 SQLite 会话存储（默认仍为 JSONL）。

## 主要体验优化与问题修复

- **对话、侧栏与输入框体验**：空白输入框按 `↑` 召回本会话已发送文本（`↑`/`↓` 浏览且不覆盖草稿）；文件右键菜单新增「添加到对话」；普通会话可拖入右侧栏并行续聊；对话压缩条目支持在右侧栏预览手动/自动摘要；「模型」设置支持自定义内置目录模型的推理档位；会话列表与 `@` 引用加载提速；搜索列表支持跨语言模糊匹配（如 `cpt` 命中 `/compact`）且新建会话支持按名/路径搜工作区；子代理与分支会话增加继承历史分隔线；共享会话（LiveShare）扩大读者可参与能力；桌面版应用菜单直达「设置」并同步单步快捷键；变更请求列表更紧凑可折叠，工作树支持自定义分支名、远端基线分支及首条消息后延迟创建。
- **Office、模型、子智能体与性能**：Office 技能整合为 `/office` 并在内置 Python 提供 `pypdf` 指导处理已有 PDF；个性化推荐默认开启（由 **设置 → 通用** 控制）；恢复实验性「持久终端」在插件页的启停入口（默认仍关闭）；DeepSeek 图片上传支持 3 并发与 429 重试，修复无响应长时间阻塞及取消导致运行时退出；经 `pi` 接入的模型自动按尺寸/字节上限缩图发送且保留原图；`web_fetch` 展示可读的网络失败原因与建议；优化长会话流式渲染、大 Markdown 表格/列表卡顿与右侧栏拖动响应，降低 `read`/`glob` 大文件/大结果后的内存滞留。
- **平台与稳定性修复**：切模型后首请求超上下文自动恢复与 `/compact` 改用最近回答的模型摘要；修复 Python wheel 等单文件运行时恢复旧会话失败；PTC 内通过 `gh`/`git push` 操作的 PR 现同步展示于代码审阅面板；修复 macOS 输入框 `Home`/`End` 行为与浏览器拒写剪贴板时的复制按钮；修复 Windows 安装完成拖动卡死、卸载残留登记及「在应用中打开」启动 VS Code/Cursor 失败（清理继承的 `ELECTRON_RUN_AS_NODE`）；修复桌面版用量/充值页 `Cmd+W`、切会话草稿附件丢失、切目录后文件引用偏移、多端口登录 Cookie 堆积致 HTTP 431、桌面诊断历史遗漏、手动输入 `@` 路径乱序及模型菜单点击分组标题误关等问题。

## 破坏性变化与重要安全迁移

`dsh-v0.2.3-alpha.1` 在 `docs/upgrade-guide/` 累计新增 **`55` 条、更新 `2` 条**升级指南（汇聚了 `0.2.2-rc.*` 并行期主线变更），重点迁移与安全边界如下：

- **工作区写入边界与工作树安全收紧**：移除 `working_directory` 工具与子代理 `cwd` 参数，改用 `enter_worktree`/`exit_worktree` 取代 `create_worktree`。`workspace-write` 边界现跟随会话实时 `cwd`：进入工作树后不再允许写原项目，且因 `.git` 位于工作树外，工作树内 `git add`/`git commit` 需额外审批或配置 `additionalWritableRoots`（Windows 忽略该项）；旧会话历史 `working-directory/change` 恢复时被忽略并回到原项目。归档清理工作树现不受只读沙箱策略限制，在沙箱外以宿主权限执行 `git worktree remove`（可通过 `retainOnArchive: true` 关闭自动清理）。
- **WebServer 默认强制鉴权与鉴权提供方拆分**：`webServer` 路由默认改为 `auth: 'required'`，自定义公开接口须显式声明 `auth: 'anonymous'`；默认 Token 鉴权迁入 `@deepseek-ai/dsh-host-authentication-token`（`cookieMaxAgeDays` 同步迁移）。
- **统一 `ctx.deepseekAuth` 与 DeepSeek API 更名**：不经 `dsh-base`/`dsh-sdk-minimal` 挂载 DeepSeek 模型或搜索/抓取插件的自定义组合须显式挂载 `@deepseek-ai/dsh-deepseek-auth`；退出账号现通过 `revoked` 信号中止在途请求。
- **Node PTC 默认持久作用域 REPL 与移除 Python PTC**：Node PTC 默认由 `per-call` 切为 `persistent-in-memory` 作用域 REPL（拒绝顶层 `return`，需旧行为可配置 `executionMode: per-call`）；彻底移除 `@deepseek-ai/dsh-experimental-ptc-runtime-python` 及所有 `language: 'python'` PTC 运行时（不影响 `python/sdk` 及普通 Python 环境）。
- **Cordis Core `4.0.0-rc.12` / Loader `1.0.0-rc.9` / Include `1.2.0` 与插件契约迁移**：`ctx.root` 改为 `ctx[Context.root]`；YAML 切至 YAML 1.2 核心模式（如 `0b101` 变字符串）；严格校验条目配置（`group: true` 须显式提供 `config: []`）；移除 `/office-docx`/`/office-pptx`/`/office-xlsx`；`SessionStatus` 迁至 `@deepseek-ai/dsh-client-ui-session-status`（须在 `inject` 声明）；客户端插件改由框架挂载时注入样式并变更 CSS Modules 类名格式；规范包导出入口与结构化工具错误码；`fileAddressFor` 改为返回绝对路径；分支会话自定义 `fork` 须提供 `parentSource`；`list_agents` 结构化结果改为 `{ running, limit, agents }`；`cordis_inspect` 取代旧双工具；macOS CUA 重命名为 `@deepseek-ai/dsh-cua-macos` / `cua-macos` 且 `useSystemPointer` 改为 `useSystemInput`；系统指令改为按来源增量更新且 SDK 支持逐条时区。
- **实验性 SQLite 会话存储**：`@deepseek-ai/dsh-session-persistence-sqlite` 需手动配置启用，默认存储仍为 JSONL。
