## 核心亮点

- **DeepSeek 官网对话导出导入器（实验性插件）**：新增可选实验性插件「DeepSeek 会话导入」（在 **插件 → 更多 → 实验性插件** 中开启），开启后在侧栏「新建会话」右侧提供上传入口，支持将 `chat.deepseek.com` 导出的 `deepseek_data-*.zip` 批量导入至指定工作区并转为可继续对话的原生 DSH 会话，完整保留原始标题、时间戳、深度思考推理、网页搜索/抓取卡片、阅读链接与图片附件（覆盖 8 种界面语言）。
- **会话日志 ZIP 导出容错增强**：导出会话日志 ZIP 时，若引用的图片或文件附件已被删除或原本无底层字节（如合成文件卡片），不再中断整个下载任务，而是将缺失引用记录至归档内的 `attachments-missing.txt` 并正常导出其余内容。
- **Windows 桌面端更新重启目录占用修复**：修复 Windows 安装器在确认更新重启时，独立状态提示窗进程可能继承并占用应用安装目录、阻碍新版本目录重命名替换的问题。

## 新功能

- **实验性插件：DeepSeek 官网对话导出导入（`@deepseek-ai/dsh-deepseek-chat-import`）**：
  - 支持在浏览器端选择 `deepseek_data-*.zip` 上传至宿主并在内存中完成校验与流式解压（默认上限：单次归档 `512 MiB`、单条目 `256 MiB`、按 `chat_session_index.json` 最近更新时间最多导入 `1,000` 个会话），实时展示上传与 `Importing n/K` 写入进度，支持关闭弹窗随时取消，并在单个会话跳过时自动递补索引中更早的会话。
  - 按 `current_message_id`（缺失时回退至最大消息 ID）提取会话分支，将导出的用户图片（`png`、`jpg`、`jpeg`、`webp`、`gif`）存为原生图片附件，将非图片或缺失文件渲染为合成文件卡片，将 `SEARCH` 与带地址的 `TOOL_OPEN` 映射为原生 `web_search` / `web_fetch` 工具卡片、将 `READ_LINK` 转为 Markdown 链接；自动剔除因内容审核撤回（`CONTENT_FILTER`）的问答轮次，并将未完成或模板回复标记为错误结束（不进入模型上下文），确保导入会话可直接无缝续聊。
- **侧栏会话操作扩展槽与可复用工作区选择器**：
  - 在「新建会话」旁新增 `sidebar.session.action` 扩展槽（同时适配展开态横向排布与 `56px` 收起轨道纵向堆叠及收起动画），发布可供任意插件弹窗复用的 `workspace.picker` 工作区选择器组件工厂（内置「添加工作区…」目录选择流程），并新增上传描边图标（`IconUploadOutlineRegular` / `IconUploadOutlineMedium`）。

## 问题修复

- **Windows 更新重启状态窗工作目录修复**：将 Windows NSIS 更新重启状态提示进程（`rundll32.exe`）的工作目录显式指定为 Windows 系统目录，避免在应用目录替换期间锁定安装目录。
- **会话日志 ZIP 导出缺失附件处理与文件流清理**：在会话日志 ZIP 导出中预先拉取文件首个分块（使真实存储损坏仍能立即报错），将已删除或无效附件引用记入 `attachments-missing.txt` 而不中断导出，并在提前取消下载时统一关闭所有已打开的文件读取流。
- **CI 沙箱归档缓存与有界下载**：在托管 Linux CI/E2E 任务中缓存经 SHA-256 校验的 `bubblewrap` `.deb` 归档并为 `curl` 配置连接/总超时与重试上限，消除 Launchpad 下载偶发卡死导致的流水线阻塞。

## 破坏性变化

- **无**：相较 `dsh-v0.2.2-rc.2` 无面向用户、现有配置文件或持久化会话格式的破坏性变化（`docs/upgrade-guide` 新增条目为 `0`）。
