# Cursor Desktop 3.28.7

[English](../../cursor/2026-11-03_3.28.7.md) | 简体中文 · **精简版 (Highlight)** | [完整详情 (Full Detail)](../full/cursor/2026-11-03_3.28.7.md)

- **发布日期**：2026-11-03
- **覆盖平台**：`mac`、`win`、`ubuntu`

## 核心亮点

- **经典 IDE 与独立 Agents 窗口双模式体验**：除完整代码编辑器外提供专为多智能体并行编排设计的独立 Agents 窗口，集中管理本地与云端会话、审阅改动与配置远程协同。
- **手机远程指挥本机任务（Steer from Phone / Remote Control）**：支持通过 6 位配对校验码将电脑与官方 iOS 客户端安全绑定，外出时用手机继续指挥本机智能体（代码检索、文件修改与终端命令仍在本机执行），并提供「保持电脑唤醒」防休眠开关及将本地会话一键迁移上云（Move to Cloud）能力。
- **子代理集群、Canvas 可视化画布与 PR 代码导览**：支持多子代理并行派发与任务进度追踪、Canvas 交互式画布创作、Pull Request 导览视图（Code Tour）生成、上下文窗口占用明细可视化及全库语义检索。
- **内置浏览器自动化与桌面 Computer Use**：内置免配置的浏览器操控与调试能力（支持点击输入、DOM 快照、截图及读取控制台与网络请求日志），并在 macOS 与 Windows 上支持受授权的桌面级应用操控。
- **iOS 锁屏实时活动同步与企业级策略管控**：支持在 iOS 锁屏与灵动岛同步追踪最多 8 个并行智能体状态，并提供细粒度工具白名单审批与团队管理员远程控制策略开关。
