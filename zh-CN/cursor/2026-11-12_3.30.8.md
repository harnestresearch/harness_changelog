- **覆盖平台**：`mac`、`win`、`ubuntu`

## 核心亮点

- **企业级 MCP 策略拦截、二次认证与会话治理**：客户端正式落地团队级 MCP 服务器白名单、黑名单、Cloud Agent 白名单及只读/按工具级访问权限管控（配套清晰的拦截原因提示）；管理后台新增 Step-Up 二次身份认证、第三方 OAuth 应用授权管理、API Key 资产盘点以及团队成员会话查看与吊销能力。
- **远程控制（Remote Control）能力扩充与配对密码学证明**：手机等远程控制端现支持归档、置顶或标记会话未读、恢复本机文件检查点（Checkpoint）、查看与修改本机 MCP 服务器及监听守护进程报告；同时在设备配对审批中新增密码学配对证明（`pairing_proof`）加固信任链。
- **MCP 事件触发后台自动化、交互文档返回与 Kalshi 连接器**：后台自动化现支持由外部 MCP 服务器事件直接触发，MCP 工具调用结果可附带交互式应用文档返回，内置 MCP 扩展新增 Kalshi 连接器（并移除旧版 Outlook、OneDrive 与 Teams 屏蔽列表），支持跨 Git Worktree 共享仓库级 MCP 状态，并为 OAuth 发现在遇到 `429`/`503` 限流时自动启用退避重试。
- **团队权限管理工具、Orbit Airlock 容器门控与空闲自动更新重启**：智能体新增团队协作者权限管理工具（`manage_access`）与支持客户端拒绝的服务端下发代码执行兜底工具（`execute`）；新增基于 Docker/Podman 的 Orbit Airlock 容器化执行门控、桌面空闲时自动重启完成更新、Windows 备用 PowerShell 进程池预热及语音通话开关。
- **「Grok Build」品牌迁移预埋与独立 Agents 窗口公测准备（特性开关默认关闭）**：客户端内预埋默认关闭的 *"Cursor is now Grok Build"* 品牌升级引导弹窗、Grok 日历/购物车/试穿/短信/积分计费接口与 `api.x.ai` 实时语音连通性探测，以及独立 Agents 窗口（`molten`）公测开关与受隐私模式管控的本地 Git 提交 AI 归属统计库。
