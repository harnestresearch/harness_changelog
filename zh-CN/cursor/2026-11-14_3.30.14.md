# Cursor Desktop 3.30.14

[English](../../cursor/2026-11-14_3.30.14.md) | 简体中文 · **精简版 (Highlight)** | [完整详情 (Full Detail)](../full/cursor/2026-11-14_3.30.14.md)

- **发布日期**：2026-11-14（CDN 发布时间：北京时间 `2026-11-14 04:27` / `2026-11-13 20:27:26` GMT；官方 changelog 尚未收录）
- **覆盖平台**：`mac`、`win`、`ubuntu`

## 核心亮点

- **在线 Web 应用发布（「Deploy App」，特性开关默认关闭）**：客户端新增将对话内构建的原型发布为可分享在线 Web 应用的支持（*"Build Live, Shareable Apps with Cursor"* / *"Deploy Folder"*），包含本地对话部署意图检测提示、工程文件上云迁移（自动排除依赖、构建产物与 `.env` 文件）、发布提案审阅确认、已发布应用的更新/重新部署/下线管理，以及本地开发服务器预览卡片（默认关闭，待服务端放量）。
- **企业团队仓库与仓内路径 Glob 细粒度治理**：团队仓库黑白名单规则从「整仓 URL 匹配」扩展为支持通配仓库（`*`）、组织级 URL 通配（`org-*`）及仓内相对路径 Glob 模式；当团队启用允许列表时，未被规则覆盖的路径默认阻断（Cursor 自身数据目录豁免）。
- **禅模式隐藏标签栏、侧聊子代理标记与本地 Grok 配置支持**：Agents（`glass`）窗口新增 *"Hide Tab Bar in Zen Mode"* 文案，侧聊（Side Chat）记录子代理类型，本地守护进程按调用方窗口布局区分会话来源，桌面主进程新增读取本机 `~/.grok` 配置文件与提交 Grok 反馈能力。
- **Electron 运行时补丁升级（`43.8.4` → `43.8.9`）**：macOS、Windows、Linux 三端同步升级 Electron 运行时并重编文件监听与语法树原生绑定；`3.30.8` 的智能体工具集、MCP 宿主与连接器及远程控制（Remote Control）能力全部保持不变。
