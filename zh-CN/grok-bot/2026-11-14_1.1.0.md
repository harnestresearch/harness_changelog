# Grok Bot 1.1.0

[English](../../grok-bot/2026-11-14_1.1.0.md) | 简体中文 · **精简版 (Highlight)** | [完整详情 (Full Detail)](../full/grok-bot/2026-11-14_1.1.0.md)

- **发布日期**：2026-11-14
- **覆盖平台**：`mac`、`win`、`ubuntu`

## 核心亮点

- **Factories 多步骤流水线**：上线基于 YAML 声明式定义的 **Factories** 自动化流水线，支持在桌面端创建、校验、定时调度、立即运行与管理多步骤 Agent 工作流。
- **Cloud Agent 应用托管与页面发布分享**：推出完整的云端应用（Cloud Agent Apps）与页面（Page）发布体系，支持带作用域的 **App Secrets** 密钥绑定管理、发布前安全审查与豁免审批、实时预览以及按团队或组织受众精细化配置分享权限。
- **Spotlight 屏幕元素拾取、本地会议录制与说话人分离**：为 Spotlight 新增屏幕元素拾取覆盖层，引入桌面本地会议录制模块与 **Local Pitman** 本地会议助手流程，并为实时语音转写（STT）增加按说话人分段（Speaker Diarization）能力。
- **消费自动批准、额度上限与 X 应用内审批**：新增可配置的消费自动批准开关与按币种消费限额控制，支持 X Money 消费验证挑战与**“在 X 应用中批准”（Approve in the X app）**确认提示，并扩充商品、外卖订单动态与地点卡片推送。
- **账户手机号验证、手机扫码配对与 GitHub 接入**：新增账户级手机短信验证码绑定、短信验证码表单认证与提交、手机端扫码配对桌面面板，以及原生 GitHub / SCM 代码仓连接流程。
- **Cursor ↔ xAI 团队合并与企业网络安全强化**：上线 Cursor 与 xAI 账号及团队席位合并向导，新增组织级网络封禁名单、团队统一 Tailscale 出口节点（Exit Node）、策略强制沙箱模式（Enforced Sandboxing）、任务标签与会话记录双向关联、话题线程回复，并升级桌面底层运行时。
