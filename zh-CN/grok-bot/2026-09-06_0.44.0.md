# Grok Bot 0.44.0

[English](../../grok-bot/2026-09-06_0.44.0.md) | 简体中文 · **精简版 (Highlight)** | [完整详情 (Full Detail)](../full/grok-bot/2026-09-06_0.44.0.md)

- **发布日期**：2026-09-06
- **覆盖平台**：`mac`、`win`、`ubuntu`

## 核心亮点

- **账号合并与团队级 Bot 管理**：支持自动识别可合并的关联账号并执行账号合并，新增管理员查看与管理团队级 Bot 及成员云沙箱迁移能力。
- **对话内密钥提交与自动审查控制**：支持在对话卡片中响应并安全提交 Bot 请求的凭据密钥，新增自动审查强制开关与云端仓库引导自动配置。
- **安全密钥 PIN 验证与 Linux 自更新**：扩展硬件安全密钥 PIN 码授权交互，并为 Linux 桌面端引入 AppImage 自动更新支持。
