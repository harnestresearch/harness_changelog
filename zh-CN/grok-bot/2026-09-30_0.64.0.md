# Grok Bot 0.64.0

[English](../../grok-bot/2026-09-30_0.64.0.md) | 简体中文 · **精简版 (Highlight)** | [完整详情 (Full Detail)](../full/grok-bot/2026-09-30_0.64.0.md)

- **发布日期**：2026-09-30
- **覆盖平台**：`mac`、`win`

## 核心亮点

- **16 类以上跨平台文档链接识别**：自动识别并展示来自 GitHub、Jira、Confluence、Linear、Google 文档/表格/幻灯片/网盘/日历、Gmail、Slack、Figma、Dropbox、Box、Airtable、Coda、Miro 与 Canva 的深链卡片。
- **指派 Bot 管理员与停用草稿**：支持为 Bot 添加或移除协同管理员、单独停用 Bot 自动起草消息功能，以及从多人聊天室移除成员。
- **语音备忘录波形与金融数据直连**：语音消息新增可视化声波图展示，并优化通过 Plaid 绑定的银行、信用卡、贷款与券商账户查询体验，优先读取真实账目数据。
