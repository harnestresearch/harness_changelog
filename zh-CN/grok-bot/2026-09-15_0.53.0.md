## 核心亮点

- **GitHub PR 专属聊天室**：支持围绕 GitHub 代码合并请求开启聊天室，并在机器人未共享或仓库未开启权限时给出明确原因提示。
- **Slack 私信授权与 1Password 自动同步**：支持 Slack 私信读写权限，应用窗口聚焦时自动同步 1Password 连接状态，并新增团队组沙箱部署配置清单与管理员邮箱审计能力。
