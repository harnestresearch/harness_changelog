## 核心亮点（基于 Linux `x64` `.deb` 与 macOS `arm64` `.dmg` 静态观测）

- **Slack 工作区安装状态机与按 Bot 维度的第三方连接管理**：在客户端协议与多语言文案中新增团队级 Slack 工作区查询、发起安装与卸载状态机（含已安装、限流与拒绝状态及 `"Connect Slack"` / `"Return to Slack"` 文案），并支持按 Bot 维度列出或断开已授权第三方应用（配合 `grok_bot_connected_apps_settings` 开关与连接认证前端分块）。
- **技能（Skill）历史版本回滚与团队发布校验提示**：客户端新增查询与回滚 Skill 历史版本接口（区分人工与 Bot 修订作者）、技能变更对比视图（`chunk-skill-change-diff`）、聊天内技能链接开关，以及团队技能发布前置提示文案（要求填写技能描述并受 Cursor 团队发布权限控制）。
- **公开更新日志通道、订单状态查询、文件库预览与航班检索文案**：新增面向客户端的公开只读 Changelog 查询接口、购物订单状态查询、消息联系人头像读取、区分 Bot 与用户存储的 Agent 文件读取解析及预览/资料库开关，补充 5 条航班搜索进度文案（`"Searching flights"`、`"Checking the fare"` 等），并将状态兜底提示由 `"Backend did not report a status"` 更新为 `"Grok's servers did not report a status"`。
- **MCP 安全治理、Microsoft 365 管理员审批与 Squarespace 连接器**：为 MCP 服务补充 Grok SSO 登录标记与组织拦截原因提示文案，落地团队级 MCP 白名单（allowlist）管理字段与“仅连接器”（`grokConnectorsOnly`）受限访问模式，内置连接器目录新增 Squarespace（`mcp.squarespace.com`），补充 Microsoft 365 五件套（Excel、OneDrive、Outlook、Power BI、SharePoint）图标与租户管理员审批链接（admin consent）引导文案，同时移除桌面端 MCP 应用 iframe `unsafe-eval` 解锁开关与 `allowEval`。
- **Cloud Agent App Secrets 客户端接线、登出直切账号与安全管控**：将 `1.1.0` 已入协议层的 **App Secrets** 子系统首次接线至桌面端 preload（5 个创建、读取、列举可用、拒绝与扩权方法），`logoutCursor` 新增登出后直接切换目标账号参数（`switchToAccountId`），新增可关闭的更新重启提示、短信表单结果存入保险库标志、团队“指定共享人”模式与企业席位授权状态、更严格的本地工具审批目标提示，以及默认关闭的沙箱系统代理自动跟随开关（`sand_system_proxy_auto`）。
- **Android 设备控制工具位与客户端资产调整**：静态代理工具注册表与本地审批枚举新增 `AndroidControlDevice` 工具位，同时从该注册表移除 `CreateTask`、`ReadTask`、`UpdateTask`、`DeleteTrackedTasks` 四个任务 CRUD 工具项（仅属协调器静态工具注册表调整，`UpdateTrackedTaskTags` 仍保留且任务状态新增 `description` 字段，并非下线产品全部任务功能）；客户端移除 `grok_bot_factories` 开关、4 个 Factory preload 遥测方法及相关前端布局分块（底层 Factory RPC 与 Protobuf 定义仍保留）；移除独立的 `telegram.png` / `whatsapp.png` 图标文件但包内平台标识字符串仍保留，属静态资源重组。
