# Grok Bot 0.46.0

[English](../../grok-bot/2026-09-09_0.46.0.md) | 简体中文 · **精简版 (Highlight)** | [完整详情 (Full Detail)](../full/grok-bot/2026-09-09_0.46.0.md)

- **发布日期**：2026-09-09
- **覆盖平台**：`mac`、`win`

## 核心亮点

- **1Password 凭据集成**：支持连接 1Password 服务账户，提供凭据调用请求逐次批准、拒绝与“始终允许”授权管理。
- **GitLab/Bitbucket/Azure DevOps 与 Webhook 通知**：代码托管连接器扩展支持 GitLab、Bitbucket 与 Azure DevOps，并新增针对 PR、代码评审、CI 状态与议题指派的 Webhook 通知配置。
- **插件市场、账号统一与网络诊断**：推出云端 Bot 插件市场、Cursor/Grok 账号统一绑定流程、团队数据导出下载、自动更新通道设置及内置网络诊断调试器。
