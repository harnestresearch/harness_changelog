# Grok Bot 0.79.0

[English](../../grok-bot/2026-11-05_0.79.0.md) | 简体中文 · **精简版 (Highlight)** | [完整详情 (Full Detail)](../full/grok-bot/2026-11-05_0.79.0.md)

- **发布日期**：2026-11-05
- **覆盖平台**：`mac`、`win`

## 核心亮点

- **购物车、虚拟试穿与机票预订**：上线商品检索与相似商品推荐、按 Bot 维度的购物车管理（含规格变体、划线价、优惠码、礼品寄语与退货政策展示）、基于自拍参考照的虚拟试穿预览及机票一键跳转预订。
- **Agent Store 市场**：支持在设置与浏览页发现、发布和共享 Agent Store，提供私有、团队可见与公开三级可见性控制。
- **日历、多平台会议与 iMessage 交互卡片**：内置 Google 日历连接器，支持 Google Meet、Zoom、Microsoft Teams 与 Webex 入会提示操作，并上线支持审批、单选、表单、页面与支付五种形态的 iMessage 交互消息卡。
- **通话中发卡、全文检索与新连接器**：语音通话支持在静音间隙主动播报简报并在通话中直接发送卡片；新增跨会话与文件的全文转写搜索、Yelp 地点详情展示、个人资料照片管理以及 Asana 与 Shopify 连接器。
