# Grok Bot 0.49.0

[English](../../grok-bot/2026-09-11_0.49.0.md) | 简体中文 · **精简版 (Highlight)** | [完整详情 (Full Detail)](../full/grok-bot/2026-09-11_0.49.0.md)

- **发布日期**：2026-09-11
- **覆盖平台**：`mac`、`win`

## 核心亮点

- **Bot 读写画布与连接器扩容**：Bot 现可直接读取和编辑 Canvas 画布内容；正式打通 GitLab、Bitbucket 与 Azure DevOps 授权回调流程，并新增 Linear 议题摘要及 Google BigQuery、Google 幻灯片访问支持。
- **技能、密钥与信息收件人白名单**：支持为 Bot 创建与更新自定义技能、按服务管理凭据密钥，以及查看和撤销 macOS 信息（iMessage）常设允许收件人。
- **团队管理面板与系统强调色跟随**：上线团队上下文、插件与密钥管理专区、市场搜索及成员消费统计，优化 1Password 权限报错提示并支持自动跟随系统主题强调色。
