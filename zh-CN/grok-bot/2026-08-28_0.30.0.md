- **发布日期**：2026-08-28
- **覆盖平台**：`mac`、`win`、`ubuntu`

## 核心亮点

- **macOS iMessage 收发与实时语音通话**：新增 macOS 本地信息（iMessage）读写与媒体解析能力，并正式上线实时语音通话功能。
- **Canvas 画布、虚拟卡审批与用量面板**：推出支持可见性控制的 Canvas 协作画布、虚拟卡交易确认提示以及全新的用量统计面板。
- **14 项连接器扩展与团队合并**：连接器目录扩充至 Microsoft 365、GitHub、Figma、HubSpot、Canva、Zoom、LinkedIn、Trello、Monday 等 14 项服务，支持 xAI 与 Cursor 团队合并流程，并新增阿语、希伯来语、希腊语与南非荷兰语本地化。
