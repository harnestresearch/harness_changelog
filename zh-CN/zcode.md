> 五端（`mac`、`win`、`ubuntu`、`ios`、`android`）完整 123 个历史版本索引（`0.1.7` → `3.18.2`，覆盖桌面三端 `mac` / `win` / `ubuntu`；独立 `ios` / `android` 端暂未发布）见 [zcode/README.md](zcode/README.md)。

## 3.18.2（2026-11-13）

承接上一正式版 [3.17.2](zcode/2026-11-02_3.17.2.md) 的官方正式版（发布于 `2026-11-13`，累计包含下方预览版 `3.18.0` / `3.18.1` 全部改动）。核心亮点见 [zcode/2026-11-13_3.18.2.md](zcode/2026-11-13_3.18.2.md)，完整技术细节见 [full/zcode/2026-11-13_3.18.2.md](full/zcode/2026-11-13_3.18.2.md)。

- **切换数据存储目录后免重新登录**：迁移数据存储目录并拷贝凭据后，自动将系统密钥环中的解密密钥同步共享至新目录，避免切换存储位置后无法登录或被迫重新登录。
- **Linux 无系统密钥环环境登录回退**：Linux 桌面版在缺少系统密钥环服务（Secret Service）时自动回退至 `0600` 权限本地私有文件密钥，解决无密钥环环境无法登录的问题。
- **国内账号（`zai_cn`）免关联 BigModel 使用 Start 套餐**：将 Start 套餐凭据材料与完整 OAuth 令牌解耦，并将 `zai_cn` 账号映射至 BigModel 起始套餐家族，修复未关联 BigModel 的国内账号无法使用 Start 套餐权益的问题。
- **Windows 检查更新兼容性修复**：修复 Windows 在系统限制或路径含特殊字符时检查更新失败的问题。

## 3.18.1（2026-11-11）

核心亮点见 [zcode/2026-11-11_3.18.1.md](zcode/2026-11-11_3.18.1.md)，完整技术细节见 [full/zcode/2026-11-11_3.18.1.md](full/zcode/2026-11-11_3.18.1.md)。

- **macOS 语音输入麦克风权限引导与字体平滑开关**：语音按钮新增五语分步权限引导弹窗（支持一键重置系统麦克风授权），macOS 设置新增「字体平滑」开关并支持跨窗口实时同步。
- **侧栏窄化、网页点选与更新修复**：支持将对话栏拖得更窄，点选网页元素不再跳完整视图或遮挡页面，修复国内用户网站登录失败与更新旧进程残留问题，并在「导出日志」中自动纳入脱敏内存快照。
