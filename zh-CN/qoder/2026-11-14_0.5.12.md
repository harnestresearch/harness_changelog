## 核心亮点（macOS `arm64` 包内静态可证改动）

- **会话恢复（`transcript.resume`）新增 4 条校验字符串（静态字符串证据）**：内置 worker 运行时（`qoder-worker-runtime.obf.mjs`）解密字符串表新增 `transcript.resume.invalid_file_snapshot_skipped`、`transcript.resume.invalid_replacements_skipped`、`transcript.resume.invalid_selected_message` 与 `Transcript resume failed: unsafe (` 四条记录，构成与官方更新说明“修复会话快照/内容替换记录异常导致对话中断”相印证的静态字符串证据（运行期具体跳过或报错恢复行为未经实机运行验证）。
- **Agent SDK 升至 `1.0.60-alpha.50` 与 `qodercli` `1.1.86-hotfix.5` 更新**：内置 `@qoder-ai/qoder-agent-sdk` / `@qoder-ai/qoder-cn-agent-sdk`（`@ali/qoder-agent-sdk-next` / `@ali/qodercn-agent-sdk-next`）由 `1.0.60-alpha.36` 升至 `1.0.60-alpha.50`，`runtime-manifest.json` 中的 `qoderCliVersion` 及按需下载 OSS 模板同步由 `1.1.86-hotfix.4` 升至 `1.1.86-hotfix.5`（Electron 保持 `43.8.4`）。
- **内置 `qoder-office-xlsx` 归档与 `xlsx-sidecar` 重打包**：重编译 Rust `xlsx-sidecar` 并替换 `qoder-office-xlsx` 内置归档包（内部文件清单与源码 commit `84d5b8fb` 不变），同步刷新 `extensions/catalog.v1.json` 文件哈希。

## 官方更新说明对照（本地包内未发现新静态差分证据项）

官方 `0.5.12` 更新日志另列出以下四项说明，在本轮本地 macOS `arm64` 应用包静态比对中**未发现新增静态差分证据**（未检出本地新静态证据**不等于**该功能或修复不存在——相关逻辑可能位于 RC4 混淆的 `electronMain.js` 内部控制流、远端配置/开关，或按需拉取的 `qodercli` `1.1.86-hotfix.5` 运行时包中）：

- **改进自动任务标题**：`app/out/renderer` 在 `0.5.11` 与 `0.5.12` 之间逐字节零变化，worker 相关字符串集合一致。
- **文件变更预览更及时显示 diff 摘要和增删行数**：`app/out/renderer` 字节级零变化，相关字符串集合无增删。
- **修复设备标识缺失导致初始化失败**：解包产物中 `device` / `umid` 相关字符串集合两版一致。
- **自定义模型目录 `reasoning effort` / 关闭 reasoning 识别**：相关校验与界面文案（如 worker 中的 `"does not support reasoning effort / context window"`，以及渲染层 `capabilitiesManagedByCli` `"Vision、Think 和 reasoning effort 由 CLI 校验后返回，此处不支持手动覆盖。"` / 英文同义文案）在 `0.5.11` 与 `0.5.12` 两版中均已存在，本次无字符串级增量。
