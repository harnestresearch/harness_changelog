## 核心亮点（官方 `0.5.20` 更新说明与静态取证对照）

- **云端任务（Cloud Tasks）**：官方说明支持在桌面端创建或继续云端任务、跟踪进度并查看生成文件。macOS `arm64` 静态比对新增 `14` 条 `cloud-session:*` IPC、`automations.*` 主进程 IPC 面、`+6` 条 `AUTOMATION_TASK_*` 错误码（由 `0.5.18` 既有 `2` 条扩至 `8` 条）、渲染层文案（`"The cloud task name is too long. Shorten it and save again."`）及 worker `/tasks` 提示。云端任务依赖服务端配套，未经动态运行验证。
- **跨设备协作（Cross-Device Collaboration）**：官方说明支持从已连接设备的工作区下载文件，并按权限管理该设备上的自动化任务。静态比对新增 `19` 条 `automationPeer.*` 渲染层键、`downloadArtifact`、`chatSession.fileDownload.*` / `Resources/runtime/file-transfer.cjs`，以及 `automations.read.v1` / `automations.manage.v1`（`automationsRead` / `automationsWrite`）权限标记；实际授权粒度以服务端为准，未经运行验证。
- **本地任务恢复（Local Task Recovery）**：官方说明支持在退出或更新 Qoder 后恢复本机符合条件的未完成任务。静态比对新增 `chat-session-recovery:{changed,decide,get}`、`.recoveryPhase`、SQLite 迁移 `20261119-00-chat-session-restart-resumption.sql` 及渲染层文案（`"This run was interrupted while the device was offline or asleep."`、`"Restore all tasks"`）。
- **受管设备登录限制（Managed Device Sign-In）**：官方说明允许企业管理员将受管设备的登录限制为已批准组织的企业账号。静态比对新增 `auth.deviceAccountBlocked.{confirm,description}`、`"Device account policy rejected the current login"`、`"Enterprise VPC sign-in"` 以及 worker 浏览器登录/组织插件管控文案；企业侧策略格式与下发执行依赖服务端，无法静态验证。
- **归档任务按组操作、超大字体与 125% 独立缩放**：官方改进新增本地归档任务按组恢复或删除（搜索结果批量删除仅作用于匹配项）、会话与输入框超大字体及 `125%` 独立界面缩放。静态比对证实新增 `restoreGroupTasks` / `archivedGroupMore` / `deleteArchiveSearchResults*` 文案键，以及 `fontSizeExtraLarge` / `uiScaleExtraLarge` 入口字符串（未见明文排版与缩放参数）。
- **问题修复（附静态归因边界）**：
  - *数据目录迁移后部分插件安装失败；受限 Windows 环境下部分插件后台服务无法启动*：worker 新增归档目录/符号链接安全安装拦截文案（`Refusing to install: archive directory is not a real directory (`）与 `actionId` 重试提示，`pluginHost.js` 增长 `+1,487` B，macOS `arm64` 差分亦移除旧 `Resources/plugin-lifecycle/{WindowsPluginJob.cs,windows-job.ps1}`；但两类具体故障均无法仅凭静态证据逐条归因。
  - *后台断线在前一轮已保存结果后仍阻塞下一轮自动化运行*：与新增 SQLite 迁移 `20261121-00-automation-run-retry-count.sql`、`20261121-01-automation-manual-pending-index.sql` 在结构上吻合（未动态验证）。
  - *已选择有效模型但仍无法开始会话*：worker 新增登出/重选模型引导文案（`Run /auth to sign in again, or /model to choose another model.`），有效模型启动失败根因无法静态逐行归因。
  - *较早消息滞后同步导致 Remote Control 消息乱序*：静态证实新增迁移标识 `20261123-01-async-question-order-clock` 及 `.messageOrder` / `.supportsMessageOrder`。
