## 核心亮点（官方 `0.5.21` 更新说明与静态取证对照）

- **新功能 — AppHub 连接器同步（`streamable_http` 与 `cloud-configuration:*`）**：官方说明新增 AppHub 连接器同步，可将本地已授权的 Streamable HTTP 连接器同步上云，供云端 Agent 与自动化使用。从 macOS `arm64` 解包元数据中独立核实：渲染层新增 `appHubError`、`loadingSyncSources` 与 `streamable_http`（渲染层新增），主进程新增 `cloud-configuration:list-apphub-items`、`cloud-configuration:sync-apphub-vault` 及两条凭据链遥测字符串（`SDK JobToken callback failed`、`SDK JobToken callback returned no credential`）。实际同步执行逻辑位于混淆代码及云端服务中，未经运行时验证。
- **改进 — 修改代理设置后提示重跑网络诊断（静态无法核验）**：官方说明在修改代理设置后，登录页与 Settings 会提示重新运行网络诊断。静态分析未检出对应新明文提示串（与 worker 字符串表零变化及静态差分报告所述“无新增文案”相容）；该项**静态无法核验**，未能在二进制中证实。
- **问题修复（四项官方说明——均静态无法逐条核验）**：
  - *云自动化编辑*：修复编辑云自动化时残留已删除 Skills/连接器，或在资源列表加载完成前提前清空选择的问题。
  - *设备时钟差*：修复设备时钟差误拒有效注册、配对或重连的问题。
  - *系统代理下本机任务模型列表*：修复系统代理环境下本机任务无法加载模型列表的问题。
  - *Windows OpenSSH 主机校验*：修复 Windows OpenSSH 主机校验失败的问题。
  - *静态取证边界*：上述四项修复均见于官方 `2026-11-27` 更新说明；`0.5.20` 与 `0.5.21` 的 worker 解码字符串表均为 `13,966` 条且列表完全一致（零增删），与静态差分报告记录的“无对应修复新文案”相容。四项修复均**静态无法核验**，未能在二进制差分中逐条证实。

## 运行时与打包更新

- **SDK 与 CLI 热修小幅递增**：Electron 维持 `43.8.4`。从 macOS `arm64` 包内 `Info.plist`、`build-manifest.json` 与 `package.json` 直接核实：`@qoder-ai/qoder-agent-sdk`（`npm:@ali/qoder-agent-sdk-next`）与 `@qoder-ai/qoder-cn-agent-sdk`（`npm:@ali/qodercn-agent-sdk-next`）由 `1.0.62-alpha.9` 升至 `1.0.62-alpha.10`，`qoderCliVersion` 由 `1.1.96-hotfix.8` 升至 `1.1.96-hotfix.9`，依赖集合其余部分零变化。
- **热修级包体变化**：盘上复算四包体积变化为 `Qoder-mac-arm64.zip` `−426` B、`Qoder-win-x64-user.exe` `−5,880` B、`Qoder-win-x64-user-app.zip` `+8,652` B、`Qoder-linux-amd64.deb` `+652,764` B。静态差分报告另记录 `app.asar` 仅增 `+13,300` B（主进程 `electronMain.js` 占 `+9,814` B）及内置 `context-plugin` / `office-xlsx` 归档换包（源自静态分析报告记录，未单独重新解包复现）。
