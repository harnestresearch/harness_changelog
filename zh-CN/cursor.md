## 3.30.14（2026-11-14）

核心亮点见 [cursor/2026-11-14_3.30.14.md](cursor/2026-11-14_3.30.14.md)，完整技术细节见 [full/cursor/2026-11-14_3.30.14.md](full/cursor/2026-11-14_3.30.14.md)。_（CDN 发布时间：北京时间 `2026-11-14 04:27` / `2026-11-13 20:27:26` GMT；官方 changelog 尚未收录。）_

### 核心亮点

- **在线 Web 应用发布（「Deploy App」，特性开关默认关闭）**：预埋将对话内构建的原型发布为可分享在线 Web 应用的客户端支持（*"Build Live, Shareable Apps with Cursor"* / *"Deploy Folder"*），涵盖对话部署意图检测提示、项目文件上云迁移（自动排除依赖、构建产物与 `.env` 文件）、发布提案审阅确认、应用更新/重新部署/下线操作，以及本地开发服务器预览卡片。
- **企业团队仓库与仓内路径 Glob 细粒度治理**：团队仓库黑白名单规则从「整仓 URL 匹配」扩展为支持通配仓库（`*`）、组织级 URL 通配（`org-*`）及仓内相对路径 Glob 模式；启用团队允许列表后，未被规则覆盖的路径默认阻断（Cursor 自身数据目录豁免）。
- **禅模式标签栏文案、本地 Grok 配置接入与 Electron `43.8.9` 升级**：Agents 窗口新增 *"Hide Tab Bar in Zen Mode"* 文案，侧聊记录子代理类型，本地守护进程按调用窗口布局区分会话来源，主进程新增读取本机 `~/.grok` 配置与提交 Grok 反馈支持，并在 macOS、Windows、Linux 三端将 Electron 升级至 `43.8.9`。

## 上一版本：3.30.8（2026-11-12）

核心亮点见 [cursor/2026-11-12_3.30.8.md](cursor/2026-11-12_3.30.8.md)，完整技术细节见 [full/cursor/2026-11-12_3.30.8.md](full/cursor/2026-11-12_3.30.8.md)。_（安装包发布时间：Win/macOS 北京时间 `2026-11-12 06:23`，Linux 北京时间 `2026-11-12 10:26`；官方 changelog 尚未收录。）_

### 核心亮点

- **企业级 MCP 策略拦截、二次认证与会话治理**：桌面端正式落地团队级 MCP 服务器白名单、黑名单、Cloud Agent 白名单及只读/按工具级权限管控；后台同步新增 Step-Up 二次认证、第三方 OAuth 应用管理、API Key 资产盘点与团队成员会话吊销。
- **远程控制（Remote Control）能力扩充与配对密码学证明**：远程控制端现支持归档、置顶或标记会话未读、恢复本机文件检查点（Checkpoint）、查看与修改本机 MCP 服务器及监听守护进程报告，并在设备配对审批中引入密码学配对证明（`pairing_proof`）。
- **MCP 事件触发自动化、团队权限工具与容器门控**：支持由外部 MCP 服务器事件触发后台自动化、返回交互式 MCP 应用文档、接入 Kalshi 连接器并跨 Git Worktree 共享 MCP 状态；新增团队权限管理工具（`manage_access`）、基于 Docker/Podman 的 Orbit Airlock 本地轮次门控与空闲自动更新重启，并预埋默认关闭的 *"Cursor is now Grok Build"* 品牌引导与 `molten` Agents 窗口公测能力。

## 近期架构基线版本：3.28.7（2026-11-03）

核心亮点见 [cursor/2026-11-03_3.28.7.md](cursor/2026-11-03_3.28.7.md)，完整技术细节见 [full/cursor/2026-11-03_3.28.7.md](full/cursor/2026-11-03_3.28.7.md)。

### 核心亮点

- **经典 IDE 与独立 Agents 窗口双模式体验**：除完整代码编辑器外提供专为多智能体并行编排设计的独立 Agents 窗口，集中管理本地与云端会话、审阅改动与配置远程协同。
- **手机远程指挥本机任务（Steer from Phone / Remote Control）**：支持通过 6 位配对校验码将电脑与官方 iOS 客户端安全绑定，外出时用手机继续指挥本机智能体（代码检索、文件修改与终端命令仍在本机执行），并提供「保持电脑唤醒」防休眠开关及将本地会话一键迁移上云（Move to Cloud）能力。
- **子代理集群、Canvas 可视化画布与 PR 代码导览**：支持多子代理并行派发与任务进度追踪、Canvas 交互式画布创作、Pull Request 导览视图（Code Tour）生成、上下文窗口占用明细可视化及全库语义检索。
- **内置浏览器自动化与桌面 Computer Use**：内置免配置的浏览器操控与调试能力（支持点击输入、DOM 快照、截图及读取控制台与网络请求日志），并在 macOS 与 Windows 上支持受授权的桌面级应用操控。
- **iOS 锁屏实时活动同步与企业级策略管控**：支持在 iOS 锁屏与灵动岛同步追踪最多 8 个并行智能体状态，并提供细粒度工具白名单审批与团队管理员远程控制策略开关。

## 近期架构基线版本：3.24.12（2026-10-09）

核心亮点见 [cursor/2026-10-09_3.24.12.md](cursor/2026-10-09_3.24.12.md)，完整技术细节见 [full/cursor/2026-10-09_3.24.12.md](full/cursor/2026-10-09_3.24.12.md)。

### 核心亮点

- **独立进程隔离与系统级沙箱保护的 MCP 宿主**：将外部工具连接器放入独立的后台辅助进程运行，并支持操作系统级命令与网络沙箱限制，防止慢速或异常插件阻塞主编辑器界面。
- **零配置内置 IDE 浏览器操控与桌面自动操控**：原生内置两大自动化能力——包含 16 项操作的内置浏览器控制器（页面跳转、无障碍树快照、点击输入、标签页管理、控制台日志与网络请求检查）以及覆盖 macOS 与 Windows 的 17 项桌面级键鼠屏幕操控能力。
- **远程连接器 OAuth 登录、云/端执行位置选择与交互式卡片**：远程连接器支持自动 OAuth 授权登录、选择在云端或本机执行工具调用、按服务筛选启用工具列表、加载 `.env` 环境变量文件，并支持在对话中渲染交互式 HTML 工具界面。
- **项目级配置变更重审批与跨客户端自动发现**：对项目仓库内共享的连接器配置进行摘要校验（配置被修改后自动拦截并要求重新批准），支持细粒度工具免审白名单与企业管理员黑白名单策略，并支持从 Claude Desktop、Windsurf 及 `.vscode` 目录导入已有连接器（首次使用需手动确认信任）。
