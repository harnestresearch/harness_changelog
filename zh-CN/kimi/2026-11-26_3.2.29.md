## 核心亮点（官方 `3.2.29` 更新说明与静态取证对照）

- **Markdown 文件预览新增大纲导航（已坐实）**：官方说明新增 Markdown 文件预览大纲导航。静态比对证实 `obsidianToc` 在 `3.2.28` `app.asar` 中为 `0` 次，在 `3.2.29` 的 macOS 与 Windows 双端均出现于 `WorkbenchPanel` 及 `en-US` / `zh-CN` 语言包（`"文档大纲"` / `"大纲列表"`；`"Document outline"` / `"Outline list"`），并伴随 `WorkbenchPanel` 与 `ObsidianNoteView` 模块更新。
- **全局搜索 UI 与交互优化（已坐实）**：官方说明优化全局搜索 UI/交互。静态比对证实语言包新增 2 条搜索文案键（`showMoreMatches`：`"显示更多匹配"`；`searchOlderConversations`：`"搜索更早的会话"`），macOS 与 Windows 双端的 `GlobalSearchModal` 均更新并引用上述键，同时新增独立的 `GlobalSearchModal` 样式文件。
- **模块级对应项（未逐行验证修复实现）**：
  - *工作台文件树展开收起优化*：macOS 与 Windows 双端均新增 `WorkbenchFileSurface` 模块（`js` + `css`）并更新 `WorkbenchPanel`，但具体防跳动/展开收起代码行无法静态逐行归因。
  - *远程控制权限模式不同步与全自动模式误弹审批*：`preload-permission-flow.mjs`、`permission-flow.html`、`permission-flow` 渲染模块、`RemoteControlPage`、`RemoteControlPreferenceCard` 及 `ApprovalPrompt` 均有更新，但具体跨端同步或全自动拦截行无法静态逐行确认。
  - *发送后听写内容误回填*：双端 `MessageList` 与 `ConversationView` 渲染模块发生更新，具体发送后防回填守卫行未静态锁定。
  - *市场插件授权过期后工具不可用*：双端新增 `use-plugin-install-flow` 模块（`js` + `css`），且 `PluginDetailPage`、`PluginsHubPage`、`PluginInstallModal`、`use-uninstall-plugin` 与 `use-personal-plugin-card-actions` 同步更新，但具体过期恢复/重连路径未逐行锁定。
- **来自官方日志、本轮未独立锁定包内落点的修复**：
  - *移动端键盘遮挡插件/技能列表*、*资料刷新时侧栏顺序跳动*、*图片预览缩放错目标*三项仅据官方 `3.2.29` 更新日志记录，本轮桌面端静态差分未独立锁定对应包内落点（尤其不将 preload 中 `pinch-zoom` 文件的移除作为图片缩放修复的行级证据）。

## 官方未提及的包内改动（未公告）

- **本地文件版本历史子系统（基于 `restic` 快照，可能受 A/B 开关控制）**：本版最大体量变动**官方 changelog 未提及**——新增基于随包 `restic` `0.19.1`（`darwin-arm64/restic` 与 `win32-x64/restic.exe`）的本地文件版本历史、版本比对、AI 改动摘要与一键还原子系统；主进程与 preload 新增 `13` 个独立 `kimi-agent:file-history-*` IPC 通道（`3.2.28` 为 `0` 个），新增 `file-history-client`、`version-diff`、`version-summary`、`restic-resolver`、`repository-key-store`、`maintenance-scheduler`、`process-supervisor`、`lease`、`ab-gate` 等主进程分块及 `restic-bsd-2-clause.txt` 许可文件；`zh-CN` 新增的 `113` 个 key 中，除上述 `2` 个全局搜索文案外，其余 `111` 个均为文件/版本历史与版本比对相关。包内存在 `fileHistoryAbEligible` 与 `isFileHistoryRuntimeEnabled`（及 `ab-gate`），表明功能可能存在 A/B 灰度开关，**不代表对所有用户立即可见**。
- **运行时、内核与网关更新**：Electron / Chromium 维持 `43.7.7` / `150.0.7871.250` 不变；内嵌 `daimon` 智能体内核双端同步升至 `1.0.15`（`1.0.14 → 1.0.15`）；`gateway.asar` 双端各增长约 `+6.4` MB；`package.json` 升级 `pnpm`（`9.15.0 → 12.21.0`）与 `@doc-k/embed-sdk`（`0.5.0 → 0.6.1`）、新增 `geographiclib-mgrs` `1.0.7`，并移除了 `3.2.28` 中的整个 `pnpm` 覆盖/补丁配置段。
