# Kimi Desktop 3.2.25

[English](../../kimi/2026-11-05_3.2.25.md) | 简体中文 · **精简版 (Highlight)** | [完整详情 (Full Detail)](../full/kimi/2026-11-05_3.2.25.md)

- **发布日期**：2026-11-05
- **覆盖平台**：`mac`、`win`

## 核心亮点

- **内置 Kimi Code 本地编程与数据分析工作台**：开箱自带独立的命令行、脚本执行与文件读写环境，无需用户手动配置外部语言运行时即可完成代码编写、数据处理与多步任务编排。
- **macOS 桌面自动操控（Computer Use）与屏幕感知**：在获得系统授权后支持屏幕截图、本地端侧 OCR 文字识别、平滑滚动与键鼠输入、访达（Finder）选中文件感知以及全局快捷唤起输入。
- **MCP 连接器生态、OAuth 授权与网页工具感知**：支持接入本地与远程连接器并内置 OAuth 一键登录与敏感操作交互确认，同时可在内置浏览器中自动识别网页声明的结构化工具。
- **Kimi Slides 演示文稿、LaTeX 排版与 3D 模型预览**：内置演示文稿本地生成与预览能力，并提供本地沙箱化的 LaTeX 学术文档编译、生物信息学序列分析及 3D CAD 模型导入预览。
- **Desktop Claw 跨渠道消息网关与远程协同**：打通桌面工作区与多端即时通讯渠道及移动端远程控制，外出时也能远程查看进度、下发指令与审阅本机文件。
