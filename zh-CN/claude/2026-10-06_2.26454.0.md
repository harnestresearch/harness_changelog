## 核心亮点

- **Quick Write 与内置会话终端**：新增 Quick Write 快捷输入能力（支持受管设备策略开关），内置会话终端仿真能力并增加终端路径安全插入校验。
- **Microsoft 365 与连接器登录管控**：支持直接使用当前 Windows 系统账户登录 Microsoft 365，并新增将连接器登录严格限制在浏览器内完成的策略开关。
- **月度消费限额、应用审核与 IDE 联动**：新增组织成员月度消费限额、MCP 应用界面快速视觉预检、面向 VS Code / Cursor / Windsurf 的 IDE 集成引导，并更新全部内置文档技能与 Office 365 连接器。
