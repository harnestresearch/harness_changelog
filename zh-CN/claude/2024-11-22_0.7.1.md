# Claude Desktop 0.7.1

[English](../../claude/2024-11-22_0.7.1.md) | 简体中文 · **精简版 (Highlight)** | [完整详情 (Full Detail)](../full/claude/2024-11-22_0.7.1.md)

- **发布日期**：2024-11-22
- **覆盖平台**：`mac`、`win`

## 核心亮点

- **MCP 服务管理界面**：新增 MCP 服务安装确认弹窗、本地服务目录选择器以及一键打开 MCP 日志文件入口。
- **开发者模式开关**：在设置中新增开发者模式（Developer Mode）切换选项及安全风险确认提示。
- **设置与主窗口界面重构**：升级设置页与主窗口交互界面，提供更清晰的早期体验反馈入口。
