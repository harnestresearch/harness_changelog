- **发布日期**：2026-11-05
- **覆盖平台**：`mac`、`ubuntu`

## 核心亮点

- **Claude Slides 导入与工具连接中心**：支持将演示文稿一键复制导入至 Claude Slides，并在界面中整合连接 GitHub、SSH 远程主机、办公工具与已连接浏览器的操作流程。
- **项目级规则与跨会话交接**：新增规则（Rules）系统并支持将规则共享给同项目所有成员，同时支持将当前任务平滑交接至新会话继续执行。
- **CLI 按需下载与 IDE 插件引导**：支持按需下载内置 Claude Code 命令行组件并提示就绪状态，同时提供 VS Code 与 JetBrains 官方扩展的一键安装引导。
