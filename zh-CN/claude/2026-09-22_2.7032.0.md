# Claude Desktop 2.7032.0

[English](../../claude/2026-09-22_2.7032.0.md) | 简体中文 · **精简版 (Highlight)** | [完整详情 (Full Detail)](../full/claude/2026-09-22_2.7032.0.md)

- **发布日期**：2026-09-22
- **覆盖平台**：`mac`、`win`、`ubuntu`

## 核心亮点

- **Figma、GitLab 与 Git LFS 支持**：接入 Figma 官方远程连接器、支持 GitLab 连接器与插件市场自动同步，并新增 Git 大文件存储（LFS）支持。
- **防休眠与设备工具开关**：新增本地设备工具启用开关与“允许阻止休眠”（Keep Awake）设置，方便长时间运行任务时防止电脑自动睡眠。
- **企业代码库白名单与身份认证**：支持配置允许访问的 GitHub 仓库白名单、企业启动器包装、身份提供商 OIDC 登录与条件访问排障，并在策略禁止跳过权限时自动切换为“接受编辑”模式。
- **Artifact 作者署名与会话操作**：支持分享 Artifact 时展示作者署名、新增归档会话与需用户确认后才触发的提议卡片，并升级桌面端运行时。
