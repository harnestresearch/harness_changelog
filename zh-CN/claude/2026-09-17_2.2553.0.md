# Claude Desktop 2.2553.0

[English](../../claude/2026-09-17_2.2553.0.md) | 简体中文 · **精简版 (Highlight)** | [完整详情 (Full Detail)](../full/claude/2026-09-17_2.2553.0.md)

- **发布日期**：2026-09-17
- **覆盖平台**：`mac`、`ubuntu`

## 核心亮点

- **云端会话与远程控制管理**：支持将本地 Claude Code 会话无缝切换至“在云端继续”，并提供组织级云端会话与 Remote Control 权限管理开关。
- **PR 自动修复归档与默认 Auto 模式**：将 Auto 模式设为 Claude Code 默认权限模式，支持自定义分支前缀、在 PR 关闭时自动归档会话，并支持自动唤醒会话以处理失败检查、合并冲突与评审意见。
- **内置浏览器管控与组织内共享**：支持在组织内部共享插件与技能，并提供 Cowork 与 Claude Code 内置浏览器的访问控制选项。
- **企业插件白名单与历史迁移**：新增插件服务器 URL 通配符允许清单、Windows 凭据脚本支持、自托管主机登录态系统级安全存储，以及将早期第三方历史会话导入当前组织的能力。
