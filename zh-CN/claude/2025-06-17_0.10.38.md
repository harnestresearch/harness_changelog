## 核心亮点

- **桌面扩展系统（`.cdx`）上线**：支持 `.cdx` 扩展文件关联与本地导入安装，提供兼容性检查与安装预览确认流程。
- **内置 MCP 服务运行宿主**：桌面端自带 MCP 运行环境，无需用户额外配置外部环境即可直接承载本地扩展与 MCP 服务。
- **API Key 管理与智能自动更新**：新增更改与更新 API Key 的界面操作，并上线支持定时检测与空闲自动重启的自动更新及崩溃上报机制。
