# Claude Desktop 1.22209.0

[English](../../claude/2026-07-16_1.22209.0.md) | 简体中文 · **精简版 (Highlight)** | [完整详情 (Full Detail)](../full/claude/2026-07-16_1.22209.0.md)

- **发布日期**：2026-07-16
- **覆盖平台**：`mac`、`ubuntu`

## 核心亮点

- **移动模拟器集成**：在 Claude Code 设置中新增可选开启的 iOS 模拟器与 Android 模拟器工具，支持直接调试与操控移动应用，并提供连续崩溃自动停止重试保护。
- **企业端模拟器管控策略**：新增管理员策略开关，允许组织在受管设备上禁用 Claude 的移动模拟器工具。
- **多端集成中心图标**：为桌面端、移动端、浏览器、IDE 及 Microsoft Office 加载项补齐浅色与深色模式的安装引导图标。
