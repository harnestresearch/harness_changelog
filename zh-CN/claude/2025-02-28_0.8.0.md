# Claude Desktop 0.8.0

[English](../../claude/2025-02-28_0.8.0.md) | 简体中文 · **精简版 (Highlight)** | [完整详情 (Full Detail)](../full/claude/2025-02-28_0.8.0.md)

- **发布日期**：2025-02-28
- **覆盖平台**：`mac`、`win`

## 核心亮点

- **全界面多语言本地化**：菜单栏、MCP 删除确认弹窗与自动更新通知全面支持多语言切换，新增印地语、印尼语、意大利语、巴西葡萄牙语及拉美西班牙语等语言包。
- **丰富菜单栏快捷项**：新增“开始新对话”、“显示主窗口”、“设置快捷键”与“打开文档”等菜单入口。
- **升级桌面底层运行时**：跨大版本升级桌面底层运行时，提升性能与稳定性。
