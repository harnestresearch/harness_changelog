# Claude Desktop 1.0.734

[English](../../claude/2025-11-21_1.0.734.md) | 简体中文 · **精简版 (Highlight)** | [完整详情 (Full Detail)](../full/claude/2025-11-21_1.0.734.md)

- **发布日期**：2025-11-21
- **覆盖平台**：`mac`、`win`

## 核心亮点

- **1.0 发行包精简与启动诊断**：大幅清理冗余构建文件以缩减安装包体积，强化进程间通信安全，并新增启动失败兜底诊断提示框。
- **复制当前链接与 Chrome 登录引导**：菜单新增“Copy URL”一键复制当前页面地址，并细化 Claude for Chrome 扩展的账号登录提示。
- **系统版本要求更新**：原生新特性的最低系统要求由 macOS 12.0 提升至 macOS 13.0。
