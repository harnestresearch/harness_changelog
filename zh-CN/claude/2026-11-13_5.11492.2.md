# Claude Desktop 5.11492.2

[English](../../claude/2026-11-13_5.11492.2.md) | 简体中文 · **精简版 (Highlight)** | [完整详情 (Full Detail)](../full/claude/2026-11-13_5.11492.2.md)

- **发布日期**：2026-11-13（北京时间 `2026-11-13 09:04`；已并入 2026-11-12 发布的 `5.11492.0`）
- **覆盖平台**：`mac`、`win`、`ubuntu`
- **版本号说明**：`5.11492.2` 为紧随 `5.1231.2` 之后采用新日期段编码的更新版本（属 `5.x` 换段演进，并非版本回退）。

## 核心亮点

- **企业受管配置模板导出与更新策略增强**：新增面向企业管理员的配置模板导出窗口，便于在 macOS 与 Windows 上批量部署受管配置；完善强制重启安装更新提示与统一管理台（Unified Claude）指引，并新增在按流量计费网络下暂停下载更新（最长推迟 12 小时）的开关。
- **独立沙箱网络权限与 Chrome 细粒度动作授权**：将沙箱网络访问从网页抓取权限中独立拆分为专属的 `SandboxNetworkAccess` 规则，便于独立管控沙箱联网；Claude for Chrome 新增覆盖点击、输入、滚动、截图及读取页面网络请求等逐动作级别的细粒度授权提示。
- **SSH 主机级设置与大文件分块读取**：新增 SSH 主机级配置与连接管理界面（`SSH hosts`、本机会话列表、主机密钥校验状态说明及 macOS 本地网络隐私提示），并支持在本地智能体会话中对已打开的大文件进行分块续读。
- **连接器多种 OAuth 模式、积分内购与内置浏览器控制**：自定义 MCP 连接器新增四种 OAuth 凭据模式（组织自备客户端 ID、公开客户端元数据 URL、Anthropic 托管凭据及免登录匿名访问），补充应用内积分包购买与身份核验流程，并支持隐藏或停靠最小化状态下的内置浏览器窗格。
- **多媒体嵌入预览、Computer Use 应用识别扩充与安全加固**：新增 Loom、Vimeo、YouTube（含 `youtube-nocookie`）及 Google Drive 文件缩略图预览，在 macOS Computer Use 中提供直达系统麦克风设置的入口，扩充 Adobe/Microsoft 套件、Bloomberg Terminal、Citrix Workspace、Okta Verify、Jamf Self Service、SAP GUI、QuickBooks、Tableau 及 Windows 系统工具等目标应用识别；同时加固 Windows `claude://` 协议参数防注入保护、收紧 Linux 主程序权限位，并补齐 Linux 端 Artifact 外链 CDN 白名单。
