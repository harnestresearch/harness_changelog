## Highlights (Official `3.2.29` Release Notes & Static Evidence)

- **Markdown Preview Outline Navigation (Confirmed Statically)**: Official notes introduce outline navigation in Markdown file preview. Static diffs confirm `obsidianToc` goes from `0` occurrences in `3.2.28` `app.asar` to present in `3.2.29` across both macOS and Windows in `WorkbenchPanel` and the `en-US` / `zh-CN` locale bundles (`"Document outline"` / `"Outline list"`; `"文档大纲"` / `"大纲列表"`), alongside `WorkbenchPanel` and `ObsidianNoteView` asset updates.
- **Global Search UI & Interaction Improvements (Confirmed Statically)**: Official notes highlight global search UI/interaction refinements. Static diffs confirm two newly added search locale keys (`showMoreMatches` — `"Show more matches"` / `"显示更多匹配"`, and `searchOlderConversations` — `"Search older conversations"` / `"搜索更早的会话"`) referenced by updated `GlobalSearchModal` bundles together with a newly added `GlobalSearchModal` stylesheet on both macOS and Windows.
- **Module-Level Corroborated Improvements & Fixes (Not Line-by-Line Verified)**:
  - *Workbench file tree expand/collapse optimization*: Adds a new `WorkbenchFileSurface` renderer module (`js` + `css`) on both macOS and Windows alongside `WorkbenchPanel` changes; exact expand/collapse anti-jitter lines cannot be attributed statically.
  - *Remote control permission-mode sync & spurious approval prompt in full-auto mode*: Updates `preload-permission-flow.mjs`, `permission-flow.html`, the `permission-flow` renderer bundle, `RemoteControlPage`, `RemoteControlPreferenceCard`, and `ApprovalPrompt`; specific sync or full-auto guard lines cannot be verified statically.
  - *Dictation text erroneously refilled after sending*: Updates `MessageList` and `ConversationView` renderer bundles on both platforms; the specific post-send guard cannot be attributed line-by-line statically.
  - *Marketplace plugin tools unavailable after authorization expires*: Adds a new `use-plugin-install-flow` renderer module (`js` + `css`) alongside updates to `PluginDetailPage`, `PluginsHubPage`, `PluginInstallModal`, `use-uninstall-plugin`, and `use-personal-plugin-card-actions`; exact token-expiry recovery logic cannot be verified line-by-line statically.
- **Official Changelog Items Without Independently Located In-Package Targets**:
  - *Mobile keyboard obscuring the plugin/skill list*, *sidebar order jumping when profile data refreshes*, and *image preview zooming the wrong target* are recorded from the official `3.2.29` release notes; no independent in-package target lines were locked down for these three fixes in this static desktop diff (in particular, preload cleanup of `pinch-zoom` is **not** treated as line-level evidence for the image-preview zoom fix).

## Unannounced Package Changes (Not Mentioned in Official Changelog)

- **Local File Version History Subsystem (`restic`-Backed, Possibly A/B Gated)**: The largest change in `3.2.29` is **not mentioned in the official `3.2.29` release notes**—a local file version history, diff/comparison, AI change-summary, and one-click restore subsystem backed by bundled `restic` `0.19.1` binaries (`darwin-arm64/restic` and `win32-x64/restic.exe`), `13` new `kimi-agent:file-history-*` IPC channels (`0` in `3.2.28`), dedicated main-process chunks (`file-history-client`, `version-diff`, `version-summary`, `restic-resolver`, `repository-key-store`, `maintenance-scheduler`, `process-supervisor`, `lease`, `ab-gate`, and related modules), `restic-bsd-2-clause.txt`, and `111` of the `113` newly added `zh-CN` locale keys (the other `2` are the global search keys above). Presence of `fileHistoryAbEligible` and `isFileHistoryRuntimeEnabled` (alongside `ab-gate`) indicates likely A/B gating, so the feature is **not necessarily immediately visible to all users**.
- **Runtime, Agent Kernel & Gateway Updates**: Electron and Chromium remain unchanged at `43.7.7` / `150.0.7871.250`; embedded `daimon` agent kernel advances `1.0.14 → 1.0.15` on both macOS and Windows; `gateway.asar` grows by roughly `+6.4` MB on both platforms; `package.json` updates `pnpm` (`9.15.0 → 12.21.0`), `@doc-k/embed-sdk` (`0.5.0 → 0.6.1`), adds `geographiclib-mgrs` `1.0.7`, and drops the previous `pnpm` overrides/patches configuration block.
