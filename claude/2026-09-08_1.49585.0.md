- **Release Date**: 2026-09-08
- **Platforms**: `mac`, `win`, `ubuntu`

## Highlights

- **macOS 13+ Requirement & Runtime Upgrade**: Upgraded the core desktop runtime across major versions, raising the minimum macOS version to 13.0+ (and macOS 15.0+ using host Xcode frameworks for the lighter iOS Simulator helper).
- **Encrypted Microsoft 365 Account Storage**: Hardened the built-in Microsoft 365 connector to store session account credentials using operating-system encrypted storage.
- **Clearer Error Prompts & Localization**: Added explicit notifications for empty model replies, remote connector tool failures, and administrator-managed updates, alongside translation updates across six languages.
