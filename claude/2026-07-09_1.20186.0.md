- **Release Date**: 2026-07-09
- **Platforms**: `mac`, `win`

## Highlights

- **Claude Browser**: Introduced Claude Browser so Claude can navigate websites and local web apps, click elements, and capture screenshots to complete tasks on your behalf.
- **Cowork Folder Authorization**: Added a per-session folder permission dialog for Cowork, clearer notices when exporting virtual-machine-only files to Google Drive, and a prominent safety warning when Skip all approvals is enabled.
- **Rich Text, Memory & Organization Groups**: Added rich-text annotations and blockquotes, topic-based memory organization, microphone permission guidance, organization group role assignments, and government cloud environment support.
