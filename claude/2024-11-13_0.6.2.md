# Claude Desktop 0.6.2

English | [简体中文](../zh-CN/claude/2024-11-13_0.6.2.md) · **Highlight** | [Full Detail](../full/claude/2024-11-13_0.6.2.md)

- **Release Date**: 2024-11-13
- **Platforms**: `mac`, `win`

## Highlights

- **Multi-Line Quick Window**: Upgraded the Quick Window floating bar from single-line to multi-line text input and added click-outside-to-close behavior.
- **Window Focus & Accessibility**: Added native macOS window focus and accessibility handling to improve Quick Window interaction.
- **MCP Compatibility Update**: Updated local MCP protocol support for broader tool compatibility.
