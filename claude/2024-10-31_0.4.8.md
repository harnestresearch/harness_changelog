# Claude Desktop 0.4.8

English | [简体中文](../zh-CN/claude/2024-10-31_0.4.8.md) · **Highlight** | [Full Detail](../full/claude/2024-10-31_0.4.8.md)

- **Release Date**: 2024-10-31
- **Platforms**: `mac`

## Highlights

- **Desktop Chat & Quick Window**: Launched the macOS desktop app featuring a main chat window, menu bar tray access, and a global-hotkey Quick Window floating input bar.
- **Local MCP Integration Support**: Added foundational support for connecting local Model Context Protocol (MCP) tools and servers.
- **Multi-Language Interface**: Shipped localization support across 10 languages including English, German, French, Japanese, Korean, and Spanish.
