## Highlights

- **Cowork EDR & Plugin Server Blocklists**: Added enterprise Endpoint Detection and Response (EDR) integration settings for the Cowork sandbox VM and wildcard URL blocklists to block unauthorized plugin MCP servers.
- **Enterprise Git & In-Slack Editing**: Added onboarding flows for GitHub organizations, GitHub Enterprise, and self-hosted GitLab instances, alongside direct editing inside Slack.
- **Artifact Retention & Skill Validation**: Added administrative retention policies that permanently delete Artifacts older than a configured maximum age, plus reserved-name checks for custom skills.
