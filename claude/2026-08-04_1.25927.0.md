- **Release Date**: 2026-08-04
- **Platforms**: `mac`, `win`, `ubuntu`

## Highlights

- **Built-In GitHub & Enterprise Connectors**: Bundled native GitHub integration alongside expanded connectivity for Microsoft 365 (including a "My Add-ins" entry), Box, Slack, Google accounts, AWS Bedrock, and Claude for Government.
- **Local Execution Consent & Permission Repair**: Added a dedicated confirmation dialog before running local tasks and a helper utility to resolve local file permission issues.
- **Workspace, Simulator & WSL Guidance**: Improved workspace naming and project deletion flows, added the Pixel 10 Pro Android Emulator device profile, and included step-by-step Windows WSL setup instructions.
