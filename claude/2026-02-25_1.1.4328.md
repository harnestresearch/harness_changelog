# Claude Desktop 1.1.4328

English | [简体中文](../zh-CN/claude/2026-02-25_1.1.4328.md) · **Highlight** | [Full Detail](../full/claude/2026-02-25_1.1.4328.md)

- **Release Date**: 2026-02-25
- **Platforms**: `mac`, `win`

## Highlights

- **Enterprise Admin Controls & Non-Destructive Extension Policy**: Added clear notices when an organization admin disables Cowork or Claude Code for Desktop, and changed disallowed extensions to be disabled in place rather than deleted so they can be re-enabled in other accounts.
- **Cowork Platform Compatibility Prompts**: Added explicit system requirement notices covering macOS 14.0+, Windows 10 build 2004+, and upcoming Windows on Arm support.
- **Self-Healing Settings & Link Error Details**: Automatically resets corrupted local settings files with a "Settings Reset" notice instead of failing to launch, and shows detailed error messages when external links fail to open.
