# Claude Desktop 2.7032.0

English | [简体中文](../zh-CN/claude/2026-09-22_2.7032.0.md) · **Highlight** | [Full Detail](../full/claude/2026-09-22_2.7032.0.md)

- **Release Date**: 2026-09-22
- **Platforms**: `mac`, `win`, `ubuntu`

## Highlights

- **Figma, GitLab & Git LFS**: Added official remote Figma connector integration, GitLab connector and marketplace auto-sync, and Git Large File Storage (LFS) support.
- **Keep Awake & Device Tool Toggles**: Added settings to allow or restrict local device tools and an "Allow keep awake" toggle letting Claude prevent system sleep during active work.
- **Enterprise Repository & Identity Policies**: Added GitHub repository allowlists, corporate launcher support, identity provider OIDC sign-in with Conditional Access troubleshooting, and automatic fallback to "Accept edits" when bypassing permissions is disallowed.
- **Artifact Attribution & Session Actions**: Added author attribution on shared Artifacts, session archiving, confirmation-gated proposal cards, and a desktop runtime upgrade.
