# Claude Desktop 0.7.1

English | [简体中文](../zh-CN/claude/2024-11-22_0.7.1.md) · **Highlight** | [Full Detail](../full/claude/2024-11-22_0.7.1.md)

- **Release Date**: 2024-11-22
- **Platforms**: `mac`, `win`

## Highlights

- **MCP Server Management UI**: Added confirmation dialogs when installing MCP servers, a folder picker for selecting local MCP server directories, and a quick action to open MCP log files.
- **Developer Mode Toggle**: Added an opt-in Developer Mode setting with a safety confirmation prompt.
- **Refreshed Settings & Window UI**: Rebuilt the Settings and main window interfaces for smoother navigation and clearer feedback.
