## Highlights

- **GitHub App Authorization**: Connected the built-in GitHub integration with GitHub App authorization and live repository queries.
- **Scheduled Tasks & Reminders**: Added on-demand "Run now" controls and natural-language scheduling and reminder prompts for recurring daily runs or quick timers.
- **Artifact Sharing & Rich Previews**: Improved Artifact sharing and auto-publish status feedback, paired with richer chart, data table, and diagram rendering in Artifact previews.
- **Windows Automation & Live Previews**: Added support for Windows app automation targets (File Explorer, Notepad, Microsoft Edge), session pop-out windows, and live Computer Use previews.
