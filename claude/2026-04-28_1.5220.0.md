- **Release Date**: 2026-04-28
- **Platforms**: `mac`, `win`

## Highlights

- **Live Cowork Screen Preview**: Added live screen previewing for the Cowork virtual machine environment.
- **Extensions Settings & Link Safety**: Introduced a dedicated Claude Extensions Settings page and a confirmation dialog before opening external links from artifacts, with an option to remember approved link types.
- **Enterprise & PR Controls**: Added admin policies for allowed workspace folders, Cowork outbound domain allowlists, auto-update installation deadlines, external credential helpers, and automatic session archiving when pull requests close.
