# Claude Desktop 0.8.0

English | [简体中文](../zh-CN/claude/2025-02-28_0.8.0.md) · **Highlight** | [Full Detail](../full/claude/2025-02-28_0.8.0.md)

- **Release Date**: 2025-02-28
- **Platforms**: `mac`, `win`

## Highlights

- **App-Wide Localization**: Localized all menu bar items, MCP removal confirmations, and automatic update notifications, expanding language coverage to include Hindi, Indonesian, Italian, Brazilian Portuguese, and Latin American Spanish.
- **Expanded Menu Bar Actions**: Added menu items including "Start New Chat", "Show Main Window", "Set shortcut", and "Open Documentation".
- **Desktop Runtime Upgrade**: Upgraded the desktop runtime to a new major version for improved performance and stability.
