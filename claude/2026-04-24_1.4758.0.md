- **Platforms**: `mac`, `win`

## Highlights

- **11-Language Localization**: Added localized web interface support across 11 locales, including German, Spanish, French, Hindi, Indonesian, Italian, Japanese, Korean, and Portuguese.
- **Enterprise Gateway Settings UI**: Added configuration controls for AWS Bedrock, Google Cloud Vertex AI, Azure AI Foundry, custom inference gateways, and OIDC Gateway SSO.
- **Chrome Extension Onboarding & Personalization**: Added guided pairing instructions for connecting the Claude Chrome extension, session prompt-box glow color customization, crash reporting controls, and an upgraded desktop runtime.
