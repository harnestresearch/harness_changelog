# Claude Desktop 2.110.0

English | [简体中文](../zh-CN/claude/2026-09-15_2.110.0.md) · **Highlight** | [Full Detail](../full/claude/2026-09-15_2.110.0.md)

- **Release Date**: 2026-09-15
- **Platforms**: `mac`, `ubuntu`

## Highlights

- **Model Catalog & Reasoning Effort**: Added organization model catalog support, an "Always start with the default model" toggle, and a five-level default reasoning effort selector (Low, Medium, High, Extra High, and Max).
- **Third-Party & Self-Hosted Inference**: Introduced enterprise settings for third-party and self-hosted inference, including Azure AI Foundry endpoints, interactive Microsoft Entra / OIDC sign-in (via browser or OS broker), and custom credential helper scripts.
- **Approval Sound Alerts & Session Tools**: Added an audio notification chime when a tool awaits approval, surfaced the scheduled tasks toggle in settings, and added actions to clean up inactive sessions, compact context buffers, and commit and open pull requests.
- **Security, Extensions & iOS Simulator**: Enforced stricter local filesystem containment, added clear guidance when extensions need a system Node installation, refreshed Word/Excel/PowerPoint skills, and enhanced iOS Simulator debugging integration.
