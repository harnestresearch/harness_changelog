English | [简体中文](../zh-CN/claude/2026-06-23_1.15200.0.md) · **Highlight** | [Full Detail](../full/claude/2026-06-23_1.15200.0.md)

- **Release Date**: 2026-06-23
- **Platforms**: `mac`, `win`

## Highlights

- **Microsoft 365 Server Configuration**: Added dedicated configuration fields for the built-in Microsoft 365 connector, including Azure cloud environment, tenant ID, client ID, and client secret.
- **Model Picker & Surface Policies**: Added admin controls to customize available models and default model order, offer 1M-context model variants, restrict allowed app surfaces, lock tool approvals, manage plugin marketplaces, and style organization banners.
- **Security & Rate-Limit Controls**: Added Google Cloud KMS options, custom request headers for allowed domains, pause controls for daily and weekly scans, and an option to reset server rate limits.
