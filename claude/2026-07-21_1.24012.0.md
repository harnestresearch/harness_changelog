## Highlights

- **Mobile Simulator Enhancements**: Added simulator screen recording support, automatic Android Studio path detection, and clearer availability notices for iOS Simulator.
- **Contextual Skill Suggestions & Sign-In Alerts**: Added non-intrusive skill recommendations (shown at most once per conversation unless engaged) and clearer prompts when built-in connector sign-in is required or canceled.
- **Interactive Artifacts & Runtime**: Expanded interactive Artifact support for translation, downloads, and permissions, upgraded the desktop runtime for improved stability, and refined Windows WSL Bash mode and pull request status notices.
