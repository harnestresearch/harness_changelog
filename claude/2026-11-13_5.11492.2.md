# Claude Desktop 5.11492.2

English | [简体中文](../zh-CN/claude/2026-11-13_5.11492.2.md) · **Highlight** | [Full Detail](../full/claude/2026-11-13_5.11492.2.md)

- **Release Date**: 2026-11-13 (`2026-11-13 09:04` UTC+8; incorporates `5.11492.0` from 2026-11-12)
- **Platforms**: `mac`, `win`, `ubuntu`
- **Version Note**: `5.11492.2` advances the `5.x` desktop release line into a new date-segment numbering epoch following `5.1231.2` (not a version rollback).

## Highlights

- **Enterprise Configuration Template Export & Update Controls**: Added a dedicated configuration template export window for IT administrators deploying managed Claude Desktop policies across macOS and Windows, expanded enforced update restart controls and Unified Claude Admin Console guidance, and added an option to pause update downloads for up to 12 hours on metered connections.
- **Standalone Sandbox Network Access & Action-Level Chrome Prompts**: Split sandbox network access out of web-fetching permissions into its own `SandboxNetworkAccess` rule so users and administrators can govern sandbox network traffic independently, and added granular per-action permission prompts in Claude for Chrome covering clicks, typing, scrolling, screenshots, and page network request inspection.
- **SSH Host Management & Large-File Session Reads**: Added per-host SSH settings and connection management views (`SSH hosts`, local computer sessions, host-key verification diagnostics, and macOS local-network privacy notices), plus chunked continuation reads so local agent sessions can reliably read large open files.
- **MCP Connector OAuth Modes, Credit Purchases & Built-in Browser Controls**: Added four OAuth client credential modes for custom MCP connectors (organization-supplied client ID, published client metadata URL, Anthropic-managed credentials, or unauthenticated access), an in-app credit bundle purchase and step-up verification flow, and docked/minimized controls for the built-in Browser pane.
- **Richer Media Previews, Computer Use Polish & Platform Hardening**: Added Loom, Vimeo, YouTube (`youtube-nocookie`), and Google Drive file thumbnail previews, a direct macOS Microphone Settings shortcut for Computer Use, expanded desktop application recognition (Adobe and Microsoft suites, Bloomberg Terminal, Citrix Workspace, Okta Verify, Jamf Self Service, SAP GUI, QuickBooks, Tableau, and Windows system utilities), hardened Windows `claude://` protocol argument handling, tightened Linux binary permissions, and brought Artifact CDN allowlists on Linux to parity with macOS.
