# Claude Desktop 0.13.11

English | [简体中文](../zh-CN/claude/2025-09-12_0.13.11.md) · **Highlight** | [Full Detail](../full/claude/2025-09-12_0.13.11.md)

- **Release Date**: 2025-09-12
- **Platforms**: `mac`, `win`

## Highlights

- **Recent Chats in Menu Bar & Dock**: Added a recent conversations list to the macOS menu bar and Dock menu for one-click switching.
- **Dictation Microphone Permission Guidance**: Added step-by-step instructions and a shortcut to open System Settings when microphone access is missing, plus clear messaging if restricted by device management.
- **Desktop Runtime Upgrade**: Upgraded the desktop runtime to a new major version for improved stability and performance.
