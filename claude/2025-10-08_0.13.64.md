- **Release Date**: 2025-10-08
- **Platforms**: `mac`, `win`

## Highlights

- **Claude for Chrome Integration**: Introduced onboarding prompts and Chrome Web Store links to connect the Claude for Chrome browser extension with Claude Desktop for browser tools.
- **New Anthropic Typography**: Refreshed typography across the app with the new Anthropic Sans and Anthropic Serif variable typefaces.
- **Quick Entry Error Feedback & Org Extension Trust**: Added UI error feedback if a Quick Entry submission fails and cryptographic verification for organization-managed extensions.
