- **Release Date**: 2026-09-11
- **Platforms**: `mac`, `ubuntu`

## Highlights

- **Native OpenSSH Engine**: Added support for using the system's native OpenSSH client alongside the built-in SSH client for remote host connections, complete with password prompt support and Windows installation guidance.
- **Certificates & Session Approvals**: Added status feedback when clearing CA certificate and mTLS caches, clearer notices that session approvals last until the session ends, and improved capability checks for interactive connector prompts.
- **Process Naming & Localization**: Clearly labeled the desktop terminal host in system activity monitors and refreshed dynamic translations across all supported languages.
