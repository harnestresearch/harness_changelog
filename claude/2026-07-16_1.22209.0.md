- **Release Date**: 2026-07-16
- **Platforms**: `mac`, `ubuntu`

## Highlights

- **Mobile Simulator Tools**: Added opt-in iOS Simulator and Android Emulator integrations under Claude Code settings so Claude can inspect and interact with mobile apps directly, complete with automatic stop-after-crash protection.
- **Enterprise Simulator Policy**: Added an administrative policy allowing organizations to block Claude's mobile simulator tools on managed devices.
- **Integration Hub Icons**: Added light and dark mode icons across the installation hub for desktop, mobile, browser, IDE, and Microsoft Office add-in integrations.
