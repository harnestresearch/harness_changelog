- **Release Date**: 2026-11-05
- **Platforms**: `mac`, `ubuntu`

## Highlights

- **Claude Slides & Work Tool Connections**: Added support for copying presentations directly into Claude Slides alongside unified UI flows to connect GitHub, SSH hosts, work tools, and connected browsers.
- **Project Rules & Session Handoff**: Added custom rules that can be kept personal or shared across everyone on a project, plus seamless session handoff when Claude transitions ongoing work to a new session.
- **On-Demand CLI & IDE Extensions**: Added on-demand Claude Code CLI downloads with readiness notices and guided installation links for official VS Code and JetBrains extensions.
