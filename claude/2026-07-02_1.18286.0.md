- **Platforms**: `mac`, `win`, `ubuntu`

## Highlights

- **Chat Memory**: Added a setting allowing Claude to generate persistent memory from your conversations.
- **In-Session Dev Preview**: Expanded live preview controls so stopping a preview leaves the local port running in the session, with clearer feedback for server startup errors.
- **Office Agents, Slack & Security**: Added organization default model selection across Chat, Cowork, and Office Agents, Slack channel search, OAuth callback port settings, and prompt-injection warnings for artifacts.
