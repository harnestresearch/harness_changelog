English | [简体中文](../zh-CN/claude/2026-04-07_1.1062.0.md) · **Highlight** | [Full Detail](../full/claude/2026-04-07_1.1062.0.md)

- **Release Date**: 2026-04-07
- **Platforms**: `mac`, `win`

## Highlights

- **Enterprise Inference Gateways**: Added managed configuration support for custom LLM gateways, AWS Bedrock, Google Cloud Vertex AI, and Azure AI Foundry, including model allowlists and token window limits.
- **Managed MCP on Windows**: Added support for reading organization-managed MCP server configurations from the Windows Registry.
- **Local Transcript Search**: Introduced a local search service for finding past conversation transcripts on desktop.
