# Claude Desktop 1.0.734

English | [简体中文](../zh-CN/claude/2025-11-21_1.0.734.md) · **Highlight** | [Full Detail](../full/claude/2025-11-21_1.0.734.md)

- **Release Date**: 2025-11-21
- **Platforms**: `mac`, `win`

## Highlights

- **1.0 Release Cleanup & Launch Diagnostics**: Slimmed down the desktop application package, strengthened inter-process security, and added a fallback diagnostic dialog if the app fails to launch.
- **Copy URL & Chrome Auth Prompts**: Added a "Copy URL" menu item to copy the current conversation address to the clipboard, plus clearer sign-in guidance for the Claude for Chrome extension.
- **Updated macOS Requirement**: Raised the minimum OS requirement for newer native features from macOS 12.0 to macOS 13.0.
