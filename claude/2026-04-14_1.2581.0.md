- **Release Date**: 2026-04-14
- **Platforms**: `mac`, `win`

## Highlights

- **Folder Authorization**: Added a clear permission prompt when Claude requests access to a local folder on your computer.
- **Cowork File Preview**: Introduced in-app file and PDF previewing for Cowork sessions and artifacts.
- **Python MCP Extensions**: Added Python runtime support for desktop extensions and user-added MCP servers, plus clearer permission-denied guidance in connector settings.
