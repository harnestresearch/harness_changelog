- **Platforms**: `mac`, `win`, `ubuntu`

## Highlights

- **GitHub PR & Remote Workflows**: Added built-in support for inspecting pull request reviews, checks, comments, merge queues, and auto-merge, alongside remote SSH session status feedback and background workspace file indexing.
- **Slack Connector & Document Collaboration**: Added guided setup for the Slack connector and drag-and-drop collaboration support for Word, Markdown, and plain-text documents.
- **Preview Permissions & Local Approvals**: Added trusted-site permissions for Preview tools, persistent cookies and storage across restarts in preview tabs, and clear guidance that skipping all approvals runs locally only.
