# Claude Desktop 0.11.3

English | [简体中文](../zh-CN/claude/2025-06-26_0.11.3.md) · **Highlight** | [Full Detail](../full/claude/2025-06-26_0.11.3.md)

- **Release Date**: 2025-06-26
- **Platforms**: `mac`, `win`

## Highlights

- **Desktop Extensions (`.dxt`)**: Transitioned extension packages from `.cdx` to `.dxt` with Markdown-rendered extension descriptions and version update controls.
- **Extension Security & Blocklist Protection**: Added signature verification, controls for unsigned or directory-loaded extensions, and automatic removal of blocked extensions with a clear notification dialog.
