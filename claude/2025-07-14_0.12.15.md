# Claude Desktop 0.12.15

English | [简体中文](../zh-CN/claude/2025-07-14_0.12.15.md) · **Highlight** | [Full Detail](../full/claude/2025-07-14_0.12.15.md)

- **Release Date**: 2025-07-14
- **Platforms**: `mac`, `win`

## Highlights

- **Voice Dictation**: Introduced macOS voice dictation support with system microphone and speech-recognition permission prompts, plus Caps Lock and double-tap Option trigger handling.
- **Quick Entry with Image Attachments**: Upgraded the `Option+Space` Quick Entry bar to support submitting prompts with attached images.
- **Unified Web Settings**: Retired the standalone local Settings window in favor of managing settings directly within the main Claude interface, while streamlining `.dxt` extension install prompts.
