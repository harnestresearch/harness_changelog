# Claude Desktop 5.1231.0

English | [简体中文](../zh-CN/claude/2026-11-10_5.1231.0.md) · **Highlight** | [Full Detail](../full/claude/2026-11-10_5.1231.0.md)

- **Release Date**: 2026-11-10
- **Platforms**: `mac`, `ubuntu`

## Highlights

- **Built-In Browser Chrome Extensions**: Added direct Chrome Web Store installation, automatic updates, permission warnings, and extension management inside Claude Desktop's built-in browser.
- **1Password Credential Autofill**: Added agentic autofill integration with 1Password so Claude can request permission to sign in using saved logins during browser tasks.
- **Interactive 3D Artifacts**: Introduced hardware-accelerated 3D rendering for interactive Artifacts with physically based lighting and tone mapping.
- **Cowork Plugins & Session Controls**: Added Cowork plugin directory support, quick Remote Control session disconnect controls, dictation availability notices, and a major desktop runtime upgrade.
