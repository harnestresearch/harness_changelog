## Highlights

- **AWS Bedrock SSO**: Added AWS IAM Identity Center browser sign-in support for enterprise Amazon Bedrock connections.
- **Enterprise Sign-In & Tool Governance**: Enabled administrators to hide Anthropic sign-in when using third-party gateways, lock approval states for specific tools while leaving others user-controlled, and block local metadata network addresses.
- **Device Simulator & Runtime**: Added macOS device simulator panel status notices and upgraded desktop runtime for improved stability and performance.
