## Highlights

- **Built-in Document & Design Skills**: Bundled six always-available skills for creating, reading, and editing Word (`docx`), PDF (`pdf` and PDF reading), PowerPoint (`pptx`), and Excel (`xlsx`) documents, as well as frontend design.
- **GitHub & Project Workflows**: Added support for cloning GitHub and GitHub Enterprise repositories directly into a session, clearer GitHub App repository lookup notices, project creation, leave, and deletion controls, and usage credit toggles.
