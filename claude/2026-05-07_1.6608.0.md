## Highlights

- **Cowork Artifact Sharing**: Added support for sharing Cowork artifacts and opening shared artifacts directly via deep links, with clear prompts when sharing is disabled or an artifact exceeds the character limit.
- **Storage & Sandbox Hardening**: Transitioned Cowork session storage to web-backed cloud storage for a lighter desktop footprint and strengthened sandboxed file-access protections.
