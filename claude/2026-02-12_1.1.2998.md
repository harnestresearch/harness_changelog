## Highlights

- **Reinstall Cowork Workspace**: Added a "Reinstall workspace" flow (with an option to submit feedback first) that re-downloads the workspace while preserving existing session data.
- **Network Log Diagnostics**: Added a "Record Net Log (30s)" diagnostic action to capture network traces for troubleshooting.
- **Desktop Runtime Upgrade**: Upgraded the desktop runtime to a new major version for improved performance and stability.
