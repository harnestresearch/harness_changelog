- **Release Date**: 2026-11-14 (`2026-11-14 05:03` UTC+8; ~20 hours after `5.11492.2`)
- **Platforms**: `mac`, `win`, `ubuntu`

## Highlights

- **Enterprise Managed File-Read Policy & Auto-Mode Guidance**: Added a dedicated `blockFileToolReadsOutsideWorkingDirectories` managed setting governing one-time file-read authorization prompts in auto-mode alongside `blockWritesOutsideWorkingDirectories`, and clarified in the managed settings reference how machine-wide `env.CLAUDE_CODE_AUTO_MODE_MODEL` replaces the auto-mode review model.
- **Office Document Skill Security & Large-Document Diff Hardening**: Hardened the bundled `docx`, `pptx`, and `xlsx` validation tools against Windows-style drive/root path traversal and out-of-bounds OOXML relationship targets, and replaced external `git diff` subprocesses during document redlining with a work-bounded diff algorithm to prevent resource exhaustion on large documents.
- **Engine Session Storage Integrity & Session Archiving**: Added a structured local storage key validation layer in the embedded Claude Code engine covering transcripts, session journals, agent memory, tasks, drafts, `jobs-root`, recovery copies, plugin caches, and three-tier (`user`/`project`/`local`) settings, plus `setSessionArchived` support laying groundwork for cloud-to-local task synchronization.
- **Multilingual Browser Extension & Billing Localization**: Added ~48 translated strings across 10 non-English locales for built-in browser extension installation, removal, permission, and CRX content verification prompts as well as subscription, auto-reload, VAT, and credit expiration (`2026-09-10`) consent copy, alongside refreshed Cowork sandbox images across platforms (with no new English desktop UI changes over `5.11492.2`).
