- **Release Date**: 2026-01-12
- **Platforms**: `mac`, `win`

## Highlights

- **Feedback with Debug Logs**: Restored "Submit Feedback" with an optional toggle to attach diagnostic debug logs directly to issue reports.
- **Browser Site Authorization Guidance**: Added clear trust reminders advising users to grant "always allow" browser permissions only to trusted websites.
- **Local Agent VM & Skills Support**: Added menu controls to reset VM sessions/bundles and enable VM debug logging, alongside foundational support for syncing and mounting Skills in local agent sessions.
