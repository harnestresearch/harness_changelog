# Claude Desktop 0.10.38

English | [简体中文](../zh-CN/claude/2025-06-17_0.10.38.md) · **Highlight** | [Full Detail](../full/claude/2025-06-17_0.10.38.md)

- **Release Date**: 2025-06-17
- **Platforms**: `mac`, `win`

## Highlights

- **Desktop Extensions (`.cdx`)**: Launched extension installation from `.cdx` files with double-click file association, compatibility checks, and preview confirmation dialogs.
- **Built-In MCP Server Host**: Added a built-in runtime host so local MCP servers and extensions can run without requiring a separate external Node installation.
- **API Key Management & Smart Auto-Updates**: Added UI controls to view and update API keys, plus scheduled idle-aware automatic app updates and crash reporting.
