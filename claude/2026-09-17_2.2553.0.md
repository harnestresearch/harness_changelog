# Claude Desktop 2.2553.0

English | [简体中文](../zh-CN/claude/2026-09-17_2.2553.0.md) · **Highlight** | [Full Detail](../full/claude/2026-09-17_2.2553.0.md)

- **Release Date**: 2026-09-17
- **Platforms**: `mac`, `ubuntu`

## Highlights

- **Cloud Sessions & Remote Control**: Added "Continue in cloud" handoff for Claude Code sessions along with organization settings to enable or turn off cloud sessions and Remote Control.
- **Pull Request Automation & Auto Mode**: Made Auto mode Claude Code's default permission mode, added automatic session archiving when pull requests close, custom branch prefixes, and PR auto-fix to address failing checks, merge conflicts, and review comments.
- **Built-In Browser & Organization Sharing**: Added intra-organization plugin and skill sharing plus access controls for the built-in browser in Cowork and Claude Code.
- **Enterprise Plugin & Migration Governance**: Added wildcard URL allowlists for plugin MCP servers, OS-encrypted sign-in state storage for self-hosted hosts, Windows credential helper support, and importing earlier third-party session history into an organization.
