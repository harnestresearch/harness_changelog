## Highlights

- **Sign-In Status Bar & Cross-Window Auth Sync**: Upgraded the status bar button from a static settings shortcut to an authentication-aware indicator—clicking while signed out launches sign-in directly, while signed-in states open a quick status menu—paired with new Sign In / Sign Out commands, automatic authentication sync across open IDE windows, and enterprise/Google Cloud Terms-of-Service state tracking.
- **Clearer Current-File vs. All-Files Diff Review & New Shortcuts**: Renamed inline and side-by-side diff actions to clarify when changes apply only to the **Current File**, added dedicated **Accept All Changes** and **Reject All Changes** commands across **All Files**, added commands to start a new conversation, toggle chat focus, and insert terminal output, split `Ctrl+L` and `Ctrl+Alt+L` terminal shortcuts between code snippets and terminal output, and refined `autoAcceptOnChat` to non-cumulative review behavior.
- **Background Task, Media & Browser Recording Bridge Support**: Expanded the IDE-to-agent webview communication bridge to support background task management (`ManageTask`), media processing, browser recording, and focus/authentication synchronization.
- **Cloud Workstation Pre-Installed CLI Detection & Reliable Local Startup**: Automatically detects pre-installed `/usr/bin/agy` binaries in Google Cloud Workstations and Cloud Shell environments (skipping unnecessary runtime CLI downloads), adds port-collision retry when launching the local `agy` hub service, and tags in-app feedback with an Antigravity IDE product identifier (`antigravity.isAntigravityIde`).
