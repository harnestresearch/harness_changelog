## Highlights

- **Background Update Checks, Instant Startup & Anti-Downgrade Protection**: Built-in `agy` extension (`1.11.0` → `1.12.0`) adds periodic background update checks with a **"Restart Agent Server"** prompt when an update is staged, defers release checks at startup so already-installed backends launch without blocking activation, and introduces update-decision guards (`downgrade_skipped`, `same_version_rebuild`, `staged_promoted`, `check_deferred`) to prevent multi-window backend downgrades and repeated downloads after recovery timeouts.
- **Remote Sign-In Port Forwarding, Auth-Code Fallback & Custom CA / Proxy Support**: Adds remote-environment sign-in port forwarding and out-of-band authorization-code fallback (`SwitchLoginToAuthCode` direct RPC call targeting the runtime `agy` backend) across `ssh-remote`, `dev-container`, `attached-container`, `cloud-shell`, `cloud-workstations`, and `codespaces`, alongside a new `antigravity.caCertificates` setting and full custom root CA / enterprise proxy resolution (`AGY_*`, `NODE_EXTRA_CA_CERTS`, `SSL_CERT_FILE`, VS Code `http.proxy*`, and dual-prefix `geminicodeassist` trusted certificates).
- **Agent Panel Find-in-Conversation Shortcut & Expanded Webview Bridge (`+26` Schemas)**: Adds the `Ctrl+F` (`Cmd+F` on macOS) **Find in Conversation** shortcut when the Agent panel or chat is focused (forwarding to the agent webview), and expands the synchronized IDE-to-webview protocol bridge by `+26` schemas covering resolved customizations (skills, rules, subagents, hooks), harness/experimental tool-call steps, model-catalog/plan-execute configuration, and document/spreadsheet/embedding content layers.
- **Code OSS Base Frozen for a Third Consecutive Release — Official Notes Reconciliation**: All substantive code changes again live exclusively in `extensions/agy/` (`3` files, `+66.9` KB) plus macOS-only MSAL native library rebuilds, while `out/`, the `11.8 MB` `jetskiAgent` renderer, the `351`-method `LanguageServerService` descriptor, and `node_modules/` remain substantively unchanged across `2.6.0` → `2.7.0` → `2.8.0`. Across the `12` official `v2.8.0` items, `4` are directly corroborated in `extensions/agy/`, `3` are corroborated via static cues or command entry points, and `3` (*60s backend readiness timeout*, *Windows logoff/shutdown recovery loop fix*, and *Windows multi-window notification focus fix*) lie outside the static IDE package (in the runtime-downloaded `agy` CLI or remotely loaded webview).
