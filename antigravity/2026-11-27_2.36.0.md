## Highlights

- **Third Consecutive Version-Only Shell paired with a Rebased Feature `language_server`**: Relative to [2.35.2](2026-11-25_2.35.2.md), the `1,167`-file (`20,690,656` B) Electron `44.9.1` desktop shell (`app.asar`) again differs **solely** in `package.json` `version` (`2.35.2` → `2.36.0`), with `chrome-devtools-mcp` `1.12.0` unchanged and byte-identical `app.asar` across all six targets. By contrast, the bundled Go `language_server` is a full release-branch rebase (`cl/1029311855` → `cl/1031268331`, baseline `1027784732` → `1030397722`; `darwin-arm` `−717,648` B, `strings` `+58,899 / −58,470`), and macOS `agy-desktop-rtc` grows by `+22,592` B (`~+22.6` KB) alongside backend remote-control Mesh transport additions.
- **Official `v2.36.0` Release Notes (`13` Improvements, `26` Fixes) — Static Corroboration vs. Webapp Scope**:
  - **Statically corroborated in client packages**: Desktop-initiated authorization for **cloud automations on remote agents** (backed by a new Trigger RPC family and `JetskiRemoteAgentProxyService` proxy layer in `language_server`, while the browser Google sign-in flow lives outside the binary) and **custom skill discovery in `~/.agents/skills`** with `~/.gemini` precedence (corroborated in `language_server` discovery paths and migration docs).
  - **Hub webapp / server-side (not provable statically from client packages)**: Headline UI/policy entries—including the **floating composer pill** in maximized side panels, **expanded Auto mode** cross-repo safe edits and non-replacing file additions, **spoken voice-call context** handoff into local conversations (only weak circumstantial voice-string growth in `language_server`), **MCP server OAuth offline access**, **Windows/Linux File & Zoom logo submenus**, **Installed tab 16-plugin pagination**, **LaTeX math in subagent replies**, **conversation summary memory/disk savings**, and the **26 fixes** (e.g., `localhost` HTTP default, macOS `Option+Cmd+/` shortcuts, Orchestrator single-agent same-model fix, `System default` microphone, mid-session OAuth token retry, Windows cross-drive plugin lookup)—cannot be individually verified from the static client packages because the Electron shell is version-only.
- **Unannounced Backend Expansion (Remote Agent Management, Mesh Transport, Security & Telemetry)**: Statically detected backend additions not detailed in the official notes include `+34` Connect-RPC methods (`338` → `372`, spanning remote agent lifecycle, files/workspace permissions, sidecars, triggers, and blueprints, partially under a new `JetskiRemoteAgentProxyService`), a **RemoteControl Mesh transport** with WebChannel fallback, **sensitivity classification** (`policyguardian/sensitivity`) and **Proctor J1/C8** supply-chain/firewall rules (querying `deps.dev` and GitHub advisories), **Sentry Go SDK** integration, `4` newly named feature flags (including `enable-resume-conversations-from-restart` and `enable-sidecar-pill-auto-open` for earlier `2.35.1` features), and a model eligibility tag rename (`neonccpa` → `neondefault`, keeping `44` models, `65` `*ToolConfig`, and `19` CUA actions unchanged).
- **Six-Target Same-Build Alignment (First `windows-arm64` Coverage)**: Official packages across all six targets (`darwin-arm`, `darwin-x64`, `linux-x64`, `linux-arm` [archive root `Antigravity-arm64/`], `windows-x64` [`app-64.7z`], and `windows-arm64` [`app-arm64.7z`]) share the exact same `app.asar` digest (`d2bc25ea…`), with `cl/1031268331` confirmed on all four macOS/Linux builds (Windows `x64`/`arm64` `language_server` PEs remain uncovered).
